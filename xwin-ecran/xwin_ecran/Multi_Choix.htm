Multi-choix

La boîte de dialogue affiche les différents choix de l'entrée du dictionnaire sélectionnée.

  • Pour ajouter un nouveau choix, saisissez ses paramètres puis cliquez sur le bouton Ajouter avant ou sur le bouton Ajouter Après. L'insertion se fait par rapport au choix préalablement sélectionné dans la liste.

  • Pour modifier le choix sélectionné dans la liste, saisissez ses nouveaux paramètres puis cliquez sur le bouton "Modifier".

  • Pour supprimer le choix sélectionné dans la liste, cliquez sur le bouton Supprimer.

   

Les choix sont des bitmaps

Cette case à cocher permet de préciser que les choix ne sont pas des textes mais des images. Un choix peut alors être :

  • Soit un nom de bitmap de la feuille de styles.

  • Soit un nom de fichier contenant le dessin (.gif, .jpg, .png, .bmp, .rle, .dib, .tga, .tif).
    Remarques :
    Il est déconseillé d'utiliser des fichiers .ico.
    Pour obtenir un visuel agréable, il est par contre conseillé d'utiliser des images ayant toutes la même taille.

La variable associée est obligatoirement de type numérique.

Voir Les multi-choix.

 

Type de choix

On distingue les types suivants :

  • Normal : Il s'agit d'un texte simple.

  • Autre liste de choix : Pour insérer des choix d'une autre entrée du dictionnaire.

  • Tableau : Les choix se trouvent dans un tableau Diva (le garnissage de ce tableau est à la charge du programme).

  • Liste : Les choix se trouvent dans une liste Diva (le garnissage de cette liste est à la charge du programme).

Dans un même multi-choix, il est possible de mixer ces quatre types à volonté.

 
 

1. Choix de type "Normal"

Si la valeur du choix est une constante, sélectionnez le radio-bouton Normal et garnissez les champs suivants :

Texte  

Libellé du choix.

Valeur

Valeur associée au choix.
C’est cette valeur qui sera transférée dans la donnée associée au multi-choix.
Si la valeur est omise, voir Multi-choix alpha et multi-choix numérique.

Noms

Noms pour les attributs dynamiques.
Ces noms permettent de modifier dynamiquement (par programme) la liste des choix proposés à l’utilisateur. En particulier, ils permettent qu'un multi-choix placé dans une colonne de tableau présente des choix différents selon la ligne.

Le fonctionnement des attributs dynamiques est expliqué en détails dans le livre de la documentation Xwin - Programmation consacré à Ywpf (rubriques consacrées aux fonctions XmeSetAttribut ou XmeListSetAttribut).

Exemple :

Célibataire - 1

Marié - 2

Divorcé - 3

Veuf - 4

 

 

2. Choix de type "Autre liste de choix"

Ce type de choix permet d'intégrer dans un multi-choix la liste des choix d'un autre multi-choix. Sélectionnez le radio-bouton Autre liste de choix et garnissez le champ :

Autre Choix ou Liste

Nom d'un autre multi-choix déjà défini dans le dictionnaire, précédé du caractère #.

Remarque : cette possibilité est rarement usitée.

 

 

3. Choix de type "Tableau"

Un multi-choix peut proposer des choix constants (lorsque les différents choix sont connus dès la conception du masque) mais aussi des choix variables (lorsque les choix sont seulement connus à l'exécution du masque). Dans ce dernier cas, une première solution consiste à les ranger dans un tableau Diva à une dimension.

Remarquez bien que ce tableau est une donnée différente de la donnée multi-choix elle-même. Le programme doit impérativement remplir le tableau avant l'affichage ou la saisie de la page concernée. Chaque élément du tableau doit être garni avec un choix du multi-choix.

Attention : dans ce cas, il n’est pas possible d’associer aux choix une valeur ou des noms (pour ce faire, utilisez les choix de type "Liste").

 

Sélectionnez le radio-bouton Tableau et garnissez les champs suivants :

Enreg  

Instance de l'enregistrement contenant le tableau.

Donnée  

Nom de la donnée tableau.

Indice Début  

Indice du premier choix dans le tableau.

Indice Fin  

Indice du dernier choix dans le tableau.

 

Exemple : Nous voulons proposer des choix tenant compte du sexe de la personne considérée. Pour ce faire, nous déclarons dans le dictionnaire un tableau de 4 éléments alpha-numériques de taille 11 et nous remplissons ce tableau dans la séquence de traitements appelée avant l'affichage de la page de masque :

Record demodd travail            ;contient le tableau TabEtat

 

travail.TabEtat (1) = 'Célibataire'

if sexe = 'M'

   Travail.TabEtat(2) = 'Marié' 

   Travail.TabEtat(3) = 'Divorcé' 

   Travail.TabEtat(4) = 'Veuf' 

else

   Travail.TabEtat (2) = 'Mariée' 

   Travail.TabEtat (3) = 'Divorcée' 

   Travail.TabEtat (4) = 'Veuve' 

endif

 

Les paramètres de ce multi-choix sont les suivants :

Type de choix

Tableau 

Enreg

Travail 

Donnée

TabEtat 

Indice Début

1 

Indice Fin

4 
 

Ils apparaîtront sous la forme : "#travail,tabetat,1,4".

 

Attention : Pour pouvoir saisir un tel type de choix, il faut que l'enregistrement contenant le tableau soit déclaré dans le masque courant. Voir Enregistrements.

 

 

4. Choix de type "Liste"

Un multi-choix peut proposer des choix constants (lorsque les différents choix sont connus dès la conception du masque) mais aussi des choix variables (lorsque les choix sont seulement connus à l'exécution du masque). Dans ce dernier cas, une deuxième solution consiste à les ranger dans une liste Diva.

Le programme doit impérativement garnir la liste avant l'affichage ou la saisie de la page concernée. Chaque élément de la liste doit être garni avec un choix du multi-choix.
 

Sélectionnez le radio-bouton Liste et garnissez le champ suivant :

Autre Choix ou Liste  

Nom de la liste Diva contenant les choix.

Chaque élément de la liste contient :
- le libellé du choix,
- la valeur associée (facultative),
- un ou plusieurs noms pour les attributs dynamiques (facultatifs),
tous séparés entre eux par un point-virgule ou une virgule.

L’instruction Diva ListGetId permet de créer une liste en lui donnant un nom. Le programme devra l'utiliser en spécifiant le nom indiqué ici.

 

Exemple :

Reprenons l'exemple précédent avec, cette fois, la déclaration et le remplissage d'une liste Diva :

 

1 liste  L
 

liste = ListGetId ("ChoixEtat")

ListErase (liste)
ListAddEnd (liste,"Célibataire;1")         ;choix avec valeurs

if sexe = 'M'

   ListAddEnd (liste,"Marié;2")

   ListAddEnd (liste,"Divorcé;3")

   ListAddEnd (liste,"Veuf;4;nom1;nom2")   ;plus deux noms pour les attributs dynamiques

else

   ListAddEnd (liste,"Mariée;2")

   ListAddEnd (liste,"Divorcée;3")

   ListAddEnd (liste,"Veuve;4,nom3")       ;plus un nom pour les attributs dynamiques

endif

 

Les paramètres de ce multi-choix sont les suivants :

Type de choix

Liste 

Autre Choix ou Liste

ChoixEtat
 

Ils apparaîtront sous la forme : "Liste : ChoixEtat".

 

 

Remarques

  • Les choix à espace sont automatiquement éliminés à l’exécution (hors tout premier choix à espace).

  • Il est interdit de mélanger dans une même entrée des choix qui précisent une valeur avec des choix qui n’en précisent pas.
