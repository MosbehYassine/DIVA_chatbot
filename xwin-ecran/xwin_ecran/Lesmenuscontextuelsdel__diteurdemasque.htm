Les menus contextuels de l'éditeur de masque

 

1. Menu contextuel des objets

Si vous cliquez avec le bouton droit de la souris sur un objet, l'objet est sélectionné et vous ouvrez un menu surgissant avec les choix suivants :

  • Propriétés : Appel des propriétés de l'objet.

  • Déplacement : Permet de déplacer l'objet sélectionné.

  • Taille : Permet de modifier la taille de l'objet. 

  • Hauteur : Permet de modifier la hauteur de l'objet.

  • Largeur : Permet de modifier la largeur de l'objet.

  • Suppression : Permet de supprimer l'objet.

  • Voir aide : Permet d'afficher l'aide fenêtrée que vous avez paramétrée pour cet objet.

  • Aller à la définition : Recherche de toutes les occurrences de la donnée courante dans le sous-projet.

  • Objet suivant/précédent : Déplacement par rapport à l'objet courant. Voir Options.

  • Garder présentation : Les paramètres de présentation de l'objet courant (police, couleur, etc.) deviennent les paramètres par défaut pour ce type d'objet. Lors de la création d'un objet de même type, ces valeurs lui seront affectées par défaut.

   

2. Menu contextuel général

Si vous cliquez avec le bouton droit de la souris dans le fond de la page vous ouvrez le menu surgissant suivant :

  • Propriétés : Appel de la boîte de dialogue des caractéristiques de la page en cours (F3).

  • Liste des objets : Appel de la boîte affichant la liste des objets de la page courante.

  • Liste des noms : Liste des noms associés aux objets (voir Attributs dynamiques ).

  • Ordre de saisie automatique : Recalcul automatique de l'ordre de saisie de la page. Voir Ordre de saisie.

  • Ordre de saisie manuel : Vous pointez les données dans l'ordre où elles devront être saisies. Voir Ordre de saisie.

  • Premier de l'ordre de saisie : L'objet qui est le premier selon l'ordre de saisie est sélectionné.

  • Coller : Colle le contenu du presse-papiers dans la page de masque courante.

  • Vérifier la taille des boîtes pour la page : Vérifie que les textes ne sont pas tronqués par les boîtes.

  • Vérifier la taille des boîtes pour le masque : Vérifie que les textes ne sont pas tronqués par les boîtes.

 

3. Menu contextuel des colonnes de tableaux

Si vous cliquez avec le bouton droit de la souris dans une colonne d'un tableau, vous obtenez un menu contextuel avec les choix suivants :

  • Propriétés : Se place dans la fenêtre des propriétés de l'objet.

  • Suppression : Permet de supprimer l'objet.

  • Voir aide : Permet d'afficher l'aide fenêtrée que vous avez paramétrée pour cet objet.

  • Aller à la définition : Recherche de toutes les occurrences de la donnée courante dans le sous-projet.

  • Coller avant / après : Colle le contenu du presse-papiers dans le tableau, avant ou après la colonne courante.

  • Objet suivant/précédent : Déplacement par rapport à l'objet courant. Voir Options

  • Garder présentation : Les paramètres de présentation de l'objet courant (police, couleur, etc.) deviennent les paramètres par défaut pour ce type d'objet. Lors de la création d'un objet de même type, ces valeurs seront proposées par défaut. La présentation de l'entête de colonne est également conservée.

 

4. Menu contextuel des en-têtes de colonnes de tableaux

Si vous cliquez avec le bouton droit de la souris dans l'en-tête d'une colonne d'un tableau, vous obtenez un menu contextuel avec les choix suivants :

  • Suppression : Permet de supprimer l'objet.

  • Garder présentation : Les paramètres de présentation de l'en-tête de colonne deviennent les paramètres par défaut. Lors de la création d'une colonne, l'en-tête prendra ces valeurs par défaut.

 

5. Menu contextuel des objets panels pages

Si vous cliquez avec le bouton droit de la souris sur un objet panel page, vous obtenez un menu contextuel avec la plupart des choix habituels du menu contextuel des objets, plus le choix suivant :

  • Afficher la page référencée : Permet d'aller sur la page référencée par l'objet panel page.

 

6. Menu contextuel pour une cellule de grille

Si vous cliquez avec le bouton droit de la souris dans le fond d’une cellule de grille, vous ouvrez le menu surgissant suivant :

  • Propriétés de la cellule : Affiche les caractéristiques de la cellule dans la fenêtre des propriétés.

  • Propriétés de la grille : Affiche les caractéristiques de la grille dans la fenêtre des propriétés.

  • Déplacer la grille : Permet de déplacer une sous-grille.

  • Fractionner horizontalement : Fractionne horizontalement la cellule en deux parties égales.

  • Fractionner verticalement : Fractionne verticalement la cellule en deux parties égales.

  • Fractionner : Ouvre la boîte de dialogue pour définir le nombre de fractionnements à opérer.

  • Ajouter une ligne avant : Ajoute une ligne avant la cellule courante.

  • Ajouter une ligne après : Ajoute une ligne après la cellule courante.

  • Ajouter une colonne avant : Ajoute une colonne avant la cellule courante.

  • Ajouter une colonne après : Ajoute une colonne après la cellule courante.

  • Coller dans la cellule : Colle le presse-papier dans la cellule.

  • Supprimer : Supprime une cellule.

 

7. Menu contextuel pour plusieurs cellules de grille

Lorsque plusieurs cellules d'une grille sont sélectionnées, le menu surgissant propose les choix suivants :

  • Propriété des cellules : Permet de modifier la présentation de toutes les cellules sélectionnées.

  • Fusionner : Fusion des cellules sélectionnées en une seule cellule.

  • Supprimer les lignes : Suppression des lignes sélectionnées.

  • Supprimer les colonnes : Suppression des colonnes sélectionnées.

  • Fractionner : Fractionner les cellules sélectionnées.
