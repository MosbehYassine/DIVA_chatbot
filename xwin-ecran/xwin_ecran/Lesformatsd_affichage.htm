Les formats d'affichage

La propriété Format de la famille Présentation permet de définir un format d'affichage pour les champs.

Ce format s'applique uniquement lors de l'affichage du champ. Au passage en saisie, celui-ci est réaffiché de manière classique, selon son type (alpha, numérique, date, etc.). Après la saisie, le format d'affichage s'applique à nouveau.

 

Exemple :

La donnée DateNai (de type date) est paramétrée avec le format de saisie JJ/MM/AAAA et le format d'affichage jjj JJ mmm AAAA.

A l'appel du masque, DATENAI contient la valeur "20071025".

  • Elle est alors affichée formatée :
    Date de naissance : Jeu 25 Oct 2007

  • Au passage en saisie, la donnée est réaffichée : 
    Date de naissance : 25/10/2007

  • L'utilisateur introduit la date suivante :
    Date de naissance : 26/10/07

  • Après validation, la donnée est réaffichée formatée :
    Date de naissance : Ven 26 Oct 2007

 
Composition du format

Le texte du format est généralement constitué de commandes ou de codes. Vous trouverez dans les rubriques suivantes des tableaux résumant leur signification. Pour tout renseignement complémentaire, consultez les rubriques associées aux fonctions Format, Formatd et Fstring du manuel de référence du langage Diva.

Si les possibilités offertes par les formats standard ne suffisent pas, vous avez la possibilité d'écrire une fonction Diva qui effectue un formatage personnalisé de la donnée (voir Format dynamique).

 

Remarques :

  • Pour les données de type Heure, il n’existe pas de format particulier (hormis le format dynamique standard \FormatHeure). Si vous précisez un format, il s’agira d'un format ALPHA.

  • Pour les données de type Date+Heure, il n’existe pas de format particulier. Si un format d'affichage est précisé, il s'agira d'un format DATE qui sera appliqué aux 8 premiers caractères de la donnée ; on appliquera sur les 6 autres caractères un format standard (HH:MM:SS) avec un espace de séparation entre la date et l'heure.

  • Pour les données de type Date Mensuelle, il n’existe pas de format particulier. Si un format d'affichage est précisé, il s'agira d'un format DATE qui sera appliqué aux 6 premiers caractères de la donnée (les 2 derniers caractères étant considérés comme étant à espace).
