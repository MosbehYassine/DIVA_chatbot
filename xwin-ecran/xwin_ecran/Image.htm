Image

Une image est un dessin statique (à l'exécution, le fait de cliquer sur une image ne déclenche aucune action), qui a essentiellement un rôle décoratif. Ses différents paramètres sont un nom de fichier (.png, .gif, etc.), un type de traitement, ...

Les images fixes (à ne pas confondre avec les images variables) que vous utilisez dans un masque sont identifiées par un nom dans la feuille de styles. Lors de l'insertion d'une image dans un masque, il suffira de spécifier son nom dans la propriété Nom dans la feuille de styles pour lui affecter l'ensemble de ses paramètres.

 

Personnalisation d'une image

Pour un maximum de souplesse, Xwin vous permet de modifier localement, pour une image précise, chacun des paramètres de l'image. Vous pouvez donc par exemple changer la couleur de fond de l'image sans avoir à apporter de modification à la feuille de styles.

 

Remarque : l'utilitaire TestImage.exe vous permet de savoir si une image peut être affichée par Harmony. Pour ce faire, lancez le programme et faites glisser l'image à afficher (drag and drop) dans la fenêtre.
