Sélection d'une donnée

Lors de l'insertion d'un objet dépendant d'une variable dans le masque (champ, multi-choix, ...), Xwin ouvre la boîte de dialogue de sélection d'une donnée.

  • La colonne de gauche propose la liste des Enregistrements qui ont été saisis par le choix Enregistrements du menu Paramètres. Vous pouvez ici ajouter un nouvel enregistrement en cliquant sur le bouton Enregistrements.

  • La colonne de droite présente la liste des champs de l'enregistrement. Les champs sont proposés dans l'ordre où ils ont été déclarés dans le dictionnaire des données.

 

Pour sélectionner un enregistrement

  • Cliquez sur son nom dans la liste des enregistrements.

 

Pour sélectionner une donnée

  • Cliquez sur son nom puis sur le bouton OK  OU 

  • double cliquez sur son nom  OU

  • tapez son nom dans la zone située au dessus de la liste des champs puis cliquez sur le bouton OK.

 

Attention :

Si la donnée que vous sélectionnez est un tableau Diva, il faudra penser à saisir les indices dans la fenêtre des propriétés de l'objet.
