Passer à la page suivante/précédente

Pour se déplacer sur la page suivante/précédente, utilisez les touches Page-Up et Page-Down ou bien utilisez les boutons et..

Lors du déplacement vers la page suivante, si cette dernière n'existe pas, Xwin vous propose de la créer.

  

Remarque

Dans Xwin, les objets Onglet "fonctionnent" et permettent donc de se positionner directement sur une page en cliquant sur l'onglet correspondant.
