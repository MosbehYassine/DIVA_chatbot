Changer Multi-choix

Cette boîte de dialogue permet de transformer les objets multi-choix sélectionnés en objets case à cocher ou groupe de radio-boutons.

Les paramètres qui sont conservés lors de la transformation sont :

- la description (nom de la donnée + indices),

- les paramètres de saisie,

- les aides,

- les traitements et les données à réafficher,

- les pièges de touche,

- les boutons valides,

- les commentaires.
