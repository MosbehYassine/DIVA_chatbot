Aide

La famille Aide permet de définir une bulle ou une aide fenêtrée et comprend les propriétés :

 

Bulle

Texte d'une bulle d'information qui sera affichée lors du stationnement de la souris sur la donnée.
Le caractère | permet de passer à la ligne à l'intérieur du texte.

Fichier

Nom du fichier contenant les textes d'aide (sans extension).
Le même fichier d'aides peut être utilisé par plusieurs fichiers masque, ce qui permet de regrouper toutes les aides de l'application. A l'inverse, un fichier masque peut aussi faire appel à plusieurs fichiers d'aide.

Pour éviter la saisie systématique de ce champ, il est conseillé d'indiquer le nom du fichier dans les paramètres généraux du masque.

Numéro

Numéro d'aide.
Ce numéro constitue la clé d'accès à la rubrique voulue dans le fichier des aides (les numéros sont définis dans le programme qui vous sert à concevoir vos aides). Une valeur nulle indique qu'aucune aide fenêtrée n'est définie pour la donnée.

 

Remarques

  • Il est également possible de définir une aide par défaut pour tous les objets en saisie d'une page Xwin. Pour cela, renseignez les paramètres d'aide par défaut dans les propriétés générales de la page (touche F3) et laissez le numéro d'aide à 0 dans les propriétés des objets de cette page pour lesquels il faut utiliser cette aide par défaut.

  • Pour une saisie rapide des aides, voir Saisie des aides.

  • Pour visualiser l'aide associée à un objet dans Xwin, sélectionnez cet objet et tapez F1.
