Créer un masque écran

La commande Nouveau permet la création d'un nouveau source. Elle crée une nouvelle fenêtre MDI dans Xwin et est accessible par deux moyens :

  • Sélectionnez le choix Nouveau du menu Fichier (raccourci clavier : Ctrl+N).

  • Ou cliquez sur le bouton de la barre d'outils.

  • La boîte de dialogue "Nouveau" apparaît : sélectionnez le choix Masque écran et validez par OK.

 

Pour enregistrer le nouveau source sur disque, consultez la rubrique Sauvegarder un masque.

 

Remarque :

  • Les nouveaux fichiers sont libellés FichierN jusqu'à leur première sauvegarde. N est ici un nombre incrémenté séquentiellement.
