Le menu Rechercher

Le menu Rechercher permet de
- faire une recherche de chaînes de caractères dans plusieurs fichiers,
- se positionner les lignes d'instructions Diva qui ont provoqué une erreur de compilation.

  • Recherche multi-fichiers : Cette commande s'utilise pour faire une recherche de mot ou de chaîne dans un ou plusieurs fichiers, préalablement chargé(s) ou non dans l'éditeur. La recherche s'applique aux fichiers source et aux séquences de traitement des fichiers masque. Voir Rechercher une chaîne ou un mot dans plusieurs fichiers dans la documentation de l'éditeur de textes.

  • Naviguer : Permet la recherche d'une entité syntaxique avec saisie du nom de cette entité. Appelle la boîte de dialogue " Naviguer ".

  • Aller à la définition : Permet la recherche de l'entité syntaxique couramment sélectionnée dans le source.

  • Niveau de navigation Suivant / Précédent : Avancée ou recul d'un niveau dans l'historique de navigation.

  • Objet suivant/précédent : Déplacement vers l'objet suivant/précédent par rapport à l'objet courant. Voir Options

  • Erreur/Occurrence Suivante / Précédente : Place le curseur sur l'instruction erronée suivante ou précédente (erreurs de compilation), sur la ligne contenant l’occurrence suivante ou précédente de la chaîne recherchée (recherche multi-fichiers) ou sur la ligne contenant l’occurrence suivante ou précédente de l’entité syntaxique concernée (navigation). Voir Projets.
