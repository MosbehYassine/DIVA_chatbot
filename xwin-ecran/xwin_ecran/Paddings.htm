Paddings

Cette boîte de dialogue permet d'ajouter, de modifier ou de supprimer un padding de la feuille de styles. Elle propose la liste des paddings existants et la zone Nom.

  • Pour modifier un padding, sélectionnez-le dans la liste ou tapez son nom puis cliquez sur le bouton Modifier. Vous pouvez également double-cliquer dans la liste des paddings. La boîte de dialogue "Padding" vous permet alors de modifier les caractéristiques du padding.

  • Pour créer un padding, tapez son nom puis cliquez sur le bouton Ajouter.
    La boîte de dialogue "Padding" vous permet alors de saisir les caractéristiques du padding.

  • Pour supprimer un padding, sélectionnez-le dans la liste ou tapez son nom puis cliquez sur le bouton Supprimer.

Remarque : si le nom dans la liste est précédé d'une étoile, cela signifie que le padding correspondant se trouve dans la feuille de styles de surcharge.

 

Les paramètres d'un padding sont les suivants :
 

Vertical

Espacement vertical ménagé au dessus ET en dessous du contenu de l'objet, exprimé en pixels.

Horizontal

Espacement horizontal ménagé à gauche ET à droite du contenu de l'objet, exprimé en pixels.

 

 

Cadre "Prendre la valeur par défaut"

Cf. rubrique Styles par défaut.

Option "Toutes les propriétés"

En cochant cette case, vous demandez que le rendu « Standard Divalto » soit appliqué, pour ce qui concerne l'ensemble des propriétés du padding, aux objets ayant ce style de padding.

Options "Vertical", "Horizontal"

Chaque case cochée demande que le rendu « Standard Divalto » soit appliqué, pour ce qui concerne la propriété correspondante du padding, aux objets ayant ce style de padding.
Par exemple, si vous validez l'option "Horizontal", le padding horizontal "standard" sera utilisée mais le padding vertical "standard" sera remplacé par la valeur spécifiée au niveau du champ "Vertical".
Ces options ne sont pas significatives si l'option "Toutes les propriétés" est sélectionnée.

 

Remarques :

  • Le client affecte aux objets champ et multi-choix un padding horizontal "de base" de 2 pixels. Le padding horizontal spécifié dans Xwin est un padding supplémentaire qui s’ajoute à ces 2 pixels de base.

  • Avec les styles de padding de la feuille de styles standard fstyleWpf :

    • Les textes des labels, des champs, des multi-choix, etc. sont alignés horizontalement.

    • Verticalement, les textes des labels sont alignés sur les cadres des cases à cocher.
      Pour les aligner sur les champs, décalez la boîte de 2 orteils.

  • Les colonnes de tableau ont un padding prédéfini, non paramétrable dans Xwin.

  • Un padding est dynamiquement modifiable, mais uniquement via un style (style global ou style bouton).
