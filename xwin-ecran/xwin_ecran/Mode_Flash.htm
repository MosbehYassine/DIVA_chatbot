Mode Flash

Le mode Flash permet de traiter les événements souris qui sont déclenchés à l'intérieur d'un objet graphique.

Par exemple, le programme diva peut être averti qu'un clic souris a eu lieu sur la barre verticale représentant le mois de septembre.

Pour plus de détails sur le mode Flash, voir le sous-projet FlashObjetGraphique du projet Exemples (/Divalto/exemples).

 

 

Méthode utilisée

  • A chaque élément de l'objet graphique (barre, image ...) on associe un identifiant. Cet identifiant permet au programme diva de déterminer exactement le lieu de l'événement.

  • Le programme diva doit passer en mode flash par l'instruction GraphFlashOn et traiter le point d'arrêt associé au mode flash. Lors d'un point d'arrêt le programme peut connaître l'identifiant de l'élément cliqué.

 

Commandes d'identification des éléments :

Un identifiant complet est composé d'un identifiant local et d'un identifiant global. Dans les cas simples, il n'est pas utile d'utiliser les deux identifiants, un seul peut suffire.

Lors d'un point d'arrêt, Harmony vous donne les deux identifiants de l'objet.

 

  • <id>ident_local

L'identifiant ident_local est associé à tous les éléments qui suivent la commande <id>.

 

  • <idpre>ident_global

L'identifiant ident_global est associé à tous les éléments qui suivent la commande <id>.

 

Exemple

Le petit programme Diva, ci dessous garni un objet graphique en lui mettant trois images identiques et teste le clic souris sur l'une ou l'autre des images.

 

 

module ygraph.dhop

1 valeur 5,0

1 IdentPrefixe 256

1  IdentObjet 256

1 Libelle 256

 

; les deux images ont l'identificateur local "abandon"

; l'identificateur global ga_ gb_ gc_ permettra de faire la

; distinction

ff.graph = "<idpre>ga_ <id>abandon<img>abandon"

ff.graph &= "<idpre>gb_ <id>abandon<img>abandon"

ff.graph &= "<idpre>gc_ <id>abandon<img>abandon"

GraphFlashOn(1000,1,1) ; activation mode flash.

; Arret = 1000 

 

xmeinput("Eform.dhoe",1,0,0) ; entrée en saisie

 

if harmony.arret = 1000 ; arret du mode Flash

   GraphFlashLock  ; désactive le mode pendant le  

                   ; traitement 

 

                   ; récupération de l'ident 

                   ; et affichage 

   GraphGetIdentObjet(harmony.identnuid,IdentPrefixe,IdentObjet) 

   Libelle = IdentPrefixe && " " & IdentObjet

   MessageBox("Vous avez cliqué sur " & left(Libelle)," ") 

   GraphFlashUnlock ; réactivation du mode Flash 

endif
