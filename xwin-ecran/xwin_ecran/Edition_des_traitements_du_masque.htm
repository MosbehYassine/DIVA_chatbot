Edition des traitements du masque

 

Des traitements peuvent être définis au niveau des paramètres généraux du masque et de chaque page, au niveau des objets en saisie, des boutons, etc. Chaque traitement est une procédure Diva identifié par le nom de cette procédure.

L'édition du code source des traitements du masque s'effectue dans Xwin, avec les particularités suivantes :

  • Les lignes de source des traitements sont stockées dans le fichier source du masque lui-même. S'il s'agit d'un masque de surcharge, une copie du source des traitements de base est aussi stockée dans le fichier de surcharge.
    Remarque : le fichier objet du masque contient lui-aussi l'objet de ses traitements.

  • Toutes les procédures de traitement du masque sont éditées regroupées.

  • Le source des traitements s'édite dans une fenêtre MDI (presque) indépendante de la fenêtre MDI du masque. Presque indépendante car :

    • La fermeture de la fenêtre MDI du masque referme automatiquement celle de ses traitements.

    • Une sauvegarde faite depuis la fenêtre MDI du masque sauve aussi le source des traitements (avec invalidation des listes d'undo et redo correspondantes).

    • La compilation du masque compile aussi ses traitements.

    • Une sauvegarde ou une demande de compilation faite depuis la fenêtre MDI des traitements du masque provoque la sauvegarde ou la compilation du masque.

    • Une modification du source des traitements implique l’affichage de l’étoile de modification dans la fenêtre masque : le masque peut donc être marqué comme modifié même si vous ne l'avez pas lui-même modifié.

  • A partir du masque, vous ouvrez ou activez la fenêtre de ses traitements par le choix Traitements du masque du menu Fenêtres (raccourci clavier Ctrl+T) ou par le bouton .
    Remarque : éditer un traitement est également possible à partir de la zone de saisie de son nom dans la fenêtre des propriétés.

  • A partir des traitements du masque, vous revenez à la fenêtre MDI du masque par le choix Masque / dictionnaire du menu Fenêtres (raccourci clavier Ctrl+T) ou par le bouton .

  • Remarque : lorsque le masque est un masque de surcharge, vous pouvez, dans la fenêtre MDI des traitements, éditer aussi les traitements de base. Le choix Traitements Base <-> Surcharge du menu Fenêtres (raccourci clavier Shift+Ctrl+T) ou le bouton permet de basculer entre traitements de surcharge et traitements de base.

  • En édition de la fenêtre MDI des traitements du masque, l'onglet vertical Arbre des traitements est ajouté.

  • Le squelette du code source d'un traitement peut être automatiquement généré par Xwin. Dans le cas d'un masque de surcharge, le squelette du traitement de surcharge peut aussi être généré (avec appel au traitement de base).
    En cas de génération, les procédures sont rangées par ordre alphabétique.

 

Restriction très importante :

La définition des procédures de traitement du masque doit obligatoirement se trouver dans le source des traitements lui-même. Elle ne peut pas être placée dans un module externe ni dans un fichier "Include". Remarque :  le compilateur détecte les procédures manquantes.
 

 

Remarque importante :

Aucune suppression automatique de lignes de code n'intervient jamais : si, au niveau d'un objet, vous annulez l'appel à un traitement (vous remettez à espace ou changez le nom de la procédure), le code source correspondant n'est pas touché. Remarque : le compilateur signale les procédures qui ne sont plus appelées (sous forme de "Warning").

 

Remarques concernant les masques de surcharge :

  • En débogage, les points d'arrêt posés dans les traitements de base peuvent (et doivent) être placés dans le source de base édité depuis le masque de surcharge. Mais attention, pour que ces points d'arrêt fonctionnent, il faut que le masque de base ait été compilé en mode debug !

  • Les occurrences de la recherche multi-fichiers et de la navigation trouvées dans les traitements de base sont éditées dans le masque de surcharge. Mais attention, pour que la navigation fonctionne dans les traitements de base, il faut avoir les DEUX fichiers "browse" (.dhbr) en ligne.
