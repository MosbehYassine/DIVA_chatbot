Liste des choix d'un dictionnaire de multi-choix

La boîte de dialogue montre la liste des multi-choix du dictionnaire courant (dernier dictionnaire utilisé dans Xwin).

  • Pour ouvrir ou créer un dictionnaire, tapez son nom dans la zone Dictionnaire puis cliquez sur le bouton Ouvrir/Créer. Si le dictionnaire n'existe pas, Xwin propose sa création. La boîte de dialogue des fichiers vous permet alors de sélectionner l'emplacement du fichier.

  • Pour ajouter une nouvelle entrée dans le dictionnaire, tapez son nom dans la zone Choix et cliquez sur le bouton Ajouter.

  • Pour modifier une entrée existante, sélectionnez-le dans la liste ou tapez son nom puis cliquez sur le bouton Modifier. Vous pouvez également double cliquer sur le choix à modifier.

  • Pour supprimer une entrée existante sélectionnez-le dans la liste ou tapez son nom puis cliquez sur le bouton Supprimer. Un boîte de dialogue vous demande alors de confirmer la suppression.
