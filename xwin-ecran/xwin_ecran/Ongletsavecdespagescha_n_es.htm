Onglets avec des pages chaînées

Rappelons qu'un masque Harmony peut être multi-écran. On déclare qu'un masque est multi-écran en établissant un chaînage entre les différentes pages du masque (champs Page suivante et Page précédente dans les paramètres généraux de chaque page). L'utilisateur passe d'une page à l'autre par Ctrl+Tab et Maj+Ctrl+Tab (ou par Ctrl+N, où N est le numéro d'ordre de l'onglet dans le groupe).

 

Dans le cas de pages chaînées, le traitement de l'onglet est entièrement transparent pour le programme Diva.

 

L'avantage de placer un onglet dans ce type de masque est multiple :

  • L'utilisateur voit clairement que le masque comporte plusieurs écrans.

  • Si l'intitulé des onglets est bien choisi, il voit aussi immédiatement dans quelle page se trouvent les données qui l'intéressent.

  • Enfin, il lui est possible de passer beaucoup plus rapidement d'une page à l'autre (sans onglet, pour passer de la page 1 à la page 5, il lui faut taper 4 fois Ctrl+Tab !).
