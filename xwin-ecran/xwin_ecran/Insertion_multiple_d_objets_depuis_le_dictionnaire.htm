Insertion multiple d'objets depuis le dictionnaire

 

Le bouton de la barre d'outils permet d'insérer des données à partir du dictionnaire, avec les fonctionnalités supplémentaires suivantes par rapport à une insertion simple :

  • Plusieurs données peuvent être insérées simultanément.

    Attention     : si vous désirez placer les nouvelles données dans un objet Tableau, vous devez d'abord sélectionner ce tableau :

    • Si vous sélectionnez le tableau proprement dit, les objets seront placés en dernière colonne.

    • Si vous sélectionnez une colonne du tableau, les objets seront placés avant la colonne sélectionnée.
       

  • Le modèle de présentation est pris en compte pour initialiser le style des objets insérés.

    Remarque     : pour obtenir une efficacité maximale du modèle de présentation, on aura intérêt à insérer séparément les champs en saisie, les champs en affichage, les champs à placer dans un objet tableau.
     

  • Enfin, le mode de présentation spécifié au niveau du dictionnaire des données (famille Présentation des propriétés d'un champ) est pris en compte pour déterminer quel type d'objet doit être créé pour chaque donnée du dictionnaire insérée.
    Dans le dictionnaire, vous pouvez en effet spécifier si la donnée est un simple champ, un multi-choix, une case à cocher, un groupe de radio-boutons, un texte riche, etc. Chaque donnée sera ainsi automatiquement créée avec le "bon" type d'objet.
    Vous pouvez aussi spécifier dans le dictionnaire un format d'affichage, des noms d'objet pour les attributs dynamiques, une entrée dans le dictionnaire des multi-choix s'il s'agit d'un objet à choix multiple. Toutes ces informations seront automatiquement placées dans les propriétés concernées.
