Menu contextuel Sous-projet

 

Le menu contextuel Sous-projet propose les commandes :

  • Paramètres : modifier les paramètres du sous-projet.

  • Renommer : changer le nom du sous-projet.

  • Définir comme sous-projet courant : sélectionner ce sous-projet comme sous-projet courant.

  • Nouveau : ajouter un sous-projet au projet.

  • Supprimer : supprimer le sous-projet.

  • Dupliquer : ajouter un sous-projet qui sera la copie du sous-projet pointé.

  • Fermer les sources appartenant à ce sous-projet : fermeture des fichiers qui appartiennent à ce sous-projet et qui n'appartiennent pas au sous-projet courant.

  • Fermer les sources n'appartenant pas à ce sous-projet : fermeture de tous les fichiers qui n'appartiennent pas au sous-projet.

  • Chercher dans le projet : rechercher un fichier dans le projet.

  • Reconstruire tout le sous-projet : recompilation de tous les sources du sous-projet.

  • Construire : compilation des sources du sous-projet qui doivent être recompilés (sources modifiés par ex.).

  • Fusionner le sous-projet et sa surcharge : fusion des traitements et des dictionnaires entre le sous-projet de base et sa surcharge.
