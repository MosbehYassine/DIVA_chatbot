Pour créer / modifier / supprimer / renommer un profil

Pour créer un profil vous pouvez :

  • cliquer avec le bouton droit sur le dossier Profils de l'arbre et choisir Nouveau Profil.

  • cliquer sur le dossier Profil et taper la touche Insert.

  • dans le menu Projet pointer sur Profil puis cliquer sur Nouveau.

  • cliquer avec le bouton droit sur un profil et choisir Dupliquer

  • dans le menu Projet pointer sur Profil puis cliquer sur Dupliquer.

 

Pour modifier un profil vous pouvez :

  • cliquer avec le bouton droit sur le profil et choisir Paramètres.

  • double cliquer sur le profil.

  • dans le menu Projet pointer sur Profil puis cliquer sur Modifier. Par ce choix vous ne pouvez modifier que le profil courant.

Vous pouvez alors saisir les paramètres du profil.

 

Pour supprimer un profil vous pouvez :

  • cliquer avec le bouton droit sur le profil et choisir Supprimer.

  • cliquer sur le profil et taper la touche Delete

  • dans le menu Projet pointez sur Profil puis cliquez sur Supprimer xxx.

Pour renommer un profil vous pouvez :

  • cliquer avec le bouton droit sur le profil et choisir Renommer.

  • cliquer sur le nom du profil.
