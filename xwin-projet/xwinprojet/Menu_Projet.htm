Menu Projet

 

Le menu Projet propose les commandes :

  • Construire le Sous-projet : compilation des sources du sous-projet courant qui doivent être recompilés (sources modifiés par ex.).

  • Compiler : compiler le fichier courant.

  • Arrêter la compilation / construction : arrêt de la compilation en cours.
     

  • Construire le Projet : compilation des sources du projet courant qui doivent être recompilés (sources modifiés par ex.).

  • Reconstruire Tout le Sous-projet : recompilation de tous les sources du sous-projet courant.

  • Reconstruire Tout le Projet : recompilation de tous les sources du projet courant.
     

  • Fusionner un projet et sa surcharge : voir la rubrique Fusion de projet et projet de surcharge.
     

  • Exécuter sans déboguer : lancement de l'exécution sans utiliser le débogueur.
