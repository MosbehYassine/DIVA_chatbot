Pour ajouter / supprimer des sources dans un sous-projet

 

Pour ajouter des sources dans un sous-projet vous pouvez :

  • cliquer droit sur le dossier Sources du sous-projet et choisir Ajouter

  • cliquer le dossier Sources du sous-projet taper la touche Insert.

  • cliquer droit sur un source et choisir Ajouter

  • cliquer sur un source et taper la touche Insert

  • dans le menu Projet pointer sur Sous-projet et cliquer sur Ajouter des sources au sous-projet xxx.

La boîte de sélection des fichiers s'ouvre. Vous pouvez sélectionner plusieurs fichier en une seule opération.

 

Remarque

Vous pouvez également créer un nouveau source dans Xwin, le sauvegarder puis sélectionner le choix Ajouter le source courant du menu popup du dossier Sources.

 

Pour supprimer des sources dans un sous-projet vous pouvez :

  • cliquer avec le bouton droit sur le source et choisir Supprimer.

  • cliquer sur le fichier et taper sur la touche Delete.

La suppression d'un source ne supprime jamais le fichier du disque. Le fichier est tout simplement retiré du projet.
