Boîte de dialogue Création d'un projet surchargeable

Cette boîte de dialogue vous permet de créer un projet surchargeable.

 

Les paramètres à saisir sont :

Répertoire destination

Il s'agit du répertoire dans lequel le sous-projet va être copié puis modifié pour devenir surchargeable.

Supprimer tous les fichiers du répertoire de destination

Si cette case est cochée, Xwin vide préalablement le répertoire des tous les fichiers projets et sous-projets. (Xwin demande confirmation avant l'effacement).

Fichiers non publiables

Vous pouvez saisir ici une liste de formats séparés par des points-virgule.

Tous les fichiers dont le nom correspond à un des formats spécifiés sont considérés comme privés et ne feront donc pas partie du projet surchargeable.

Ex : gtp*.dhsp;gtt*.dhsp
