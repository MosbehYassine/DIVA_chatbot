Fichiers du projet

Projet

La description du projet se trouve dans un fichier ayant l'extension dhpt.

Ce fichier contient :

  • les paramètres généraux,

  • les différents profils,

  • les groupes de sources,

  • la liste des sous-projets.

 

Sous-projet

La description d'un sous-projet se trouve dans un fichier ayant l'extension dhps.

Ce fichier contient :

  • les paramètres généraux,

  • la liste des groupes de sources,

  • la liste des noms de sources.

 

Navigation

Les fichiers utilisés pour la navigation ont l'extension dhbr.

Ils sont générés par le compilateur et ne sont utiles qu'à la navigation.
