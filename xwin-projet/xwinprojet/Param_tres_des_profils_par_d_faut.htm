Paramètres des profils par défaut

Les paramètres par défaut des profils sont :

 

Répertoire des objets

Chemin d'un répertoire où sont stockés les objets résultants des compilations.

Si le projet est surchargé, vous devez spécifier un répertoire pour les objets du projet surchargé ET un répertoire pour le projet de surcharge.

Voir Surcharge des projets : Principe.

Répertoire des fichiers de navigation

Chemin d'un répertoire où sont stockés les fichiers .dhbr pour la navigation.

Si le projet est surchargé, vous devez spécifier un répertoire pour les fichiers de navigation du projet surchargé ET un répertoire pour le projet de surcharge.

Voir Surcharge des projets : Principe.

Répertoire des fichiers de couverture du code

Chemin d'un répertoire où sont stockés les fichiers .dhcc contenant les informations de couverture du code.

Voir Contrôle de code source.

Version cible

Version d’Harmony sur laquelle les objets compilés seront exécutés. Si les sources compilés utilisent des instructions ou des fonctionnalités incompatibles avec la version cible spécifiée, les compilateurs génèrent une erreur.

Autres options

Options du compilateur xDivaCompiler autres que "Option debug" et "Génération des fichiers de navigation".

Implicites

Nom d'un fichier de chemins implicites.

/VALUE

Compilation conditionnelle pour le compilateur xDivaCompiler.

La syntaxe est : param1=[v/f];param1=[v/f]

Exemple : debug=V;interne=F;

Constantes

Permet de définir des constantes du langage Diva. Ces constantes sont transmises au compilateur.

Exemple : maconstante=10

Voir Const.

Vérifier que les fonctions non "private" sont des surcharges

Voir Private.
