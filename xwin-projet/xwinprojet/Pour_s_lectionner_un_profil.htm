Pour sélectionner un profil

Pour sélectionner un profil, vous pouvez

  • expanser le dossier Profils, puis cliquer avec le bouton droit sur le profil et cliquer sur Choisir ce profil.

  • dans le menu Projet pointer sur Profil puis cliquez sur Choisir.

Le profil sélectionné apparaît sur fond rouge.

 

 

Remarque

Si vous voulez qu'un profil soit automatiquement sélectionné lorsque vous chargez un projet, vous pouvez :

  • expanser le dossier Profils, puis cliquer avec le bouton droit sur le profil et cliquer sur ce profil par défaut.

  • dans le menu Projet pointer sur Profil puis cliquez sur Définir xxx par défaut.
