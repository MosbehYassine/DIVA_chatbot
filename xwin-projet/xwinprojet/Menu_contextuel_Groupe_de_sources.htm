Menu contextuel Groupe de sources

 

Le menu contextuel Groupes de sources propose les commandes :

  • Paramètres : propriétés du groupe.

  • Nouveau fichier : ajouter un ou plusieurs sources au groupe.

  • Ajouter le source courant : ajouter le source en cours d'édition au groupe.

  • Supprimer : supprimer le groupe pointé.

  • Renommer : changer le nom du groupe.

  • Nouveau groupe : ajouter un nouveau groupe au projet.

  • Commentaires : placer des commentaires au niveau du groupe.
