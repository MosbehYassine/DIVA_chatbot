Boîte de dialogue Recherche

La recherche dans le projet, permet de trouver toutes les occurrences d'un fichier dans le projet.

Dans la boîte de dialogue, saisissez le nom de fichier que vous recherchez (la vous permet de sélectionner une des recherches précédentes).

Le tableau contient alors la liste des occurrences trouvées.

Dans cette liste :

  • un clic simple met le focus sur le fichier correspondant dans l'arbre du projet

  • un double clic ferme la fenêtre de recherche et met le focus sur le fichier sélectionné (F3 permet ensuite de se déplacer sur l'occurrence suivante)

Les cases à cocher permettent de :

  • rechercher uniquement dans les noms des sous-projets. (la recherche est beaucoup plus rapide)

  • d'éliminer les doublons (un même fichier peut se trouver dans plusieurs sous-projets)

  • d'utiliser les caractères jocker (* et ?) pour la recherche.
