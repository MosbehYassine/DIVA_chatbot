Paramètres des profils

Cette boîte de dialogue présente :

  • à gauche les paramètres spécifiques du profil

  • à droite les paramètres par défaut.

Si un paramètre n'est pas renseigné pour un profil, c'est le paramètre du profil par défaut qui est utilisé.

 

 

Les paramètres des profils sont :

 

Répertoire des objets

Chemin d'un répertoire ou sont stockés les objets résultants des compilations.

Si le projet est surchargé, vous devez spécifier un répertoire pour les objets du projet surchargé ET un répertoire pour le projet de surcharge.

Voir Surcharge des projets : Principe.

Répertoire des fichiers de navigation

Chemin d'un répertoire où sont stockés les fichiers .hbr pour la navigation.

Si le projet est surchargé, vous devez spécifier un répertoire pour les fichiers de navigation du projet surchargé ET un répertoire pour le projet de surcharge.

Voir Surcharge des projets : Principe.

Répertoire des fichiers de couverture du code

Chemin d'un répertoire où sont stockés les fichiers .dhcc contenant les informations de couverture du code.

Voir Contrôle de code source

Le bouton <Nettoyer> permet de vide le répertoire. 

Option Debug

Valide ou non l'option D du compilateur xDivaCompiler. Pour que les programmes soient utilisables avec le débogueur, cette option doit être cochée.

La compilation en mode " débogueur " génère des informations spécifiques. Il en résulte une augmentation de la taille du code généré et, accessoirement, un possible ralentissement de l'exécution. En conséquence, lorsque votre programme est validé, n'oubliez pas de le recompiler en mode " normal " et utilisez la version correspondante du code objet en exploitation.

Option Couverture du code

 

Valide ou non l'option DC du compilateur xDivaCompiler.

La compilation avec cette option génère les informations nécessaire à la couverture du code.

Voir Contrôle de code source.

Génération des fichiers de navigation (browse)

Valide ou non l'option B du compilateur xDivaCompiler. Pour pouvoir naviguer dans les sources, cette option doit être cochée.

Les informations de navigation sont stockées dans des fichiers à part, distincts des objets exécutables. Ils ont l'extension Hbr.

Voir Introduction à la navigation.

Fermer les fichiers au chargement de sous-projet

Si cette option est validée, lors d'un changement de sous-projet, Xwin ferme tous les fichiers chargés dans l'éditeur.

Bavard

Si cette option est cochée, Xwin affiche des messages pendant les compilations. Par défaut, seul le nom du fichier en cours de compilation est affiché.

Ignorer les /HIDEFUNCTIONS

Cette option permet de compiler en ignorant les /HIDEFUNCTIONS des sources que vous compilez.  Cela permet, en  phase de développement, de voir toutes les fonctions dans l'assistance au codage. Lors de la compilation des objets à diffuser, il faut invalider cette option et les fonctions seront cachées.
Cela ne permet pas de voir les fonctions cachées des modules dont vous n'avez pas les sources.
Voir Assistance au codage dans la documentation Utiliser l'éditeur de textes.

Un objet débordant de la clip grille provoque une erreur de compilation

Cette option permet de considérer ces débordements non plus comme des avertissements (warnings) mais comme des erreurs.

Afficher toutes les colonnes des tableaux (à l’exécution)

L'utilisateur peut paramétrer l'affichage des colonnes des tableaux à l'exécution. Il peut être intéressant pour le développeur de voir son tableau soit comme un utilisateur, soit en intégralité (pour, par exemple, tester la saisie de toutes les colonnes). Cette option permet de choisir l'un de ces deux modes :

  • Lorsque le programme est lancé depuis Xwin et que cette option est désactivée, l’affichage des colonnes reste paramétrable et le tableau est vu en tant qu’utilisateur. Idem lorsque le programme n’est pas lancé depuis Xwin.

  • Si le programme est lancé depuis Xwin et que l’option est activée, toutes les colonnes sont toujours affichées à l’exécution.

Version cible

Version d’Harmony sur laquelle les objets compilés seront exécutés. Si les sources compilés utilisent des instructions ou des fonctionnalités incompatibles avec la version cible spécifiée, les compilateurs génèrent une erreur.

Autres options

Options du compilateur xDivaCompiler autres que "Option debug" et "Génération des fichiers de navigation".

Implicites

Nom d'un fichier de chemins implicites.

/VALUE

Compilation conditionnelle pour le compilateur xDivaCompiler.

La syntaxe est : param1=[v/f];param1=[v/f]

Exemple : debug=V;interne=F;

Constantes

 

Permet de définir des constantes du langage Diva. Ces constantes sont transmises au compilateur.

Exemple : maconstante=10

Voir Const.

Vérifier que les fonctions non "private" sont des surcharges

Voir Private.
