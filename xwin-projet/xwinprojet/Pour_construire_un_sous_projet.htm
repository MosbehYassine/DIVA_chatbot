Pour construire un sous-projet

Pour construire un sous-projet vous devez tout d'abord définir le sous-projet comme sous projet courant puis :

  • cliquez sur le bouton

  • ou sélectionnez le choix Construire le sous-projet du menu Projet (raccourci clavier : F10)

  • ou cliquez avec le bouton droit sur le dossier du projet et sélectionnez le choix Construire.

 

La construction d'un sous-projet se fait en deux opérations :

  • la première opération consiste à établir la liste des fichiers qui doivent être compilés. Cette liste est établie en fonction des dates de modification des fichiers, des fonctions modifiées etc.

  • la seconde opération consiste à compiler les sources sélectionnés.

 

Remarque

Le choix Construire tous les sous-projets expansés du menu contextuel Sous-projet permet de construire plusieurs sous-projets.
