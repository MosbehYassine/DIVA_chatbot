Menu Contextuel Profil

 

Le menu contextuel Profil propose les commandes :

  • Paramètres : consulter / modifier les paramètres du profil.

  • Renommer : changer le nom du profil.

  • Choisir ce profil : sélectionner ce profil.

  • Ce profil par défaut : définir ce profil comme profil par défaut.

  • Supprimer : supprimer ce profil.

  • Dupliquer : créer un profil qui sera la copie du profil pointé.
