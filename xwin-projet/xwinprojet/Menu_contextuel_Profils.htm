Menu contextuel Profils

 

Le menu contextuel Profils propose les commandes :

  • Nouveau profil : ajouter un profil au projet.

  • Paramètres par défaut : modifier les paramètres par défaut des profils.

  • Créer un fichier de profils personnel :  pour stocker les profils non pas dans le projet lui-même mais dans un fichier à part. Cela permet à chaque développeur d'avoir ses propres profils.
    Le fichier contenant les profils est créé dans le même répertoire que le projet et son nom est constitué de : nom_du_projet  + ".profils." + code_utilisateur + ".user".
    Dans l'arbre du projet, le dossier Profils est suivi de (perso) pour rappeler que les profils sont stockés à part.
