Sous menu Projet

 

Le sous-menu Projet du menu Projet propose les commandes :

  • Nouveau Sous-projet : création d'un nouveau sous-projet.

  • Inclure un Sous-projet : ajouter un sous-projet existant au projet.

  • Nouveau Groupe de sources : créer un nouveau groupe de sources.

  • Créer un projet surchargeable : création d'un projet surchargeable à partir du projet en cours.

  • Paramètres : paramètres du projet courant.
