Menu contextuel Fichier Divers

 

Le menu contextuel Fichier Divers propose les commandes :

  • Ouvrir : ouverture / exécution du fichier.

  • Ouvrir en mode texte : ouverture du fichier en le chargeant en mode texte dans Xwin.

  • Copier le nom du fichier : copier le nom du fichier dans le presse-papiers.

  • Ajouter : ajouter un ou plusieurs fichiers dans le dossier.

  • Retirer : retirer le fichier du dossier sans le supprimer.

  • Supprimer le fichier : supprimer le fichier pointé du disque.

  • Propriétés : propriétés du fichier.

  • Explorer : ouverture de l'explorateur de fichiers dans le répertoire contenant le fichier pointé.
