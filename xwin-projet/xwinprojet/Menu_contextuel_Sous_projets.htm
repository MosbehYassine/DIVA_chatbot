Menu contextuel Sous-projets

 

Le menu contextuel Sous-projets propose les commandes :

  • Nouveau : ajouter un sous-projet au projet.

  • Inclure : ajouter un sous-projet existant au projet.

  • Réduire tous les sous-projets : dans l'arbre, fermer tous les sous-projets qui sont expansés.

  • Construire tous les sous-projets expansés : compilation des sources des sous-projets expansés dans l'arbre et qui doivent être recompilés (sources modifiés par ex.).

  • Reconstruire tous les sous-projets expansés : recompilation de tous les sources des sous-projets expansés dans l'arbre.

  • Chercher dans le projet : rechercher un fichier dans le projet.
