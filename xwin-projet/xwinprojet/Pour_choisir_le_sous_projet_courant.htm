Pour choisir le sous-projet courant

Pour choisir le sous-projet courant vous pouvez :

  • cliquer avec le bouton droit sur le sous-projet et choisir Définir comme sous-projet courant.

  • ouvrir un fichier source d'un autre sous-projet (par double clic ou Entrée).

 

Le sous-projet courant est celui :

  • qui est compilé quand vous cliquez sur le bouton ou que vous frappez la touche F10

  • qui est exécuté lors du lancement du débogueur

  • dans lequel se fait la navigation (F11).

 

Remarque : L’ouverture d’un fichier du dossier Includes ne provoque jamais le changement de sous-projet.
