Pour inclure un sous-projet

Vous pouvez inclure un sous-projet existant dans un projet. Un même sous projet peut appartenir à plusieurs projets.

Pour inclure un sous-projet dans un projet vous pouvez :

  • cliquer droit sur le dossier Sous-projets et choisir Inclure

  • dans le menu Projet pointer sur Projet et cliquer sur Inclure un sous-projet
