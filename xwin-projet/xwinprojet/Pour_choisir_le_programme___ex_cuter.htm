Pour choisir le programme à exécuter

 

Pour démarrer une exécution, Xwin a besoin de connaître le nom du programme objet que vous désirez lancer. En effet, d'une part l'éditeur de textes vous permet de charger plusieurs sources de programme exécutable, d'autre part, il n'est pas interdit de déboguer un programme lancé indirectement (par exemple depuis un menu).

Le nom du programme objet à lancer peut être spécifié dans les paramètres du projet ou dans les paramètres du sous-projet.

Pour lancer une application Web, vous devez préciser le Mode (Page Html) et la page à lancer dans le navigateur.

Que ce soit au niveau du projet ou du sous-projet, vous pouvez garnir les paramètres suivants :

 

Mode

Type de programme à lancer.

Normal : pour exécuter un programme Diva avec des masques en version 6

Page Html :  Xwin lance alors le navigateur par défaut avec comme paramètre le nom de la page.

Service Web :  Xwin lance alors le programme qui appelle le service web.

Client léger : pour exécuter un programme Diva avec des masques en version 7.

Client léger Web : pour exécuter un programme Diva en utilisant un navigateur internet (html5).
                           Voir Identification en mode client léger Web.

 

Type de transport

DhsTerminalServer : transport par socket TCP.

Service Web : transport utilisant les services web de IIS.

Local : appelé aussi client lourd.

Ce paramètre n'est pas utilisé en mode Client léger Web.

 

Url du service web

 

Url pour accéder au service web (en mode Service web)

Programme à exécuter

 

Nom du programme a exécuter lors du debug ou page à lancer en mode Page Html ou Client léger Web.

Application, libellé de regroupement
et Numéro

Si le programme à exécuter est un menu, ces trois paramètres permettent d'exécuter automatiquement un choix du menu.

Avec analyseur de performances

Lancement avec l'analyseur de performances. Voir le livre consacré à ce sujet dans le manuel de référence d'Harmony.

Garder les numéros de ligne

Garder les numéros de ligne pour les piles lors de l'analyse de performances.

Nombre de niveaux de la pile à garder

Nombre de niveaux de la pile à garder lors de l'analyse de performances.

 

Lors de l'exécution, Xwin recherche le nom du programme à exécuter :

  • d'abord dans les paramètres du sous-projet courant,

  • puis dans les paramètres du projet

 

Après avoir déterminé le nom du programme a exécuter, Xwin procède de la même façon pour le choix du menu.

  • si les paramètres du sous-projet précisent un choix de menu, c'est ce choix qui sera automatiquement lancé (il est possible de préciser uniquement les paramètres du menu au niveau du sous-projet, le programme étant pris au niveau du projet).

  • sinon ce sont les paramètres du projet qui seront pris.

 

Remarques

  • Si aucun nom de fichier n'est précisé, Xwin tente d'exécuter le fichier courant en remplaçant l'extension du source courant par l'extension "dhop".

  • En mode Page Html, Xwin lance le navigateur par défaut. Vous pouvez choisir un autre navigateur que le navigateur par défaut en ajoutant la ligne suivante dans le chapitre Internet de Divalto.ini (avec l'utilitaire xDivaltoMajIni) :
    [internet]
    nav_debug=chemin du navigateur

  • Xwin ajoute au chemin du navigateur la page à afficher. Certains navigateurs ne traitent pas ce paramètre. Dans ce cas, vous devez préciser le chemin de la page à lancer dans les options du navigateur (page par défaut).
