Pour modifier les paramètres par défaut des profils

Pour modifier les paramètres par défaut des profils, vous pouvez :

  • cliquer avec le bouton droit sur le dossier Profils de l'arbre et choisir Paramètres par défaut.

  • dans le menu Projet pointer sur Profil puis cliquer sur Paramètres par défaut.
