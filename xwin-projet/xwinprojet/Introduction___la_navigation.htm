Introduction à la navigation

La navigation dans les sources d'un projet (sous-projet) est certainement la fonctionnalité la plus intéressante offerte par le projet.

 

La navigation dans les sources vous permet de trouver instantanément

  • la définition d'une donnée,

  • la définition d'une fonction,

  • toutes les lignes de source où une variable est utilisée,

  • toutes les lignes de source où une fonction est utilisée,

  • tous les objets dans les masques qui sont liés à une donnée,

  • tous les objets dans les masques qui utilisent un choix d'un dictionnaire de multi-choix

  • etc.
