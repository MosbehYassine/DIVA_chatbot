Pour créer / modifier / supprimer / renommer un groupe de sources

Pour créer un groupe de sources vous pouvez :

  • cliquer avec le bouton droit sur le dossier Groupes de sources de l'arbre et choisir Nouveau.

  • cliquer sur le dossier Groupes de sources et taper la touche Insert.

  • cliquer avec le bouton droit sur un groupe et choisir Nouveau groupe.

  • dans le menu Projet cliquer sur Nouveau groupe de sources.

Xwin crée une nouvelle entrée dans l'arbre et vous invite à saisir le nom du groupe.

 

Pour modifier le nom d'un groupe vous pouvez :

cliquer sur le nom du profil. Le nom passe alors en mode édition.

 

Pour supprimer un groupe de sources vous pouvez :

  • cliquer avec le bouton droit sur le groupe et choisir Supprimer.

  • cliquer sur le groupe et taper la touche Delete

 

Pour renommer un groupe de sources vous pouvez :

  • cliquer avec le bouton droit sur le groupe et choisir Renommer.

  • cliquer sur le nom du groupe de sources.
