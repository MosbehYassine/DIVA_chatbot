Pour chercher un fichier dans le projet

Pour chercher un fichier dans le projet,

  • sélectionnez le choix Chercher dans le projet dans le menu contextuel du projet ou d'un sous-projet.

  • puis tapez le nom du fichier à chercher

  • Xwin affiche la liste des occurrences trouvées dans le projet.
