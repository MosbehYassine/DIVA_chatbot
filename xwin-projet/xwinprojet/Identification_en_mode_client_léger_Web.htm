Identification en mode client léger Web

 

En mode client léger Web, Xrtdiva est toujours lancé par le service DhsDivaAgent.

Ce dernier effectue une authentification Windows en utilisant le code utilisateur et le mot de passe fourni par l'utilisateur.

Pour ne pas être obligé de saisir ces informations à chaque session, la possibilité existe de les stocker dans un fichier paramètres.

 

Ce fichier paramètre se nomme : /divalto/sys/utilisateurHtml5.txt

 

Il contient les informations suivantes (séparées par une virgule) :

  • code utilisateur windows

  • mot de passe windows

  • code utilisateur harmony

  • mot de passe harmony

  • environnement

Exemple : bhouver@divalto,xxxxx,demo,,local

 

Attention :

  • Pour que l'authentification systématique soit invalidée, il est nécessaire de modifier le paramétrage "normal" du site Web IIS en autorisant l'authentification anonyme (voir le manuel de référence d'Harmony, chapitre "Client léger Harmony Web", rubrique "Création et configuration d'une application IIS sur le serveur de clients légers Web").

  • Le système doit contenir une variable d'environnement DIVALTOSYS qui pointe sur le chemin du répertoire divalto/sys.

  • Ce fonctionnement n'est valable que pour les programmes lancés depuis XWIN.

     

Choix du navigateur

Par défaut, Xwin lance le navigateur déclaré par défaut sur votre ordinateur. Si vous désirez déboguer votre application avec un autre navigateur, spécifiez son chemin complet d’accès, par xDivaltoMajini, dans la clé Nav_Debug du chapitre [Internet] (base de registre locale à l'utilisateur).

Remarque : Xwin lance le navigateur en lui passant le nom de la page ia.aspx en paramètre sur la ligne de commande, mais certains navigateurs n’acceptent pas ce paramètre. Si la page ia.aspx ne s’affiche pas, indiquez l’URL de cette page comme page de démarrage du navigateur.
