Naviguer dans le sous-projet

La navigation dans les sources d'un sous projet se fait en deux étapes :

  • la sélection de ce que vous recherche

  • la navigation proprement dite.

Une étape intermédiaire peut s'ajouter s'il y a ambiguïté quand à la recherche à effectuer.

 

Etape 1 : Spécifier la recherche

Pour commencer la navigation dans le sous-projet courant, c'est à dire, rechercher la définition d'une variable, d'une fonction, d'un choix etc. et de toutes ses occurrences, plusieurs méthodes sont possibles.

 

Méthode 1.

  • Tapez Shift+F11

  • Dans la boîte de dialogue saisissez le mot que vous recherchez (la vous permet de sélectionner une des recherches précédentes).

Méthode 2

  • Placez le curseur sur le mot que vous recherchez (ou sur un objet dans un masque), cliquez avec le bouton droit et sélectionnez le choix Naviguer (raccourci clavier F11).

 

Etape 2 : Naviguer

Xwin effectue la recherche, garni la fenêtre Navigation et se place sur la définition de la donnée / fonction etc.

Pour vous déplacer d'occurrence en occurrence :

  • Sélectionnez le choix Erreur / Occurrence Suivante du menu Rechercher (raccourci clavier : F4). Xwin active le source contenant la première occurrence et place automatiquement le curseur sur la ligne concernée.

  • Sélectionnez ensuite le choix Erreur / Occurrence Suivante (raccourci clavier : F4) ou le choix Erreur / Occurrence Précédente (raccourci clavier : Shift+F4) du menu Rechercher, pour passer à l'occurrence suivante ou revenir sur l'occurrence précédente.

 

Si vous désirez vous positionner directement sur une occurrence précise :

  • Sélectionnez la ligne dans la liste des occurrences de la fenêtre Navigation puis tapez Entrée.

  • Ou double-cliquez simplement sur cette ligne.

 

Etape Intermédiaire

Si votre requête présente une ambiguïté Xwin ouvre une boîte de dialogue vous demander de sélectionner une ou plusieurs possibilités.

Le bouton Tous (raccourcis clavier T ou Alt+T) vous permet de sélectionner toutes les possibilités.

Pour plus de détails sur le contenu de cette boîte de dialogue, voir Boîte de dialogue Navigation
