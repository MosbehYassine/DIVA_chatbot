Projet

Le projet est une entité de grande taille. Il représente une application complète. Par exemple, Divalto Achat-Vente est un projet, Divalto Comptabilité est un autre projet.

Le projet comporte les éléments suivants :

  • des paramètres généraux

  • une liste de profils,

  • une liste de groupes de sources

  • un liste de fichiers Divers

  • une liste de sous-projets.

 

Actions réalisables au niveau du projet
Le projet étant une entité très volumineuse, le travail se fera le plus souvent au niveau d'un sous-projet.

Au niveau d'un projet il est possible :

  • de créer / modifier / supprimer / sélectionner un profil

  • de créer / modifier / supprimer un groupe de sources

  • de créer / modifier une sous-projet

  • de naviguer dans tous les sources du projet (rechercher toutes les occurrences d'une donnée dans tout le projet)

  • de construire le projet (compiler les sources qui doivent l'être)

  • de reconstruire le projet (compiler tous les sources).
