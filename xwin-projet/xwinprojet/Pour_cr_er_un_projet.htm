Pour créer un projet

Pour créer un projet, sélectionnez le choix Nouveau projet du menu Fichier.

Puis :

  • dans le boîte de dialogue des fichiers, placez-vous dans le répertoire et saisissez le nom du projet.

  • sélectionnez le profil qui vous est proposé.

Le projet est maintenant créé avec des paramètres par défaut..

Vous allez pouvoir

  • saisir les paramètres du projet

  • créer des profils

  • créer des groupes de sources

  • créer des sous-projets.
