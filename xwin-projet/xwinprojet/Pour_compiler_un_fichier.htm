Pour compiler un fichier

Pour compiler un fichier :

  • activez la fenêtre contenant le fichier et sélectionnez le choix Compiler du menu Projet (raccourci clavier Shift+F10).

  • ou activez la fenêtre contenant le fichier et cliquez sur le bouton

  • ou cliquez avec le bouton droit sur le fichier dans l'arbre du projet et sélectionnez le choix Compiler.
