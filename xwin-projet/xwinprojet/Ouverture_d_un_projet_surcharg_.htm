Ouverture d'un projet surchargé

Pour créer une nouvelle surcharge, ouvrez le projet surchargé (livré par Divalto par exemple). Xwin vous demande alors dans quel répertoire vous voulez créer le projet de surcharge. Si votre installation respecte les recommandations de Divalto, un assistant vous est proposé.

Pour ouvrir une surcharge de projet existante, ouvrez le fichier de surcharge (celui qui se termine par la lettre « u »). Le projet de surcharge contient un chemin relatif lui permettant d’accéder au projet surchargé. Si ce dernier n’existe plus, Xwin vous demande de pointer le répertoire contenant le projet surchargé.
