Pour afficher la fenêtre Navigation

La fenêtre Navigation s'affiche automatiquement dès que vous demandez à naviguer dans les sources.

Pour afficher manuellement cette fenêtre :

  • Cliquez sur l'onglet Navigation en bas de la fenêtre Xwin. Si cet onglet n'apparaît pas, cela signifie que la fenêtre des comptes rendus n’est pas affichée ou que la bordure de séparation entre fenêtres MDI et fenêtre Comptes rendus est placée tout en bas de l'écran. Dans le premier cas, consultez la rubrique : Pour afficher la fenêtre des comptes rendus ; dans le second cas, consultez la rubrique : Pour modifier la taille des fenêtres de Xwin.

  • Sélectionnez le choix Onglet Navigation du menu Fenêtre.

Remarque

  • Xwin conserve un historique des navigations. Si la liste affichée dans la fenêtre Navigation ne correspond pas à votre attente, cela signifie peut-être que vous avez opéré plusieurs navigations. Dans ce cas, utilisez les choix Niveau de navigation suivant / précédent du menu Rechercher (raccourcis clavier Ctrl+F11 et Maj+Ctrl+F11) pour avancer ou reculer dans l'historique. Voir Historique des navigations.
