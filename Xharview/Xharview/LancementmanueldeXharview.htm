Lancement manuel de DivaltoViewer

DivaltoViewer est lancé automatiquement à la fin d'une édition en mode graphique si le choix <Aperçu avant impression> du menu système de la fenêtre Harmony est coché. Mais DivaltoViewer peut aussi être appelé "manuellement". Pour ce faire, vous avez le choix entre deux méthodes :

  • Lancez le programme DivaltoViewer.exe depuis l'Explorateur ou par la commande <Exécuter> du menu Démarrer de Windows. Il vous faudra alors charger un état sauvegardé par le choix <Fichier : Ouvrir> du menu de DivaltoViewer.
    Remarque : Si vous lancez DivaltoViewer par la commande <Exécuter>, vous pouvez saisir immédiatement le nom du fichier à charger derrière le nom du programme. Exemple : DivaltoViewer.exe SauveEtat.dhvw

  • Avec l'Explorateur de Windows, sélectionnez le fichier de type ".dhvw" désiré. Cliquez ensuite sur le bouton droit de la souris. Le menu contextuel qui apparaît vous propose en particulier les choix <Ouvrir> et <Imprimer> :
    <Ouvrir> lance DivaltoViewer avec chargement du fichier.
    <Imprimer> lance l'impression du fichier par DivaltoViewer.
