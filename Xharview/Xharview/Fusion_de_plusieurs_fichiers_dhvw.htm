Fusion de plusieurs fichiers dhvw

 

Le choix correspondant du menu Options de DivaltoViewer permet de fusionner l’aperçu courant avec un autre fichier dhvw. Il est ainsi possible de créer un fichier dhvw unique regroupant plusieurs fichiers d’aperçu.

 

Remarque : Cette opération peut aussi se faire par programme. La documentation de Xwin contient la description détaillée des fonctions (préfixées par DhToolsDhvw), ainsi qu’un exemple.

 

Limitations

  • Il faut que l’orientation d’impression soit identique dans tous les fichiers dhvw.  

  • Les paramètres d’impression sont toujours les paramètres du fichier dhvw de base.
