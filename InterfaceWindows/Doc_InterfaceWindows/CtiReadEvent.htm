CtiReadEvent  Famille  Thème

La fonction CtiReadEvent permet de lire un evénement, c’est à dire qu’elle permet de lire le numéro de téléphone de l’appelant.

 

Int CtiReadEvent ( tel )

 

Paramètres

Tel

Variable alphanumérique qui reçoit le numéro de téléphone de l’appelant.

 

Retour

0

Il n’y a pas d’événement à traiter

1

Appel en cours. Tel contient le numéro de téléphone.

2

Appel connecté.

3

Appel déconnecté.

4

 

Demande d’informations du client . Tel contient le numéro de téléphone du client.

Phone Pc possède une fenêtre popup avec un bouton « Voir fiche » ; lorsque l’utilisateur clique sur ce bouton, le programme qui gère les événements Cti reçoit cet événement. Il doit alors rechercher le client à partir du numéro de téléphone et exécuter la fonction CtiPopupInfo.

5

Mode transfert de fiche, valable uniquement sur ISI-COM.

L'interface ISI-COM permet de transférer un appel vers un autre poste, le programme Diva traitant le CTI sur le poste appelé reçoit alors un événement 5.
