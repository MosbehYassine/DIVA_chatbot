Introduction aux fonctions Cti

Les fonctions CTI permettent a votre programme Diva de dialoguer avec un standard téléphonique.

Elles permettent de gérer les appels sortants (numérotation) et entrants. Par exemple, il est possible d’afficher automatiquement la fiche client en fonction du numéro de téléphone de l’appelant.

Ces fonctions utilisent le module ycti.dhop.

 

Remarque

Le logiciel PhonePC de Microconcept permettant de dialoguer avec le standard de l’entreprise doit être installé et paramètré.
