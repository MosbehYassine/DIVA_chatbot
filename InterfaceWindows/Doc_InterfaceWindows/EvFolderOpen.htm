EvFolderOpen Famille  Thème

La fonction EvFolderOpen ouvre et initialise la Dll dhEventFolder.dll.

 

module "ysystemex.dhop"

Ptr EvFolderOpen ( caractère , tempo )

 

Paramètres

Caractère

Caractère qui sera placé dans le tampon du clavier lorsqu’une modification du répertoire est détectée. Le fait de placer ce caractère dans le tampon du clavier va réveiller le programme.
Ce caractère pourra être lu par une instruction Getbchar . Si l’appel entrant doit pouvoir être détecté pendant la saisie d’un masque Harmony, il faut mettre un point d’arrêt sur la touche correspondante.

Si l’appel a lieu pendant une instruction XmeConsult ou XmeListConsult, Harmony.Key contient le code de retour clavier correspondant.

Une fois le caracètre lu, le programme doit boucler sur la fonction EvFolderGet pour lire les evénements.

 

Tempo

Délai en secondes. Si au bout de ce délai ancun événément n’a eu lieu pour un répertoire surveillé, un événement est déclenché sur ce répertoire pour forcer le programme à traiter ces répertoires.

Cette temporisation est une sécurité forçant le programme à traiter les répertoires à des intervalles réguliers, au cas ou Windows aurait « sauté » un message.

 

Retour

0

Pas d’erreur

1

Erreur au chargement de la dll dhEventFolder.dll
