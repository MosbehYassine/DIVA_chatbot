EvFolderWriteEvent  Famille  Thème

La fonction EvFolderWriteEvent permet de forcer le déclenchement d’un événement pour un répertoire donné.

Lorsqu’un événement se produit pour un répertoire, il se peut que le programme Diva ne puisse pas le traiter immédiatement. Par exemple, si le programme veut déplacer le fichier, il doit attendre que le programme qui crée le fichier ait fini d’écrire. Si donc le programme détecte qu’il ne peut pas encore traiter l’événement, il appelle EvFolderWriteEvent pour que l’événement soit à nouveau déclenché un peu plus tard.

EvFolerWriteEvent permet également de déclencher un événement sur un répertoire immédiatement après l’appel de EvFolderStart . Cela pour prendre en compte les fichiers qui auraient été créés alors que le répertoire n’était pas encore surveillé.

 

module "ysystemex.dhop"

Ptr EvFolderWriteEvent ( ticket , tempo )  

 

Paramètres

Ticket

Ticket du répertoire pour lequel l’événément va être déclenché. Ce ticket a été rendu préalablement par la fonction EvFolderStart .

 

Tempo

Delai en secondes après lequel l’événement sera déclenché.

 

Retour

0

Erreur.

Autre

????

 

Exemple

Le sous-projet EvFolder du projet exemples.dhpt contient un exemple complet de surveillance de répertoire et de traitement des fichiers.

 

;ouverture du fichier sans le share_write

;si le programme n'a pas encore fini d'écrire dans le fichier

;WinCreateFile sort en erreur 32 , erreur de partage

hd = WinCreateFile( left(fic), GENERIC_READ,FILE_SHARE_READ,0,OPEN_EXISTING,0,0)

if hd = -1

 err = WinGetLastError

 display " Erreur ouverture " 0

 display err 0

 display " active WriteEvent"

 ;s'il y a une erreur de partage , c'est que le programme n'a pas

 ;fini d'écrire le fichier

 ;on demande alors d'être réveillé dans 10 secondes,

 ;on ne boucle pas sur l'ouverture de fichier afin de ne pas ralentir

 ;le serveur inutilement

 EvFolderWriteEvent(ticket,10)

endif
