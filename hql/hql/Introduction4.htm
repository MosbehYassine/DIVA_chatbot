Introduction

Les entrées clavier et les affichages se font à l'aide des masques écran d'Harmony.

Les impressions se font à l'aide des masques imprimante d'Harmony.

Toutes les fonctions du langage Diva peuvent être utilisées, mais Hql propose quelques procédures permettant de simplifier au maximum la programmation.

La variable contenant le nom du masque écran est Hql.MsqEcran. Par défaut le nom du masque écran est obtenu en changeant l'extension .dhop du nom du module de chapitres en .dhoe.

La variable contenant le nom du masque imprimante est Hql.MsqImp. Par défaut le nom du masque écran est obtenu en changeant l'extension .dhop du nom du module de chapitres en .dhoi.

Ces données peuvent être modifiées dans le chapitre HqlDebutListe.
