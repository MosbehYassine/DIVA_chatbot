Déclaration des fichiers et des enregistrements

Dans le module des chapitres, vous DEVEZ obligatoirement déclarer les enregistrements publics suivants :

  • L'enregistrement HQL, qui est défini dans le dictionnaire système Ddsys.dhsd et qui sert de zone de communication entre XHql.dhop et le module.

  • L'enregistrement du fichier considéré par l'instruction Record.

Exemple :

Public record Ddsys.dhsd HQL

Public record odfdd.dhsd Article

En fonction des besoins, il faudra également déclarer :

  • l'enregistrement SYSTEM du dictionnaire Ddsys.dhsd (si vous utilisez par exemple le code utilisateur)

  • les fichiers externes

  • les enregistrements de manœuvre 

  • etc.

Exemple :

Public record Ddsys.dhsd System

hFile Odfdd.dhsd Odf TdfFour

Public record odfdd.dhsd Four

 

Contrôle des versions de fichiers

Harmony contrôle la cohérence entre les versions des fichiers et des programmes qui y accèdent. Pour cela la description d'une base dans le dictionnaire de données comporte un numéro de version. Le fichier comporte lui aussi un numéro de version. Pour les programmes ordinaires, ce contrôle est effectué automatiquement à l'ouverture du fichier déclaré par l'instruction Hfile. Dans le cas particulier de HQL, celui-ci ne connaît pas à priori le fichier qu'il va traiter. Ce fichier n'est connu que par le programme appelant et par le module de traitement.

L'instruction HfileVersion permet d'indiquer dans le module des chapitres, le nom du fichier pour lequel il faut contrôler la version. Si cette instruction est présente dans le module, HQL contrôle la cohérence de version avec le fichier. Si l'option « Toujours contrôler la version » est active au niveau du fichier, et que l'instruction HfileVersion est absente du module, HQL interrompt le traitement avec une erreur fatale.

Le contrôle de la version peut-être inhibé en positionnant l'indicateur HQL.CheckVersion à ZOOM_NON avant l'appel du programme HQL ou bien dans le chapitre HQLPreliminaire. Ceci peut-être intéressant dans le cas où le même programme traite indifféremment une base réelle ou une extraction de la base dans un fichier temporaire. Dans ce dernier cas, il ne faut pas contrôler la version.

Exemple :

HFileVersion Odfdd.dhsd Odf
