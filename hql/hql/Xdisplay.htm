Xdisplay  Famille Thème

 

La procédure Xdisplay affiche une page du masque par l'instruction XmeDispv (en mode Goto).

 

Xdisplay [ page ]

 

Paramètres

Page

Numéro de page à afficher. La valeur par défaut est 1.

 

Remarques

  • Cette fonction peut être utilisée pour afficher la page de fond du programme Hql.

  • Elle peut également être utilisée pour mettre à jour l'écran, pour indiquer la progression du programme par exemple.

  • Il existe un modèle de masque d'écran (xqlm.dhse) que vous pouvez copier.
