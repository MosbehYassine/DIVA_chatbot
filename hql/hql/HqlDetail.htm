HqlDetail  Famille Thème

 

Le chapitre HqlDetail est exécuté pour chaque enregistrement sélectionné. Si le programme comporte un tri, HqlDetail est appelé lors du parcours des enregistrements préalablement triés.

Attention, si le programme comporte un tri, l'enregistrement n'est pas relu depuis le fichier (le tri est fait dans une liste). Il n'est donc pas possible d'utiliser la fonction de réécriture (hrewrite) sans refaire une lecture préalable depuis le fichier.
