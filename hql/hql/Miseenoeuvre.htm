XHQL

Le source du module des chapitres peut être saisi à l'aide de l'éditeur Xwin ou de tout autre éditeur de textes standard.

Les masques sont saisis et compilés à l'aide de Xwin. Utilisez comme modèles les masques types livrés avec Harmony.

La fonction XHQL permet de lancer le moteur HQL. Il s'exécute dans un espace mémoire distinct de celui du programme appelant. Les paramètres d'appel de la fonction sont stockés dans l'enregistrement HQL qui est transmis au moteur au travers du tunnel. Les paramètres les plus courants sont des paramètres formels de la fonction, alors que des paramètres plus particuliers doivent être positionnés dans l'enregistrement HQL.

XHql (Hql,[Fichier],[Enreg],[ModuleChapitre],[MasqueEcran],[MasqueImp])

Paramètres

Hql

est l'enregistrement qui contient les paramètres du moteur Hql. C'est le seul paramètre obligatoire de la fonction. Les autres paramètres sont facultatifs, ils permettent néanmoins d'appeler le moteur en une seule instruction dans la plupart des cas.

[Fichier]

est le nom du fichier disque. Il correspond à la donnée Hql.fichier.

[Enreg]

est le nom de l'enregistrement. Il doit être déclaré public dans le module des chapitres. Il correspond à la donnée Hql.Enreg.

[ModuleChapitre]

est le nom de l'objet du module des chapitres. Il correspond à la donnée Hql.ModTrait.

[MasqueEcran]

est le nom de l'objet du masque d'écran. Il correspond à la donnée Hql.MsqEcran. Par défaut le nom du masque écran est déduit du nom du module des chapitres en changeant l'extension .dhop en .dhoe.

[MasqueImp]

est le nom de l'objet du masque d'impression. Il correspond à la donnée Hql.MsqImp. Par défaut le nom du masque imprimante est déduit du nom du module des chapitres en changeant l'extension .dhop en .dhoi.

Quelques paramètres de l'enregistrement Hql

Hql.cle

permet d'indiquer la clé de lecture du fichier de base. Le fichier de base sera lu à partir de la valeur de cette donnée si Hql.Clemin et Hql.Clemax ne sont pas positionnés.

Hql.CleMin et Hql.CleMax

Permettent de borner la clé de lecture du fichier de base. Le fichier de base sera lu à partir Hql.CleMin si le sens de lecture du fichier est normal et à partir de Hql.CleMax si le sens de lecture est inverse.

Hql.Sens

Permet d'indiquer le sens de lecture du fichier de base. La valeur ZOOM_SENS_NORMAL indique un sens de lecture normal alors que la valeur ZOOM_SENS_INVERSE indique le sens de lecture inverse.

Voir l'enregistrement Hql pour la description de tous les paramètres possibles.
