Gestion des modèles d'imprimante

La gestion des modèles se commande, depuis n'importe quel menu de type Hmenu (Harmony.dhop, par exemple), par la frappe de Shift+F6.

En suivant la procédure habituelle des zooms, vous pouvez créer de nouveaux modèles, consulter, modifier ou supprimer des modèles existants. Une fiche modèle contient les champs suivants :

 

Toutes impressions
 

Modèle d'imprimante

Nom du modèle (6 caractères maximum).

Libellé

Commentaire (30 caractères maximum).

Format pour le spool

Ce champ de quatre caractères maximum précise l'imprimante et le paramétrage Windows à utiliser pour imprimer l'état.
Par xDivaltoPrinters, l'administrateur du système doit établir un lien entre ce format et le couple imprimante / paramétrage associé : Cf. rubrique "Liaison entre modèle et imprimante/ paramétrage Windows" du guide d'utilisation en ligne d'Harmony.
Remarque : le format est significatif uniquement en mode d'impression "Spool".

Hauteur papier

Nombre maximum de lignes par page (toutes orientations pour les états graphiques ; en mode portrait uniquement pour les états caractères).

Type d'imprimante

Si vous sélectionnez l'option Maquette, toute édition effectuée avec ce modèle générera un fichier "maquette", qui pourra ensuite être rejoué indépendamment du programme ayant produit cette édition. Cette option est normalement réservée à un usage de développement et de test.

Suffixer le nom du fichier maquette avec la date

Cette option permet, lorsque le choix Maquette a été sélectionné comme type d'imprimante, de suffixer le nom du fichier généré par la date de l'édition. Elle permet d'obtenir plusieurs versions de maquette à partir d'une même édition.

 
 

Toutes impressions en mode graphique
 

Mode d'impression

Le choix "Spool" est obligatoire en mode graphique car les états (caractères ou graphiques) édités en mode graphique doivent passer par le spouleur de Windows.

Fichier descriptif

FIHWGRA (ou FIHWGRC) est obligatoire en mode graphique.
Ce paramètre ne concerne que les états caractères.
FIHWGRC utilise des caractères plus "comprimés" que FIHWGRA. Il permet donc de placer plus de caractères dans une ligne. Utilisez-le, par exemple, si votre imprimante ne permet pas d'imprimer 80 caractères par ligne en mode normal ou 132 caractères par ligne en mode comprimé.
Attention : l'envoi d'une séquence d'initialisation en début d'édition est obligatoire avec FIHWGRC (Cf. annexe "Envoi d'une séquence d'initialisation à l'imprimante" du guide d'utilisation en ligne d'Harmony).

 
 

Toutes impressions caractères
 

Saut de page standard

Méthode pour réaliser les sauts de page :
Oui demande que les sauts de page soient commandés par l'envoi du caractère 0C (form-feed). Ce choix est obligatoire pour les imprimantes laser.
Non demande que les pages soient au besoin complétées avec des lignes blanches, jusqu'à atteindre la hauteur de papier indiquée.

Saut de page

Commande de saut(s) de page :
Avant : un saut de page est fait au début de chaque édition.
Après : un saut de page est fait à la fin de chaque édition.
Avant et après : un saut de page est fait au début et à la fin de chaque édition.
Aucun : pas de saut de page en début ni en fin d'édition.

Hauteur papier
en mode paysage

Nombre maximum de lignes par page quand l'état est édité en mode paysage (Cf. rubrique "Réglage de la hauteur d'édition" du guide d'utilisation en ligne d'Harmony).
Si ce champ est laissé à 0, c'est le paramètre "Hauteur papier" qui indique le nombre maximum de lignes par page.

Mode paysage / Caractères comprimés

Si vous cochez la case située sur la ligne :
"Plus de 132 colonnes",
"81 à 132 colonnes",
"1 à 80 colonnes",
les états faisant respectivement plus de 132 caractères par ligne,
de 81 à 132 caractères par ligne, de 1 à 80 caractères par ligne seront édités en mode paysage / caractères comprimés (pour toutes explications complémentaires, voir la rubrique "Réglage de la largeur d'édition" du guide d'utilisation en ligne d'Harmony).

 
 

Impressions caractères en mode caractères
 

Mode d'impression

Spool : les éditions passent par le spouleur de Windows (mode conseillé).
Normal : les éditions sont faites sur l'imprimante affectée à la tâche.
Transparence : interdit sous Windows.

Unité logique

Numéro d'unité logique de l'imprimante en mode d'impression normal.

Fichier descriptif

Nom du fichier descriptif imprimante.

 

Remarque : Le fichier de stockage des modèles d'imprimante (Fprinters.dhfi) est un fichier "système", unique pour toutes les applications Harmony. Le paramétrage des imprimantes de l'installation peut donc se faire à partir de n'importe quel menu (y compris le menu Harmony.dhop).
