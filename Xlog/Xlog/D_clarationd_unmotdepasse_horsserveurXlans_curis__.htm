Déclaration d'un mot de passe (hors serveur Xlan sécurisé)

Le mot de passe permet d'interdire, à quiconque ne le connaît pas, d'accéder à votre code utilisateur. Pour déclarer ou, par la suite, modifier votre mot de passe :

  • Tapez la touche Tab après l'introduction de votre code utilisateur ou de votre mot de passe actuel.

  • Cliquez sur le bouton Modifier votre mot de passe.

  • Tapez le mot de passe souhaité à deux reprises (pour éviter les fautes de frappe). Seul l'administrateur pourra ensuite retrouver le mot de passe que vous avez introduit.

 

Si vous désirez annuler votre mot de passe, procédez de la même manière mais tapez la touche Entrée à deux reprises à la place du mot de passe.
