ZoomAvantWrite       Famille  Thème

 

Objet : Traitements avant écriture.

Procédure : Facultative.

Exécutée : Avant l'écriture d'une nouvelle fiche.

 

La procédure ZoomAvantWrite est appelée après la validation d'une création ou d'une duplication et avant l'écriture du nouvel enregistrement dans la base.

Elle peut être utilisée pour :

  • Interdire la création sous certaines conditions.

  • Compléter l'enregistrement créé avec des données non saisies (par exemple, le code utilisateur, la date de création).

  • Revenir à la saisie si une anomalie est détectée.

  • Affecter les données composant l'index principal si la page 2 n'est pas saisie.

  • Changer le titre variable de la fenêtre en mode fiche en garnissant la donnée Zoom.TitreVar.
     

Au retour de la procédure ZoomAvantWrite, le zoom se poursuit normalement si la donnée Zoom.Ok est positionnée à 'O' (valeur par défaut).

Positionnez Zoom.Ok à la valeur :

  • 'N' pour interdire la création, avec affichage du message "Création interdite".

  • 'I' pour interdire la création, sans affichage du message.

  • 'S' pour forcer le retour à la saisie.
    Sans précision contraire, la saisie reprendra sur la donnée en cours au moment de la validation du masque mais vous pouvez choisir le point de retour en positionnant Harmony.Retour et Harmony.CplRetour à la manière habituelle.

 

Exemple 1 :

Ajout de la date de création.

Public Procedure ZoomAvantWrite

Beginp

   Article.DateCrea = Today

Endp

 

Exemple 2 :

Vérification d'une donnée saisie. Si la donnée X est erronée, on revient dans le masque sur cette donnée. A cet effet, on affecte à cette dernière le point de séquence numéro 100.

Public Procedure ZoomAvantWrite

Beginp

   If <condition non réalisée sur la donnée X>

      MessageBox ("Donnée X incorrecte","Message",MB_OK + MB_ICONEXCLAMATION)

      Zoom.Ok = 'S'

      Harmony.Retour = XMENEXT_POINT_SEQUENCE

      Harmony.CplRetour = 100

   Endif

Endp
