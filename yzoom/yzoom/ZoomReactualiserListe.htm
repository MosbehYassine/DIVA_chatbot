ZoomReactualiserListe

 

Cette procédure sans paramètres réactualise toutes les lignes du mode liste. Pour cela, elle ré-exécute la requête et réaffiche le tableau à partir du début. Attention, l'élément courant de la liste est perdu.
 

Elle peut être appelée par exemple dans la séquence ZoomApresModif ou ZoomConsult si des lignes du mode liste sont susceptibles d'être modifiées.

 

Rappel

Pour appeler cette procédure, il est nécessaire de déclarer le module xzoom7.dhop par l'instruction module "xzoom7.dhop".

 

Voir aussi :

ZoomReactualiserPage, qui ne perd pas l'élément courant.
