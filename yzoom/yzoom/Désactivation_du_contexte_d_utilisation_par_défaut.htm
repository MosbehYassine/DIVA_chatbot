Désactivation du contexte d'utilisation par défaut

 

Lorsque l’utilisateur définit un contexte par défaut pour le zoom, celui-ci s’applique automatiquement au chargement du zoom. Cela permet par exemple à un commercial de filtrer les clients de sa région. Dans le cas d’un pilotage du zoom (scénario), ce fonctionnement peut s'avérer gênant. Par exemple, si on appelle le zoom du client associé à un événement et que ce client se situe dans une autre région, le zoom n’affichera aucun résultat.

C’est pourquoi il est possible, dans la procédure ZoomDebut, de désactiver l’application du contexte par défaut en mode piloté.
 

A cet effet, l’enregistrement Zoom comporte le champ ContexteDefaut qui, s'il est positionné à ZOOM_NON, désactive le contexte par défaut. Ce champ est initialisé à ZOOM_OUI à l'entrée dans le zoom.

 

Exemple :

If G7.ZoomPar = 1                 ;pilotage par référence

   Zoom.ContexteDefaut = ZOOM_NON

Endif

 

 

Afficher la liste des contextes sur la page du tableau pour un choix rapide

 

Pour un changement rapide de contexte d'utilisation, le développeur peut facilement donner cette possibilité aux utilisateurs.

Pour cela, il suffit de :

1. Placer un champ de type Multi-choix sur la page 3 du masque

2. Ce multi-choix doit être l'instance "Contexte.ListeContexte". "Contexte" étant un enregistrement du dictionnaire ddsys.dhsd.

3. Dans un dictionnaire de multi-choix, il faut rajouter une entrée dont le type de choix est "Liste" et dont l'identifiant de la liste est "Id_ListeContexte"

4. L' "arrêt après" doit être positionné à 32 et "notifier la modification" doit être à "oui"

 

Ce multi-choix sera automatiquement garnis par le moteur du zoom, et lorsque l'utilisateur sélectionne un contexte, il sera directement appliqué.

 

 

Il est également possible de simplement copier/coller le champ présent dans le masque zoom7.dhsf disponible dans le répertoire divalto/sys
