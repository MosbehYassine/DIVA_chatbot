ZoomInitListe       Famille  Thème

 

Objet : Traitement avant l'impression en mode liste.

Procédure : Facultative.

Exécutée : Avant une impression en mode liste.

 

Si cette procédure n'existe pas dans le module standard du zoom (Zoom.ModTrait) et que la donnée Zoom.ModTraitI est renseignée, cette procédure est appelée dans le module Zoom.ModTraitI.

 

La procédure ZoomInitListe est appelée avant chaque impression en mode liste.

Elle peut être utilisée pour :

  • Choisir le modèle d'imprimante. Si un choix permet d'annuler l'impression, on positionnera la donnée Zoom.Ok à 'N'.

  • Spécifier le nom du masque d'impression (Zoom.MsqImp).

  • Indiquer si l'on souhaite une présentation détaillée (généralement une page par fiche) plutôt qu'une présentation standard (généralement une ligne par fiche). Pour cela, il faut positionner l'indicateur Zoom.LouFiche à ZOOM_OUI (valeur par défaut ZOOM_NON) et garnir le numéro du bloc à imprimer pour le détail d'une fiche (Zoom.NoBloc). Par défaut, le numéro de bloc est celui du mode fiche (5).

  • Inhiber l'ouverture de la boîte de dialogue demandant l'impression complète ou partielle, détaillée ou standard (voir les deux paragraphes précédents). Pour cela, on positionnera la donnée Zoom.Ok à 'A'. Dans ce cas, le zoom prendra soit les valeurs standard si aucun paramètre n'a été positionné, soit les valeurs positionnées dans cette séquence.

  • Masquer la question du choix de la liste détaillée ou standard dans la boîte de dialogue. S'il n'y a pas d'impression détaillée prévue, on positionnera Zoom.NoBloc à 0.

  • Abandonner l'impression en positionnant Zoom.Ok à 'N'. Dans ce cas l'impression n'aura pas lieu du tout.

  • Initialiser des données.
