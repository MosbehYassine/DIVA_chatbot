ZoomApresDetail       Famille  Thème

 

Objet : Traitement après l'impression d'un bloc détail en mode liste.

Procédure : Facultative.

Exécutée : Après une impression du bloc 2.

 

Si cette procédure n'existe pas dans le module standard du zoom (Zoom.ModTrait) et que la donnée Zoom.ModTraitI est renseignée, cette procédure est appelée dans le module Zoom.ModTraitI.

 

La procédure ZoomApresDetail est appelée après chaque impression du bloc détail (2).
