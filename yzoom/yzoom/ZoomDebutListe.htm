ZoomDebutListe       Famille  Thème

 

Objet : Traitement avant l'impression.

Procédure : Facultative.

Exécutée : Avant une impression.

 

Si cette procédure n'existe pas dans le module standard du zoom (Zoom.ModTrait) et que la donnée Zoom.ModTraitI est renseignée, cette procédure est appelée dans le module Zoom.ModTraitI.

 

La procédure ZoomDebutListe est appelée avant chaque impression.

Elle peut être utilisée pour :

  • Changer le nom du masque d'impression (Zoom.MsqImp).

  • Changer le numéro du bloc à imprimer en mode fiche (Zoom.NoBloc).

  • Initialiser des données.
