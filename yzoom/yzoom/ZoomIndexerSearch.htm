ZoomIndexerSearch

 

Cette procédure permet de notifier le serveur Search d'une action à faire.

 

ZoomIndexerSearch ( Action, IdATraiter )

 

Paramètres :

 

Action :

SEARCH_INDEX_DOCUMENT

Demande une indexation

SEARCH_DELETE_DOCUMENT

Demande la suppression du document dans la base Search

SEARCH_MODIFY_DOCUMENT

Demande la mise à jour du document dans la base Search

 

IdATraiter

  Identifiant SQL de la ligne à traiter. Cet identifiant s'obtient via la fonction RecordSql.GetId().

 

 

Attention : Le ZoomSql, lors d'une création, modification et suppression, se charge de notifier le serveur Search.
