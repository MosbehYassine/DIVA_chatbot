Zoom.SceExport

 

Indique si l’exportation des données par l’impression paramétrable est ou non autorisée.

L’impression paramétrable permet d’envoyer les données vers l’imprimante mais également vers le presse-papiers ou dans un fichier texte ou au format Htm. Ce paramètre vaut :

  • ZOOM_EXPORT_TOUT lorsque l’export est autorisé vers tous ces supports (valeur par défaut).

  • ZOOM_EXPORT_IMP autorise uniquement l’impression.

  • ZOOM_EXPORT_RIEN interdit la fonction d’export des données.
