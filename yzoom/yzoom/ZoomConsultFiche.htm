ZoomConsult       Famille  Thème

 

Objet : Traitement après consultation.

Procédure : Facultative.

Exécutée : Après une action de l'utilisateur en consultation (tous modes d'affichage).

 

Cette séquence de traitement peut être utilisée notamment pour :

  • Appeler un autre zoom.

  • Afficher une page d'informations complémentaires.

  • Appeler un autre programme.

  • Afficher un menu surgissant (popup).

 

Menu popup :

Pour afficher un menu surgissant, il faut garnir Harmony.PopupMenu avec l'identifiant du menu à afficher et positionner Zoom.Ok à 'N'.

 

Remarque :

Dans cette séquence, il est possible d'appeler la procédure publique ZoomReactualiserListe afin de mettre à jour l'ensemble des éléments de la liste de l'objet tableau. Cela peut s'avérer utile lorsque le traitement effectue des modifications sur d'autres fiches affichées. Il convient alors de déclarer le module xzoom7.dhop par l'instruction "module" puis d'appeler la procédure ZoomReactualiserListe. Par exemple :
 

Module "xzoom7.dhop"

Public Procedure ZoomConsult

Beginp

Record ddsys.dhsd Zoom WZoom

   If Harmony.Key = K_F8

      Init WZoom = ' '

      ZoomSql (WZoom,'article','me1.dhof','mod1.dhop')

      If WZoom.ModifFlg = ZOOM_OUI

         ZoomReactualiserListe        ;ou ZoomReactualiserPage (*)

      Endif

   Endif

Endp

 

 

(*) Attention, ZoomReactualiserListe ré-exécute la requête. On repart donc au début et le courant de la liste est perdu. Pour ne pas ré-exécuter la requête et ne pas perdre le courant, il faut appeler la procédure ZoomReactualiserPage, qui relit seulement les lignes de la page en cours, sans perdre le courant.
