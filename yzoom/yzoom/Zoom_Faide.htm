Zoom.Faide

 

Indique le nom du fichier d'aides de l'application. Si ce paramètre est absent, le choix Aide du menu Aide est grisé. S'il est présent, ce choix provoquera l'affichage de l'aide Zoom.NoAide du fichier Faide.

 

Remarque :

Il s'agit ici d'une aide spécifique à l'application. L'aide standard expliquant le fonctionnement général du zoom est toujours disponible pour l'utilisateur (F1).
