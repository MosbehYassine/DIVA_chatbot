Déclaration des RecordSql

 

Dans le module de traitements Diva d'un zoom, vous DEVEZ obligatoirement déclarer Public :

  • L'enregistrement ZOOM, qui est défini dans le dictionnaire système ddsys.dhsd et qui sert de zone de communication entre xZoom7 et le module de traitements.

  • Le RecordSql considéré par l’instruction RecordSql.

 

Exemple :

Public Record ddsys.dhsd Zoom

Public RecordSql gtrsart.dhoq Article

 

En fonction des besoins, il faudra également déclarer :

  • L'enregistrement SYSTEM du dictionnaire ddsys.dhsd (si vous utilisez par exemple le code utilisateur).

  • Les RecordSql des tables externes.

  • Les enregistrements de manœuvre.

  • Etc.
     

Exemple :

Public Record ddsys.dhsd System

Public RecordSql gtrstiers.dhoq Four
