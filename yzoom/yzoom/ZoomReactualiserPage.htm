ZoomReactualiserPage

 

Cette procédure sans paramètres réactualise la page courante du mode liste. Pour cela, elle relit et réaffiche tous les enregistrements couramment affichés. L'élément courant de la liste est conservé. Attention : Par contre, elle ne fait pas apparaître les nouvelles lignes qui auraient pu être créées.
 

Elle peut être appelée par exemple dans la séquence ZoomApresModif ou ZoomConsult si des lignes du mode liste sont susceptibles d'être modifiées.

 

Rappel

Pour appeler cette procédure, il est nécessaire de déclarer le module xzoom7.dhop par l'instruction module "xzoom7.dhop".

 

Voir aussi :

ZoomReactualiserListe, qui fait apparaître les nouvelles lignes éventuellement créées.
