XmeMenuPopupErase  Famille  Thème

Suppression des choix d'un menu surgissant

 

Ptr XmeMenuPopupErase (Id_Menu)

 

Paramètre :

Id_Menu

Identifiant du menu rendu par la fonction XmeMenuGetId.

 

Valeur rendue par la fonction : 0.

 

Description de la fonction :

  • Rappelons que dans l’éditeur de menus de Xwin, un menu popup est conventionnellement dessiné comme une barre de menu classique comportant un unique choix principal. Ce choix est fictif car il n’apparaît jamais à l’exécution (ce sont ses sous-choix qui constituent le menu popup).

  • La fonction XmeMenuPopupErase permet de supprimer tous les choix d'un menu popup existant.
    Plus précisément, la fonction supprime uniquement les sous-choix du choix fictif principal. Le choix fictif lui-même n'est pas supprimé.

  • Pour ensuite regarnir le menu popup vidé de ses choix, utilisez la fonction XmeMenuInsertItem.

 

Exemple :

 

1 Id_popup L                                  ;ident menu popup

...

...
XmeLoad "masque"                              ;chargement du masque

Id_popup = XmeMenuGetId ("masque","POPUP")    ;chargement menu "POPUP"

...

...

XmeMenuPopupErase (id_popup)                  ;effacement des choix existants

 

;peuplement du nouveau menu popup

;remarque : "Fictif" est le nom du choix fictif dans Xwin

params = ...                                  ;paramètres du nouveau 1er choix

XmeMenuInsertItem (id_popup,params,MENU_LAST_ITEM,"Fictif",FALSE)

params = ...                                  ;paramètres du nouveau 2ème choix

XmeMenuInsertItem (id_popup,params,MENU_LAST_ITEM,"Fictif",FALSE)

params = ...                                  ;paramètres du nouveau dernier choix

XmeMenuInsertItem (id_popup,params,MENU_LAST_ITEM,"Fictif",TRUE)
