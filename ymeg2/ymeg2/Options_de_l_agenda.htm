Options de l'agenda

 

L’objet agenda propose un certain nombre d’options.

 

Pour positionner UNE option, il faut :

  • Utiliser une instance de l’enregistrement ObjectOption du dictionnaire ddCalendar.dhsd.

  • Préciser l’option choisie dans le champ ObjectOption.Option.

  • Affecter sa valeur dans le champ ObjectOption.Value.
    Remarque : ce champ est de type alphanumérique ; si vous lui affectez une variable binaire (nature B, X ou L), prenez soin de la convertir en alpha par la fonction ToString ; réciproquement, utilisez la fonction Val pour transférer une option dans une variable binaire.

  • Ajouter l’option à l’agenda avec la fonction XmeCalendarSetOption.

Si vous désirez positionner plusieurs options, répétez cette opération pour chacune d'elles.

 

Les identifiants des options, ainsi que les valeurs possibles de certaines options, sont des "Define" Diva définis dans le fichier "Include" zCalendar.dhsp.

Cas particulier des options concernant les types de vue proposés :

  • Le programme peut changer le libellé affiché des vues et/ou choisir de ne pas proposer tel ou tel type de vue.
    Par défaut, un libellé standard est proposé pour chaque type de vue et tous les types de vue possibles sont proposés à l'utilisateur.
    Pour ne proposer que certaines d'entre elles, vous devez ajouter une option par vue désirée (voir l'exemple 2 ci-dessous).

  • Attention, les options qui concernent les vues doivent se programmer AVANT le premier affichage de la page Xwin contenant l’agenda.

  • XmeCalendarSetOption garantit l’unicité d'une option dans la liste des options. Ainsi, si on ajoute deux fois la vue « Semaine », elle n’apparaîtra qu’une seule fois dans l’agenda.

 

Droits de personnalisation

A condition de lui en donner les droits, l'utilisateur peut personnaliser certaines options (en cliquant sur le bouton "Options" tout en bas de l'agenda). Par exemple, il peut choisir le 1er jour de la semaine, ses heures de travail, etc. Les valeurs qu'il choisit sont sauvegardées dans sa base de registres locale, de manière à les retrouver lorsqu'il rouvre son agenda.

Si vous désirez forcer une option par programme, il ne faut pas autoriser l'utilisateur à modifier cette option.

Lorsque l'agenda est affiché, le client initialise dans un premier temps les options avec les valeurs sauvegardées dans la base de registre. Ensuite et seulement si l'utilisateur n'a pas le droit correspondant, il prend en compte l'option forcée par programme.

Corollaire : Lorsque le programme ne donne pas le droit de modification d'une option à l'utilisateur, il doit aussi la forcer par programme.

 

 

Exemples :
 

Public Record ddCalendar.dhsd ObjectOption Opt

 

;Donner tous les droits de personnalisation à l'utilisateur :

Opt.Option   = CAL_OPT_CUSTOMIZATION

Opt.OptValue = CAL_CUSTOM_EVERYTHING

XmeCalendarSetOption (IdCal,Opt)
 

;Ne proposer que les vues journalières et hebdomadaires :

Opt.Option   = CAL_OPT_VIEW_DAILY             ;vue journalière

Opt.OptValue = "Jour"                         ;libellé affiché personnalisé

XmeCalendarSetOption (IdCal,Opt)
Opt.Option   = CAL_OPT_VIEW_WEEKLY            ;vue hebdomadaire

Opt.OptValue = " "                            ;libellé affiché par défaut

XmeCalendarSetOption (IdCal,Opt)

 

;Forcer les intervalles mineurs et majeurs

;(nécessite d'interdire le changement d'intervalles)

Opt.Option   = CAL_OPT_CUSTOMIZATION

Opt.OptValue = CAL_CUSTOM_EVERYTHING - CAL_CUSTOM_CHANGE_TICK_LENGTH  ;tous droits de personnalisation

XmeCalendarSetOption (IdCal,Opt)                                      ;hormis les intervalles

Opt.Option   = CAL_OPT_MINOR_TICK_LENGTH

Opt.OptValue = CAL_MINOR_TICK_LENGTH_30M                              ;forcer les intervalles

XmeCalendarSetOption (IdCal,Opt)

Opt.Option   = CAL_OPT_MAJOR_TICK_LENGTH

Opt.OptValue = CAL_MAJOR_TICK_LENGTH_1H

XmeCalendarSetOption (IdCal,Opt)

 

 

Extraire les valeurs unitaires d'une option à valeurs combinées

Ce paragraphe concerne les options CAL_OPT_MASK_WORKING_DAYS, CAL_OPT_ACCESS_RIGHTS et CAL_OPT_CUSTOMIZATION dont la valeur peut être une combinaison de plusieurs valeurs unitaires toutes égales à une puissance de 2.

La fonction XmeCalendarGetBinaryMaskValues permet de retrouver les valeurs unitaires à partir de la valeur combinée de l'option. Par exemple, si on lui passe en paramètre la valeur 61, elle retourne :

<value>32<value>16<value>8<value>4<value>1

ce qui permet de retrouver les différentes valeurs qui ont été combinées.
