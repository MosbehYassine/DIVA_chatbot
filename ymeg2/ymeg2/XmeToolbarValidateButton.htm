XmeToolbarValidateButton  Famille  Thème

Invalidation ou revalidation d’un bouton de barre d'outils

 

Ptr XmeToolbarValidateButton (Id_Toolbar, Id_Bouton, Etat, Prise_en_compte)

 

Paramètres :

Id_Toolbar

Identifiant de la barre d'outils rendu par la fonction XmeToolbarGetId.

Id_Bouton

Identificateur du bouton à invalider ou revalider.

Etat

FALSE : le bouton doit être invalidé (il devient invisible).
TRUE  : le bouton doit être revalidé (il redevient visible).

Prise_en_compte

TRUE  : la barre d'outils doit être immédiatement réaffichée.
FALSE : la barre d'outils ne doit pas être immédiatement réaffichée.

FALSE permet d'optimiser les réaffichages de la barre d'outils lorsque vous effectuez plusieurs invalidations ou revalidations successives de bouton : ne mettez ce drapeau à TRUE qu'au tout dernier appel à XmeToolbarValidateButton. Attention toutefois : ce dernier appel ne doit pas concerner un bouton dont l’état n’est pas modifié (la fonction étant ignorée si l’état du bouton reste inchangé, l’ensemble des réaffichages sera « perdu ») !

Remarque : dans les versions d'Harmony précédant la version 7, cette optimisation n’affectait pas forcément les performances de manière visible. Mais elle peut s’avérer cruciale en client léger pour éviter un fort ralentissement de l’affichage.

Ce paramètre facultatif (TRUE par défaut) n’est significatif que si la barre d'outils est déjà affichée.

 

Valeur rendue par la fonction :

0 : Pas d’erreur détectée.

0x107B : Bouton inconnu dans la barre d'outils.

 

Description de la fonction :

La fonction XmeToolbarValidateButton permet d’invalider (Etat = FALSE) ou revalider (Etat = TRUE) le bouton d’identificateur Id_Bouton dans la barre d'outils Id_Toolbar. Un bouton invalidé devient totalement invisible.

 

Remarque : 

Lorsqu'une même barre d'outils est affichée dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de bouton, surcharge, ...) sont répercutées dans TOUTES les OCCURENCES affichées.

 

Exemple :

;Invalidation des boutons "OPTION_1" et "OPTION_2"

XmeToolbarValidateButton (Id_toolbar,"OPTION_1",FALSE,FALSE)

XmeToolbarValidateButton (Id_toolbar,"OPTION_2",FALSE)
