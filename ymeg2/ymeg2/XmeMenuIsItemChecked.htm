XmeMenuIsItemChecked  Famille  Thème

Test de l'état d'un choix de menu de nature case à cocher ou bouton radio

 

Ptr XmeMenuIsItemChecked (Id_Menu, Id_Choix)

 

Paramètres :

Id_Menu

Identifiant du menu rendu par la fonction XmeMenuGetId.

Id_Choix

Identificateur du choix.

 

Valeur rendue par la fonction :

FALSE :   Le choix est actuellement décoché.
(valeur aussi rendue si le choix n’est ni une "case à cocher" ni un "bouton radio")

TRUE   :   Le choix est actuellement coché.

0x1089 :   Choix inconnu dans le menu.

 

Description de la fonction :

La fonction XmeMenuIsItemChecked permet de connaître l’état courant du choix d’identificateur Id_Choix dans le menu Id_Menu. Elle ne s’applique qu’aux choix de nature « case à cocher » ou « bouton radio ».

 

Exemple :

1 Status X

...

Status = XmeMenuIsItemChecked (Id_menu,"OPTION")

If (Status = TRUE)                       ;le choix "OPTION" est coché :

   ...                                   ;traitement 

Endif
