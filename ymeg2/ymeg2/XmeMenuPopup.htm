XmeMenuPopup  Famille  Thème

Appel explicite à un menu surgissant

 

Ptr XmeMenuPopup (Id_Menu)

 

Paramètre :

Id_Menu

Identifiant du menu rendu par la fonction XmeMenuGetId.

 

Valeur rendue par la fonction :

  • 0 : L'utilisateur n'a sélectionné aucun choix.

  • 1 : L'utilisateur a sélectionné un choix de type "Point d'arrêt".

  • 2 : L'utilisateur a sélectionné un choix de type "Point de traitement".

  • 3 : L'utilisateur a sélectionné un choix de type "Génération de caractères".

 

Description de la fonction :

  • La fonction XmeMenuPopup permet d’appeler un menu contextuel des ressources de Xwin par programme (pour plus de détails, consultez la rubrique Menus : Chargement et affichage).

  • Si un choix de type "Point d'arrêt" est sélectionné, Harmony.DataArret est positionné.

  • Si un choix de type "Point de traitement" est sélectionné, le traitement est exécuté. Les valeurs Harmony.Retour et Harmony.CplRetour éventuellement positionnées par ce traitement sont ignorées. Toutefois, elles sont transmises au programme appelant qui peut, le cas échéant, en tenir compte. Aucun réaffichage automatique des données du masque n'est effectué au retour du traitement.

  • Si un choix de type "Génération de caractères" est sélectionné, Harmony.Key est positionné.

  • La fonction complémentaire XmeMenuPopupErase peut être utilisée pour supprimer tous les choix d'un menu popup existant.

 

Attention, XmeMenuPopup ne tient pas compte du contexte d'appel. Il en résulte que :

  • Le grisage automatique des choix nommés ne fonctionne pas avec XmeMenuPopup (mais il existe une autre méthode d'affichage des menus contextuels qui permet ce grisage automatique : voir la rubrique Menus : Chargement et affichage).

  • Certaines variables de l'enregistrement Harmony ne sont pas positionnées à l'appel du traitement (choix de type "Point de traitement") ou au retour de la fonction (par exemple : Harmony.DataPage, Harmony.DataSeq ; Harmony.Arret en saisie).

 

Exemple :

 

1 Id_popup L                                  ;ident menu popup

1 st       X

...

...
XmeLoad "masque"                              ;chargement du masque

Id_popup = XmeMenuGetId ("masque","POPUP")    ;chargement menu "POPUP"

...

...

st = XmeMenuPopup (id_popup)                  ;appel explicite au menu

if st <> 0                                    ;un choix a été sélectionné :

   SWITCH ...                                 ;traitement des choix

   ... 

endif
