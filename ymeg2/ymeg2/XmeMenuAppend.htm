XmeMenuAppend  Famille  Thème

Ajout d’un menu de surcharge à un menu

 

Long XmeMenuAppend (Id_Menu, Nom_du_masque, Nom_du_menu, Abandon)

 

Paramètres :

Id_Menu

Identifiant du menu à surcharger rendu par la fonction XmeMenuGetId.

Nom_du_masque

Nom du fichier masques contenant le menu de surcharge.

Nom_du_menu

Nom du menu de surcharge.

Abandon

Ce drapeau précise le traitement à effectuer en cas d'erreur :

  • TRUE : la fonction ne rend pas la main et une erreur système est affichée.

  • FALSE : la fonction rend la main avec une valeur de retour nulle.

Paramètre facultatif (TRUE par défaut).

 

Valeur rendue par la fonction :

  • 0 : une erreur a été détectée (masque non chargé ou menu de surcharge inexistant dans le masque ou identifiant du menu à surcharger erroné).
    Cette valeur ne peut être rendue que si le paramètre Abandon vaut FALSE.

  • Autre : identifiant du menu (inchangé).

 

Description de la fonction :

  • La fonction XmeMenuAppend ajoute au menu Id_Menu un second menu, identifié par le Nom du fichier masques où il a été dessiné et par le Nom de menu qui lui a été attribué dans l’éditeur de ressources de Xwin.

  • Pour en savoir plus sur la manière de dessiner un menu de surcharge dans Xwin, consultez la rubrique Menus : Surcharge.

  • En cas d’erreur, vous choisissez si votre programme garde la main et traite l’erreur (Abandon = FALSE) ou s’il est arrêté avec un message d’erreur système (Abandon = TRUE qui est la valeur par défaut).

 

Remarques :

  • Le masque doit être préalablement chargé par XmeLoad.

  • Si le menu de base est déjà affiché, il est immédiatement actualisé à l’écran.

  • Un même menu peut être surchargé plusieurs fois.

  • Lorsqu'un même menu est affiché dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de choix, surcharge, ...) sont répercutées dans TOUTES les OCCURENCES affichées.

 

Exemple 1 :

1 Id_menu L

...

XmeLoad ("MASQUE")

Id_menu = XmeMenuGetId ("MASQUE","MENU")

...

XmeMenuAppend (Id_menu,"MASQUE","MENU_SURCHARGE")

 

Exemple 2 :

1 Id_menu L

...

XmeLoad ("MASQUE")

Id_menu = XmeMenuGetId ("MASQUE","MENU")

...

XmeLoad ("SURCHARGE")

XmeMenuAppend (Id_menu,"SURCHARGE","MENU_SURCHARGE")
