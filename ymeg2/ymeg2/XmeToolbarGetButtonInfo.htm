XmeToolbarGetButtonInfo  Famille  Thème

Lecture des paramètres d'un bouton de barre d'outils

 

Ptr XmeToolbarGetButtonInfo (Id_Toolbar, Id_Bouton, Caractéristiques)

 

Paramètres :

Id_Toolbar

Identifiant de la barre d'outils rendu par la fonction XmeToolbarGetId.

Id_Bouton

Identificateur du bouton concerné.

Caractéristiques

Zone de réception des caractéristiques du bouton (voir paragraphe Lecture des paramètres du bouton ci-après). Il s’agit d’une chaîne de caractères au format HMP (Harmony Markup Parameters).

 

Valeur rendue par la fonction :

0 : Pas d’erreur détectée.

0x107B : Bouton inconnu dans la barre d'outils.

 

Description de la fonction :

La fonction XmeToolbarGetButtonInfo permet de récupérer les caractéristiques actuelles du bouton d’identificateur Id_Bouton dans le barre d'outils Id_Toolbar.

 

Lecture des paramètres du bouton :

Au retour de la fonction XmeToolbarGetButtonInfo, le paramètre Caractéristiques est garni avec les caractéristiques actuelles du bouton. Il s’agit d’une chaîne de caractères au format HMP (Harmony Markup Parameters) : pour récupérer la valeur d’un paramètre, utilisez la fonction HmpRead ou HmpSeek. XmeToolbarGetButtonInfo délivre les paramètres et valeurs respectives suivants :

<BOUTON>

Nom de bouton dans la feuille de styles (sur 32 caractères).
Délivré uniquement pour les boutons terminaux.

<TYPE>

Type et Nature :

  • NORMAL : type Terminal et nature Normal.

  • CASE : type Terminal et nature Case à cocher
    (dans ce cas, le paramètre <Coche> est délivré).

  • RADIO : type Terminal et nature Bouton radio
    (dans ce cas, le paramètre <Coche> est délivré).

  • SEPARATEUR : type Séparateur
    (dans ce cas, <Type> est le seul paramètre délivré).

<LIBELLE>

Texte.

<POLICE>

Nom de la police du texte dans la feuille de styles (sur 32 caractères).

<BITMAP>

Nom d’image bitmap dans la feuille de styles (sur 32 caractères).
Remarque : si l’image a été récupérée à partir d’un bouton (resp. d’une image bitmap) de la feuille de styles, le nom délivré ici sera celui du bouton (resp. de la bitmap).

<NOMSELEC>

Nom pour la sélection (sur 32 caractères).

<BULLE>

Bulle d'aide.

<ACTION>

+

<ARRET>
ou
<CHAINE>

Type de traitement  :

  • ARRET : le bouton génère un point d’arrêt
    (<Arret> est ici garni avec le numéro d’arrêt cadré à droite sur 5 caractères).

  • TRAITEMENT : le bouton génère un point de traitement
    (le source du traitement n’est pas accessible).

  • CHAINE : le bouton génère une chaîne de caractères
    (<Chaine> est ici garni avec la chaîne à générer).

<LICENCECONSULT>

 

Valeur de l'option "Licence consultation" (0 ou 1).
Remarque : Cette option n'est pas délivrée si la taille de la zone de réception des caractéristiques du choix est insuffisante pour la contenir.

<COCHE>

Drapeau reflétant l'état courant programmé par XmeToolbarCheckButton ou XmeToolbarCheckRadioButton (non délivré hors "case à cocher" ou "bouton radio") :

  • 1 : le bouton est coché.

  • 0 : le bouton est décoché.

<ACTIF>

Drapeau reflétant l'état courant programmé par XmeToolbarEnableButton :

  • 1 : le bouton est activé (non grisé).

  • 0 : le bouton est désactivé (grisé).

<VALIDE>

Drapeau reflétant l'état courant programmé par XmeToolbarValidateButton :

  • 1 : le bouton est validé.

  • 0 : le bouton est invalidé.

 

Exemple :

1 params 1000

1 alpha 200

...

 

XmeToolbarGetButtonInfo (Id_toolbar, "BoutonX", params)

                         Alpha = HmpSeek (params, "type", ' ')

Switch Alpha

   Case 'NORMAL' 

      ... 

   Case 'CASE' 

      ... 

   Case 'RADIO' 

      ...

   Case 'SEPARATEUR' 

      ...
