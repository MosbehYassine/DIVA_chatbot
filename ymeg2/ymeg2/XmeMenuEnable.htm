XmeMenuEnable  Famille  Thème

Désactivation (grisage) ou réactivation (dégrisage) d’un menu complet

 

XmeMenuEnable (Id_Menu, Etat)

 

Paramètres :

Id_Menu

Identifiant du menu rendu par la fonction XmeMenuGetId.

Etat

FALSE : le menu doit être globalement désactivé (grisé).
TRUE  : le menu doit être globalement réactivé (dégrisé).

 

Description de la fonction :

La procédure XmeMenuEnable permet de désactiver (Etat = FALSE) ou réactiver (Etat = TRUE) globalement le menu d’identifiant Id_Menu. Lorsqu’un menu est globalement désactivé, tous ses choix principaux apparaissent grisés à l’écran et aucun ne peut plus être sélectionné par l’utilisateur.

 

Remarques :

  • Il est possible de désactiver plusieurs fois le même menu. Mais attention, pour que le menu redevienne opérationnel, il faut le réactiver autant de fois qu’il a été désactivé.

  • Cette fonction n’est prise en compte que si le menu spécifié est DEJA AFFICHÉ dans la fenêtre EN COURS. Elle est ignorée dans le cas contraire.

  • Si votre programme empile plusieurs fenêtres, il est inutile de désactiver les menus affichés dans les fenêtres autres que la fenêtre courante car le système les désactive automatiquement.

 

Exemple :

;Invalidation du menu complet

XmeMenuEnable (Id_menu, FALSE)
