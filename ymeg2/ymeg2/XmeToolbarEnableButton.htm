XmeToolbarEnableButton  Famille  Thème

Désactivation (grisage) ou réactivation (dégrisage) d’un bouton de barre d'outils

 

Ptr XmeToolbarEnableButton (Id_Toolbar, Id_Bouton, Etat)

 

Paramètres :

Id_Toolbar

Identifiant de la barre d'outils rendu par la fonction XmeToolbarGetId.

Id_Bouton

Identificateur du bouton à désactiver ou réactiver.

Etat

FALSE : le bouton doit être désactivé (grisé).
TRUE  : le bouton doit être réactivé (dégrisé).

 

Valeur rendue par la fonction :

0 : Pas d’erreur détectée.

0x107B : Bouton inconnu dans la barre d'outils.

 

Description de la fonction :

La fonction XmeToolbarEnableButton permet de désactiver (Etat = FALSE) ou réactiver (Etat = TRUE) le bouton d’identificateur Id_Bouton dans la barre d'outils Id_Toolbar. Un bouton désactivé apparaît grisé à l’écran et ne peut plus être sélectionné par l’utilisateur. Cette fonction reste sans effet pour un bouton de type séparateur.

 

Remarque :

Lorsqu'une même barre d'outils est affichée dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de bouton, surcharge, ...) sont répercutées dans TOUTES les OCCURENCES affichées.

 

Exemple :

;Désactivation du bouton "COUPER"

XmeToolbarEnableButton (Id_toolbar,"COUPER",FALSE)
