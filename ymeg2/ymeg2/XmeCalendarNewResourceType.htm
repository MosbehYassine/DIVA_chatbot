XmeCalendarNewResourceType  Famille Thème

Ajout d'un type de ressource à la liste des types de ressource d'un agenda

 

Long XmeCalendarNewResourceType (Identifiant, Type, Nom, Libellé, [Multi], [Image], [Couleur], [Code_page], [BitmapPath])

 

Paramètres :
 

Identifiant

Enregistrement identifiant l'agenda rendu par la fonction XmeCalendarGetId.

Type

Numéro d'un type de ressource (type pré-défini ou nouveau type : Cf. rubrique Types de ressource d'un agenda).
Ce numéro doit être unique et servira d'identifiant pour la fonction XmeCalendarNewResource.

Nom

Nom du type de ressource (32 caractères maximum).
Ce nom sert de clef pour le composant client (XWPF et XHTML5) et doit donc être unique et ne pas contenir d'espace.

Libellé

Libellé du type de ressource affiché (32 caractères maximum).

Multi

Lorsque cette valeur est positionnée à FALSE, cela signifie qu'un rendez-vous ne pourra posséder qu'une seule ressource de ce type. Si vous affectez plusieurs ressources de ce type au même rendez-vous, aucune erreur n'est détectée mais seule la dernière est prise en compte.
Paramètre facultatif (TRUE par défaut).

Exemple :
On peut décider que plusieurs ressources de type "PARTICIPANT" peuvent être associées aux rendez-vous de la catégorie "REUNION" mais une seule ressource de type "SALLE".

Image

Nom d'une image dans la feuille de styles ou nom d'un fichier image (.bmp, .png, ...).
Paramètre facultatif (32 caractères maximum).
Cette image sera utilisée par défaut pour toutes les ressources de ce type.

Couleur

Nom d'une couleur dans la feuille de styles.
Paramètre facultatif (32 caractères maximum).
Cette couleur sera utilisée par défaut pour toutes les ressources de ce type.

Code_page
 

Code page du libellé (jeu de caractères à utiliser pour afficher le libellé en langue étrangère).
Paramètre facultatif (0 par défaut).

BitmapPath

Chemin Harmony contenant l'emplacement du fichier image (facultatif).

 

Valeur rendue par la fonction :

-1 : ticket invalide.

Autre : Adresse du nouveau type de ressource dans la liste des types de ressource.

 

Description de la fonction :

La fonction XmeCalendarNewResourceType ajoute un type de ressource à la liste des types de ressource de l'agenda ou personnalise un type de ressource pré-défini.

 

Exemple :
 

XmeCalendarNewResourceType (IdCal,4,"PARTICIPANT","Participant à une réunion",,,"BLEU")

XmeCalendarNewResourceType (IdCal,5,"SALLE","Salle de réunion",FALSE,,"VERT")
