XmeGanttGetId  Famille Thème

Identification et initialisation d'un objet Gantt

 

Char XmeGanttGetId (Masque, Page, Gantt)

 

Paramètres :
 

Masque

Nom du fichier masque.

Page

Numéro de page.

Gantt

Nom de l'objet Gantt.
 

 

Valeur rendue par la fonction :

Instance d'un enregistrement IdGantt du dictionnaire ddgantt.dhsd identifiant le Gantt (et ses listes), à passer en paramètre de toutes les fonctions appelées ultérieurement par le programme et référençant le Gantt. Vous trouverez le format de cet enregistrement à la rubrique Interface de programmation d'un objet Gantt.
 

 

Attention, XmeGanttGetId doit être exécuté AVANT le premier affichage de la page Xwin contenant le Gantt.

 

Description de la fonction :

  • La fonction XmeGanttGetId crée et initialise les listes associées au Gantt. A cette occasion, Ywpf garnit un enregistrement, rendu par XmeGanttGetId, qui servira à identifier le Gantt de manière unique. Aucune fonction gérant le Gantt ne peut être appelée AVANT XmeGanttGetId car l'enregistrement renvoyé doit être passé en paramètre à toutes les fonctions concernant le Gantt.

  • Le Gantt est identifié par le Nom du fichier masque plus le Numéro de page où il a été dessiné et par le Nom du Gantt qui lui a été attribué dans Xwin (une même page de masque peut contenir plusieurs objets Gantt de noms différents; des objets Gantt portant le même nom peuvent être dessinés dans des pages différentes).
     

Remarques :

  • Le masque doit être préalablement chargé par XmeLoad.

  • Cette fonction nomme les listes afin de faciliter leur reconnaissance dans le débogueur de Xwin.
    Les noms sont calculés en concaténant nom du masque (sans l'extension), numéro de la page, nom de du Gantt et nom de la liste (en séparant les éléments par un _).

 

Exemple :
 

Module  "yGantt.dhop"
Include "zGantt.dhsp"

Public  Record ddGantt.dhsd IdGantt IdGantt ;enregistrement d'identification

...

XmeLoad ("masque")                              ;chargement du masque

IdGantt = XmeGanttGetId ("masque",1,"GANTT")    ;initialisation du Gantt nommé GANTT

                                                ;et situé dans la page 1 du masque
