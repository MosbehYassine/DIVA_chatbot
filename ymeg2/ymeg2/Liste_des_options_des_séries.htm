Comme LINE, mais l'aire sous la courbe est matérialisée

CHART_OPTV_SR_T_RANGE

Série de points "Range". Chaque point est décrit par son abscisse et deux "ordonnées" : une valeur minimum et une valeur maximum.

Les valeurs maximum et les valeurs minimum sont reliés entre elles et l'aire délimitée par les deux courbes est matérialisée.

Mode de combinaison.

Le mode de combinaison n'est disponible qu'avec les séries cartésiennes et un axe des abscisse catégoriel.

Cette option permet de piloter la manière dont les points de différentes séries, mais partageant la même abscisse, vont être combinés.

 

Mode de combinaison

Description

CHART_OPTV_SR_COMBINEMODE_CLUSTER

Uniquement pour séries de barres, les barres sont accolées les une aux autres.

CHART_OPTV_SR_COMBINEMODE_STACK

Les séries sont empilées.

CHART_OPTV_SR_COMBINEMODE_STACK100

Les séries sont empilées et le total est normalisé (permet de visualiser aisément des proportions).
