XmeCalendarGetResourceType  Famille Thème

Lecture d'un type de ressource dans la liste des types de ressource d'un agenda

 

Long XmeCalendarGetResourceType (Identifiant, Type_Ressource, &Objet_Type_Ressource)

 

Paramètres :
 

Identifiant

Enregistrement identifiant l'agenda rendu par la fonction XmeCalendarGetId.

Type_Ressource

Numéro du type de ressource.

Objet_Type_Ressource

Instance d'un enregistrement ObjectResourceType du dictionnaire ddCalendar.dhsd.

 

Valeur rendue par la fonction :

0 : Type de ressource non trouvé.

Autre : Adresse du type de ressource dans la liste des types de ressource de l'agenda.

 

Description de la fonction :

La fonction XmeCalendarGetResourceType cherche le type de ressource dont le numéro est fourni en paramètre dans la liste des types de ressource et charge l'enregistrement correspondant.

 

Exemple :
 

Record ddCalendar.dhsd ObjectResourceType TypeRessource

1  adr  L

...

XmeCalendarNewResourceType (IdCal,4,"PARTICIPANT","Participant à une réunion",,,"BLEU")

XmeCalendarNewResourceType (IdCal,5,"SALLE","Salle de réunion",FALSE,,"VERT")

...

adr = XmeCalendarGetResourceType (IdCal,5,TypeRessource)
