XmeMenuGetId  Famille  Thème

Chargement en mémoire d’un menu classique ou surgissant
Lecture de son identifiant

 

Long XmeMenuGetId (Nom_du_masque, Nom_du_menu, Abandon)

 

Paramètres :

Nom_du_masque

Nom du fichier masques contenant le menu à charger.

Nom_du_menu

Nom du menu à charger.

Abandon

Ce drapeau précise le traitement à effectuer en cas d'erreur :

  • TRUE : la fonction ne rend pas la main et une erreur système est affichée.

  • FALSE : la fonction rend la main avec une valeur de retour nulle.

Paramètre facultatif (TRUE par défaut).

 

Valeur rendue par la fonction :

  • 0 : une erreur a été détectée (masque non chargé ou menu inexistant dans le masque).
    Cette valeur ne peut être rendue que si le paramètre Abandon vaut FALSE.

  • Autre : identifiant du menu, à passer en paramètre de toutes les fonctions référençant le menu et appelées ultérieurement par le programme.

 

Description de la fonction :

  • Au premier appel, la fonction XmeMenuGetId charge le menu en mémoire. A cette occasion, Ywpf calcule une valeur, rendue par XmeMenuGetId, qui servira à identifier le menu de manière unique. Aucune fonction gérant le menu ne peut être appelée avant XmeMenuGetId car l'identifiant renvoyé doit être passé en paramètre de toutes les fonctions concernant le menu.

  • Lors des appels suivants, la fonction XmeMenuGetId renvoie simplement l'identifiant du menu.

  • Le menu est identifié par le Nom du fichier masques où il a été dessiné et par le Nom de menu qui lui a été attribué dans l’éditeur de ressources de Xwin (un même fichier masques peut contenir plusieurs menus ; des menus portant le même nom peuvent être dessinés dans des fichiers masques différents).

  • En cas d’erreur, vous choisissez si votre programme garde la main et traite l’erreur (Abandon = FALSE) ou s’il est arrêté avec un message d’erreur système (Abandon = TRUE qui est la valeur par défaut).

 

Remarques :

  • Le masque doit être préalablement chargé par XmeLoad.

  • Vous pouvez charger plusieurs menus dans un même programme.

  • Le même menu peut être affiché dans plusieurs fenêtres (même si celles-ci sont simultanément présentes à l'écran) et ces fenêtres peuvent contenir la même page ou des pages de masque différentes.
    Mais attention    , lorsqu'un même menu est affiché dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de choix, surcharge, ...) sont répercutées dans TOUTES les OCCURENCES affichées.

 

Exemple 1 :

;chargement du menu nommé MENU à partir du masque MASQUE

;abandon du programme en cas d’erreur

1 Id_menu L

...

XmeLoad ("MASQUE")

Id_menu = XmeMenuGetId ("MASQUE","MENU")

 

Exemple 2 :

;chargement du menu nommé POPUP_MENU à partir du masque MASQUE

;avec traitement des erreurs par le programme

1 Id_popup_menu L

...

XmeLoad ("MASQUE")

Id_popup_menu = XmeMenuGetId ("MASQUE","POPUP_MENU",FALSE)

If Id_popup_menu = 0                               ;erreur

   ... 

Endif
