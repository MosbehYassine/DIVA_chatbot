XmeMenuValidateItem  Famille  Thème

Invalidation ou revalidation d’un choix de menu

 

Ptr XmeMenuValidateItem (Id_Menu, Id_Choix, Etat, Prise_en_compte)

 

Paramètres :

Id_Menu

Identifiant du menu rendu par la fonction XmeMenuGetId.

Id_Choix

Identificateur du choix à invalider ou revalider.

Etat

FALSE : le choix doit être invalidé (il devient invisible).
TRUE  : le choix doit être revalidé (il redevient visible).

Prise_en_compte

TRUE  : le menu doit être immédiatement réaffiché.
FALSE : le menu ne doit pas être immédiatement réaffiché.

FALSE permet d'optimiser les réaffichages du menu lorsque vous effectuez plusieurs invalidations ou revalidations successives de choix principal : ne mettez ce drapeau à TRUE qu'au tout dernier appel à XmeMenuValidateItem. Attention toutefois : ce dernier appel ne doit pas concerner un choix dont l’état n’est pas modifié (la fonction étant ignorée si l’état du choix reste inchangé, l’ensemble des réaffichages sera « perdu ») !

Remarque : dans les versions d'Harmony précédant la version 7, cette optimisation n’affectait pas forcément les performances de manière visible. Mais elle peut s’avérer cruciale en client léger pour éviter un fort ralentissement de l’affichage.

Ce paramètre facultatif (TRUE par défaut) n’est significatif que si le menu est déjà affiché et si le choix concerné est un choix principal.

 

Valeur rendue par la fonction :

0 : Pas d’erreur détectée.

0x1089 : Choix inconnu dans le menu.

 

Description de la fonction :

La fonction XmeMenuValidateItem permet d’invalider (Etat = FALSE) ou revalider (Etat = TRUE) le choix d’identificateur Id_Choix dans le menu Id_Menu. Un choix invalidé devient totalement invisible, de même que son sous-menu si ce choix est tête de sous-menu.

 

Remarque : 

Lorsqu'un même menu est affiché dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de choix, surcharge, ...) sont répercutées dans TOUTES les OCCURENCES affichées.

 

Exemple :

;Invalidation des choix "OPTION_1" et "OPTION_2"

XmeMenuValidateItem (Id_menu,"OPTION_1",FALSE,FALSE)

XmeMenuValidateItem (Id_menu,"OPTION_2",FALSE)

 

Voir également :

XmeMenuEnableItem, qui permet de désactiver (griser) un choix de menu.
