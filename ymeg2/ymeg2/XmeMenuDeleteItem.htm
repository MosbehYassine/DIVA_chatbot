XmeMenuDeleteItem  Famille  Thème

Destruction d'un choix de menu

 

Ptr XmeMenuDeleteItem (Id_Menu, Id_Choix, Prise_en_compte)

 

Paramètres :

Id_Menu

Identifiant du menu rendu par la fonction XmeMenuGetId.

Id_Choix

Identificateur du choix à détruire.

Prise_en_compte

TRUE  : le menu doit être immédiatement réaffiché.
FALSE : le menu ne doit pas être immédiatement réaffiché.

FALSE permet d'optimiser les réaffichages du menu lorsque vous effectuez plusieurs destructions successives de choix principal : ne mettez ce drapeau à TRUE qu'à la toute dernière destruction.

Remarque : dans les versions d'Harmony précédant la version 7, cette optimisation n’affectait pas forcément les performances de manière visible. Mais elle peut s’avérer cruciale en client léger pour éviter un fort ralentissement de l’affichage.

Ce paramètre facultatif (TRUE par défaut) n’est significatif que si le menu est déjà affiché et si le choix concerné est un choix principal.

 

Valeur rendue par la fonction :

0 : Pas d’erreur détectée.

0x1089 : Choix inconnu dans le menu.

 

Description de la fonction :

La fonction XmeMenuDeleteItem permet de supprimer le choix d’identificateur Id_Choix dans le menu Id_Menu. Si le choix est tête de sous-menu, son sous-menu est également supprimé.

 

Remarque :

Lorsqu'un même menu est affiché dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de choix, surcharge, ...) sont répercutées dans TOUTES les OCCURENCES affichées.

 

Exemple :

XmeMenuDeleteItem (Id_menu,"Option")
