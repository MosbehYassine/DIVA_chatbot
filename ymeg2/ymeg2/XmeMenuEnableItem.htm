XmeMenuEnableItem  Famille  Thème

Désactivation (grisage) ou réactivation (dégrisage) d’un choix de menu

 

Ptr XmeMenuEnableItem (Id_Menu, Id_Choix, Etat)

 

Paramètres :

Id_Menu

Identifiant du menu rendu par la fonction XmeMenuGetId.

Id_Choix

Identificateur du choix à désactiver ou réactiver.

Etat

FALSE : le choix doit être désactivé (grisé).
TRUE  : le choix doit être réactivé (dégrisé).

 

Valeur rendue par la fonction :

0 : Pas d’erreur détectée.

0x1089 : Choix inconnu dans le menu.

 

Description de la fonction :

La fonction XmeMenuEnableItem permet de désactiver (Etat = FALSE) ou réactiver (Etat = TRUE) le choix d’identificateur Id_Choix dans le menu Id_Menu. Un choix terminal désactivé apparaît grisé à l’écran et ne peut plus être sélectionné par l’utilisateur. Un choix tête de sous-menu désactivé apparaît grisé à l’écran et son sous-menu devient inaccessible. Cette fonction reste sans effet pour un choix de type séparateur.

 

 

Remarque :

Lorsqu'un même menu est affiché dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de choix, surcharge, ...) sont répercutées dans TOUTES les OCCURENCES affichées.

 

Exemple :

;Désactivation du choix "COUPER"

XmeMenuEnableItem (Id_menu,"COUPER",FALSE)

 

Voir également :

XmeMenuEnable, qui permet de désactiver globalement tout un menu.
