XmeMenuGetItemInfo  Famille  Thème

Lecture des paramètres d'un choix de menu

 

Ptr XmeMenuGetItemInfo (Id_Menu, Id_Choix, Caractéristiques)

 

Paramètres :

Id_Menu

Identifiant du menu rendu par la fonction XmeMenuGetId.

Id_Choix

Identificateur du choix concerné.

Caractéristiques

Zone de réception des caractéristiques du choix (voir paragraphe Lecture des paramètres du choix ci-après). Il s’agit d’une chaîne de caractères au format HMP (Harmony Markup Parameters).

 

Valeur rendue par la fonction :

0 : Pas d’erreur détectée.

0x1089 : Choix inconnu dans le menu.

 

Description de la fonction :

La fonction XmeMenuGetItemInfo permet de récupérer les caractéristiques actuelles du choix d’identificateur Id_Choix dans le menu Id_Menu.

 

Lecture des paramètres du choix :

Au retour de la fonction XmeMenuGetItemInfo, le paramètre Caractéristiques est garni avec les caractéristiques actuelles du choix. Il s’agit d’une chaîne de caractères au format HMP (Harmony Markup Parameters) : pour récupérer la valeur d’un paramètre, utilisez la fonction HmpRead ou HmpSeek. XmeMenuGetItemInfo délivre les paramètres et valeurs respectives suivants :

<BOUTON>

Nom de bouton dans la feuille de styles (sur 32 caractères).
Délivré uniquement pour les choix terminaux.

<TYPE>

Type et Nature :

  • NORMAL : type Terminal et nature Normal.

  • CASE : type Terminal et nature Case à cocher
    (dans ce cas, le paramètre <Coche> est délivré).

  • RADIO : type Terminal et nature Bouton radio
    (dans ce cas, le paramètre <Coche> est délivré).

  • SOUS-MENU : type Sous-menu.

  • SEPARATEUR : type Séparateur
    (dans ce cas, <Type> est le seul paramètre délivré).

<LIBELLE>

Libellé.

<BITMAP>

Nom d’image bitmap dans la feuille de styles (sur 32 caractères)
Remarque : si l’image a été récupérée à partir d’un bouton (resp. d’une image bitmap) de la feuille de styles, le nom délivré ici sera celui du bouton (resp. de la bitmap).

<NOMSELEC>

Nom pour la sélection (sur 32 caractères).

<AIDE>

Texte d'aide.

<ACTION>

+

<ARRET>
ou
<CHAINE>

Type de traitement  :

  • ARRET : le choix génère un point d’arrêt
    (<Arret> est ici garni avec le numéro d’arrêt cadré à droite sur 5 caractères).

  • TRAITEMENT : le choix génère un point de traitement
    (le source du traitement n’est pas accessible).

  • CHAINE : le choix génère une chaîne de caractères
    (<Chaine> est ici garni avec la chaîne à générer).

<LICENCECONSULT>

 

Valeur de l'option "Licence consultation" (0 ou 1).
Remarque : Cette option n'est pas délivrée si la taille de la zone de réception des caractéristiques du choix est insuffisante pour la contenir.

<COCHE>

Drapeau reflétant l'état courant programmé par XmeMenuCheckItem ou XmeMenuCheckRadioItem (non délivré hors "case à cocher" ou "bouton radio") :

  • 1 : le choix est coché.

  • 0 : le choix est décoché.

<ACTIF>

Drapeau reflétant l'état courant programmé par XmeMenuEnableItem :

  • 1 : le choix est activé (non grisé).

  • 0 : le choix est désactivé (grisé).

<VALIDE>

Drapeau reflétant l'état courant programmé par XmeMenuValidateItem :

  • 1 : le choix est validé.

  • 0 : le choix est invalidé.

 

Exemple :

1 params 1000

1 alpha 200

...

 

XmeMenuGetItemInfo (Id_menu, "ChoixX", params)

Alpha = HmpSeek (params, "type", ' ')

      ...

      ...

   Case 'SOUS-MENU' 

      ...
