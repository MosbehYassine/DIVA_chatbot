XmeCalendarGetBinaryMaskValues  Famille Thème

Extraction des valeurs unitaires d'un masque binaire

 

String XmeCalendarGetBinaryMaskValues (Masque)

 

Paramètre :
 

Masque

Valeur binaire à décomposer.

 

Valeur rendue par la fonction :

Chaîne au format HMP décrivant les valeurs unitaires qui composent le masque binaire.

 

Description de la fonction :

  • La fonction XmeCalendarGetBinaryMaskValues permet de décomposer un masque binaire pour obtenir les valeurs unitaires (toutes égales à une puissance de 2) qui ont servi à sa conception.

  • Elle peut être utilisée pour retrouver les valeurs unitaires qui ont été combinées pour former les options de l'agenda CAL_OPT_MASK_WORKING_DAYS, CAL_OPT_ACCESS_RIGHTS et CAL_OPT_CUSTOMIZATION.
     

Exemple :

Si on lui passe en paramètre la valeur 61, la fonction retourne :

<value>32<value>16<value>8<value>4<value>1
