XmeMenuCheckRadioItem  Famille  Thème

Coche d’un choix de menu de nature bouton radio
Décoche du choix du groupe radio précédemment coché

 

Ptr XmeMenuCheckRadioItem (Id_Menu, Id_Choix)

 

Paramètres :

Id_Menu

Identifiant du menu rendu par la fonction XmeMenuGetId.

Id_Choix

Identificateur du choix à cocher.

 

Valeur rendue par la fonction :

0 :          Pas d’erreur détectée.
(remarque : aucune erreur n’est signalée - la fonction est ignorée - si le choix spécifié n'est pas de nature "bouton radio")

0x1089 : Choix inconnu dans le menu.

 

Description de la fonction :

La fonction XmeMenuCheckRadioItem ne s’applique qu’aux choix faisant partie d’un "groupe de boutons radio". Elle permet de cocher le choix d’identificateur Id_Choix dans le menu Id_Menu, le choix du groupe précédemment coché étant automatiquement décoché.

 

Programmation d’un groupe de choix "bouton radio" :

Initialement, tous les choix appartenant à un groupe de boutons radio sont à l’état « non coché ». De plus, lorsque l’utilisateur sélectionne un des choix du groupe, l’état de la coche N’est PAS AUTOMATIQUEMENT actualisé. En conséquence (voir l’exemple), votre programme doit exécuter XmeMenuCheckRadioItem :

  • Avant le premier affichage du menu, pour cocher le choix du groupe qui doit apparaître initialement coché (sauf si aucun des choix ne doit être coché au départ).

  • Ensuite, pour mettre l’état des choix du groupe à jour en cas de sélection d’un des choix par l’utilisateur (si l’utilisateur sélectionne un choix appartenant à un groupe de boutons radio, le programme doit cocher ce choix – le choix du groupe précédemment coché étant automatiquement décoché).

 

Remarques :

  • XmeMenuCheckRadioItem ne permet pas de décocher TOUS les choix d’un groupe de boutons radio. Pour ce faire, appliquez la fonction XmeMenuCheckItem à tous les choix du groupe.

  • Vous pouvez utiliser la fonction XmeMenuIsItemChecked pour connaître l’état courant du choix.

  • Lorsqu'un même menu est affiché dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de choix, surcharge, ...) sont répercutées dans TOUTES les OCCURENCES affichées.

 

Exemple :

...
Id_menu = XmeMenuGetId ("MASQUE","MENU")     ;chargement du menu "MENU"

XmeMenuSetWindow (Id_menu,"MASQUE",1)        ;attachement à la page 1

                                             ;Init groupe de choix avant affichage

XmeMenuCheckRadioItem (Id_menu,"OPTION_1")   ;groupe OPTION_1/2/3 :

                                             ;OPTION_1 coché au départ 

 

XmeDisp ("MASQUE",1,XME_MODE_GOTO)           ;affichage page 1 & menu

...

 

Fini = FALSE                                 ;consultation tableau

Do

   XmeListConsult (Id_tableau) 

   Switch Harmony.Key 

      Case K_ESCAPE                          ;abandon 

         Fini = TRUE

 

      Case Harmony.DataArret = 101           ;arrêt <-> choix OPTION_1 

         XmeMenuCheckRadioItem (Id_menu,"OPTION_1") 

         ... 

 

      Case Harmony.DataArret = 102           ;arrêt <-> choix OPTION_2 

         XmeMenuCheckRadioItem (Id_menu,"OPTION_2") 

         ... 

 

      Case Harmony.DataArret = 103           ;arrêt <-> choix OPTION_3 

         XmeMenuCheckRadioItem (Id_menu,"OPTION_3")

         ... 

 

      Case ... 

 

      Default 

         XmeListConsultDefault (Id_tableau,Ligne,Scrollbar32) 

   EndSwitch 

While not Fini

Wend
