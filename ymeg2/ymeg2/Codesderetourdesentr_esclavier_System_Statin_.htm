Codes de retour des entrées clavier (Harmony.Key)

Cette rubrique présente la liste des valeurs que peut prendre la variable Harmony.Key suite à une entrée clavier.

Dans les programmes, il est conseillé de ne pas utiliser les valeurs numériques, peu parlantes, mais plutôt les Defines Diva (de la forme K_xxxx) déclarés dans le fichier Include ZDIVA (fichier inclus automatiquement par le compilateur Diva en tête de votre source).
Exemple : if Harmony.Key = K_F3
