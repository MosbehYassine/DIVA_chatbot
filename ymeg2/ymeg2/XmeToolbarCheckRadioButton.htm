XmeToolbarCheckRadioButton  Famille  Thème

Coche d’un bouton de barre d'outils de nature bouton radio
Décoche du bouton du groupe radio précédemment coché

 

Ptr XmeToolbarCheckRadioButton (Id_Toolbar, Id_Bouton)

 

Paramètres :

Id_Toolbar

Identifiant de la barre d'outils rendu par la fonction XmeToolbarGetId.

Id_Bouton

Identificateur du bouton à cocher.

 

Valeur rendue par la fonction :

0 :           Pas d’erreur détectée.
(remarque : aucune erreur n’est signalée - la fonction est ignorée - si le bouton spécifié n'est pas de nature "bouton radio")

0x107B : Bouton inconnu dans la barre d'outils.

 

Description de la fonction :

La fonction XmeToolbarCheckRadioButton ne s’applique qu’aux boutons faisant partie d’un "groupe de boutons radio". Elle permet de cocher le bouton d’identificateur Id_Bouton dans la barre d'outils Id_Toolbar, le bouton du groupe précédemment coché étant automatiquement décoché.

 

Programmation d’un groupe de "boutons radio" :

Initialement, tous les boutons appartenant à un groupe de boutons radio sont à l’état « non coché ». De plus, lorsque l’utilisateur sélectionne un des boutons du groupe, l’état de la coche N’est PAS AUTOMATIQUEMENT actualisé. En conséquence (voir l’exemple), votre programme doit exécuter XmeToolbarCheckRadioButton :

  • Avant le premier affichage de la barre d'outils, pour cocher le bouton du groupe qui doit apparaître initialement coché (sauf si aucun des boutons ne doit être coché au départ).

  • Ensuite, pour mettre l’état des boutons du groupe à jour en cas de sélection d’un des boutons par l’utilisateur (si l’utilisateur sélectionne un bouton appartenant à un groupe de boutons radio, le programme doit cocher ce bouton – le bouton du groupe précédemment coché étant automatiquement décoché).

 

Remarques :

  • XmeToolbarCheckRadioButton ne permet pas de décocher TOUS les boutons d’un groupe de boutons radio. Pour ce faire, appliquez la fonction XmeToolbarCheckButton à tous les boutons du groupe.

  • Vous pouvez utiliser la fonction XmeToolbarIsButtonChecked pour connaître l’état courant du bouton.

  • Lorsqu'une même barre d'outils est affichée dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de bouton, surcharge, ...) sont répercutées dans TOUTES les OCCURENCES affichées.

 

Exemple :

...

Id_toolbar = XmeToolbarGetId ("MASQUE","OUTILS")       ;chargement

XmeToolbarSetWindow (Id_toolbar,"MASQUE",1)            ;attachement page 1

                                                       ;Init groupe avant affichage

XmeToolbarCheckRadioButton (Id_toolbar,"OPTION_1")

                                                       ;groupe OPTION_1/2/3 :

                                                       ;OPTION_1 coché au départ

 

XmeDisp ("MASQUE",1,XME_MODE_GOTO)                     ;affichage page 1 & outils

...

 

Fini = FALSE                                           ;consultation tableau

Do

   XmeListConsult (Id_tableau) 

   Switch Harmony.Key 

      Case K_ESCAPE                                    ;abandon 

         Fini = TRUE

 

      Case Harmony.DataArret = 101                     ;arrêt <-> bouton OPTION_1

         XmeToolbarCheckRadioButton (Id_toolbar,"OPTION_1")

         ...

 

      Case Harmony.DataArret = 102                     ;arrêt <-> bouton OPTION_2

         XmeToolbarCheckRadioButton (Id_toolbar,"OPTION_2")

         ... 

 

      Case Harmony.DataArret = 103                     ;arrêt <-> bouton OPTION_3

         XmeToolbarCheckRadioButton (Id_toolbar,"OPTION_3")

         ...

 

      Case ... 

 

      Default

         XmeListConsultDefault (Id_tableau,Ligne,Scrollbar32) 

   EndSwitch

While not Fini

Wend
