Spécificités de développement pour le client léger Web

 

Dans l'architecture 3 tiers d'Harmony, la couche Présentation est assurée par le client léger Harmony. Deux types de client léger sont proposés par Harmony : le client léger Wpf, qui s'exécute de manière classique sur un poste client équipé du système Windows, et le client léger Web (ou client léger Html) qui s'exécute dans un navigateur Web.

 

Les applications Harmony destinées aux clients légers Web et Wpf sont dans l'ensemble identiques. Elles utilisent les mêmes masques d’écran Xwin et font appel au même exécuteur de masques Ywpf. Toutefois, le client léger Html s’exécute dans un navigateur Web et certaines fonctionnalités, habituellement offertes par le système Windows et accessibles sous Xwpf, ne sont pas mises à disposition sur le Web (en particulier pour des raisons de sécurité).

 

Ce livre présente les restrictions imposées par le Web, les fonctionnalités non implémentées en Html5 et les différences entre Wpf et Html susceptibles de nécessiter des adaptations dans les programmes d'application.

 

Il contient les rubriques :

Traitements effectués en cas de fermeture du navigateur.

Différences d’affichage entre Html et Wpf.

Restrictions imposées par les navigateurs Web.

Fonctions non implémentées en Html.

Autres différences entre Html et Wpf affectant la programmation.

 

 

Remarque importante :

Le "Client léger Web" et "Harmony Web" sont deux produits totalement distincts, qui utilisent deux technologies différentes et ne doivent pas être confondus.
 

Les documentations de développement pour ces deux produits sont totalement séparées :

  • Les applications Harmony exécutables en clients légers Html et Wpf utilisent les masques d’écran et font appel à l'exécuteur de masques Ywpf.
    Documentations associées :
    Xwin - Atelier de développement Harmony - Editeurs : "Masques écran : concepts généraux" et "Utiliser l'éditeur de Masques écran : Manuel de référence".
    Xwin - Atelier de développement Harmony - Programmation : "Ywpf, exécuteur de masques d'écran - Manuel de référence (1ère et 2ème partie)" et "Spécificités de développement pour le client léger Web".

  • Les applications "Harmony Web" utilisent les masques Web et font appel à l'exécuteur de masques Yweb.
    Documentations associées :
    Xwin - Atelier de développement Harmony - Editeurs : "Masques web : concepts généraux" et "Utiliser l'éditeur de Masques web : Manuel de référence".
    Xwin - Atelier de développement Harmony - Programmation : "Yweb, exécuteur de masques Web - Manuel de référence".
