XmeToolbarCheckButton  Famille  Thème

Coche ou décoche d’un bouton de barre d'outils de nature case à cocher

 

Ptr XmeToolbarCheckButton (Id_Toolbar, Id_Bouton, Etat)

 

Paramètres :

Id_Toolbar

Identifiant de la barre d'outils rendu par la fonction XmeToolbarGetId.

Id_Bouton

Identificateur du bouton à cocher ou décocher.

Etat

TRUE  : le bouton doit être coché.
FALSE : le bouton doit être décoché.

 

Valeur rendue par la fonction :

0 :           Pas d’erreur détectée.
(remarque : aucune erreur n’est signalée - la fonction est ignorée - si le bouton spécifié n'est ni de nature "case à cocher" ni de nature "bouton radio")

0x107B : Bouton inconnu dans le barre d'outils.

 

Description de la fonction :

La fonction XmeToolbarCheckButton permet de cocher (Etat = TRUE) ou décocher (Etat = FALSE) le bouton d’identificateur Id_Bouton dans la barre d'outils Id_Toolbar. Elle ne s’applique qu’aux boutons de nature "case à cocher" ou "bouton radio" (voir première remarque).

 

Programmation d’un bouton "case à cocher" :

Initialement, un bouton de nature case à cocher est à l’état « non coché ». De plus, lorsque l’utilisateur sélectionne un tel bouton, l’état de la coche N’est PAS AUTOMATIQUEMENT actualisé. En conséquence (voir l’exemple), votre programme doit exécuter XmeToolbarCheckButton :

  • Avant le premier affichage de la barre d'outils, pour cocher le bouton s’il doit apparaître initialement coché.

  • Ensuite, pour mettre l’état du bouton à jour en cas de sélection par l’utilisateur (si l’utilisateur sélectionne un bouton non coché, le programme doit le cocher et inversement, si l’utilisateur sélectionne un bouton déjà coché, le programme doit le décocher).

 

Remarques :

  • Pour cocher un bouton de nature "bouton radio", on utilisera de préférence la fonction XmeToolbarCheckRadioButton, qui décoche automatiquement le bouton du groupe radio précédemment coché. Toutefois, XmeToolbarCheckButton peut être utilisée pour décocher (un à un) TOUS les boutons du groupe (ce que ne permet pas XmeToolbarCheckRadioButton).

  • Vous pouvez utiliser la fonction XmeToolbarIsButtonChecked pour connaître l’état courant du bouton.

  • Lorsqu'une même barre d'outils est affichée dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de bouton, surcharge, ...) sont répercutées dans TOUTES les OCCURENCES affichées.

 

Exemple :

...
Id_toolbar = XmeToolbarGetId ("MASQUE","OUTILS")       ;chargement

XmeToolbarSetWindow (Id_toolbar,"MASQUE",1)            ;attachement page 1

                                                       ;Init boutons avant affichage

XmeToolbarCheckButton (Id_toolbar,"OPTION_1",TRUE)

                                                       ;OPTION_1 coché au départ

                                                       ;OPTION_2 non coché

 

XmeDisp ("MASQUE",1,XME_MODE_GOTO)                     ;affichage page 1 & outils

...

 

Fini = FALSE                                           ;consultation tableau

Do

   XmeListConsult (Id_tableau) 

   Switch Harmony.Key 

      Case K_ESCAPE                                    ;abandon 

         Fini = TRUE

 

      Case Harmony.DataArret = 101                     ;arrêt <-> bouton OPTION_1 

         XmeToolbarCheckButton (Id_toolbar,"OPTION_1", \ 

            not XmeToolbarIsButtonChecked (Id_toolbar,"OPTION_1")) 

         ...

 

      Case Harmony.DataArret = 102                     ;arrêt <-> bouton OPTION_2 

         XmeToolbarCheckButton (Id_toolbar,"OPTION_2", \ 

            not XmeToolbarIsButtonChecked (Id_toolbar,"OPTION_2")) 

         ... 

 

      Case ... 

 

      Default 

         XmeListConsultDefault (Id_tableau,Ligne,Scrollbar32) 

   EndSwitch 

While not Fini

Wend
