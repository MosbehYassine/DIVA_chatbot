XmeGanttDisplay  Famille Thème

Affichage des données d'un Gantt

 

XmeGanttDisplay (&Identifiant)

 

Paramètre :
 

Identifiant

Enregistrement identifiant le Gantt rendu par la fonction XmeGanttGetId.

 

Description de la procédure :

  • La procédure XmeGanttDisplay affiche les données du Gantt dont l'identifiant est fourni en paramètre (en se limitant à la partie présente à l'écran).

  • XmeGanttDisplay NE peut être appelée QUE si la page de masque contenant le Gantt est la page courante (ou l'une de ses pages panels). Les fonctions d'affichage de la page (XmeDisp, XmeDispv, etc.) affichent le cadre du Gantt mais pas ses données.

 

Remarque :

L'affichage des données du Gantt est optimisé de telle manière que seuls les valeurs modifiées sont actualisées à l'écran. En conséquence, il n'existe pas de fonction permettant d'afficher un élément isolé du Gantt.

 

Exemple :
 

Module  "yGantt.dhop"
Include "zGantt.dhsp"

Public  Record ddGantt.dhsd IdGntt IdGantt

...

 

MAIN

...

XmeLoad ("masque")                             ;chargement du masque

XmeInfoPage ("masque",1)                       ;récupération de la taille de la page

XmeSetWindowSize ("masque",1,Harmony.Opara3,Harmony.Opara4)

                                               ;--> taille initiale de la fenêtre Harmony

IdGantt = XmeGanttGetId ("masque",1,"GANTT")   ;initialisation Gantt

...

XmeDispv ("masque",1,XME_MODE_GOTO)            ;affiche la page contenant le Gantt

...

XmeGanttDisplay (IdGantt)                      ;affiche les données du Gantt
