Ressources

 

Des ressources, telles que des personnes, des salles, des matériels, peuvent être affectées aux rendez-vous. Chaque ressource comporte :

  • Un Type de ressource.

  • Une couleur (nom de couleur dans la feuille de styles).
    A défaut, la couleur sera celle définie au niveau du type de ressource.

  • Une image (nom d'image dans la feuille de styles ou nom d'un fichier image : .bmp, .png, ...).
    A défaut, l'image sera celle définie au niveau du type de ressource.

  • Un libellé.

Pour créer une ressource, faites appel à la fonction XmeCalendarNewResource.

Pour associer une ressource à un rendez-vous, utilisez la fonction XmeCalendarAddAssociateResource.

L'enregistrement descriptif d'une ressource dans le dictionnaire ddCalendar.dhsd est ObjectResource.

 

 

Exemple de ressource :

La ressource de type Personne PERSONNE_1 peut être définie ainsi :

Type de ressource : CAL_MANPOWER

Couleur : BLEU

Image : AGENDA_PERSONNE ou PierreDupont.png

Libellé : Pierre Dupont
