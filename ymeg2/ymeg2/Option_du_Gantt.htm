Options du Gantt

 

L’objet Gantt propose un certain nombre d’options.

 

Pour positionner UNE option, il faut :

  • Utiliser une instance de l’enregistrement ObjectOption du dictionnaire ddGantt.dhsd.

  • Préciser l’option choisie dans le champ ObjectOption.Option.

  • Affecter sa valeur dans le champ ObjectOption.Value.
    Remarque : ce champ est de type alphanumérique ; si vous lui affectez une variable binaire (nature B, X ou L), prenez soin de la convertir en alpha par la fonction ToString ; réciproquement, utilisez la fonction Val pour transférer une option dans une variable binaire.

  • Ajouter l’option à l’agenda avec la fonction XmeGanttSetOption.

Si vous désirez positionner plusieurs options, répétez cette opération pour chacune d'elles.

 

Les identifiants des options, ainsi que les valeurs possibles de certaines options, sont des "Define" Diva définis dans le fichier "Include" zGantt.dhsp.

Exemples :
 

Public Record ddGantt.dhsd ObjectOption Opt

 

;Définition de la plage à afficher :

Opt.Option   = GANTT_OPT_VISIBLE_RANGE_START

Opt.OptValue = DhAddSeconds(time(1) & "000000", -(3600*24))          ; début de la plage (hier)

XmeGanttSetOption (IdGantt,Opt)

Opt.Option   = GANTT_OPT_VISIBLE_RANGE_End

Opt.OptValue = DhAddSeconds(time(1) & "000000", 3600*24*31)          ; fin de la plage (+31 jours)

XmeGanttSetOption (IdGantt,Opt)

 

 

;Définition du formatage du timeruler :

Opt.Option   = GANTT_OPT_TIMERULER_GROUP           

Opt.OptValue = GANTT_TIMERULER_1_WEEK                         

XmeGanttSetOption (IdGantt,Opt)
Opt.Option   = GANTT_OPT_TIMERULER_GROUP_FORMAT            

Opt.OptValue = "{0:dd/MM/yyyy}"                            

XmeGanttSetOption (IdGantt,Opt)

 

 

 

Extraire les valeurs unitaires d'une option à valeurs combinées

Ce paragraphe concerne l'option GANTT_OPT_ACCESS_RIGHTS dont la valeur peut être une combinaison de plusieurs valeurs unitaires toutes égales à une puissance de 2.

La fonction XmeGanttGetBinaryMaskValues permet de retrouver les valeurs unitaires à partir de la valeur combinée de l'option. Par exemple, si on lui passe en paramètre la valeur 7, elle retourne :

<value>4<value>2<value>1

ce qui permet de retrouver les différentes valeurs qui ont été combinées.
