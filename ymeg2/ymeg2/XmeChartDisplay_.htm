XmeChartDisplay  Famille Thème

Affichage d'un graphique

 

XmeChartDisplay (&IdChart)

 

Paramètre :
 

IdChart

Enregistrement identifiant le graphique, rendu par la fonction XmeChartGetId.

 

Description de la procédure :

  • La procédure XmeCchartDisplay affiche les données du graphique dont l'identifiant est fourni en paramètre (en se limitant à la partie présente à l'écran).

  • XmeChartDisplay NE peut être appelée QUE si la page de masque contenant l'agenda est la page courante (ou l'une de ses pages panels). Les fonctions d'affichage de la page (XmeDisp, XmeDispv, etc.) affichent le cadre du graphe mais pas ses données.

 

Exemple :
 

module ychart.dhop

include zchart.dhsp

 

...

record ddsys.dhsd IdChart chartId                

...

XmeLoad ("masque")                               ;chargement du masque

chartId = XmeChartGetId(masque, 1, "PieChart")   ;initialisation du graphique nommé PieChart

                                                 ;et situé dans la page 1 du masque

...

XmeDispv ("masque",1,XME_MODE_GOTO)              ;affiche la page contenant le graphe.

...

XmeChartDisplay (chartId )                          ;affiche les données du graphe.
