XmeCalendarSetRecurrence  Famille Thème

Positionnement d'une règle de récurrence sur un rendez-vous d'un agenda

 

Long XmeCalendarSetRecurrence (Identifiant, Rendez_vous, [Fréquence], [Intervalle], [Masque_des_jours], [Jour_ordinal], [Jour_du_mois], [Mois_de_l_année], [Nbmax_occurrences], [Fin_récurrence])

 

Paramètres :
 

Identifiant

Enregistrement identifiant l'agenda rendu par la fonction XmeCalendarGetId.

Rendez_vous

Identifiant du rendez-vous retourné par la fonction XmeCalendarNewAppointment.

Fréquence

Fréquence de récurrence :

  • CAL_RECURRENCE_NONE : pas de récurrence (valeur par défaut).

  • CAL_RECURRENCE_DAILY : journalière.
    Dans ce cas, la fonction force les valeurs suivantes :

    • Jour_ordinal = 0.

    • Jour_du_mois = 0.

    • Mois_de_l_année = 0.

De plus, si on spécifie un Masque de jours, alors Intervalle doit valoir 1.
Sinon, Masque de jours doit valoir CAL_MASK_NONE.

  • CAL_RECURRENCE_WEEKLY : hebdomadaire.
    Dans ce cas, la fonction force les valeurs suivantes :

    • Jour_ordinal = 0.

    • Jour_du_mois = 0.

    • Mois_de_l_année = 0.

Spécifiez un Masque de jours pour indiquer le(s) jour(s) de la semaine concerné(s).

  • CAL_RECURRENCE_MONTHLY : mensuelle.
    Dans ce cas, la fonction force les valeurs suivantes :

    • Mois_de_l_année = 0.

    • Si Jour_du_mois est non nul :
      Jour_ordinal       = 0.
      Masque de jours       = CAL_MASK_NONE.
       

  • CAL_RECURRENCE_YEARLY : annuelle.
    Dans ce cas, la fonction force les valeurs suivantes :

    • Intervalle = 1.

    • Si Jour_du_mois est non nul :
      Jour_ordinal       = 0.
      Masque de jours       = CAL_MASK_NONE.

Intervalle

Intervalle entre deux occurrences (selon la fréquence indiquée précédemment ; 1 par défaut).
Permet par exemple de spécifier qu'un rendez-vous a lieu tous les n jours, semaines ou mois.

Masque_des_jours

Masque (*) des jours de la semaine :

  • CAL_MASK_NONE : aucun.

  • CAL_MASK_SUNDAY, CAL_MASK_MONDAY, CAL_MASK_TUESDAY, CAL_MASK_WEDNESDAY, CAL_MASK_THURSDAY, CAL_MASK_FRIDAY, CAL_MASK_SATURDAY : dimanche, lundi, ...

  • CAL_MASK_WEEKDAYS : tous les jours sauf samedi et dimanche.

  • CAL_MASK_WEEKENDDAYS : samedi et dimanche.

  • CAL_MASK_EVERYDAY : tous les jours (valeur par défaut).

(*) Vous pouvez additionner plusieurs valeurs (ou utiliser la fonction BOR) pour les combiner.

Voir aussi la fonction XmeCalendarGetBinaryMaskValues.

Jour_ordinal

Jour ordinal ou 0 (valeur par défaut) :

  • CAL_FIRST : première occurrence du jour de la semaine dans le mois.

  • CAL_SECOND : 2ème occurrence du jour de la semaine dans le mois.

  • CAL_THIRD : 3ème occurrence du jour de la semaine dans le mois.

  • CAL_FOURTH : 4ème occurrence du jour de la semaine dans le mois.

  • CAL_LAST = dernière occurrence du jour de la semaine dans le mois.

Permet par exemple de spécifier qu'un rendez-vous a lieu tous les 3ème jeudi du mois ou tous les derniers jeudi de Juillet.

Spécifiez un Masque de jours pour indiquer le jour de la semaine concerné.

Jour_du_mois

Numéro du jour dans le mois ou 0 (valeur par défaut).

Mois_de_l_année

Numéro du mois dans l’année ou 0 (valeur par défaut).

Nbmax_occurrences

Nombre maximal d’occurrences ou 0 (valeur par défaut).

Fin_récurrence

Date de fin de la récurrence (exclue) ou espace (valeur par défaut).

 

Valeur rendue par la fonction :

-1 : ticket invalide ou courant erroné.

Autre : Adresse du rendez-vous dans la liste des rendez-vous.

 

Description de la fonction :

  • La fonction XmeCalendarSetRecurrence positionne une règle de récurrence sur le rendez-vous spécifié en paramètre.

  • Pour plus de renseignements sur la récurrence, consultez l’exemple de programmation d’agenda fourni  dans le dossier /Divalto/Exemples/Agenda. Le masque Calendar.dhsf contient en particulier une fenêtre à onglets (intitulée "Propriétés de la récurrence") qui  montrent les options disponibles pour les récurrences journalières, hebdomadaires, mensuelles et annuelles. Vous pouvez vous en inspirer pour proposer votre propre paramétrage des récurrences.
    N. B. : Les pages de masque de l’exemple contiennent des multi-choix dont les valeurs font l’objet d’un "Define" dans zCalendar.dhsp.

  • Les informations concernant la récurrence sont stockées dans l’enregistrement "rendez-vous" ObjectAppointment.

  • Attention (en particulier si vous modifiez les paramètres de récurrence directement dans cet enregistrement) : Soyez très attentif à la cohérence des informations fournies. Des paramètres erronés ou incompatibles peuvent provoquer des dysfonctionnements, voire un "bouclage" ou un "plantage" du composant Agenda.

 

Exemples :
 

XmeCalendarSetRecurrence (IdCal,IdRv, ...

... CAL_RECURRENCE_DAILY,,CAL_MASK_MONDAY)                      ;tous les lundi

... CAL_RECURRENCE_DAILY,2)                                     ;tous les 2 jours

... CAL_RECURRENCE_WEEKLY,2,CAL_MASK_TUESDAY+CAL_MASK_THURSDAY) ;toutes les 2 semaines, Mardi et Jeudi

... CAL_RECURRENCE_MONTHLY,,CAL_MASK_THURSDAY,CAL_THIRD)        ;tous les 3ème Jeudi du mois

... CAL_RECURRENCE_YEARLY,,CAL_MASK_THURSDAY,CAL_LAST,,7)       ;tous les derniers Jeudi de Juillet

... CAL_RECURRENCE_MONTHLY,,,,4,,6)                             ;tous les 4 du mois pendant 6 mois

... CAL_RECURRENCE_MONTHLY,,,,10,,,"20131231")                  ;tous les 10 du mois jusqu'à fin 2013
