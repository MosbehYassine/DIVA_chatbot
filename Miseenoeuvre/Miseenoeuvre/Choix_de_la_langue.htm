Choix de la langue

Par défaut, Harmony utilise le code langue défini au niveau de l'utilisateur Windows. Ce code langue est positionné par le choix <Options régionales et linguistiques> du Panneau de configuration. Vous avez la possibilité de sélectionner une autre langue en procédant de la manière suivante :

  • Cliquez avec le bouton droit de la souris sur l'icône Divalto dans la zone de notification (à droite de la barre des tâches de Windows).

  • Dans le sous-menu Langues affichage, sélectionnez le code langue désiré.

 

Par défaut, la langue utilisée pour les états imprimés est la même que celle utilisée pour les affichages. Vous avez la possibilité de sélectionner une autre langue d'impression en procédant de la manière suivante :

  • Cliquez avec le bouton droit de la souris sur l'icône Divalto dans la zone de notification.

  • Dans le sous-menu Langues impression, sélectionnez le code langue désiré.

  • Remarque : certaines applications Harmony proposent aussi de sélectionner une langue d'impression, ce qui vous permet d'imprimer un document particulier dans la langue d'un destinataire étranger, tout en conservant votre propre langue d'impression au niveau de la zone de notification.

 

Remarque :

Le choix Langue d'origine demande que les écrans ou les états Harmony soient affichés ou imprimés dans la langue avec laquelle ils ont été conçus (et donc sans traduction).

 

 

Attention / Restriction :

  • Le changement de langue n'affecte pas les programmes en cours d'exécution. Pour que le changement soit effectif, refermez et relancez vos applications Harmony.

  • La fonctionnalité "multi-langues" nécessite un paramétrage spécifique d'Harmony : voir la rubrique Paramétrage du livre consacré à la traduction des applications.

  • La possibilité d'imprimer avec un code langue différent du code langue utilisé pour les affichages NE concerne PAS les impressions paramétrables des zooms.
