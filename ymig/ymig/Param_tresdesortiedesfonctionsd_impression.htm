Paramètres de sortie des fonctions d'impression

Après l'impression d'un bloc ou suite à un point d'arrêt, le contrôle est rendu au programme appelant. Celui-ci a accès à un certain nombre d'informations, fournies par Ymig et récapitulées dans le tableau suivant :
 

Harmony.Iarret

Numéro du point d'arrêt courant, si la sortie a été provoquée par un point d'arrêt.

System.Zpage

Numéro de page courante.

System.Zligne

Numéro de ligne dans la page (*).



(*) Attention, la variable System.Zligne est actualisée en fin de bloc (**) et non ligne par ligne :

  • Le programme peut donc tester System.Zligne pour, par exemple, connaître le nombre de lignes encore disponibles dans la page.

  • System.Zligne peut être imprimée dans une ligne détail.

  • Mais System.Zligne ne peut être imprimée sur chaque ligne d'un bloc comprenant plusieurs lignes (le même numéro sera édité sur toutes les lignes du bloc).
     

(**) Cas d'un bloc contenant un objet Tableau :

Après l'impression d'un bloc contenant un tableau, Ymig laisse le numéro de ligne courant inchangé. Le numéro délivré n’est donc pas encore actualisé.
Ensuite :

  • Après l’impression d’un bloc inclus dans le tableau, Ymig incrémente normalement le numéro de ligne courant de la taille du bloc Tableau.

  • Si l'impression d'un bloc ne faisant plus partie du tableau est demandée, Ymig positionne au préalable le numéro de ligne courant derrière la fin du bloc contenant le tableau.
