XmiAllowExport  Famille Thème

Autorisation ou interdiction d'export tableur

 

XmiAllowExport (Drapeau)

 

Paramètre :

Drapeau
 

  • FALSE :
    L'état produit ne pourra pas faire l'objet d'un export tableur.
     

  • TRUE :
    L'état produit pourra faire l'objet d'un export tableur, sous réserve que l'option "Générer les données pour l'export tableur" soit valide dans DivaltoViewer.

 

Description de la fonction :

Cette procédure permet d'interdire ou ré-autoriser l'export de l'état imprimé vers un tableur.
Par défaut, l'export tableur est autorisé. L'export tableur est une fonction proposée par l'utilitaire DivaltoViewer.

 

Exemple :
 

XmiAllowExport (FALSE)               ;interdire l'export tableur
