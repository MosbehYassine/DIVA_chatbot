Saut de page (masques Xwin caractères)

Cette rubrique concerne uniquement les impressions de masques caractères.

Il existe deux méthodes pour commander un saut de page à l'imprimante :

  • Lui envoyer un ordre de saut de page (caractère $0C).
    Cette méthode est obligatoire pour les imprimantes de type " feuille à feuille ", telles les imprimantes laser. En effet, tant que l'ordre de saut n'a pas été reçu, l'imprimante n'éjecte pas la feuille.
    Cette méthode fonctionne également pour une imprimante à alimentation " en continu ", à condition qu'elle reconnaisse le format du papier utilisé.

  • Lui envoyer (au besoin) une série de sauts de ligne.
    Cette méthode permet d'employer un format de papier non reconnu par l'imprimante. Si, par exemple, vous voulez utiliser du papier pré-imprimé comportant 64 lignes par page, avec une imprimante qui reconnaît uniquement un format de 66 lignes par page (format le plus courant), il faudra utiliser cette deuxième méthode.

 

Avant d'appeler Ymig pour exécuter un masque, il faut charger la donnée Harmony.Ihauteur en fonction du mode de saut de page souhaité :

Harmony.Ihauteur = 0

Saut de page par $0C.

Harmony.Ihauteur = hauteur de page

Saut de page par sauts de ligne.

 

Le garnissage de cette donnée N'est PAS impératif, dans la mesure où elle est toujours initialisée au lancement du programme :

  • Suivant la valeur du paramètre " Saut de page standard " du modèle d'imprimante, si un modèle a été sélectionné :
     
    * OUI : saut de page par $0C.
     
    * NON : saut de page par sauts de ligne.
    Dans ce cas, le nombre de lignes par page indiqué dans le modèle est placé dans Harmony.Ihauteur ; toutefois, le nombre de lignes considéré par Ymig sera celui indiqué dans le masque si vous avez sélectionné l'option " Hauteur de Page : d'après le masque " dans les paramètres généraux du masque Xwin.
     
    Un modèle est chargé dès que l'utilisateur fait appel à un menu de type Divalto ; dans ce cas, votre programme ne doit normalement pas modifier Harmony.Ihauteur, sous peine de désactiver la gestion des modèles.

  • A la valeur 0 (saut par $0C), si aucun modèle n'est sélectionné.
