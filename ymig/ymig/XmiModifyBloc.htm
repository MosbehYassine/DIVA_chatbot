XmiModifyBloc  Famille Thème

Modification des caractéristiques d'un bloc

 

XmiModifyBloc (Nom du fichier masque, Numéro de bloc)

 

Paramètres :

Nom du fichier masque
(Harmony.Imasque)

Nom du fichier masque (fichier objet, 32 caractères maximum).
Le cas échéant, l'extension .dhoi doit être précisé.

Numéro de bloc
(Harmony.Ibloc)

Numéro de bloc.

Harmony.Opara1

Nombre de lignes du bloc.

Harmony.Opara2

Type du bloc (1=Fixe, 2=Mobile, 3=Fond, 4=Tableau).

Harmony.Opara3

Numéro de ligne début (*).

Harmony.Opara4

Numéro de ligne fin (*).

Harmony.Opara5

Numéro de bloc si débordement.

Harmony.Opara6

Numéro de bloc si chaînage.

Harmony.Opara7

Saut de page début (1=non, 2=oui).

Harmony.Opara8

Saut de page fin (1=non, 2=oui).

Harmony.Opara9

Numéro de point d'arrêt Avant.

Harmony.Opara12

Numéro de point d'arrêt Après.
 

(*) Harmony.Opara3 et Harmony.Opara4 peuvent prendre des valeurs négatives. Le codage utilisé est le suivant :

[ 1     .. 32767 ] : valeur positive

[ 32768 .. 65535 ] : valeur négative

                     avec 32768 <=> 0

                          65535 <=> -32767

Exemple : 32774 <=> 32768 - 32774 = -6.

 

Description de la fonction :

  • XmiModifyBloc permet de modifier dynamiquement les caractéristiques du bloc, identifié par un Nom de fichier masque et par un Numéro de bloc dans ce fichier.

  • Elle permet en particulier la désactivation partielle ou totale de l'impression d'un bloc (voir la rubrique "Désactivation de l'impression d'un bloc mobile" du livre consacré à l'éditeur de masque d'imprimante Xwin).

  • La procédure Diva XmiModifyBloc ne comporte que deux paramètres. Avant de l'appeler, vous devez charger TOUTES les variables Harmony.Oparai nommées dans le tableau ci-dessus.

  • Il est donc conseillé d'utiliser d'abord la fonction XmiInfoBloc, pour lire les caractéristiques du bloc saisies par Xwin (et ainsi initialiser les variables Harmony.Oparai), puis d'effectuer les modifications désirées avant d'appeler XmiModifyBloc.

 

Exemple :

...

XmiInfoBloc ("MASQUE.dhoi",4)   ;lecture préalable caractéristiques

                                ;bloc 3, fichier masque "MASQUE" 

 

Harmony.Opara1 = 0              ;modifications...

Harmony.Opara3 = 0              ;(ici, désactivation du bloc)

Harmony.Opara4 = 0

 

XmiModifyBloc ("MASQUE.dhoi",4) ;réécriture caractéristiques

...
