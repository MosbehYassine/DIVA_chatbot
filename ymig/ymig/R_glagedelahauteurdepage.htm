Réglage de la hauteur de page

Indépendamment de la taille physique de la feuille de papier, vous disposez de deux méthodes pour préciser le nombre de lignes que vous voulez faire figurer sur chaque page :

  1. Nombre de lignes paramétré dans le masque Xwin.
    Une première méthode consiste à figer le nombre de lignes par page en l'indiquant directement au niveau du masque : dans Xwin, sélectionnez le choix Masque du menu Paramètres pour ouvrir la boîte de dialogue "Masque d'impression" ; cochez le bouton radio d'après le masque du groupe Hauteur de page et renseignez le champ Nombre de lignes (ici, la valeur du paramètre Harmony.Inblignes ne sera pas prise en compte).
     

  2. Nombre de lignes paramétré par programme.
    Une deuxième méthode consiste à indiquer le nombre de lignes par page au niveau du programme appelant : dans Xwin, sélectionnez le choix Masque du menu Paramètres pour ouvrir la boîte de dialogue "Masque d'impression" et cochez le bouton radio d'après le modèle du groupe Hauteur de page (ici, le champ Nombre de lignes n'est plus significatif).
    La donnée Harmony.Inblignes doit alors contenir le nombre de lignes par page désiré, avant de commencer l'impression du masque. Le garnissage de cette donnée N'est PAS impératif, dans la mesure où elle est toujours initialisée au lancement du programme. On distinguera deux cas :
     
    a) Vous tenez compte du modèle d'imprimante sélectionné par l'utilisateur (la notion standard de modèle d'imprimante est définie dans le manuel de référence d'Harmony ; rappelons également qu'un modèle est chargé dès que l'utilisateur fait appel à un menu de type Divalto).
    Harmony.Inblignes est correctement initialisée avec le nombre de lignes par page paramétré dans le modèle. Laissez donc sa valeur inchangée.
     
    b) Vous ne tenez pas compte du modèle d'imprimante.
    Si aucun modèle n'est chargé, Harmony.Inblignes est initialisée par défaut à 66. Si cette valeur ne convient pas, modifiez-la dans votre programme.
