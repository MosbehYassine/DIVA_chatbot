Impression d'un état à l'écran

L'utilitaire DivaltoViewer permet la visualisation à l'écran des états imprimés (Cf. manuel de référence d'Harmony). C'est normalement l'utilisateur qui choisit le périphérique d'édition mais ce choix peut aussi être fait par programme :

  • Sortie sur imprimante.
    Pour forcer la sortie de l'état sur l'imprimante, programmez l'instruction :

cr = CM (1330,44,0)       ;cr = status (type X)

  • Sortie sur écran.
    Pour forcer la sortie de l'état sur l'écran, programmez l'instruction :

cr = CM (1330,44,1)

  • Lecture du périphérique de sortie courant.
    Pour connaître le périphérique de sortie courant, programmez l'instruction :

cr = CM (1330,44,2)       ;résultat :

                          ;cr=0 <=> imprimante

                          ;cr=1 <=> écran
