PtrRecordSqlFreeInstance  Famille  Thème

 

La fonction PtrRecordSqlFreeInstance permet de libérer une instance de RecordSql créée par DuplicateInstance

   

Bool PtrRecordSqlFreeInstance (PtrRecord)

   

Paramètres

PtrRecord

Donnée de type RecordSqlPtr pointant vers le RecordSql créé par DuplicateInstance.

   

Retour

TRUE

Pas d'erreur

FALSE

PtrRecord ne pointe pas vers une instance créée par DuplicateInstance.
   
 
 Remarques
  • Les instances allouées par DuplicateInstance doivent être implicitement libérées par PtrRecordSqlFreeInstance
  • En fin de programme, toutes les instances sont automatiquement libérées.

Exemple

RecordSql gtrsart.dhoq article articlepp

RecordSqlPtr ptart

 

articlepp.DuplicateInstance(ptart)

ptart.Select()

PtrRecordSqlFreeInstance(ptart)
