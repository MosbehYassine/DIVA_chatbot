RecordSql.UpdateValues  Famille  Thème

 

Exécute une mise à jour avec les valeurs définies via la fonction RecordSql.AddUpdateValue

 

Long RecordSql.UpdateValues ( )

 

Retour

1

Pas d'erreur

Toutes les erreurs provoquent l'arrêt du programme

 

Remarques :

  • Si des clauses Where ont été spécifiées, elle seront appliquées

  • La condition commune est toujours appliquée

 

Exemple :

 

instance.AddUpdateValue("DOS = DOS + 1")

instance.UpdateValues()
