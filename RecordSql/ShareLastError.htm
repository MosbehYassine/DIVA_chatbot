RecordSql.ShareLastError   Famille  Thème

 

Ptr = RecordSql.ShareLastError ( &résultat)

 

Paramètre

Résultat

Variable de type alpha ou string recevant une chaîne Hmp indiquant la tâche qui réserve l'entité. Si l'entité est partagée par plusieurs tâches, la chaîne contient la liste des tâches qui partagent l'entité.

La chaîne Hmp contient les paramètres suivants :

Si l'entité est réservée :

<Reserved>

Etat de l'entité. (R = réservé, F = forcé). Si ce paramètre est absent, cela signifie que l'entité est partagée.

<Task>

Numéro de tâche qui réserve l'entité.

<Host>

Nom de l'ordinateur qui réserve l'entité

<User>

Nom de l'utilisateur qui réserve l'entité

 

 

Si l'entité est partagée, pour chaque tâche partageant l'entité :

<Share>

Numéro de tâche qui partage l'entité

<Host>

Nom de l'ordinateur qui partage l'entité

<User>

Nom de l'utilisateur qui partage l'entité

 

Retour

0

Pas d’erreur

Autre

Code d’erreur système.
