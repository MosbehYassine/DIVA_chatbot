OverWrite - OverWrittenBy

 

La balise <DictionarySql> contient deux paramètres qui indiquent si le dictionnaire est une surcharge et si le dictionnaire est surchargé. Comme la surcharge peut être à plusieurs niveaux, les deux paramètres peuvent être simultanément présents.

Voir DictionarySql

 

Convention de nommage

La convention est d’ajouter un u à la fin du nom du dictionnaire d’origine. Ainsi, si la règle est respectée, le nombre de u à la fin du nom indique le niveau de la surcharge.

Exemple

Le dictionnaire gtrsart.dhsq est surchargé par le dictionnaire gtrsartu.dhsq, pouvant lui-même être surchargé par gtrsartuu.dhsq, et ainsi de suite.

 

OverwrittenBy

Pour être surchargeable, le dictionnaire doit contenir l’attribut OverwrittenBy dans la balise <DictionarySQL>.

Exemple

<DictionarySql … DataBase=DAV overwrittenby="gtrsartu.dhoq">

Le dictionnaire de surcharge doit être compilé pour produire un objet du dictionnaire de surcharge (extension .dhoq). A l’exécution, la présence du dictionnaire de surcharge est facultative.

 

Overwrite

Pour indiquer qu’un dictionnaire de recordSql est une surcharge, on ajoute l’attribut Overwrite dans la balise <DictionarySQL> du dictionnaire de surcharge.

Exemple

<DictionarySQL  …  overwrite="gtrsart.dhoq">

 

Si le dictionnaire de surcharge doit lui-même pouvoir être surchargé, on ajoutera l’attribut OverwrittenBy dans la balise <DictionarySQL> du dictionnaire de surcharge.

Exemple

<DictionarySQL  …  overwrite="gtrsart.dhoq" overwritenby="gtrsartuu.dhoq" >
