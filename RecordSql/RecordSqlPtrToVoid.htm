RecordSqlPtrToVoid  Famille  Thème

L'instruction RecordSqlPtrToVoid permet de copier un pointeur de RecordSql dans une zone alpha. Cela permet par exemple de mettre un pointeur de recordSql dans un élément de liste.

Ensuite, l'instruction RecordSqlPtrFromVoid permet de replacer cette valeur dans un pointeur de recordSql.

    

RecordSqlPtrToVoid  (RecordSqlPtr, VoidPtr)

    

Paramètres

RecordSqlPtr

Donnée de type RecordSqlPtr.

VoidPtr

Donnée de alpha (taille=50) qui reçoit le résultat.

 

Exemple

 

public record a5dd.dhsd mz

1 st L

 

structure ElementListe

   1 ptArtVoid 50

endStructure

 

RecordDiva ElementListe

1 liste L = ListCreate()

 

recordSqlPtr ptart

recordSqlPtr ptart2

 

main

 

; allocation d'un recordSql

mz.Dos = "998"

st = PtrRecordSqlNew ("gtrsart.dhoq","article",ptart)

if (st <> 0)

   messageBox(GetRecordSqlErrorMessage()," ")

endif

ptart.Select()

 

; place le pointeur dans une liste

RecordSqlPtrToVoid(ptart,ElementListe.ptartVoid)

listAddEnd(liste,elementListe)

........................................

; récupère le pointeur de la liste

ListFirst(liste,ElementListe)

RecordSqlPtrFromVoid(ptart2,elementListe.ptArtVoid)

ptart2.Select()

ProgramExit
