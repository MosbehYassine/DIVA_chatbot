Utilisation dans les RecordSql

 

Dans le RecordSQL, le mot clé Using permet de chercher l’expression de la jointure dans un dictionnaire de jointures.

Il remplace dans ce cas le mot clé ON qui précédait l’expression de la jointure dans les sections <xxxJoin>.

 

<xxxJoin [Database="nom"] [ GlobalConf={ yes | no } ] [ Name="nom" ] [ Dependencies="nom" ] [ ColumnNames="nom" ] [ NoActivate ]>

[ DictionaryName ] table [ as uniqueAlias ]

{ ON conditionDeJointure | USING NomDeJointure[(p1 [,pn])] }

 

La jointure est cherchée dans le dictionnaire de jointures dont le nom est DictionaryName (ou DefaultDictionary défini dans la balise <DictionarySql>) avec l'extension .dhsj.

 

Exemple :

 

<LEFTJOIN>

ART as ArticleRemplacement

ON ArticleRemplacement.Dos = ART.Dos AND ArticleRemplacement.Ref = ART.RefRpl

 

Devient

 

<LEFTJOIN>

ART as ArticleRemplacement

USING ArticleRemplacement
