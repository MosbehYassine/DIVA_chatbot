RecordSql.Where.UseClause   Famille  Thème

RecordSql.Having.UseClause

RecordSql.OrderBy.UseClause

 

La méthode UseClause permet d'invoquer un critère de sélection ou de tri par son nom. Cette méthode est essentiellement utilisée par le Zoom.

 

RecordSql.Where.UseClause ( Nom  [, paramètres ] )

RecordSql.Having.UseClause ( Nom  [, paramètres ] )

RecordSql.OrderBy.UseClause ( Nom )

 

Paramètres

Nom

Nom du critère (de la fonction) à invoquer.

 

Paramètres

Liste des paramètres attendus par le critère invoqué. Attention, le nombre et le type des paramètres ne peut être vérifié à la compilation.

 

Retour

1

Pas d'erreur
  Toutes les erreurs provoquent l'arrêt du programme
