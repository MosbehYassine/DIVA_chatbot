RecordSql.Column.Activate   Famille  Thème

 

La méthode Column.Activate permet d'activer certains champs.

 

Long RecordSql.Column.Activate ( noms )

 

Paramètre

noms

Chaîne contenant les noms de champs à activer. Les différents noms doivent être séparés par le caractère ; (point-virgule).

 

Retour

1

Pas d'erreur

Toutes les erreurs provoquent l'arrêt du programme

 

Mot joker

Il existe un joker :

  • "$ALL" : permet d'activer tous les champs

 

Les noms des champs à activer peuvent être de la forme :

  • Table.Champ si la table n'a pas d'alias

  • AliasTable.Champ si table possède un alias

  • AliasChamp

Il existe également la possibilité d'écrire Table.$ALL ou AliasTable.$ALL pour activer l'ensemble des champs de cette table.

 

Remarque :

  • Par défaut, tous les champs sont activés, à l'exception de ceux marqués "NoActivate".

  • L'activation d'une case d'un champ tableau entraîne l'activation de toutes les cases du champ.
