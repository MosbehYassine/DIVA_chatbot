RecordSql.GetOption   Famille  Thème

 

La méthode GetOption permet de récupérer la valeur d'une option de l'instance courante du RecordSql.

 

Long RecordSql.GetOption ( Option, &Valeur )

 

Paramètres

Option

Identifiant de l'option

  Valeur

Valeur de l'option (type L)

 

Retour

1

Pas d'erreur

0

Erreur (option inexistante par exemple)
 
 

Les options disponibles sont :

 

RSQL_IGNORE_FROM_CONF

Ignore la confidentialité sur la table de base.
 

RSQL_IGNORE_JOIN_CONF

Ignore les confidentialités de toutes les jointures.
 

RSQL_IGNORE_HERITAGE_JOIN_CONF

Si une jointure est marqué "GlobalConf" et qu'elle est confidentielle, seul les champs de la table de base sont rendus.
 

RSQL_FROM_ONLY

Exécute la requête avec uniquement les champs de la table de base.

Aucune jointure n'est exécutée.

Attention : les champs calculés, même s'ils viennent de la table de base, ne sont pas inclus dans ce select.
 

RSQL_NO_EXPRESSION

Permet de ne pas sélectionner les champs calculés.
 

RSQL_OPTION_FAST

Permet de ne pas utiliser l'option "OPTION(FAST 1)" de SQL Server.
 
 

RSQL_SET_MODE_ZOOM
 

  

Permet de passer le RecordSql en mode Zoom (usage interne du Zoom uniquement).
