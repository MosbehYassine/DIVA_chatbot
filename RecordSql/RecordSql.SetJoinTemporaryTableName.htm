SetJoinTemporaryTableName   Famille  Thème

 

Cette méthode permet d'assigner à une jointure une table temporaire précédemment créée.

 

Long RecordSql.SetJoinTemporayTableName ( JoinName, tableName )

 

Paramètre

JoinName

Nom de la jointure.

tableName

Nom de table temporaire.

 

 

  Exemple

TmpRecordSql dico.dhoq Article art_tmp

TmpRecordSql dico.dhoq Fournisseur fou_tmp

 

1 Nom S

nom = fou_tmp.GetTemporaryTableName()

art_tmp.SetJoinTemporaryTableName( 'FournisseurHabituel', nom ) 

 

art_tmp.Select()   ; la jointure vers fou se fera sur la table temporaire
