Fichier source - fichier objet

Un dictionnaire de RecordSQL est un fichier texte, d'extension .dhsq et contenant la description de plusieurs RecordSQL. Il se saisit avec l'éditeur de textes de Xwin.

Les dictionnaires de RecordSql doivent être placés dans les projets de Xwin et compilés comme tous les autres sources. L'extension d'un dictionnaire objet est .dhoq.
