RecordSql.Join.Activate   Famille  Thème

 

La méthode Join.Activate permet d'activer certaines jointures.

 

Long RecordSql.Join.Activate ( noms )

 

Paramètre

noms

Chaîne contenant les noms de jointures à activer. Les différents noms doivent être séparés par le caractère ; (point-virgule).

 

Retour

1

Pas d'erreur

Toutes les erreurs provoquent l'arrêt du programme

 

Mots joker

Il existe deux jokers :

  • "$ALL" : permet d'activer toutes les jointures

  • "$OVERWRITED" : permet d'activer toutes les jointures issues de surcharges. Cette option est particulièrement utile pour les distributeurs afin qu'ils puissent activer/désactiver leurs propres jointures d'un coup.

 

Remarque : Par défaut, toutes les jointures sont activées, sauf celles marquées "NoActivate".
