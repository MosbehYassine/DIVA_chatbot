RecordSql.Select   Famille  Thème

 

La méthode Select exécute la requête et renvoie la première ligne de résultat.

 

Long RecordSql.Select ()

 
 

Retour

0

La requête n'a pas retourné de ligne

1

Pas d'erreur

Toutes les autres erreurs provoquent l'arrêt du programme

 
 

Exemple

Public RecordSql 'GTRSTIERS.dhoq' CLIENT

Client.Where.Zoom_pk("C0000001")           ; positionnement du where

St = Client.Select()                       ; lecture
