SubQuery   Famille  Thème

 

L'objet RecordSQL permet de coder des sous-requêtes dans la section <SubQuery>. Cette section inclut toutes les sous-requêtes, chacune identifiée par un Case. Les sous-requêtes peuvent accepter des paramètres.

Les sous-requêtes peuvent être utilisées dans les sections <Select>, <Join> et <Where>.

 

L'appel d'une sous-requête s'effectue via le mot clé "SubQuery.NomDeLaSousRequête(paramètres)".

L'ancienne syntaxe est dépréciée (elle compile, mais ne dispose pas de l'aide à la saisie dans Xwin)  : "SubQuery(NomDeLaSousRequete, paramètres)".

 

Remarque :

Pour des raisons de compatibilité avec la base DB2, si l'on désire récupérer uniquement la première ligne, il faut utiliser les mots-clés "#TOP1" et "#FETCH1".

A l'exécution, ces deux jokers seront remplacés par le code SQL correspondant à la base de données cible.

#TOP1 doit être placé directement après le Select.

#FETCH1 doit être placé tout à la fin de la requête.

 

 

Exemple :

<RecordSql Name="exemple">

<Select>

Art.*

SubQuery.MaSousRequete as monChamp(10)

<From>

Art

<Where>

case MonWhere (char param1)

Art.Dos = SubQuery.MaSousRequete2(param1)

<SubQuery>

case MaSousRequete

Select Art.Dos From Art Where Art.Dos = 1

case MaSousRequete2 (char param1)

Select Art.Dos From Art Where Art.Dos = param1

case MaSousRequete3

                    Select #TOP1 Art.Dos From Art #FETCH1
