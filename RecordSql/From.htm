From   Famille  Thème

 

La balise From permet de déclarer la table principale de la requête.

Elle contient les attrbuts :

[DataBase=...]

Permet de changer le nom de l'implicite pour cette table.

[Insert=Yes/No]

Autorise (Yes) ou interdit (No) les insertions.

[Update=Yes/No]

Autorise (Yes) ou interdit (No) les modifications.

[Delete=Yes/No]

Autorise (Yes) ou interdit (No) les suppressions.

[ReadOnly]

Interdit toute modification.

 

La balise From contient le nom de la table du dictionnaire de données sous la forme :

[DictionaryName] table [as uniqueAlias]

  • DictionaryName est le nom du dictionnaire (s’il est différent du dictionnaire par défaut).

  • Table est le nom de la table dans le dictionnaire.

  • [as uniqueAlias] permet de définir un alias pour la table.

 

Remarques concernant les alias

Lorsqu’un nom de table est suivi d’un alias, celui-ci remplace le nom de la table.

Ceci est indispensable lorsqu’un RecordSQL utilise plusieurs instances d’une même table (on utilisera plutôt l’alias au niveau des tables jointes). Dans ce cas, lors de l’utilisation des champs en Diva ou dans les masques, le nom des champs est préfixé par l’alias suivi du caractère _ (underscore).

Dans l'exemple : <From>

     Cli as Client

On écrira :

Rec.Client_Tiers pour référencer le champ Tiers de la table Client de l’instance Rec du RecordSQL.

 

Remarque

Si, dans la balise Select, la déclaration du champ lui-même est suivie d’un alias (as uniqueName), celui-ci s’applique tel quel, sans ajout de préfixe.
