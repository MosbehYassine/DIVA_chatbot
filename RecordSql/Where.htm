Where   Famille  Thème

 

La balise Where permet de définir des critères de sélection. Elle ne comporte pas d’attributs.

 

<Where>

Critère commun

case ConditionName_1  [Commentaire] [Dependencies="T1;Alias2"]

condition ...

case ConditionName_2  [Commentaire] [Dependencies="T1;Alias2"]

condition ...

 

Chaque critère est identifié par un nom unique qui lui permet d'être sélectionné par le programme Diva.

Les critères peuvent comporter des paramètres. La condition est du code Sql et se doit de respecter la syntaxe de la clause WHERE de SQL.

 

Critère commun

La première condition suivant la balise <where> est un critère de sélection commun à tous les critères de sélection. Il s’applique donc dans tous les cas.

Exemple :

<WHERE>

CLI.Dos = 1

 

Les autres critères

Chaque autre critère est introduit par le mot clé Case et identifié par son ConditionName.

 

case [ public | private ] ConditionName [ ( { char | int | date | dh | charList | intList | dateList } paramName [ ,...n ] ) ]  [ Commentaire ] [ Dependencies="T1;Alias2" ]

           texte_de_la_condition

 

  • [ public | private ] s’appliquera à la surcharge de ce RecordSQL. 3 modes sont possibles :

Custom

Si la condition est également définie dans la surcharge, elle s’ajoute (par un ET logique) à la condition standard.
C’est le mode par défaut. Il n’y a pas de mot clé pour ce mode.

Public

Si la condition est également définie dans la surcharge, elle annule et remplace la condition standard.

Private

La condition standard ne peut pas être surchargée.

 

  • ConditionName est le nom de la condition. Le programme Diva choisit la condition à utiliser avec la méthode Where de l’instance du RecordSQL (voir le chapitre associé à la programmation des RecordSQL).

Exemple :

Rec.Where.MaCondition()

  • Commentaire : Ce libellé facultatif apparaît, dans le ZoomSQL, dans le multichoix permettant de sélectionner des critères de sélection prédéfinis.
     

  • Dependencies : Cet attribut permet d'indiquer la ou les jointures nécessaires à l'exécution de la condition. Son fonctionnement est le même que l'attribut Dependencies de la jointure.

 

Paramètres des conditions Where

Une condition Where peut comporter des paramètres qui seront transmis lors du choix de la condition. Ces paramètres sont typés :

Char

Alphanumérique

Int

Numérique

Date

Date

Dh

Date (avec vérification à la compilation que le type est respecté)

CharList

Identifiant d'une liste de valeurs de type alphanumérique

IntList

Identifiant d'une liste de valeurs de type numérique (sauf types B, X et L)

DateList

Identifiant d'une liste de valeurs de type date

 

Exemple 1 :

Case Zoom_ClientValide (date HsDt)

CLI.HsDt is Null Or CLI.HsDt > HsDt

 

En Diva, le choix de cette condition s'écrit :

Rec.Where.Zoom_ClientValide(dateSaisie)

 

 

Exemple 2 :

Case In_ListeReference(CharList ref)

art.ref in (ref)

 

En Diva :

1 idLst L = ListCreate

ListAddEnd(idLst, "ALB0001")

ListAddEnd(idLst, "ALB0002")

ListAddEnd(idLst, "ALB0003")

 

rec.Where.In_ListeReference(idLst)

 

 

Texte de la condition

Le texte de la condition se trouve sur les lignes qui suivent le Case (jusqu’au prochain case ou la prochaine balise).

Il doit respecter la syntaxe de la clause Where du langage SQL. Le compilateur de dictionnaire de RecordSQL ne fait aucun contrôle à cet égard.

Si le RecordSQL doit être portable vers différents moteurs de base de données, utiliser impérativement des expressions compatibles avec ces moteurs.

Les champs des enregistrements publics déclarés après la balise <RecordSql> peuvent être utilisés dans les critères de sélection.

Exemple :

<WHERE>

CLI.Dos = MZ.Dos

 

Quelques exemples :
 

CLI.NomAbr LIKE UPPER(nomAbr) Or UPPER(CLI.Nom) LIKE UPPER(nomAbr)

CLI.Tiers BETWEEN debut AND fin

CLI.Ce4 = 1 And CLI.Stat(1) LIKE Stat1

 

La condition Exists

Si l’on souhaite interdire la création de doublons dans une table par le Zoom, il faut créer une condition portant impérativement le nom Exists. Elle doit être invoquée dans la procédure ZoomApresCleCreation du Zoom.

Exemple :

Case Exists(char tiers)

     CLI.Tiers = tiers

 

Dans ZoomApresCleCreation :

Client.Where.Exists(Client.Tiers)
