RecordSql.AddExcept  Famille  Thème

 

AddUnion permet d'utiliser l'opération ensembliste EXCEPT.

Cela permet de retirer aux résultats de la première requête le résultat de la seconde.

 

Long RecordSql.AddExcept ( InstanceRecordSql )

 

Paramètres

InstanceRecordSql

Instance du RecordSql avec lequel l'instance courante va faire un Except

 

Retour

1

OK

 

Attention : tous les RecordSql concernés par l'ensemble doivent avoir le même nombre de colonnes et les types des colonnes doivent se correspondre.

Il appartient au développeur de s'assurer que c'est le cas.

 

 

Exemple :

 

RecordSql "recordsql.dhoq" monRecord monInstance

RecordSql "recordsql.dhoq" monRecord2 monInstance2

 

monInstance.AddExcept(monInstance2)

monInstance.Select()

 

Dans cet exemple, la requête sera :

 

PremièreRequête

EXCEPT

SecondRequête

 

 

Remarque : il est possible d'imbriquer les ensembles.

Exemple :

 

instance1.AddUnion(instance2)

instance2.AddExcept(instance3)

instance2.AddUnion(instance4)

instance4.AddIntersect(instance5)

 

instance1.Select()
