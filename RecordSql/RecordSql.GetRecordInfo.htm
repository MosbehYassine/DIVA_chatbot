RecordSql.GetRecordInfo   Famille  Thème

 

La méthode GetRecordInfo permet d'obtenir les caractéristiques de la table principale du RecordSql.

 

Long RecordSql.GetRecordInfo ( &Resultat )

 

Paramètre

Resultat

Variable structurée recevant les informations.

structure RecordSqlInfo

1 Adresse  L        ; adresse de la table principale

1 Filler   L

1 Taille   L        ; taille de la table principale

1 PosCe    L        ; non renseigné

1 ValCe    B        ; non renseigné

1 Dico    32        ; nom du dictionnaire de données

1 Mnemo   32        ; mnémonique

1 NomInstance 128   ; nom de l'instance (c'est le nom que porte la table principale du recordSql)

1 Libre 200

endStructure

 

 

Retour

0

Pas d'erreur

1

Erreur, pas d'informations retournées
