XRecordSQLCheck

 

L'utilitaire XRecordSQLCheck vérifie les dictionnaires de RecordSql en effectuant les opérations suivantes :

  • Contrôle de la syntaxe SQL des requêtes.

  • Vérification que les expressions de jointures utilisent des colonnes correspondant à un index de la table jointe (pour éviter que la base de données fasse des produits cartésiens de tables).
    Remarque : Cette vérification peut être invalidée pour une jointure donnée en lui affectant la propriété NoCheck.

 

Le lancement de cet outil est pilotable en ligne de commande. Les arguments de la ligne de commande sont :

 

-implicite : chemin complet vers le fichier des implicites.

-connexion : chemin complet vers le fichier des connexions.

-mode : "dico" ou "rep" pour lancer la vérification en mode "par dictionnaire" ou "par répertoire".

 

Si le mode choisi est "dico" :

-ficDico : chemin complet du dictionnaire de recordSQL.

-cheminSge : chemin du répertoire contenant les surcharges.

 

Si le mode choisi est "rep" :

-cheminRep : chemin complet du répertoire à vérifier.

-cheminSge : chemin du répertoire contenant les surcharges.

-filtre : filtre à appliquer (ex : gtrs*).

-exclusion : fichier spécifiant les exclusions. C'est un fichier .txt avec sur chaque ligne, soit un nom de fichier dictionnaire de recordSQL (avec l'extension .dhoq), soit un nom de recordSQL.

 

-option :

1 : Tout

2 : Erreurs

3 : Warning

 

-taille :

0 : Non

1 : Oui

 

-export : chemin complet du fichier qui contiendra le résultat de la vérification.

 

-requete : pour avoir dans la sortie le texte des requêtes en erreur

 

 

Exemple :

xrecordsqlcheck.exe -implicite "C:\divalto\ERP211\Fichiers\ImplicitesDemo.xml" -connexion "C:\divalto\ERP211\Fichiers\Connexions.xml" -mode Dico -ficDico "c:\divalto\erp211\objets\rsia.dhoq" -option 1 -export "c:\users\xgehl\desktop\log.txt" -requete 1

xrecordsqlcheck.exe -implicite "C:\divalto\ERP211\Fichiers\ImplicitesDemo.xml" -connexion "C:\divalto\ERP211\Fichiers\Connexions.xml" -mode rep -cheminrep "c:\divalto\erp211\objets" -option 1 -export "c:\users\xgehl\desktop\log.txt" -requete 1
