Paramétrage au lancement de la génération

 

Lorsque vous demandez la génération d'un zoom, le générateur ouvre un masque de saisie rappelant le dictionnaire, le fichier et la table concernés. Dans ce masque, vous pouvez modifier certains paramètres déjà saisis soit au niveau du projet, soit au niveau du dictionnaire de données. Ces paramètres ne sont pas re-détaillés ici : 

 

Style - Feuille

Nom de la feuille de styles.
 

Modèle de présentation

Nom du modèle de présentation dans cette feuille de styles.
 

Modèle - Masque

Fichier modèle pour le masque d'écran.
 

Modèle - Module

Fichier modèle pour le module de traitements.
 

Paramètres

Liste des paramètres (séparés par des points-virgules) de personnalisation des traitements du zoom.
 

Masque

Nom du masque d'écran (sans extension).
 

Module

Nom du module de traitements (sans extension).
 

Menu

Nom du menu.
 

Numéro

Numéro du zoom dans le menu.
 

Regroupement

Nom du regroupement dans le menu.
 

Application

Nom de l'application dans le menu.
 

 

 

Vous pouvez aussi garnir les paramètres complémentaires suivants :

 

Répertoire

Répertoire de stockage des fichiers générés.
 

Ajouter les Sources dans le projet actif

Cochez cette case pour que les sources générés soient automatiquement ajoutés à la liste des sources du sous-projet courant.
 

Taille des boîtes des champs par palier
 

Si vous décochez cette case, chaque champ en saisie aura sa propre taille de boîte (calculée en fonction de sa taille).
Sinon, le générateur affecte la même taille de boîte à des champs en saisie de tailles proches (en procédant par palier).

Générer le zoom en consultation
 

Cochez cette case pour que le zoom généré ne soit accessible qu'en consultation.
 

Générer le zoom sans création
 

Cochez cette case pour que l'utilisateur ne puisse pas créer de fiche.

Générer le zoom dans l'environnement ERP Divalto
 

Cochez cette case si le zoom est destiné à s'exécuter dans l'environnement de l'ERP Divalto.

 

 

Remarque : A la validation du masque, tous ces paramètres sont sauvegardés dans la base de registres, ce qui permet de retrouver des valeurs identiques si vous relancez plusieurs fois une génération. Mais attention, si vous effacez un paramètre au niveau du projet ou du dictionnaire des données, cette opération ne sera pas répercutée ici puisque vous retrouverez la dernière valeur introduite : il faudra donc aussi effacer ici ce paramètre.
