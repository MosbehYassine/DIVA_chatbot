Saisie et génération d'un fichier d'aides

 

Pour concevoir vos aides, utilisez l’outil de développement RoboHelp (version minimale : Robohelp8), qui simplifiera considérablement la saisie et la génération des fichiers d'aides.

 

Spécifiez le format de mise en page WebHelp (attention à ne pas sélectionner le format WebHelp Pro).

 

Attention :

  • Au niveau des propriétés de mise en page dans RoboHelp, le dossier de sortie doit impérativement porter le nom du fichier d'aides spécifié dans les masques Xwin ou dans vos programmes et la page de lancement doit impérativement porter ce même nom avec l'extension .htm (voir la remarque finale dans la rubrique Gestion des aides fenêtrées sous Harmony).

    Exemple     :
    Dans un masque Xwin, vous avez paramétré l'aide contextuelle suivante pour une donnée en saisie :
    Fichier : monaide ; Numéro : 1407.
    --> Spécifiez comme dossier de sortie et page de lancement : ...\monaide\monaide.htm.
     

  • Pour qu'une rubrique d'aide soit directement accessible via son numéro, il faut lui attribuer dans RoboHelp un ID de mappage égal au numéro.

    Exemple     :
    Avec le même paramétrage dans Xwin (Fichier : monaide ; Numéro : 1407), affectez à la rubrique d'aide concernée l'ID de mappage 1407 dans RoboHelp.
