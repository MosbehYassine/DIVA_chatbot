Exécution des moulinettes

Répertoires origine et destination

La moulinette demande le répertoire d’origine du fichier en lecture et le répertoire destination du fichier à créer.

Si le répertoire destination est précisé

  • Si le fichier existe déjà, il est préalablement supprimé.

 

Si le répertoire destination n’est pas précisé

  • La moulinette crée un sous-répertoire « old » dans le répertoire du fichier origine et déplace ce dernier dans ce répertoire old. Le fichier ne doit pas exister dans le répertoire « old ».

  • Le fichier destination est créé dans le répertoire origine.

 

Lancement par ProgramCall

Les moulinettes peuvent être lancées par l’instruction ProgramCall.

Dans ce cas, il faut placer dans le tunnel les éléments suivants par l’instruction Ping :

  • repertoire_origine : nom du répertoire origine

  • repertoire_destination : nom du répertoire destination.

 

En retour, la moulinette renvoie dans le tunnel un status qui se nomme « StatusMoulinette » et qui peut être lu par l’instruction PongReceive.

Le status retourné par la moulinette peut prendre une des valeurs suivantes :

0

Le fichier à été converti sans erreur.

1

Le fichier existe déjà dans le répertoire « old » (répertoire destination non renseigné).

2

Le fichier existe déjà dans le répertoire « old » et est réservé (répertoire destination non renseigné).

3

La version du fichier à convertir est différente de celle indiquée dans l’ancienne version du dictionnaire.

4

La version du fichier à convertir est déjà égale à celle indiquée dans la nouvelle version du dictionnaire.

 

Exemple

 Ping("repertoire_origine","/Divalto/fic")

 Ping("repertoire_destination","/Divalto/nvfic")

 ProgramCall("fic_41_42.dhop")

 PongReceive("StatusMoulinette",st)

 

Remarques

  • La moulinette affiche les compteurs d’enregistrements lus et écrits. A la fin, elle écrit dans un fichier journal (xgenconversionfichier.dhfd) un récapitulatif du nombre d’enregistrements par table.

  • A chaque erreur, la moulinette imprime le message d’erreur et journalise l’erreur. Elle force l’aperçu avant impression et donc à la fin du programme un état  DivaltoViewer est affiché s’il y a eu une ou plusieurs erreurs.
