Traitement Table Après Read

 

Le traitement local (facultatif) "Après Read", associé à une table d'un fichier, est automatiquement appelé par les instructions Diva iRead, iPread et iSeek après la lecture de l'enregistrement.

 

Il s'agit d'une procédure ayant les paramètres suivants :

  • tdf
    Table de définition de fichier utilisée pour effectuer la lecture de l'enregistrement (passée par adresse).

  • table
    Instance de l'enregistrement lu (passée par adresse).

  • cle
    Clé de l'enregistrement lu.

  • partage
    Code de partage utilisé pour la lecture.

  • operation
    Spécifie l'opération exacte de lecture :

    • R : Read.

    • P : Pread.

    • S : Seek.

 

Exemple du squelette de la procédure généré par Xwin :
 

;*

Public Procedure Table_MonFichier_MaTable_Read (&tdf,&table,cle,partage,operation)

;

Record *  htdf tdf                  ;table de définition de fichier

Record MonDico.dhsd MaTable table

1   cle        A                    ;clé

1   partage    1                    ;code de partage

1   operation  1                    ;R=read ; P=pread ; S=seek

Beginp

   

Endp
