Fusion de dictionnaires


Le choix Fusionner surcharge permet de fusionner un dictionnaire avec sa surcharge dans un nouveau dictionnaire.

Le nouveau dictionnaire créé à cette occasion peut à nouveau être surchargé selon la méthode habituelle.

 

Exemple 

Vous avez développé une application qui surcharge le dictionnaire gtfdd.dhsd de Divalto. Vous désirez diffuser cette application avec la possibilité de surcharger le dictionnaire. Pour que cela soit possible, vous devez préalablement fusionner le dictionnaire gtfdd.dhsd et la surcharge que vous avez créée.

 

Consultez la rubrique Fusion des traitements pour connaître la méthode utilisée pour fusionner les traitements de base et de surcharge du dictionnaire.
