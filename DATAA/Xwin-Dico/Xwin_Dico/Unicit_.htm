Unicité

Chaque objet est défini dans le dictionnaire de manière unique, c'est à dire que deux objets différents de même type ne peuvent porter le même nom. Cette caractéristique est importante car elle influe le choix des noms de champs. N'utilisez pas des noms trop vagues genre "Libellé". Un libelle d'article pourra être sur 80 caractères mais le libellé d'un autre objet pourra être sur 20 positions et ne sera donc pas le même champ.

De plus, un même champ peut être référencé dans plusieurs tables et si vous modifiez ses caractéristiques, vous modifiez automatiquement la structure de toutes ces tables dans le dictionnaire.

Par exemple, la donnée GrRef (référence article) est définie une seule fois dans le dictionnaire de Divalto Achats-Ventes et elle est utilisée dans les tables

Mouv  : mouvements

Dar  : décomposition

Lart  : libellé complémentaire

Rcl  : référencement client etc.

 

Remarque

Il est possible de définir des tableaux à l'intérieur des tables.
