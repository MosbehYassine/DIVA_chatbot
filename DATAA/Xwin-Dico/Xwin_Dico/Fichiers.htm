Fichiers

 

Les paramètres d’un fichier sont :
 

Libellé

Texte libre décrivant le fichier

 

Famille Fichier

Nom

Nom physique du fichier sur le disque. Ce nom ne doit pas être un nom absolu.

Exemple : ccfdce.dhfi

Type

Type du fichier :

I fichier séquentiel-indexé.

N (normal)  : fichier de données ayant une structure interne propre à Harmony.

U : fichier texte standard (avec CRLF pour marquer la fin des lignes).

Taille des enregistrements

Pour les fichiers de type I, indique la taille des enregistrements du fichier N associé.

Si une taille est précisée, cela signifie que tous les enregistrements du fichier ont la même taille.

Si la taille n’est pas précisée, cela signifie que la taille des enregistrements est variable. Cette solution est utilisée lorsque une même fichier contient plusieurs tables.

Version

Numéro de version du fichier. Lors de l’utilisation du fichier, Harmony vérifie que les modules qui ouvrent le fichier ont été compilés avec la bonne description de ce dernier. Pour plus de détails, voir la rubrique "Version des fichiers" du livre de la documentation Xwin - Programmation consacré au langage Diva.

Fichier temporaire

Indique que le fichier est un fichier temporaire.
Cette propriété est utilisée lors de génération automatique des liens dans le dictionnaire. Les fichiers temporaires sont ignorés lors de cette génération.

 

Famille Moulinettes

Sans reprise des données

Cette propriété est utilisée par le générateur de moulinette. Si elle est cochée, la moulinette générée ne fait que créer le fichier avec la bonne version et les bonnes clés, mais ne recopie pas les enregistrements.

 

 

 

Remarques

Un fichier de type séquentiel-indexé est physiquement composé de deux fichiers, un fichier des paramètres et clés et un fichier des données (de type N généralement). Le nom du fichier des données est déduit du nom fichier des clés en remplaçant l’extension .dhfi par l’extension .dhfd. Il n’y a donc pas lieu de préciser le nom du deuxième fichier.
