Impression du dictionnaire / Export HTML

 

L’impression du dictionnaire correspond à une sortie HTML.

Ce choix est accessible depuis le menu contextuel (choix Export Html) des fichiers ou des tables.

Le fichier Html généré contient des liens qui permettent de naviguer dans les tables et les index.

 

Remarques 

Xwin lance directement l’ouverture du document HTML dans le navigateur internet. En cas d’export HTML d’une sélection multiple, seul le dernier document généré est affiché dans la fenêtre du navigateur internet.

Le nom du fichier généré est « xxxx.HTML » où xxxx est le nom du fichier ou de la table exportée. Ces fichiers sont stockés dans le répertoire des fichiers temporaires de l’utilisateur.
