Fusion des traitements

 

A l'occasion d'une fusion d'un dictionnaire avec sa surcharge, Xwin effectue les traitements suivants :

  • Les fonctions de la base présentes aussi dans la surcharge (et uniquement celles-ci) sont préfixées par _Std_.

  • Les appels aux fonctions de base par Standard.XXX sont remplacés par des appels classiques aux fonctions _Std_XXX.

  • Les attributs de déclaration (Public, Private) des fonctions communes sont "recalculés".

  • Le code de base est inclus dans le code de surcharge :

    • Les lignes situées avant la 1ère fonction sont copiées telles quelles en tête du nouveau source.
      Remarque : les déclarations de la base sont copiées sans aucune vérification par rapport aux déclarations de la surcharge. Il convient donc de fusionner les déclarations "à la main".

    • Les fonctions sont copiées fonction par fonction avec inclusion par ordre alphabétique.
      Remarques :

      • Les lignes situées après le dernier Endp/Endf sont copiées avec la dernière fonction.

      • Il se peut que des erreurs de compilation se produisent parce que l'ordre d'apparition des fonctions a été cassé (une fonction appelée se retrouvant derrière la fonction appelante).

  • Les occurrences du nom du dictionnaire de départ sont patchées avec le nom du dictionnaire issu de la fusion.

 

Conseil concernant les surcharges

On aura intérêt à préfixer les procédures/fonctions locales d'une surcharge, de manière à ne pas avoir de doublons avec les procédures/fonctions locales de la base. Idem avec les instances des enregistrements et des fichiers.
