Index

 

Les paramètres d’un index sont :
 

Mnémonique

Nom de l'index.

Nom de la clé

Nom de la clé pour le séquentiel-indexé.
Vous devez garnir, soit le "Nom de la clé", soit "Lettre".
Voir : Les fichiers séquentiel-indexé.

Libellé

Texte libre décrivant l’index

 

 

Famille Clé

Lettre

Lettre clé utilisée pour cet index de A-Z et de a-z
Attention : la lettre clé A est différente de la lettre clé a 
Si "Nom de la clé" est renseigné, laissez vide cette zone.

Clé primaire

Indique si la clé donne accès de manière unique à tous les enregistrements de la table.

 

Famille Code Condition

Champ

Si l’index est conditionnel, indiquez ici le champ qui contient la condition

Condition

Si l’index est conditionnel, indiquez la condition à tester entre Champ et Valeur

Valeur

Si l’index est conditionnel, indiquez la valeur qui détermine la condition.

La clé sera générée dans l’index si l’expression : Champ Condition Valeur est vraie.

Exemple :

 Champ  : ce6

 Condition : =

 Valeur : 1

 indique que la clé sera générée dans l’index si ce6 = 1

 

Famille Type d’index SQL

Type

Détermine le type d’index pour une base de données SQL (SQL Serveur ou Oracle).

Voir la documentation consacrée à SQL.

Référence pour la table intermédiaire

Détermine si l’index sert de référence au cas ou le type d’index sélectionné nécessite la création d’une table intermédiaire.

Voir la documentation consacrée à SQL.
