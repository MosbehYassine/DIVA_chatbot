Fichiers du dictionnaire



Le source d'un dictionnaire est stocké dans un fichier d'extension .dhsd.

 

Les commentaires associés aux objets du dictionnaire sont stockés dans un fichier séparé, de nom identique à celui du dictionnaire et d'extension .dhdt. Le fichier des commentaires se trouve obligatoirement dans le même répertoire que le fichier .dhsd.

 

Les traitements du dictionnaire sont compilés dans un fichier objet d'extension .dhod.

 

Les dictionnaires sont inclus dans le projet au même titre que les sources Diva et les masques.
