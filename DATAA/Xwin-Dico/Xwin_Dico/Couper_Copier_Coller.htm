Couper / Copier / Coller

L’éditeur de dictionnaire autorise les opérations de Couper, Copier et Coller.

Ces opérations peuvent être faites dans un même dictionnaire, ou entre plusieurs dictionnaires.

 

Remarques importantes

La sélection de plusieurs objets ne peut se faire que dans la zone tableau. Les opérations de Couper et Copier peuvent se faire à partir de l’arbre mais avec un seul élément.

De ce fait la sélection est forcément homogène.

 

Sélection dans le tableau

La sélection de plusieurs éléments se fait toujours dans le tableau.

Pour sélectionner un groupe de lignes :

  • enfoncez la touche Shift et sélectionnez les lignes avec les flèches de direction.

  • ou cliquez sur la première ligne du groupe, enfoncez la touche Shift puis cliquez sur la dernière ligne du groupe.

Les lignes sélectionnées sont marquées par une coche :

 

Couper / Copier

Lorsqu’un ou plusieurs éléments sont sélectionnés, les choix Couper / Copier et les boutons correspondants sont actifs.

 

Coller

Pour coller le contenu du presse-papier dans le dictionnaire, placez vous dans l’arbre ou dans le tableau et appelez le choix Coller.

Lors d’un Coller,

  • si des éléments sont sélectionnés dans le tableau au moment du Coller, ces éléments sont préalablement supprimés.

  • Xwin vérifie préalablement que l’opération est possible. Par exemple, lors du collage de champs dans une table, Xwin empêche la création de doublons dans la table.

 

Remarques sur la suppression des objets

  • Lors de la suppression d’une table dans un fichier et que cette table n’est plus utilisée dans aucun fichier, Xwin vous propose de garder la définition de la table.
    Si vous décidez de garder la définition de la table, cette dernière est alors placée dans les tables mémoires.
    Si vous ne voulez pas garder la définition de la table, Xwin vous demande champ par champ si vous voulez garder la définition des champs qui ne sont plus utilisés.

  • Si on supprime un fichier, les tables qui ne sont plus utilisées dans aucun fichier sont automatiquement mises dans les tables mémoires.
