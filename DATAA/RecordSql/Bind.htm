Bind   Famille  Thème

 

Bind permet de lier une table d’un RecordSQL avec une instance publique du Record correspondant à la Table. Cette possibilité existe pour des raisons de compatibilité avec les développements antérieurs à la version 7.

 

Bind  InstanceSql  [ InstanceDiva ]

 

Paramètres

InstanceSql  

Nom de l'instance dans le RecordSql

InstanceDiva

Nom de l'instance dans le programme Diva. Si les deux instances ont le même nom, ce paramètre peut être omis.

 

Pour utiliser Bind, il faut impérativement que tous les champs de la table à lier soient sélectionnés (Table.*).

 

Exemple :

<RecordSql Name=client Comment='Clients'>

Bind CLI

<SELECT>

CLI.*

 

En diva :

 

public record gtfdd.dhsd cli

public RecordSql dicosql.dhoq client

...

;Le Record CLI et la table CLI du RecordSQL ont la même adresse mémoire

;Donc : cli.Tiers est la même donnée que client.Tiers

 

Pourquoi utiliser BIND ?

Certaines fonctions de bas niveau de l’ERP utilisent des enregistrements publics.

On utilisera BIND lorsqu’on souhaite utiliser ces fonctions de bas niveau après avoir accédé à la table de l’ERP par un RecordSQL.
