RecordSql.Join.Deactivate   Famille  Thème

 

La méthode Join.Deactivate permet de désactiver certaines jointures.

 

Long RecordSql.Join.Deactivate ( noms )

 

Paramètre

noms

Chaîne contenant les noms de jointures à désactiver. Les différents noms doivent être séparés par le caractère ; (point-virgule).

 

Retour

1

Pas d'erreur

Toutes les erreurs provoquent l'arrêt du programme

 

Mots joker

Il existe deux jokers :

  • "$ALL" : permet de désactiver toutes les jointures

  • "$OVERWRITED" : permet de désactiver toutes les jointures issues de surcharge. Cette option est particulièrement utile pour les distributeurs afin qu'ils puissent activer/désactiver leurs propres jointures simplement.

 

Remarque :

  • Par défaut, toutes les jointures sont activées, sauf celles marquées "NoActivate".

  • Si des champs de jointures sont déclarés dans le chapitre "MandatoryColumns" ou si la jointure est marquée GlobalConf, alors elle ne sera pas désactivée.
