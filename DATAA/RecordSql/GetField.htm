GetField Famille  Thème

 

La fonction GetField permet de lire un champ ajouté dynamiquement à une instance de recordSQL.

 

Long RecordSql.GetField(Nomduchamp, &Valeur)

 

Paramètre

Nomduchamp

Nom du champ à lire dans l'instance.

 

 Valeur

Variable dans laquelle stocker la réponse

 

Retour

0 : Pas d'erreur

Autre : Voir le contenu de Message.

 

Exemple

public recordsql testsrsql.dhoq MyArticle ArticleMin  

public procedure article

1 ReaderId L

1 Valeur S

1 St L

beginp

ArticleMin.AddField("Designation", "ART.des", 3, 20)

ArticleMin.AddField("Coeff", "ART.COEFPTS", 2, 8)

ArticleMin.AddField("Qte", "ART.CDEINQTE", 1, 13)

ArticleMin.AddField("IDS", "ART.ART_ID", 9, 5)

ArticleMin.AddField("hsdt", "ART.USERMODH", 4, 8)

ArticleMin.ReaderSelect();

ReaderId = ArticleMin.ReaderOpen()

1  testals L

; Exécution de la requête

 

ArticleMin.ReaderSelect(ReaderId)

 

do

   St = ArticleMin.ReaderNext(ReaderId)      ; Lecture

while  St = 1

ArticleMin.GetField("Designation", Valeur)

ArticleMin.GetField("Coeff", Valeur)

ArticleMin.GetField("IDS", Valeur)

ArticleMin.GetField("hsdt", Valeur)

Wend

endp
