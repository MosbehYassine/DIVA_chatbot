PtrRecordSqlNew Famille  Thème

 

La fonction PtrRecordSqlNew permet de créer une nouvelle instance d'un RecordSql.

    

Long PtrRecordSqlNew (NomDictionnaire, NomRecordSql, PtrRecord)

    

Paramètres

NomDictionnaire

Nom du dictionnaire de RecordSql

NomRecordSql

Nom du RecordSql dans le dictionnaire

PtrRecord

Donnée de type RecordSqlPtr recevant l'adresse de la nouvelle instance.

   

Retour

0

Pas d'erreur

-1

Erreur lors de l'allocation. Voir GetRecordSqlErrorMessage

Autre

Erreur système (voir les codes d'erreur Harmony)
    
  
 Remarques
  • Les instances allouées par PtrRecordSqlNew doivent être implicitement libérées par PtrRecordSqlFreeInstance.
  • En fin de programme, toutes les instances sont automatiquement libérées.
  • Voir DuplicateInstance  qui permet d'allouer un RecordSql à partir d'une instance existante.

Exemple

recordSqlPtr ptart

1 st L

public record a5dd.dhsd mz

 

main

mz.Dos = "998"

st = PtrRecordSqlNew ("gtrsart.dhoq","article",ptart)

if (st <> 0)

   messageBox(GetRecordSqlErrorMessage()," ")

endif

ptart.Select()
