Introduction au dictionnaire de jointures

 

Le dictionnaire de jointures permet de centraliser dans un dictionnaire la description des jointures entre les tables, plutôt que de les reproduire dans chaque RecordSQL qui les utilise. Dans l'ERP Divalto, il existe un dictionnaire par domaine contenant la description des jointures vers les tables cibles de ce domaine.

 

Les avantages :

  • La description -centralisée- peut être modifiée à un endroit unique (en cas d'erreur, d'évolution, etc.).

  • Le développeur n'a pas besoin de connaître l'expression SQL de la jointure qui lie deux tables, mais simplement son nom dans le dictionnaire de jointures.

  • Le risque d'erreur dans l'expression d'une jointure est nettement diminuée puisque le développeur utilise des jointures déjà écrites et testées.

 

Le dictionnaire de jointures porte le nom du dictionnaire de données où est décrite la table cible avec l'extension .dhsj.

 

Remarque : pour garder la compatibilité, les expressions de jointure ON peuvent toujours être utilisées dans les RecordSQL.
