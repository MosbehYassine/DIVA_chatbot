RecordSql.SetInfo   Famille  Thème

 

La méthode SetInfo permet d'envoyer des informations au RecordSql sous forme d'une chaîne Hmp.

 

long RecordSql.SetInfo ( Commande , Informations )

 

Paramètres

Commande

Les valeurs possibles pour Commande sont :

 

RSQL_DEACTIVATE_COLUMN

Permet d'envoyer les colonnes à sélectionner (usage interne du ZoomSql uniquement)

 

Informations

Chaine HMP contenant les informations à envoyer

 

 

Retour

1

OK.

0

Erreur.
