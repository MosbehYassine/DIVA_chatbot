Tables temporaires

 

Utilité

Il peut être pratique d'utiliser la puissance de SQL pour effectuer certaines opérations sur des données.

Pour ce faire, il existe des instructions pour travailler sur des tables temporaires, qui sont créées et détruite à la volée.

 

Utilisation

L'utilisation d'une table temporaire ne diffère pas par rapport à une table normale. Toutes les instructions sont autorisées.

Lors de la déclaration, il faut déclarer un RecordSql temporaire. Il s'utilise comme un RecordSql normal.

 

Déclaration

[public / protected] TmpRecordSql [keepDataNames] dictionnaire recordSql instance [noCreate] [keepOnExit]

 

Dès la déclaration, la table temporaire correspondante à la table <From> du RecordSql est créée avec la même structures et index.

Dès la sortie du programme (ou fonction si la déclaration est locale à la fonction), la table temporaire est supprimée.

 

Pour travailler avec des tables temporaires dans d'autres programmes / fonctions, il faut empêcher la suppression avec l'option keepOnExit.

De même, de l'autre coté, il ne faut pas recréer la table temporaire, mais utiliser cette déjà créée avec l'option noCreate.

Pour connaître et affecter le nom de la table temporaire, utiliser les fonctions GetTemporaryTableName et SetTemporaryTableName.

 

Attention

Les tables temporaires sont toujours supprimées automatiquement à la fermeture du processus. De ce fait, l'utilisation d'une table temporaire partagées entre deux programmes appelés en mode NO_WAIT est impossible.

 

 

Exemple d'un programme qui crée une table temporaire, y insère une ligne et appelle un autre programme qui va lire cette ligne

 

programme1 :

 

main

 

TmpRecordSql dico.dhoq Article tmpArt KeepOnExit     ; création d'une table temporaire qui ne sera pas supprimé à la sortie du programme

RecordSql dico.dhoq Article art

 

art.Select()

tmpArt.art = art.art

tmpArt.Insert()

 

1 tmpTableName S

tmpTableName = tmpArt.GetTemporaryTableName()        ; récupération du nom de la table temporaire

 

ping("name", tmpTableName)

programCall("prg.dhop", , CALL_WAIT)                 ; appel d'un nouveau programme en mode WAIT

 

 

programme2 :

 

main

 

TmpRecordSql dico.dhoq Article tmpArt NoCreate       ; création d'une instance de table temporaire mais sans créer la table

 

1 tmpTableName S

pingReceive("tmpTableName", tmpTableName)

 

tmpArt.SetTemporaryTableName(tmpTableName)           ; affectation du nom de la table temporaire

 

tmpArt.Select()                                      ; utilisation
