MandatoryColumns   Famille  Thème

 

Le chapitre "MandatoryColumns" permet d'indiquer les champs qui seront obligatoirement présents dans la requête, même après avoir désactivé toutes les jointures et tous les champs.

 

Elle comporte un attribut :

 [Zoom=yes | no]

Si Zoom=yes, la section sera prise en compte uniquement dans un ZoomSql.

 

Cette fonctionnalité est particulièrement utile pour le ZoomSql qui, pour garnir le tableau du mode liste, retire tous les champs de la requête qui ne sont pas affichés dans le tableau.

Cependant, il peut être nécessaire de toujours disposer de la valeur de certains champs. Pour être certain de les récupérer, il faut mettre ces champs dans ce chapitre "MandatoryColumns".

 

Restrictions :

  • Un champ marqué "NoActivate" ne peut pas figurer dans ce chapitre.

  • Un champ issu d'une jointure marquée "NoActivate" ne peut pas figurer dans ce chapitre.

  • Un champ de "MandatoryColumns" doit obligatoirement figurer dans le "Select".

  • Si un champ du Select possède un alias, il faut utiliser cet alias.

Attention :

Ce chapitre est toujours pris en compte si l'attribut Zoom est manquant ou s'il est positionné à No.

Pour restreindre ce chapitre au ZoomSql, il faut positionner Zoom=yes.
