GroupBy   Famille  Thème

 

La balise GroupBy permet de définir des critères de regroupement.

Elle comporte un attribut :

 [Dynamic=yes/no]

Permet d'activer les regroupements dynamiques.

 

<GroupBy>

Liste_des_colonnes

 

 

Si le regroupement dynamique n'est pas activé

La balise GroupBy est suivie par la liste des champs critères de regroupement. Toutes les colonnes de la balise <Select> (en dehors des fonctions d’agrégation) doivent être présentes dans la balise <GroupBy>. Par contre, une colonne peut être présente dans cette balise sans être sélectionnée.

Les critères de sélection pour le regroupement sont définis dans la balise <Having>

 

Si le regroupement dynamique est activé

La liste des colonnes doit être vide. Sont alors placées dans le regroupement toutes les colonnes de la balise <Select> qui ne sont pas marquées avec l'attribut GroupBy=No.

Les instructions RecordSql.GroupBy.Activate et RecordSql.GroupBy.Deactivate permettront de modifier dynamiquement les colonnes du regroupement.

 

 

Exemple 1 (non dynamique) :

 

<RecordSql Name=TopCA>

<Select>

MOUV.REF, Sum(MOUV.MONT) as Montant(10,2),

ART.DES

<From>

MOUV

<Join>

ART

ON MOUV.DOS = ART.DOS and MOUV.REF = ART.REF

<Where>

Case private ParClient

    MOUV.Ticod = 'C' and MOUV.Picod = 4

<GroupBy>

MOUV.REF, ART.DES

<Having>

Case Montant (int mt)

    Montant >= mt

<OrderBy>

Case ParMontant

    Montant DESC

 

 

 

Exemple 2  (dynamique) :

 

<RecordSql Name=TopCA>

<Select>

MOUV.REF,

Sum(MOUV.MONT) as Montant(10,2) GroupBy=no,

ART.DES

<From>

MOUV

<Join>

ART

ON MOUV.DOS = ART.DOS and MOUV.REF = ART.REF

<Where>

Case private ParClient

    MOUV.Ticod = 'C' and MOUV.Picod = 4

<GroupBy Dynamic=yes>

<Having>

Case Montant (int mt)

    Montant >= mt

<OrderBy>

Case ParMontant

    Montant DESC
