DuplicateInstance  Famille  Thème

 

La fonction DuplicateInstance permet de créer une nouvelle instance d'un RecordSql déjà existant.

   

Long RecordSql.DuplicateInstance (PtrRecord)

   

Paramètres

PtrRecord

Donnée de type RecordSqlPtr recevant l'adresse de la nouvelle instance.

   

Retour

0

Pas d'erreur
   
 
 Remarques
  • Les instances allouées par DuplicateInstance doivent être implicitement libérées par PtrRecordSqlFreeInstance.
  • En fin de programme, toutes les instances sont automatiquement libérées.
  • Seule la structure du RecordSql est allouée. Les données ne sont pas recopiées dans la nouvelle instance.
  • Voir PtrRecordSqlNew qui permet d'allouer un RecordSql sans déclaration préalable.

Exemple

RecordSql gtrsart.dhoq article articlepp

RecordSqlPtr ptart

 

articlepp.DuplicateInstance(ptart)

ptart.Select()

PtrRecordSqlFreeInstance(ptart)
