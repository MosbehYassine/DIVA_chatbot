Select   Famille  Thème

 

La balise Select permet de définir les colonnes de la requête Sql.

Elle comporte les attributs :

 [Top=n]

Limite le nombre de lignes de résultat de la requête aux n premières lignes.

 [Distinct=yes/no]

Correspond à l’option "distinct" du langage SQL.

 

Elle contient la liste des champs ou expressions qui constituent la structure du RecordSQL, séparés par une virgule.

  • Champs

{ table | alias }.ColumnName [ as uniqueName ] [ NoActivate ] [ GroupBy=yes | no ]

Le nom du champ est précédé du nom de la table ou de son alias. S'il est suivi du paramètre uniqueName, ce dernier sera le nom par lequel il faudra référencer le champ.

L'attribut NoActivate permet d'indiquer que le champ ne sera pas sélectionné par défaut. Sa sélection s'obtient alors par programme. Voir RecordSql.Column.Activate.

L'attribut GroupBy permet de retirer une colonne du regroupement. Voir GroupBy.
 

Cas particulier des tableaux

Les tableaux n’existent pas dans une base de données.

A la création de la table, un tableau est remplacé par autant de colonnes qu’il y a d'éléments dans le tableau. Chaque nom de colonne est suffixé par son indice dans le tableau. Par exemple, le tableau Rep(3) crée les trois champs Rep_0001, Rep_0002 et Rep_0003. Néanmoins, dans la description du RecordSQL et dans son utilisation en Diva et dans les masques, l’écriture indicée est conservée. En Diva, l'écriture indicée avec une variable est autorisée si tous les éléments du tableau sont inclus dans le RecordSQL.

On pourra donc écrire :

o Rep(1), Rep(2)

o Rep(1) as CommercialSedentaire, Rep(2) as CommercialTerrain

o Rep(*) pour inclure toutes les éléments dans le RecordSQL.

 

  • Expressions

Expression as UniqueName { (Format) | (ReferenceDico) } [ Name="nom" ] [ NoActivate ] [ GroupBy=yes|no ]

Expression est une expression SQL. Le compilateur n’effectue aucun contrôle de la syntaxe de l’expression. Si l’on se soucie de la portabilité du RecordSQL vers différents moteurs de base de données, utiliser impérativement des expressions compatibles avec ces moteurs.

L’expression doit toujours être suivie d’un UniqueName qui servira à la référencer puis impérativement du format de stockage ou d’une référence à un format en provenance du dictionnaire de données.

L'attribut Name permet d'identifier la ou les jointures nécessaires à la résolution du champ (utilisé pour la désactivation des jointures). Cet attribut est obligatoire si le paramètre ZoomOptimize du chapitre RecordSql est positionné à YES.

L'attribut NoActivate permet d'indiquer que le champ ne sera pas sélectionné par défaut. Sa sélection s'obtient alors par programme. Voir RecordSql.Column.Activate.

L'attribut GroupBy permet de retirer une colonne du regroupement. Voir GroupBy.

Exemples :

PU*QTE as MT(10,2)

PU*QTE as MT (>gtfdd.dhsd MT)

 

  • Tous les champs d’une table

{ table | alias }.*

Le nom de la table ou son alias est suivi d’une étoile.

Exemple :

CLI.*
