RecordSql   Famille  Thème

 

Cette balise marque le début d'un nouveau RecordSQL.

Elle comporte les attributs :

Name=...

Définit le nom du RecordSQL.

[DataBase=...]

Permet de changer le nom de l'implicite SQL par défaut pour ce RecordSQL.

[Comment=...]

Permet d'ajouter un commentaire qui sera affiché dans Xwin lors de la sélection des données.

[ZoomOptimize=yes/no]

Indique que le RecordSQL a été optimisé pour un usage dans le Zoom Sql.

 

La balise RecordSql inclut une liste de balises décrivant le RecordSQL.
Les balises <Select> et <From> sont obligatoires.
Toutes les autres balises (<MandatoryColumns>, <Join>, <Where>, <Groupby>, <Having>, <OrderBy>) sont facultatives.

 

Si l'attribut ZoomOptimize est positionné à la valeur YES, le Zoom Sql va désactiver les jointures qui ne servent pas lors de l'affichage du mode liste. Reportez-vous à la rubrique Optimisation d'un RecordSql pour le Zoom pour prendre connaissance des règles à appliquer pour effectuer cette optimisation.

 

Remarques

  • La balise <RecordSql> peut être suivie par la déclaration de Records publics, qui pourront ensuite être utilisés dans le corps du RecordSQL. Ces enregistrements sont essentiellement utilisés dans les balises Where et Join.
    Par exemple, on déclarera ici l'enregistrement MZ, qui contient des paramètres généraux indispensables comme le numéro de dossier.

  • La balise <RecordSql> peut être suivie de directives Bind, qui permettent de lier des enregistrements aux Records publics déclarés dans le programme Diva.

Exemple

<RecordSQL Name=Facture Comment=”Le client et ses satellites”>

Public Record A5DD.dhsd MZ
