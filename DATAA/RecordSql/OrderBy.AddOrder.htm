RecordSql.OrderBy.AddOrder   Famille  Thème

 

La méthode OrderBy.AddOrder permet de créer dynamiquement un ordre de tri.

 

Long RecordSql.OrderBy.AddOrder ( noms )

 

Paramètre

noms

Chaîne contenant les noms de champs sur lesquels trier. Les différents noms doivent être séparés par le caractère ; (point-virgule). On peut également spécifier l'ordre de tri.

 

Retour

1

Pas d'erreur

Toutes les erreurs provoquent l'arrêt du programme.

 

Les noms des champs à activer peuvent être de la forme :

  • Table.Champ si la table n'a pas d'alias

  • AliasTable.Champ si table possède un alias

  • AliasChamp

 

Pour spécifier l'ordre de tri, il faut faire suivre le nom du champ par le caractère : (double-point) suivi de soit ASC soit DESC.

 

Exemple :

 

Record.OrderBy.AddOrder ("ART.REF;ART.DES:DESC;ART.FAM(1):DESC")
