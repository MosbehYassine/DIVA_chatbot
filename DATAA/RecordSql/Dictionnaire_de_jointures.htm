Dictionnaire de jointures

 

Le dictionnaire commence par un entête :

 

<DictionaryJoinSql DataBase="DAV" OverwrittenBy="gtfddu.dhsj" Overwrite="" ModuleInfo="">

 

L’attribut facultatif DATABASE permet d’indiquer le nom de la base de données pour la table jointe :

  • Si une valeur est définie dans le dictionnaire de jointures, elle est toujours prise en compte en remplacement de celle du RecordSQL.

  • S’il n’y a pas de valeur, on conserve celle du dictionnaire de RecordSQL.

Lors de la compilation de la clause USING, si l’attribut Database défini dans la balise <Join> du RecordSQL est différent de celui du dictionnaire de jointures, le compilateur signale un Warning.

 

Les jointures vers une table cible sont regroupées dans une section <JOIN> ayant pour attribut le nom de la table cible dans le dictionnaire de données. Chaque jointure est décrite par un case portant le nom de la jointure.

 

Exemple :

 

<JOIN Table=ART>

case ArticleMemeTarif

ON $join.Dos = ART.Dos and $join.Ref = ART.TaRef

case ArticleRemplacement

ON $join.Dos = $from.Dos and $join.Ref = $from.RefRpl

 

<JOIN Table=CLI>

...

 

Le fait de regrouper les jointures par table de destination a plusieurs conséquences :

  • Les noms de jointure sont uniques par table cible.
    Au chargement d’un dictionnaire de jointures, le compilateur vérifie :

    • L’unicité des tables cibles.

    • L’unicité des noms de jointure pour une table cible.

  • La recherche de la clause USING s’effectue dans le chapitre lié à la table de cible.

 

Exemple :

<JOIN Table="ART">

Case ArticleRemplacement

ON $join.Dos = $from.Dos AND $join.Ref = $from.RefRpl

 

 

Chaque jointure vers une table cible est identifiée par un nom de case unique (ici ArticleRemplacement).
Sur la ligne suivante, l'expression de la jointure : ON $join.Dos = $from.Dos AND $join.Ref = $from.RefRpl

 

$from est remplacé à la compilation par le nom de la table d’origine ou son alias (c’est-à-dire celle du <from>).

<FROM Insert=Yes Update=Yes Delete=Yes>
ART

 

$join est remplacé à la compilation par le nom de la table jointe ou son alias (c’est-à-dire celle du <join>).

<JOIN01>
ART as ArticleRemplacement

 

 

Exemple :

RecordSQL

<FROM Insert=Yes Update=Yes Delete=Yes>

ART

<LEFTJOIN>

ART as ArticleRemplacement

Using ArticleRemplacement

 

 

Dictionnaire de jointures

Case ArticleRemplacement

ON $join.Dos = $from.Dos AND $join.Ref = $from.RefRpl

 

Résultat

<LEFTJOIN>

ART as ArticleRemplacement

ON ArticleRemplacement.Dos = ART.Dos AND ArticleRemplacement.Ref = ART.RefRpl

 

 

Les paramètres : Using NomDeJointure [(p1, [,pn])]

 

L’utilisation d’une jointure peut comporter des paramètres (en plus des paramètres implicites que sont $from et $join) :

  • Dans le dictionnaire de jointures, les noms des paramètres suivent le nom de la jointure ; par exemple case FamStat(indice).

  • Dans l’expression de la jointure, on matérialisera ces paramètres par leur nom précédé du signe $ ; par exemple $indice.
    Ils seront remplacés à la compilation par les paramètres suivant le nom de jointure dans la clause USING.

 

Exemple :

Dans le dictionnaire de jointures :

<JOIN Table=T012>

case FamStat(indice)

ON ($join.Dos = case T000.TabTyp(12) when 2 then 999 else $from.dos end) and $join.cebin = 12 and $join.FamNo = $indice and $join.Fam = $from.Fam($indice)

 

Dans le RecordSql :

<Join01>

T012 as FamStat1

Using FamStat(1)

<Join01>

T012 as FamStat2

Using FamStat(2)

<Join01>

T012 as FamStat3

Using FamStat(3)
