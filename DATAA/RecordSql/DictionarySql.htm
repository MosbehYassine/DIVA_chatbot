DictionarySql   Famille  Thème

 

Cette balise est obligatoire et unique pour un dictionnaire de RecordSQL.


Elle comporte les attributs :

[DefaultDictionary=...]

Définit le dictionnaire de données par défaut pour les tables des sections <From> et <Join>.

[DataBase=...]

Définit l'implicite SQL par défaut à laquelle sont associées les tables.
Ce nom est défini dans le fichier paramètre des Implicites SQL pour définir la base de données réelle de stockage des tables.

[ModuleInfo=...]

Commentaire, rendu par la fonction Diva ModuleInfo.

[ModuleVersion=...]

Version, rendue par la fonction Diva ModuleInfo.

[OverWrite=...]

Nom du dictionnaire surchargé, si le dictionnaire courant est un dictionnaire de surcharge.
La présence de l'objet surchargé est indispensable pour compiler une surcharge.

[OverWrittenby=...]

Nom du dictionnaire qui surcharge le dictionnaire courant. Ce dictionnaire peut ne pas exister.
La surcharge étant possible sur plusieurs niveaux, un même dictionnaire de RecordSql peut avoir les paramètres OverWrite et OverWrittenby renseignés.

 

Exemple :

<DictionarySql defaultdictionary=gtfdd.dhsd database=dav>
