RecordSql.PagingReaderSelect   Famille  Thème

 

La méthode PagingReaderSelect exécute la requête SQL de manière paginée. Les filtres, les critères de tris etc. doivent être préalablement positionnés.

La pagination permet de lire la table par bloc. Cela permet d’optimiser les performances sur un affichage de tableau par exemple.

 

Attention : Cette fonctionnalité n’est pas supportée par DB2, ni par les versions de Microsoft SQL Server antérieures à la version 2012.

 

 

Long RecordSql.PagingReaderSelect ( [ IdReader] , Offset , Count )

 

Paramètre

IdReader

Si ce paramètre est omis, la méthode PagingReaderSelect retourne l'identifiant d'un nouveau Reader.
Si ce paramètre est précisé, la méthode PagingReaderSelect utilise le Reader passé en paramètre.

 

Offset

Indique l’indice de départ de lecture

 

Count

Indique le nombre de lignes à lire

 

Retour

 

La méthode retourne l'identifiant du Reader.

Attention, même dans le cas ou IdReader est spécifié, il faut récupérer le résultat de la fonction, car ReaderSelect peut retourner une autre valeur.

Toutes les erreurs provoquent l'arrêt du programme

 

Exemple

Voir Les Readers

RecordSql gtrsart.dhoq Article

1 idReader L

1 offset L

1 nbLu L

 

nbLu = 50

Offset = 0

 

idReader = article.ReaderOpen()

do while nbLu = 50

   nbLu = 0

   idReader = article.PagingReaderSelect(idreader, offset, 50)

   do while article.ReaderNext(idReader)

      nbLu++

   wend

   offset += nbLu

wend

 

article.ReaderClose(idReader)
