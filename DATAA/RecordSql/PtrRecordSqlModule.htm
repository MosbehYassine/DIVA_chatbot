PtrRecordSqlModule   Famille  Thème

 

La fonction PtrRecordSqlModule permet d'obtenir l'adresse d'un RecordSql déclaré dans un module, qu'il soit public ou non.

  

Long PtrRecordSql (module,  nom_instance_recordSql , pointeur)

  

Paramètres

Module

Nom du module dans lequel on cherche le RecordSql.

Si ce paramètre est à espaces, la recherche se fait dans le module courant.

Nom_instance_recordSql

Nom de l'instance à chercher.

Pointeur

Donnée de type RecordSqlPtr recevant l'adresse.

 

  

Retour

0

Pas d'erreur

1

RecordSql non trouvé

2

L'enregistrement trouvé ne correspond pas à un RecordSql correctement initialisé.
  

Exemple

RecordSqlPtr pointeur

PtrRecordSql ("module.dhop", "TopCa", pointeur)
