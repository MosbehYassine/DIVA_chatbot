RecordSql.GroupBy.Deactivate   Famille  Thème

 

La méthode GroupBy.Deactivate permet de désactiver certains champs.

 

Long RecordSql.GroupBy.DeActivate ( noms )

 

Paramètre

noms

Chaîne contenant les noms de champs à désactiver. Les différents noms doivent être séparés par le caractère ; (point-virgule).

 

Retour

1

Pas d'erreur

Toutes les erreurs provoquent l'arrêt du programme

 

Mot joker

Il existe un joker :

  • "$ALL" : permet de désactiver tous les champs

 

Les noms des champs à désactiver peuvent être de la forme :

  • Table.Champ si la table n'a pas d'alias

  • AliasTable.Champ si table possède un alias

  • AliasChamp

 

Par défaut, toutes les colonnes du <Select> sont dans le GroupBy, sauf celles qui sont marquées avec l'attribut GroupBy=No.
