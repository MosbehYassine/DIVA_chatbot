RecordSqlGetModuleInstancesNames  Famille  Thème

 

La fonction RecordSqlGetModuleInstancesNames permet de connaître la liste des instances de RecordSql déclarées dans un module.

    

Long RecordSqlGetModuleInstancesNames (résultat, module, public, préfixe, premier)

    

Paramètres

Résulat

Variable alpha ou string qui contiendra la liste au format HMP

 

Module

Nom du module. Il est automatiquement chargé si nécessaire.

 

Public

1 = que les instances publiques

2 = que les instances privées

3 = toutes les instances

 

Préfixe

Permet de filtrer les instances par un préfixe.

 

Premier

Délivrer uniquement le premier nom d'instance correspondant aux critères.

   

Retour

0

Pas d'erreur

2

Module non trouvé

 

Toutes les autres erreurs interrompent le programme.
    
La chaine HMP contient :

<INSTANCE>

Nom de l'instance

<PUBLIC>

1 si publique, 0 si privée
