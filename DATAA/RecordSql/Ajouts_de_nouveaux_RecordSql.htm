Ajouts de nouveaux RecordSql

 

Un RecordSQL déclaré dans le dictionnaire de surcharge n’existant pas dans le dictionnaire de base est un nouveau RecordSQL. Il n'y a aucune contrainte concernant les nouveaux RecordSql.

Pour surcharger un RecordSql existant, il suffit de le déclarer dans la surcharge avec son nom dans le dictionnaire surchargé.
