RecordSql.ChangeTable   Famille  Thème

 

La méthode ChangeTable est spécifique pour le BI (Business Intelligence = Décisionnel).

Elle permet de tracer les modifications effectuées sur une table.

 

Long RecordSql.ChangeTable ( NomTable , Version )

 

La méthode ChangeTable remplace la clause FROM par FROM CHANGETABLE(CHANGES NomDeLaTable,VERSION NuméroDeVersion)

 

Paramètres

NomTable

Nom de la table.

 

Version

Version

 

Retour

1

Pas d'erreur
  Toutes les erreurs provoquent l'arrêt du programme
