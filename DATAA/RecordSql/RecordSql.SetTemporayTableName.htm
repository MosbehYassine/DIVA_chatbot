SetTemporaryTableName   Famille  Thème

 

Cette méthode permet d'assigner à un RecordSql temporaire le nom de sa table temporaire.

 

Long RecordSql.SetTemporayTableName( tableName )

 

Paramètre

tableName

Nom de table temporaire.

 

 

  Exemple

TmpRecordSql dico.dhoq Article art noCreate

art.SetTemporaryTableName( LeNom )
