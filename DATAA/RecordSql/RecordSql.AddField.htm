RecordSql.AddField Famille  Thème

 

La fonction AddField permet d'ajouter dynamiquement un champ à une instance de recordSQL.

 

Long RecordSql.AddField (nom, expression, nature, longueur)

 

Paramètre

Nom

Nom du champ à ajouter dans l'instance.

 

 Expression

Expression permettant de calculer le champ

 

 Nature

Voir les valeurs de la fonction DataNature.

 

 Longueur

Taille du champ

 

 

Retour

0 : Pas d'erreur

-1 : Le champ existe déjà

Autre : Le programme est interrompu par une exception.
