RecordSql.ReaderInsert   Famille  Thème

 

La méthode ReaderInsert ajoute une ligne dans la table de base (balise <From>).

 

Long RecordSql.ReaderInsert (  IdReader )

 

Paramètre

IdReader

Identifiant du Reader à utiliser.

 

Retour

Id

La méthode retourne l'identifiant de la nouvelle ligne.

Voir GetId
  Toutes les erreurs provoquent l'arrêt du programme

 

Remarque

ReaderInsert est équivalent à Insert.
