RecordSql.Where.AddClause   Famille  Thème

RecordSql.Having.AddClause

RecordSql.OrderBy.AddClause

 

La méthode AddClause permet d'ajouter un critère de sélection ou de tri. Ces critères ajoutés n'ont pas de paramètres. Leur invocation se fait par la méthode UseClause.

 

RecordSql.Where.AddClause ( Nom  , Code  )

RecordSql.Having.AddClause ( Nom  , Code  )

RecordSql.OrderBy.AddClause ( Nom   , Code  )

 

Paramètres

Nom

Nom du critère (de la fonction) à invoquer.

 

Code

Code Sql du critère.

 

Retour

1

Pas d'erreur
  Toutes les erreurs provoquent l'arrêt du programme
