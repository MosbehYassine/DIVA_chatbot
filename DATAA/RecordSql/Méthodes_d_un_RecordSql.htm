Méthodes d'un RecordSql

 

Un RecordSql met à la disposition du développeur un certain nombre de méthodes.

La notation pointée est utilisée pour appeler ces méthodes : Instance.Methode()

 

Les méthodes retournent en général une valeur indiquant le résultat de l'opération. En cas d'erreur que le programme ne saurait traiter, le programme est interrompu.
Par exemple, la méthode Select

  • retourne 1 si une ligne a été lue

  • retourne 0 si aucune ligne a été lue

  • Arrête le programme pour toute autre erreur (erreur dans la syntaxe Sql par exemple)

 

Exemples

 

Public RecordSql 'GTRSTIERS.dhoq' CLIENT

 

Client.Where.Zoom_Like_Tiers(Tiers) ; pour positionner une condition Where

Client.Select()                     ; pour lire une ligne du RecordSQL
