RecordSql.ReaderSelect   Famille  Thème

 

La méthode ReaderSelect exécute la requête SQL. Les filtres, les critères de tris etc. doivent être préalablement positionnés.

 

Long RecordSql.ReaderSelect ( [ IdReader] )

 

Paramètre

IdReader

Si ce paramètre est omis, la méthode ReaderSelect retourne l'identifiant d'un nouveau Reader.
Si ce paramètre est précisé, la méthode ReaderSelect utilise le Reader passé en paramètre.

 

Retour

 

La méthode retourne l'identifiant du Reader.

Attention, même dans le cas ou IdReader est spécifié, il faut récupérer le résultat de la fonction, car ReaderSelect peut retourner une autre valeur.

Toutes les erreurs provoquent l'arrêt du programme
