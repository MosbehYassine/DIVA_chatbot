RecordSql.GetColumnValue    Famille  Thème

 

La fonction GetColumnValue permet de récupérer la valeur d'un champ du RecordSql.

Elle est spécialement utile quand on travaille avec des pointeurs car l'écriture "record.champ" n'est pas possible.

 

Long RecordSql.GetColumnValue (  NomChamp, &ValeurChamp )

 

Paramètre

NomChamp

Nom du champ à récupérer

 ValeurChamp

Valeur du champ

 
 

Retour

1 : Pas d'erreur

0 : Le champ n'a pas été trouvé dans le RecordSql

 

Toutes les autres erreurs sont fatales.

 

Remarque : pour les champs "tableaux", il est possible de récupérer l'intégralité du champ via la synxtaxe "tab(*)" ou une seule case avec "tab(1)".

 

Exemple :

 

RecordSql gtrsart.dhoq Article

1 ref >gtfdd.dhsd ref

1 fam >>gtfdd.dhsd famtb

 

Article.Select()

Article.GetColumnValue("ref", ref)

Article.GetColumnValue("fam(*)", fam(*))
