RecordSql.AddUpdateValue  Famille  Thème

 

Ajout d'une expression de mise à jour pour la fonction RecordSql.UpdateValues

 

Long RecordSql.AddUpdateValue ( expression )

 

Paramètre

expression

Expression de mise à jour pour un champ.

 

Retour

1

Pas d'erreur

Toutes les erreurs provoquent l'arrêt du programme

 

Exemple :

 

instance.AddUpdateValue("DOS = DOS + 1")

instance.UpdateValues()
