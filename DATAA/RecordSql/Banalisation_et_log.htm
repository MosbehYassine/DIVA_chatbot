Banalisation et log

 

Banalisation

 

Dans le langage SQL, il existe des mots réservés qu'il est impossible d'utiliser pour nommer un champ, table ou alias.

S'il parait évident que personne ne va appeler une table "from" ou encore "select", les moteurs de base de données peuvent en ajouter de nouveaux, et il n'est pas impossible qu'un nom de champ/table déjà existant devienne un mot réservé.

 

C'est pour cette raison que l'exécution d'un recordsql va banaliser les champs, tables et alias dans la requête.

Sous Microsoft SQL Server, la banalisation est du style : [table].[champ] as [alias]

Sous IBM DB2, elle est : "table"."champ" as "alias"

 

Une partie de cette banalisation est effectuée à la compilation du recordsql. Le reste, est fait au moment de l'exécution.

De plus, la compilation va toujours générer une banalisation pour SQL Server. La conversion vers DB2 est effectuée à l'exécution.

 

Remarque : Tous les cas ne sont pas détectés. Par exemple, dans une requête écrite par un développeur dans une subquery, les alias d'un champ dans le select ne sont pas banalisés.

Cette banalisation restera à la charge du développeur.

 

Attention : les banalisations faites manuellement par le développeur doit utiliser la syntaxe pour SQL Server.

 

 

Journalisation des requêtes

 

Il est possible d'activer une trace des requêtes SQL exécutées.

Pour l'activer, il faut, dans le fichier connexions.xml, rajouter la balise <logSql></logSql> après la balise <harmonyShareServer>.

Il faut lui donner un nom de chemin windows du fichier log. Par exemple : c:\divalto\log.sql

 

Par défaut, seule la dernière requête est journalisée. Pour conserver toutes les requêtes SQL, il faut rajouter après la balise <logSql> la balise <ecraserLog></ecraserLog>.

Cette balise demande un booléen.

 

Exemple :

 

<connexion nom="default">

      <type>5</type>

      <nomBase>ERP212</nomBase>

      <chaineDeConnexion>Data Source=PSXBDXG02\SQL2017;Trusted_Connection=Yes;Initial Catalog=ERP212</chaineDeConnexion>

      <harmonyShareServer>PSXBDXG02</harmonyShareServer>

      <logSql>c:\divalto\sql.sql</logSql>

      <ecraserLog>false</ecraserLog>    <!-- false : ne pas écraser le log; true : écraser le log  -->

 </connexion>
