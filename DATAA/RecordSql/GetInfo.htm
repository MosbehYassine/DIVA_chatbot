RecordSql.GetInfo   Famille  Thème

 

La méthode GetInfo permet d'obtenir une chaîne Hmp donnant les caractéristiques d'un RecordSql.

 

long RecordSql.GetInfo ( Commande , Résultat )

 

Paramètres

Commande

Les valeurs possibles pour Commande sont

 

RSQL_WHERE_BEGIN

 

Retourne la première clause Where (sans paramètre).

nom

Nom de la clause.

libelle

Libellé.

codeSql

Code SQL correspondant.

RSQL_WHERE_NEXT

Retourne la clause Where suivante. Voir RSQL_WHERE_BEGIN

RSQL_ALL_WHERE_BEGIN

 

Retourne la première clause Where parmis toutes les clauses.

nom

Nom de la clause.

libelle

Libellé.

codeSql

Code SQL correspondant.

declaration

Déclaration tel qu'écrite dans le recordSql

 

RSQL_ALL_WHERE_NEXT

Retourne la clause Where suivante. Voir RSQL_ALL_WHERE_BEGIN

RSQL_ORDERBY_BEGIN

Retourne la première clause OrderBy

nom

Nom de la clause.

libelle

Libellé.

champ *

Nom du champ.

ordreDeTri *

ASC ou DESC.

(*) Pour chaque champ de l'ordre de saisie.

 

RSQL_ORDERBY_NEXT

Retourne la clause OrderBy suivante. Voir RSQL_ORDERBY_BEGIN

RSQL_HAVING_BEGIN

Retourne la première clause Having.

nom

Nom de la clause.

libelle

Libellé.

 

RSQL_HAVING_NEXT

Retourne la clause Having suivante. Voir RSQL_HAVING_BEGIN
 

RSQL_COLUMN_BEGIN

Retourne les caractéristiques de la première colonne.

nom

Nom du champ (en majuscules).

nomCasse

Nom du champ avec la casse.

libelle

Libellé du champ.

nomSql

Nom utilisé en Sql (table.champ).

Pour les tableaux : Var_indices.

nomTable

Nom de la table dans le dictionnaire dhsd.

aliasTable

Alias de la table.

nature

Nature de la colonne :

1 = Numérique avec décimales variables

2 = Numérique

3 = Alphanumérique

4 = Date (aaaammjj)

5 = 1 caractère

6 = Type B

7 = Type X

8 = Binaire

9 = Type L

10 = Heure (hhmmss)

11 = Date mensuelle (aaaamm)

12 = Date + heure (aaaammjjhhmmss)  

13 = Durée

14 = Blob

masqueOdbc

1 / 0 Indique si le champ est masqué pour Odbc.

expression

1 / 0 Indique si la colonne est un champ calculé.

taille

Taille de la colonne.

nbdec

Nombre de décimales.

adresse

Adresse en mémoire.

tableDeBase

Indique si la table du champ courant est la table de la balise From.

indice1 à

indice4

Indices si la colonne est dans un tableau.

 

RSQL_COLUMN_NEXT

Retourne les caractéristiques de la colonne suivante.

Voir RSQL_COLUMN_BEGIN.

 

RSQL_TABLE_NAME

Retourne le nom de la table From du RecordSql.
 

RSQL_ALIAS_TABLE_ID

Retourne le nom complet (table.nom) de l'identifiant de la table From.
 

RSQL_CURRENT_ORDERBY

Retourne les caractéristiques de l'ordre de tri sélectionné. Voir RSQL_ORDERBY_BEGIN.

 

RSQL_CURRENT_WHERE

Retourne la clause Where courante.

nom

Nom de la clause.

codeSql

Code SQL correspondant.

 

RSQL_HAVE_GROUPBY

1 / 0 Indique si le RecordSql contient la clause Group By.

RSQL_HAVE_DISTINCT

1 / 0 Indique si le RecordSql contient la clause Distinct.

RSQL_RECORDSQL_NAME

Retourne le nom du RecordSql

RSQL_DATABASE_NAME

Retourne le nom de la base données accédée par le RecordSql

RSQL_ZOOM_OPTIMIZE

Permet de savoir le RecordSql possède l'attribut ZoomOptimize=Yes

RSQL_IS_ROWS_CONF

Permet de savoir si, pendant la lecture, au-moins une ligne (complète, ou les champs de jointures) a été ignorée ou mise à blanc à cause des confidentialités. Retourne '1' si c'est le cas, '0' sinon.

RSQL_TABLE_ROWS_CONF

Retourne le détail des tables qui ont été confidentialisées durant la lecture

{TableRowsConf}

Début des informations concernant la prochaine table

<TableName>

Nom de la table

<TableAlias>

Alias de la table

<IsFromTable>

Indique si c'est la table principale (0 ou 1)

<IsGlobalConf>

Indique si la jointure est marquée GlobalConf (0 ou 1)

RSQL_GET_RECORDS_INFO

Permet d'obtenir des informations sur les tables du RecordSql.

{Record}

Début des informations concernant un record

<Nom>

Nom de l'instant du record

<Adresse>

Adresse en mémoire du record

<Taille>

Taille du record

RSQL_COMMENT

Permet d'obtenir le commentaire du RecordSql (contenu de l'attribut Comment du RecordSql)

RSQL_SERVER_TYPE

Permet d'obtenir le type de la base de données cible (SQL Server ou IBM DB2)
Il existe deux constantes dans zdiva.dhsp :

- RSQL_SQL_SERVER

- RSQL_IBM_DB2

 

Résultat

Chaine HMP recevant le résultat en fonction de la commande.

 

 

Retour

1

OK.

0

Erreur.

 

Voir

RecordSql.GetRecordInfo
