LoadTableFields Famille  Thème

 

La fonction LoadTableFields permet d'obtenir très rapidement la liste des champs d'une table provenant d'un dictionnaire de données.

Contrairement à la fonction DDInterface qui charge le fichier .dhsd, LoadTableFields envoie une requête au serveur xlan, qui a toutes les informations dans son cache.

Par exemple, pour le dictionnaire gtfdd.dshd les temps passent de 1,2 secondes à 30 millisecondes.

 

Long RecordSql.LoadTableFields (liste, [ dictionnaire] , [table], options, message)

 

Paramètre

Liste

Liste diva qui va recevoir le résultat, c'est à dire la liste des champs de la table.
Cette liste est créée par la fonction, et doit être détruite par votre programme.

Les éléments de la liste sont définis dans le dictionnaire ddsys :
record ddsys.dhsd DDInterfaceDataField new

Seuls les champs suivants sont renseignés :

FieldName

FieldPosition

FieldSize

FieldTypeNature

FieldNbdec

FieldNbdim

FieldDim

FieldEnj

FieldLibelle

FieldNatureInput

 

 Dictionnaire

Nom du dictionnaire. Par défaut, c'est le nom du dictionnaire dhsd qui décrit la table From du recordSql

 Table

Nom de la table. Par défaut, c'est le nom de la table From du recordSql 

 Options

Chaîne HMP contenant les options.

<FindNomSql>1 ou 0 Spécifier que la recherche doit se faire également sur les noms Sql
<RecordSQL>1 ou 0 Pour avoir les noms de données Sql
<NatureExt>1 ou 0 Les champs de type blob ne sont pas retournés comme des données alpha.

 

 Message

En cas d'erreur, contient la description de l'erreur.

 

Retour

0 : Pas d'erreur

Autre : Voir le contenu de Message.

 

Exemple

1 liste L

1 st X

1 messErr S

record ddsys.dhsd DDInterfaceDataField new


st = article.LoadTableFields (liste, "gtfdd.dhsd", "art", "<FindNomSql>1", messErr)

if st <> 0

   messageBox(messErr, "Erreur LoadTableFiels : " & tostring(st))

   programExit

endif

ListBegin(liste)

Loop ListNext(liste, new) not in (0,-1)

   display [ new.FieldName " " new.FieldSql ]

endloop
