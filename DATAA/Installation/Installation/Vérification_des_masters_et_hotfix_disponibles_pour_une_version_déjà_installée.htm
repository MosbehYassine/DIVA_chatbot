Vérification des services packs et hotfix disponibles pour une version déjà installée

 

Hors installation, il est également possible de prendre connaissance des Services Packs et Hotfix disponibles pour la version installée (ainsi que des éventuelles versions ultérieures du produit).

 

Pour ce faire, sélectionnez le choix Utilitaires : Liste des produits installés pour Divalto du menu Harmony.

 

Attention :

Ce choix tient compte de l’environnement courant. En effet, plusieurs versions de l’ERP peuvent cohabiter sur un même ordinateur (en particulier sur le poste d’un développeur).

 

L'utilitaire présente un tableau affichant les informations suivantes :

  • Sur fond blanc : les produits déjà installés.
    Chaque ligne de la liste affiche l’identifiant du produit, son libellé et sa date d’installation.

    On y trouvera généralement :

    • Une ligne pour le runtime Harmony (sachant que la dernière version d’Harmony assure la compatibilité avec les versions précédentes de l’ERP).

    • Eventuellement une liste de Hotfix déjà installés pour le runtime.

    • Une ligne pour la version de l’ERP de l’environnement courant.

    • Eventuellement une liste de Hotfix déjà installés pour cette version de l’ERP.

Remarque :
Les informations concernant le runtime proviennent du fichier /Divalto/Sys/MasterId_Harmony.txt (fichier automatiquement créé ou mis à jour lors d’une installation du runtime).
Les informations concernant l'ERP proviennent du fichier MasterId_ERP.txt situé dans le répertoire de l’environnement courant (fichier automatiquement créé ou mis à jour lors d’une installation de l'ERP).
Ces fichiers n’existent qu’à partir de la version 7.3a.

  • Sur fond jaune : tous les Hotfix disponibles non encore installés.
     

  • Sur fond vert : la dernière version du Master disponible correspondant à la version installée (Service Pack), suivie de la liste des Hotfix disponibles pour ce Master.
     

  • Sur fond bleu : les autres Masters disponibles.
    A titre indicatif, le tableau affiche également les versions majeures postérieures à la version installée.

 

Pour toutes les lignes du tableau, un clic dans la colonne URL affichant un lien permet d’accéder au site de téléchargement du Master ou du Hotfix concerné.
