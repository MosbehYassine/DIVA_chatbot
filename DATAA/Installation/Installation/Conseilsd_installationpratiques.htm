Conseils d'installation pratiques

  • Dans la table des serveurs de fichiers Harmony, identifiez les serveurs par leur nom NetBios (nom qui apparaît dans le voisinage réseau).

  • Centralisez la gestion des utilisateurs et des chemins implicites.
    Dans le chapitre [System] de Divalto.ini des clients du serveur de fichiers (serveurs d'applications ou postes fonctionnant en mode local), ajoutez la ligne :
    ServeurXlogf=nom_du_serveur
    Remarque : la gestion des serveurs et des chemins Harmony ne peut pas être centralisée.

  • Il est généralement inutile de créer des chemins Harmony sur les postes autonomes ou les clients d'un serveur de fichiers. Réservez les chemins Harmony aux serveurs Xlan.

  • Limitez au maximum le nombre de fichiers de chemins implicites. Pour cela, affectez le même fichier aux utilisateurs qui exécutent les mêmes applications.
    Utilisez le fichier d'implicites par défaut ImplicitesDefaut.txt pour les utilisateurs "majoritaires". Créez de nouveaux fichiers uniquement pour les autres utilisateurs.
