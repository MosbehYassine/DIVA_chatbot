Principes généraux du développement d'un widget

 

Initialisation

 

La plupart des types de widgets possède une fonction d'initialisation.

Cette fonction est appelée une seule fois dans la vie du widget, au moment de son ajout dans la grille (ou au chargement de l'interface d'accueil pour un widget déjà placé en grille).

Elle sert à faire les initialisations nécessaires au calcul des valeurs. Elle peut également renvoyer immédiatement les valeurs du widget.

 

Function String InitWidget (&Widget)

Record a5dd.dhsd MWidget Widget

Beginf

    freturn ""

Endf

 

 

Mise à jour

 

Certains types de widgets possèdent une fonction de mise à jour associée à une fréquence de rafraîchissement.

Cette fonction est appelée selon la fréquence renseignée.

Elle sert à mettre périodiquement à jour les valeurs affichées par le widget.

 

Function String UpdateWidget (&Widget)

Record a5dd.dhsd MWidget Widget

Beginf

    freturn ""

Endf

 

 

Action utilisateur

 

Certains types de widgets possèdent une procédure d'action.

Cette procédure est appelée lorsque l'utilisateur double clique sur un élément du widget.

 

Procedure ActionWidget (&Widget, DivaId)

Record a5dd.dhsd MWidget Widget

1      DivaId    S

Beginp

Endp

 

 

Paramètres et valeur renvoyée

 

Toutes les fonctions et procédures prennent en paramètre l'enregistrement associé au widget (enregistrement MWIDGET du dictionnaire A5DD.DHSD).

Les fonctions renvoient une chaîne au format HMP contenant les données à afficher.

 

Attention : Chaque type de widgets possède ses propres balises HMP.

 

 

Paramétrage du widget

 

Les paramètres du widget renseignés dans la zone "Paramètres" du Zoom des widgets sont placés dans la zone MWIDGET.MSG.
