Saisie des données

Nous distinguerons les types de donnée suivants :

  • Les données "simples" ou champs.
    Pour les saisir, il faut taper les caractères qui les composent au clavier. Si une valeur est déjà proposée, Tab ou Flèche en bas permet de la conserver.

  • Les multi-choix.
    Il faut ici sélectionner un choix parmi une liste de valeurs prédéfinies. Le concepteur du masque présente le multi-choix "ouvert" ou "fermé" :
    - Ouvert, un tableau affiche la liste des valeurs possibles.
    - Fermé, seule la valeur courante est affichée.
    Dans ce second cas, le concepteur choisit aussi si le positionnement du curseur sur le multi-choix provoque ou non son ouverture immédiate.

  • Les cases à cocher.
    Ces données sont représentées à l'écran par un petit carré et l'option ou la valeur qu'elles symbolisent est validée lorsque la case est cochée.

  • Les groupes de radio-boutons.
    Un bouton radio est représenté à l'écran par un petit cercle et l'option ou la valeur qu'il symbolise est validée lorsque le bouton est coché (cercle plein). Il n'existe pas de bouton radio isolé (il ferait doublon avec une case à cocher) mais deux ou plusieurs boutons radio peuvent être réunis pour former un groupe de radio-boutons. Un et un seul des boutons du groupe est valide à un instant donné : si l'on coche un autre bouton du groupe, le bouton précédemment coché est automatiquement invalidé.

  • Les textes riches, dont la saisie (ou la consultation) fait appel à l'éditeur de textes graphique.

 

Attention : La saisie d'une donnée de type champ, multi-choix, case à cocher ou groupe de radio-boutons est invalidée (la donnée retrouve automatiquement sa valeur précédente) si vous remontez dans le masque par la touche Back-Tab, Flèche en haut ou Page Précédente. Par contre, un clic souris sur une variable précédente conserve à la donnée sa nouvelle valeur.
