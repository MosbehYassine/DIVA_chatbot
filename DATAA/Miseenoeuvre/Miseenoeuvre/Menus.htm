Menus

L'utilisation des menus Windows vous est sans doute familière. Aussi n'en détaillerons-nous pas ici la mise en œuvre (consultez au besoin la documentation Windows). Toutefois, rappelons-en rapidement les principes de base. Les menus Windows peuvent être de deux types :

  • Les menus "classiques".
    Un menu classique se présente sous la forme d'une "barre de menu" horizontale, affichée en haut de la fenêtre courante. Il est généralement accessible à tout moment.

  • Les menus contextuels.
    Un menu contextuel (aussi appelé menu "surgissant") est présenté verticalement dans une fenêtre spécifique. Pour y avoir accès, il faut en général cliquer avec le bouton droit de la souris sur une zone ou une donnée particulière du masque.

 

Dans un menu, on distingue plusieurs types de choix :

  • Choix en-tête de sous-menu.
    Sa sélection fait apparaître un sous-menu à l'écran. Hormis les choix principaux de menu classique, on reconnaît ce type de choix par le signe > affiché derrière le texte du choix. Si le choix apparaît grisé à l'écran, l'ensemble du sous-menu devient inaccessible. Cela signifie que les fonctions commandées par ce sous-menu ne sont pas disponibles.

  • Choix terminal.
    Sa sélection provoque l'appel d'une fonction de l'application. Si le choix apparaît grisé à l'écran, cela signifie que cette fonction n'est pas disponible.

  • Option de l'application.
    Sa sélection permet l'activation ou la désactivation d'une option du programme. Lorsque l'option est activée, le choix est « coché » ; on distingue alors :
    - Les choix "isolés" non exclusifs : si le texte du choix est accompagné d’une image, celle-ci est entourée d’un cadre « enfoncé » ; sinon, une coche ayant la forme d'un v est dessinée.
    - Les groupes de choix exclusifs : dans un tel groupe, un seul choix peut être coché à la fois ; si le texte du choix coché est accompagné d’une image, celle-ci est entourée d’un cadre « enfoncé » ; sinon, une coche de forme ronde (o) est dessinée.

 

Quelque soit le type de choix, une touche de raccourci peut lui être associée.
