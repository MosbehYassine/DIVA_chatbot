Zonage (version 6)

 

Le zonage d’un objet tableau consiste à colorer globalement un groupe de lignes sur deux pour faciliter la lecture de ce tableau. Par exemple, on pourra colorer 1 ligne sur deux, deux lignes sur cinq ou modifier la couleur des lignes lorsque la valeur d’une colonne change pour marquer une rupture. La couleur de zonage utilisée pour une cellule du tableau est automatiquement calculée pour différer légèrement de la couleur de base de cette cellule.

C’est le programmeur qui décide du type de zonage dans l’éditeur de masques d’écran Xwin. S’il a demandé un zonage « par défaut », vous pouvez le paramétrer en sélectionnant le choix Zonage tableau et Couleur du menu système Windows d'une fenêtre Harmony :

  • Zonage actif
    Option d'activation du zonage.

  • Nombre de lignes non colorées / colorées
    Précisent comment doit se faire l'alternance des lignes colorées et non colorées.
