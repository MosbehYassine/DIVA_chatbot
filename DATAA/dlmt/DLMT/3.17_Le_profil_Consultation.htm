Le profil Consultation

Le profil « Consultation uniquement » permet d’accéder aux mêmes fonctionnalités de l’ERP que le profil administrateur, mais uniquement en consultation. Aucune création, modification ou suppression de données n’est alors autorisée.

Les choix de menus, les boutons de barres d’outils (et les raccourcis clavier correspondants) permettant d’accéder à des fonctionnalités de création, de modification ou de suppression de données sont alors inopérants.
