Ligne d'état

Le titre de la barre d'outils et de format vous renseigne sur l'état du texte édité. On y trouve successivement :

  • Le nom du fichier où est stocké le texte.
    Le texte peut être simplement rangé en mémoire. Dans ce cas, aucun nom n'apparaît.

  • Eventuellement une étoile (*). Sa présence indique que le texte a été modifié depuis la dernière sauvegarde.

  • Entre parenthèses, le type du texte édité :
    RTF     (Rich Text File), si le texte est "riche".
    TXT     si le texte est "simple".
