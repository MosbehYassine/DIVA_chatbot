Notions de base pour l'envoi de fax ou de message

Pour envoyer un fax ou un message, un outil de messagerie a besoin de connaître les informations suivantes :

  • L'adresse du destinataire.
    C'est par exemple son adresse Mail, son adresse Internet ou le numéro de son fax.
     

  • Le type de transport à utiliser pour envoyer le message à cette adresse.
    Le type de transport indique quel "driver" doit être utilisé pour envoyer le message. Il peut être différent d'un poste à un autre et ne doit donc pas être stocké avec l'adresse du destinataire. Il faut paramétrer localement DivaltoViewer pour que celui-ci sache faire le lien avec le bon "driver de message".
    Ce lien est contenu dans ce que nous appellerons l'adresse finale du destinataire, qui va donc contenir l'adresse du destinataire proprement dite et le type de transport à utiliser.
     
    Exemple d'un     envoi de fax par le gestionnaire de fax de Windows :
    Le gestionnaire utilise des adresses finales du type :
    [FAX: numéro de téléphone du fax]
    ou
    [FAX: nom du destinataire @ numéro de téléphone du fax]
     
    Si nous voulons envoyer un fax au numéro "03 88 01 02 03" ou "paul@03 88 01 02 03", il faudra que DivaltoViewer construise une adresse finale du type :
    [FAX:03 88 01 02 03]
    ou
    [FAX:paul@03 88 01 02 03]
     
    Exemple     d'un envoi de message à l'adresse "paul@wanadoo.fr" avec la messagerie Internet :
    Celle-ci utilise des adresses finales de type :
    [SMTP: adresse Internet]
    L'adresse finale sera ici :
    [SMTP: paul@wanadoo.fr]
     

  • Le nom du profil de messagerie à utiliser ainsi que le mot de passe s'il existe.
    Un client de messagerie comme Outlook permet généralement de créer plusieurs profils avec des paramètres différents.

    Exemple     : Dans les paramètres du fax pour un profil, on peut indiquer si le fax doit être envoyé "Dès que possible" ou "A partir d'une certaine heure". On peut aussi envoyer ou non une "Page de garde" devant chaque fax.
    On peut donc créer un profil dédié à DivaltoViewer, avec d'autres paramètres que le profil par défaut, demandant par exemple de ne pas envoyer de page de garde et/ou d'envoyer les fax Divalto à partir d'une certaine heure.

DivaltoViewer permet de paramétrer ces informations afin de pouvoir construire l'adresse finale d'un destinataire et se connecter à la messagerie.
