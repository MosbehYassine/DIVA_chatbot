Relecture d'un fichier de sauvegarde

Pour recharger un état préalablement sauvegardé, activez le choix du menu <Fichier : Ouvrir>. Ce choix appelle la fenêtre d'ouverture de fichier standard de Windows : sélectionnez le nom du fichier contenant l'état désiré. Par défaut, DivaltoViewer propose toujours le dernier fichier sauvegardé.
