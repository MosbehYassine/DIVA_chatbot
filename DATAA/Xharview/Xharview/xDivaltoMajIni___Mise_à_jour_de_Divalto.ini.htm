xDivaltoMajIni : Mise à jour de Divalto.ini

 

xDivaltoMajIni.exe est l'utilitaire qui DOIT être utilisé pour modifier un élément "Divalto" de la base de registre.

Il propose les choix de menu suivants :

  • Fichier

    • Voir les groupes Divalto_ de cet utilisateur / Voir tous les groupes de cet utilisateur.
      Ces choix affichent les groupes d'appartenance de l'utilisateur dans la base des utilisateurs de Windows.

      Saisir un nom de groupe à ajouter dans la propagation.
      Ce choix affiche une boîte de dialogue qui permet de saisir une liste de groupes vers lesquels on souhaite propager les modifications.

      Pour plus de détails, consultez la rubrique Installation d'un serveur multi-bases.
       

    • Connexion au serveur du client léger.
      Permet de travailler sur la base de registre du serveur d'applications.
       

    • Déconnexion du serveur du client léger.
      Permet de travailler sur la base de registre locale.
       

    • Quitter.

       

  • Lecture (sélection de la section à modifier)

    • Base de registre locale à l'utilisateur (HKEY_CURRENT_USER).
      Sélectionnez ce choix pour mettre à jour les paramètres propres à chaque utilisateur.

      Chaque utilisateur dispose de sa propre section      . Les modifications apportées le sont par défaut pour l'utilisateur courant.

      Il est également possible de les répercuter pour d'autres comptes d'utilisateur (voir paragraphe "Propagation des modifications sur d'autres postes du serveur d'applications ci-dessous").
       

    • Base de registre globale à l'ordinateur (HKEY_LOCAL_MACHINE).
      Sélectionnez ce choix pour mettre à jour les paramètres généraux non spécifiques à l'utilisateur.

      Remarque       : xDivaltoMajIni doit ici être exécuté en mode administrateur. A défaut, les valeurs visualisées et éventuellement modifiées ne seront pas les valeurs réelles mais une copie de celles-ci. Le cas échéant, xDivaltoMajIni affiche donc un message pour signaler qu'il n'a pas les droits suffisants et vous propose de le relancer avec les droits de l'administrateur.
       

    • Base de registre de l'utilisateur "Compte système local" (HKEY_USERS).
      Sélectionnez ce choix pour mettre à jour les paramètres qui prévalent quand un nouvel utilisateur ouvre une session sans avoir de profil utilisateur propre (c'est en particulier le cas des services qui tournent sous le compte système local, comme par exemple les services Divalto DhsDivaAgent et DhsServices).
       

    • Avec / Sans filtrage des chapitres.
      Par défaut (avec filtrage), les chapitres gérés "en interne" (par exemple les chapitres propres à Xwin) ne sont pas affichés.
      Si vous sélectionnez le choix sans filtrage, tous les chapitres de la section Divalto.ini seront présentés. Il est fortement déconseillé de modifier le contenu des clés "internes".

 

Propagation des modifications sur d'autres postes du serveur d'applications

xDivaltoMajIni stocke les paramètres propres à un utilisateur dans Divalto.ini. Cette section de la base de registre est liée à l'utilisateur en cours. Suite à une modification, xDivaltoMajIni propose de propager (*) les changements que vous effectuez à tout ou partie des utilisateurs du même serveur :

  • En cas de réponse négative, les nouveaux paramètres ne concerneront que l'utilisateur courant (seul son Divalto.ini sera modifié).
     

  • Sinon, les nouveaux paramètres seront copiés dans tout ou partie des Divalto.ini du serveur.
    Pour plus de détails, consultez la rubrique Installation d'un serveur multi-bases.

    Remarque :     la copie dans la section Divalto.ini d'un autre utilisateur déjà connecté n'est pas instantanée. Elle se fera lorsque cet utilisateur cliquera sur le bouton Réactualiser dans les Options Avancées de la boîte de connexion. A défaut, la copie se fera lorsque l'utilisateur se reconnectera au serveur et à condition qu'une heure se soit écoulée depuis sa dernière connexion.

(*) ATTENTION : cette fonctionnalité est uniquement disponible si vous lancez l'utilitaire par la commande <Exécuter> du menu Démarrer de Windows avec le paramètre /propager :

xDivaltoMajIni.exe /propager
 

 

Utilisation de xDivaltoMajIni

  • Cliquez sur la case + en regard d'un chapitre pour développer ce chapitre et afficher ses clés.
    Cliquez sur la case – pour le refermer.

  • Pour créer un nouveau chapitre (avec une première clé), positionnez-vous sur un chapitre existant, tapez Inser et sélectionnez le choix "Ajouter un chapitre".
    Pour créer une nouvelle clé dans un chapitre donné, positionnez-vous sur ce chapitre, tapez Inser et sélectionnez le choix "Ajouter une valeur" ou alors positionnez-vous sur une clé existante de ce chapitre et tapez Inser.
    Après validation, la clé est marquée comme étant à créer. La création effective aura lieu lorsque vous quitterez le programme. Pour annuler une création, positionnez-vous sur la ligne concernée et tapez la touche Echap.

  • Pour modifier une clé existante, positionnez-vous sur cette clé et tapez Entrée ou double-cliquez sur la ligne concernée. Après validation, la clé est marquée comme étant à modifier. La modification effective aura lieu lorsque vous quitterez le programme. Pour annuler une modification, positionnez-vous sur la ligne concernée et tapez la touche Echap.

  • Pour supprimer un chapitre ou une clé existant, positionnez-vous sur ce chapitre ou sur cette clé et tapez Suppr. Après validation, le chapitre ou la clé est marqué comme étant à supprimer. La suppression effective aura lieu lorsque vous quitterez le programme. Pour annuler une suppression, positionnez-vous sur la ligne concernée et tapez la touche Echap.

 

Fonctions de traitement des anciens fichiers Divalto.ini

A partir de la version 6.2 d'Harmony, le contenu des fichiers Divalto.ini est transféré dans la base de registre de Windows.

A condition de lancer l'utilitaire par la commande <Exécuter> du menu Démarrer de Windows avec le paramètre /a (xDivaltoMajini.exe /a), vous avez accès à de nouveaux choix au menu, permettant de lire un fichier Divalto.ini (choix Lecture : De l'ancien Divalto.ini) ou de charger un fichier dans la base de registre (choix du menu Chargement).
