Pour compiler un programme Diva

Pour compiler les sources modifiés du sous-projet courant :

  • Sélectionnez le choix Construire le sous-projet du menu Projet (raccourci clavier : F10)
    Ou
    Cliquez     sur le bouton de la barre d'outils.

 

Pour compiler un source isolé du sous-projet courant :

  1. Activez la fenêtre contenant ce source.

  2. Sélectionnez le choix Compiler du menu Projet (raccourci clavier : Maj+F10)
    Ou
    Cliquez     sur le bouton de la barre d'outils.

 

Pour compiler les sources modifiés du projet courant :

  • Sélectionnez le choix Construire le Projet du menu Projet.

 

Pour recompiler tous les sources du sous-projet courant :

  • Sélectionnez le choix Reconstruire Tout le Sous-projet du menu Projet.

 

Pour recompiler tous les sources du projet courant :

  • Sélectionnez le choix Reconstruire Tout le Projet du menu Projet.

 

Pour compiler un programme (hors projet) :

  1. Si vous N'avez PAS précisé le nom du source à compiler dans les options de compilation, activez la fenêtre contenant le source à compiler (si vous avez précisé le nom du source dans les options de compilation, vous n'êtes pas obligé d'activer cette fenêtre).

  2. Sélectionnez le choix Compiler du menu Projet (raccourci clavier : Maj+F10).
    Ou
    Cliquez     sur le bouton de la barre d'outils.

 

Remarques :

  • Lorsque la fenêtre « Compte rendu » est en mode « Masquage automatique », le lancement d’une compilation ouvre la fenêtre pour vous permettre de consulter les éventuelles erreurs et lui transfert le focus pour qu’elle ne se referme pas immédiatement. Pour redonner rapidement le focus à la fenêtre d’édition Mdi, tapez la touche Echap.

  • Au lancement d'une compilation, Xwin sauvegarde automatiquement TOUS les fichiers source édités modifiés.

  • Pour pouvoir utiliser le débogueur, votre programme doit être compilé en mode " débogueur ".
