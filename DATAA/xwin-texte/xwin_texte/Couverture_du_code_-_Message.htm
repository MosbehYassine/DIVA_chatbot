Couverture du code - Message

 

Cette boîte de dialogue est affichée lorsque la fonction de couverture du code détecte une anomalie. Le message d'anomalie est également placé dans la fenêtre de l'onglet "Messages" (de manière permanente).

 

Si vous décochez la case Ne plus afficher cette boîte de dialogue, les anomalies suivantes n'ouvriront plus la boîte et seront uniquement répertoriées dans l'onglet "Messages".

Le choix Afficher la boîte de dialogue des messages du sous-menu Couverture du code (menu Déboguer ou menu contextuel de l'éditeur de textes) doit être utilisé pour rétablir l'affichage de la boîte.



Remarque : Le contenu de la fenêtre "Messages" peut être effacé : cliquez droit dans la barre de titre de l'onglet et sélectionnez le choix Effacer du menu contextuel.
