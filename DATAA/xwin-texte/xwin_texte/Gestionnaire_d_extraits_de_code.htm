Gestionnaire d'extraits de code

Pour pouvoir insérer des extraits de code personnalisés dans vos programmes, vous devez d'abord constituer vos fichiers d'extrait de code et les stocker dans des dossiers spécifiques.

 

Vous devez aussi répertorier le ou les dossiers de stockage de vos fichiers personnels, à l'aide du gestionnaire d’extraits de code, accessible par le choix correspondant du menu Outils.
 

Conseil : Pour améliorer les performances, stockez uniquement des fichiers d'extrait de code dans les dossiers que vous avez spécifiés avec le gestionnaire d'extraits de code.

 

Ce choix du menu ouvre une boîte de dialogue vous permettant d'ajouter ou de retirer des éléments à la liste des dossiers qui vous sera proposée à l'ouverture du sélecteur d'extraits de code.


Si vous expansez un dossier dans l'arbre affiché dans le cadre de gauche, vous affichez la liste de tous les fichiers d'extraits de code contenus par ce dossier (remarque : Xwin ne fait pas de recherche dans les sous-dossiers ; le cas échéant, ajoutez les sous-dossiers à la liste).

Si vous sélectionnez un de ces fichiers, vous affichez dans le cadre de droite toutes les informations sur ce fichier (identifiant, auteur, descriptif et code source). Vous pouvez alors cliquer sur le bouton Editer pour charger le fichier sélectionné dans Xwin.
