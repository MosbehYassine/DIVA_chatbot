Pour annuler tous les points d'arrêt

  1. Sélectionnez le choix Points d'arrêt du menu Déboguer
    (raccourci clavier : Maj+Ctrl+B).
    La boîte de dialogue " Points d'arrêt " apparaît.

  2. Cliquez sur le bouton Tout Supprimer.

  3. Cliquez sur le bouton OK.
