Utiliser la fenêtre Dictionnaires

L'écran de Xwin contient une barre d'onglets Comptes rendus, située sous la zone d'affichage des fenêtres MDI. En phase de mise au point, le volet Dictionnaires affiche les dictionnaires Diva créés par le programme.

 

Afficher la fenêtre Dictionnaires

Pour faire apparaître la fenêtre " Dictionnaires " à l'écran, en phase de mise au point :

  • Cliquez sur l'onglet Dictionnaires. Si cet onglet n’apparaît pas, la fenêtre est ancrée et donc déjà affichée.
     

  • Ou sélectionnez le choix Dictionnaires du menu Déboguer : Fenêtres du débogueur.

  • Ou cliquez sur le bouton de la barre d'outils du débogueur.

Nota : Vous disposez de nombreuses possibilités pour afficher cette fenêtre à votre convenance : ancrage permanent, déplacement à l’écran, ajustement de sa taille, etc. Pour plus de détails, consultez la rubrique barre d'onglets Comptes rendus.

 

Contenu de la fenêtre Dictionnaires

La fenêtre affiche une ligne par dictionnaire Diva créé par le programme en cours. Pour chaque dictionnaire, vous trouvez les renseignements suivants :

<ticket> : <élément courant> / <nombre d'éléments> = <valeur>
 

<ticket>

Valeur du ticket associé au dictionnaire.

<élément courant>

Position de l'élément courant (à partir de 1).

<nombre d'éléments>

Nombre d'éléments.

<valeur>

Valeur de l'élément courant.

 

 

Consulter un dictionnaire Diva

Double-cliquez sur la ligne représentant le dictionnaire à examiner. Une boîte de dialogue est affichée pour vous permettre de visualiser ses éléments.

 

La boîte donne les renseignements suivants :
 

Numéro

Valeur du ticket associé au dictionnaire.

Courant / nombre d'éléments

Position de l'élément actuellement sélectionné (à partir de 1) / nombre d'éléments total.

Position / courant

Position / adresse de l'élément courant au moment de l'arrêt du programme.

Instance de

Lorsque le débogueur connaît la structure de l'élément, il affiche ici le nom du dictionnaire de données et le nom de l'enregistrement ; dans ce cas, l'élément est automatiquement expansé (ses données composantes sont affichées).
Sinon, voir la paragraphe " Si l'élément n'est pas automatiquement expansé " ci-dessous.
 

La fenêtre affiche le contenu de l'élément sélectionné, surmonté de la clé.

 

Pour vous déplacer dans la liste

Utilisez l'ascenseur ou les différents boutons :

Premier élément.

Elément précédent.

Elément courant au moment de l'arrêt du programme.

Elément suivant.

Dernier élément.

Clé.

 

Si l'élément n'est pas automatiquement expansé

Si les champs qui composent l'élément ne sont pas affichés, cela signifie que le débogueur ne sait pas déterminer "tout seul" la structure de l'élément.

Pour expanser l'élément, cliquez sur le bouton Changer le type puis entrez le nom du dictionnaire et le nom de l'enregistrement concerné.
