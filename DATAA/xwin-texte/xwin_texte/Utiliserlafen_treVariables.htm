Utiliser la fenêtre Variables

L'écran de Xwin contient une barre d'onglets Comptes rendus, située sous la zone d'affichage des fenêtres MDI. En phase de mise au point, le volet Variables affiche la valeur des données que vous y avez placées. Les valeurs sont actualisées à chaque arrêt du programme.

 

Afficher la fenêtre Variables

Pour faire apparaître la fenêtre Variables à l'écran, en phase de mise au point :

  • Cliquez sur l'onglet Variables. Si cet onglet n’apparaît pas, la fenêtre est ancrée et donc déjà affichée.
     

  • Ou sélectionnez le choix Variables du menu Déboguer : Fenêtres du débogueur.

  • Ou cliquez sur le bouton de la barre d'outils du débogueur.

Nota : Vous disposez de nombreuses possibilités pour afficher cette fenêtre à votre convenance : ancrage permanent, déplacement à l’écran, ajustement de sa taille, etc. Pour plus de détails, consultez la rubrique barre d'onglets Comptes rendus.

 

 

Placer une donnée dans la fenêtre Variables

Placez dans la fenêtre Variables les données que vous consultez souvent à un instant donné. Pour cela :

  • Utilisez le bouton "Ajouter aux variables" dans la boîte de dialogue "Consulter / Modifier une variable".

  • Ou sélectionnez le choix "Ajouter à la liste des variables" du menu surgissant contextuel de l'éditeur de textes (pour le faire apparaître, cliquez droit sur le nom de la variable dans le source) ou d'une fenêtre de débogage rapide.

 

Expanser un enregistrement ou un tableau dans la fenêtre Variables

Lorsque la variable est un enregistrement, vous pouvez visualiser les données qui le constituent. De même, vous pouvez visualiser les éléments d'un tableau :

  • Le signe plus (+) apparaît initialement en première colonne de la ligne affichant le nom de la structure. Si vous double-cliquez sur cette ligne, la structure est "expansée" (les données de l'enregistrement ou les éléments du tableau sont affichés).

  • A partir de là, c'est le signe moins (-) qui apparaît en première colonne. Si vous double-cliquez sur la ligne une nouvelle fois, la structure est "réduite" (les sous-données disparaissent de la liste).

 

Supprimer une donnée de la fenêtre Variables

Lorsqu'une donnée que vous avez placée dans la fenêtre Variables ne vous intéresse plus, ôtez-la de la liste. Pour cela :

  • Sélectionnez la ligne correspondante et tapez la touche Suppr.
