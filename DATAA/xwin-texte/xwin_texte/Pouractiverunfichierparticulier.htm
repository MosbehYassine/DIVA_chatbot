Pour activer un fichier particulier

 

Méthode 1 :

  • En mode cascade ou mosaïque, cliquez n'importe où dans la fenêtre affichant le fichier désiré.

 

Méthode 2 :

  • Cliquez sur l’onglet correspondant dans la barre d’onglets « Fichiers ».

 

Méthode 3 :

  • Sélectionnez le nom du fichier désiré en bas du menu Fenêtre. S'il n'apparaît pas dans les neuf premiers noms, activez d'abord le choix Plus de Fenêtres… puis cherchez le fichier dans la liste de la boîte Sélection d'une fenêtre.

 

Méthode 4 :

  • Tapez la touche Ctrl+Tab ou Maj+Ctrl+Tab.
    Une fenêtre affichant la liste des fichiers actifs est ouverte (attention, cette fenêtre se referme dès que vous relâchez la touche Ctrl).
    Pour vous déplacer dans la liste, utilisez les ascenseurs, la molette de la souris ou le clavier (touches Ctrl+Tab, Maj+Ctrl+Tab, Ctrl+Flèches, Ctrl+Page-Up/Down).
    Vous pouvez vous rendre directement sur un source donné en cliquant sur son nom, ou en le sélectionnant dans la liste puis en relâchant la touche Ctrl.

 

Méthode 5 :

  • Activez le choix Liste des fichiers chargés du menu Fenêtre (raccourci clavier F6). Double-cliquez sur son nom dans la liste affichée ou sélectionnez son nom et cliquez sur le bouton Ok.
