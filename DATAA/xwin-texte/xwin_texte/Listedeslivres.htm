Liste des livres de l'aide Xwin

Le choix Editeurs du menu Aide de Xwin donne accès aux livres suivants (onglet Sommaire de l'aide) :

Utiliser l'aide en ligne

Comment et où trouver l'information ; parcours des fenêtres d'aide ; organisation générale de la documentation.

Utiliser l'atelier Xwin
(manuel de référence &
instructions pas à pas)

Compilation des programmes et des masques (hors projet) ; exécution des programmes (hors projet) ; contrôle des fenêtres d'édition.

Utiliser l'éditeur de textes
(manuel de référence &
instructions pas à pas)

Gestion des fichiers source ; parcours d'un source ; fonctions d'édition ; configuration de l'éditeur ; menus, barre d'outils et raccourcis clavier.

Utiliser le débogueur
(manuel de référence &
instructions pas à pas)

Techniques de mise au point des programmes Diva (points d'arrêt, consultation et modification des données, pile des fonctions, historique) ; menus, barre d'outils et raccourcis clavier.

Dictionnaires :
Concepts généraux

Hiérarchie ; tables, bases, champs et sous-champs, index ; natures de donnée ; protection ; surcharge ; etc.

Utiliser l'éditeur de
dictionnaire
(manuel de référence)

Description de l’écran ; fonctions d’édition ; barres d’outils et raccourcis clavier ; boîtes de dialogue ; etc.

Masques écran :
Concepts généraux

Masques mono et multi écran ; pages et fenêtres ; aides ; points d'arrêt et de traitement ; pièges de touche ; points de séquence ; attachements ; polices et couleurs ; etc.

Utiliser l'éditeur de
masques écran
(manuel de référence)

Gestion des fichiers source ; parcours d'un source ; fonctions d'édition ; menus, barre d'outils et raccourcis clavier ; étapes de la création d'un masque ; feuille de styles ; paramétrage ; etc.

Masques imprimante :
Concepts généraux

Mise en page ; mode WYSIWYG ; notion de bloc ; points d'arrêt et de traitement ; adresses de destination ; formats ; etc.

Utiliser l'éditeur de
masques imprimante
(manuel de référence)

Menu ; étapes de la création d'un masque ; paramétrage ; etc.

Utiliser l'éditeur de
ressources
(manuel de référence)

Fonctions d'édition des ressources (menus et barres d’outils).

Utiliser l'éditeur de
menus
(manuel de référence)

Fonctions d'édition des menus.

Utiliser l'éditeur de
barres d’outils
(manuel de référence)

Fonctions d'édition des barres d'outils.

Utiliser les projets
(manuel de référence)

Fenêtre des projets, gestion des projets, compilation et exécution des programmes et des masques ; navigation ; surcharge ; etc.

 

Le choix Programmation du menu Aide de Xwin donne accès aux livres suivants :

Diva : Techniques de programmation

Modules et programmes ; tunnels ; enchaînements et appels de programme ; lancement de programmes Windows ; etc.

Diva
(manuel de référence)

Structure des programmes ; manuel de référence des instructions, procédures et fonctions du langage ; gestion de fichiers Harmony ; gestion des listes ; etc.

RecordSql

Description de l'objet RecordSql.

Ywpf, exécuteur de
masques d'écran 1 & 2
(manuel de référence)

Instructions d'appel à Ywpf ; programmation de la saisie d'un masque ; programmation des objets spéciaux (textes riches, ascenseurs, onglets, menus, barres d’outils, tableaux, arbres, …) ; entrées clavier ; pilotage de saisie de masques ; etc.

Ymig, exécuteur de
masques d'imprimante
(manuel de référence)

Instructions d'appel à Ymig ; pagination des états ; programmation de l'impression d'un masque ; etc.

Yweb, exécuteur de
masques Web
(manuel de référence)

Instructions d'appel à Yweb ; programmation des masques Web ; etc.

Zoom SQL et Zoom Web
(manuel de référence)

Organisation générale ; masques Xwin ; fonctions du module Diva ; mise en œuvre ; etc.

Aides fenêtrées
(manuel de référence)

Aide au format Harmony ; aide au format Windows ; conversion des aides Harmony en aides Windows.

HQL
(manuel de référence)

Outil facilitant la programmation d'états d'impression ; tri ; ruptures ; comptages ; etc.

Interface Windows

Fonctions d’interface avec le système Windows : drag & drop ; Cti ; surveillance des répertoires ; fermeture de session ; etc.
