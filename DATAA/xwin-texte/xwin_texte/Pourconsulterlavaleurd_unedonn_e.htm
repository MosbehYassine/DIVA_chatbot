Pour consulter la valeur d'une donnée

Pour visualiser ponctuellement la valeur d'une donnée :

 
En ligne d'état :

  • Cliquez sur le nom de la variable dans le source.
    Sa valeur est affichée sur la ligne d'état.

 

Dans la fenêtre de débogage rapide :

  • Faites stationner la souris sur le nom de la variable dans le source.
    Sa valeur est affichée dans une fenêtre, ouverte à la manière d'une bulle.

 

Dans la boîte de dialogue de consultation d'une variable :

  1. Placez le curseur sur la variable ou sélectionnez-la dans votre source.

  2. Validez le choix Consulter / Modifier une variable du menu Déboguer (raccourci clavier : Maj+Ctrl+F8) ou cliquez sur le bouton de la barre d'outils du débogueur.
    La boîte de dialogue "Consulter / Modifier une variable" apparaît.

 

Pour disposer d'une valeur constamment actualisée, il faut placer la variable dans la fenêtre "Variables". Pour ce faire, consultez la rubrique :

Pour ajouter une donnée dans la fenêtre des variables

 

Pour visualiser automatiquement les variables nommées dans les dernières instructions exécutées, affichez la fenêtre "Contexte". Cette fenêtre affiche aussi la valeur rendue par une fonction au retour de celle-ci.
