Parcourir les fenêtres MDI

Pour passer d'une fenêtre MDI à une autre :

  • En mode cascade ou mosaïque, cliquez n'importe où dans la fenêtre choisie.

  • Ou cliquez sur l’onglet correspondant dans la barre d'onglets « Fichiers ».

  • Ou sélectionnez son nom dans le menu Fenêtre.

  • Ou tapez (Maj+)Ctrl+Tab puis sélectionnez son nom dans la liste des fichiers actifs.

  • Ou activez le choix Liste des fichiers chargés du menu Fenêtre (raccourci clavier F6) puis double-cliquez sur son nom dans la liste affichée (ou sélectionnez son nom et cliquez sur le bouton Ok).

 

Les raccourcis clavier Ctrl+Tab et Maj+Ctrl+Tab (Ctrl+F6 et Maj+Ctrl+F6 sont également possibles) fonctionnent précisément de la manière suivante :

  • Si vous tapez Ctrl+Tab (respectivement Maj+Ctrl+Tab) à plusieurs reprises SANS lâcher la touche Ctrl, vous balayez circulairement les différentes fenêtres, dans un sens (respectivement dans l'autre).

  • Si vous relâchez la touche Ctrl puis tapez à nouveau Ctrl+Tab, vous revenez à la dernière fenêtre active.
