Pour imprimer un fichier source complet

  1. Activez la fenêtre contenant le source.

  2. Sélectionnez le choix Imprimer du menu Fichier (raccourci clavier : Ctrl+P).
    La boîte de dialogue " Imprimer " apparaît.

  3. Choisissez l'option de portée Tout.

  4. Au besoin, modifiez les options de mise en page.

  5. Validez par OK.
