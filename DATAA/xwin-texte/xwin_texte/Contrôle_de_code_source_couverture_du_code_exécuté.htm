Couverture du code exécuté

 

La couverture du code est une puissante fonctionnalité du débogueur de Xwin. Lorsqu'elle est activée, ce dernier marque toutes les instructions du programme qui ont été exécutées, à l'occasion d'un ou plusieurs tests. Dans vos sources, les lignes effectivement exécutées (ainsi que toutes les lignes ne contenant pas de code exécutable Diva) font alors l'objet d'une coloration spécifique, avec pour conséquence que :
 

Les lignes non coloriées n'ont jamais été exécutées.
 

Vous pouvez ainsi mesurer visuellement l'efficacité de vos tests, ligne par ligne ou bloc par bloc, en repérant facilement les endroits où votre programme n’est jamais passé. Relancez de nouveaux tests en conséquence, avec pour objectif de vous assurer que toutes les instructions ont été exécutées au moins à une reprise.

Bien entendu, le fait d'avoir emprunté tous les chemins possibles NE signifie PAS que votre programme ne comporte aucun bogue mais permet certainement d'éliminer une part non négligeable de bogues triviaux.

 

 

Vocabulaire employé pour la couverture du code

  • Une instruction exécutée en mode "Couverture du code" est dite "tracée".
    Remarque : à un instant donné, sont uniquement tracées les instructions des sources du sous-projet courant.

  • Dans le source, la ligne de code correspondante est dite "couverte".
    Remarque : Xwin détecte si tout ou seulement partie des éléments de la ligne a été exécuté. On distinguera donc les lignes "totalement" ou "partiellement" couvertes.

Remarque :

La couverture de code ne doit pas être confondue avec l'historique de l'exécution du programme (le débogueur de Xwin conserve l'historique des 500 dernières instructions exécutées ; à l'occasion d'un arrêt du programme, vous pouvez l'utiliser pour vérifier "par où est passé" votre programme avant son interruption).
