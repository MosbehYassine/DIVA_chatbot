Colorisation des lignes couvertes

 

Quand les lignes couvertes sont-elles coloriées ? 

  • Activation manuelle : vous pouvez à tout moment activer ou désactiver la colorisation spécifique à la couverture du code, grâce au choix Colorier les lignes couvertes du sous-menu Couverture du code (menu Déboguer ou menu contextuel de l'éditeur de textes) ou grâce au bouton de la barre d'outils de l'éditeur de textes (raccourci clavier Ctrl+F9).
     

  • Activation / désactivation automatique : de plus, une option de Xwin (non validée par défaut) permet de passer automatiquement en mode "Colorier les lignes couvertes" au lancement de l'exécution d'un programme en mode débogueur, et de revenir automatiquement en mode normal lorsque l'exécution du programme se termine (Cf. rubrique Configuration de la couverture du code). Remarque : si cette option est validée, une (dés)activation manuelle reste toujours possible.

 

Comment les lignes couvertes sont-elles coloriées ?

 

Les instructions composées étant prises en compte, deux couleurs sont utilisées pour indiquer si une ligne de code a été couverte :

  • La première couleur (intitulée "Ligne totalement couverte") est appliquée aux lignes dont toutes les composantes ont été exécutées (*).
    Prenons l'exemple schématique de code suivant :

    alpha = 0 | beta = 1
    if alpha = 1 or beta = 1
    gamma = 3
    endif

    La 2ème ligne est ici totalement couverte car les deux composantes du test     if alpha = 1 or beta = 1 sont exécutées (la première condition du OU logique n'étant pas réalisée, la seconde a du être exécutée ; et remarquez que si beta ne valait pas 1, il en serait de même).

    Remarque     : les lignes ne comportant pas de code exécutable Diva sont également coloriées avec cette couleur (de manière à ne pas créer de "trous" artificiels pouvant faire croire visuellement que certaines lignes n'ont pas été exécutées). Pour un source donné, cette coloration des lignes sans code exécutable a lieu, à chaque nouvelle exécution de l'application, au moment où une première instruction de ce source est exécutée.

     

  • La seconde couleur (intitulée "Ligne partiellement couverte") est appliquée aux lignes dont une partie seulement des composantes a été exécutée (*).
    Prenons l'exemple schématique de code presque identique suivant :

    alpha = 0 | beta = 1
    if alpha = 0     or beta = 1
    gamma = 3
    endif

    La 2ème ligne est ici partiellement couverte car la seconde composante du test     if alpha = 0 or beta = 1 n'a pas été exécutée (la première condition du OU logique étant réalisée ; et remarquez à nouveau que si beta ne valait pas 1, il en serait de même).

 

(*) Une ligne a de multiples composantes lorsqu'elle est formée de plusieurs instructions (séparées par "|") ou lorsqu'elle contient une instruction composée (opérateurs booléens, Condition, etc.).

 

 

Choix des couleurs :

 

Au niveau des options de Xwin (volet "Polices et couleurs"), vous pouvez choisir les deux couleurs spécifiquement utilisées pour la couverture du code : Cf. rubrique Modifier les couleurs. Ces couleurs sont intitulées : "Couverture : Ligne entièrement couverte" et "Couverture : Ligne partiellement couverte".
