Pour créer un fichier source

  1. Sélectionnez le choix Nouveau du menu Fichier (raccourci clavier : Ctrl+N).
    Ou
    Cliquez     sur le bouton de la barre d'outils.
    La boîte de dialogue "Nouveau" apparaît.
     

  2. Sélectionnez le choix :

    • Texte pour créer un nouveau source Diva (extension .dhsp).

    • Dictionnaire de RecordSql pour créer un nouveau dictionnaire de RecordSql (extension .dhsq).

    • Dictionnaire de jointures Sql pour créer un nouveau dictionnaire de Jointures Sql (extension .dhsj).
       

  3. Validez par OK.

 

Pour enregistrer le nouveau source sur disque, consultez la rubrique Pour sauvegarder un fichier source.
