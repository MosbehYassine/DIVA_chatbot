Le menu Rechercher de l'éditeur de textes

 

Le menu Rechercher propose les commandes de recherches et remplacements de chaîne, les commandes de parcours du texte actif et les commandes de navigation :

  • Chercher : Permet la recherche d'une chaîne de caractères ou d'un mot dans le texte actif.

  • Remplacer : Permet le remplacement d'une chaîne par une autre dans le texte actif.

  • Recherche multi-fichiers : Permet la recherche d'une chaîne de caractères ou d'un mot dans un ou plusieurs fichiers (sources et masques).

  • Naviguer : Permet la recherche d'une entité syntaxique avec saisie du nom de cette entité.

  • Aller à la définition : Permet la recherche de l'entité syntaxique couramment sélectionnée dans le source.

  • Niveau de navigation Suivant / Précédent : Avancée ou recul d'un niveau dans l'historique de navigation.

  • Aller à la ligne : Permet de spécifier un numéro de ligne où se rendre dans le texte actif.

  • Structure début / fin, Elément de structure suivant / précédent : Permettent de parcourir une structure de contrôle Diva (Switch – Endswitch ou Beginp – Endp, par exemple). Traite aussi l'imbrication des parenthèses et des crochets.

  • Erreur/Occurrence Suivante / Précédente : Place le curseur sur l'instruction erronée suivante ou précédente (erreurs de compilation), sur la ligne contenant l’occurrence suivante ou précédente de la chaîne recherchée (recherche multi-fichiers) ou sur la ligne contenant l’occurrence suivante ou précédente de l’entité syntaxique concernée (navigation).

  • Poser / Annuler Marque : Place ou annule une marque sur la ligne courante du texte actif.

  • Marque Suivante / Précédente : Cherche la marque suivante ou précédente dans le texte actif.

  • Annuler Toutes Marques : Supprime toutes les marques du texte actif.
