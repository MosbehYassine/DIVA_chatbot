Utiliser la fenêtre de débogage rapide

En phase de mise au point, lorsque le programme est à l'arrêt, si la souris stationne quelques instants sur une variable (instance d’enregistrement, champ, donnée locale) ou sur une expression sélectionnée, une fenêtre d’information affiche la valeur courante de cette donnée ou expression.
 

Si, dans cette fenêtre, vous cliquez dans la zone affichant la valeur de la variable, vous passez en mode saisie, ce qui vous permet de modifier cette valeur.

 

Si vous cliquez droit à l'intérieur de la fenêtre, vous demandez l'affichage d'un menu surgissant contextuel permettant la modification de la valeur de la donnée, son ajout à la fenêtre Variables, la copie de son nom ou de sa valeur dans le presse-papier, ainsi que la modification du type d'affichage des données (décimal ou hexadécimal).

 

Attention : la fenêtre de débogage rapide ne s'affichera pas si vous avez invalidé l'option "Afficher la fenêtre de débogage rapide".

 

 

Afficher la fenêtre de débogage rapide

Pour ouvrir cette fenêtre, en phase de mise au point et lorsque le programme est à l'arrêt :

  • Placez le curseur souris sur la variable (ou sur une expression sélectionnée au préalable) à visualiser.
    Remarque : si la variable est un champ d'un enregistrement (Enreg.Champ), la fenêtre affichera l'enregistrement si le curseur souris survole le nom de l'enregistrement, le champ si le curseur souris survole le nom du champ.

  • Attendez quelques instants sans bouger la souris (comme pour l'affichage d'une bulle).

 

Expanser un enregistrement ou un tableau dans la fenêtre de débogage rapide

Lorsque la variable est un enregistrement, vous pouvez visualiser les données qui le constituent. De même, vous pouvez visualiser les éléments d'un tableau :

  • Le signe plus (+) apparaît initialement à gauche de la ligne affichant le nom de la structure. Si vous cliquez sur le +, la structure est "expansée" (les données de l'enregistrement ou les éléments du tableau sont affichés dans une deuxième fenêtre ; utilisez au besoin l'ascenseur ou la roulette pour faire défiler les sous-données).
    Le cas échéant, plusieurs expansions en cascade sont possibles.

  • A partir de là, c'est le signe moins (-) qui apparaît à gauche de la ligne. Si vous cliquez sur le -, la structure est "réduite" (la fenêtre affichant les sous-données est refermée).

 

Modifier la valeur d'une variable dans la fenêtre de débogage rapide

Pour modifier la valeur d'une variable affichée dans une fenêtre de débogage rapide :

  • Cliquez dans la zone affichant son nom ou sa valeur (ou cliquez droit sur la ligne concernée et sélectionnez le choix Modifier la valeur du menu contextuel).

  • Saisissez la nouvelle valeur.
    Attention     : une chaîne alphanumérique doit être encadrée de ' ou ".

  • Tapez Tab ou Entrée pour valider la saisie (ou cliquez hors zone de saisie dans la fenêtre).
    Tapez Echap pour abandonner.

 

Placer la donnée dans la fenêtre Variables

Si vous êtes amené à consulter régulièrement une donnée, placez-la dans la fenêtre Variables. A partir de la fenêtre de débogage rapide :

  • Cliquez droit sur la ligne affichant la donnée à ajouter.

  • Sélectionnez le choix Ajouter à la liste des variables du menu surgissant contextuel.

 

Copier l'expression ou la valeur dans le presse-papier

Vous pouvez copier le nom de la donnée (ou l'expression sélectionnée) ainsi que sa valeur dans le presse-papier :

  • Cliquez droit sur la ligne affichant la donnée concernée.

  • Sélectionnez le choix Copier l'expression ou Copier la valeur du menu surgissant contextuel.

 

Changer le type d'affichage (décimal ou hexadécimal)

  • Cliquez droit à l'intérieur de la fenêtre de débogage rapide.

  • Validez ou invalidez l'option Afficher en hexadécimal du menu surgissant contextuel.

 

Visualiser le code source situé sous la fenêtre de débogage rapide sans la refermer

Si vous cliquez avec le bouton du milieu à l'intérieur de la fenêtre de débogage rapide, la fenêtre devient transparente.

 

 

Refermer la fenêtre de débogage rapide

Pour refermer la fenêtre de débogage rapide, il suffit de déplacer le curseur souris à l'extérieur de la zone rectangulaire délimitée par le nom de la donnée et la fenêtre elle-même. Vous pouvez aussi taper la touche Echap.
