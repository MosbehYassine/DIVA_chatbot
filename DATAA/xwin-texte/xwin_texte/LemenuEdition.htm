Le menu Edition de l'éditeur de textes

 

Le menu Edition propose les commandes d'édition et de sélection complète du texte actif :

  • Annuler : Invalide la dernière opération d'édition.

  • Recommencer : Exécute à nouveau la dernière opération annulée.

  • Copier : Copie la sélection ou la ligne courante dans le presse-papiers.

  • Couper : Détruit la sélection avec recopie dans le presse-papiers.

  • Coller : Insère le contenu du presse-papiers dans le texte.

  • Supprimer : Détruit la sélection sans recopie dans le presse-papiers.

  • Tout sélectionner : Sélectionne la totalité du texte de la fenêtre active.

  • Indenter : Insère une tabulation en tête de toutes les lignes sélectionnées.

  • Désindenter : Détruit la tabulation débutant toutes les lignes sélectionnées.

  • Mettre en commentaire : Ajoute un point-virgule devant toutes les lignes sélectionnées.

  • Rétablir les instructions : Supprime le point-virgule situé en tête de toutes les lignes sélectionnées.

  • Maj => Min : Convertit le caractère courant ou la sélection en minuscules.

  • Min => Maj : Convertit le caractère courant ou la sélection en majuscules.

  • Afficher les éléments courants en surbrillance : Annule ou rétablit les mises en surbrillance automatiques.

  • Saisie Assistée : Liste des membres : Affiche la fenêtre "Liste des membres" de la saisie assistée.

  • Saisie Assistée : Informations sur les paramètres : Affiche la fenêtre d'information sur les paramètres de la fonction en cours.

  • Saisie Assistée : Compléter le mot : Complète le mot en cours si aucune ambiguïté ne subsiste (sinon, affiche la fenêtre "Liste des membres").
