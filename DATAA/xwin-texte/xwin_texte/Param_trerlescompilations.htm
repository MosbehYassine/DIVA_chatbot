Paramétrer les compilations

Si vous compilez vos sources dans le cadre d'un projet Xwin, le paramétrage des compilations s'effectue au niveau des propriétés des profils.

 

 

La suite de cette rubrique concerne uniquement les applications exécutées HORS cadre d'un projet de Xwin.

Si vous désirez, par exemple, opter pour une compilation en mode "normal" ou une compilation en mode "débogueur", vous devez l'indiquer dans les paramètres de compilation.

 

Pour ouvrir la boîte de dialogue des paramètres et accéder aux options de compilation Diva :

  • Sélectionnez le choix Options du menu Outils.

  • Dans la liste des chapitres, cliquez sur Compilation, exécution hors projet pour afficher le volet présentant les options de compilation.

 

Les compilations Diva sont paramétrables sur les points suivants :

  • Mode de compilation :

    • Le mode "débogueur" vous permet de bénéficier des fonctions du débogueur lorsque vous mettrez au point vos programmes.
      Remarque : la fonction de couverture du code n'est disponible que dans le cadre d'un projet.

    • Le mode "normal" vous permet de générer les codes objet utilisés en exploitation.
       

  • Nom du source de programme à compiler.

    • Si vous laissez ce paramètre à espace, est compilé le programme situé dans la fenêtre active au moment où vous lancez la compilation. Cette solution est intéressante lorsque vous êtes amené à développer plusieurs programmes en même temps.

    • Si vous renseignez ce paramètre, est toujours compilé le programme dont le nom de source est indiqué ici, et ce, quelque soit la fenêtre active au moment où vous lancez la compilation. Cette solution est très pratique lorsque vous développez un programme unique faisant référence à des fichiers "Include" : vous pouvez travailler dans une fenêtre contenant un fichier Include et lancer la compilation du programme principal sans quitter cette fenêtre.
      Remarque : Ce paramètre ne concerne pas les masques ; pour compiler un masque, il faut toujours que la fenêtre correspondante soit active au moment de lancer la compilation.
       

  • Options de compilation.
    Voir la rubrique "Options du compilateur" de la documentation de programmation de Xwin.
     

  • Dossier des fichiers objet.

    • Si vous renseignez ce paramètre, les fichiers objet sont toujours stockés dans le dossier indiqué ici. Les fichiers objet qui n'existent pas encore dans ce dossier sont automatiquement créés, sans demande de confirmation.
      Si le nom du source ne comporte pas d'extension, le nom de l'objet est déduit du nom du source en lui ôtant son premier caractère (exemple : STEST => TEST) ; sinon, l'extension .dhsp est remplacée par .dhop (exemple : TEST.dhsp => TEST.dhop).

    • Si vous laissez ce paramètre à espace, les fichiers objet ne sont pas automatiquement créés. Xwin ouvre une boîte de dialogue vous demandant de choisir le dossier de stockage.
