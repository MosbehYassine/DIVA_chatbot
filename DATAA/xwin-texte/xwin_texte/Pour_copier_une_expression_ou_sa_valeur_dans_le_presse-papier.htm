Pour copier une expression ou sa valeur dans le presse-papier

 

Pour copier une expression ou sa valeur dans le presse-papier (en phase de mise au point et lorsque le programme est à l'arrêt) :

  1. Placez le curseur souris sur la variable (ou sur l'expression sélectionnée au préalable).

  2. Attendez quelques instants sans bouger la souris (comme pour l'affichage d'une bulle).
    La fenêtre de débogage rapide est ouverte.

  3. Cliquez droit sur la ligne affichant la variable.

  4. Sélectionnez le choix Copier l'expression ou Copier la valeur du menu surgissant contextuel.
