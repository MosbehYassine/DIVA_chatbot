Gestionnaire d'extraits de code

Utilisez cette boîte de dialogue pour déclarer le ou les dossiers de stockage de vos fichiers d'extrait de code personnels.

 

Vous pouvez ici ajouter (bouton Ajouter) ou retirer (bouton Supprimer) des éléments à la liste des dossiers qui vous sera proposée à l'ouverture du sélecteur d'extraits de code.


Si vous expansez un dossier dans l'arbre affiché dans le cadre de gauche, vous affichez la liste de tous les fichiers d'extraits de code contenus par ce dossier.

Remarque : Xwin ne fait pas de recherche dans les sous-dossiers ; le cas échéant, ajoutez les sous-dossiers à la liste.

 

Si vous sélectionnez un fichier, vous affichez dans le cadre de droite toutes les informations sur ce fichier (identifiant, auteur, descriptif et code source).

 

Conseil : Pour améliorer les performances, stockez uniquement des fichiers d'extrait de code dans les dossiers que vous spécifiez ici.
