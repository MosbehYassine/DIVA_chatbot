Pour afficher les données en décimal dans le débogueur

 
 

Méthode 1 :

  1. Sélectionnez le choix Options du menu Outils.
    La boîte de dialogue "Options" apparaît.

  2. Dans la liste des chapitres, cliquez sur Débogage : Général.
    Le volet présentant les options du débogueur est affiché.

  3. Choisissez l'option Décimal du groupe "Affichage des données en".

  4. Validez par OK.

 

Méthode 2 :

  1. Cliquez avec le bouton droit de la souris à l'intérieur d'une fenêtre de débogage rapide.

  2. Décochez le choix Afficher en hexadécimal du menu contextuel.
