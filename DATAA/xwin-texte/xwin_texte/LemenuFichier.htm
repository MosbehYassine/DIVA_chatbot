Le menu Fichier de l'éditeur de textes


Le menu Fichier propose les commandes de gestion des fichiers textes, les commandes de gestion des fichiers projets ainsi que la commande Quitter (Xwin) :

  • Nouveau : Permet la création d'un nouveau document. Affiche la boîte de dialogue " Nouveau ".

  • Ouvrir : Permet le chargement d'un document existant. Affiche la boîte de dialogue " Ouverture du fichier source ".

  • Fermer : Ferme le fichier actif (et la fenêtre MDI correspondante).

  • Nouveau Projet : Permet la création d'un nouveau projet. Affiche la boîte de dialogue " Ouverture d’un projet ".

  • Ouvrir Projet : Permet le chargement d'un projet existant. Affiche la boîte de dialogue " Ouverture d’un projet ".

  • Fermer Projet : Ferme le projet courant.

  • Enregistrer : Sauve le fichier actif.

  • Enregistrer Sous : Permet la sauvegarde du contenu du fichier actif dans un fichier différent. Affiche la boîte de dialogue " Sauvegarde du fichier source ".

  • Tout Enregistrer : Sauve tous les fichiers ouverts et modifiés.

  • Imprimer : Permet l'impression du fichier texte actif ou de la sélection en cours dans le fichier actif. Affiche la boîte de dialogue " Imprimer ".

  • Fichiers récents : Permet le chargement d'un source récemment utilisé.

  • Projets récents : Permet le chargement d'un projet récemment utilisé.

  • Quitter : Fait sortir du programme Xwin.
