Ouvrir un fichier Include ou un source de Module

Si un programme source fait appel à un fichier "Include" ou à un "Module" (instruction Diva Include ou Module), l'éditeur propose un moyen rapide pour charger le source correspondant :

  • Cliquez avec le bouton droit de la souris n'importe où sur la ligne contenant l'instruction Include ou Module, pour ouvrir le menu contextuel de l'éditeur.

  • Le choix Ouvrir doit être valide et afficher le nom du fichier source référencé par l'instruction Include ou Module.
    Exemple :
    Ligne de programme :  Include "COMMUN.dhsp"
    Choix au menu :  Ouvrir COMMUN.dhsp

  • Sélectionnez le choix Ouvrir fichier.

Nota : L'instruction "Module" référence toujours un fichier objet. Pour déterminer le nom du source correspondant, l'éditeur remplace l'extension .dhop par .dhsp. Exemple : MODU.dhop => MODU.dhsp.
