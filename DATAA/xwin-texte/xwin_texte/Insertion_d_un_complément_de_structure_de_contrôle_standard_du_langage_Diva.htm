Insertion d'un complément de structure de contrôle standard du langage Diva

L'outil d'insertion d'extraits de code de Xwin permet également, sous certaines conditions décrites ci-après, de compléter automatiquement le code d'une structure Diva standard préexistante. Par exemple, vous pouvez taper le mot clé <for> puis demander la génération du squelette de la boucle for, ou taper la définition d'une fonction puis demander la génération de la déclaration des paramètres et du corps de la fonction.

 

Insérer un complément de structure dans le code source

  • Placez le curseur sur la ligne débutant par le mot clé à compléter.
    Remarque : La position du curseur dans la ligne (colonne) est sans importance. Xwin ne tient pas non plus compte d'une éventuelle sélection actuelle de texte.
     

  • Tapez Ctrl+E ou sélectionnez le choix Compléter la structure Diva du menu contextuel de l'éditeur de textes.
     

  • Restriction (hors procédure et fonction) : l'instruction à compléter doit être la première instruction de la ligne.
    En pratique, le mot clé ne doit être précédé d'aucun caractère significatif (seuls les espaces et les tabulations sont acceptés). Ainsi, dans l'exemple suivant, la complémentation n'aura pas lieu :

    alpha = 1 | if
     

  • Instruction éclatée sur plusieurs lignes.
    Dans les cas du type suivant :

    if alpha = 1 or \
    beta  = 2 or \
    gamma = 3

    vous pouvez placer le curseur sur l'une quelconque des lignes (trois dans cet exemple) de l'instruction avant de taper Ctrl+E.

 

Génération du code complémentaire

Le code généré ici est grosso modo identique au code inséré par la fonction Insertion d'une structure de contrôle standard du langage Diva. Notez toutefois les particularités suivantes :

  • /if ainsi que les sous-structures else, elsif, /else et while font également l'objet d'une génération de complément de code.
     

  • Restriction concernant la génération de l'instruction proprement dite.
    Cette génération n'a lieu que si le début de la structure n'est suivi sur la ligne d'aucun caractère significatif (seuls les espaces et les tabulations sont acceptés).

    Ainsi :
    for     sera complété par  <i> = 1 to <n> [step <p>]

    Alors que :
    for  ;commentaire
    ne le sera pas.

  • Code généré pour les (prototypes de) procédures et fonctions.
    Xwin analyse plus finement la ligne de définition d'une procédure ou d'une fonction (ou de son prototype). Il vérifie la présence des différents éléments syntaxiques et adapte la génération en conséquence (il refuse même la génération si une anomalie syntaxique est détectée).

    Par exemple :
    Public Function     génère sur la première ligne  <t> <n>

    Alors que :
    Public Function char     génère uniquement  <n>


    Génération automatique de la déclaration des paramètres

    Si vous avez     saisi la liste des paramètres AVANT de taper Ctrl+E, Xwin génère automatiquement leur déclaration.

    Ainsi, Ctrl+E tapé après la saisie de :
    procedure MaProc (MonPara1,MonPara2)

    insère :
    1 MonPara1 <t>
    1 MonPara2 <t>


    Vous pouvez aussi procéder à la génération d'une procédure ou d'une fonction en deux temps. Par exemple :

    Tapez Maj+Ctrl+E et sélectionnez la structure <procedure>. Xwin génère la définition :
    procedure <n>

    Modifiez la ligne pour obtenir :
    procedure MaProc (MonPara1,MonPara2)

    Tapez maintenant Ctrl+E. Xwin ajoute à la génération précédente :
    1 MonPara1 <t>
    1 MonPara2 <t>
