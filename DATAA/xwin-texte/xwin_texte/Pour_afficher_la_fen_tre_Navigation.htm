Pour afficher la fenêtre Navigation

 

Méthode 1 :

  • Cliquez sur l'onglet Navigation. Si cet onglet n’apparaît pas, la fenêtre est ancrée et donc déjà affichée. 

     

Méthode 2 :

  • Sélectionnez le choix Navigation du sous-menu Fenêtres comptes rendus du menu Fenêtre.

 

Rappel : Xwin conserve un historique des navigations. Si la liste affichée dans la fenêtre Navigation ne correspond pas à votre attente, cela signifie peut-être que vous avez opéré plusieurs navigations. Dans ce cas, utilisez les choix Niveau de navigation suivant / précédent du menu Rechercher (raccourcis clavier Ctrl+F11 et Maj+Ctrl+F11) pour avancer ou reculer dans l'historique.
