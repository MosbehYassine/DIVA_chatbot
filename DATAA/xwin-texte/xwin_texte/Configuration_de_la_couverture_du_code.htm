Configuration de la couverture du code

 

Vous pouvez paramétrer la fonction de couverture du code à différents niveaux :

  1. Options du profil :
     

    • Rappel : la trace des instructions nécessite d'avoir validé les deux options de compilation "Option Debug" et "Option Couverture du code".
       

    • Répertoire des fichiers de couverture du code

      Les fichiers des couvertures sont rangés dans ce répertoire (répertoire des fichiers "Browse" puis des fichiers "Objet" par défaut). Rappelons qu'à chaque source couvert est associé un fichier des couvertures, dont le nom est déduit du nom du fichier source en remplaçant le suffixe .dhsX par _dhsX.dhcc (exemple : fic.dhsp --> fic_dhsp.dhcc).

      Attention       :  Xwin ne gère pas le partage des informations de couverture par plusieurs utilisateurs.

      Nettoyage du répertoire       : Le bouton Nettoyer permet de supprimer tous les fichiers (.dhcc) contenus par ce répertoire. Mais attention, cette opération supprime aussi toutes les informations de couverture courantes.


       

  2. Options de Xwin (volet Débogage : Couverture du code) :
     

    • Activer la couverture du code

      Cette option active ou désactive globalement la fonction de couverture du code (      indépendamment de l'option de compilation sans laquelle la couverture ne peut pas fonctionner).

      Attention : si cette option est désactivée, Xwin n'effectue plus aucun des traitements attachés à la fonction de couverture. En particulier, le suivi des modifications des sources est stoppé et si vous modifiez un source, les informations de couverture associées deviendront obsolètes.

      Désactivez globalement la couverture uniquement si vous ne souhaitez pas utiliser cette fonctionnalité.

    • Activer / Désactiver automatiquement la colorisation des lignes couvertes en Début / Fin de session de débogage

      Si vous validez cette option, Xwin passe automatiquement en mode "Colorier les lignes couvertes" au lancement de l'exécution d'un programme en mode débogueur, et revient automatiquement en mode normal lorsque l'exécution du programme se termine.
       

    • Effacer les informations de couverture à chaque nouvelle exécution

      Par défaut, les informations de couverture sont conservées entre deux exécutions de l'application. Ceci permet de couvrir les différentes portions de code des sources concernés, en effectuant plusieurs tests successifs.
      Si vous validez cette option, toutes les informations attachées à       tous les sources du sous-projet courant seront effacées à chaque nouvelle exécution de l'application.

       

  1. Options de Xwin (volet Environnement : Police et couleurs) :
     

    • Les deux couleurs utilisées spécifiquement pour visualiser les informations liées à la couverture du code sont paramétrables : Cf. rubrique Modifier les couleurs.
      Ces couleurs sont identifiées : "Couverture : Ligne entièrement couverte" et "Couverture : Ligne partiellement couverte".


       

  2. Sous-menu "Couverture du code" (menu Déboguer ou menu contextuel de l'éditeur de textes) et barre d'outils de l'éditeur de textes :
     

    • Tracer les instructions exécutées : Ce choix du menu (bouton de la barre d'outils - raccourci clavier Maj+Ctrl+F9) vous permet de stopper ou de redémarrer la trace des instructions exécutées.

    • Colorier les lignes couvertes : Ce choix du menu (bouton de la barre d'outils - raccourci clavier Ctrl+F9) vous permet d'activer ou désactiver la colorisation spécifique des lignes couvertes.
       

    • Afficher la boîte de dialogue des messages : Lorsque la fonction de couverture du code détecte une anomalie, elle affiche un message à la fois dans la fenêtre de l'onglet "Messages" et dans une boîte de dialogue. Cette dernière comporte une case à cocher "Ne plus afficher cette boîte de dialogue". Si vous avez décoché la case, ce choix du menu vous permet de rétablir l'affichage de la boîte de dialogue.
