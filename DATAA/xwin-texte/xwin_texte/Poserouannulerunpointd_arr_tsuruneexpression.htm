Poser ou annuler un point d'arrêt sur une expression

 

Un point d'arrêt si expression vraie demande l'interruption du programme dès qu'une certaine expression en mémoire passe à vraie.

Un point d'arrêt si expression change demande l'interruption du programme dès qu'une certaine expression en mémoire change de valeur.

 

Ces conditions peuvent être combinées à la notion d'arrêt sur ligne. Ainsi :

Un point d'arrêt sur ligne si expression vraie demande l'interruption du programme sur une ligne du source, à condition qu'une certaine expression en mémoire soit vraie.

Un point d'arrêt sur ligne si expression change demande l'interruption du programme sur une ligne du source, à condition qu'une certaine expression en mémoire ait changé de valeur depuis le dernier arrêt sur cette ligne.

 

Pour poser ce type de point d'arrêt :

  • Dans le cas d'un arrêt combiné, placez le curseur sur la ligne de source choisie.

  • Sélectionnez le choix Points d'arrêt du menu Déboguer pour ouvrir la boîte de dialogue "Points d'arrêt" (raccourci clavier : Maj+Ctrl+B).

  • Sélectionnez le type d'arrêt choisi et spécifiez l'expression à tester.

  • Cliquez sur le bouton Ajouter puis validez par OK.

 

Pour annuler un point d'arrêt posé précédemment, ouvrez la boîte de dialogue "Points d'arrêt", sélectionnez la ligne de la liste des points d'arrêt affichant celui à effacer puis cliquez sur le bouton Supprimer.

Le bouton Tout supprimer permet d'annuler tous les points d'arrêt posés, en une seule opération.
