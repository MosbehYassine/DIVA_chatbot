Pour sauvegarder dans un autre fichier

Pour sauvegarder votre texte dans un autre fichier que celui ouvert au départ (sous un autre nom) :

  1. Activez la fenêtre concernée.

  2. Sélectionnez le choix Enregistrer sous du menu Fichier (raccourci clavier : Maj+Ctrl+S).
    La boîte de dialogue " Sauvegarde du fichier source texte " apparaît.

  3. S'il n'est pas déjà sélectionné, cliquez sur le dossier de stockage.

  4. Entrez le nom du fichier.

  5. Validez par OK.
