Options - Débogage - Couverture du code

 

Les options concernant la fonction de couverture du code sont les suivantes :

  • Activer la couverture du code

    Active ou désactive globalement la fonction de couverture du code (    indépendamment de l'option de compilation sans laquelle la couverture ne peut pas fonctionner).
    Attention : si cette option est désactivée, Xwin n'effectue plus aucun des traitements attachés à la fonction. En particulier, le suivi des modifications des sources est stoppé et si vous modifiez un source, les informations de couverture associées deviendront obsolètes.
     

  • Activer / Désactiver automatiquement la colorisation des lignes couvertes en Début / Fin de session de débogage

    Si vous validez cette option, Xwin passe automatiquement en mode "Colorier les lignes couvertes" au lancement de l'exécution d'un programme en mode débogueur, et revient automatiquement en mode normal lorsque l'exécution du programme se termine.
     

  • Effacer les informations de couverture à chaque nouvelle exécution

    Par défaut, les informations de couverture sont conservées entre deux exécutions d'un programme. Ceci permet de couvrir les différentes portions de code des sources concernés, en passant par plusieurs exécutions successives.
    Si vous validez cette option, toutes les informations attachées à     tous les sources du sous-projet courant seront effacées à chaque nouvelle exécution du programme.

 

 

Procédures correspondantes :

Pour activer ou désactiver globalement la couverture du code

Pour activer ou désactiver automatiquement la colorisation des lignes couvertes

Pour effacer les informations de couverture du code à chaque nouvelle exécution
