Pour effacer toutes les informations de couverture du code existantes

  • Ouvrez la boîte des propriétés de votre profil actif.

  • Cliquez sur le bouton Nettoyer, situé en vis à vis du champ "Répertoire des fichiers de couverture du code".

 

Attention :

Tous les fichiers (.dhcc) contenus par ce répertoire sont supprimés.
Cette opération supprime également toutes les informations de couverture courantes.
