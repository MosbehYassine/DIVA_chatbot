Utiliser les marques

Vous pouvez placer une marque sur n'importe quelle ligne de source de manière à ensuite accélérer le re-positionnement sur l'une de ces lignes, en utilisant un raccourci clavier, un bouton de la barre d'outils ou un choix du menu Rechercher. Vous pouvez aussi effacer une marque lorsque vous n'en avez plus besoin ou même effacer toutes les marques d'un source donné en une opération. Une fonction de la fenêtre de recherche permet aussi de marquer toutes les lignes d'un source contenant la chaîne de caractères recherchée.

 

Une ligne marquée est signalée par l'affichage d'une icone "Marque" dans la marge.

 

Note : Les marques sont sauvegardées entre les sessions. Précisément, la sauvegarde s'effectue au déchargement du source et exclut les marques posées dans un source non sauvegardé par la suite.

 

Pour marquer une ligne, placez-y le curseur puis :

  • Sélectionnez le choix Poser / Annuler Marque du menu Rechercher (raccourci clavier : Ctrl+F2).

  • Ou cliquez sur le bouton de la barre d'outils.

  • Vous pouvez aussi cliquer avec le bouton droit de la souris, dans la partie gauche de la marge en regard de la ligne souhaitée, et sélectionner le choix Poser/Annuler une marque du menu contextuel.

 

Pour démarquer une ligne, procédez de la même manière.

 

Pour vous rendre sur la ligne marquée suivante la plus proche :

  • Sélectionnez le choix Marque Suivante du menu Rechercher (raccourci clavier : F2).

  • Ou cliquez sur le bouton de la barre d'outils.

 

Pour vous rendre sur la ligne marquée précédente la plus proche :

  • Sélectionnez le choix Marque Précédente du menu Rechercher (raccourci clavier : Maj+F2).

  • Ou cliquez sur le bouton de la barre d'outils.

 

Pour effacer toutes les marques d'un source :

  • Sélectionnez le choix Annuler Toutes Marques du menu Rechercher.

  • Ou cliquez sur le bouton de la barre d'outils.

 

Pour marquer toutes les lignes d'un source contenant une chaîne de caractères :

  • Affichez la fenêtre de recherche.

  • Dans cette fenêtre, saisissez la chaîne à rechercher et sélectionnez les éventuelles options de recherche.

  • Dans cette fenêtre, cliquez sur le bouton de la barre d'outils.
