Pour ouvrir un fichier Include ou un source de Module

L'éditeur propose un moyen rapide pour charger un fichier include ou un source de module référencé par l'instruction Diva Include ou Module :

  1. Cliquez avec le bouton droit de la souris n'importe où sur la ligne contenant l'instruction Include ou Module.
    Le menu surgissant contextuel de l'éditeur s'ouvre.

  2. Sélectionnez le choix Ouvrir fffff.
    Le choix Ouvrir doit être valide et afficher le nom du fichier source référencé par l'instruction Include ou Module.
    Exemple :
    Ligne de programme :  Include "COMMUN.dhsp"
    Choix au menu :  Ouvrir COMMUN.dhsp

 

Nota : L'instruction "Module" référence toujours un fichier objet. Pour déterminer le nom du source correspondant, l'éditeur remplace l'extension .dhop par .dhsp. Exemple : MODU.dhop => MODU.dhsp.
