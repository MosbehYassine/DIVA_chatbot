Pour naviguer dans les sources

 

Méthode 1 :

  1. Optionnel : dans le texte, positionnez le curseur sur l’entité syntaxique voulue. L'éditeur utilise ce positionnement pour sélectionner une entité par défaut. Si vous désirez "forcer" une entité par défaut, sélectionnez-la.

  2. Appelez le choix Naviguer du menu Rechercher (raccourci clavier : Maj+F11).
    La boîte de dialogue « Naviguer » apparaît.

  3. Entrez le nom de l’entité syntaxique voulue et validez par OK.
    Ceci garnit le volet « Navigation » de la fenêtre des comptes rendus avec la liste des définitions et références de l’entité choisie. De plus, l’éditeur se positionne sur la première définition de l’entité dans le source concerné.
    Vous pouvez ici utiliser le caractère joker * ou ? pour présélectionner plusieurs entités de noms similaires. Exemple :
    don* pour présélectionner toutes les données dont le nom commence par don.

  4. Si une ambiguïté est détectée, sélectionnez l’entité voulue dans la liste affichée par la boîte Naviguer et validez par OK
    Ou
    Cliquez     sur le bouton Tous pour naviguer indifféremment sur toutes les entités affichées.

  5. Par la suite, sélectionnez les choix Erreur/Occurrence Suivante (raccourci clavier F4) et Erreur/Occurrence Précédente (raccourci clavier Maj+F4) du menu Rechercher pour parcourir la liste des définitions et références de(s) entité(s) choisie(s) (volet « Navigation » de la fenêtre des comptes rendus activé).

 

Méthode 2 :

  1. Dans le texte, positionnez le curseur sur l’entité syntaxique voulue ou sélectionnez-la.

  2. Appelez le choix Aller à la définition du menu Rechercher (raccourci clavier : F11).
    Ce choix garnit le volet « Navigation » de la fenêtre des comptes rendus avec la liste des définitions et références à l’entité choisie. De plus, l’éditeur se positionne sur la première définition de l’entité dans le source concerné.

  3. Si une ambiguïté est détectée, sélectionnez l’entité voulue dans la liste affichée par la boîte Naviguer et validez par OK
    Ou
    Cliquez     sur le bouton Tous pour naviguer indifféremment sur tous les exemplaires de l’entité.

  4. Par la suite, sélectionnez les choix Erreur/Occurrence Suivante (raccourci clavier F4) et Erreur/Occurrence Précédente (raccourci clavier Maj+F4) du menu Rechercher pour parcourir la liste des définitions et références de(s) entité(s) choisie(s) (volet « Navigation » de la fenêtre des comptes rendus activé).

 

Lorsque la fenêtre « Navigation » est en mode « Masquage automatique », le lancement d’une recherche ouvre la fenêtre pour vous permettre de consulter les éventuelles occurrences trouvées et lui transfert le focus pour qu’elle ne se referme pas immédiatement. Pour redonner rapidement le focus à la fenêtre d’édition Mdi, tapez la touche Echap.

 

Rappel : Xwin conserve un historique des navigations. Si la liste affichée dans la fenêtre Navigation ne correspond pas à votre attente, cela signifie peut-être que vous avez opéré plusieurs navigations. Dans ce cas, utilisez les choix Niveau de navigation suivant / précédent du menu Rechercher (raccourcis clavier Ctrl+F11 et Maj+Ctrl+F11) pour avancer ou reculer dans l'historique.
