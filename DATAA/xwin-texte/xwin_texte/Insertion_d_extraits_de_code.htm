Insertion d'extraits de code

 

Xwin fournit un outil intitulé outil d'insertion d'extraits de code. Un sélecteur d'extraits de code vous autorise, en quelques clics souris, à insérer des blocs de code prêts à l'emploi dans le document actif. Les extraits de code peuvent vous permettre d'écrire des instructions plus facilement, plus rapidement et de manière plus fiable.

 

Trois types d'insertion sont proposés (au menu contextuel de l'éditeur de textes ou par l'intermédiaire de raccourcis clavier) :

  • Insertion d'un fichier d'extrait de code personnalisé.
    Le code à insérer dans votre document est recherché dans un fichier d'extrait personnel.
    Utilisez le Gestionnaire d'extraits de code pour ajouter des dossiers à la liste des dossiers dans lesquels le sélecteur d'extraits de code recherchera les fichiers d'extrait.
     

  • Insertion d'une structure de contrôle standard du langage Diva.
    Par exemple, l'extrait de code <for> ou l'extrait de code <function> crée une boucle for ou une fonction vide.
     

  • Insertion d'un complément de structure de contrôle standard du langage Diva.
    Par exemple, le mot clé <for> est complété avec le squelette de la boucle for, une ligne de définition de fonction est complétée avec la déclaration de ses paramètres et le corps de la fonction.
