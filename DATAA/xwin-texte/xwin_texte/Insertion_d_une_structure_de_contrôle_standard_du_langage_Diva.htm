Insertion d'une structure de contrôle standard du langage Diva

L'outil d'insertion d'extraits de code de Xwin permet d'insérer automatiquement dans votre programme un extrait de code correspondant :

  • A l'une des structures de contrôle standard du langage Diva (do ou do while, for, if, loop, repeat, switch ou switch2, plus structure, beginp et beginf).
    Par exemple, l'extrait de code <for> insère une boucle for vide.

  • A une procédure ou à une fonction (procedure, function).
    Par exemple, l'extrait de code <procedure> insère une procédure avec un corps vide.

  • A un prototype de procédure ou de fonction (proto procedure, proto function).

 

Afficher le sélecteur de structures

  • Placez le curseur sur la ligne derrière laquelle vous voulez insérer l'extrait de code.
    Remarque : La position du curseur dans la ligne (colonne) est sans importance. Xwin ne tient pas non plus compte d'une éventuelle sélection actuelle de texte.

  • Tapez Maj+Ctrl+E ou sélectionnez le choix Insérer une structure Diva... du menu contextuel de l'éditeur de textes.
    Ce choix fait appel au sélecteur de structures, composé du champ en saisie "Insérez la structure" et d'une boîte à liste présentant la liste des structures faisant l'objet d'un extrait de code standard.
    Vous pouvez maintenant taper le nom d'une structure ou sélectionner une structure dans la liste.

 

Naviguer dans la Liste des structures

  • Vous pouvez naviguer dans la liste en la faisant défiler (ascenseur ou molette) ou en utilisant les touches de direction (Flèche en Bas, Flèche en Haut, Page Up, Page Down, Ctrl+Page Up, Ctrl+Page Down).

  • La sélection dans la liste « suit » les caractères tapés dans le champ "Insérez la structure". Si vous connaissez les premières lettres de son nom, tapez-les pour atteindre directement la structure désirée dans la liste.

 

Insérer une structure dans le code source

Effectuez l'une des opérations suivantes :

  • Sélectionnez le nom de la structure (clic simple, touche de direction, ...) puis tapez Tab ou Entrée.

  • Double-cliquez sur son nom.

  • Sans nom sélectionné, tapez Tab ou Ctrl+Entrée pour insérer le code de l'élément de la liste qui a le focus.

L'extrait de code, correspondant à la structure validée, est inséré dans le document derrière la ligne pointée par le curseur clavier (cette ligne restant inchangée).
 

Remarquez les cas particuliers suivants :

  • Le code généré pour if inclut toujours le membre else :

    if <t>

    else

    endif

    Si vous souhaitez une structure if sans else    , tapez Ctrl+Z (commande Annuler) après l'insertion.
    Ceci éliminera uniquement le membre else du code généré pour ne conserver que :

    if <t>

    endif
     

  • Le code généré pour procedure, function, proto procedure et proto function ne comporte pas de paramètre et n'inclut donc pas leur déclaration. Une génération automatique de la déclaration des paramètres est toutefois possible à posteriori (voir la rubrique Insertion d'un complément de structure de contrôle standard du langage Diva).

 

Refermer le sélecteur de structures

A tout moment, tapez Echap ou cliquez dans l'éditeur.
