Saisie et personnalisation d'un fichier d'extrait de code

Les extraits de code doivent être écrits dans un fichier d'extension .dhsp et doivent respecter le format suivant :

  • La première ligne du fichier doit être impérativement :
    <Extrait de code Diva>

  • Les lignes suivantes sont au format HMP, avec un seul paramètre par ligne (l'ordre des paramètres est quelconque, hormis <Code> qui doit être en dernier) :

    • <Version>1.1 (paramètre et valeur obligatoires).

    • <Ident>xxxxxx (paramètre obligatoire).
      La valeur indiquée ici identifie l'extrait. C'est cet identifiant qui apparaîtra dans la liste présentée par le sélecteur d'extraits de code et qui pourra servir de raccourci clavier lors de la sélection.

    • <Auteur>aaaaaa (paramètre facultatif).
      Indiquez ici la personne responsable de l'extrait de code.

    • <Curseur>cccccc (paramètre facultatif, $C$ par défaut).
      Chaîne de reconnaissance pour le positionnement du curseur (voir paragraphe "Positionnement du curseur dans le code inséré" ci-après). Attention, la casse est ici significative.

    • <Date>dddddd (paramètre facultatif, $D$ par défaut).
      Chaîne de reconnaissance pour l'insertion de la date (voir paragraphe "Placement de la date dans le code inséré" ci-après). Attention, la casse est ici significative.

Pour les deux paramètres suivants, le contenu débute sur la ligne qui suit le mot clé (un texte situé immédiatement derrière le mot clé est ignoré) et peut comporter plusieurs lignes :

    • <Description> (paramètre et contenu obligatoires).
      Saisissez ici un court descriptif de l'extrait. Celui-ci apparaîtra en tête de la fenêtre d'information rapide, lors de la sélection de l'extrait dans la liste des extraits disponibles.

    • <Code> (en DERNIER, paramètre et contenu obligatoires).
      Saisissez ici le code source à insérer.

 

Positionnement du curseur dans le code inséré

Vous pouvez demander à ce que le curseur soit positionné à un endroit précis de votre code, après son insertion.
Pour ce faire, faites figurer la chaîne "$C$" (attention, la casse est significative) n'importe où dans votre code source : le curseur sera positionné à l'endroit où figure cette chaîne et cette dernière sera supprimée du code effectivement généré.
Si la chaîne par défaut "$C$" ne convient pas, vous pouvez spécifier une autre valeur derrière le paramètre <Curseur>.
 

 

Placement de la date dans le code inséré

Vous pouvez demander à insérer la date du jour dans votre code.

Pour ce faire, faites figurer la chaîne "$D$" (attention, la casse est significative) n'importe où dans votre code source. La date insérée est au format JJ/MM/AAAA.

Si la chaîne par défaut "$D$" ne convient pas, vous pouvez spécifier une autre valeur derrière le paramètre <Date>.

 
 
 

Exemple

 

<Extrait de code Diva>

<Version>1.1

<Ident>XmeInput

<Auteur>Divalto

<Curseur>$C$
 

<Description>

Boucle de saisie d'une page de masque écran
(mode Goto)
 

<Code>

fini = 0

XmeInput ("$C$<masque>.dhof",<page>,0,XME_MODE_GOTO)  ;lance la saisie

do

   switch Harmony.Arret                               ;tests des causes de l'interruption

      case Harmony.Key = K_F9                         ;abandon

         fini = 1
 

      case Harmony.Key in (K_UP,K_BTAB)               ;Flèche en haut ou Maj+Tab

                                                      ;tapée sur la 1ère donnée du masque
 

      case Harmony.Key in (K_F10,K_TAB,K_DOWN)        ;validation ou sortie par Tab ou Flèche en bas
fini = 2                                     ;              sur la dernière donnée du masque

   endswitch
 

while fini = 0

   XmeNext (Harmony.Retour,Harmony.CplRetour)         ;poursuite de la saisie

wend
 

 

Si un fichier d'extrait est erroné

Lorsque Xwin détecte une erreur dans un fichier d'extrait de code (à l'ouverture du gestionnaire d'extraits de code ou lors d'une demande d'insertion), il ne présente pas ce fichier dans la liste des extraits disponibles. Afin que vous puissiez remédier au problème, il édite l'erreur dans l'onglet Messages. Attention : Xwin continue de garnir cet onglet tant que l'erreur n'est pas corrigée. Après correction, vous pouvez effacer le contenu de l'onglet Messages en cliquant droit dans la barre de titre de l'onglet et en sélectionnant le choix Effacer du menu contextuel.



Rappel :

  • Pour être pris en compte par Xwin, vous devez répertorier les dossiers dans lesquels vous avez stocké vos fichiers d'extrait, à l'aide du Gestionnaire d’extraits de code (accessible à partir du menu Outils).

  • Des exemples d'extrait sont livrés dans le dossier /Divalto/Exemples/Extraits.

 

Conseils :

  • Pour améliorer les performances, stockez uniquement des fichiers d'extrait de code dans les dossiers que vous avez spécifiés avec le gestionnaire d'extraits de code.

  • Pour saisir vos fichiers, utilisez l'éditeur de textes de Xwin, créez un projet spécifique (avec un ou plusieurs sous-projets) et "rangez" les fichiers source dans le dossier Divers (afin d'éviter les inévitables erreurs de compilation).

  • Depuis le Gestionnaire d'extraits de code, vous pouvez aussi charger le fichier couramment sélectionné dans Xwin en cliquant sur le bouton Editer.
