Pour paramétrer le débogueur

  1. Sélectionnez le choix Options du menu Outils.
    La boîte de dialogue "Options" apparaît.

  2. Dans la liste des chapitres, cliquez sur Débogage : Général ou Débogage : Couverture du code.
    Le volet présentant les options correspondantes du débogueur est affiché.

  3. Saisissez les divers paramètres.

  4. Validez par OK.
