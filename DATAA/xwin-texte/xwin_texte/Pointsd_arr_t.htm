Points d'arrêt

Utilisez cette boîte de dialogue (raccourci clavier Maj+Ctrl+B) pour définir un point d'arrêt dans le source courant. Un point d'arrêt permet d'interrompre temporairement l'exécution du programme. Vous pouvez alors examiner la valeur des données globales et locales, consulter la pile d'exécution, rejouer l'historique (voir " par où " est passé votre programme), etc.

Il existe sept types de point d'arrêt :

  • Arrêt sur ligne : le programme s'interrompt, sans autre condition, juste avant que le débogueur n'exécute l'instruction située sur la ligne marquée par le point d'arrêt.

  • Arrêt sur ligne si expression vraie : comme précédemment, le programme s'interrompt juste avant que le débogueur n'exécute l'instruction située sur la ligne marquée par le point d'arrêt. Toutefois, l'interruption n'aura lieu que si une certaine expression en mémoire est vraie.

  • Arrêt sur ligne si expression change : arrêt similaire au cas précédent mais cette fois, l'interruption n'aura lieu que si une certaine expression en mémoire a changé de valeur.

  • Arrêt si expression vraie : le programme s'interrompt dès qu'une certaine expression en mémoire passe à vraie.

  • Arrêt si expression change : le programme s'interrompt dès qu'une certaine expression en mémoire change de valeur.

  • Arrêt si attribut dynamique change : le programme s'interrompt dès que la valeur d’un attribut dynamique est modifiée (fonctions Diva XmeSetAttribut et XmeResetAttribut).

  • Arrêt si attribut dynamique ligne change : le programme s'interrompt dès que la valeur d’un attribut dynamique « tableau » est modifiée (fonctions Diva XmeListSetAttribut et XmeListResetAttribut).

 

Type

Type du point d'arrêt (voir liste ci-dessus). Choisissez un type parmi ceux proposés en multi-choix.

Ligne

Numéro de la ligne (dans le source en cours) où placer le point d'arrêt (pour les types Arrêt sur ligne). Le numéro de la ligne où se trouve le curseur est proposé par défaut.

Attribut

Attribut dynamique à tester (pour les types Arrêt si attribut dynamique change).

Expression
ou
Nom d’objet

Variable à évaluer (pour les arrêts si expression vraie ou change).

Nom des objets concernés (pour les types Arrêt si attribut dynamique change).

Nom de ligne

Nom des lignes concernées (pour le type Arrêt si attribut dynamique ligne change).

Points d'arrêt

Liste des points d'arrêt actuellement posés.
Le signe plus (+) en première colonne d'une ligne indique que le point d'arrêt correspondant est activé. Le signe moins (-) signale un point d'arrêt inactivé.
Vous pouvez sélectionner un point d'arrêt dans la liste et le supprimer (bouton Supprimer), l'inactiver (bouton Invalider) ou le réactiver (bouton Revalider).
Vous pouvez aussi supprimer tous les points d'arrêt enregistrés (bouton Tout supprimer).
Vous pouvez aussi vous positionner sur la ligne de code incluant un point d'arrêt, en double-cliquant sur l'élément de la liste correspondant (la boîte de dialogue est alors refermée).

Ajouter

Ajoute le point d'arrêt ayant les caractéristiques indiqués dans les boîtes Type, Ligne et Expression à la liste des points d'arrêt courants.

Supprimer

Annule le point d'arrêt sélectionné en liste.

Invalider | Revalider

Si le point d'arrêt sélectionné en liste est actif, cliquez sur le bouton Invalider pour l'inactiver temporairement ; le débogueur n'en tiendra plus compte jusqu'à ce que vous le réactiviez en cliquant sur le bouton Revalider.

Tout Supprimer

Annule tous les points d'arrêt posés précédemment.

Tout Invalider

Invalide tous les points d'arrêt posés précédemment.

Tout Revalider

Revalide tous les points d'arrêt posés précédemment.
