Pour insérer le code d'une structure de contrôle Diva

 

Pour afficher le sélecteur de structures

  1. Placez le curseur sur la ligne derrière laquelle vous voulez insérer l'extrait de code.
    La position du curseur dans la ligne (colonne) est sans importance. Xwin ne tient pas non plus compte d'une éventuelle sélection actuelle de texte.
     

  2. Tapez Maj+Ctrl+E.

    OU

    Sélectionnez le choix Insérer une structure Diva... du menu contextuel de l'éditeur de textes.

    Le sélecteur de structures, composé du champ en saisie "Insérez la structure" et d'une boîte à liste présentant la liste des structures faisant l'objet d'un extrait de code standard, est affiché. Vous pouvez maintenant taper le nom d'une structure ou sélectionner une structure dans la liste.

 

Pour naviguer dans la Liste des structures

  • Faites défiler la liste avec l'ascenseur ou la molette.

    OU

    Utilisez les touches de direction (Flèche en Bas, Flèche en Haut, Page Up, Page Down, Ctrl+Page Up, Ctrl+Page Down).
     

  • La sélection dans la liste « suit » les caractères tapés dans le champ "Insérez la structure".
    Si vous connaissez les premières lettres de son nom, tapez-les pour atteindre directement la structure désirée dans la liste.

 

Pour insérer une structure dans le code source

  • Sélectionnez le nom de la structure (clic simple, touche de direction, ...) puis tapez Tab ou Entrée.

    OU

    Double-cliquez     sur son nom.

    OU

    Sans nom sélectionné, tapez Tab ou Ctrl+Entrée pour valider l'élément de la liste qui a le focus.

    L'extrait de code, correspondant à la structure validée, est inséré dans le document derrière la ligne pointée par le curseur clavier (cette ligne restant inchangée).

 

Cas particuliers :

  • Le code généré pour if inclut toujours le membre else.
    Si vous souhaitez une structure if sans else    , tapez Ctrl+Z (commande Annuler) après l'insertion.
    Ceci éliminera uniquement le membre else du code généré.
     

  • Le code généré pour procedure, function, proto procedure et proto function ne comporte pas de paramètre et n'inclut donc pas leur déclaration. Une génération automatique de la déclaration des paramètres est toutefois possible à posteriori (voir la rubrique Pour compléter le code d'une structure de contrôle Diva).

 

Pour refermer le sélecteur de structures

  • A tout moment, tapez Echap ou cliquez dans l'éditeur.
