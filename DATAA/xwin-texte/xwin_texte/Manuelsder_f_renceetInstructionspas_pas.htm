Manuels de référence et Instructions pas à pas

La documentation de l'atelier de développement Harmony comprend de nombreux sujets : Dictionnaire, Editeur de textes, Editeur de masques (écran, impression, Web), Editeur de ressources, Gestionnaire de projets, Débogueur, etc. Chaque sujet documenté fait l'objet d'un ou plusieurs parmi les livres suivants :

  • Sujet : Concepts généraux.
    Ce type de livre présente les concepts de base qu’il est nécessaire de bien posséder avant d’entrer dans le détail des fonctionnalités du produit.

  • Sujet : Manuel de référence.
    Ce type de livre décrit le sujet de manière complète et en détaille toutes les caractéristiques, comme par exemple les menus, les barres d'outils ou les boîtes de dialogue.

  • Sujet : Instructions pas à pas.
    Ce type de livre contient de courtes rubriques décrivant comment réaliser une tâche, comme par exemple poser un point d'arrêt dans un programme. Les titres de ces rubriques débutent tous par le mot Pour.

 

Exemple : Le débogueur de Xwin est documenté dans les livres " Utiliser le débogueur : Manuel de référence " et " Utiliser le débogueur : Instructions pas à pas ".
