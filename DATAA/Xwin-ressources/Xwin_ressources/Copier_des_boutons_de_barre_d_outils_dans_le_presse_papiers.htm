Copier des boutons de barre d'outils dans le presse-papiers

Des opérations de copier / couper / coller peuvent être effectuées sur les boutons d’une barre d’outils. Vous pouvez copier dans le presse-papiers un ou plusieurs boutons. Pour effectuer une copie :

  1. Sélectionnez le ou les boutons à copier.

  2. Validez le choix Copier du menu Edition (raccourci clavier Ctrl+Inser)
    ou
    Cliquez     sur le bouton de la barre d'outils
    ou
    Cliquez droit     sur le bouton à copier (pour le sélectionner) puis validez le choix Copier du menu contextuel.

 

Remarques :

  • Les boutons copiés depuis une barre d’outils peuvent être collés dans la même barre d’outils, dans une autre barre d’outils du même fichier masques ou dans une barre d’outils d’un fichier masques différent.

  • Vous pouvez copier des boutons de barre d’outils puis les coller dans un menu.
