Supprimer un choix de menu

Pour supprimer un (ou plusieurs) choix existant(s) :

  1. Si ce choix est un choix du menu principal, passez au point suivant.
    Si ce choix est un choix d’un sous-menu de niveau 1, affichez d’abord ce sous-menu en sélectionnant le choix principal correspondant.
    S’il s’agit d’un choix d’un sous-menu de niveau supérieur, poursuivez le même processus jusqu’à afficher ce dernier sous-menu.

  2. Sélectionnez le ou les choix concernés puis validez le choix Supprimer du menu Edition (raccourci clavier Suppr)
    ou
    Cliquez droit     sur le choix (pour le sélectionner) puis validez le choix Supprimer du menu contextuel.

 

Remarque :  dans le cas d'un choix générant un point de traitement, cette opération NE supprime QUE l'objet choix et laisse le code source du traitement inchangé.
