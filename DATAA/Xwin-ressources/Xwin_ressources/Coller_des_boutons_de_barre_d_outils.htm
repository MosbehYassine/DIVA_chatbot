Coller des boutons de barre d'outils

Des opérations de copier / couper / coller peuvent être effectuées sur les boutons d’une barre d’outils. Vous pouvez coller depuis le presse-papiers un ou plusieurs boutons. Pour ce faire :

  1. Sélectionnez le bouton avant lequel vous voulez insérer les boutons à coller (éventuellement par un clic droit).

  2. Validez le choix Coller du menu Edition ou du menu contextuel (raccourci clavier Maj+Inser)
    ou
    Cliquez     sur le bouton de la barre d'outils.

 

Remarques :

  • Les boutons copiés ou coupés depuis une barre d’outils peuvent être collés dans la même barre d’outils, dans une autre barre d’outils du même fichier masques ou dans une barre d’outils d’un fichier masques différent.

  • Vous pouvez copier ou couper des objets boutons d’un masque d’écran puis les coller dans une barre d’outils.

  • Vous pouvez copier ou couper des choix de menu puis les coller dans une barre d’outils.
