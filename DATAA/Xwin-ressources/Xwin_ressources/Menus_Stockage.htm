Menus - Stockage

Les menus font partie des ressources de vos applications. Comme toute ressource, un menu est donc stocké dans un fichier masques d'écran. Vous pouvez :

  • Stocker autant de menus que vous le désirez dans un même fichier masques.

  • Stocker un menu dans un fichier masques différent du fichier contenant le ou les masques avec lesquels ce menu sera affiché à l'exécution (autrement dit, l’utilisation d’un menu à l’exécution n’est pas limitée aux masques du fichier où il est stocké). Par exemple, il est parfaitement possible de dessiner un menu dans un fichier A et, à l’exécution, d’afficher ce menu sur une page de masque du fichier B. L’association d’un menu à une page est faite dans le programme Diva, par des fonctions spécifiques.

  • Stocker la surcharge d’un menu dans un fichier masques différent du fichier contenant le menu surchargé (un menu peut d’ailleurs être surchargé plusieurs fois).

 

Remarque : Si vous effectuez une sauvegarde en édition de masque, de ressources, de menu ou de barre d’outils, vous sauvegardez le fichier masques d’écran concerné en globalité (masque lui-même mais aussi toutes ses ressources, menus et barres d’outils).
