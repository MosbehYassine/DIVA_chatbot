Copier des choix de menu dans le presse-papiers

Des opérations de copier / couper / coller peuvent être effectuées sur les choix d’un menu. Vous pouvez copier dans le presse-papiers soit un choix isolé, soit plusieurs choix du menu principal ou d’un même sous-menu. Dans les deux cas, les sous-menus d’un choix copié sont également copiés. Pour effectuer une copie :

  1. Sélectionnez le ou les choix à copier.

  2. Validez le choix Copier du menu Edition (raccourci clavier Ctrl+Inser)
    ou
    Cliquez     sur le bouton de la barre d'outils
    ou
    Cliquez droit     sur le choix à copier (pour le sélectionner) puis validez le choix Copier du menu contextuel.

 

Remarques :

  • Les choix copiés depuis un menu peuvent être collés dans le même menu, dans un autre menu du même fichier masques ou dans un menu d’un fichier masques différent.

  • Vous pouvez copier des choix de menu puis les coller dans une barre d’outils.
