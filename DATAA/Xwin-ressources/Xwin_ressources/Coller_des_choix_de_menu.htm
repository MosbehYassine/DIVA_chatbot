Coller des choix de menu

Des opérations de copier / couper / coller peuvent être effectuées sur les choix d’un menu. Vous pouvez coller depuis le presse-papiers un ou plusieurs choix, soit dans le menu principal soit dans un même sous-menu. Si des choix copiés comportaient des sous-menus, ceux-ci sont également collés. Pour effectuer un coller :

  1. Si les choix doivent être collés dans le menu principal, passez au point suivant.
    Si les choix doivent être collés dans un sous-menu de niveau 1, affichez d’abord ce sous-menu en sélectionnant le choix principal correspondant.
    Si les choix doivent être collés dans un sous-menu de niveau supérieur, poursuivez le même processus jusqu’à afficher ce dernier sous-menu.

  2. Sélectionnez le choix avant lequel vous voulez insérer les choix à coller (éventuellement par un clic droit).

  3. Validez le choix Coller du menu Edition ou du menu contextuel (raccourci clavier Maj+Inser)
    ou
    Cliquez     sur le bouton de la barre d'outils.

 

Remarques :

  • Les choix copiés ou coupés depuis un menu peuvent être collés dans le même menu, dans un autre menu du même fichier masques ou dans un menu d’un fichier masques différent.

  • Vous pouvez copier ou couper des objets boutons d’un masque d’écran puis les coller dans un menu.

  • Vous pouvez copier ou couper des boutons de barre d’outils puis les coller dans un menu.
