Couper des boutons de barre d'outils

Des opérations de copier / couper / coller peuvent être effectuées sur les boutons d’une barre d’outils. Vous pouvez couper (c’est à dire supprimer avec copie dans le presse-papiers) un ou plusieurs boutons. Pour ce faire :

  1. Sélectionnez le ou les boutons à couper.

  2. Validez le choix Couper du menu Edition (raccourci clavier Maj+Suppr)
    ou
    Cliquez     sur le bouton de la barre d'outils
    ou
    Cliquez droit     sur le bouton à couper (pour le sélectionner) puis validez le choix Couper du menu contextuel.

 

Remarques :

  • Les boutons coupés depuis une barre d’outils peuvent être collés dans la même barre d’outils, dans une autre barre d’outils du même fichier masques ou dans une barre d’outils d’un fichier masques différent.

  • Vous pouvez couper des boutons de barre d’outils puis les coller dans un menu.

  • Dans le cas d'un bouton générant un point de traitement, cette opération NE supprime QUE l'objet bouton et laisse le code source du traitement inchangé.
