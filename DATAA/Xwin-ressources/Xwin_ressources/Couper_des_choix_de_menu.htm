Couper des choix de menu

Des opérations de copier / couper / coller peuvent être effectuées sur les choix d’un menu. Vous pouvez couper (c’est à dire supprimer avec copie dans le presse-papiers) soit un choix isolé, soit plusieurs choix du menu principal ou d’un même sous-menu. Dans les deux cas, les sous-menus d’un choix coupé sont également coupés. Pour ce faire :

  1. Sélectionnez le ou les choix à couper.

  2. Validez le choix Couper du menu Edition (raccourci clavier Maj+Suppr)
    ou
    Cliquez     sur le bouton de la barre d'outils
    ou
    Cliquez droit     sur le choix à couper (pour le sélectionner) puis validez le choix Couper du menu contextuel.

 

Remarques :

  • Les choix coupés depuis un menu peuvent être collés dans le même menu, dans un autre menu du même fichier masques ou dans un menu d’un fichier masques différent.

  • Vous pouvez couper des choix de menu puis les coller dans une barre d’outils.

  • Dans le cas d'un choix générant un point de traitement, cette opération NE supprime QUE l'objet choix et laisse le code source du traitement inchangé.
