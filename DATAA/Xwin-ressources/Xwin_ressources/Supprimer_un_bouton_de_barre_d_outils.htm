Supprimer un bouton de barre d'outils

Pour supprimer un (ou plusieurs) bouton(s) existant(s) :

  • Sélectionnez le ou les boutons concernés puis validez le choix Supprimer du menu Edition (raccourci clavier Suppr)
    ou
    Cliquez droit     sur le bouton (pour le sélectionner) puis validez le choix Supprimer du menu contextuel.

 

Remarque :  dans le cas d'un bouton générant un point de traitement, cette opération NE supprime QUE l'objet bouton et laisse le code source du traitement inchangé.
