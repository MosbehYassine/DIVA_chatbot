XmeGanttAddColumn  Famille Thème

Ajout d'une colonne à afficher

 

Long XmeGantAddColumn (Identifiant, Titre, Binding, Type, [CodePage])

 

Paramètres :
 

Identifiant

Enregistrement identifiant du Gantt rendu par la fonction XmeGanttGetId.

Titre

Libellé d'entête de la colonne à afficher

Binding

Nom de la donnée liée dans ObjectTask

Type

Type d'affichage de la colonne

GANTT_COL_TYPE_NORMAL : colonne normale

GANTT_COL_TYPE_TREE : colonne arborescente

CodePage

Code page des textes (jeu de caractères à utiliser pour afficher les textes en langue étrangère).
Paramètre facultatif (0 par défaut).

 

Valeur rendue par la fonction :

-1 : ticket invalide.

Autre : Adresse de l'élément dans la liste des colonnes.

 

Description de la fonction :

  • La fonction XmeGanttAddColumn ajoute une colonne à afficher sur la gauche de l'objet Gantt.

  • Pour modifier une colonne déjà présente dans cette liste, il faut passer par la fonction XmeGanttModifyColumn.

  • Le paramètre "Binding" correspond au nom de la donnée dans l'enregistrement ObjectTask.

  • Si le paramètre "Binding" est erroné, l'objet affichera alors la donnée "Title".

  • Le paramètre "Type" permet de définir des colonnes de type arbre. Voir Colonnes.

  • Si cette liste est vide, le tableau de gauche n'est pas affiché.

 

Remarque :

Pour optimiser les transferts d'informations avec l'objet Gantt, la liste n'est pas immédiatement mise à jour (elle le sera au prochain affichage des données du Gantt).

 

Exemple :
 

XmeGanttAddColumn(IdGantt, "Titre", "Title", GANTT_COL_TYPE_NORMAL)

XmeGanttAddColumn(IdGantt, "Début", "StartTime")

XmeGanttAddColumn(IdGantt, "Fin", "EndTime")
