Menus : Types de traitement des choix

Les choix terminaux d’un menu peuvent déclencher trois types d’événement ((propriété Type de traitement dans l’éditeur de menus de Xwin) :

  • Génération de caractère.
    La sélection du choix simule la frappe au clavier d'une touche précisée dans la propriété Traitement / Arrêt / Chaîne des choix. La plupart du temps, il s’agira d’une touche de fonction. Consultez l’aide (appel depuis la fenêtre des propriétés) pour connaître la syntaxe que cette chaîne doit respecter.

  • Point d’arrêt.
    La sélection du choix déclenche un point d’arrêt dont le numéro doit être précisé dans la propriété Traitement / Arrêt / Chaîne (numéro compris entre 1 et 65535) des choix.

  • Point de traitement.
    La sélection du choix déclenche un point de traitement. Le source correspondant doit être saisi directement dans Xwin : cliquez dans la colonne de droite de la propriété Traitement / Arrêt / Chaîne des choix puis sur le bouton d’ouverture de la fenêtre d’édition de texte source.
