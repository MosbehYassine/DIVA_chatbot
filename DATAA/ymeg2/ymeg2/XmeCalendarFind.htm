XmeCalendarFind  Famille Thème

XmeCalendarFind permet de rechercher un élément dans une liste non triée (en mode Normal).

Elle balaye séquentiellement la liste et fait toujours une comparaison alpha-numérique.

 

Long XmeCalendarFind (Identifiant, ObjetAChercher, &ObjetTrouve)

 

Paramètre :
 

Identifiant

Identifiant de la liste.

Vous trouverez cet identifiant dans l'enregistrement rendu par la fonction XmeCalendarGetId (Cf. rubrique Interface de programmation d'un agenda).

ObjetAChercher

Instance de l'objet à rechercher

ObjetTrouve

Instance qui contiendra l'objet trouvé

 

Description de la fonction :

Valeur rendue par la fonction :

-1 : ticket invalide.

0 : objet non trouvé

Autre : Adresse de l'élément cherché dans la liste
