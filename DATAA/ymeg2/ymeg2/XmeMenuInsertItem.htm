XmeMenuInsertItem  Famille  Thème

Ajout d’un choix au menu

 

XmeMenuInsertItem (Id_Menu, Caractéristiques, Lieu, Choix_de_référence, Prise_en_compte)

 

Paramètres :

Id_Menu

Identifiant du menu rendu par la fonction XmeMenuGetId.

Caractéristiques

Chaîne de caractères au format HMP (Harmony Markup Parameters), contenant les caractéristiques du choix à créer (voir paragraphe Paramètres de création du nouveau choix ci-après).

Lieu et
Choix_de_référence

L’endroit dans le menu où sera inséré le nouveau choix est défini par ces deux paramètres de la manière suivante :

  • Lieu = MENU_AFTER_ITEM :
    Insertion après le choix identifié Choix_de_référence, au même niveau de menu ou sous-menu.

  • Lieu = MENU _BEFORE_ITEM :
    Insertion avant le choix identifié Choix_de_référence, au même niveau de menu ou sous-menu.

  • Lieu = MENU _FIRST_ITEM :
    Insertion comme premier choix :
    -     Principal si Choix_de_référence = Espace.
    -     Du sous-menu d'en-tête le choix identifié Choix_de_référence sinon.

  • Lieu = MENU _LAST_ITEM :
    Insertion comme dernier choix :
    -     Principal si Choix_de_référence = Espace.
    -     Du sous-menu d'en-tête le choix identifié Choix_de_référence sinon.

Remarques :

Syntaxiquement, Choix_de_référence est un paramètre facultatif valant espace par défaut ; cependant, ce paramètre doit contenir un identificateur de choix valide avec les valeurs MENU_AFTER_ITEM et MENU _BEFORE_ITEM du paramètre Lieu.

Dans le cas d'un menu popup non vide, les valeurs MENU_FIRST_ITEM et MENU_LAST_ITEM du paramètre Lieu NE doivent PAS être employés avec Choix_de_référence égal à espace, puisqu’un menu popup ne comporte qu'un seul choix principal (fictif).

 

Prise_en_compte

TRUE  : le menu doit être immédiatement réaffiché.
FALSE : le menu ne doit pas être immédiatement réaffiché.

FALSE permet d'optimiser les réaffichages du menu lorsque vous effectuez plusieurs créations successives de choix principal : ne mettez ce drapeau à TRUE qu'au tout dernier ajout.

Remarque : dans les versions d'Harmony précédant la version 7, cette optimisation n’affectait pas forcément les performances de manière visible. Mais elle peut s’avérer cruciale en client léger pour éviter un fort ralentissement de l’affichage.

Ce paramètre facultatif (TRUE par défaut) n’est significatif que si le menu est déjà affiché et si le choix concerné est un choix principal.

 

Description de la fonction :

La procédure XmeMenuInsertItem permet d’ajouter dynamiquement un nouveau choix au menu d’identifiant Id_Menu. Utilisez les paramètres Lieu et Choix_de_référence pour préciser le lieu d’insertion du nouveau choix dans le menu (Cf. texte ci-dessus).

 

Paramètres de création du nouveau choix :

Les caractéristiques du nouveau choix doivent être spécifiées dans le paramètre Caractéristiques. Il s’agit d’une chaîne de caractères au format HMP (Harmony Markup Parameters), pouvant contenir les paramètres et valeurs respectives suivants (sauf mention contraire, un paramètre est facultatif) :

<Bouton>

Nom d’un bouton dans la feuille de styles (32 caractères maximum -interdit si choix de type Sous-menu, ignoré si séparateur).
Tous les paramètres de création du choix sont récupérés dans la feuille de styles.
Voir aussi le paragraphe "Cas particulier du paramètre <Bouton>" dans la présente rubrique.

<Ident>

Identificateur.
En final, le choix doit être obligatoirement identifié : si ce paramètre est absent, il faut que le paramètre <Bouton> soit présent et que la zone Identifiant du cadre Ressources soit renseignée dans la feuille de styles.

<Type>

Type et Nature :

  • NORMAL (valeur par défaut) : type Terminal et nature Normal.

  • CASE : type Terminal et nature Case à cocher
    (interdit comme choix principal de menu classique).

  • RADIO : type Terminal et nature Bouton radio
    (interdit comme choix principal de menu classique).

  • SOUS-MENU : type Sous-menu.

  • SEPARATEUR : type Séparateur
    (interdit comme choix principal de menu classique).

<Libelle>

Libellé (hors séparateur, ignoré sinon).
En final, le choix doit être obligatoirement libellé : si ce paramètre est absent, il faut que le paramètre <Bouton> soit présent et que la zone Texte soit renseignée dans la feuille de styles.

<Bitmap>

Nom d’image bitmap dans la feuille de styles (32 caractères maximum -interdit si choix de type Sous-menu, ignoré si séparateur).
Remarque 1 : une 1ère recherche est d'abord effectuée dans les boutons de la feuille de styles ; en cas de succès, le fichier image de ce bouton est utilisé ; en cas d’insuccès, une 2ème recherche est faite dans les images bitmaps de la feuille de styles pour assurer la compatibilité avec la version 5 d’Harmony.
Remarque 2 : aucune vérification n’est effectuée sur son existence.

<NomSelec>

Nom pour la sélection (32 caractères maximum - ignoré si séparateur).

<Aide>

Texte d'aide (ignoré si séparateur).

<Arret>
OU
<Chaine>

Numéro du point d'arrêt ou Chaîne à générer
(interdit si choix de type Sous-menu, ignoré si séparateur).
En final, un choix terminal doit obligatoirement comporter un traitement (et un seul). Si ces deux paramètres sont absents, il faut que le paramètre <Bouton> soit présent et qu’un traitement valide (arrêt ou chaîne) lui soit associé dans la feuille de styles.
Le numéro de point d’arrêt doit être compris entre 1 et 65535. La chaîne doit respecter la même codification que celle utilisée à la saisie, dans les propriétés des choix de Xwin.
Remarque : il n’est pas possible ici d’actionner un point de traitement.

<LicenceConsult>

0 ou 1.
Si cette option est positionnée à la valeur 1, le choix est automatiquement grisé lorsque le programme s'exécute en mode "Licence consultation". Le cas échéant (voir la propriété "Chaine"), l'option invalide aussi automatiquement la touche affectée au choix.

Rappelons que dans ce mode, toute modification dans une base de données Divalto est interdite. On pourra donc activer cette option pour tous les choix commandant une fonction de création, modification ou suppression dans la base.

 

 

Cas particulier du paramètre <Bouton>

Le paramètre <Bouton> permet de récupérer - dans la feuille de styles - des valeurs qui font également l’objet d’un paramètre individuel. Il n’est pas interdit de préciser conjointement le paramètre <Bouton> et un ou plusieurs paramètres individuels. Dans ce cas, chaque paramètre individuel annule et remplace la valeur correspondante trouvée dans la feuille de styles.

 

Restriction d'utilisation du paramètre <Bouton> : L'aide et, le cas échéant, le texte du bouton sont recherchés dans la feuille de styles. Or cette dernière ne fait pas l'objet d'une traduction en langue étrangère. Si votre logiciel doit être traduit, n'utilisez pas ce paramètre ou alors faites-le suivre des paramètres <Aide> et, le cas échéant, <Libelle> avec en paramètre des chaînes de caractères traduites (voir l'instruction Diva Translate).

 

Remarque :

Lorsqu'un même menu est affiché dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de choix, surcharge, ...) sont répercutées dans TOUTES les OCCURRENCES affichées.

 

Exemple :

1 Params 1000

...

 

;Ajout, en fin de menu principal, du choix tête de sous-menu Fichier :

Params = "<Ident>Choix_1<Type>Sous-Menu<Libelle>&Fichier"

XmeMenuInsertItem (Id_menu, Params, MENU_LAST_ITEM)

 

;Ajout, en début du sous-menu Fichier, du choix terminal Ouvrir

;générant le point d’arrêt numéro 11 :

Params = "<Ident>Choix_11<Libelle>&Ouvrir\tCtrl+O<Arret>11" & \

         "<Bitmap>OUVRIR<Aide>Ouverture d’un fichier"

XmeMenuInsertItem (Id_menu, Params, MENU_FIRST_ITEM, "Choix_1") 

 

;Ajout, après le choix Ouvrir, du choix terminal Fermer

;générant le point d’arrêt numéro 12 :

Params = "<Ident>Choix_12<Libelle>&Fermer<Arret>12" & \

         "<Aide>Fermeture d’un fichier"

XmeMenuInsertItem (Id_menu, Params, MENU_AFTER_ITEM, "Choix_11") 

 

;Ajout, après le choix Fermer, du choix terminal Quitter

;entièrement défini dans le bouton Quitter de la feuille de styles :

Params = "<Bouton>Quitter"
XmeMenuInsertItem (Id_menu, Params, MENU_AFTER_ITEM, "Choix_12")

 

;Ajout, en fin du sous-menu Fichier, du choix terminal Zoom articles

;nommé "zoom" pour la sélection et générant la touche de fonction F8 :

Params = "<Ident>Choix_14<Type>Normal<Libelle>&Zoom articles\tF8" & \

         "<Chaine>#F8<Bitmap>ZOOM<NomSelec>zoom" & \

         "<Aide>Appel du zoom des articles"

XmeMenuInsertItem (Id_menu, Params, MENU_LAST_ITEM, "Choix_1")

 

;Ajout, avant le choix Zoom articles, d’un séparateur :

Params = "<Ident>Choix_13<Type>Separateur"

XmeMenuInsertItem (Id_menu, Params, MENU_BEFORE_ITEM, "Choix_14")
