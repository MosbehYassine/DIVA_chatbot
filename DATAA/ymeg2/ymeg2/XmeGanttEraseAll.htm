XmeGanttEraseAll  Famille Thème

Réinitialisation de toutes les listes d'un Gantt

 

Long XmeGanttEraseAll (Identifiant)

 

Paramètre :
 

Identifiant

Enregistrement identifiant le Gantt rendu par la fonction XmeGanttGetId. 

 

Description de la fonction :

Cette fonction efface toutes les listes (tâches, colonnes, ... : Cf. rubrique Interface de programmation d'un Gantt) associées au Gantt.

Voir la fonction Diva ListErase.

 

Remarque :

Pour optimiser les transferts d'informations avec l'objet Gantt, les listes ne sont pas immédiatement effacées (elles le seront au prochain affichage des données du Gantt).
