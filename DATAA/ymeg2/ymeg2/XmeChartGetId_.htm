XmeChartGetId  Famille Thème

Identification et initialisation d'un objet graphe

 

Char XmeChartGetId  (Masque, Page, Chart)

 

Paramètres :
 

Masque

Nom du fichier masque.

Page

Numéro de page.

Chart

Nom de l'objet graphe dans le masque.
 

 

Valeur rendue par la fonction :

Instance d'un enregistrement IdChart du dictionnaire ddsys.dhsd identifiant le graphe (et ses listes).
 

Attention, XmeChartGetId doit être exécuté AVANT le premier affichage de la page Xwin contenant le graphique.

 

Description de la fonction :

  • La fonction XmeChartGetId crée et initialise les listes associées au graphique. A cette occasion, Ywpf garnit un enregistrement, rendu par XmeChartGetId, qui servira à identifier le de manière unique. Aucune fonction gérant le graphique ne peut être appelée AVANT XmeChartGetId.

  • Le graphe est identifié par le Nom du fichier masque plus le Numéro de page où il a été dessiné et par le Nom du graphe qui lui a été attribué dans Xwin (une même page de masque peut contenir plusieurs graphiques de noms différents).
     

Remarques :

  • Le masque doit être préalablement chargé par XmeLoad.

  • Cette fonction nomme les listes afin de faciliter leur reconnaissance dans le débogueur de Xwin.
    Les noms sont calculés en concaténant nom du masque (sans l'extension), numéro de la page, nom du graphique et nom de la liste (en séparant les éléments par un _).

 

Exemple :
 

module ychart.dhop

include zchart.dhsp

record ddsys.dhsd IdChart chartId                

...

XmeLoad ("masque")                               ;chargement du masque

chartId = XmeChartGetId(masque, 1, "PieChart")   ;initialisation du graphique nommé PieChart

                                                 ;et situé dans la page 1 du masque
