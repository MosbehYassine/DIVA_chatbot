Barres d'outils : Types de traitement des boutons

Les boutons terminaux d’une barre d'outils peuvent déclencher trois types d’événement (propriété Type de traitement dans l’éditeur de barres d'outils de Xwin) :

  • Génération de caractères.
    La sélection du bouton simule la frappe au clavier d'une touche précisée dans la propriété Traitement / Arrêt / Chaîne des choix. La plupart du temps, il s’agira d’une touche de fonction. Consultez l’aide (appel depuis la fenêtre des propriétés) pour connaître la syntaxe que cette chaîne doit respecter.

  • Point d’arrêt (*).
    La sélection du bouton déclenche un point d’arrêt dont le numéro doit être précisé dans la propriété Traitement / Arrêt / Chaîne (numéro compris entre 1 et 65535) des boutons.

  • Point de traitement.
    La sélection du bouton déclenche un point de traitement. Le source correspondant doit être saisi directement dans Xwin : cliquez dans la colonne de droite de la propriété Traitement / Arrêt / Chaîne des choix puis sur le bouton d’ouverture de la fenêtre d’édition de texte source.

 

(*) En règle générale, un bouton de barre d'outils est activé uniquement s'il est cliqué avec le bouton gauche de la souris. Un bouton de barre d'outils, défini dans Xwin avec la propriété Type de traitement égale à "Point d'arrêt", fait exception à cette règle. Ceci permet par exemple d'afficher un menu contextuel lorsque l'utilisateur clique sur ce type de bouton avec le bouton droit de la souris (voir la rubrique Clic droit sur un bouton de barre d'outils dans la 1ère partie de la documentation consacrée à l'exécuteur de masques d'écran Ywpf).
