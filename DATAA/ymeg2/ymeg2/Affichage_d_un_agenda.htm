Affichage d'un agenda

 

Le "cadre" d'un objet agenda est affiché par les fonctions classiques d'affichage de page de Ywpf (XmeDisp, etc.). Par contre, aucune fonction de base de Ywpf n'affiche les données d'un agenda. Il faut utiliser pour cela les fonctions spécifiques "agenda" XmeCalendarDisplay ou XmeCalendarConsult.

 

Il n'existe pas de fonction permettant d'afficher un élément isolé d'un agenda. En revanche, tout réaffichage est optimisé de telle manière que seuls les éléments modifiés ou supprimés par rapport à l'état précédent sont actualisés à l'écran.

 

Attention :

  • XmeCalendarGetId doit être exécuté AVANT le premier affichage de la page Xwin contenant l’agenda.

  • Un objet agenda ne peut pas être inclus dans un masque multi-écran (pages chaînées), pour la raison suivante : seule une fonction telle que XmeCalendarDisplay permet d'afficher les données d'un agenda ; dans un masque multi-écran, le passage d'une page à une autre est transparent pour le programme ; celui-ci n'étant pas averti du changement de page, il ne peut appeler XmeCalendarDisplay pour remplir l'agenda et ce dernier sera affiché vide. Vous pouvez toutefois contourner ce problème en remplaçant le masque multi-écran par des masques mono-écran (pages non chaînées), avec programmation explicite des changements de page.
