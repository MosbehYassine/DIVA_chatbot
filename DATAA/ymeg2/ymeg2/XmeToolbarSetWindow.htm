XmeToolbarSetWindowEx

Attachement d’une barre d’outils à une page de masque, pour préparer son affichage

 

XmeToolbarSetWindow (Id_Toolbar, Nom_du_masque, Numéro_de_page)

XmeToolbarSetWindowEx (Id_Toolbar, Nom_du_masque, Numéro_de_page, [Principale])

 

Paramètres :

Id_Toolbar

Identifiant de la barre d'outils rendu par la fonction XmeToolbarGetId.

Nom_du_masque

Nom du fichier masques contenant la page à attacher.

Numéro_de_page

Numéro de cette page dans le fichier masques.

Principale

Positionnez ce paramètre facultatif à TRUE pour afficher une barre d'outils "secondaire" avec le type de rendu "principal". (Cf. rubrique Chargement et affichage.)

 

 

Description de la fonction :

  • Il n’existe pas à proprement parler de fonction Diva pour afficher une barre d'outils mais, pour préparer son affichage dans une fenêtre Harmony, il faut attacher la barre d’outils à une page de masque, par la procédure XmeToolbarSetWindow ou XmeToolbarSetWindowEx. Cet attachement fait que la barre d'outils sera ensuite automatiquement affichée en même temps que la page de masque spécifiée (à l’occasion d’un XmeDisp, XmeDispv, XmeInput, XmeConsult de cette page).

  • Plusieurs barres d'outils peuvent être attachées à une même page : dans ce cas, la fenêtre affichera toutes les barres d’outils simultanément, dans l’ordre des attachements.

  • Par défaut, le rendu de la première barre d'outils affichée est différent du rendu des barres suivantes : Cf. rubrique Chargement et affichage. La fonction XmeToolbarSetWindowEx permet d'obtenir le type de rendu principal pour une barre d’outils secondaire, dans le but d’afficher deux ou plusieurs barres et non une seule sur fond coloré. Mais attention, il est impossible de demander un type de rendu principal pour une page et pas pour une autre (car le type de rendu est déterminé au premier affichage de la barre et ne peut plus évoluer ensuite).

 

En cas d’affichage de différentes pages dans la fenêtre :

Dans une fenêtre Harmony, vous affichez la page de masque P1 à laquelle la barre d'outils M1 est attachée. La barre d'outils M1 s’affiche donc en même temps que la page P1.

Tout d’abord, une première remarque : si la page P1 est affichée en mode GOSUB, sachez que « sa » barre d'outils M1 disparaîtra au XmeRet de P1.

Voyons maintenant ce qui se passe si dans la même fenêtre vous affichez ultérieurement une page de masque P2 :

  1. Affichage de P2 en mode GOTO ou GOSUB, SANS barre d'outils attachée à P2 : la barre d'outils M1 est conservée.
    Ainsi, si votre programme affiche toujours la ou les mêmes barres d'outils (cas le plus courant), attachez ces barres d'outils uniquement à la première page affichée : elles seront ensuite conservées même si d’autres pages sont ultérieurement affichées dans la fenêtre. En particulier, il est donc inutile d'attacher une barre d'outils commune à chaque page d’un masque multi-écran (masque comportant plusieurs pages chaînées) : il suffit de l’attacher à la première affichée.

  2. Affichage de P2 en mode GOTO, AVEC une barre d'outils M2 attachée à P2 : la barre d'outils M2 annule et remplace la barre d'outils M1.

  3. Affichage de P2 en mode GOSUB, AVEC une barre d'outils M2 attachée à P2 : la barre d'outils M2 annule et remplace la barre d'outils M1 mais M1 est réaffichée au XmeRet de P2.

Remarques :

  • Le masque doit être préalablement chargé par XmeLoad.

  • Il est conseillé d’attacher la barre d'outils avant le premier affichage de la page associée (on appellera XmeToolbarSetWindow immédiatement après XmeToolbarGetId).

  • Une même barre d'outils peut être attachée à plusieurs pages différentes (du même fichier masques ou de fichiers masques différents).

  • Il n’est pas possible de supprimer une barre d'outils.

  • Il n’est pas possible de remplacer une barre d'outils par une autre pour une même page de masque (mais il est possible de le faire pour une même fenêtre : attachez la seconde barre d'outils à une deuxième page et affichez cette dernière lorsque la seconde barre d'outils est requise).

  • Une même barre d'outils peut être affichée plusieurs fois dans des fenêtres empilées.

  • L’attachement peut concerner une page d’un fichier masques autre que celui où est dessinée la barre d'outils.

 

Attention :

L’attachement de ressources spécifiques à une page panel n’est pas géré. Lorsqu’une page mère incluant des pages panels est affichée, Ywpf affiche les ressources attachées à cette page mère mais il NE parcourt PAS l’arbre des pages panels pour voir si d'autres ressources leur sont attachées (si c’est le cas, ces attachements sont ignorés). Il faut donc limiter l'attachement de ressources aux seules pages mères.

 

Exemple :

1 Id_toolbar L                         ;ident barre d'outils

...

XmeLoad ("MASQUE")                     ;chargement du masque

                                       ;chargement de la barre 

                                       ;d'outils "OUTILS" 

Id_toolbar = XmeToolbarGetId ("MASQUE","OUTILS")

                                       ;attachement à la page 1

XmeToolbarSetWindow (Id_toolbar,"MASQUE",1) 

 

XmeDisp ("MASQUE",1,XME_MODE_GOTO)     ;affichage page 1 & outils

...
