XmeToolbarEnable  Famille  Thème

Désactivation (grisage) ou réactivation (dégrisage) d’une barre d'outils complète

 

XmeToolbarEnable (Id_Toolbar, Etat)

 

Paramètres :

Id_Toolbar

Identifiant de la barre d'outils rendu par la fonction XmeToolbarGetId.

Etat

FALSE : la barre d'outils doit être globalement désactivée (grisée).
TRUE  : la barre d'outils doit être globalement réactivée (dégrisée).

 

Description de la fonction :

La procédure XmeToolbarEnable permet de désactiver (Etat = FALSE) ou réactiver (Etat = TRUE) globalement la barre d'outils d’identifiant Id_Toolbar. Lorsqu’une barre d'outils est globalement désactivée, tous ses boutons apparaissent grisés à l’écran et aucun ne peut plus être sélectionné par l’utilisateur.

 

Remarques :

  • Il est possible de désactiver plusieurs fois la même barre d'outils. Mais attention, pour que la barre d'outils redevienne opérationnelle, il faut la réactiver autant de fois qu’elle a été désactivée.

  • Cette fonction n’est prise en compte que si la barre d'outils spécifiée est DEJA AFFICHÉE dans la fenêtre EN COURS. Elle est ignorée dans le cas contraire.

  • Si votre programme empile plusieurs fenêtres, il est inutile de désactiver les barres d’outils affichées dans les fenêtres autres que la fenêtre courante car le système les désactive automatiquement.

 

Exemple :

;Invalidation de la barre d'outils complète

XmeToolbarEnable (Id_toolbar,FALSE)
