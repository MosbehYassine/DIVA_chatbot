XmeGanttGetBinaryMaskValues  Famille Thème

Extraction des valeurs unitaires d'un masque binaire

 

String XmeGanttGetBinaryMaskValues (Masque)

 

Paramètre :
 

Masque

Valeur binaire à décomposer.

 

Valeur rendue par la fonction :

Chaîne au format HMP décrivant les valeurs unitaires qui composent le masque binaire.

 

Description de la fonction :

  • La fonction XmeGanttGetBinaryMaskValues permet de décomposer un masque binaire pour obtenir les valeurs unitaires (toutes égales à une puissance de 2) qui ont servi à sa conception.

  • Elle peut être utilisée pour retrouver les valeurs unitaires qui ont été combinées pour former les options du Gantt GANTT_OPT_ACCESS_RIGHTS.
     

Exemple :

Si on lui passe en paramètre la valeur 7, la fonction retourne :

<value>4<value>2<value>1
