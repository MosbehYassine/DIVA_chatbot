XmeMenuCheckItem  Famille  Thème

Coche ou décoche d’un choix de menu de nature case à cocher

 

Ptr XmeMenuCheckItem (Id_Menu, Id_Choix, Etat)

 

Paramètres :

Id_Menu

Identifiant du menu rendu par la fonction XmeMenuGetId.

Id_Choix

Identificateur du choix à cocher ou décocher.

Etat

TRUE  : le choix doit être coché.
FALSE : le choix doit être décoché.

 

Valeur rendue par la fonction :

0 :           Pas d’erreur détectée.
(remarque : aucune erreur n’est signalée - la fonction est ignorée - si le choix spécifié n'est ni de nature "case à cocher" ni de nature "bouton radio")

0x1089 : Choix inconnu dans le menu.

 

Description de la fonction :

La fonction XmeMenuCheckItem permet de cocher (Etat = TRUE) ou décocher (Etat = FALSE) le choix d’identificateur Id_Choix dans le menu Id_Menu. Elle ne s’applique qu’aux choix de nature "case à cocher" ou "bouton radio" (voir première remarque).

 

Programmation d’un choix "case à cocher" :

Initialement, un choix de nature case à cocher est à l’état « non coché ». De plus, lorsque l’utilisateur sélectionne un tel choix, l’état de la coche N’est PAS AUTOMATIQUEMENT actualisé. En conséquence (voir l’exemple), votre programme doit exécuter XmeMenuCheckItem :

  • Avant le premier affichage du menu, pour cocher le choix s’il doit apparaître initialement coché.

  • Ensuite, pour mettre l’état du choix à jour en cas de sélection par l’utilisateur (si l’utilisateur sélectionne un choix non coché, le programme doit le cocher et inversement, si l’utilisateur sélectionne un choix déjà coché, le programme doit le décocher).

 

Remarques :

  • Pour cocher un choix de nature "bouton radio", on utilisera de préférence la fonction XmeMenuCheckRadioItem, qui décoche automatiquement le choix du groupe radio précédemment coché. Toutefois, XmeMenuCheckItem peut être utilisée pour décocher (un à un) TOUS les choix du groupe (ce que ne permet pas XmeMenuCheckRadioItem).

  • Vous pouvez utiliser la fonction XmeMenuIsItemChecked pour connaître l’état courant du choix.

  • Lorsqu'un même menu est affiché dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de choix, surcharge, ...) sont répercutées dans TOUTES les OCCURENCES affichées.

 

Exemple :

...
Id_menu = XmeMenuGetId ("MASQUE","MENU")      ;chargement du menu "MENU"

XmeMenuSetWindow (Id_menu,"MASQUE",1)         ;attachement à la page 1

                                              ;init choix avant affichage

XmeMenuCheckItem (Id_menu,"OPTION_1",TRUE)    ;OPTION_1 coché au départ

                                              ;OPTION_2 non coché 

 

XmeDisp ("MASQUE",1,XME_MODE_GOTO)            ;affichage page 1 & menu

...

 

Fini = FALSE                                  ;consultation tableau

Do

   XmeListConsult (Id_tableau) 

   Switch Harmony.Key 

      Case K_ESCAPE                           ;abandon 

         Fini = TRUE

 

      Case Harmony.DataArret = 101            ;arrêt <-> choix OPTION_1 

         XmeMenuCheckItem (Id_menu,"OPTION_1", \

            not XmeMenuIsItemChecked (Id_menu,"OPTION_1")) 

         ...

 

      Case Harmony.DataArret = 102            ;arrêt <-> choix OPTION_2 

         XmeMenuCheckItem (Id_menu,"OPTION_2", \

            not XmeMenuIsItemChecked (Id_menu,"OPTION_2")) 

         ... 

 

      Case ... 

 

      Default 

         XmeListConsultDefault (Id_tableau,Ligne,Scrollbar32) 

   EndSwitch 

While not Fini

Wend
