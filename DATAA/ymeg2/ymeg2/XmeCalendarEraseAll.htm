XmeCalendarEraseAll  Famille Thème

Réinitialisation de toutes les listes d'un agenda

 

Long XmeCalendarEraseAll (Identifiant)

 

Paramètre :
 

Identifiant

Enregistrement identifiant l'agenda rendu par la fonction XmeCalendarGetId. 

 

Description de la fonction :

Cette fonction efface toutes les listes (rendez-vous, ressources, catégories, ... : Cf. rubrique Interface de programmation d'un agenda) associées à l'agenda.

Voir la fonction Diva ListErase.

 

Remarque :

Pour optimiser les transferts d'informations avec l'objet agenda, les listes ne sont pas immédiatement effacées (elles le seront au prochain affichage des données de l'agenda).
