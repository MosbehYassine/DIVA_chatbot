XmeToolbarSetButtonInfo  Famille  Thème

Modification des paramètres d'un bouton de barre d'outils

 

Ptr XmeToolbarSetButtonInfo (Id_Toolbar, Id_Bouton, Caractéristiques, Prise_en_compte)

 

Paramètres :

Id_Toolbar

Identifiant de la barre d'outils rendu par la fonction XmeToolbarGetId.

Id_Bouton

Identificateur du bouton à modifier.

Caractéristiques

Chaîne de caractères au format HMP (Harmony Markup Parameters), contenant les nouvelles caractéristiques du bouton (voir paragraphe Paramètres de modification du bouton ci-après).

Prise_en_compte

Paramètre obsolète ignoré à partir de la version 7 d'Harmony.

 

Valeur rendue par la fonction :

0 : Pas d’erreur détectée.

0x107B : Bouton inconnu dans la barre d'outils.

 

Description de la fonction :

La fonction XmeToolbarSetButtonInfo permet de modifier certaines caractéristiques actuelles du bouton d’identificateur Id_Bouton dans le barre d'outils Id_Toolbar.

Attention, cette fonction ne permet pas de changer :

  • L’identificateur du bouton.

  • Le type ou la nature du bouton.
    En particulier, la fonction est purement et simplement ignorée si le bouton est un séparateur.

  • L’état (coche, activité ou validité) du bouton.
    Utilisez pour cela les fonctions spécifiques de changement d’état (XmeToolbarCheckButton, XmeToolbarCheckRadioButton, XmeToolbarEnableButton, XmeToolbarValidateButton).

 

Paramètres de modification du bouton :

Les nouvelles caractéristiques du bouton doivent être spécifiées dans le paramètre Caractéristiques. Il s’agit d’une chaîne de caractères au format HMP (Harmony Markup Parameters), avec les particularités suivantes :

  • La valeur actuelle d’un paramètre NON mentionné N’est PAS modifiée.
    Exemple : "<Libelle>Nouveau libellé" modifie le libellé et laisse l'image bitmap inchangée.

  • La valeur actuelle d’un paramètre mentionné mais SANS valeur est annulée.
    Exemple : "<Bitmap><Libelle>Nouveau libellé" modifie le libellé et annule l'image bitmap.

XmeToolbarSetButtonInfo traite les paramètres et valeurs respectives suivants :

<Bouton>

Nom d’un bouton dans la feuille de styles (32 caractères maximum).
Tous les paramètres de modification sont récupérés dans la feuille de styles (les paramètres non modifiables – Ident et Type – ne sont pas repris).
Attention, un paramètre non renseigné dans la feuille efface la valeur correspondante actuelle (une exception toutefois : si aucun traitement valide n’est associé au bouton dans la feuille, le traitement actuel n’est pas modifié).
Remarque : le paramètre <Bouton> sans valeur associée est ignoré.
Voir aussi le paragraphe "Cas particulier du paramètre <Bouton>" dans la présente rubrique.

<Libelle>

Texte du bouton.

<Police>

Nom de la police du texte dans la feuille de styles (32 caractères maximum).

<Bitmap>

Nom d’image bitmap dans la feuille de styles (32 caractères maximum).
Remarque 1 : une 1ère recherche est d'abord effectuée dans les boutons de la feuille de styles ; en cas de succès, le fichier image de ce bouton est utilisé ; en cas d’insuccès, une 2ème recherche est faite dans les images bitmaps de la feuille de styles pour assurer la compatibilité avec la version 5 d’Harmony.
Remarque 2 : aucune vérification n’est effectuée sur son existence.

<NomSelec>

Nom pour la sélection (32 caractères maximum).

<Bulle>

Bulle d'aide.

<Arret>
OU
<Chaine>

Numéro du point d'arrêt ou Chaîne à générer.
Les paramètres <Chaine> et <Arret> ne doivent être ni présents ni annulés simultanément.
Le numéro de point d’arrêt doit être compris entre 1 et 65535. La chaîne doit respecter la même codification que celle utilisée à la saisie, dans les propriétés des boutons de Xwin.
Remarque : il n’est pas possible ici d’actionner un point de traitement.

<LicenceConsult>

0 ou 1.
Si cette option est positionnée à la valeur 1, le bouton est automatiquement grisé lorsque le programme s'exécute en mode "Licence consultation". Le cas échéant (voir la propriété "Chaine"), l'option invalide aussi automatiquement la touche affectée au bouton.

Rappelons que dans ce mode, toute modification dans une base de données Divalto est interdite. On pourra donc activer cette option pour tous les boutons commandant une fonction de création, modification ou suppression dans la base.

 

 

Cas particulier du paramètre <Bouton>

Le paramètre <Bouton> permet de récupérer - dans la feuille de styles - des valeurs qui font également l’objet d’un paramètre individuel. Il n’est pas interdit de préciser conjointement le paramètre <Bouton> et un ou plusieurs paramètres individuels. Dans ce cas, chaque paramètre individuel annule et remplace la valeur correspondante trouvée dans la feuille de styles.
Attention : En modification, les paramètres du nouveau bouton dans la feuille de styles « écrasent » les paramètres actuels ; en particulier, un paramètre existant est effacé s’il n’est pas renseigné dans la feuille (sauf traitement). Le cas échéant, pensez à ajouter au paramètre <Bouton> les paramètres concernés individuellement.

 

Restriction d'utilisation du paramètre <Bouton> : La bulle et, le cas échéant, le texte du bouton sont recherchés dans la feuille de styles. Or cette dernière ne fait pas l'objet d'une traduction en langue étrangère. Si votre logiciel doit être traduit, n'utilisez pas ce paramètre ou alors faites-le suivre des paramètres <Bulle> et, le cas échéant, <Libelle> avec en paramètre des chaînes de caractères traduites (voir l'instruction Diva Translate).

 

Remarque :

Lorsqu'une même barre d'outils est affichée dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de bouton, surcharge, ...) sont répercutées dans TOUTES les OCCURENCES affichées.

 

Exemples :

1 params 1000

...

 

;Modification du libellé :

Params = "<Libelle>Nouveau libellé"

XmeToolbarSetButtonInfo (Id_toolbar, "Bouton", params)

 

;Modification libellé, bitmap, bulle, nom et point d’arrêt :

Params = "<Libelle>Nouveau libellé<Bitmap>BITMAP_BIS" & \

         "<Arret>19<NomSelec>nom_bis<Bulle>Nouvelle bulle"

XmeToolbarSetButtonInfo (Id_toolbar, "Bouton", params) 

 

;Changement complet de bouton :

Params = "<Bouton>Autre_bouton"

XmeToolbarSetButtonInfo (Id_toolbar, "Bouton", params)
