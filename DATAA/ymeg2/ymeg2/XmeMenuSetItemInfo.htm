XmeMenuSetItemInfo  Famille  Thème

Modification des paramètres d'un choix de menu

 

Ptr XmeMenuSetItemInfo (Id_Menu, Id_Choix, Caractéristiques, Prise_en_compte)

 

Paramètres :

Id_Menu

Identifiant du menu rendu par la fonction XmeMenuGetId.

Id_Choix

Identificateur du choix à modifier.

Caractéristiques

Chaîne de caractères au format HMP (Harmony Markup Parameters), contenant les nouvelles caractéristiques du choix (voir paragraphe Paramètres de modification du choix ci-après).

Prise_en_compte

Paramètre obsolète ignoré à partir de la version 7 d'Harmony.

 

Valeur rendue par la fonction :

0 : Pas d’erreur détectée.

0x1089 : Choix inconnu dans le menu.

 

Description de la fonction :

La fonction XmeMenuSetItemInfo permet de modifier certaines caractéristiques actuelles du choix d’identificateur Id_Choix dans le menu Id_Menu.

Attention, cette fonction ne permet pas de changer :

  • L’identificateur du choix.

  • Le type ou la nature du choix.
    En particulier, la fonction est purement et simplement ignorée si le choix est un séparateur.

  • L’état (coche, activité ou validité) du choix.
    Utilisez pour cela les fonctions spécifiques de changement d’état (XmeMenuCheckItem, XmeMenuCheckRadioItem, XmeMenuEnableItem, XmeMenuValidateItem).

 

Paramètres de modification du choix :

Les nouvelles caractéristiques du choix doivent être spécifiées dans le paramètre Caractéristiques. Il s’agit d’une chaîne de caractères au format HMP (Harmony Markup Parameters), avec les particularités suivantes :

  • La valeur actuelle d’un paramètre NON mentionné N’est PAS modifiée.
    Exemple : "<Libelle>Nouveau libellé" modifie le libellé et laisse l'image bitmap inchangée.

  • La valeur actuelle d’un paramètre non obligatoire mentionné mais SANS valeur est annulée.
    Exemple : "<Bitmap><Libelle>Nouveau libellé" modifie le libellé et annule l'image bitmap.

XmeMenuSetItemInfo traite les paramètres et valeurs respectives suivants :

<Bouton>

Nom d’un bouton dans la feuille de styles (32 caractères maximum - interdit si choix de type Sous-menu).
Tous les paramètres de modification sont récupérés dans la feuille de styles (les paramètres non modifiables – Ident et Type – ne sont pas repris).
Attention, un paramètre non renseigné dans la feuille efface la valeur correspondante actuelle (deux exceptions toutefois : si la zone Texte n’est pas renseignée dans la feuille, le libellé actuel n’est pas modifié car il est obligatoire ; si aucun traitement valide n’est associé au bouton dans la feuille, le traitement actuel n’est pas modifié).
Remarque : le paramètre <Bouton> sans valeur associée est ignoré.
Voir aussi le paragraphe "Cas particulier du paramètre <Bouton>" dans la présente rubrique.

<Libelle>

Libellé.

<Bitmap>

Nom d’image bitmap dans la feuille de styles (32 caractères maximum -interdit si choix de type Sous-menu).
Remarque 1 : une 1ère recherche est d'abord effectuée dans les boutons de la feuille de styles ; en cas de succès, le fichier image de ce bouton est utilisé ; en cas d’insuccès, une 2ème recherche est faite dans les images bitmaps de la feuille de styles pour assurer la compatibilité avec la version 5 d’Harmony.
Remarque 2 : aucune vérification n’est effectuée sur son existence.

<NomSelec>

Nom pour la sélection (32 caractères maximum).

<Aide>

Texte d'aide.

<Arret>
OU
<Chaine>

Numéro du point d'arrêt ou Chaîne à générer
(interdit si choix de type Sous-menu).
Les paramètres <Chaine> et <Arret> ne doivent être ni présents ni annulés simultanément.
Le numéro de point d’arrêt doit être compris entre 1 et 65535. La chaîne doit respecter la même codification que celle utilisée à la saisie, dans les propriétés des choix de Xwin.
Remarque : il n’est pas possible ici de générer un point de traitement.

<LicenceConsult>

0 ou 1.
Si cette option est positionnée à la valeur 1, le choix est automatiquement grisé lorsque le programme s'exécute en mode "Licence consultation". Le cas échéant (voir la propriété "Chaine"), l'option invalide aussi automatiquement la touche affectée au choix.

Rappelons que dans ce mode, toute modification dans une base de données Divalto est interdite. On pourra donc activer cette option pour tous les choix commandant une fonction de création, modification ou suppression dans la base.

 

 

Cas particulier du paramètre <Bouton>

Le paramètre <Bouton> permet de récupérer - dans la feuille de styles - des valeurs qui font également l’

objet d’un paramètre individuel. Il n’est pas interdit de préciser conjointement le paramètre <Bouton> et un ou plusieurs paramètres individuels. Dans ce cas, chaque paramètre individuel annule et remplace la valeur correspondante trouvée dans la feuille de styles.
Attention : En modification, les paramètres du nouveau bouton dans la feuille de styles « écrasent » les paramètres actuels ; en particulier, un paramètre existant est effacé s’il n’est pas renseigné dans la feuille (sauf libellé et traitement). Le cas échéant, pensez à ajouter au paramètre <Bouton> les paramètres concernés individuellement.

 

Restriction d'utilisation du paramètre <Bouton> : L'aide et, le cas échéant, le texte du bouton sont recherchés dans la feuille de styles. Or cette dernière ne fait pas l'objet d'une traduction en langue étrangère. Si votre logiciel doit être traduit, n'utilisez pas ce paramètre ou alors faites-le suivre des paramètres <Aide> et, le cas échéant, <Libelle> avec en paramètre des chaînes de caractères traduites (voir l'instruction Diva Translate).

 

Remarque :

Lorsqu'un même menu est affiché dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de choix, surcharge, ...) sont répercutées dans TOUTES les OCCURENCES affichées.

 

Exemples :

1 params 1000

...

 

;Modification du libellé :

Params = "<Libelle>Nouveau libellé"

XmeMenuSetItemInfo (Id_menu, "Choix", params)

 

;Modification libellé, bitmap, aide, nom et point d’arrêt :

Params = "<Libelle>Nouveau libellé<Bitmap>BITMAP_BIS" & \

         "<Arret>19<NomSelec>nom_bis<Aide>Nouvelle aide"

XmeMenuSetItemInfo (Id_menu, "Choix", params)

 

;Changement complet de choix :

Params = "<Bouton>Autre_bouton"

XmeMenuSetItemInfo (Id_menu, "Choix", params)
