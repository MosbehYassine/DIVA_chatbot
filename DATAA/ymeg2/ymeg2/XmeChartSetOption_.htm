XmeChartSetOption Famille Thème

Ajout d'une option dans la liste des options d'un graphique

 

Long XmeChartSetOption (&IdChart, OptionCode, OptionValue)

 

Paramètres :
 

IdChart

Enregistrement identifiant le graphique, rendu par la fonction XmeChartGetId.

OptionCode

Code identifiant l'option ajoutée

OptionValue

Valeur de l'option.

 

Valeur rendue par la fonction :

-1 : ticket invalide.

Autre : Adresse de l’option dans la liste des options.

 

Description de la fonction :

  • La fonction XmeChartSetOption ajoute UNE option à la liste des options de l’agenda.
    Si vous désirez positionner plusieurs options, il faut appeler la fonction pour chacune d'elles.

  • Une option est identifiée par la valeur de son code option. Chaque option est unique, et, en cas d'ajout d'une option qui était déjà dans la liste, le dernier ajout écrase les précédentes valeurs de cette option.

  • La liste des options est disponible dans le fichier zchart.dhsp et à la rubrique
