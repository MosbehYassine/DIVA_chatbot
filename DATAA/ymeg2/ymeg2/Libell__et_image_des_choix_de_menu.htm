Menus : Libellé et image des choix

Hormis les séparateurs, tous les choix d’un menu affichent un libellé (propriété Texte dans l’éditeur de menus de Xwin).

De plus, si le choix est un choix terminal non situé dans la barre de choix principaux d’un menu classique, vous pouvez aussi lui affecter une image bitmap (propriété Nom dans la feuille de style ou Fichier Image dans l’éditeur de menus de Xwin), qui sera affichée devant le libellé.

 

Remarques sur le libellé d’un choix :

Windows permet la sélection d’un choix par un raccourci clavier. Pour sélectionner un choix principal de menu classique au clavier, l’utilisateur doit taper Alt+X, où X désigne le caractère souligné du libellé du choix. Si ce choix ouvre un sous-menu, l’utilisateur doit ensuite taper simplement X, où X désigne à nouveau le caractère souligné du libellé du sous-choix à atteindre, et ainsi de suite.

Pour souligner un caractère du libellé, il faut le faire précéder du caractère conventionnel _. Par exemple :

Libellé : _Fichier affichera le choix Fichier
Libellé : Forma_t affichera le choix Format

 

Hors choix principal, vous pouvez aussi faire figurer dans le libellé les caractères conventionnels "\t" : dans ce cas, les caractères qui suivent seront cadrés à droite. On utilise généralement cette fonctionnalité pour signaler à l’utilisateur le raccourci clavier correspondant à la sélection du choix. Par exemple :

Libellé : _Ouvrir\tCtrl+O affichera le choix Ouvrir  Ctrl+O
Libellé : _Création\tF3  affichera le choix Création  F3
