XmeCalendarGroupByResourceType  Famille Thème

Mise en route d'un regroupement dans l'agenda

 

Long XmeCalendarGroupByResourceType (Identifiant, Type_De_Ressource, [ GroupBy ] )

 

Paramètres :
 

Identifiant

Enregistrement identifiant l'agenda rendu par la fonction XmeCalendarGetId.

Type_De_Ressource

Numéro du type de ressources sur lequel effectuer le regroupement.
Ce numéro est celui fourni lors de la création du type de ressources par la fonction XmeCalendarNewResourceType ou l'un des numéros de type pré-défini.

La valeur 0 permet d'annuler le regroupement en cours.

GroupBy

False par défaut.

Depuis la version 7.3. Indique qu'il faut générer les actions "_GROUPED" en vue regroupée lors des clics. Voir Evénements liés à l'objet agenda.

 

Valeur rendue par la fonction : 1.

 

Description de la fonction :

  • La fonction XmeCalendarGroupByResourceType permet d'opérer un regroupement suivant le type de ressources passé en paramètre.
    Tous les types de vue sont concernés.

  • Pour annuler le regroupement courant, fournissez un numéro de type nul en paramètre à la fonction.

  • Si le paramètre GroupBy est positionné à TRUE, les évènements renvoyés sont ceux suffixés par "_GROUPED". Voir Evénements liés à l'objet agenda.

 

Attention :

Les ressources qui font l'objet d'un regroupement doivent impérativement avoir le même type de ressource.

Supposons par exemple que vous souhaitez effectuer un regroupement sur des personnes (ayant normalement le type de ressources "Personne") et une salle (ayant normalement le type de ressources "Salle"). Pour ce faire, vous devez créer un nouveau type de ressource, commun à ces personnes et à cette salle, et leur affecter ce nouveau type de ressources par la fonction XmeCalendarModify.

Si vous revenez ensuite à une visualisation des informations sans ce regroupement, ré-affectez à ces ressources leur type de ressource "normal".

 

 

Exemple 1 :
 

...

XmeCalendarNewResourceType     (IdCal,4,"REGROUPEMENT","Regroupement",,,"BLEU")

...

XmeCalendarGroupByResourceType (IdCal,4)

 

Exemple 2 :
 

;Annulation du regroupement

XmeCalendarGroupByResourceType (IdCal,0)
