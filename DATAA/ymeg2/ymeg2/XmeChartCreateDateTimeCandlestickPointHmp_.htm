XmeChartCreateDateTimeCandlestickPointHmp Famille Thème

Création de la chaîne hmp décrivant un point de graphique cartésien décrivant une donnée de boursière (ouverture, fermeture, minimum, maximum).

 

Char XmeChartCreateDateTimeCandlestickPointHmp (date, minValue, maxValue, openValue, closeValue, seriesId, pointId, pointLabel, pointColor, pointSelectionColor, tooltip)

 

Paramètres :
 

date

date et heure (DH)

minValue

Valeur minimum (numérique).

maxValue

Valeur maximum (numérique).

openValue

Valeur d'ouverture (numérique)

closeValue

Valeur de fermeture (numérique)

seriesId

Identifiant de la série parente (alphanumérique).

pointId

Identifiant du point (alphanumérique).

pointLabel

Libellé du point (alphanumérique).

pointColor

Couleur du point (alphanumérique).

pointSelectionColor

Couleur de sélection du point (alphanumérique).

tooltip

infobulle (alphanumérique).

 

Valeur rendue par la fonction :

espace : si le paramètre seriesId est absent ou invalide.

Autre : chaîne hmp décrivant le point défini par les paramètres.

 

Description de la fonction :

Cette fonction crée la chaîne hmp qui décrit un point "Ohlc" de graphique cartésien tel que défini par les paramètres.

Les points "Ohlc" sont taillés pour représenter des données boursières, mais conviennent pour toutes situations où un état peut être décrit par quatre paramètres.

Seuls l'identifiant de la série, et les coordonnées du points (category, minValue, maxValue,openValue, closeValue) sont obligatoires.

 

Pré-requis sur les axes :

L'axe des abscisses doit être temporel.

 

Pré-requis sur les séries :

le type de série de la série parente doit être l'un des suivant :

- CHART_OPTV_SR_T_OHLC

- CHART_OPTV_SR_T_CANDLESTICK

 

Remarque : Les fonctions XmeChartCreateDateTimeCandlestickPointHmp et XmeChartCreateDateTimeOhlcPointHmp remplissent le même rôle et sont parfaitement interchangeables.

Deux fonctions distinctes existent afin de pouvoir garder un code le plus cohérent, compréhensible et facilement maintenable.

 

Exemple :
 

module ychart.dhop

include zchart.dhsp

 

...

record ddsys.dhsd IdChart chartId                

...

XmeLoad ("masque")                               ;chargement du masque

chartId = XmeChartGetId(masque, 1, "CartesianChart")   ;initialisation du graphique nommé CartesianChart et situé dans la page 1 du masque

...

XmeChartSetOption(chartId, CHART_OPT_CHART_TYPE, CHART_OPTV_CHART_TYPE_CARTESIAN)

...

ListAddEnd(chartId.IdSeries, XmeChartCreateCartesianSeriesHmp("serie1", CHART_OPTV_SR_T_CANDLESTICK, , , , true))

...          

ListAddEnd(chartId.IdPoints, XmeChartCreateDateTimeCandlestickPointHmp ("20161201130000", 11.7, 27.5, 12.7, 25, "serie1", , "pt1","affok" ))           

...

 

XmeDispv ("masque",1,XME_MODE_GOTO)              ;affiche la page contenant le graphe.

...

XmeChartDisplay (chartId )                       ;affiche les données du graphe.
