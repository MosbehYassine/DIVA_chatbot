XmeGanttConsult  Famille Thème

Consultation d'un Gantt

 

XmeGanttConsult (&Identifiant)

 

Paramètre :
 

Identifiant

Enregistrement identifiant le Gantt rendu par la fonction XmeGanttGetId.

 

Description de la procédure :

  • XmeGanttConsult est la procédure à appeler pour proposer une consultation et attendre un événement sur un objet Gantt.
    Elle NE peut être exécutée QUE si la page de masque contenant le Gantt est la page courante (ou l'une de ses pages panels).

  • La procédure affiche, comme XmeGanttDisplay, les données du Gantt dont l'identifiant est fourni en paramètre (en se limitant à la partie présente à l'écran).

  • Elle se met ensuite en attente d'une frappe au clavier ou d'un événement souris significatif.

  • Le contrôle est rendu au programme appelant dès qu'un événement clavier ou souris est produit par l'utilisateur :

    • Si une touche du clavier a été tapée, la variable Harmony.Key est positionnée à la manière habituelle, de même que les indicateurs ShiftKey et ControlKey.

    • Si un événement souris s'est produit, Harmony.Key est mis à 0.

  • Un délai peut être associé à la fonction XmeGanttConsult, de manière à ce que celle-ci rende la main à intervalles réguliers et ce, même si l'utilisateur ne produit aucun événement clavier ou souris. Pour tous les détails de mise en œuvre, consultez la rubrique consacrée à la fonction XmeSetTimer.

 

Exemple :
 

;Schéma de programmation d'une consultation par XmeGanttConsult

Fini = FALSE

DO                                                ;boucle d'attente

  XmeGanttConsult (IdGantt)                       ;(ré)affiche le Gantt et attend

  SWITCH Harmony.DataArret                        ;événement produit ?

    CASE Harmony.Key = K_ESCAPE                   ;touche Echap :

      Fini = TRUE                                 ;stop

 

    CASE nnn                                      ;point d'arrêt gantt

      SWITCH2 Harmony.GanttClic                   ;test événement gantt produit :

        CASE GANTT_TASK_CLIC                      ;clic sur une tâche

          ...

 

        CASE GANTT_MODIFY_TASK                    ;modification d'une tâche

          ...

 

        CASE ...                                  ;etc.

          ...

 

      ENDSWITCH

 

    CASE ...                                      ;autres cas (menu, barre d'outils, ...)

      ...

 

    ...

 

  ENDSWITCH

WHILE Fini = FALSE

WEND

...

 

 

Remarques :

  • XmeGanttConsult :

    • Valide tous les boutons et choix de menu non nommés.

    • Valide les boutons et choix de menu nommés, à condition qu'ils soient présents dans la liste des boutons valides du Gantt (pour modifier cette liste, cliquez sur la ligne Boutons valides des propriétés du Gantt).

  • Si l'utilisateur clique sur un bouton ou un choix de menu générant un point d'arrêt, la main est rendue au programme ; celui-ci peut récupérer le numéro du point d'arrêt dans Harmony.DataArret ; après le traitement du point d'arrêt, vous pouvez bien entendu rappeler la fonction XmeGanttConsult mais un éventuel code de retour placé dans Harmony.Retour sera ignoré (ce code n'a de sens qu'à l'appel de l'instruction XmeNext).

  • Si l'utilisateur clique sur un bouton ou un choix de menu associé à un point de traitement, la séquence de traitement est exécutée ; au retour de cette séquence, Ywpf revient toujours à la consultation ; les données de la page courante (hors tableaux et Gantt) sont automatiquement réaffichées ; un éventuel code de retour placé dans Harmony.Retour sera ignoré (ce code n'a de sens qu'au retour d'un traitement exécuté en saisie).

  • En consultation par XmeGanttConsult, tous les événements souris significatifs rendent la main. Attention, le numéro du point d'arrêt généré n'est pas transmis dans Harmony.Arret mais dans Harmony.DataArret. Les événements souris traités sont les suivants :

    • Clic "Gantt".
      Outre le numéro du point d'arrêt lié au Gantt transmis dans Harmony.DataArret, le programme peut récupérer tous les renseignements sur le clic produit (Cf. rubrique Evénements liés à l'objet Gantt).

    • Clic "tableau".

    • Clic sur une donnée en saisie.

    • Onglets. Attention, seuls les onglets placés sur des pages non chaînées sont valides ; ceux placés sur des pages chaînées sont ignorés.

 

Appel d’un menu surgissant en consultation de Gantt

Pour afficher un menu surgissant (popup-menu) à l’occasion d’une consultation de Gantt, chargez la donnée Harmony.PopupMenu avec l’identifiant du menu à afficher, avant d’appeler XmeGanttConsult (exemple à la rubrique Menus : Chargement et affichage d'un menu).

 

Appel de l’aide associée à la page consultée

Avec Xwin, vous pouvez associer une aide à toute page de masque. Cette aide servira d’abord d’aide par défaut pour toutes les données présentes dans cette page. Il peut aussi être intéressant d’afficher cette aide si l’utilisateur tape Shift+F1 (touche standard d’appel de l’aide) alors que la page est en consultation par XmeGanttConsult. Pour ce faire, en réponse à la touche Shift+F1, appelez successivement les fonctions XmeInfoPage pour récupérer le nom du fichier d’aides et le numéro de l’aide associée à la page puis le fonction XmeHelp.
