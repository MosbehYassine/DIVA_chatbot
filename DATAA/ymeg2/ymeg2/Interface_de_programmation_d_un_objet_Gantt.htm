Interface de programmation d'un Gantt

 

Les fonctions permettant de programmer l'objet Gantt sont définies dans le module système "yGantt.dhop". Ce module doit être déclaré dans votre programme par :
 

Module "yGantt.dhop"

 

Les fonctions font références à de nombreux "Define" Diva, définis dans le fichier Include "zGantt.dhsp". Vous devez inclure ce fichier dans votre source par :
 

Include "zGantt.dhsp"

 

La programmation d'un Gantt utilise aussi les enregistrements (Record) suivants, définis dans le dictionnaire système "ddGantt.dhsd" :

  • IdGantt.
    Cet enregistrement est la valeur de retour de la fonction XmeGanttGetId. Il est ensuite passé en paramètre à toutes les fonctions concernant le Gantt (voir la rubrique Gestion des listes associées à un objet Gantt).

    Cet enregistrement contient en particulier les identifiants des différentes listes associées au Gantt. Son format est le suivant :

    • IdGantt : Réservé à un usage interne.

    • IdTask : Identifiant de la liste des tâches.

    • IdHighlightedTask : Identifiant de la liste des tâches à afficher en surbrillance.

    • IdColumn : Identifiant de la liste des colonnes.

    • IdOption : Identifiant de la liste des options.

    • Autres : Réservés à un usage interne ou ultérieur.

Attention, XmeGanttGetId doit être exécuté AVANT le premier affichage de la page Xwin contenant le Gantt.
 

  • ObjectTask.
    Enregistrement descriptif d'une tâche.

     

  • ObjectOption.
    Enregistrement descriptif d'une option du Gantt.

 

Voir aussi : Gestion des listes associées à un objet Gantt.
