XmeToolbarDeleteButton  Famille  Thème

Destruction d'un bouton de barre d'outils

 

Ptr XmeToolbarDeleteButton (Id_Toolbar, Id_Bouton, Prise_en_compte)

 

Paramètres :

Id_Toolbar

Identifiant de la barre d'outils rendu par la fonction XmeToolbarGetId.

Id_Bouton

Identificateur du bouton à détruire.

Prise_en_compte

TRUE  : la barre d'outils doit être immédiatement réaffichée.
FALSE : la barre d'outils ne doit pas être immédiatement réaffichée.

FALSE permet d'optimiser les réaffichages de la barre d'outils lorsque vous effectuez plusieurs destructions successives de bouton : ne mettez ce drapeau à TRUE qu'à la toute dernière destruction.

Remarque : dans les versions d'Harmony précédant la version 7, cette optimisation n’affectait pas forcément les performances de manière visible. Mais elle peut s’avérer cruciale en client léger pour éviter un fort ralentissement de l’affichage.

Ce paramètre facultatif (TRUE par défaut) n’est significatif que si la barre d'outils est déjà affichée.

 

Valeur rendue par la fonction :

0 : Pas d’erreur détectée.

0x107B : Bouton inconnu dans la barre d'outils.

 

Description de la fonction :

La fonction XmeToolbarDeleteButton permet de supprimer le bouton d’identificateur Id_Bouton dans la barre d'outils Id_Toolbar.

 

Remarque :

Lorsqu'une même barre d'outils est affichée dans plusieurs fenêtres empilées, ses MISES A JOUR (grisages, invalidations, coches, ajouts ou suppressions de bouton, surcharge, ...) sont répercutées dans TOUTES les OCCURENCES affichées.

 

Exemple :

XmeToolbarDeleteButton (Id_toolbar,"Option")
