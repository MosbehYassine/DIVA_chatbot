XmeCalendarSetOption  Famille Thème

Ajout d'une option dans la liste des options d'un agenda

 

Long XmeCalendarSetOption (Identifiant, Option)

 

Paramètres :
 

Identifiant

Enregistrement identifiant l'agenda rendu par la fonction XmeCalendarGetId.

Option

Instance de l'enregistrement ObjectOption du dictionnaire ddCalendar.dhsd.

 

Valeur rendue par la fonction :

-1 : ticket invalide.

Autre : Adresse de l’option dans la liste des options.

 

Description de la fonction :

  • La fonction XmeCalendarSetOption ajoute UNE option à la liste des options de l’agenda.
    Si vous désirez positionner plusieurs options, il faut appeler la fonction pour chacune d'elles.

  • Pour positionner une option, il faut :

    • Utiliser une instance de l’enregistrement ObjectOption du dictionnaire ddCalendar.dhsd.

    • Préciser l’option choisie dans le champ ObjectOption.Option.

    • Affecter sa valeur dans le champ ObjectOption.Value.
      Remarque : ce champ est de type alphanumérique ; si vous lui affectez une variable binaire (nature B, X ou L), prenez soin de la convertir en alpha par la fonction ToString ; réciproquement, utilisez la fonction Val pour transférer une option dans une variable binaire.

    • Pour une option contenant un libellé, précisez le code page (jeu de caractères à utiliser pour afficher les textes en langue étrangère, sinon 0) dans le champ ObjectOption.CodePage.

    • Ajouter l’option à la liste en exécutant la fonction XmeCalendarSetOption.

  • Attention, les options qui concernent les vues doivent se programmer avant le premier affichage de la page Xwin contenant l’agenda. Ensuite, tout changement sur les vues est ignoré.

Vous trouverez la liste des options disponibles ainsi que des exemples à la rubrique Options de l'agenda.
