XmeToolbarIsButtonChecked  Famille  Thème

Test de l'état d'un bouton de barre d'outils de nature case à cocher ou bouton radio

 

Ptr XmeToolbarIsButtonChecked (Id_Toolbar, Id_Bouton)

 

Paramètres :

Id_Toolbar

Identifiant de la barre d'outils rendu par la fonction XmeToolbarGetId.

Id_Bouton

Identificateur du bouton.

 

Valeur rendue par la fonction :

FALSE :   Le bouton est actuellement décoché.
(valeur aussi rendue si le bouton n’est ni une "case à cocher" ni un "bouton radio")

TRUE :     Le bouton est actuellement coché.

0x107B :  Bouton inconnu dans la barre d'outils.

 

Description de la fonction :

La fonction XmeToolbarIsButtonChecked permet de connaître l’état courant du bouton d’identificateur Id_Bouton dans la barre d'outils Id_Toolbar. Elle ne s’applique qu’aux boutons de nature « case à cocher » ou « bouton radio ».

 

Exemple :

1 Status X

...

Status = XmeToolbarIsButtonChecked (Id_toolbar,"OPTION")

If (Status = TRUE)                     ;le bouton "OPTION" est coché :

   ...                                 ;traitement 

Endif
