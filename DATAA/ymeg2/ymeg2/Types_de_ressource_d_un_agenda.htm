Types de ressource

 

Toute ressource fait référence à un type de ressource.  Chaque type de ressource possède :

  • Une couleur (nom de couleur dans la feuille de styles), qui servira de couleur par défaut pour les ressources concernées.

  • Une image (nom d'image dans la feuille de styles ou nom d'un fichier image : .bmp, .png, ...), qui servira d'image par défaut pour les ressources concernées

  • Un libellé.
     

Trois types de ressource sont pré-définis :

  • Le type Personne (CAL_MANPOWER).

  • Le type Matériel (CAL_MATERIAL).

  • Le type Lieu (CAL_LOCATION).

Il est possible, par programme, de personnaliser un type pré-défini et / ou d'ajouter de nouveaux types de ressource :

  • Pour créer un nouveau type de ressource, faites appel à la fonction XmeCalendarNewResourceType.
    Attention    , il faut affecter au nouveau type un identifiant numérique unique de valeur strictement supérieure à 3 (sinon il s'agira d'une personnalisation d’un type pré-défini).

  • Pour personnaliser un type pré-défini, appelez cette même fonction en lui passant en paramètre l'identifiant concerné (CAL_MANPOWER, CAL_MATERIAL ou CAL_LOCATION).

Le type de ressource est un paramètre de la fonction de création d'une ressource.

L'enregistrement descriptif d'un type de ressource dans le dictionnaire ddCalendar.dhsd est ObjectResourceType.

 

 

Exemples :

  1. Personnaliser le type de ressource "Personne" :

;affecter à chaque ressource de type Personne

;le libellé de type de ressource "Personnel de l’entreprise"

XmeCalendarNewResourceType (IdCal,CAL_MANPOWER,,"Personnel de l’entreprise")

  1. Créer le nouveau type de ressource "Ressource de l’entreprise" :

XmeCalendarNewResourceType (IdCal,4,"Ress_ent","Ressource de l’entreprise")

 

 

Les ressources déclarées avec le même type de ressource peuvent faire l'objet d'un regroupement.
