XmeMenuSetWindow  Famille  Thème

Attachement d’un menu classique à une page de masque, pour préparer son affichage

 

XmeMenuSetWindow (Id_Menu, Nom_du_masque, Numéro_de_page)

 

Paramètres :

Id_Menu

Identifiant du menu rendu par la fonction XmeMenuGetId.

Nom_du_masque

Nom du fichier masques contenant la page à attacher.

Numéro_de_page

Numéro de cette page dans le fichier masques.

 

Description de la fonction :

Il n’existe pas à proprement parler de fonction Diva pour afficher un menu mais, pour préparer l’affichage d’un menu classique dans une fenêtre Harmony, il faut l’attacher à une page de masque, par la procédure XmeMenuSetWindow. Cet attachement fait que le menu sera ensuite automatiquement affiché en même temps que la page de masque spécifiée (à l’occasion d’un XmeDisp, XmeDispv, XmeInput, XmeConsult de cette page).

 

En cas d’affichage de différentes pages dans la fenêtre :

Dans une fenêtre Harmony, vous affichez la page de masque P1 à laquelle le menu M1 est attaché. Le menu M1 s’affiche donc en même temps que la page P1.

Tout d’abord, une première remarque : si la page P1 est affichée en mode GOSUB, sachez que « son » menu M1 disparaîtra au XmeRet de P1.

Voyons maintenant ce qui se passe si dans la même fenêtre vous affichez ultérieurement une page de masque P2 :

  1. Affichage de P2 en mode GOTO ou GOSUB, SANS menu attaché à P2 : le menu M1 est conservé.
    Ainsi, si votre programme affiche toujours le même menu (cas le plus courant), attachez ce menu uniquement à la première page affichée : il sera ensuite conservé même si d’autres pages sont ultérieurement affichées dans la fenêtre. En particulier, il est donc inutile d'attacher un menu commun à chaque page d’un masque multi-écran (masque comportant plusieurs pages chaînées) : il suffit de l’attacher à la première affichée.

  2. Affichage de P2 en mode GOTO, AVEC un menu M2 attaché à P2 : le menu M2 annule et remplace le menu M1.

  3. Affichage de P2 en mode GOSUB, AVEC un menu M2 attaché à P2 : le menu M2 annule et remplace le menu M1 mais M1 est réaffiché au XmeRet de P2.

Remarques :

  • Le masque doit être préalablement chargé par XmeLoad.

  • Il est conseillé d’attacher le menu avant le premier affichage de la page associée (on appellera XmeMenuSetWindow immédiatement après XmeMenuGetId).
    Remarque : Xwpf retaille automatiquement la fenêtre en cas d'ajout d'un menu programmé après le premier affichage mais Xhtml5 (client léger Html) ne le fait pas, ce qui entraîne l’apparition d'ascenseurs.

  • Un même menu peut être attaché à plusieurs pages différentes (du même fichier masques ou de fichiers masques différents). Par contre, il n’est pas possible d’attacher deux menus à une même page (le cas échéant, une erreur est détectée).

  • Il n’est pas possible de supprimer un menu.

  • Il n’est pas possible de remplacer un menu par un autre pour une même page de masque (mais il est possible de le faire pour une même fenêtre : attachez le second menu à une deuxième page et affichez cette dernière lorsque le second menu est requis).

  • Un même menu peut être affiché plusieurs fois dans des fenêtres empilées.

  • L’attachement peut concerner une page d’un fichier masques autre que celui où est dessiné le menu.

  • XmeMenuSetWindow NE concerne PAS les menus surgissant.

 

Attention :

L’attachement de ressources spécifiques à une page panel n’est pas géré. Lorsqu’une page mère incluant des pages panels est affichée, Ywpf affiche les ressources attachées à cette page mère mais il NE parcourt PAS l’arbre des pages panels pour voir si d'autres ressources leur sont attachées (si c’est le cas, ces attachements sont ignorés). Il faut donc limiter l'attachement de ressources aux seules pages mères.

 

Exemple :

1 Id_menu L                                  ;ident menu classique

...

XmeLoad ("MASQUE")                           ;chargement du masque

 

Id_menu = XmeMenuGetId ("MASQUE","MENU")     ;chargement du menu "MENU"

XmeMenuSetWindow (Id_menu,"MASQUE",1)        ;attachement à la page 1

 

XmeDisp ("MASQUE",1,XME_MODE_GOTO)           ;affichage page 1 & menu
