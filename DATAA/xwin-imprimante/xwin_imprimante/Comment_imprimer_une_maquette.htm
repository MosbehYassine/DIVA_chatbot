Comment imprimer une maquette

 

L'impression d'une maquette pré-enregistrée peut être demandée depuis l’assistant de personnalisation des impressions ou depuis l'atelier de développement Xwin.

 

Dans Xwin, vous avez le choix entre les deux méthodes suivantes :

  • Chargez le masque d'impression souhaité.
    Au besoin, activez la fenêtre MDI correspondante.
    Sélectionnez le choix Imprimer une maquette du menu Fichier.
     

  • Dans la fenêtre des projets, cliquez droit sur le nom du fichier masque souhaité.
    Sélectionnez le choix Imprimer une maquette du menu contextuel.

Ces choix ouvrent d'abord une boîte de dialogue permettant de choisir le nom du fichier maquette à imprimer.

 

Remarque :

Imprimer une maquette depuis Xwin permet d’afficher un aperçu de l'état imprimé sans qu'il soit nécessaire de relancer le programme de traitement à chaque nouvel essai. Ceci peut s'avérer nettement plus productif lorsque les temps de traitement sont importants ou lorsque le lancement de l'édition réelle demande du temps (saisie répétitive des paramètres, ...).
