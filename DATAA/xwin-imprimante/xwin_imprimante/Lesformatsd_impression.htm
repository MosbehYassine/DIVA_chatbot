Les formats d'impression

Le champ Format dans la zone Présentation permet de définir un format d'impression pour les champs.

 

Composition du format

Le texte du format est constitué de commandes ou de codes. Vous trouverez ci-après trois tableaux résumant leur signification.

Pour tout renseignement complémentaire, consultez les rubriques associées aux fonctions Format, Formatd et Fstring du livre Diva : Manuel de référence.

Remarques

  • Pour les données de type heure, il n’existe pas de formatage particulier (hors \FormatHeure). Si vous précisez un format, il s’agira d'un format ALPHA

  • Pour les données de type Date+Heure, il n’existe pas de formatage particulier. Si un format d'affichage est précisé, il s'agira d'un format "Date" qui sera appliqué aux 8 premiers caractères de la donnée ; si une saisie sur 14 caractères est demandée, on appliquera sur les 6 autres caractères un format "Heure" standard avec un espace de séparation entre date et heure

  • Pour les données de type Date+Heure, il n’existe pas de formatage particulier. Si un format d'affichage est précisé, il s'agira d'un format "Date" qui sera appliqué aux 8 premiers caractères de la donnée ; sur les 6 autres caractères, un format "Heure" standard sera appliqué, avec un espace de séparation entre date et heure.

  • Pour les données de type "Date mensuelle" , il n’existe pas de formatage particulier. Si un format d'affichage est précisé, il s'agira d'un format "Date" qui sera appliqué aux 6 premiers caractères de la donnée (les 2 derniers caractères seront mis à espace).
