Les multi-choix

Avant d'aborder cette rubrique, il est conseillé de s'être familiarisé au préalable avec les multi-choix "écran" (voir les rubriques correspondantes dans le manuel de référence de Xwin - écran).

 

Le multi-choix consiste à imprimer un texte en fonction d'un code contenu par la donnée, ce code pouvant être numérique (cas le plus courant) ou alpha-numérique. L'impression d'un multi-choix permet donc d'imprimer "en clair" le code contenu par la donnée. Ce code provient généralement de la saisie d'un multi-choix dans un masque écran. La réponse donnée à la saisie est codée et le multi-choix à l'impression permet de décoder la donnée pour imprimer le texte clair correspondant.

Dans Xwin, le fonctionnement du multi-choix dépend du type de choix (avec ou sans valeurs associées) et du type de la donnée (numérique ou alpha-numérique).

 

1. Multi-choix avec valeurs associées

Lorsqu’une valeur est associée à un choix, ce n'est pas le contenu de la réponse sélectionnée par l'utilisateur qui est transféré dans la donnée mais la valeur associée. Mais il faut bien entendu imprimer le libellé correspondant à la valeur contenue par la donnée.

Exemple : Dans un masque écran, nous avons la donnée numérique ETAT, dont voici la liste des choix et des valeurs :
- Marié  1
- Divorcé 3 
- Célibataire 5 
- Veuf  7


La donnée ETAT contient alors : 

- 1 pour Marié
- 3 pour Divorcé
- 5 pour Célibataire
- 7 pour Veuf.

Pour imprimer le libellé correspondant à la valeur, il suffit d'insérer dans le masque un objet de type Multi-choix ayant la même entrée dans le dictionnaire des multi-choix.

 

 

2. Multi-choix sans valeurs associées

Multi-choix sur une donnée numérique

Lorsque la donnée multi-choix est de nature numérique (nombre entier, nature B, X ou L), ce n'est pas le contenu de la réponse sélectionnée par l'utilisateur qui est transféré dans la donnée mais son numéro d'ordre dans la liste de choix. Mais il faut bien entendu imprimer le libellé correspondant au numéro d'ordre contenu par la donnée.

Remarque : la taille du libellé peut être ici quelconque puisque c'est le numéro du choix qui est rangé dans la variable.
 

Exemple : Dans un masque écran, nous avons la donnée numérique ETAT dont voici la liste des choix :
- Marié
- Divorcé
- Célibataire
- Veuf


La donnée ETAT contient donc : 

- 1 pour Marié
- 2 pour Divorcé
- 3 pour Célibataire
- 4 pour Veuf.

Pour imprimer le libellé correspondant à la valeur, il suffit d'insérer dans le masque un objet de type Multi-choix ayant la même entrée dans le dictionnaire des multi-choix.

 

Multi-choix sur une donnée alpha-numérique

Lorsque la donnée multi-choix est de nature alpha-numérique, la valeur sélectionnée par l'utilisateur est directement transférée dans la donnée. Il n'y a donc aucun traitement à faire sur cette donnée pour imprimer son contenu (elle n'est pas codée).

Ce type de donnée sera donc mis dans le masque comme un objet Champ et non comme un objet Multi-choix.

 

Toutefois, le multi-choix en impression sur une donnée alpha-numérique permet d'imprimer un texte différent du contenu de la donnée.

Exemple : La donnée ETAT est maintenant une donnée alpha-numérique de longueur 1, qui contient un des caractères suivant :
- M pour Marié
- D pour Divorcé
- C pour Célibataire
- V pour Veuf.

Nous voulons imprimer non pas ce seul caractère, mais le libellé en entier. Pour cela, nous allons insérer un objet Multi-choix dans le masque et créer une nouvelle entrée dans le dictionnaire des multi-choix. Un choix se compose alors de deux parties :
a. la valeur réelle de la donnée
b. le libellé correspondant à imprimer.

Voici la liste des choix pour l'impression de la donnée ETAT :
- 1 MMarié
- 2 DDivorcé
- 3 CCélibataire
- 4 VVeuf
