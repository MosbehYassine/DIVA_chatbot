Objet Champ

Les paramètres spécifiques d'un objet de type champ sont :

 

Famille Présentation

Multi-ligne

Autorise l'impression sur plusieurs lignes en cas de débordement du contenu du champ dans la boîte.
Voir : Les objets multi-ligne.
 

Multilingue

 

Indique si le contenu de la zone doit être traduit à l'impression.

  • D'après le dictionnaire
    Le paramètre est chargé depuis le dictionnaire de données (valeur par défaut).

  • Oui
    Le contenu du champ doit être traduit. Cela permet de demander la traduction d'un champ pour un bloc de masque en particulier.

  • Non
    Le contenu du champ ne doit pas être traduit.

Voir : Traduction des champs multilingues

 

Format

Définition d'un format d'impression. Voir : Les formats d'impression.

Espace si zéro

Demande l'impression d'une zone à espace si la donnée (de nature numérique ou durée) est nulle.

Impression Hexadécimal

Case à cocher uniquement valide pour les champs de nature B, X, L ou Binaire :
Non Cochée : les données sont imprimées au format entier décimal.
Cochée : elles sont imprimées en hexadécimal.

Remarque : les données de nature "Binaire" sont limitées à quatre octets.
