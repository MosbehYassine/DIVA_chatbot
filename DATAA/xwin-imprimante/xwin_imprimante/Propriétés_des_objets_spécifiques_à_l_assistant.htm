Propriétés des objets spécifiques à l'assistant

 

Pour un objet, les propriétés spécifiques à l'assistant sont regroupées dans la famille Assistant de personnalisation :

 

Masquable par l’utilisateur

Si cette option est positionnée à "Oui", l’utilisateur aura le droit de masquer l'objet au niveau de l'assistant.

Les objets masqués ne sont plus visibles sur l'état imprimé.
 

Par défaut, tous les objets sont masquables. Si un objet doit impérativement figurer dans le document imprimé (par exemple, une donnée qui doit être légalement présente dans une facture), il faut positionner l'option à "Non". Dans l’assistant, les objets non masquables n’apparaissent pas dans la liste des objets à masquer de la "page".
 

Nom pour la personnalisation

Dans l'assistant, une ligne portant cet intitulé est ajoutée à la liste des objets à masquer de la "page". Tous les objets portant le même "Nom pour la personnalisation" (attention, la casse doit être respectée) sont regroupés sous cette ligne, légèrement en retrait (à la manière d'un arbre -limité à deux niveaux-).
 

L'utilisateur conserve la possibilité de masquer ou démasquer les objets nommés individuellement mais il peut aussi invalider ou re-valider la ligne de regroupement, auquel cas, tous les objets concernés sont globalement masqués ou démasqués.
 

Ceci permet par exemple de regrouper tous les objets présents dans un cartouche. L'utilisateur peut alors masquer le cartouche en une seule opération. De même, on peut ainsi grouper un label et le champ correspondant.
 

Un objet ne peut porter qu'un seul "Nom pour la personnalisation".

Il est interdit d'affecter un nom pour la personnalisation à un objet "Non masquable par l'utilisateur".
 

 

Exception :

Les blocs de type Tableau n'étant pas affichés par l'assistant, ces propriétés ne sont pas significatives pour les objets placés dans ce type de bloc. Par contre, l'utilisateur à la possibilité de masquer globalement un bloc de type Tableau (voir la rubrique Propriétés des blocs de type Tableau spécifiques à l'assistant) ou de masquer une colonne de tableau (voir la rubrique Propriétés des colonnes de tableau spécifiques à l'assistant).
