Encadrements

Cette boîte de dialogue permet d'ajouter, de modifier ou de supprimer un encadrement de la feuille de styles. Elle propose la liste des encadrements existants et la zone Nom.

  • Pour modifier un encadrement, sélectionnez-le dans la liste ou tapez son nom puis cliquez sur le bouton Modifier. Vous pouvez également double-cliquer dans la liste des encadrements. La boîte de dialogue "Encadrement" vous permet alors de modifier les caractéristiques de l'encadrement.

  • Pour créer un encadrement, tapez son nom puis cliquez sur le bouton Ajouter.
    La boîte de dialogue "Encadrement" vous permet alors de saisir les caractéristiques de l'encadrement.

  • Pour supprimer un encadrement, sélectionnez-le dans la liste ou tapez son nom puis cliquez sur le bouton Supprimer.

Remarque : si le nom dans la liste est précédé d'une étoile, cela signifie que l'encadrement correspondant se trouve dans la feuille de styles de surcharge.

 

Le seul paramètre d'un encadrement est son type :

  • Sans : l'objet est affiché sans encadrement.

  • Simple : un cadre simple entoure l'objet.

  • Relief relâché : l'objet est affiché dans une surface ayant l'aspect d'un bouton relâché.

  • Relief enfoncé : l'objet est affiché dans une surface ayant l'aspect d'un bouton enfoncé.

  • Cadre relâché : l'objet est entouré d'un cadre donnant l'impression de relief.

  • Cadre enfoncé : l'objet est entouré d'un cadre qui semble s'enfoncer dans le fond.
