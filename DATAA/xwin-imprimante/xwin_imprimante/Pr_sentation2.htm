Présentation

Vous trouverez la documentation des paramètres de présentation communs avec les masque d'écran en suivant le lien Présentation dans la documentation des masques d'écran.

 

Les paramètres spécifiques aux masques d'impression sont :
 

Multi-ligne

Pour les objets concernés (Textes, Champs et Multi-choix), autorise l'impression sur plusieurs lignes en cas de débordement du contenu dans la boîte.
 

Colonne

Pour les objets situés dans un bloc de type Tableau, spécifie la colonne d'appartenance de l'objet (Automatique par défaut).

La modification de ce paramètre ouvre une boîte de dialogue permettant de choisir parmi les possibilités suivantes :

  • *** Aucune ***.
    L'objet n'appartient pas à une colonne précise (colonne 0).

  • *** Automatique ***.
    La colonne d'appartenance est déterminée de manière automatique, en fonction de la position de l'objet dans le tableau.

  • Liste des colonnes du tableau.
    Si vous sélectionnez une colonne dans cette liste, l'objet est considéré comme appartenant à cette colonne, quelque soit sa position réelle dans le tableau.

Les règles d'appartenance d'un objet à une colonne et leur signification sont expliquées à la rubrique Constituants d'un objet Tableau.
