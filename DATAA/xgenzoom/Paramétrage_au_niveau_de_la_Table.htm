Paramétrage au niveau des tables

Les paramètres du générateur de zoom à indiquer dans les propriétés globales (famille Générateur de zoom) des tables du dictionnaire de données sont les suivants :

 

Pour la génération du zoom sur la table elle-même :
 

Numéro du zoom

 

Numéro du zoom dans le fichier menu pour accéder à cette table (Obligatoire).

Titres des onglets

Titres des différents onglets (séparés par une virgule).
Si les champs de la table sont répartis sur plusieurs pages (en mode Fiche), vous pouvez indiquer ici les titres à affecter aux onglets correspondants.
Exemple : Titre un,Titre deux,Titre trois
Remarque : Cette zone est facultative, les titres pouvant être renseignés manuellement après génération du masque.
 

Nom du masque

Nom du source du masque écran (Obligatoire).
Spécifiez ici le nom du source du masque sans son extension .dhse.
 

Nom des traitements

Nom du source des traitements du zoom (Obligatoire).
Spécifiez ici le nom du source des traitements sans son extension .dhsp.
 

Application

Nom de l’application pour l'insertion dans la table des zooms du menu (Obligatoire).
 

Regroupement

Nom du regroupement pour l'insertion dans la table des zooms du menu (Facultatif).
 

Numéro d’ordre

Numéro d’ordre du zoom dans la table des zooms du (regroupement du) menu Divalto.
Si cette zone est laissée à espace, le numéro d'ordre est automatiquement incrémenté (de 10 en 10).
 

Zoom.Res

Préfixe (Obligatoire) affecté à la variable Zoom.Res (gestion du partage), à chaque affectation de cette variable dans le source des traitements généré.
La génération lui ajoutera les champs de la clé primaire.
 

 

Remarque :  Pour générer un zoom sur une table, il est impératif qu’elle dispose d'une clé primaire.

 

 

Pour la génération d'un lien vers la table dans un autre zoom :
 

Libellé

Si la table courante doit apparaître en tant que table liée dans un zoom généré (sur une autre table), sélectionnez ici le champ de la table contenant son "libellé" (le texte identifiant au mieux la fiche pour l'utilisateur).
Exemple : "Des" pour l'enregistrement Art de Divalto.

Dans le zoom appelant généré, ce libellé apparaîtra (en affichage) en face du "code d'accès" (*) à la table liée, afin que l'utilisateur ne voie pas uniquement ce code mais aussi le libellé, plus "parlant".

Pour récupérer ce libellé dans l'enregistrement lié, le code généré inclura la fonction Diva de recherche Iseek. Le drapeau suivant (Aff. libellé mode Liste) permet de restreindre cette recherche au mode Fiche ou de l'inclure aussi aux modes Liste.
 

(*) Attention : si l'index qui donne accès à la table liée est formé de plusieurs données, il faut indiquer au générateur laquelle de ces données doit servir de "code d'accès", c'est à dire de "point de départ" pour appeler le zoom lié. Ce renseignement doit être fourni dans la propriété "Champ principal" de l'index primaire de la table liée.
 

Aff. libellé mode Liste

Positionnez ce drapeau à :

  • Non si vous voulez que la recherche du libellé précédent soit effectuée uniquement en mode Fiche. Cette valeur permet d'accélérer l'affichage en mode Liste.

  • Oui si la recherche doit aussi être faite en mode Liste.
    Attention toutefois : si l'affichage du libellé ne peut guère être pénalisant en mode Fiche (le plus souvent, l'affichage d'une fiche ne nécessitera qu'un nombre réduit de recherches de libellé connexe), le nombre de recherches sera multiplié par le nombre de fiches présentes à l'écran en mode Liste, ce qui pourra provoquer un ralentissement de l'affichage dans ce mode.
