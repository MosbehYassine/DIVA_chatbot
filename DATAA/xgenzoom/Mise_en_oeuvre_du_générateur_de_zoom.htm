Mise en oeuvre du générateur de zoom

 

Remarque préliminaire : Les fonctions de Xwin associées au générateur de zoom nécessitent le paramétrage préalable du générateur (au niveau des propriétés du projet et du dictionnaire des données).

 

Pour faire appel à ces fonctions :

  • Chargez le dictionnaire des données concerné.

  • Cliquez droit sur le nom de l'article désiré dans l'arbre du dictionnaire (partie gauche de l'écran).
    Un menu contextuel est ouvert, proposant en particulier les trois choix suivants (ces choix étant également disponibles au menu Outils du dictionnaire) :
     

    • Générer le zoom.

      Ce choix appelle le générateur de zoom. Après une dernière mise à jour des paramètres, validez pour lancer la génération.

      Si la table fait référence à des tables liées, un tableau est affiché avec la liste de ces tables liées. Cochez les lignes des liens à générer avant de valider.

      La génération crée les fichiers sources et met à jour la table des zooms du menu de l'application. Si une surcharge du fichier contenant la table des zooms (xxxxxU.dhfi) est en ligne, on enregistre le nouveau zoom dans la table de la surcharge ; sinon, on l’enregistre dans la table du fichier paramétré. Vous pouvez indifféremment paramétrer le menu de l'ERP Divalto (fichier A5f) ou un menu Harmony de type hMenu.

      Remarque : Il est possible de relancer plusieurs fois la génération d'un zoom. Ceci vous permet de faire des essais avec divers paramètres ou fichiers modèles de génération. Si le zoom a déjà été généré, vous avez le choix entre tout régénérer, régénérer uniquement le masque ou régénérer uniquement le module de traitements.

      Attention       : Le générateur NE compile PAS automatiquement les sources générés ; cette opération reste à votre charge.
       

    • Mise à jour de la table des zooms.
      Ce choix vous permet une mise à jour à posteriori de la table des zooms du menu de l'application. Si le zoom existe déjà avec des paramètres différents, le générateur propose de les remplacer ; sinon, il ne fait rien.
       

    • Appeler le zoom.
      Ce choix vous permet d'exécuter le zoom généré (sous réserve que vous ayez compilé les sources générés). Il fait appel au programme AppelZoom.dhop dont le source et l'objet sont livrés dans /Divalto/Sys. Vous pouvez modifier ce programme si l'appel de vos zooms nécessite un traitement préalable spécifique.

 

En cas d'erreur de compilation du module des traitements :

Attention, si vous utilisez un modèle de traitements standard et l'option "Générer le zoom dans l'environnement ERP Divalto", vous devez garnir la zone Paramètres des propriétés du projet avec un des paramètres standard. A défaut, il manquera la génération d'un Include qui provoquera des erreurs de compilation.
Exemple : Pour un zoom lié à Achat-Vente, placez "DAV" dans la zone Paramètres.
