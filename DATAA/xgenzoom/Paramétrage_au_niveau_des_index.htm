Paramétrage au niveau des index

Les paramètres du générateur de zoom à indiquer dans les propriétés (famille Générateur de zoom) des index du dictionnaire de données sont les suivants :

 

Champ principal
(index primaire)

Sélectionnez ici le nom du "champ principal" de l’index (dernier champ de l'index par défaut).
Exemple : Tiers dans Index_C_Four.

Avec le champ indiqué ici, le générateur garnit :

  • Zoom.SceValeur dans la séquence ZoomDebut.

  • Zoom.Valeur dans la séquence ZoomValidation.
     

En cas de génération d'un autre zoom contenant un lien faisant référence à cet index, ce nom de champ précise également le "point de départ" dans le masque du zoom appelant. Pour plus de détails à ce sujet, reportez-vous à la description de la propriété "Libellé" dans la rubrique Paramétrage au niveau des tables.
 

Auto-incrémentable
(index primaire)

La valeur Oui indique que l'index est auto-incrémentable.
Dans ce cas, le code généré proposera un numéro ou un code "suivant" lors des créations de fiche.
 

Valeur initiale
(index primaire)

Valeur de départ du champ principal de l'index, utilisée lors de la première création (index auto-incrémentable uniquement).
 

No du mode Liste

Numéro du mode Liste du zoom associé à cet index.
Ce numéro permet de préciser l'ordre des différents modes liste du zoom (qui ne reflète pas obligatoirement l'ordre des index dans le dictionnaire).

Si vous mettez cette zone à 0, cet index ne génèrera pas de mode liste, SAUF si TOUS les index ont leur No du mode Liste à 0, auquel cas toutes les clés génèreront un mode Liste, en suivant l’ordre des index dans le dictionnaire.
