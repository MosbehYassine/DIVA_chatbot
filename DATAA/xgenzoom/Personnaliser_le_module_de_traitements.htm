Personnaliser le module de traitements

 

Remplacement de la chaîne de réservation par un Define Diva

Dans le modèle de traitements, vous pouvez faire figurer la ligne :

Define Xxxx = $res$

  • Si ce Define n'est pas dans le modèle, la ligne de code Zoom.Res = <chaîne à réserver> est générée dans toutes les procédures concernées.

  • Si ce Define se trouve dans le modèle, ces lignes ne sont plus générées. Le générateur remplace simplement "$res$" par la chaîne à réserver. Il faut alors que le modèle contienne la ligne Zoom.Res = Xxxx dans toutes les procédures concernées.

 

Gestion des notes et des fichiers joints

Le zoom généré gère les notes et/ou les fichiers joints à condition :

  • D'avoir coché la case Générer le zoom dans l'environnement ERP Divalto dans la boîte de paramétrage affiché après le lancement du générateur.

  • Que le modèle de traitements le prévoit.

  • Que la table concernée contienne les champs Note et/ou Joint.

Dans les modèles, faites commencer par #NOTE (resp. #JOINT) les lignes de code spécifiques aux Notes (resp. aux  Fichiers joints). Ainsi, ces lignes ne seront pas générées si la table n'est pas concernée.

 

Exemple (Cf. modèles livrés en standard) :

#NOTE XmeMenuEnableItem(Zoom.Idmenu,'NOTE',True)

#JOINT XmeMenuEnableItem(Zoom.Idmenu,'JOINT',True)

 

 

Généralisation à n'importe quel champ

Ce principe peut être généralisé.

Si vous faites commencer une ligne de code du modèle de traitements par #Xxxxx, cette ligne ne sera générée que si la table concernée contient un champ de nom Xxxxx.

 

 

Lignes de code conditionnelles

Dans le but d'utiliser le même modèle pour toutes les applications tout en générant des traitements spécifiques à chacune, il est possible de rendre conditionnelle la génération de certaines lignes de code du modèle. Pour ce faire :

  • "Marquer" les lignes concernées en les faisant commencer par le caractère ">" suivi d’un "mot clé".
    Il est bien entendu possible d'utiliser plusieurs mots clés dans un même source, comme le montre l'exemple suivant (Cf. modèles livrés en standard) :

    >COMMUN Include "A5TCZ000.dhsp"
    >DCPT Include "CCTCZ000.dhsp"
    >DAV Include "GTTCZ00.dhsp"
     

  • Au niveau des paramètres du projet (le projet étant généralement lié à une application), saisissez une liste de mots-clés (séparés par un point-virgule) dans la zone Paramètres. Parmi les lignes conditionnelles, ne seront générées que celles débutant par un mot-clé faisant partie de cette liste de paramètres.

 

Clé d'accès auto-incrémentable

Si vous désirez que la clé principale du zoom soit auto-incrémentable, positionnez la propriété "Auto-incrémentable" à Oui et renseignez la propriété "Valeur initiale" dans les propriétés des index du dictionnaire.

 

 

Garnissage automatique d'une clé

Pour qu'une clé soit automatiquement garnie, renseignez la propriété "Garnissage" dans les propriétés des champs d'index du dictionnaire.
