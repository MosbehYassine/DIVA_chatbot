Utiliser un modèle de masque ou de traitement

Outre les différents paramétrages décrits précédemment, vous disposez d'un autre moyen pour personnaliser la génération de vos zooms : les modèles de masque et de traitements.
 

Un modèle de masque (respectivement un modèle de traitements) est un source de masque (respectivement un source de traitements) de zoom, dont s'inspirera le générateur pour produire un nouveau zoom nécessitant un minimum d'interventions manuelles avant de devenir exploitable.

 

Attention : Pour qu'un modèle soit pris en compte par le générateur, vous devez le spécifier dans la liste des modèles, au niveau des paramètres du projet de votre application.

 

 

Modèle de masque d'écran

Le générateur utilise tout d'abord le masque modèle pour récupérer certains paramètres généraux des pages du masque : type (page ou fenêtre), position et taille à l'écran, couleur de fond, ... Il utilise le dessin des pages du mode Fiche pour effectuer la répartition des données de la table entre les différents onglets. Il utilise le dessin de la page 11 (1er mode Liste) comme modèle de tableau et d'en-tête de saisie de la clé début de recherche (remarque : seule la page 11 est utilisée).

Pour plus de détails à ce sujet, consultez la rubrique Personnaliser le masque d'écran.
 

 

Modèle de traitements

Le générateur génère toutes les lignes de code indispensables au bon fonctionnement du zoom (affectations des clés d'accès et de Zoom.Res, garnissage des clés non saisies, accès aux tables liées, ...). Le modèle de traitements permet d'y ajouter du code personnalisé (séquences ZoomDebut et ZoomArret par exemple).

Pour plus de détails à ce sujet, consultez la rubrique Personnaliser le module de traitements.
 

Remarque : Pour ne pas alourdir inutilement le source des traitements du zoom, certaines fonctions "générales" ne sont pas directement inclues dans le source généré (XzoomGenerator_Zoom_Call, GenZoomIncrementer_Code, ...). Elles sont définies dans le module yZoomGenerator.dhop, dont le source yZoomGenerator.dhsp est livré (dans /Divalto/Sys).

 

 

Modèles "standard"

Plusieurs modèles sont livrés (dans /Divalto/Sys) : ModeleZoom.dhse/dhsp, ModeleZoom1.dhse/dhsp et ModeleZoom2.dhse/dhsp. Vous pouvez les utiliser tels quels ou vous en inspirer pour créer vos propres modèles.
