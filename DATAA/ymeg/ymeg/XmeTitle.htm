XmeTitle  Famille Thème

Changement du titre de la fenêtre Harmony principale

 

XmeTitle (Titre,[CodePage])

 

Paramètre :

Titre
(Harmony.Message)

Nouveau titre de la fenêtre (80 caractères maximum).

CodePage

Code page (code page de l'utilisateur courant par défaut).
Attention : en client léger Wpf et Html, ce paramètre est ignoré ; le code page utilisé est toujours celui de l'utilisateur courant.

 

Description de la fonction :

  • La fonction XmeTitle modifie le titre de la fenêtre courante avec le Titre indiqué puis remet la zone Harmony.Message à espace.
    Elle peut être appelée pour changer le titre de la fenêtre Harmony principale.

  • Le code page permet de sélectionner un jeu de caractères graphiques différent du jeu occidental (voir les fonctions Diva GetLanguageCode et GetLanguageCodePage).

 

Exemple :

XmeTitle ("Nouveau titre")
