XmeListScrollBarInit  Famille Thème

(Re)calcul et (ré)affichage de l'ascenseur vertical d'un tableau

 
XmeListScrollBarInit (Identifiant, Ascenseur)

 
Paramètres :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

Ascenseur

Adresse de l'enregistrement "ascenseur" (on utilisera l'enregistrement standard ScrollBar32 du dictionnaire système DDSYS.dhsd) ; au retour de la procédure, l'enregistrement est actualisé pour refléter l'état de l'ascenseur vertical du tableau.
 

 
Description de la fonction :

  • La procédure XmeListScrollBarInit " calcule " (et affiche) l'ascenseur vertical du tableau dont l'identifiant est fourni en paramètre, en fonction de son état actuel (nombre total d'éléments, nombre de lignes présentes à l'écran, rang du premier élément affiché, présence d'une " ligne de création ").

  • La zone Ascenseur est un paramètre de sortie (sa valeur avant l'appel n'est pas significative), qui recevra les informations de gestion de l'ascenseur actualisées. Elle doit respecter la structure de l'enregistrement standard ScrollBar32 du dictionnaire système DDSYS.dhsd.

Précisément, cette procédure standard (dont le source est fourni à titre d'exemple dans le fichier ZYDEFPRO.dhsp) effectue les opérations suivantes :

  • Chargement de la valeur début à 1 :
    ScrollBar32.PositionMin = 1

  • Chargement de la valeur fin avec le nombre d'éléments présents dans le tableau (avec un minimum de 1) :
    ScrollBar32.PositionMax = MAX (XmeListCount (    Identifiant),1)
     
    Si vous autorisez la création d'un nouvel élément par un clic souris dans la colonne d'état " création ", cette valeur est augmentée de 1 car un élément supplémentaire est compté pour la " ligne de création " (rappelons que cette méthode de création est optionnelle ; pour la valider, appelez la procédure XmeListSetCreatingOption avec le paramètre Création à TRUE) :
    IF XmeListGetCreatingOption (    Identifiant)
    ScrollBar32.PositionMax ++
    ENDIF

  • Chargement du pas " flèche " à 1 :
    ScrollBar32.LineStep = 1

  • Chargement du pas " page " avec le nombre de lignes présentes à l'écran (rappelons que ce pas ne doit toutefois pas dépasser la valeur fin) :
    ScrollBar32.PageStep = MIN (XmeListScreenCount (    Identifiant), ScrollBar32.PositionMax)

  • Chargement de la position courante avec le rang de l'élément affiché en première ligne :
    ScrollBar32.CurrentPosition = XmeListGetOffset (    Identifiant)

  • Affichage de l'ascenseur par XmeListSetScrollBar :
    XmeListSetScrollBar (    Identifiant, Ascenseur)

 
Attention :

  • XmeListScrollBarInit NE peut être appelée QUE si la page de masque contenant le tableau est la page courante (ou une de ses pages panels).

  • Le premier appel à XmeListScrollBarInit doit se faire, le cas échéant, APRES le garnissage initial du tableau et APRES l'appel à XmeListSetCreatingOption.

  • L'initialisation de l'ascenseur vertical du tableau par XmeListScrollBarInit (ou une procédure équivalente) est obligatoire si vous utilisez la procédure standard XmeListConsultDefault.
