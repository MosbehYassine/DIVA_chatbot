Export des données d’un tableau

Le module yListExport.dhop permet en particulier :

  • D’exporter les données d’un tableau (de manière similaire à l’impression paramétré du zoom : fonctions Paramétrer l'impression, Imprimer, Ouvrir les paramètres, Enregistrer les paramètres, Enregistrer les paramètres sous).

  • De filtrer les lignes d’un tableau (de manière similaire à la fonction de filtrage du zoom : fonctions Filtrer et Enlever les filtres).

Ce module peut être appelé par tous les programmes qui gèrent un objet tableau.

 

Il inclut les deux procédures publiques principales :

  • XmeListExportPopupMenu.
    Cette première procédure affiche un menu surgissant contextuel, proposant les fonctions d'export et/ou de filtrage que vous souhaitez fournir à l'utilisateur pour un objet tableau.
     

  • XmeListExport.
    Cette deuxième procédure exécute l'action correspondant au point d'arrêt généré par le choix du menu sélectionné par l'utilisateur.

 

Auxquelles s'ajoute la procédure secondaire suivante :

  • XmeListExportRefreshColumnHeaders.
    Cette procédure réaffiche les étoiles et réinitialise les bulles des en-têtes de colonne du tableau.
    On l'utilisera, lorsqu'un filtre est en cours, après un changement de page de masque suivi du retour à l'affichage du tableau (le changement de page provoquant la perte des attributs dynamiquement modifiés dans ColumnInfo, cette instruction permet de les repositionner).

 

Exemple de programmation :

 

Module "yListExport.dhop"

1 Ident  L

1 Fini   B

...

 

Ligne = " "

XmeLoad ("EOBJTAB")

XmeInfoPage ("EOBJTAB",1)                   ;récupération de la taille de la page 1

XmeSetWindowSize ("EOBJTAB",1,Harmony.Opara3,Harmony.Opara4) ;--> taille initiale de la fenêtre

 

Ident = XmeListGetId ("EOBJTAB",1,"TABLEAU",Ligne)

 

...

XmeDispv ("EOBJTAB",1,XME_MODE_GOTO)        ;affiche page tableau

 

Fini = FALSE

DO

   XmeListConsult (Ident)                   ;consultation

   SWITCH Harmony.Key

      CASE K_ESCAPE                         ;fin

         Fini = TRUE

 

      ;exemple d'appel du menu surgissant : l'utilisateur effectue un Ctrl+Clic

      ;avec le bouton gauche de la souris dans l'en-tête de la colonne d'état

      CASE Harmony.DataArret = <Arret_tableau> \  ;(point d'arrêt <=> tableau concerné)

           and Harmony.TabClic    = LIST_CLICK_HEADING_CONTROL \

           and Harmony.SourisClic = SIMPLE_CLICK \

           and Harmony.SourisBout = LEFT_BUTTON \

           and Harmony.SourisClav = CTRL_CLICK

         XmeListExportPopupMenu (Ident, ZOOM_EXPORT_IMP)

 

      ;XMELIST_ARRET_EXPORT est un Define de zdiva testant que Harmony.Dataarret

      ;contient un numéro de point d'arrêt <=> choix du menu précédent

      CASE XMELIST_ARRET_EXPORT

         XmeListExport (Ident, Ligne, ZOOM_EXPORT_IMP)  ;exécution de l'action

 

      CASE ...                              ;autre événement traité par le pg

         ...

 

      DEFAULT                               ;autres événements traités par défaut

         XmeListConsultDefault (Ident, Ligne, Ascens)

   ENDSWITCH

WHILE Fini = FALSE

WEND
