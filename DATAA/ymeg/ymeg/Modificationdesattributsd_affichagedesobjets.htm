Modification des attributs d'affichage des objets

Cf. fonctions XmeSetAttribut et XmeResetAttribut.

 

Cas particulier des objets affichés plusieurs fois simultanément dans une même fenêtre

Un même objet peut apparaître plusieurs fois dans une même fenêtre lorsque la page Xwin à laquelle il appartient est elle-même affichée plusieurs fois avec différents offsets (remarque : les objets inclus dans un tableau ne sont pas concernés).

Si, pour un tel objet, on désire affecter dynamiquement des attributs différents à chaque occurrence affichée (par exemple, colorer la première en bleu, la seconde en blanc et la troisième en rouge), il faut que ces occurrences portent toutes un nom d’objet différent.

La méthode suivante permet d’attribuer dynamiquement un nom à un objet :

  1. Dans le masque, concaténez au nom concerné la chaîne conventionnelle $L$$C$.
    Exemple     : Bouton$L$$C$

  2. Dans le paramètre Nom des objets des fonctions XmeSetAttribut et XmeResetAttribut applicables à une certaine occurrence de l’objet, concaténez au nom d’objet deux numéros (au format LLLCCC – attention, format figé sur 2x3 chiffres : si un numéro est inférieur à 100, complétez-le avec un ou deux zéros – voir l’exemple ci-dessous), où :

  • LLL est l’offset ligne (Harmony.Oligne) avec lequel la page contenant cette occurrence a été affichée (Cf. rubrique Déplacement d'un masque à l'écran).

  • CCC est l’offset colonne (Harmony.Ocolonne) avec lequel la page contenant cette occurrence a été affichée (Cf. rubrique Déplacement d'un masque à l'écran).

Exemple :

;Nouvelle couleur de fond pour 3 occurrences de l’objet nommé Bouton :

;bleu  : objet dans la page d’offsets ligne=8 , colonne=43

;blanc : objet dans la page d’offsets ligne=11, colonne=43

;rouge : objet dans la page d’offsets ligne=14, colonne=43

XmeSetAttribut ("Bouton008043", AN_COULEUR_FOND, "BLEU")

XmeSetAttribut ("Bouton011043", AN_COULEUR_FOND, "BLANC")

XmeSetAttribut ("Bouton014043", AN_COULEUR_FOND, "ROUGE")
