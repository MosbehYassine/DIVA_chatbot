Exemple de programmation du point d'arrêt "Demande de saisie"

Remarque préliminaire :

Nous considérons ici comme acquises certaines notions fondamentales de la programmation sous Harmony : déclaration des chemins implicites, paramétrage et mise en œuvre des projets dans l'éditeur Xwin, création des bases, tables et champs dans le dictionnaire, création et paramétrage des masques d'écran, etc.

 

Cet exemple montre comment définir et utiliser le point d'arrêt "Demande de saisie" pour autoriser les changements de page à la souris dans un masque du type suivant (Cf. rubrique Programmation du point d'arrêt "Demande de saisie") :

 

+------------------------------------+ <--+

| Code client       : ........       |    |

| Numéro de facture : ........       |    | Page "En-tête"

| ...                                |    |

+------------------------------------+ <--+

                   ...

                   ...

+------------------------------------+ <--+

| Tva               : ........       |    |

| Total             : ........       |    | Page "Pied"

| ...                                |    |

+------------------------------------+ <--+

 
Rappelons que Ywpf ne traite automatiquement les positionnements souris qu'à l'intérieur de la page Xwin en cours de saisie. Un clic souris sur une donnée affichée à l'écran mais située dans une autre page Xwin reste alors sans effet. Ainsi, sans programmation particulière, la souris ne peut être utilisée pour aller de l'en-tête vers le pied ou pour revenir à l'en-tête à partir du pied (car l'en-tête et le pied sont des pages Xwin différentes) :
 

+------------------------------------+

| Code client       : ........       |

| Numéro de facture : ........       |<-------+

| ...                                |        |

+------------------------------------+        |

                   ...                        |

                   ...                        |

+------------------------------------+        |

| Tva               : ........       |        |

| Total             : ........       |<-------+

| ...                                |

+------------------------------------+

<-- Positionnements souris non traités par Ywpf en interne

mais résolus à l'aide de points d'arrêt "Demande de saisie"

 
Dans cet exemple, on procède à la saisie d'un en-tête et d'un pied de facture (voir schéma ci-dessus) :

  • L'en-tête est dessiné en page 1 du fichier masques.
    C'est une zone de 5 lignes, contenant le cadre, les textes et les champs (code client, numéro de facture, etc.) de l'en-tête.

  • Le pied est dessiné en page 2.
    C'est une zone de 5 lignes, contenant le cadre, les textes et les champs (Tva, total, etc.) du pied.

 

1. Déclaration des objets dans le dictionnaire des données

  • Enregistrement " En-tête de facture " (EFACT).
    Créez cet enregistrement (simplifié) avec les données suivantes :
    -     Codcli (10) : Code client.
    -     NumFact (8,0) : Numéro de facture.

  • Enregistrement " Pied de facture " (PFACT).
    Créez cet enregistrement (simplifié) avec les données suivantes :
    -     TVA (2,0) : Code TVA.
    -     Total (14,2) : Montant total.

 

2. Création et paramétrage des masques d'écran

  • Création du fichier masques.
    Créez le nouveau source masques Edemand.dhsf.

  • Déclaration des enregistrements utilisés dans le masque.
    Sélectionnez le choix Enregistrements du menu Paramètres et déclarez les enregistrements EFACT et PFACT.

  • Paramètres de la page 1 (en-tête).
    Libellé     : En-tête de la facture.
    Effacement     : Effacement complet.
    Nombre de lignes     : 23.
    Nombre de colonnes     : 80.
    Arrêt demande de saisie     : 100.

  • Paramètres de la page 2 (pied).
    Libellé     : Pied de la facture.
    Effacement     : Pas d'effacement.
    Nombre de lignes     : 5.
    Nombre de colonnes     : 80.
    Offset ligne     : 16.
    Arrêt demande de saisie     : 101.

 

3. Dessin de la page 1 : En-tête

  • Création des cadre, textes et données de l'en-tête.
    Créez les objets représentés ci-dessous :

+------------------------------------------+

| Code client : AAAAAAAA                   |

| Numéro de facture : AAAAAAAA             |

|                                          |

+------------------------------------------+

  • Paramétrage de la donnée Code client.
    On pourra affecter à cette donnée :
    -     Un point d'arrêt ou de traitement Après, destiné à vérifier que le code introduit existe dans le fichier "Clients".
    -     Un piège de la touche F8, destiné à appeler le zoom "Clients" si l'utilisateur tape F8 en saisie du code.

 

4. Dessin de la page 2 : Pied

  • Création des cadre, textes et données du pied.
    Créez les objets représentés ci-dessous :

+------------------------------------+

| Tva : NN                           |

| Total : NNNNNN                     |

|                                    |

+------------------------------------+

  • Paramétrage de la donnée TVA.
    On pourra affecter à cette donnée un point d'arrêt ou de traitement Après, destiné à recalculer le montant total de la facture.

  • Paramétrage de la donnée Total.
    Ce champ ne doit pas être saisi par l'utilisateur : on le déclarera donc "En affichage".

 

5. Programme Diva

Remarques :

  • Ce schéma de programme a pour but d'illustrer de manière simple la mise en oeuvre des points d'arrêt "Demande de saisie". Il ne prétend pas montrer une véritable saisie d'en-tête et de pied de facture et les procédures de saisie sont réduites au minimum (pour un exemple plus complet de procédure de saisie, consultez la rubrique Exemple général de programmation d'une saisie de masque).

  • On se positionne directement sur la donnée cliquée, grâce à la notion de point de séquence. Rappelons à ce propos :
    1. Qu'un point de séquence est toujours affecté à toutes les données : si vous n'affectez pas vous-même de point de séquence à une donnée au niveau de Xwin, Ywpf lui en affectera un dynamiquement.
    2. Que le paramètre Numéro de point de séquence de la fonction XmeInput permet de démarrer la saisie sur la donnée portant le point de séquence paramétré.
    3. Qu'à l'occasion d'un point d'arrêt "Demande de saisie", le point de séquence de la donnée cliquée est transmis dans Harmony.SourisSeq (avec le numéro de la page Xwin concernée dans Harmony.SourisPage).

 

;Schéma de programmation de points d'arrêt "Demande de saisie"

 

...

 

PUBLIC RECORD Appli.dhsd Efact                     ;enregistrement en-tête

PUBLIC RECORD Appli.dhsd Pfact                     ;               pied

 

1 PtSeq X                                          ;point séquence donnée cliquée

1 Etat X

 

;Fonction : SaisieEntete

;Type : Int

;Description : Saisie de l'en-tête

;En sortie : - 1 = validation

;            - 2 = abandon

;            - 3 = clic sur une donnée du pied

 

FUNCTION INT SaisieEntete (seq)

1 seq X

1 fini X

 

BEGINF

   fini = 0                                        ;page 1 en mode GOTO 

   XmeInput ("EDEMAND",1,seq,XME_MODE_GOTO)        ;(-> directement sur 

   DO                                              ;    la donnée cliquée) 

      SWITCH Harmony.Arret

         CASE Harmony.Key = K_ESCAPE

            fini = 2                               ;abandon

 

         ; CASE xxx                                ;arrêt après saisie code

         ;    ...                                  ;client : test d'existence

 

         ; CASE yyy                                ;piège F8 sur code client :

         ;    ...                                  ;appel du zoom clients

 

         CASE 101                                  ;en-tête => pied :

            PtSeq = Harmony.SourisSeq              ;point séquence donnée cliquée

            fini = 3                               ;sortie

 

                                                   ;après les points d'arrêt 

         CASE Harmony.Key in (K_UP, K_BTAB)        ;flèche en haut ou Back-Tab

                                                   ;sur la 1ère donnée

 

         CASE Harmony.Key in (K_RETURN, K_TAB, K_DOWN)

            fini = 1                               ;validation 

      ENDSWITCH 

 

   WHILE NOT fini 

      XMENEXT (Harmony.Retour, Harmony.CplRetour)

   WEND

 

   FRETURN (fini) 

ENDF

 

 

;Fonction : SaisiePied

;Type : Int

;Description : Saisie du pied

;En sortie : - 1 = validation

;            - 2 = abandon

;            - 3 = clic sur une donnée de l'en-tête

 

FUNCTION INT SaisiePied (seq)

1 seq X

1 fini X

 

BEGINF

   fini = 0                                        ;page 2 en GOSUB

   XmeInput ("EDEMAND",2,seq,XME_MODE_GOTO)        ;(-> directement sur 

   DO                                              ;la donnée cliquée) 

      SWITCH Harmony.Arret

         CASE Harmony.Key = K_ESCAPE

            fini = 2                               ;abandon 

 

         ; CASE xxx                                ;arrêt après saisie code TVA

         ;    ...                                  ;recalcule le total

 

         CASE 100                                  ;pied => en-tête :

            PtSeq = Harmony.SourisSeq              ;point séquence donnée cliquée

            fini = 3                               ;sortie

 

                                                   ;après les points d'arrêt 

         CASE Harmony.Key in (K_UP, K_BTAB)        ;flèche en haut ou Back-Tab

                                                   ;sur la 1ère donnée

 

         CASE Harmony.Key in (K_RETURN, K_TAB, K_DOWN)

            fini = 1                               ;validation 

      ENDSWITCH 

 

   WHILE NOT fini 

      XMENEXT (Harmony.Retour, Harmony.CplRetour)

   WEND

 

   FRETURN (fini) 

ENDF

 

 

;Programme principal

 

MAIN

PtSeq = 0                                          ;initialisations

Efact = " "

Pfact = " "

XmeLoad ("EDEMAND")                                ;chargement masque

XmeInfoPage ("EDEMAND",1)                          ;récupération de la taille de la page 1

XmeSetWindowSize ("EDEMAND",1,Harmony.Opara3,Harmony.Opara4) ;--> taille initiale de la fenêtre

...

XMEDISPV ("EDEMAND",1,XME_MODE_GOTO)

XMEDISPV ("EDEMAND",2,XME_MODE_GOTO)

...

 

REPEAT

   Etat = SaisieEntete (PtSeq)                     ;saisie de l'en-tête 

   IF Etat <> 3 

      EXITREPEAT 

   ENDIF 

   Etat = SaisiePied (PtSeq)                       ;saisie du pied 

   IF Etat <> 3 

      EXITREPEAT 

   ENDIF 

UNTIL Etat <> 3
