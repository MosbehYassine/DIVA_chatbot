XmeInfoPage  Famille Thème

Lecture des caractéristiques d'une page

 

XmeInfoPage (Nom du fichier masque, Numéro de page)

 

Paramètres :

Nom du fichier masque
(Harmony.Ofichier)

Nom du fichier objet (32 caractères maximum).

Numéro de page
(Harmony.Opara1)

Numéro de la page concernée.

 

Description de la fonction :

La fonction XmeInfoPage permet d'obtenir des informations sur la page de masque identifiée par un Nom de fichier masque et par un Numéro de page dans ce fichier. Elle peut par exemple être utilisée pour connaître la taille d'une page ou pour savoir si cette page doit être saisie. L'appel à cette fonction ne modifie pas l'état de Ywpf.

Au retour de la fonction, les informations sont disponibles dans les données Opara1 à Opara6 de l'enregistrement Harmony :

Harmony.Opara1

Offset ligne.

Harmony.Opara2

Offset colonne.

Harmony.Opara3

Nombre de lignes.

Harmony.Opara4

Nombre de colonnes.

Harmony.Opara5

0 si la page est vide
# 0 sinon (fonction XmeDisp(v) possible).
Remarque : une page contenant uniquement un objet tableau est considérée comme non vide.

Harmony.Opara6

0 si la page ne comporte aucune variable en saisie
# 0 sinon (fonction XmeInput possible).
Attention : une page, dont les seules données en saisie appartiennent à un objet tableau, est considérée comme ne comportant pas de variable en saisie (fonction XmeInput impossible ; voir la fonction " tableau " XmeListInputPossible).

Harmony.Opara7

Numéro de la page chaînée suivante, en cas de pages chaînées dans Xwin (ou 0 si la page n'a pas de page suivante).

Remarque : XmeInfoPage « saute » automatiquement les onglets grisés ou cachés par attributs dynamiques mais pas les pages vides.

Harmony.Opara8

Numéro de la page chaînée précédente, en cas de pages chaînées dans Xwin (ou 0 si la page n'a pas de page précédente).

Remarque : XmeInfoPage « saute » automatiquement les onglets grisés ou cachés par attributs dynamiques mais pas les pages vides.

Harmony.Opara9

0 si la page ne contient pas un objet "Grille".
# 0 sinon.

Harmony.AidePgFic
Harmony.AidePgNum

Nom du fichier d’aides et numéro de l’aide déclarée au niveau de la page.
Ces informations peuvent servir à programmer l'appel à cette aide (fonction XmeHelp) en réponse à la frappe de la touche Shift+F1 dans un XmeConsult ou XmeListConsult.

 

Exemple :

XmeInfoPage ("MASQUE",4)      ;demande d'informations sur la

                              ;page 4 du fichier masque "MASQUE"
