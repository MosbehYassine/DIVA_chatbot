XmeGetInputDatasFromPage Famille Thème

Obtenir la liste des données en saisie d'une page

 

Int XmeGetInputDatasFromPage (Nom du fichier masque, Numéro de page)

 

Paramètres :

Nom du fichier masque
(Harmony.Masque)

Nom du fichier masque.

Numéro de page
(Harmony.Page)

Numéro de la page.

 

Valeur rendue par la fonction : Ticket identifiant une liste contenant la description des champs en saisie.

 

 

Description de la fonction :

  • Cette fonction retourne une liste d'éléments.
    La description de ces éléments correspond à la table InputField du dictionnaire ddsys.dhsd. (Record ddsys.dhsd InputField)

Quelques remarques concernant les champs de InputField :

Expression

Expression contient instance.champ(indices). Cela permet de faire un DataDescriptor pour récupérer la valeur du champ.

LibelleDansMasque

Il s'agit du texte se trouvant à gauche de la zone en saisie dans la page.

MnemoRecordDictionnaire

Nom de l'enregistrement dans le dictionnaire dhsd. Dans le cas des recordSql le nom de la table peut être un alias et ne permet pas de retrouver le nom de la table dans le dictionnaire.

TypeObjet

Type de l'objet :
- 2 = objet "Champ".
- 3 = objet "Multi-choix".
- 9 = objet "Bitmap variable".
- 17 = objet "Arbre".

Cadrage

Objet "Champ" ou "Graphique" :
- 1 = Aucun.
- 2 = Gauche.
- 3 = Droite.
- 4 = Centré.
Autres objets : 0.

Nature

Nature de la donnée (type X) :
1 = Numérique (décimales variables).
2 = Numérique (décimales fixes).
3 = Alphanumérique.
4 = Date.
6 = Type B.
7 = Type X.
9 = Type L.
10 = Heure.
11 = Date mensuelle.
12 = Date + heure
13 = Durée.

 

  • Remarques :

    • Après usage, il faut détruire la liste par ListDestroy.

    • Pour les données de type Multi-Choix et Groupe-Radio, la liste des choix (ou des noms de boutons) est placée dans la première propriété associée à l'élément de la liste. Utiliser ListGetProp pour lire cette propriété.

 

Exemple :
 

1 liste L

Record ddsys.dhsd InputField

 

main

   xmeLoad("gtez000_sql.dhof")

   liste = XmeGetInputDatasFromPage(harmony.masque,11)

   ListBegin(liste)

   Loop ListNext(liste,InputField ) <> 0

      display InputField .LibelleDansMasque && " " & InputField .expression

   endloop

   ListDestroy(liste)

   ProgramExit
