DefProcCopier  Famille Thème

Procédure " Copier " d'une ligne de tableau / arbre personnalisée
(appelée par XmeListConsultDefault)

 
DefProcCopier (Identifiant)

 
Paramètre :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

 
Conditions d'exécution de la procédure :

Pour que XmeListConsultDefault fasse appel à DefProcCopier, vous devez :

  • Mettre le paramètre Perso de XmeListConsultDefault à la valeur TRUE.

  • Dans votre programme et avant tout appel à XmeListConsultDefault, placer le nom du module (qui peut être le programme courant) contenant la définition de DefProcCopier, dans la zone DefpModule de l'enregistrement Harmony.

 
Description de la procédure :

  • La procédure DefProcCopier est appelée par XmeListConsultDefault après une demande de " Copier " par l'utilisateur et avant la copie d'une ligne dans le presse-papiers. En cas de copie d'une sélection, elle est appelée avant la copie dans le presse-papiers de CHAQUE ligne sélectionnée.

  • Elle peut être utilisée par exemple pour effectuer une copie personnelle des lignes concernées.
    Remarque : Avant d'appeler DefProcCopier, XmeListConsultDefault fait pointer le courant de la liste sur la ligne à copier et garnit l'enregistrement concerné avec le contenu de cette ligne.

  • En cas de " Copier " d'un élément d'arbre, les sous-niveaux de l'élément sont automatiquement copiés dans le presse-papiers.
    DefProcCopier est alors appelée pour CHAQUE ligne copiée (donc pour l'élément " père " puis pour chaque " descendant ").
    En cas de copie d'une sélection dans un arbre, rappelons que les pères sélectionnés sont tous de même niveau.

  • Lorsque l'utilisateur effectue un " Copier ", un en-tête de reconnaissance personnalisé peut être placé par XmeListConsultDefault dans le presse-papiers. Vous pouvez ensuite consulter cet en-tête lorsque l'utilisateur effectue le " Coller " correspondant. Pour tous les détails à ce sujet, reportez-vous à la rubrique consacrée à la fonction DefProcColler.

 

Attention : DefProcCopier DOIT laisser l'élément courant de la liste inchangé. De plus, c'est l'enregistrement concerné (garni en entrée) lui-même qui sera copié dans le presse-papiers ; si vous changez son contenu, c'est l'enregistrement modifié qui sera copié.
