XmeListGetUserColumns  Famille Thème

Lecture de la liste des numéros des colonnes d'un tableau affichées par l'utilisateur
(liste délivrée dans l'ordre défini dans Xwin)

 
Char XmeListGetUserColumns (Identifiant)

 
Paramètre :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

 
Valeur rendue par la fonction :

Chaîne de caractères contenant la liste des numéros de colonne séparés entre eux par un ";" (point virgule). La première colonne porte le numéro 1.
Exemple : "1;2;3;6;13".

 
Description de la fonction :

La fonction XmeListGetUserColumns permet de récupérer la liste des numéros des colonnes affichées par l'utilisateur pour le tableau passé en paramètre.

Attention, les numéros de colonne sont délivrés ici dans l'ordre défini dans Xwin. Pour obtenir les numéros de colonne dans l'ordre d'affichage demandé par l'utilisateur, utilisez la fonction XmeListGetUserOrderedColumns.

 
Attention :  XmeListGetUserColumns NE peut être appelée QUE si la page de masque contenant le tableau est la page courante.

 

Exemple :
 

1    colonnes    S
colonnes = XmeListGetUserColumns (Ident)

 

Remarque : XmeListGetColumn permet aussi de lire la valeur du paramètre "Affichage" d'une colonne, qui a été paramétrée dans Xwin par le développeur (ColumnInfo.Affichage).
