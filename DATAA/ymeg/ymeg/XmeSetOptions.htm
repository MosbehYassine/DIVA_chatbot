XmeSetOptions  Famille Thème

Positionnement des options complémentaires :

  • Paramétrage de la fermeture du navigateur Web (client léger Html uniquement)

 

XmeSetOptions (Options)

 
Paramètre :

Options

Chaîne au format HMP, contenant la liste des options complémentaires.

 

Description de la fonction : Cette fonction permet de spécifier des options de fonctionnement complémentaires. Garnissez le paramètre Options avec ces options, au format Hmp :

 

  • Paramètre HMP activant ou annulant la demande de confirmation de la fermeture du navigateur Web.
    C    lient léger Html uniquement.
    Pour tous les détails concernant cette fermeture, voir la     rubrique Traitements effectués en cas de fermeture du navigateur.

<HTMLBrowserCloseWarning>

Texte du message (ou vide pour annuler une demande de confirmation précédente).

Exemples :

  • Activation :
    Message = Translate ("Texte du message")           ;texte du message traduit
    XmeSetOptions ("<HTMLBrowserCloseWarning>" & Message)

  • Annulation d'une demande précédente :
    XmeSetOptions ("<HTMLBrowserCloseWarning>")  ;texte vide
