XmeListExportPopupMenu  Famille Thème

Appel du menu surgissant pour l'export et le filtrage des données d'un tableau

 

XmeListExportPopupMenu (Identifiant, Pexport, [Pfiltre])

 
Paramètres :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

Pexport

Paramètre de gestion de l’export (Cf. variable Zoom.SceExport).

Pfiltre

Positionnez cette option à TRUE si vous autorisez le filtrage des éléments du tableau, à FALSE sinon (valeur par défaut).

 
 
Description de la procédure :

  • Cette procédure demande l'affichage d'un menu surgissant contextuel proposant les choix suivants :

    • Export des données d’un tableau (de manière similaire à l’impression paramétré du zoom) :
      Paramétrer l'impression       (paramétrage de l'édition et export ; point d'arrêt numéro 15)
      Imprimer       (demande d'impression ; point d'arrêt numéro 24)
      Ouvrir les paramètres       (ouverture d'un fichier de sauvegarde des paramètres ; point d'arrêt numéro 12).
      Enregistrer les paramètres       (enregistrement des paramètres dans un fichier ; point d'arrêt numéro 13).
      Enregistrer les paramètres sous       (idem dans un autre fichier ; point d'arrêt numéro 14).

    • Filtrage des lignes d’un tableau (de manière similaire à la fonction de filtrage du zoom) :
      Filtrer       (saisie des filtres ; point d'arrêt numéro 10).
      Enlever les filtres       (annulation des filtres ; point d'arrêt numéro 7).

  • Suivant les fonctions d'export et/ou de filtrage que vous souhaitez fournir pour l'objet tableau Identifiant, déterminez les choix effectivement proposés à l'utilisateur grâce aux paramètres Pexport et Pfiltre.

  • Chaque choix du menu génère un point d'arrêt.
    Vous pouvez ensuite appeler la fonction XmeListExport pour traiter ce point d'arrêt et exécuter l'action correspondante.

  • XmeListExportPopupMenu est définie dans le module yListExport.dhop. Votre programme doit donc déclarer ce module
    (Module "yListExport.dhop") avant d'y faire appel.
