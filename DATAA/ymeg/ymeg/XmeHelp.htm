XmeHelp  Famille Thème

Affichage d'une aide fenêtrée

 

XmeHelp (Nom du fichier d'aides, Numéro de l'aide)

 

Paramètres :

Nom du fichier d'aides
(Harmony.Ofichier)

Nom du fichier contenant les textes d'aide (28 caractères maximum, l'extension étant automatiquement ajoutée au nom indiqué).
Il est possible d’afficher l'aide fenêtrée dans une fenêtre secondaire. Pour ce faire, faites suivre le nom du fichier du caractère ">" puis du nom donné à la fenêtre secondaire (fenêtre généralement dénommée « Secondary Windows » dans les outils de développement d’aides). Par exemple : Aides>Second

Numéro de l'aide
(Harmony.Opara1)

Numéro de l'aide à afficher ou
65534 pour afficher le sommaire de l'aide avec fichier .cnt ou
65535 pour afficher le sommaire de l'aide sans fichier .cnt.

 

Description de la fonction :

  • La fonction XmeHelp demande l'affichage de l'aide fenêtrée identifiée par un Nom de fichier d'aides et par un Numéro d'aide dans ce fichier.

  • Le fichier d'aides doit avoir le format standard des aides Windows (fichier .chm ou .hlp). L’extension n’a pas besoin d’être précisée.

  • En remplaçant le numéro d'aide classique par 65534 ou 65535, vous demandez l'affichage du sommaire de l'aide : utilisez 65534 lorsque vous livrez un fichier .cnt en plus du fichier .hlp ou un fichier .chm, 65535 sinon.

  • Ywpf appelle cette fonction en interne :
    -     Quand l'utilisateur tape la touche Shift+F1 (ou clique sur un bouton équivalent), en saisie d'une donnée pour laquelle vous avez défini une aide fenêtrée dans l'éditeur de masques de Xwin.
    -     Quand l'utilisateur clique sur le bouton d'aide de la barre de titre de la fenêtre puis clique sur une donnée pour laquelle vous avez défini une aide fenêtrée dans l'éditeur de masques de Xwin.

  • Dans vos programmes Diva, vous pouvez utiliser la fonction XmeHelp pour imposer l'affichage d'une aide fenêtrée.
    Vous pouvez aussi l'utiliser pour simuler le traitement interne de Ywpf lors d'une consultation de masque (XmeConsult, XmeListConsult). En consultation par ces fonctions, Ywpf utilise en effet une donnée interne de 1 caractère pour permettre à l'utilisateur d'effectuer une entrée clavier. Cette donnée ne faisant pas partie du masque, il vous est impossible de lui associer une aide au niveau de l'éditeur de masques de Xwin. Vous pouvez par contre programmer l'affichage de cette aide, en réponse à la frappe de la touche Shift+F1 (voir l'exemple).

 

Exemple :

fini = 0

LOOP fini = 0

   XmeConsult ("MASQUE",1,XME_MODE_GOTO);consultation page 1 

                                        ;fichier masque "MASQUE" 

   SWITCH Harmony.Key                   ;test du caractère tapé 

                                        ;par l'utilisateur 

      CASE K_SF1                        ;touche Shift+F1

         XmeInfoPage ("MASQUE",1)       ;recherche aide dans le masque

         XmeHelp (Harmony.AidePgFic,Harmony.AidePgNum)

 

      CASE K_ESCAPE                     ;touche Echap

         fini = 1                       ;fin

 

      ... 

   ENDSWITCH
