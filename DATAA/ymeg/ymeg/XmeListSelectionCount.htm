XmeListSelectionCount  Famille Thème

Lecture du nombre d'éléments marqués ou sélectionnés d'un tableau

 
Long XmeListSelectionCount (Identifiant)

 
Paramètre :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

 
Valeur rendue par la fonction : Nombre de lignes marquées du tableau.

 
Description de la fonction :

La fonction XmeListSelectionCount délivre le nombre total de lignes marquées du tableau dont l'identifiant est fourni en paramètre (pour plus de détails, voir les rubriques Marquage des lignes d'un tableau et Sélection multiple des lignes d'un tableau). Les éléments marqués sont ceux dont le champ " Sélection " de la donnée de contrôle associée (Donnée de contrôle.Selection) vaut TRUE.

 

XmeListSelectionCount est une facilité d'écriture qui équivaut à programmer les instructions suivantes :
 

;Compteur = XmeListSelectionCount (Ident)

 

XmeListGetPosition (Ident, Position)

XmeListBegin (Ident)

Compteur = 0

LOOP XmeListNext (Ident, Ligne) <> 0

   IF RowInfo.Selection

      Compteur ++

   ENDIF 

ENDLOOP

XmeListSetPosition (Ident, Position)

XmeListCurrent (Ident, Ligne)

 

Exemple :
 

Compteur = XmeListSelectionCount (Ident)
