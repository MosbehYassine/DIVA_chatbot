XmeListGetCreatingOption  Famille Thème

Lecture de l'option "Création dans un tableau par un clic souris dans la colonne d'état"

 
Bin XmeListGetCreatingOption (Identifiant)

 
Paramètre :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

 
Valeur rendue par la fonction :

  • TRUE si vous avez autorisé l'utilisateur à cliquer souris dans la colonne d'état " création ", en regard de la première ligne vide du tableau, pour créer un nouvel élément.

  • FALSE dans le cas contraire.

 
Description de la fonction :

La fonction XmeListGetCreatingOption permet de consulter la valeur courante de l'option positionnée par XmeListSetCreatingOption (FALSE par défaut).

 

Exemple :
 

Drapeau = XmeListGetCreatingOption (Ident)
