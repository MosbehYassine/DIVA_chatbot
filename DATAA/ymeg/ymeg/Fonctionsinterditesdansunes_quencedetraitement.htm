Fonctions interdites dans une séquence de traitement

Les fonctions suivantes de Ywpf ne peuvent être appelées dans une séquence de traitement du masque :

  • XmeNext.

  • XmeRet.

  • XmeExecuteTreatmentAfter et XmeListExecuteTreatmentAfter.

  • XmeInputEndTreatment.

 

De plus, les fonctions suivantes sont interdites en mode GOTO dans une séquence de traitement :

  • XmeClearv.

  • XmeConsult.

  • XmeDisp.

  • XmeDispv.

  • XmeInput.

 

Enfin, tout appel isolé d'une page panel dans un point de traitement est interdit (voir la rubrique Conditions d'appel isolé d’une page panel).
