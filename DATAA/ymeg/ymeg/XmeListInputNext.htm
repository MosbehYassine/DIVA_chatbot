XmeListInputNext  Famille Thème

Reprise de la saisie d'une ligne d'un tableau

 
XmeListInputNext (Identifiant, Code retour, Code complémentaire)

On écrira généralement :
XmeListInputNext (Identifiant, Harmony.Retour, Harmony.CplRetour)

 
Paramètres :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

Code retour

Code de retour principal.

Code complémentaire

Code de retour complémentaire.

 
Description de la fonction :

Après une interruption de la saisie d'une ligne de tableau (dont l'identifiant est indiqué en paramètre), suite à un point d'arrêt ou à un piège de touche, le programme peut demander la reprise de la saisie, en appelant la procédure XmeListInputNext avec les Codes de retour appropriés (exactement comme un XmeNext poursuit une saisie lancée par XmeInput).
Une saisie de ligne de tableau diffère peu d'une saisie habituelle de page de masque. Pour tous renseignements complémentaires, consultez le chapitre Programmation de la saisie d'un masque et la rubrique consacrée à la procédure XmeNext.

 
Attention :

  • XmeListInputNext ne doit pas être utilisée pour LANCER la saisie de la ligne : il faut pour cela appeler la procédure XmeListInput.

  • XmeListInputNext n'actualise pas les lignes du tableau à l'écran.

 

Exemple : Cf. exemple de la rubrique XmeListInput
