XmeListMode  Famille Thème

Définition du mode de stockage des éléments d'un tableau

 
Long XmeListMode (Identifiant, Mode, Adresse fonction)

 
Description de la fonction :

Voir la fonction Diva ListMode, avec le paramètre Ticket remplacé par :

 
Paramètre :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.


Attention : Il n’est pas possible de choisir le mode de tri automatique si on autorise les modifications et/ou les insertions d’éléments via XmeListConsultDefault (car celle-ci ne gère pas les changements immédiats de l'ordre d'affichage suite à une modification ou à une création d'élément).
