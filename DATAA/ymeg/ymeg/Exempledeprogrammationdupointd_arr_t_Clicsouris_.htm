Exemple de programmation du point d'arrêt "Clic souris"

Remarque préliminaire :

Nous considérons ici comme acquises certaines notions fondamentales de la programmation sous Harmony : déclaration des chemins implicites, paramétrage et mise en œuvre des projets dans l'éditeur Xwin, création des bases, tables et champs dans le dictionnaire, création et paramétrage des masques d'écran, etc.

 

Cet exemple montre comment définir et utiliser le point d'arrêt "Clic souris" pour appeler un menu contextuel, lorsque l'utilisateur clique avec le bouton droit de la souris sur une donnée en saisie quelconque du masque suivant (Cf. rubrique Programmation des points d'arrêt et de traitement "Clic souris") :

 

+------------------------------------+

| Donnée 1 : ........                |

| Donnée 2 : ........                |

| Donnée 3 : ........                |

| Donnée 4 : ........                |

| ...                                |

+------------------------------------+

 

1. Paramétrage des données du masque

  • Donnée 1, 2, 3, … : dans les propriétés de la donnée :
    Arrêt clic souris     : 101, 102, 103, …

 

2. Programme Diva

Remarque :

  • Ce schéma de programme a pour but d'illustrer de manière simple la mise en oeuvre du point d'arrêt "Clic souris". Aussi, la procédure de saisie du masque est réduite au minimum (pour un exemple complet de procédure de saisie, consultez la rubrique Exemple général de programmation d'une saisie de masque). De même, si l'appel des menus contextuels est programmé, le calcul de leurs identificateurs ne l'est pas (pour un exemple plus complet à ce sujet, voir le chapitre consacré aux menus).
     

;Schéma de programmation de points d'arrêt "Clic souris"

 

...

 

;Fonction : SAISIE

;Type : Int

;Description : Saisie du masque

;En sortie : - 1 = validation

;            - 2 = abandon

 

FUNCTION INT Saisie

1 fini X

 

BEGINF

   fini = 0 

   XmeInput ("ECLIC",1,0,XME_MODE_GOTO)                 ;page 1

   DO

      SWITCH Harmony.Arret 

         CASE Harmony.Key = K_ESCAPE 

            fini = 2                                    ;abandon 

 

         CASE 101                                       ;donnée 1

            if Harmony.SourisBout = RIGHT_BUTTON (*)

               Harmony.Retour = XMENEXT_POPUP_MENU

               Harmony.PopupMenu = IdPopup1

            endif

 

         CASE 102                                       ;donnée 2

            if Harmony.SourisBout = RIGHT_BUTTON (*)

               Harmony.Retour = XMENEXT_POPUP_MENU

               Harmony.PopupMenu = IdPopup2

            endif

 

         CASE 103                                       ;donnée 3

            if Harmony.SourisBout = RIGHT_BUTTON (*)

               Harmony.Retour = XMENEXT_POPUP_MENU

               Harmony.PopupMenu = IdPopup3

            endif

 

         ...                                            ;etc.

 

                                                        ;après les points d'arrêt 

         CASE Harmony.Key in (K_UP, K_BTAB)             ;flèche en haut ou Back-Tab

                                                        ;sur la 1ère donnée

 

         CASE Harmony.Key in (K_RETURN, K_TAB, K_DOWN)

            fini = 1                                    ;validation 

      ENDSWITCH 

 

   WHILE NOT fini 

      XMENEXT (Harmony.Retour, Harmony.CplRetour)

   WEND

 

   FRETURN (fini) 

ENDF

 

 

;Programme principal

 

MAIN

...

XMELOAD ("ECLIC")

...

 

Etat = Saisie                                           ;saisie

...
