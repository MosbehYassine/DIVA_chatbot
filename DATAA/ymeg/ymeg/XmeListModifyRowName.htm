XmeListModifyRowName  Famille Thème

Modification du nom de la ligne courante d’un tableau (attributs dynamiques)

 

Long XmeListModifyRowName (Identifiant, Nom de ligne)

 

Paramètres :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

Nom de ligne

Paramètre facultatif :

  • Présent : la valeur indiquée est transférée dans la donnée RowInfo.NomLigne de l’élément courant du tableau et dans la donnée de votre programme RowInfo.NomLigne.

  • Absent : la valeur actuelle de la donnée de votre programme Rowinfo.NomLigne est transférée telle quelle dans la donnée RowInfo.NomLigne de l’élément courant du tableau.

 

Description de la fonction :

  • La fonction XmeListModifyRowName s’utilise dans le cadre de l’affectation dynamique d’attributs d'affichage aux cellules d’un tableau (pour plus de détails sur ce point, consultez les deux rubriques précédentes consacrées aux fonctions XmeListSetAttribut et XmeListResetAttribut).

  • XmeListModifyRowName modifie la valeur de la donnée RowInfo.NomLigne de l'élément COURANT du tableau, dans le but de changer les attributs d’affichage d’une ou plusieurs cellules de la ligne correspondante.
    Si le paramètre Nom de ligne est présent (exemple 1 ci-dessous), son contenu est transféré dans la donnée RowInfo.NomLigne de l’élément courant (ainsi que dans la donnée de votre programme RowInfo.NomLigne).
    Si le paramètre Nom de ligne est absent (exemple 2 ci-dessous), c’est la valeur actuelle de la donnée de votre programme RowInfo.NomLigne qui est transférée.

  • ATTENTION : dans un point d’arrêt ou de traitement, IL FAUT utiliser cette fonction pour changer le nom d’une ligne EN COURS DE SAISIE (et non programmer « manuellement » la modification en liste).

    En effet, parce qu’elle NE modifie QUE RowInfo.Nomligne en liste, XmeListModifyRowName N’est PAS EQUIVALENTE à la séquence de programme :

XmeListCurrent (id,wligne)  ;wligne pour ne pas écraser les

                            ;champs déjà saisis !

Rowinfo.NomLigne = "xxx"    ;nouveau nom de ligne

XmeListModify (id,ligne)    ;mise à jour en liste

XmeListModify modifierait l'élément courant de la liste en totalité (et pas uniquement RowInfo.NomLigne) : ainsi, les valeurs déjà saisies par l’utilisateur avant le point d’arrêt/traitement seraient définitivement enregistrées et ce, même si l’utilisateur abandonne ultérieurement la saisie !!

  • L’appel à XmeListModifyRowName est ignoré (sans erreur) si dans le masque Xwin, vous n’avez pas défini de donnée de contrôle des lignes pour le tableau.

 
Valeur rendue par la fonction :

1 : Identifiant invalide.

0 : Pas d'élément courant dans le tableau.

Autre : Adresse de l'élément courant dans la liste (ok).

 

Exemples : les deux exemples suivants produisent un résultat équivalent.

Exemple 1 :

XmeListModifyRowName (id,"NOUVEAU_NOM")

Exemple 2 :

RowInfo.NomLigne = "NOUVEAU_NOM"

XmeListModifyRowName (id)
