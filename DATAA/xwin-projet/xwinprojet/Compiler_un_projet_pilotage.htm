Compiler un projet

Il est possible de charger Xwin et de lancer la construction d'un projet en passant les paramètres depuis la ligne de commande.

Une fois les compilations achevées, Xwin se termine.

 

Syntaxe des paramètres :   -action aaaa  -project pppp  [ -user uuuu ]  -profile pppp  [ -output oooo ]

 

action

- build      (construire le projet)
- buildall   (reconstruire le projet)

project

Nom du projet à charger. Il est conseillé de passer un nom complet, avec tout le chemin

user

Code utilisateur. Si ce paramètre n'est pas positionné, Xwin prend le code utilisateur par défaut

profile

Nom du profil à utiliser

output

Nom du fichier de sortie. Tous les messages sont écrits dans ce fichier
Par défaut : /divalto/sys/xwin_output.txt

 

Exemple

C:\divalto\sys\Xwin6.exe -action buildall  -project "/divalto/test/test.dhpt"  -profile profil1 -output /divalto/test/xwin_output.txt

Lancement de Xwin avec les paramètres suivants :

  • reconstruction du projet /divalto/test/test.dhpt

  • utiliser le profil profil1

  • le fichier de sortie est /divalto/test/xwin_output.txt
