Pour charger un fichier dans l'éditeur

Pour charger un fichier dans l'éditeur vous pouvez :

  • cliquer sur Ouvrir du menu Fichier

  • cliquer sur un nom de fichier dans le sous-menu Fichiers récents du menu Fichiers.

  • cliquez sur le bouton

 

Depuis l'arbre du projet, vous pouvez :

  • sélectionner le fichier puis taper Entrée

  • double-cliquer sur le fichier

  • cliquer avec le bouton droit sur le fichier et sélectionner le choix Ouvrir

 

Remarques

Pour ouvrir un fichier masque ou dictionnaire en mode texte, utilisez le choix Ouvrir en mode texte du menu contextuel.

Lorsque vous ouvrez un fichier depuis l'arbre du projet, le sous-projet contenant ce fichier devient automatiquement le sous-projet courant. Si vous ne voulez pas que le sous-projet change, il faut enfoncer la touche Ctrl au moment de l'ouverture du fichier ou choisir le choix Ouvrir sans changer de sous-projet. du menu contextuel. Seule l’ouverture d’un fichier du dossier Includes ne provoque jamais le changement de sous-projet.

Une méthode astucieuse est d'utiliser la navigation. Plutôt que de vous demander dans quel fichier se trouve la fonction que vous voulez voir, tapez Shift+F11, tapez le nom de la fonction et Xwin vous positionne automatiquement dans le bon source.
