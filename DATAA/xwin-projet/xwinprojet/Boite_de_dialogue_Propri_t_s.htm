Boîte de dialogue Propriétés

Cette boîte de dialogue affiche les caractéristiques d'un fichier.

Le seul paramètre modifiable est :

Privé

Si cette option est cochée, ce sous-projet (ou ce fichier) ne figurera pas dans le projet de surcharge lorsque ce dernier sera créé. (ce paramètre n'apparaît pas pour les fichiers includes, ou dans les projets surchargés).
