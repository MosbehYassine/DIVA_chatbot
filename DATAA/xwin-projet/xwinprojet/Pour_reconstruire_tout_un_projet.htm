Pour reconstruire tout un projet

Pour reconstruire tout un projet :

  • sélectionnez le choix Reconstruire tout le projet du menu Projet

  • ou cliquez avec le bouton droit sur la racine de l'arbre et sélectionnez le choix Reconstruire tout le projet.

 

La reconstruction d'un sous projet se fait en deux étapes :

  • suppression de tous les fichiers objets du sous-projet

  • compilation de tous les sources du sous-projet.
