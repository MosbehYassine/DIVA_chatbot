La création d’un projet de surcharge peut s’effectuer au travers d’un assistant .Cette fonctionnalité évite de réaliser manuellement de nombreuses opérations lors de cette création.

 

L’accès à l’assistant nécessite que les règles d’installation des produits aient été respectées. En particulier, le répertoire où est installé l’ERP doit obligatoirement contenir la chaine « /erp ».

L’assistant :

Crée l’arborescence du projet de surcharge sous le répertoire « chemin relatif des surcharges » fourni en paramètre. Le  répertoire de base porte le « Nom de la surcharge » suffixé par le nom du répertoire de la version de base (par exemple « Dubois_Erp207 » pour la surcharge du master 207 pour le client Dubois).

Crée le projet de surcharge dans le sous-répertoire « Sources ».

Crée le fichier des implicites du projet.

Crée le profil de développement.

Crée éventuellement un environnement et l’associe au projet. Dans ce cas, les fichiers des utilisateurs (xlog), le fichier de connexion à la base de données, les fichiers d’implicites sont recopiés dans le sous-répertoire « fichiers » de la surcharge.

Duplique éventuellement la base de données afin de disposer d’un jeu de données spécifiques au projet surchargé. Dans ce cas, le répertoire « fichiers » du projet d’origine est copié dans celui de la surcharge. Le répertoire « BaseSql » contient alors les dictionnaires de données ainsi que le fichier fhsql.dhfi de paramétrage des accès à la base de données. L’assistant duplique la base de données et crée une nouvelle source de données permettant d’accéder à celle-ci.  Le fichier connexions.xml est mis à jour pour pointer vers la nouvelle instance de la base.

Attention : l’option « Duplication de la base de données » arrête le serveur SQL afin de pouvoir effectuer la copie de la base. Il convient donc de s’assurer que le serveur n’est pas en cours d’utilisation et d’exécuter Xwin7 en tant qu’administrateur si l’UAC est active.
