Pour ajouter / supprimer un groupe de sources dans un sous-projet

 

Pour ajouter un groupe de sources dans un sous-projet vous pouvez :

  • cliquer avec le bouton droit sur le dossier Groupes de sources du sous-projet et choisir Nouveau

  • cliquer le dossier Groupes de sources du sous-projet et taper la touche Insert.

  • cliquer avec le bouton droit sur un des groupes du sous-projet et taper la touche Insert.

  • dans le menu Projet pointer sur Sous-projet et cliquer sur Inclure des groupes de sources au sous-projet xxx.

La boîte de sélection des groupes s'ouvre. Vous pouvez sélectionner plusieurs groupes en une seule opération.

 

Pour supprimer un groupe de sources d'un sous-projet vous pouvez :

  • cliquer avec le bouton droit sur le groupe et choisir Supprimer.

  • cliquer sur le groupe et taper sur la touche Delete.
