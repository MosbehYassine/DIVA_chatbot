Paramètres des sous-projets

Les paramètres des sous-projets sont :

Mode

Type de programme à lancer.

Normal : pour exécuter un programme Diva avec des masques en version 6

Page Html :  Xwin lance alors le navigateur par défaut avec comme paramètre le nom de la page.

Service Web :  Xwin lance alors le programme qui appelle le service web.

Client léger : pour exécuter un programme Diva avec des masques en version 7.

Client léger Web : pour exécuter un programme Diva en utilisant un navigateur internet (html5).  
                            Voir Identification en mode client léger Web.

 

Type de transport

DhsTerminalServer : transport par socket TCP.

Service Web : transport utilisant les services web de IIS.

Local : appelé aussi client lourd.

Ce paramètre n'est pas utilisé en mode Client léger Web.

Url du service Web

Url pour accéder au service web.

Programme à exécuter

Nom du programme a exécuter lors du debug ou page à lancer en mode Page Html ou Client léger Web.

Si le nom du programme a exécuter n'est pas renseigné ici, le nom du programme a exécuter sera pris au niveau des paramètres du projet.

 

Application, libellé de regroupement
et Numéro

Si le programme à exécuter est un menu, ces trois paramètres permettent d'exécuter automatiquement un choix du menu.

Comme pour le programme a exécuter, si ces paramètres ne sont pas renseignés, ils sont pris au niveau du sous-projet.

 

Privé

Si cette option est cochée, ce sous-projet ne figurera pas dans le projet de surcharge lorsque ce dernier sera créé.
