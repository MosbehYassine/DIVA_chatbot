Pour reconstruire tout un sous-projet

Pour reconstruire tout un sous-projet, vous devez tout d'abord définir le sous-projet comme sous projet courant puis :

  • sélectionnez le choix Reconstruire tout le sous-projet du menu Projet

  • ou cliquez avec le bouton droit sur le dossier du sous-projet et sélectionnez le choix Reconstruire tout le sous-projet.

 

La reconstruction d'un sous projet se fait en deux étapes :

  1. suppression de tous les fichiers objets du sous-projet

  2. compilation de tous les sources du sous-projet.

 

Remarque

Le choix Reconstruire tous les sous-projets expansés du menu contextuel Sous-projet permet de construire plusieurs sous-projets.
