Notion de profil

Un profil regroupe un ensemble de paramètres relatifs au projet.

Parmi ces paramètres on trouve :

  • les chemins implicites

  • les options de compilation

  • les chemin des fichiers objets et des fichiers pour la navigation.

Pour un projet il est possible de définir plusieurs profils. Le choix d'un profil permet de sélectionner automatiquement un ensemble de paramètres.

Par exemple, on définira généralement un profil "Debug" et un profil "Release" ; le profil "Debug" ayant les options de compilation positionnées afin de pouvoir utiliser le débogueur et le profil "Release" n'ayant pas ces options de positionnées.
