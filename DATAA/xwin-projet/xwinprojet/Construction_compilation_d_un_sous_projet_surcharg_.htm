Construction / compilation d'un sous-projet surchargé

Seuls les fichiers se trouvant dans les dossiers de surcharge sont compilés. Xwin ignore toujours les fichiers ne trouvant pas dans les dossiers de surcharge.

Si vous voulez absolument compiler un source qui se trouve dans les dossiers d'origine, vous pouvez insérer ce fichier dans un dossier de surcharge. Xwin autorise qu'un fichier figure dans le dossier Sources et dans le dossier Sources surcharge.
