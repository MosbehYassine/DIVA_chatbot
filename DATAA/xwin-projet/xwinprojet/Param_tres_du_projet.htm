Paramètres du projet

Les paramètres du projet sont :

Nom

Nom du projet

Dictionnaire de traduction pour les masques.

Nom du dictionnaire à utiliser pour la traduction des masques. (Divalto par défaut).
Voir le livre consacré à la Traduction des applications.
 

Traitement après saisie d'un champ

Lorsqu'un champ contenant des traitements dans le dictionnaire est ajouté à un masque, deux possibilités sont offertes :

  • Générer l'appel au traitement du dictionnaire. Le masque appelle la procédure "Après saisie" qui est dans le dictionnaire.

  • Copier le traitement du dictionnaire dans le masque. La procédure "Modèle" qui est dans le dictionnaire est copiée dans les traitements du masque.

Coller d’objets dans un masque

Ne pas copier le code source des traitements : si vous cochez cette case, Xwin n'effectue plus la copie du code source des traitements, faite normalement à l’occasion d’un coller d’objets dans un masque.

F5 compile avant d'exécuter

Option qui demande à Xwin de recompiler le sous-projet courant lorsque l'exécution du programme en mode Debug est demandée. Cela évite d'oublier de compiler les sources.

Mode

Type de programme à lancer :

Normal : pour exécuter un programme Diva avec des masques en version 6

Page Html :  Xwin lance alors le navigateur par défaut avec comme paramètre le nom de la page.

Service Web :  Xwin lance alors le programme qui appelle le service web.

Client léger : pour exécuter un programme Diva avec des masques en version 7.

Client léger Web : pour exécuter un programme Diva en utilisant un navigateur internet (html5).
                            Voir Identification en mode client léger Web.

 

Type de transport

DhsTerminalServer : transport par socket TCP.

Service Web : transport utilisant les services web de IIS.

Local : appelé aussi client lourd.

Ce paramètre n'est pas utilisé en mode Client léger Web.

 

Url du service Web

Url pour accéder au service web (en mode Service web)

 

Programme à exécuter

 

Nom du programme a exécuter lors du debug ou page à lancer en mode Page Html ou Client léger Web.

Si le nom du programme à exécuter n'est pas renseigné au niveau du sous-projet, c'est celui-ci qui est utilisé.

 

Application, libellé de regroupement
et Numéro

Si le programme est un menu, ces trois paramètres permettent d'exécuter automatiquement un choix du menu.

Comme pour le programme à exécuter, ces paramètres peuvent être précisés au niveau du sous-projet.
