Menu contextuel Projet

 

Le menu contextuel Projet propose les commandes :

  • Paramètres : Modifier les paramètres du projet.
     

  • Nouveau sous-projet : créer un sous-projet.

  • Inclure un sous-projet : ajouter un sous-projet existant au projet.

  • Fermer le projet : fermer le projet.
     

  • Construire : compilation des sources du projet qui doivent être recompilés (sources modifiés par ex.).

  • Reconstruire tout le projet : recompilation de tous les sources du projet.

  • Fusionner un projet et sa surcharge : voir la rubrique Fusion de projet et projet de surcharge.
     

  • Extraire les libellés en vue de la traduction : constitution d'un dictionnaire pour la traduction.

  • Changer code langue : choisir un code langue pour l'affichage des masques.

  • Vérifier la taille des boîtes : vérifier la taille des boîtes pour les objets Texte et Multi-choix.
     

  • Chercher dans le projet : rechercher un fichier dans le projet.

  • Créer un projet surchargeable : création d'un projet surchargeable à partir du projet en cours.
     

  • Aide à la migration.
