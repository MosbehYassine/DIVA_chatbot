Menu contextuel Source

 

Le menu contextuel Source propose les commandes :

  • Ouvrir : charger le fichier pointé dans l'éditeur.

  • Ouvrir en mode texte : charger le fichier en mode texte (pour modifier le source d'un masque par exemple).

  • Ouvrir sans changer de sous-projet : ouvrir le fichier, sans changer de sous-projet courant si le fichier pointé n'appartient pas au sous-projet courant.

  • Ajouter : ajouter un ou plusieurs fichiers au sous-projet.

  • Retirer du sous-projet : retirer le fichier du sous-projet sans suppression physique.

  • Supprimer le fichier : supprimer physiquement le fichier.

  • Copier le nom du fichier : copier le nom du fichier dans le presse-papiers.

  • Créer un masque de surcharge : créer un masque qui surcharge le masque courant.

  • Comparer avec le masque de base : visualiser les différences entre le masque de surcharge pointé et le masque de base correspondant.

  • Créer un module de surcharge : créer un source texte de surcharge.
    C    réer un dictionnaire de RecordSql de surcharge : créer un source dictionnaire de RecordSql de surcharge.
    C    réer un dictionnaire de Jointures Sql de surcharge : créer un source dictionnaire de Jointures Sql de surcharge.

  • Compiler : compiler le source pointé (il n'a pas besoin d'être préalablement chargé).

  • Propriétés : propriétés du fichier.

  • Explorer : ouverture de l'explorateur de fichiers dans le répertoire contenant le fichier pointé.

  • Exécuter en mode debug : lancement du programme en mode debug (l'extension dhsp est remplacée par dhop).

  • Exécuter : lancement du programme sans debug (l'extension dhsp est remplacée par dhop).

  • Imprimer une maquette : lancement de l'utilitaire de sélection et d'impression d'une maquette pour le masque imprimante pointé.

  • Vérifier la syntaxe SQL : vérification de la syntaxe du dictionnaire de RecordSql (comme l'utilitaire xRecordSqlCheck).
