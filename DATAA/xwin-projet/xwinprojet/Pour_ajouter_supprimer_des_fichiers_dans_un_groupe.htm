Pour ajouter / supprimer des sources dans un groupe

Pour ajouter des sources dans un groupe vous pouvez :

  • cliquer droit sur le groupe et choisir Nouveau fichier

  • cliquer sur le groupe et taper la touche Insert

  • cliquer droit sur un des sources du groupe et choisir Ajouter

  • cliquer sur un des sources du groupe et taper la touche Insert.

La boîte de sélection des fichiers s'ouvre. Vous pouvez sélectionner plusieurs fichier en une seule opération.

 

Pour supprimer des sources dans un groupe vous pouvez :

  • cliquer avec le bouton droit sur le source et choisir Supprimer.

  • cliquer sur le source et taper sur la touche Delete.

La suppression d'un source d'un groupe ne supprime jamais le fichier du disque.
