Divers

Le dossier Divers peut contenir des fichiers de toute sorte.

Vous pouvez par exemple y mettre des fichiers de documentation (.doc), des programmes diva (.dhop), des fichiers indexés (.dhfi) etc.

Lors de l'ouverture d'un fichier de ce dossier, Xwin lance le programme associé à l'extension du fichier. Les fichiers .dhfi et .dhfd sont ouverts dans Xwin.

Les fichiers .dhop sont exécutés.

 

Remarques

  • Tous les fichiers placés dans les dossiers doivent être accessibles par les chemlns implicites de la tâche.

  • Les fichiers .dhop sont exécutés par un ProgramCall (avec l’option CALL_NOWAIT). La chaîne xwin_lancementdivers est placée dans le tunnel avec la valeur 1. Cela permet éventuellement de tester dans le programme s’il a été appelé depuis Xwin.
