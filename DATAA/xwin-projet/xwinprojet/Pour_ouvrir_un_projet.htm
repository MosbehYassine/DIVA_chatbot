Pour ouvrir un projet

Pour ouvrir un projet, sélectionnez le choix Ouvrir projet du menu Fichier.

Vous pouvez également ouvrir un projet depuis l'explorateur de Windows en double cliquant sur un fichier .dhpt.

 

Remarques

Lors du lancement de Xwin, le dernier projet utilisé est automatiquement rechargé.

Le sous-menu Projets récents du menu Fichiers vous propose la liste des derniers projets utilisés. Pointez le choix Projets récents du menu Fichier et cliquez sur le nom du projet.
