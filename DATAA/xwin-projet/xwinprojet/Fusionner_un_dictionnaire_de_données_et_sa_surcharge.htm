Fusionner un dictionnaire de données et sa surcharge

Il est possible de lancer la fusion d'un dictionnaire et de sa surcharge depuis la ligne de commande.

Une fois l'opération de fusion achevée, Xwin se ferme.

 

Syntaxe des paramètres :   -action fusiondico  -project pppp  [ -user uuuu ]  -profile pppp  [ -output oooo ]  

                                        -dicoOrigine ooooo -dicoFusion fffff

 

project

Nom du projet à charger. Il est conseillé de passer un nom complet, avec tout le chemin

user

Code utilisateur. Si ce paramètre n'est pas positionné, Xwin prend le code utilisateur par défaut

profile

Nom du profil à utiliser

output

Nom du fichier de sortie. Tous les messages sont écrits dans ce fichier
Par défaut : /divalto/sys/xwin_output.txt

dicoOrigine

Nom du dictionnaire de données à fusionner. Ce dictionnaire est ouvert normalement, et la surcharge est chargée depuis le même répertoire ou d'après les implicites.

dicoFusion

Nom du dictionnaire fusionné.
