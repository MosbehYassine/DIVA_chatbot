Pourquoi utiliser les projets ?

Une meilleure organisation des sources.

Au vu de l'exemple précédent ce premier intérêt des projets semble évident. A chaque programme de l'application correspond un sous-projet, avec un nom parlant. La liste des sources d'un projet permet immédiatement de voir quels sont les sources concernés. De plus, le double clic sur un fichier permet de le charger dans l'éditeur Xwin.

Lors de l'ouverture d'un projet, Xwin recharge automatiquement les sources du sous-projet qui étaient chargés lors de la dernière utilisation du projet.

 

La compilation automatique

Le projet permet de déterminer automatiquement quels sont les sources qui doivent être recompilés après une modification dans un source.

Le calcul des dépendances entre les différents éléments d'une application (sources, modules, dictionnaires) se fait de façon entièrement automatique.

Au moment de la compilation, Xwin utilise ces dépendances pour déterminer quels sont les sources qui doivent être recompilés. Ce calcul se fait de façon extrêmement fine afin de faire le minimum de compilations.

Par exemple, une modification dans le corps d'une fonction d'un module, n'entraîne que la compilation du module lui-même. Par contre, si la signature de la fonction a été modifiée (nombre de paramètres de la fonction par exemple), tous les modules ou masques qui utilisent cette fonction seront recompilés. Les modules ou masques qui utilisent le module modifié mais qui n'appellent pas la fonction modifiée ne seront pas compilés.

 

La navigation dans les sources

La fonctionnalité la plus intéressante offerte par le projet est certainement la navigation dans les sources.

La navigation permet de se positionner instantanément

  • sur la définition d'une donnée,

  • sur la définition d'une fonction,

  • sur toutes les lignes de source où une variable est utilisée,

  • sur toutes les lignes de source où une fonction est utilisée,

  • sur tous les objets dans les masques qui sont liés à une donnée,

  • sur tous les objets dans les masques qui utilisent un choix d'un dictionnaire de multi-choix

  • etc.
