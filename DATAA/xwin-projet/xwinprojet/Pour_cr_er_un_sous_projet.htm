Pour créer / supprimer un sous projet

Pour créer un sous-projet vous pouvez :

  • cliquer avec le bouton droit sur le dossier Sous-projets et choisir Nouveau

  • dans le menu Projet pointer sur Projet et cliquer sur Nouveau sous-projet

  • cliquer avec le bouton droit sur un projet et choisir Nouveau.

Puis :

  • dans le boîte de dialogue des fichiers, placez-vous dans le répertoire et saisissez le nom du sous-projet.

Le sous-projet est maintenant créé avec des paramètres par défaut.

Vous devez saisir les paramètres propres au sous-projet puis ajouter des groupes et des sources dans le sous-projet.

 

Pour supprimer un sous-projet vous pouvez :

  • cliquer avec le bouton droit sur le sous-projet puis choisir Supprimer

  • cliquer sur le sous-projet et taper la touche Delete.

Xwin vous demande si le fichier contenant le sous-projet doit être supprimé. Ne cochez pas la case si vous voulez réutiliser ce sous-projet. La suppression du fichier du sous-projet supprime le fichier .dhps. La suppression ne touche en aucun cas à vos fichiers sources.
