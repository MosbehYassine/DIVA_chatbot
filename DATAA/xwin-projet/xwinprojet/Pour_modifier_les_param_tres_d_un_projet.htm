Pour modifier les paramètres d'un projet

Pour modifier les paramètres d'un projet vous pouvez :

  • cliquer avec le bouton droit sur la racine de l'arbre et sélectionner le choix Paramètres.

  • dans le menu Projet pointer sur Projet puis cliquer sur Paramètres.

Vous pouvez alors saisir les paramètres du projet.
