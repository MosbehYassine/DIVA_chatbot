Boîte de dialogue Création d'un module / dictionnaire Sql de surcharge

Cette boîte de dialogue vous permet de créer le source de surcharge d'un module ou d'un dictionnaire Sql et de l'intégrer au sous-projet courant.

Le nom du fichier à créer est recherché dans le fichier courant. Ce dernier doit donc contenir :

  • L'instruction OverWrittenBy (module).

  • L'attribut OverWrittenBy dans la balise <DictionarySql> (dictionnaire de RecordSql).

  • L'attribut OverWrittenBy dans la balise <DictionaryJoinSql> (dictionnaire de Jointures Sql).

 

Les paramètres à saisir sont :

Répertoire où créer le fichier

Nom du répertoire dans lequel le source de surcharge doit être créé.

Ajouter au sous-projet

Ajouter ou non le nouveau fichier au sous-projet courant.
