Pour corriger les erreurs de compilation

Lorsque le compilateur Diva détecte des erreurs syntaxiques (dans un programme ou dans les séquences de traitement d'un masque), Xwin les affiche dans la fenêtre Compte-rendu. A partir de là :

  • Sélectionnez le choix Erreur / Occurrence Suivante du menu Rechercher (raccourci clavier : F4). Xwin active le source contenant la première erreur et place automatiquement le curseur sur la ligne concernée. Une marque est affichée en marge pour vous permettre de facilement repérer la ligne erronée courante.Vous pouvez saisir immédiatement les corrections nécessaires.

  • Sélectionnez ensuite le choix Erreur / Occurrence Suivante (raccourci clavier : F4) ou le choix Erreur / Occurrence Précédente (raccourci clavier : Shift+F4) du menu Rechercher, pour passer à l'erreur suivante ou revenir sur l'erreur précédente.

  • Répétez l'opération jusqu'à ce que vous ayez corrigé toutes les erreurs.

 

Si vous désirez vous positionner directement sur une erreur précise :

  • Sélectionnez la ligne affichant l'erreur dans la liste des erreurs de la fenêtre Compte-rendu puis tapez Entrée.

  • Ou double-cliquez simplement sur cette ligne.
