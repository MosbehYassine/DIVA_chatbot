Introduction

harmony gère trois types de fichiers :

  • les fichiers de type C ou U (fichiers sources),

  • les fichiers de type N (fichiers de données),

  • les fichiers de type I (séquentiels-indexés).

 

Les fichiers de type C (sous mos) ou de type U (sous unix et windows) contiennent généralement du texte (fichier source, fichier d'aide,...). Ils peuvent être lus à l'aide des éditeurs standards (xed sous mos, edit sous windows, vi sous unix).

 

Les fichiers de type N (Normaux) contiennent les données des applications et les fichiers exécutables (Diva, Masques...). Ces fichiers sont rarement utilisés directement par les applications, mais plutôt comme composantes des fichiers séquentiels-indexés.

 

Les fichiers séquentiels-indexés sont composés de deux fichiers physiquement distincts :

  • un fichier de données, généralement de type N;

  • un fichier "Paramètres et Clés" de type I qui contient les paramètres du séquentiel-indexé (description des clés) et les clés d'accès elles-mêmes.

Nous détaillerons plus loin la structure de chaque type de fichiers ainsi que les méthodes d'accès et les fonctions permettant de les manipuler.

 

Diva propose deux familles de fonctions pour la gestion de fichier. Les fonctions évoluées (préfixées par la lettre H) et les fonctions de base (préfixées par la lettre F). Il est conseillé d'utiliser les fonctions évoluées pour éviter d'alourdir le programme principal par de nombreux tests d'erreur et surtout pour éviter d'oublier de traiter certaines erreurs.
