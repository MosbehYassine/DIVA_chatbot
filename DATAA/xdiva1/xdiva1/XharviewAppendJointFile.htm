XharviewAppendJointFile  Famille  Thème

La fonction XharviewAppendJointFile permet d’ajouter des fichiers joints à l’état Xharview.

Il est possible de joindre jusque 31 fichiers.

Attention : cette fonction doit être éxecutée juste avant l’instruction PrintEnd.

 

Ptr XharviewAppendJointFile (fic1 , fic2)

 

Paramètres

Fic1

Nom complet (avec le chemin) au format windows du fichier à joindre. Le nom complet d’un fichier ouvert dans un programme Diva peut être obtenu par la fonction GetSystemFileName.

Fic2

Nom du fichier tel qu’il apparaîtra dans le message. Si ce paramètre est à espaces, il est automatiquement remplacé par le nom du fichier (sans le chemin).

 

 

Retour

0

Pas d’erreur.

Autre

Erreur.
 

Exemples

 

;fichier réel : c:\Divalto\sys\ListeClients.txt

;nom du fichier que vera le receveur du message : ListeClients.txt

XharviewAppendJointFile("c:\Divalto\sys\ListeClients.txt"," ")

 

;fichier réel : c:\Divalto\sys\xx4A10.tmp

;nom du fichier que vera le receveur du message : xx4A10.tmp

XharviewAppendJointFile("c:\Divalto\sys\xx4A10.tmp"," ")

 

;fichier réel : c:\Divalto\sys\xx4A10.tmp

;nom du fichier que vera le receveur du message : ListeClients.txt

XharviewAppendJointFile("c:\Divalto\sys\xx4A10.tmp","ListeClients.txt")
