StringNew Famille Thème  

L’instruction StringNew permet d’allouer de l’espace pour une variable de type String.

 

StringNew (variable , longueur)

Paramètres

Variable

Donnée de type String.

Longueur

Taille à allouer pour la variable. Après l’instruction StringNew la variable de type String est une chaîne à espaces de taille Longueur. La chaîne est initialisée à espaces.

 

Remarque

  • Cette instruction est rarement utilisée, l’allocation des données de type String étant automatique. Elle permet par exemple d’initialiser une donnée de type String dans laquelle on veut faire une lecture par Hread.
