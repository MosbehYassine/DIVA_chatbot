WinDivaltoGlobalWriteInt - WinDivaltoWriteInt Famille Thème

L'instruction WinDivaltoWriteInt permet d’écrire un entier dans le registre, sous la clé "HKEY_CURRENT_USER\SOFTWARE\Divalto\divalto.ini\"

L'instruction WinDivaltoGlobalWriteInt permet d’écrire un entier dans le registre, sous la clé "HKEY_LOCAL_MACHINE\SOFTWARE\Divalto\divalto.ini\"

 

Ces instructions se trouvent dans le module ysystemex.dhop.

 

WinDivaltoWriteInt (section, entrée , valeur)

WinDivaltoGlobalWriteInt (section, entrée , valeur)

 

Paramètres

Section

Sous chemin dans le registre.

Entrée

Nom de la valeur à écrire.

Valeur

Valeur à écrire.
