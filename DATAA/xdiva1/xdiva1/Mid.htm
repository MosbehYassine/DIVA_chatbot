Mid  Famille 

 

La fonction Mid permet d'extraire une sous chaîne d'une chaîne de caractères. Elle peut se trouver à gauche dans une affectation.

 

Char = mid (variable, position, [ longueur ])

 

Paramètres

Variable

Le type de la variable est quelconque.

Position

Valeur numérique indiquant la position de début (à partir de 1) de la sous chaîne à extraire.

Longueur

Valeur numérique indiquant la taille de la sous chaîne à extraire. Si ce paramètre est omis ou nul, la longueur est :
Taille de variable - position + 1
c'est à dire la partie droite de variable à partir de position.

 

Retour

La fonction renvoie la sous chaîne définie par Position et Longueur. Le type de retour est toujours alphanumérique.

 

Exemples

display mid("BONJOUR",3,4)

; affiche NJOU

 

mid(art,3,5) = '12345'

; positionne les caractères 12345 à partir du troisième caractères

de Art.

 

1 art 10 = "1234567890"

display mid(art,5)

; affiche 567890
