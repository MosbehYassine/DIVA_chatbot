Gestion des erreurs

En cas d'erreur fatale lors de l'exécution d'un programme Diva, ce dernier n'a pas la possibilité de reprendre la main pour exécuter un traitement d'erreur. Le système réalise les opérations suivantes :

  • fermeture de tous les fichiers ouverts par le programme,

  • libération de toutes les ressources allouées par le programme,

  • affichage d'une boîte de dialogue contenant un message et permettant de visualiser la pile des fonctions au moment de l'arrêt.

  • écriture d'un message dans le fichier journal ferror.log.

Tous les messages d'erreurs sont affichés dans une même fenêtre.

Cette nouvelle méthode d'affichage des erreurs peut être utilisée dans les programmes Diva grâce aux instructions  ErrorFatal, ErrorWarning, et Ferror. La fonction SystemLogWrite permet d’écrire dans le fichier journal.

Le fichier journal peut être consulté avec le programme Xconsole.dhop (au menu d’Harmony).
