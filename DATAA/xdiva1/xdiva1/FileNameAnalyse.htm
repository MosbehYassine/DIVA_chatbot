FileNameAnalyse  Famille Thème

 

La fonction FileNameAnalyse analyse un nom de fichier Harmony et retourne les différents éléments de ce nom.

 

Long = FileNameAnalyse (nom_complet, résultat, serveur, nom_fichier, extension , flag_répertoire)

 
Paramètres

Nom

Nom complet du fichier à analyser. Tous les autres paramètres sont garnis en retour par la fonction.

Résultat

Nom du fichier à ouvrir (256 caractères maximum). Résultat ne contient pas le nom du serveur.

Serveur 

Nom du serveur (32 caractères maximum) si le fichier est sur le réseau.

Nom_fichier

Nom du fichier (256 caractères maximum). Il s'agit du nom trouvé après le dernier séparateur / et sans l'extension.

Extension

Eventuelle extension du fichier (6 caractères maximum).

Flag_répertoire

Booléen indiquant que le nom à analyser est un nom de répertoire.

 

Retour

La valeur de retour de la fonction doit obligatoirement être stockée dans une donnée de type L.

0

Le nom du fichier est un nom complet d'un fichier local.

-1

Le fichier se trouve sur un serveur xlan.

-2

Le nom est incomplet.

-4

Le fichier se trouve sur un serveur en mode poste à poste.

Autres

Code d'erreur système.
 

Exemples

1 resultat 256

1 serveur 32

1 extension 6

1 nom 256

1 st L

main

st = FileNameAnalyse("//serveur/Divalto/sys/fic.txt", \

                      resultat,serveur,nom,extension)

st --> -1

resultat --> /Divalto/sys/fic.txt

serveur --> serveur

nom --> fic

extension --> txt

 

st = FileNameAnalyse("/Divalto/sys/fic.txt", \

                      resultat,serveur,nom,extension)

st --> 0

resultat --> c:/Divalto/sys/fic.txt

serveur --> rien

nom --> fic

extension --> txt
