String et fonctions du langage Diva

Les données de type String s’utilisent comme des données de type alpha-numérique. Les fonctions du langage acceptent toutes de recevoir un String en paramètre.

Les fonctions de lecture de liste (ListFirst …) peuvent être utilisées avec des String. La variable de type String est allouée en fonction de la taille de l’élément de la liste. De même pour les fonctions PingReceive, DataCompute, Sort, Left, Mid, Right, Search, WebServiceDivaExecute, HfileCheckVersion, HmpRead, HmpSeek, DDInterface.

Une variable de type String peut être utilisée pour lire dans un fichier (Hread) à condition qu’elle soit allouée avec la taille de l’enregistrement. Si la donnée de type String à une taille de 1 avant la lecture, seul le premier caractère de l’enregistrement sera lu.

 

Remarques concernant quelques fonctions du langage Diva.

  • La fonction Size (DataSize) retourne la longueur allouée de la chaîne de caractères.
    1 monstring S
    monstring = "abc " --> size(monstring) vaut 4

  • La fonction Length retourne la longueur de la chaîne sans les espaces de fin (3 dans l’exemple précédent)

  • La fonction Ptr renvoie l’adresse de la chaîne de caractères. Attention, cette adresse peut être nulle si aucune affectation n’a été faite dans la donnée.

  • La fonction DataType retourne la valeur 3, comme pour les données de type alpha-numérique.
