GetStack

La fonction GetStack renvoie la pile d’exécution du programme sous la forme d’une chaîne HMP.

Elle est utilisée pour rechercher une anomalie dans un programme. Il est possible d’écrire dans un fichier mouchard les paramètres d’appels ainsi que la trace de la pile.

 

Alpha GetStack

 

Retour

La fonction retourne une chaîne de caractère au format HMP .

Elle contient les paramètres suivants :

<module>xxxx

nom du module

<function>xxxx

nom de la fonction

<file>xxxx

Nom du fichier (si le module est compilé en mode debug)

<line>xxxx

numéro de ligne.

 

Exemple

public procedure afficheStack

beginp

1 stack S

1 param S

1 mod S

1 fonc S

1 ligne S

1 valeur S

1 fichier S

1 st X

 

   display "-----------------------------------------------------"

   stack = GetStack

   loop (st := hmpread(stack,param,valeur)) = 0

      if param = "MODULE" 

         if mod <> "" 

            display mod & ":" & fonc & " " & fichier & ":" & ligne 

         endif 

         mod = valeur 

         fonc = "" 

         ligne = "" 

         fichier = "" 

      elsif param = "FUNCTION" 

         fonc = valeur 

      elsif param = "LINE" 

         ligne = valeur 

      elsif param = "FILE" 

         fichier = valeur 

      endif 

   endloop

   if mod <> ""

      display mod & ":" & fonc & " " & fichier & ":" & ligne 

   endif

endp
