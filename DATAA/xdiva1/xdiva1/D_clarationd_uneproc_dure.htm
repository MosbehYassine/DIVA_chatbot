Déclaration d'une procédure  Famille Thème

 

Syntaxe : [ Public ] [ Private ] procedure nom [ (p1, p2...., pN) ]

Le mot clé Public indique que la procédure est accessible depuis un autre module.

Le mot clé Private indique que la fonction n'est pas une fonction de surcharge. Voir Private

Le mot clé Procedure doit être suivi du nom de la procédure suivi de la liste des paramètres formels entre parenthèses.

La liste des paramètres formels est facultative. Il est possible de définir des procédures n'ayant aucun paramètre. Dans ce cas il ne faut pas mettre de parenthèses après le nom de la procédure.

Si le paramètre formel doit être passé par adresse, le nom de ce dernier doit être précédé du caractère &.

 

Remarque

Les modules de surcharge peuvent contenir des fonctions publiques.

 

Exemples

procedure tri(&tableau)

est le début d'une procédure dont le seul paramètre formel est un tableau passé par adresse.

 

procedure affiche

est une procédure sans paramètres.
