Opérateurs d'affectation  Famille

 

Les opérateurs d'affectation sont les suivants :

Opérateur

Action

=

Simple affectation
i = j

+=

Affectation avec addition
i += j ó i = i + j

-=

Affectation avec soustraction
i -= j ó i = i – j

*=

Affectation avec multiplication
i *= j ó i = i * j

/=

Affectation avec division
i /= j ó i = i / j

:=

Affectation en cours d'instruction
Loop (stat := Fread(tdf,art,'P')) = 0
Endloop

A la fin de l'exécution de la boucle, stat contient le dernier code renvoyé par la fonction Fread.
Attention à entourer l'affectation de parenthèses si nécessaire.

&=

Concaténation de chaînes de caractères.

a &= b <=> a = left(a) & b
