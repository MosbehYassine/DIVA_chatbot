WinRegReadString  Famille Thème

La fonction WinRegReadString permet de lire une chaine de caractères dans le registre.

Cette fonction se trouve dans le module ysystemex.dhop.

  

Alpha WinRegReadString (clé, nom_valeur)

 

Paramètres

Clé

Clé dans le registre.

Nom_valeur

Valeur à lire.

  

Retour

La fonction retourne la chaine de caractères lue.

Si la clé ou la sous-clé n’existent pas, la fonction retourne espace.

  

Exemple

module "ysystemex.dhop"

1 buf 256

main

buf=WinRegReadString("HKEY_CURRENT_USER\Software\DivaltoHarmony\macle","Mavaleur")
