Exec  Famille Thème

 

La fonction Exec permet d'exécuter un programme Windows.

Voir également les fonctions WinFindExecutable, WinRegQueryKeyRun et WinShellExecute qui permettent respectivement de trouver le chemin d'un exécutable, d'exécuter le programme associé à un fichier.

Long Exec (programme , ligne , [ modeexec ] , [ modeaff ] )

Paramètres

programme

Nom du programme a exécuter. Si le chemin complet n'est pas précisé, la recherche de l'exécutable se fait dans l'ordre suivant :

- le répertoire courant,

- le répertoire System de Windows,

- le répertoire de Windows

- les répertoires précisés dans la variable d'environnement PATH.

ligne

Ligne de commande à passer au programme.

modeexec

Détermine le comportement du parent une fois que l'exécution du fils est commencée.

Valeur

Action

EXEC_GOTO

Mode Goto.
Le programme en cours se termine. Valeur par défaut

EXEC_GOSUB

Mode Gosub sans attente.
Le programme en cours continue son exécution en même temps que le nouveau programme.

EXEC_GOSUB_WAIT

Mode Gosub avec attente.
Le programme en cours attend la fin du nouveau programme pour continuer son exécution.

modeaff

Détermine le comportement du programme lancé. La valeur par défaut est SW_SHOWNORMAL.

Valeur

SW_HIDE

SW_SHOWNORMAL

SW_NORMAL

SW_SHOWMINIMIZED

SW_SHOWMAXIMIZED

SW_MAXIMIZE SW_SHOWNOACTIVATE

SW_SHOW

SW_MINIMIZE

SW_SHOWMINNOACTIVE

SW_SHOWNA

SW_RESTORE

SW_SHOWDEFAULT

SW_MAX

Retour

La fonction Exec renvoie la valeur –1 en cas d'échec du lancement du programme. En mode Goto avec attente, la fonction donne la valeur renvoyée par le programme. Dans les autres cas, la fonction renvoie 0.

 

Exemple

Exec("d:\Program Files\microsoft office\office\winword.exe" , \

     "monfichier", EXEC_GOSUB_WAIT)
