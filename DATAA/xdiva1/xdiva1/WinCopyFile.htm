WinCopyFile  Famille Thème

 

La fonction WinCopyFile copie un fichier existant dans un nouveau fichier.


Long WinCopyFile (Départ, Arrivée , FlagExiste)

 

Paramètres

Départ

Nom du fichier à copier.

Arrivée

Nom du fichier de destination.

FlagExiste

Spécifie ce que fait la fonction si le fichier Arrivée existe. Si ce paramètre vaut TRUE et que le fichier existe, la fonction retourne une erreur. Si ce paramètre vaut FALSE et que le fichier existe, le fichier est écrasé par la copie.

 

Retour

TRUE

Pas d'erreur.

FALSE

Erreur. Appelez la fonction WinGetLastError pour connaître le détail de l'erreur.

 

Remarques

Les attributs de sécurité du fichier origine ne sont pas transmis au fichier destination.

Les autres attributs du fichier de départ sont transmis au fichier destination. Par exemple, si le fichier de départ à l'attribut FILE_ATTRIBUTE_READONLY, le fichier destination aura également l'attribut FILE_ATTRIBUTE_READONLY.
