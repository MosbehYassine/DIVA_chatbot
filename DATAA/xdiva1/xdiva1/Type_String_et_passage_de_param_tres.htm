Type String et passage de paramètres

Les données de type String peuvent être utilisées comme paramètres formels et paramètres réels des fonctions et procédures.

Lorsque le paramètre formel est de type alpha-numérique (avec passage par adresse ou valeur), le paramètre réel peut être une donnée de type String.

Exemple :

procedure p1(alpha)

1 alpha 10

beginp

   display "!" & alpha & "!" 

endp

 

main

1 monstring S = "string"

1 monalpha 10 = "alpha"

 

p1(monstring) --> !string ! 

p1(monalpha)  --> !alpha ! 

 

Lorsque le paramètre formel est de type String et passé par valeur, le paramètre réél peut être une donnée alpha-numerique.

Exemple :

procedure p1(s)

1 s S

beginp

   display "!" & s & "!" 

endp

 

main

1 monstring S = "string"

1 monalpha 10 = "alpha"

 

p1(monstring) --> !string! 

p1(monalpha)  --> !alpha ! 

 

Lorsque le paramètre formel est de type String et passé par adresse, le paramètre réél doit être une donnée de type String (le compilateur génère une erreur dans le cas contraire).

Exemple :

procedure p1(&s)

1 s S

beginp

   s &= "z" 

endp

 

main

1 monstring S = "string"

1 monalpha 10 = "alpha"

 

p1(monstring) 

display monstring --> !stringz! 

; p1(monalpha) --> erreur de compilation
