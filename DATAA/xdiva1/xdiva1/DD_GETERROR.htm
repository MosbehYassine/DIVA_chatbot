DD_GETERROR  Famille  Thème

Long DDInterface (Commande , &ticket , [paramètres] , retour, [niveau])

 

DD_GETERROR

La commande DD_GETERROR permet de recevoir un message d’erreur complet. Elle est appelée après une commande ayant retourné une erreur.

 

Retour contient une chaîne HMP avec les paramètres suivants :

 

CodeErreur

Code d’erreur principal.

CodeSystème

Code d’erreur système.

CodeErrno

Code rendu par Windows.

TexteErreur

Texte de l’erreur.

 

 

Exemple

1  ticket L 

1  reponse 8096  

 if DDInterface(DD_OPEN,ticket,"odfdd.dhsd",reponse) <> 0

    DDInterface(DD_GETERROR,ticket," ",reponse,niveaudico) 

    display HmpSeek(reponse,"TexteErreur");

    ProgramExit

 endif
