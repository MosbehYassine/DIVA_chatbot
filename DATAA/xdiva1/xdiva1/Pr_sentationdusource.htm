Présentation du source

En général, un source Diva contient les éléments suivants :

  • les déclarations de données,

  • les déclarations de modules,

  • les fonctions/procédures

  • le programme principal.

La compilation se faisant en une passe, toute donnée ou fonction/procédure doit être déclarée avant d'être utilisée.
 

Déclarations

En général, les déclarations sont regroupées en début du source. Néanmoins, il est tout à fait possible de déclarer des données plus loin dans le source.

Commentaires

Le caractère ; indique que tout ce qui suit dans la ligne est à considérer comme étant un commentaire.
Les commentaires que vous placez dans vos sources sont exploités par le module d'assistance au codage de Xwin. Voir Insertion de commentaires dans le code.

 

Etiquettes

Les étiquettes de branchement doivent être précédées du mot clé Label.
 

Instructions

Il est possible de mettre plusieurs instructions sur la même ligne source en les séparant par le caractère | (code ANSI $7C). Seule exception : les instructions Beginp Beginf et Include doivent être seules sur leur ligne.

Il est également possible de continuer une même instruction sur la ligne suivante en terminant la ligne par le caractère \ (code ANSI $5C)

 

Expressions

La syntaxe du langage Diva est dite "régulière", c'est-à-dire que toute variable peut être remplacée par une expression complexe dont le résultat est du même type.

Dans la présente documentation, s'il n'y a pas de précisions explicites à ce sujet, le mot variable peut être interprété comme étant une expression complexe.

L'utilisation des parenthèses se fait suivant l'usage habituel. Elles permettent d'indiquer l'ordre des opérations à effectuer et apportent un gain de lisibilité des instructions complexes.
