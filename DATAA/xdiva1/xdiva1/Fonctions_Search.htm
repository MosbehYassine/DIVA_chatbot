Fonctions Search

Les fonctions Search permettent de dialoguer avec le serveur Power Search.

Elles permettent essentiellement de demander l'indexation d'un nouveau document, la ré-indexation d'un document modifié, la suppression de l'index d'un document supprimé.

Ces fonctions sont automatiquement appelées par le Zoom si un serveur Search est paramétré. Dans le cas d'une application qui crée ou modifie des documents, il faut appeler ces fonctions pour que la base Search soit mise à jour.

La fonction SearchOn permet de savoir qu'un serveur Search est paramétré et que le site dispose de la licence nécessaire pour l'utiliser.

La fonction SearchOpen permet d'ouvrir une session sur le serveur Search.

Les fonctions SearchCreateDocument, SearchModifyDocument et SearchDeleteDocument permettent de demander l'indexation ou la suppression de documents.

Les autres fonctions Search sont à usage interne pour le programme d'interrogation XSearch.dhop et pour la console XSearchConsole.dhop.
