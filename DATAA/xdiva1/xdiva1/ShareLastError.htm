ShareLastError  Famille Thème

 

La fonction ShareLastError permet de savoir quelle est la tâche qui réserve une entité. Elle peut être appelée après une fonction Hshare qui a rendu H_RESERVED.

 

Ptr = ShareLastError (tdf , résultat)

 

Paramètres

Tdf

Table de définition de fichier. Elle doit correspondre au fichier pour lequel la fonction Hshare à renvoyé H_RESERVED.

Résultat

Variable de type alpha ou string recevant une chaîne Hmp indiquant la tâche qui réserve l'entité. Si l'entité est partagée par plusieurs tâches, la chaîne contient la liste des tâches qui partagent l'entité.

La chaîne Hmp contient les paramètres suivants :

Si l'entité est réservée :

<Reserved>

Etat de l'entité. (R = réservé, F = forcé). Si ce paramètre est absent, cela signifie que l'entité est partagée.

<Task>

Numéro de tâche qui réserve l'entité.

<Host>

Nom de l'ordinateur qui réserve l'entité

<User>

Nom de l'utilisateur qui réserve l'entité

 

 

Si l'entité est partagée, pour chaque tâche partageant l'entité :

<Share>

Numéro de tâche qui partage l'entité

<Host>

Nom de l'ordinateur qui partage l'entité

<User>

Nom de l'utilisateur qui partage l'entité

 

Retour

0

Pas d’erreur

Autre

Code d’erreur système.

 

Exemple

record * htdf tdf

Procedure TraiterErreurShare

1 chaine S

1 host   S

1 user   S

1  tache  4,0

1 mode   1

1 param  S

1  valeur S

beginp

   ShareLastError(tdf,chaine)

   if (mode := hmpSeek(chaine,"reserved")) <> " "

      tache = HmpSeek(chaine,"task")

      host  = HmpSeek(chaine,"host")

      user  = HmpSeek(chaine,"user")

      display "Mode=" & mode & " Tache=" & tache & "  Host=" & host & "  User=" & user

   else

      Loop HmpRead(chaine,param,valeur) = 0

         switch param

         case "SHARE"

            tache = valeur

         case "HOST"

            host = valeur

         case "USER"

            user = valeur

            display "Tache=" & tache & "  Host=" & host & "  User=" & user

         endswitch

      endloop

   endif

endp

 

1 car 1

1 st  X

1 entite S = "entité"

main

tdf.Name = "fconfig.dhfi"

hopen(tdf,"P")

Loop TRUE

   Input "R=réserver  P=partager  F=Forcé  L=libérer" car

 

   switch fstring("U",car)

   case "R"

      st = Hshare(tdf,entite,"R")

      if st = H_RESERVED

         TraiterErreurShare

      endif

   case "P"

      st = Hshare(tdf,entite,"P")

      if st = H_RESERVED

         TraiterErreurShare

      endif

   case "F"

       st = Hshare(tdf,entite,"F")

       if st = H_RESERVED

          TraiterErreurShare

       endif

   case "L"

       st = Hshare(tdf,entite,"L")

   default

      programExit

   endswitch

endloop
