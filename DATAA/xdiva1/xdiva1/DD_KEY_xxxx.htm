DD_KEY_xxxx  Famille  Thème

Long DDInterface (Commande , &ticket , [paramètres] , retour, [niveau])

 

DD_KEYBEGIN

La commande DD_KEYBEGIN permet de se positionner sur le premier index du fichier et de la table courants.

Il faut donc avoir préalablement lu un fichier et une table de ce fichier.

 

Retour contient les caractéristiques du champ. Voir DDInterface : Index

La lecture des champs de l’index se fait par les commandes DD_DATAKEYBEGIN et DD_DATAKEY_NEXT .

 

Retour

0

pas d’erreur.

2

Pas d’index pour cette table.

autre

Erreur. Voir DD_GETERROR

 

Exemple

1  ticket L 

1  reponse 8096  

1  stindex X

stindex = DDInterface(DD_KEYBEGIN,ticket,,reponse)

 

DD_KEYBEGINFILE

La commande DD_KEYBEGINFILE permet de se positionner sur le premier index du fichier courant. A la différence de DD_KEYBEGIN qui délivre les index d’une seule table, DD_KEYBEGINFILE délivre tous les indexs du fichier.

Il faut donc avoir préalablement lu un fichier.

 

Retour contient les caractéristiques du champ. Voir DDInterface : Index

La lecture des champs de l’index se fait par les commandes DD_DATAKEYBEGIN et DD_DATAKEY_NEXT .

 

Retour

0

pas d’erreur.

2

Pas d’index pour cette table.

autre

Erreur. Voir DD_GETERROR

 

Exemple

1  ticket L 

1  reponse 8096  

1  stindex X

stindex = DDInterface(DD_KEYBEGINFILE,ticket,,reponse)

 

DD_KEYNEXT

La commande DD_KEYNEXT permet de lire l’index suivant. Il faut donc avoir préalablement lu un index par DD_KEYBEGIN.

La lecture des champs de l’index se fait par les commandes DD_DATAKEYBEGIN et DD_DATAKEY_NEXT .

 

Retour contient les caractéristiques du champ. Voir DDInterface : Index

 

Retour

0

pas d’erreur.

2

Plus d’index pour la table

autre

Erreur. Voir DD_GETERROR

 

Exemple

1  ticket L 

1  reponse 8096  

1  stindex X

stchamp = DDInterface(DD_KEYNEXT,ticket,,reponse)
