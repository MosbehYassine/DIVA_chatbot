Le partage des fichiers

Lors de l'ouverture d'un fichier, trois modes de partage sont possibles :

  • le mode réservé (R)

  • le mode partagé (P)

  • le mode lecture-seulement (READ_ONLY) et partagé (F).

Le mode réservé est exclusif, c'est à dire qu'aucun programme ne peut ouvrir un fichier déjà ouvert en mode réservé. Si le fichier est déjà ouvert par un autre programme, l'ouverture en mode réservé est refusée.

Le mode partagé permet à plusieurs programmes d'ouvrir simultanément le même fichier. Pour assurer l'intégrité du fichier, le programme doit alors veiller si nécessaire à bien gérer le partage des enregistrements.

Le mode lecture-seulement permet d'ouvrir un fichier en mode partagé pour lequel l'utilisateur a les droits de lecture mais pas les droits d'écriture. En mode P ou R les fichiers sont toujours ouverts en lecture-écriture (O_RDWR).

Ce mode peut être utilisé pour accéder à un fichier d'un CDROM.

La libération du fichier est automatique, soit à la fermeture du fichier, soit lors de l'enchaînement à un autre programme.

Voir les instructions de déclaration de fichier HFile et HTmpFile qui permettent d'ouvrir les fichiers automatiquement en précisant le mode de partage.

 

Exemple :

status = fopen(tdf,"P")
ouvre le fichier en mode partagé.
