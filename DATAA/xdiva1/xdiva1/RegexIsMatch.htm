RegexIsMatch  Famille 

 

La fonction RegexIsMatch permet de tester si une chaîne de caractères correspond à un format. Par exemple, tester qu'une adresse de messagerie internet est valide.

Le format utilise la syntaxe des expressions régulières.

 

Long = RegexIsMatch  ( chaine , format, [options] , [timeout] )

 

Paramètres

Chaine

Chaîne dans laquelle une correspondance doit être recherchée.

 

Format

Modèle d'expression régulière à mettre en correspondance.

 

Options

Options pour la correspondance. Voir Options Regex

 

TimeOut

Un délai d’attente en milli-secondes ou 0 pour indiquer que la méthode ne doit pas expirer.

 

Retour

0

L'expression régulière ne trouve aucune correspondance

1

L'expression régulière trouve une correspondance

2

Un des paramètres est null

3

Options n’est pas une valeur correcte

ou Timeout a une valeur négative, nulle ou supérieure à environ 24 jours

4

Une erreur d’analyse d’expression régulière s’est produite.

5

Le délai d'attente a expiré

6

Autre exception .net
 
 

Exemple :

 

; Vérifier qu'une adresse de messagerie internet est valide.

 

main

 

1 formatregex S

 

formatregex = '^(?("")("".+?(?<!\\)""@)|(([0-9a-z]((\.(?!\.))|[-!#\$%&' & \

               "'\*\+/=\?\^`\{\}\|~\w])*)(?<=[0-9a-z])@))" & \

               '(?(\[)(\[(\d{1,3}\.){3}\d{1,3}\])|(([0-9a-z][-0-9a-z]*[0-9a-z]*\.)+[a-z0-9][\-a-z0-9]{0,22}[a-z0-9]))$'

 

RegexIsMatch("Bruno.houver@laposte.net",formatregex   ,RegexOpt_IgnoreCase);    --> 1

RegexIsMatch("Bruno.houver@laposte.net",formatregex);                           --> 0 (à cause du B majucule)

RegexIsMatch("Bruno.houver!laposte.net",formatregex   ,RegexOpt_IgnoreCase, 1); --> 0
