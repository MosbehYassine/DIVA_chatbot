GetErrno  Famille Thème

 

GetErrno permet de récupérer le code d'erreur du système d'exploitation.


Long = GetErrno

 
Ce code complémentaire d'erreur est affiché par la fonction Ferror.

Il peut être placé dans le paramètre CodeCompl de la fonction ErrorFatal.
