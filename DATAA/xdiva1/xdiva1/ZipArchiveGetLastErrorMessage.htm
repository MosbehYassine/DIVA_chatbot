ZipArchiveGetLastErrorMessage Famille Thème

 

La fonction ZipArchiveGetLastErrorMessage() permet de récupérer le message d’erreur détaillé de la dernière fonction en échec du module de gestion des archives.

 

Alpha ZipArchiveGetLastErrorMessage()

 

Retour

La fonction renvoie le message d'erreur détaillé.

 

Remarque

Cette fonction doit être appelée immédiatement après celle qui a renvoyé un code d'erreur.
