HSiCreate  Famille Thème

 

La fonction HSiCreate permet de créer un fichier de type I (séquentiel indexé). HSiCreate crée et initialise le fichier paramètres et clés et crée le fichier des données.

Pour créer un fichier de type C, U ou N, il faut utiliser HCreateFile.

 

Ptr = HSiCreate (fichier, nomdata, type, lgenr, clés, [étendu], status, [abort])

 
Paramètres

Fichier

Nom complet du fichier des clés.

NomData

Nom du fichier des données.

Si ce nom est à espaces, le nom du fichier des données est déduit du nom des clés de la manière suivante :

- si le fichier des clés a une extension, le fichier des données a le même nom avec l'extension .dhfd.

- si le fichier des clés n'a pas d'extension, le fichier des données a le même nom suffixé par la lettre d.

En général, on ne précisera pas le chemin complet pour le nom du fichier des données. Dans ce cas, il sera créé dans le même répertoire que le fichier des clés.

 

Type

Type (N C ou U) du fichier des données.

Lgenr

Taille des enregistrements du fichier des données (0 = taille variable).

Clés

Description des clés. Ce paramètre doit être une instance de l'enregistrement Cles du dictionnaire ddsys.dhsd. Cette zone doit préalablement être initialisée par des $00.

Etendu

Paramètre non utilisé.

Status

Donnée de type X qui reçoit le code d'erreur système.

Abort

Booléen (TRUE par défaut) indiquant si la fonction doit arrêter le programme en cas d'erreur, ou rendre la main avec un code d'erreur.

En cas d'arrêt du programme, la fenêtre standard des erreurs est affichée et l'erreur est journalisée dans le fichier ferror.log.

 

 

L'enregistrement Cles contenant la description des clés est un tableau de 256 cases pour les clés.

LettreCle

Lettre clé.

NomCle

Nom de la clé. Il faut préciser soit LettreCle soit NomCle.

PositionCe

Position du code enregistrement.

ValeurCe

Valeur du code enregistrement.

TestCe

Test à effectuer sur le code enregistrement

 

0 =
1 <>
2 <
3 >
4 <=
5 >=
6 &

égal
différent
inférieur
supérieur
inférieur ou égal
supérieur ou égal
et logique
 

Pour chaque clé, on trouve ensuite un tableau de 16 éléments décrivant les données qui composent la clé :

PosCle

Position d'un fragment de clé.

LgCle

Longueur d'un fragment de clé.

 

Retour

La fonction renvoie la valeur nulle en cas de succès. Sinon, elle renvoie un code d'erreur principal, et le paramètre Status contient le code d'erreur du système.

Pour la liste des erreurs possibles, voir Erreurs des fonctions HcreateFile, HSicreate

Si Abort = TRUE, toutes les erreurs provoquent l'arrêt du programme.

 

Remarque

L'instruction HTmpFile permet de créer des fichiers séquentiels indexés temporaires. La description des clés est prise dans le dictionnaire des données.

La fonction DDInterface permet de lire la structure des clés d’un fichier telle qu’elle est définie dans le dictionnaire des données.

Exemple

; Création du fichier ftest.dhfi

; Le fichier des données sera ftest.dhfd

record 'ddsys.dhsd' cles

1 statsys x

 

init cles = $00

cles.lettrecle(1) = 'A'

cles.poscle (1,1) = 1

cles.lgcle (1,1) = 6

HSiCreate("/Divalto/sys/ftest.dhfi"," ","N",124,cles, \

Etendu = TRUE,statsys,abort = TRUE)
