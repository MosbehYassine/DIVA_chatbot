AssemblyLoad  Famille  Thème

La fonction AssemblyLoad permet de charger une assembly .net.

 

Long  AssemblyLoad  ( nom_assembly )

 

Paramètres

nom_assembly

Nom de l'assembly à charger.

 

Retour

 

0

Erreur. Appelez AssemblyGetError. pour en connaître le détail.

Autre

Ticket permettant d'utiliser l'assembly.

 

 

Remarques

Il est conseillé de placer vos assemblies  dans le répertoire /divalto/sys.

AssemblyLoad appelle la méthode Assembly.LoadFrom de .net. Vous pouvez consulter la documentation de cette fonction.
