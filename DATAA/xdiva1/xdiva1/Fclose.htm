Fclose  Famille Thème

 

Fclose ferme un fichier préalablement ouvert.

 

Ptr = fclose ( tdf )

 

Paramètres

Tdf

Table de définition de fichier.

  

Retour

0  

Pas d'erreur. 

autres

Code d'erreur système. 

  

Remarque

Les fichiers ouverts automatiquement par l'instruction HFile sont fermés automatiquement par le système. La fonction Fclose est utilisée pour fermer les fichiers ouverts manuellement par la fonction Fopen.
 

Exemple

;________________________________________________________________

; Fonction : F_CLOSE

; Type : int

; Description : Ferme le fichier tdf

;

; Paramètre en sortie : 0 = ok # = erreur

;________________________________________________________________

;

Function int F_CLOSE (&tdf)

Record * htdf tdf ;table de définition

beginf

   cr = fclose (tdf) 

   if cr <> 0  

      MessageBox(" Erreur système numéro " & binhexa (stx (cr)) & \ 

                    " à la fermeture du fichier " & left(tdf.name)," ") 

   endif 

   freturn (cr) 

endf
