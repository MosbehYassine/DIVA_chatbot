Band  Famille

 

La fonction Band permet d'effectuer un Et logique entre 2 valeurs.

 

? = band (v1 , v2)

 

Paramètres

V1 V2

Les deux paramètres sont de type quelconque.

 

Retour

Le type du retour de la fonction dépend du type des deux paramètres V1 et V2.

  • si un des paramètres est de type N ou L le résultat est de type L.

  • sinon si un des paramètres est de type X le résultat est de type X

  • sinon le résultat est de type B.

 

Exemple

Faire tomber le cinquième bit d'un caractère, ce qui revient à le passer en caractère majuscule.

1 car 1
car = Band(car, $df)
