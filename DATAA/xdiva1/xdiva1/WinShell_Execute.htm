WinShell_Execute Famille Thème

 

Long WinShell_Execute (Opération, fichier, [paramètres], [répertoire], mode_aff)

 

Cette fonction est très similaire à la fonction WinShellExecute. Elle requiert les mêmes paramètres et retourne les mêmes valeurs.

Elle exécute le fichier comme le ferait la fonction WinShellExecute mais en plus entretient une liste interne des fichiers qu'elle a lancés, ainsi que la date et l'heure de dernière modification du fichier au moment du lancement.

Lorsque cela est possible, on garde également un lien avec le processus qui ouvre ou exécute le fichier (cela n’est pas toujours possible, par exemple lorsque ce sont des appels DDE)

 

Remarque 1 :

En client léger WPF, WinShell_Execute s’exécute sur le poste du client léger, il faut donc préalablement charger le fichier sur le poste client avec la fonction LcWinDownload.

 

Remarque 2 :

Lorsque qu’une seule application est utilisée pour de multiples fichiers (par exemples plusieurs documents Word), on ne sait pas distinguer l’état des fichiers de manière individuelle : tant que l’application n'est pas fermée, les fichiers de ce type seront tous considérés comme en cours d'utilisation.

 

Paramètres :

Opération

Opération à effectuer.

"open"

La fonction ouvre le fichier. Le fichier peut être un exécutable ou un document ou un répertoire.

"print"

La fonction imprime le fichier. Le fichier doit être un document et non un exécutable.

"explore"

La fonction lance l'explorateur de Windows sur le répertoire précisé dans Fichier.

Fichier

Nom de fichier ou nom de programme ou nom de répertoire.

Paramètres

Si le paramètre Fichier est un exécutable, ces paramètres sont passés à l'application. Valeur par défaut = espace

Répertoire

Permet de positionner le répertoire par défaut. Valeur par défaut = espace.

Mode_aff

Mode d'affichage du programme. Valeur par défaut = SHOW_ NORMAL (seul mode possible en client léger Html).
Les valeurs possibles sont :

SW_HIDE

SW_SHOWNORMAL

SW_NORMAL

SW_SHOWMINIMIZED

SW_SHOWMAXIMIZED

SW_MAXIMIZE SW_SHOWNOACTIVATE

SW_SHOW

SW_MINIMIZE

SW_SHOWMINNOACTIVE

SW_SHOWNA

SW_RESTORE

SW_SHOWDEFAULT

SW_MAX

 

Retour : 

 

0

Pas d'erreur.

2

Fichier non trouvé

3

Chemin non trouvé

5

Accès au fichier interdit

8

Pas assez de mémoire

11

Format de l'exécutable erroné.

26

Conflit de partage de la ressource (sharing violation)

27

Association incomplète

28

Erreur de time-out dans la transaction DDE

29

Erreur lors de la transaction DDE.

30

La transaction DDE ne peut se terminer car d'autres transactions sont en cours.

31

Pas d'association avec le fichier spécifié.

32

Dll non trouvée
