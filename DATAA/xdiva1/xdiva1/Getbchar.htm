Getbchar  Famille 

 

La fonction Getbchar attend qu'un caractère soit tapé au clavier. Cette fonction est bloquante, c'est à dire que le programme est stoppé jusqu'à la frappe d'un caractère.

 

Bin = getbchar ( AvecHarmonyKey )

 

Paramètres

AvecHarmonyKey

TRUE

la fonction positionne Harmony.key. Il est conseillé d'utiliser ce mode.

FALSE

(valeur par défaut) la fonction ne modifie pas Harmony.Key. Ce mode permet d'assurer la compatibilité totale avec la fonction GetbChar de la version 5 d'Harmony.

 

 
Retour

Le code ANSI de la touche frappée.

La donnée Harmony.Key est positionnée, il est conseillé d'utiliser cette valeur plutôt que la valeur retournée par la fonction.
