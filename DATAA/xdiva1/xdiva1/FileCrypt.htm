FileCrypt  Famille Thème

FileCrypt permet de crypter un fichier. Les fichiers cryptés par FileCypt peuvent être décryptés par la fonction FileUncrypt .

Le fichier crypté est également comprimé.


Ptr = FileCrypt (fichier_départ , fichier_arrivée, clé, code_système)


Paramètres

Fichier_départ

Nom du fichier à crypter.

Fichier_arrivée

Nom du fichier crypté. Si ce fichier n'existe pas, il est automatiquement créé. Le fichier d'arrivée doit obligatoirement être distinct du fichier de départ.

Code_système

Donnée numérique qui reçoit un code d'erreur système.

Clé

Clé de cryptage. Cette clé est bien évidemment nécessaire au décryptage. Elle ne doit pas être trop courte (plus de 20 caractères).

  
Retour

La fonction retourne un code d'erreur principal et un code d'erreur système.

Voir Codes d'erreurs des fonctions de cryptage et de compression .

 

Remarque

La fonction Crypt permet de crypter une chaîne de caractères.

 

Exemple


1 cle S

1 st x

1 ficdepart S = "xxxx" 

1 ficarrivee S = "yyyy" 

cle = "ceciestmacledecryptage" 

FileCrypt(ficdepart,ficarrivee,cle,st)
