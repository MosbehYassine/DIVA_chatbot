SelectPrinter

La fonction SelectPrinter permet de charger un modèle d'imprimante. A la différence de HSelectPrinter, cette fonction n'affiche pas de message en cas d'erreur mais renvoie deux codes d'erreurs.

 

Numer SelectPrinter (modèle, mode, errsys, eimp, temporaire)

 

Paramètres

 

Modèle

Modèle d'imprimante à charger.

Mode

MODELE_CONSEILLE

Le modèle est conseillé, c'est à dire que le menu pourra sélectionner un autre modèle le temps de l'exécution d'un programme.

MODELE_IMPERATIF

Le modèle est impératif, c'est à dire que le menu ne peut pas le modifier.

Errsys

Code d'erreur système (Valeur fournie en retour)

Eimp 

Instance de l'enregistrement Eimp du dictionnaire ddsys.dhsd. Cet enregistrement est garni en retour par les paramètres du modèle chargé.

 

Temporaire

TRUE

Le modèle d'origine sera restauré à la fin du programme (retour au menu)

FALSE

Le modèle d'origine ne sera pas restauré à la fin du programme (valeur par défaut).

 

Retour

E_MODELE_TRANSPARENCE

Le mode transparence est interdit sous Windows. Voir la définition du modèle. 

E_MODELE_VIDEOVIDE

Le fichier (fihxxxx) est vide.

E_MODELE_ERRVIDEO

Le fichier (fihxxxx) est erroné. Eimp.zivideo contient le nom du fichier et Errsys contient le code d'erreur système.

E_MODELE_OPENVOIE

Erreur d'ouverture de la voie série ou parallèle, Errsys contient le code d'erreur système

E_MODELE_ERRVIDEO1

Erreur lors du chargement du fichier vidéo. Eimp.zivideo contient le nom du fichier et Errsys contient le code d'erreur système.

E_MODELE_MODPRINTER

Erreur lors du chargement du modèle, Errsys contient le code d'erreur système.

E_MODELE_ERRFIMP 

Erreur sur le fichier Fprinters, Errsys contient le code d'erreur système.

E_MODELE_MODELEABSENT

Modèle absent.

 

Exemple

1  errsys X

Record ddsys.dhsd Eimp

main

display SelectPrinter("test",MODELE_CONSEILLE,errsys,eimp,TRUE)
