SortCompare SortCompareByValue

Les fonctions SortCompare et SortCompareByValue permettent de comparer le plus rapidement possible deux éléments lors de tris avec les instructions Sort, ListSort et ListMode.

La différence entre les deux fonctions est la suivante : Les paramètres de SortCompare sont passés par adresse et les paramètres de SortCompareByValue sont passés par valeur.

Le passage par adresse est plus rapide que le passage par valeur, mais il interdit de passer une concaténation. Du coup SortCompare oblige à passer par des variable locales ce qui occasionne une baisse des performances.

 

Long = SortCompare ( &V1 , &V2 )

  Long = SortCompareByValue ( V1 , V2 )

 

Paramètres

V1 V2

V1 et V2 sont les deux données à comparer

 

Retour

0

V1 > V2

1

V1 < V2

2

V1 = V2
 

Exemples

function long compare(&p1,&p2)

1 p1 N

1 p2 N

beginf

freturn SortCompare(p1,p2) ; est equivalent à 

   ; freturn (condition(p1=p2,2,p1<p2))

endf

 

function long triExt (&a , &b)

record ddsys.dhsd DDInterfaceDataField a

record ddsys.dhsd DDInterfaceDataField b

beginf

; Les [] pour la concaténation sont bien plus performants que l'opérateur & quand il y a plus de champs à concaténer

freturn SortCompareByValue( [ a.FieldName a.FieldLibelle ... ],  [ b.FieldName b.FieldLibelle ... ])

endf
