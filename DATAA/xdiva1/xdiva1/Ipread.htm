Ipread  Famille Thème

 

La fonction Ipread ne peut être utilisée qu'avec les fichiers séquentiels indexés.

Ipread permet :

  • de lire l'enregistrement précédent le dernier enregistrement lu (La lecture se fait d'après l'index courant et la "fin de fichier" est provoquée par le début de l'index).

  •  de se positionner directement sur un enregistrement en modifiant la clé. L'enregistrement lu est alors celui ayant la clé la plus proche (inférieure ou égale) de la clé demandée (voir exemple).

Ptr = Ipread  ( tdf , table [,nomIndex] [, valeurClé ] [ ,partage ] )

Paramètres

Tdf

Table de définition de fichier.

Table

Donnée réceptrice qui contiendra l'enregistrement lu.

NomIndex

Ce paramètre est facultatif. Il permet de préciser le nom de l'index qui doit être utilisé. S'il n'est pas précisé, la lecture se fait selon l'index courant.

ValeurClé

Ce paramètre est facultatif. Si ValeurClé est spécifié, la lecture se fait à partir de cette valeur de clé. L'enregistrement lu est celui ayant la clé la plus proche (inférieure ou égale) de la clé demandée.

Code_réservation

Mode de partage de l'enregistrement ('P' par défaut).

  

Retour

0  

Pas d'erreur. 

Si une procédure Après Read est définie dans le dictionnaire, elle est appelée.

Les paramètres passés à la procédure Après Read sont :

Tdf

La Tdf du fichier.

Table

L'enregistrement qui a été lu.

Cle

La valeur de la clé associée à l'enregistrement lu.

Partage

Le mode de partage.

Opération

Opération effectuée sur le fichier.
R = lecture du suivant (iread)
P = lecture du précédent (ipread)
S = lecture directe (iseek)

 

H_EOF  

Début de fichier atteint.

H_RESERVED  

Enregistrement réservé.

Toutes les autres erreurs provoquent l'arrêt du programme

  

Remarques

Il est possible de modifier la clé avant d'utiliser la fonction Ipread pour se positionner directement sur un enregistrement. L'enregistrement lu est alors celui dont la clé est inférieure ou égale à la clé placée dans la TDF.

 

Pour lire un fichier "à l'envers", il faut charger au départ la clé avec une valeur supérieure à la clé la plus grande possible.
Exemples :
 fic.keyValue = $FF ou
 fic.keyValue = "zzzzzz"

 

Si la fonction Ipread retourne H_EOF (début de fichier), un appel à la fonction Iread délivre le premier enregistrement du fichier d'après l'index courant.

Si l'enregistrement contient une zone packée, celle-ci est automatiquement dépackée.

La fonction IFilter permet de filtrer les enregistrements.

La fonction GetLastRecord permet de récupérer le dernier enregistrement lu.

 

Exemple

Lire le fichier des compositeurs à partir de la fin.

comp.keyValue = $FF ; positionnement clé

do

   st = Ipread (comp , cpenr ,"NomCompo",,'F') 

while st = 0

   display [ cpenr.codecp " " cpenr.nom " " cpenr.prenom ] 

wend
