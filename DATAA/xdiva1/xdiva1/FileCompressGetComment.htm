FileCompressGetComment  Famille Thème

 

Cette fonction permet de lire les commentaires d'un fichier comprimé par FileCompress.


Ptr = FileCompressGetComment (fichier , comm)


Paramètres

Fichier

Nom du fichier comprimé.

Comm

Donnée alphanumérique qui reçoit les commentaires associés au fichier.

 
Retour

0

Pas d'erreur.

Autres

Code d'erreur système
