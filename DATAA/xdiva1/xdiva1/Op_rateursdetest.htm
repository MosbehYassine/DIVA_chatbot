Opérateurs de test  Famille

 

Tous les opérateurs de test rendent comme résultat une valeur de type L contenant 0 pour faux et 1 pour vrai. Il est donc possible d'écrire les instructions suivantes :
i = (j < 0)+1
if i | display "i est différent de 0" | endif

Il y a possibilité de mélanger les types, le type de la comparaison est déterminé par le type de la variable de gauche.

Les opérateurs de test sont :

=   : égal

<   : inférieur

>   : supérieur

<=   : inférieur ou égal

>=   : supérieur ou égal

<>   : différent

In   : appartenance à une énumération

Like  : comparaison approximative

Match  : comparaison approximative

LikeSql : comparaison approximative compatible Sql

Cas particulier :

Il est possible d'affecter une chaîne d'espaces à une variable numérique définie par longueur,décimales.

La valeur de cette variable est nulle et les tests suivants sont vrais :

If v = " "
If v = 0


Voir

La fonction Inspect permet de tester l'appartenance d'une valeur à une liste de valeurs et/ou à un intervalle.

La fonction Search permet de rechercher un élément dans un tableau.

Les fonctions Max et Min qui retournent respectivement la plus petite et la plus grande valeur.
