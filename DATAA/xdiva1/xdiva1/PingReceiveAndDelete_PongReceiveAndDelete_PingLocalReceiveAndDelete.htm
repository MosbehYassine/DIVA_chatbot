PingReceiveAndDelete - PongReceiveAndDelete - PingLocalReceiveAndDelete  Famille Thème

Les fonctions PingReceiveAndDelete, PongReceiveAndDelete, PingLocalReceiveAndDelete permettent de lire une donnée dans un tunnel. Une fois la donnée lue, elle est supprimée du tunnel.

Pour lire une donnée dans un tunnel sans la supprimer du tunnel, il faut uitliser les fonctions PingReceive - PongReceive - PingLocalReceive.

 

Long PingReceiveAndDelete ( libellé , donnée)

Paramètres

Libellé

Chaîne de caractères identifiant la donnée a lire dans le tunnel.

Donnée

Donnée dans laquelle est affectée la valeur lue dans le tunnel. Si le libellé n'est pas trouvé dans le tunnel, donnée est mise à espaces.


Retour

0 si la donnée a été trouvée dans le tunnel, 1 sinon.
