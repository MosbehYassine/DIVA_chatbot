XmlGetFileError  Famille  Thème

La fonction XmlGetFileError doit être appelée après la fonction XmlOpen si cette dernière à renvoyé la valeur nulle. Elle retourne le code et le nom complet du fichier en erreur.

 

Ptr = XmlGetFileError (&Fichier)

Fichier

Contient en retour le nom complet du fichier en erreur.

 

Retour

La fonction retourne le code de l’erreur.

Pour un fichier au format Windows, le code d’erreur est fourni par Windows (fonction GetLastError). Pour un fichier au format Harmony, le code est un code d’erreur Harmony ; dans ce cas, l’erreur a pu être provoquée soit par l’ouverture du fichier, soit par la lecture (le fichier est lu en entier lors de l’appel à XmlOpen).
