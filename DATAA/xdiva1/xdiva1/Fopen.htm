Fopen  Famille Thème

 

La fonction Fopen permet d'ouvrir un fichier "à la main". Par défaut les fichiers déclarés par l'instruction HFile sont automatiquement ouverts.

 

Ptr fopen ( tdf [, code_réservation ] )

 

Paramètres

Tdf

Table de définition de fichier. Le nom du fichier à ouvrir doit être placé au préalable dans le champ name de la tdf.

Code_réservation

Mode de partage du fichier ('R' par défaut).

  

Retour

0  

Pas d'erreur. 

$13  

Nom de fichier incorrect. 

$14  

Fichier absent. 

H_RESERVED  

Erreur de partage. 

autres

Code d'erreur système. 

 

Remarques :

Un fichier ouvert doit être fermé avant toute réouverture.

Sous Unix, les noms de fichiers doivent être en caractères minuscules. Harmony ne peut accéder à un fichier unix dont le nom comprend un caractère majuscule. Le nom du fichier à ouvrir placé dans la tdf est automatiquement convertit en caractères minuscules.

Si le fichier est de type I (séquentiel-indexé), la clé de la tdf est initialisée à "A". Une lecture (fread) délivrera donc le premier enregistrement du fichier pour la clé A.

 

Exemple :

;________________________________________________________________

; Fonction : F_OPEN

; Type : int

; Description : Ouvre le fichier "fic" en mode "par"

;

; Paramètres en sortie : 0 = ok 1 = absent 2 = réservé

; 3 = erreur système

;________________________________________________________________

;

Function int F_OPEN (fic , &tdf , par , mes)

1 fic A ; nom du fichier

record * htdf tdf ; table définition fichier

1 par A ; code partage

1 mes A ; indic message si absent

beginf

   tdf.name = fic 

   cr = fopen (tdf,par) 

   switch cr 

   case 0 ;ok 

      freturn (0) 

   case $14 ;absent 

      if mes = 'O' 

         MessageBox("Fichier :" & left(tdf.name) & " absent"," ")

      endif 

      freturn (1) 

   case H_RESERVED ;réservé 

      MessageBox("Fichier : " & left(tdf.name) & " réservé"," ") 

      freturn (2) 

   default ;erreur système 

      MessageBox(Erreur système numéro " & binhexa (stx (cr)) & \ 

                  " à l'ouverture du fichier " & left(tdf.name)," ") 

      freturn (3) 

   endswitch 

endf

 

Exemple d'appel :

if f_open("fcomp",comp,"P",0) <> 0

   ProgramExit 

endif
