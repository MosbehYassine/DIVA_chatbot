OpenXml_WriteFormat  Famille  Theme

 

La fonction OpenXml_WriteFormat modifie le contenu d'une cellule. L'écriture dans la cellule se fait avec un format.

 

int OpenXml_WriteFormat (lig, col, valeur, [form], [decim], [multi], [zero], [indexcouleurfond], [p1], [p2], [p3])

 

Paramètres

Lig

Numéro de ligne.

 

Col

Numéro de colonne.

 

Valeur

Valeur de la cellule.

 

Form

 Format de la valeur :

"Texte"

Valeur représente un texte et le format d'affichage par défaut est "@".

"Numeric"

Valeur est numérique, le champ <decim> doit contenir le nombre de 0

que l'on veut voir après la virgule.

"Date"

Valeur est une date au format AAAAMMJJ.

"DateHeure"    

Valeur doit être au format AAAAMMJJHHMMSS.

"Heure"

Valeur doit être au format HHMM [SS] ; la zone secondes [SS] n'est pas lue (on peut la mettre ou pas, on fait comme si c'était 00).

"HeureMinuteSeconde"

Valeur doit être au format HHMMSS.

"Duree"

Valeur doit contenir un nombre de secondes.

"MultiChoix"

Valeur contient le numéro de choix et le champ <multi> doit contenir la liste des choix possibles, séparés par le caractère | . Le résultat est de type texte.

 

Decim

Nombre de décimales si le format est "Numeric".

 

Multi

 Liste des choix si le format est  "multichoix" (les choix sont séparés par le caractère |).

 

Zero

FALSE : une valeur nulle est remplacée par des espaces (valeur par défaut).

TRUE : une valeur nulle est affichée.

 

IndexCouleurFond

Indice de la couleur de fond :

0 = couleur par défaut.

Autre : voir le tableau des couleurs.

 

P1

Identifiant de la police rendu par la fonction OpenXml_CreateFont.

0 = police par défaut.

 

P2

Drapeau de séparation des milliers (0 par défaut) :

1 : avec séparation des milliers.

Remarque : Nécessite que la séparation des milliers soit autorisée dans les paramètres de configuration Divalto Office (choix "Paramétrage Office" du menu Harmony.dhop, onglet "Format des données pour le tableur", option "Autoriser le découpage des milliers"). Dans l’onglet "Format des données pour le tableur", l'utilisateur peut définir le caractère à utiliser pour la séparation des milliers (espace par défaut).

 

P3

Mode fichier (0 par défaut) :

1 : le champ Valeur contient un nom de fichier et la valeur de la cellule doit être lue à partir de ce fichier. Ceci permet par exemple de mettre un grand texte dans une cellule.

 

Remarques :

  • L’écriture se fait en mémoire uniquement. Les modifications sont enregistrées lors de l'appel à la fonction OpenXml_FileClose.

  • Cette fonction ne traite pas les formules (voir la fonction OpenXml_WriteFormula).

  • Attention : La fonction ne lance pas le recalcul des cellules. Pour recalculer le tableau et que le résultat soit enregistré, il faut recharger le fichier dans Excel et sauvegarder le résultat. Au prochain appel à OpenXml, la lecture des cellules fournira les valeurs recalculées.

Retour

0

Pas d'erreur.

Autre

Erreur. Voir la fonction OpenXml_GetMsgError.

 

 

Exemples

OpenXml_WriteFormat (lig,col,"10,1239","Numeric",2) ;Numérique (2 chiffres après la virgule)

OpenXml_WriteFormat (lig,col,"20140926","Date")

OpenXml_WriteFormat (lig,col,"Simple texte","Texte")

OpenXml_WriteFormat (lig,col,"201409261030","DateHeure")

OpenXml_WriteFormat (lig,col,"103000","Heure")

OpenXml_WriteFormat (lig,col,"103000","HeureMinuteSeconde")

OpenXml_WriteFormat (lig,col,"70","Duree")          ;1 minutes et 10 secondes

OpenXml_WriteFormat (lig,col,2,"MultiChoix",0,"Monsieur|Madame")

 

ppgras  = OpenXml_CreateFont(1)     ; police juste gras

pptitre = OpenXml_CreateFont(1,16 ) ; police gras et taille 16

OpenXml_WriteFormat (lig,col,"10,126","Numeric",2," ",false,0,ppgras)  ;gras et pas de couleur

OpenXml_WriteFormat (lig,col,"10,1239","Numeric",2," ",false,3,ppgras) ;gras et couleur 3 (rouge)

OpenXml_WriteFormat (lig,col,"20140926","Date"," ",false,24,pptitre)   ;grand titre, couleur 24 (bleu ciel)

OpenXml_WriteFormat (lig,col,"Simple texte","Texte"," ",false,0,0)     ;pas de format

OpenXml_WriteFormat (lig,col,"201409261030","DateHeure"," ",false,0,0) ;rien

OpenXml_WriteFormat (lig,col,"103000","Heure"," ",false,24,pptitre)    ;grand titre et couleur 24

OpenXml_WriteFormat (lig,col,"103000","HeureMinuteSeconde"," ",false,24)
