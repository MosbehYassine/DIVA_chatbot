Gestion de dictionnaires

Diva intègre un ensemble de fonctions permettant de gérer des objets dictionnaires.

Un dictionnaire est une collections de <clé,valeur>. La clé est unique dans le dictionnaire, il n'est donc pas possible d'insérer deux éléments ayant la même clé. La recherche dans un dictionnaire est quasi instantanée, quelque soit le nombre d'éléments du dictionnaire.

Un dictionnaire est identifié par un ticket rendu par la fonction de création DictionaryCreate. Ce ticket est ensuite passé en paramètre à toutes les fonctions de gestion des dictionnaires.

La fonction DictionaryAdd permet d'ajouter des éléments à un dictionnaire.

La fonction DictionarySearch permet de rechercher une valeur à partir de sa clé.

Les fonctions DictionaryBegin, DictionaryNext permettent de balayer le dictionnaire séquentiellement, dans l'ordre de création des clés.

Les fonctions DictionaryModify, DictionaryRemove permettent respectivement de modifier un élément et supprimer un élément du dictionnaire.

 

Dictionnaires nommés

Il est possible d’associer un nom à un dictionnaire puis de rechercher un dictionnaire d’après son nom.

La fonctions DictionaryGetId recherche un dictionnaire d’après son nom. Si le dictionnaire n’existe pas, il est automatiquement créé avec le nom spécifié.

La fonction DictionarySetName permet d’associer un nom à un dictionnaire existant.
