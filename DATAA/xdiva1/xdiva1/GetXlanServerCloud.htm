GetXlanServerCloud

 

La fonction GetXlanServerCloud retourne le nom du serveur xlan dans la table des serveurs.

Cette fonction n'a de sens que si le programme s'exécute sur une plate forme cloud. Voir IAmCloudServer.

 

BOOL GetXlanServerCloud

 

Retour

La fonction renvoie le nom du serveur xlan. Ce nom provient de l'environnement courant de l'utilisateur.
