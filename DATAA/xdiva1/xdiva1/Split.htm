Split   Famille 

 

La fonction Split permet de décomposer une chaîne de caractères en mots. Chaque appel de la fonction délivre le mot suivant.

 

Alpha = Split (chaîne , position , [ séparateurs ] , [ séparateursPaire ] , [ séparateursNonRendus ] , [ quotes ] )

 
  

Paramètres

Chaîne

Chaîne de caractères en entrée.

 

Position

Entrée : Position dans Chaîne à partir de laquelle débute l'analyse.

Retour : Contient la position à partir de laquelle chercher le prochaine mot.

 

Séparateurs

Chaîne de caractères contenant la liste des caractères séparateurs de mots.

Cette chaîne peut être vide.

Exemple : ":.()&=+<>-/*, "

 

SéparateursPaire

Chaîne de caractères contenant la liste des séparateurs de mots qui sont sur deux positions. Les paires doivent être séparées par un espace.

Attention : les paires ne sont prises en compte que si le premier caractère se trouve également dans Séparateurs.

Exemple : ">= <= .. += &= && := ++ --"

 

SéparateursNonRendus

Chaîne de caractères contenant les séparateurs simples qui ne seront pas rendus par la fonction.

Par exemple, si nous voulons extraire une liste de paramètres entre virgules, la virgule elle même ne nous intéresse pas. On mettra donc la virgule dans SéparateursNonRendus

Le séparateur espace n'est jamais rendu.

Les séparateurs non rendus ne doivent pas se trouver dans la liste Séparateurs

 

Quotes

1

un mot entre quotes doit toujours être considéré comme un mot, indépendamment des séparateurs (valeur par défaut)

0

un mot entre quotes n'est pas  toujours être considéré comme étant un mot

2

les quotes sont ignorées, c'est à dire quelles sont traitées comme des caractères ordinaires.

 

 

Retour

La fonction renvoie le mot extrait de chaîne.

S'il n'y a plus de mots dans la chaîne, la fonction retourne $00.

Position contient la position courante pour la recherche du mot suivant.

 

Exemple 1

; 2 séparateurs : espace et =

1 position L

1 chaine   S

1 mot      S

position = 1

chaine =  "a = b T"

loop (mot := Split(chaine,position," =")) <> $00

   display "!" & mot & "!"  

endloop

 

La fonction affiche les mots suivants :  

!a!
!=!
!b!
!T!

 

Exemple 2 : séparateurs non rendus

1 position L

1 chaine   S

1 mot      S

position = 1

chaine =  "a,,,b"

loop (mot := Split(chaine,position,"",,",")) <> $00

   display "!" & mot & "!"

endloop

 

La fonction affiche les mots suivants :  

!a!
!!
!!
!b!

La virgule n'est pas rendue, mais Split retourne deux mots vides pour les trois virgules qui se suivent.

 

Exemple 3 : mots entre quotes

1 position L

1 chaine   S

1 mot      S

chaine =  "'a''b'"

loop (mot := Split(chaine,position," ",quotes=0)) <> $00

   display "!" & mot & "!"

endloop

 

La fonction affiche : !'a''b'!

Les mots entre quotes ne sont pas séparés.

 

Si Quotes=TRUE la fonction affiche les mots suivants :

!'a'!
!'b'!

Les mots entre quotes ont été séparés.

 

Exemple 4 : Séparateurs doubles

 

1 position L

1 chaine   S

1 mot      S

position = 1

separateurs = ":*.()&=+<>-/*, "

sepdoubles  = ">= <= .. += &= && := ++ --"

 

chaine = 'if (a:=fonction("a",10++))+20 = 10'

loop (mot := Split(chaine,position,separateurs,sepdoubles)) <> $00

   display "!" & mot & "!"

endloop

 

On affiche :

!if!

!(!

!a!

!:=!

!fonction!

!(!

!"a"!

!,!

!10!

!++!

!)!

!)!

!+!

!20!

!=!

!10!
