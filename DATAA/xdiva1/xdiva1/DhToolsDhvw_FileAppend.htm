DhToolsDhvw_FileAppend  Thème

Ajoute un fichier .dhvw à la suite du fichier .dhvw de base.

 

int DhToolsDhvw_FileAppend (fichier)

 

Paramètre

fichier

Nom complet Windows du fichier .dhvw à ajouter à la fin du fichier de base.

 

Retour :

0  - si pas d'erreur

1  - si erreur

 

Description :

Cette fonction ajoute le fichier .dhvw mentionné en paramètre au fichier de base chargé au départ par la fonction DhToolsDhvw_FileOpen.

A la fin des ajouts, refermez le fichier de base par la fonction DhToolsDhvw_FileClose.

 

Exemple : Voir la rubrique Exemple de fusion de fichiers dhvw.
