HFileVersion

 

La déclarative HFileVersion permet d’effectuer un contrôle de la version d’une base pour les programmes qui ne connaissent pas a priori le fichier qu’ils vont traiter (Zoom et HQL par exemple). Elle est placée dans le module Diva associé au Zoom ou au programme Hql .

La gestion des versions de bases est détaillée au chapitre Version des fichiers .

 

HFileVersion Dico Base

Dico

Nom du dictionnaire de données.

Base

Nom de la base dans le dictionnaire.

 

Exemple

HFileVersion Odfdd.dhsd Odf

 

Remarques

  • Pour les programmes ordinaires, le contrôle de version est effectué automatiquement à l'ouverture du fichier déclaré par l'instruction Hfile.

  • Les programmes Zoom et HQL ne connaissent pas a priori le fichier qu’ils vont traiter. Ils font donc appel au module de traitement que vous avez développé pour connaître la version de la base fournie par le dictionnaire et effectuent le contrôle de la version.

  • Si HFileVersion est présente dans le module de traitement, le programme (Zoom ou Hql) contrôle la cohérence de version avec le fichier.

  • Attention, si l'option « Toujours contrôler la version » est active au niveau du fichier, et que l'instruction HfileVersion est absente du module, le programme est interrompu avec une erreur fatale.
