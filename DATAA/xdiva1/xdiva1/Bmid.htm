Bmid  Famille 

 

La fonction Bmid permet d'extraire un caractère d'une chaîne de caractère et de transformer le type de ce caractère en binaire.
Elle peut se trouver à gauche dans une affectation.


Bin Bmid (variable , position)


Paramètres

Variable

Le type de la variable est quelconque.

Position

Valeur numérique indiquant la position de début (à partir de 1) du caractère à extraire.


Retour

La fonction renvoie le caractère pointé par Position. Le type de retour est toujours binaire.


Exemple


1 arti 15

Bmid(arti,15) = $00 

; positionne la valeur binaire $00 dans le dernier caractère

; de arti.
