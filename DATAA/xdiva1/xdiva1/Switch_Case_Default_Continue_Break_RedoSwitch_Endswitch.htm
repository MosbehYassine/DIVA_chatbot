Endswitch

 

L'instruction Switch Case est une généralisation de l'instruction de sélection simple If. Dans cette structure, l'expression qui suit le mot réservé Switch est appelée sélecteur.

A l'exécution, la valeur du sélecteur doit correspondre à l'une des sélections possibles. Les instructions associées sont alors exécutées, après quoi le contrôle est donné à l'instruction suivant la fin de la structure (sauf si une instruction Continue a été rencontrée). Si le sélecteur ne correspond à aucune des sélections, les instructions suivant le mot réservé Default sont exécutées. Si le mot réservé Default est absent, l'exécution du programme se poursuit après le mot réservé Endswitch qui est obligatoire.

Continue provoque un branchement sur l'instruction qui suit le Case suivant (voir exemple).

Break provoque la sortie de la structure Switch. L'exécution du programme se continue après Endswitch.

RedoSwitch provoque un branchement à l'instruction Switch. Expression est à nouveau évaluée.
 

Attention : la valeur du sélecteur est empilée. Il ne faut jamais sortir de la structure par un GOTO ni par un EXIT.

 

L'expression de sélection peut prendre plusieurs formes :

Sélection par une constante :

C'est le cas le plus utilisé. Le mot réservé Case est suivi d'une constante, et le sélecteur est comparé à cette valeur.

Exemple :

Switch etat

Case "m"

   display 'marie'

Case "c"

   display 'célibataire"

Case "d"

   display 'divorce'

Case "v"

   display 'veuf'

Default

   display 'etat indéterminé'

Endswitch

 

Sélection par une variable

Il est possible de remplacer la constante dans l'expression de sélection par une variable ou une expression qui n'utilise aucun des opérateurs de test. Cette écriture est similaire au cas précédent.

Exemple :
 

Switch i+j
Case pi*r*r

   …

Case root(p)

   …

Endswitch

  

Sélection par une expression de test

Si l'expression de test contient au moins un opérateur de test, l'expression est évaluée telle quelle sans tenir compte de la valeur du sélecteur.

Il est toujours possible de faire référence à la valeur du sélecteur en utilisant la variable prédéfinie VSW. Cette variable représente toujours la valeur du sélecteur dans la structure Switch Case en cours.

Exemple 1 : Cet exemple illustre la possibilité d'utiliser des opérateurs de test en utilisant la valeur du sélecteur.

Switch dep

Case 57

   display 'lorraine' 

Case 54

   display 'lorraine' 

Case vsw in (67,68)

   display 'alsace' 

Case vsw in (75,91..95,78)

   display 'île de France' 

Endswitch

 Exemple 2 : Cet exemple illustre la possibilité d'utiliser le Case sans même faire référence à la valeur du sélecteur.

xmeinput ... ; saisie masque

switch harmony.arret ; point d'arrêt

case Harmony.Key = K_ESCAPE ; abandon ?

   fini = 1 

case 2                      ; appel de zoom

   ZoomSql (...)

...                         ; etc.

endswitch

Exemple 3 : Cet exemple illustre l'utilisation de Continue. Le programme effectue un traitement en fonction d'un numéro de département. Pour le département 75, il doit effectuer un traitement particulier pour la ville de Paris mais également effectuer le traitement standard de la région parisienne.

 

switch dep

case dep in (67..68)

   Traitement("Alsace") 

case 75

   Traitement("Ville de Paris")  

   continue 

case dep in (93,94,78)

   Traitement("Région parisienne")  

endswitch
