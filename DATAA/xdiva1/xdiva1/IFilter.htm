IFilter  Famille Thème

 

La fonction Ifilter permet de positionner un filtre de sélection sur un fichier.

Ce filtre permet de ne lire que les enregistrements désirés tout en améliorant les temps de réponse. Dans le cas d’un fichier situé sur un serveur Xlan, la sélection est faite sur le serveur ce qui diminue le trafic sur le réseau. Dans le cas d’un serveur SQL, le serveur SQL filtre lui-même les enregistrements, et les temps de réponse sont considérablement améliorés.

Une fois le filtre positionné, les lectures par Iread et Ipread ne délivrent que des enregistrements qui remplissent la condition exprimée par le filtre. Seules les fonctions de lecture séquetielle sont concernées par le filtre. Les fonctions de recherche (iseek) ne sont pas affectées.

 

Int Ifilter (Tdf, Filtre, NomIndex, [ Cle ] , [ Abort])

Tdf

Table de définition de fichier du fichier préalablement ouvert.

Filtre

Texte exprimant la condition que les enregistrements délivrés doivent remplir.

Si le texte est à espaces, le filtre est retiré pour la clé spécifiée.

La syntaxe du filtre est celle de la "search condition" du langage SQL.

Search_condition désigne une expression logique avec des opérateurs NOT, AND et OR avec des parenthèses.

Les éléments de base d'une expression logique sont les suivants :

  • expression < | > | <= | >= | = | <> expression

  • expression [NOT] BETWEEN expression AND expression

  • expression [NOT] IN (valeur [,...])

  • expression [NOT] LIKE masque
    masque     est une chaîne de caractères, où _ désigne un caractère quelconque et % une suite quelconque de caractères ( même vide ).

NomIndex

Nom de l'index auquel le filtre est associé (il est donc possible de placer un filtre par clé du fichier).

Clé

Ce paramètre permet de spécifier la clé de départ pour la prochaine lecture.

Si Clé est omis, c’est la valeur de la clé courante de la Tdf qui est utilisée.

Abort

Booléen (True par défaut) indiquant si le programme doit être interrompu en cas d’erreur.

 

 

Retour

0

Pas d’erreur

Autre

Code d’erreur système. Voir ErrorFatal

Si le texte du filtre est à espaces (pour retirer le filtre), la fonction retourne le nombre d’accès physiques effectués depuis le positionnement du filtre. Il ne s’agit donc pas d’un code d’erreur.

 

Remarques

  • Le dictionnaire doit être en ligne (et à jour) sur le serveur au moment de l’exécution du filtre.

  • Le fichier doit contenir le nom du dictionnaire et le nom de la base dans ce dernier (xtools.dhop, Modifier les caractéristiques).

  • Les index de type multi-tables et avec identifiant ne permettent pas l'utilisation de la fonction Ifilter.

 

Complément sur la syntaxe du filtre

 

1) Les fonctions.

 

La syntaxe du filtre permet l'utilisation des fonctions scalaires suivantes :

 

Fonction   

Commentaire    

Exemple

Lower (chaine)

Conversion d'une chaine en minuscule

lower(Nom)

Upper (chaine)

Conversion d'une chaine en majuscule 

upper(Nom)

Day (date)

 Jour d'une date D8

day(Ecrdt)

Month (date)

 Mois d'une date D8 

 month(Ecrdt)

Year (date) 

 Année d'une date D8  

 year(Ecrdt)

Letf (chaine,lg)

Sous-chaine gauche de chaine

 left(Nom,10)

Right (chaine,lg) 

 Sous-chaine droite de chaine 

 right(Nom,10)

Substring (chaine,pos,lg)

 Sous-chaine de chaine

substring(Nom,2,3)

 

Les fonctions peuvent être imbriquées. Ex : lower(left(Nom,10)) = 'jules'

 

2) Tableaux.

 

Pour l'utilisation d'un champ d'un tableau il faut utiliser la syntaxe Tab_iiii pour désigner l'élément Tab(i) où iiii est l'indice sur 4 positions.

 

Exemple : Tab(1) devient Tab_0001

  Tab(3,4) devient Tab_00030004

 

3) Dates

 

Pour tester la valeur espace d'une date, il faut utiliser les opérateurs is null ou is not null.

 

Exemples  

  hfilter(tdf,"is Ecrdt null")

  hfilter(tdf,"is Echdt not null")

 

Exemple

 Lecture des articles dont la référence est comprise en R3 et R6.

  

hfile "odfdd.dhsd" odfic tdf

1 art 60

main

; positionnement du filtre 

Ifilter(tdf,"Reference Between 'R3' and 'R6'","PARREFERENCE")

 loop iread(tdf,art) = 0

   display art

 endloop

; retrait du filtre 

 ifilter(tdf," ",'B')
