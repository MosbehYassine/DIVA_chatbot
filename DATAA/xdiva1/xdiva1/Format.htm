Format  Famille 

 

La fonction Format permet une mise en forme évoluée des données numériques.

 

Char Format (format , variable)

 

Paramètres

Format

Format à appliquer à variable.

Le format est une chaîne de caractère qui se décompose en :

  • un texte libre facultatif qui précédera le nombre formaté ;

  • suivi du caractère "<" , .

  • suivi d'une chaîne de caractères facultative qui précédera immédiatement le premier caractère non blanc du nombre formaté ;

  • suivie d'une commande de mise en forme ;

  • suivie du caractère ">" ;

  • suivi d'un texte libre facultatif qui suivra le nombre formaté.

La commande de mise en forme se compose d'une chaîne où chaque élément est :

       - Soit un code représentant l'un des chiffres du nombre, le signe ou le séparateur décimal.

       - Soit un caractère qui sera reproduit tel quel, à la position qu'il occupe dans le format.

code

action

0

Chiffre ou signe ; les 0 non significatifs sont remplacés par des espaces.

9

Chiffre ou signe ; les 0 non significatifs sont conservés.

*

Chiffre ou signe ; les 0 non significatifs sont remplacés par des *

 

 

+

Signe si négatif ou chiffre ou espace

-

Signe ou chiffre ou espace

 

 

V

Virgule décimale

v

Point décimal

 

 

Autre

Tout autre caractère est reproduit tel quel
 
 

Variable

Valeur numérique à mettre en forme.

Retour

La fonction renvoie la chaîne de caractères mise en forme.

 

Remarques

Si le code "+" ou "-" apparaît dans le format à une certaine position, le signe sera placé exactement à cette position.

Si le code "+" ou "-" apparaît plusieurs fois dans le format, le signe sera placé à la position du dernier rencontré ne correspondant pas à un chiffre significatif.

Le code "+" ou "-" peut être positionné derrière le nombre formaté si celui-ci comporte une virgule ou un point décimal.

Si le format ne comporte ni "9", ni "*", ni "-", le résultat de la mise en forme d'un nombre nul sera une zone entièrement blanche (mis à part les deux textes).

Si le format est entre parenthèses et que le nombre est négatif, le résultat est la valeur absolue du nombre entre parenthèses.
