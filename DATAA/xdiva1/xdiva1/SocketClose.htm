SocketClose  Famille   Thème

La fonction SocketClose permet de libérer un socket. Si une connexion était en cours, celle-ci est fermée.

Bool = SocketClose ( socket )

 

Paramètres

Socket

Socket obtenu par la fonction SocketNew .

 

Retour

TRUE

Pas d’erreur

FALSE

Erreur. Voir SocketLastError
