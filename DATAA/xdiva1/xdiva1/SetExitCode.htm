SetExitCode   Famille Thème

 

SetExitCode permet de positionner le code de retour du processus Xrtdiva.

Ce code peut être testé dans les fichiers batch (.bat) pour savoir si le programme s'est correctement déroulé. La variable ERRORLEVEL contient le code positionné par SetExitCode. Si le programme s'est terminé normalement et que la fonction SetExitCode n'a pas été appelée, ERRORLEVEL vaut zéro.

 

Int SetExitCode ( code )

Paramètres

Code

Valeur qui sera retournée lorsque le processus xrtdiva se termine. Xrtdiva ajoute automatiquement la valeur 1000000 au code passé en paramètre. Cela permet de distinguer les codes positionnés par SetExitCode des codes systèmes.

 

Retour

La fonction renvoie l'ancienne valeur si la fonction SetExitCode a déjà été appelée.

 

Remarques

Si le programme diva est lancé par Xwpf, ce code est transmis à Xwpf qui le positionne de son coté. Cela signifie que la variable ERRORLEVEL sera positionnée par la valeur de SetExitCode dans tous les cas.

Si un programme ne se termine pas normalement, ExitCode prend une des valeurs suivantes :

2

Erreur interne Xrtdiva

3

Erreur interne Xrtdiva

4

Exception dans Xrtdiva (pointeur null par exemple)

5

Erreur interne Xrtdiva

6

Erreur interne Xrtdiva

7

Erreur de connexion (xwpf)

8

Exception dans Xwpf

9

La connexion est tombée

<=1000000

Erreur système Harmony (20 = fichier absent par exemple)

>1000000

Code de retour positionné par le programme.
