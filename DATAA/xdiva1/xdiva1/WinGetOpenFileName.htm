WinGetOpenFileName  Famille Thème

 

La fonction WinGetOpenFileName ouvre la boîte de dialogue de sélection des fichiers de Windows, permettant à l'utilisateur de choisir un fichier à ouvrir.

Voir WinShBrowseForFolder qui permet de sélectionner un répertoire.

Voir également FileBox qui permet d'appeler la boîte de dialogue d'Harmony.

 

Long WinGetOpenFileName( StructureOpenFile , Résultat)

 

Paramètres

StructureOpenFile

Donnée de 700 caractères contenant les informations utilisées pour ouvrir la boîte de dialogue. En retour, cette structure contient des renseignements sur le (ou les) fichier sélectionné.

Résultat

En entrée, cette donnée contient le nom du fichier à proposer. S'il n'y a pas de nom à proposer, Résultat doit être initialisé à espaces

Cette donnée contient en retour le nom du fichier sélectionné.
En cas de sélection multiple, cette donnée contient tout d'abord le chemin du répertoire, un caractère $00, puis tous les noms de fichiers sélectionnés. Les noms sont séparés par le caractère $00 et la liste se termine par deux caractères $00.

Retour

TRUE

Indique que l'utilisateur a sélectionné un fichier.

FALSE

Indique que l'utilisateur n'a pas sélectionné de fichier (sortie par Abandon) ou que la donnée de réception est trop petite pour contenir le résultat.

 

Remarque

En sortie de la boîte de dialogue, le répertoire courant est restauré à sa valeur d'avant l'appel.

 

Cas particulier du client léger Web

La fonction WinGetOpenFileName est utilisable, si elle est suivie d'un appel à la fonction LCWinUpload.

Remarque : Par contre, les fonctions WinGetSaveFileName et WinShBrowseForFolder ne sont pas utilisables en client léger Web.
 

 

Exemple

Ce programme ouvre la boîte de dialogue de sélection des fichiers avec les paramètres suivants :

  • La sélection multiple est autorisée (OFN_ALLOWMULTISELECT + OFN_EXPLORER).

  • L'utilisateur n'a pas le droit de taper un nom de fichier qui n'existe pas (OFN_FILEMUSTEXIST).

  • Quatre filtres sont possibles :
    - Masques (we*,wi*)
    - Includes (z*)
    - Sources (s*)
    - Tous (*.*)
    Le filtre par défaut est le troisième.
    Filtre = "Masques|we*;wi*|includes|z*|sources diva|s*|*.*|*.*" IndexFiltre = 3

  • Le répertoire initial est d:\Divalto\sys et le fichier proposé par défaut est d:\Divalto\sys\stest.
    Fichiers = "d:\Divalto\sys\stest"
    RepertoireInitial = "d:\Divalto\sys"

  • Le titre de la boîte de dialogue est "Ouverture de fichier".
    Titre = "Ouverture de fichier"

En retour, si l'utilisateur a sélectionné un seul fichier le programme affiche le fichier sélectionné ; si l'utilisateur a sélectionné plusieurs fichiers, le programme affiche le répertoire contenant les fichiers sélectionnés puis le nom de tous les fichiers sélectionnés.

 

1 Bufopen 700 ; zone paramètres

2 Flags L 

2 Filtre 256 

2 IndexFiltre X 

2 IndexNom X 

2 IndexExtension X 

2 RepertoireInitial 256 

2 Titre 80 

2 ExtensionDefaut 4 

 

1 Fichiers 32000 ; zone de réception des fichiers

; sélectionnés 

1 pos L ; données de travail

1 oldpos L

 

; garnissage des paramètres 

Bufopen = " "

Filtre = "Masques|we*;wi*|includes|z*|sources diva|s*|*.*|*.*"

IndexFiltre = 3

Fichiers = "d:\Divalto\sys\stest"

RepertoireInitial = "d:\Divalto\sys"

Titre = "Ouverture de fichier"

Flags = OFN_ALLOWMULTISELECT + OFN_EXPLORER + OFN_FILEMUSTEXIST 

ExtensionDefaut = " "

 

; appel de la boîte de dialogue

if WinGetOpenFileName(Bufopen, Fichiers) = FALSE

   ProgramExit 

endif

 

; Affichage du résultat

; Si le premier nom est suivi de deux caractères $00,

; cela indique qu'il n'y a qu'un seul fichier de sélectionné

 

pos = string($00 , Fichiers , 1)

if mid(Fichiers, pos + 1,1) = $00

   display "Un seul fichier " & left(Fichiers, pos) 

else

   display "Sélection multiple " 

   display "Répertoire " & left(Fichiers, pos-1) 

endif

 

; balayage et affichage de tous les noms de fichiers 

do

   oldpos = pos + 1 

   pos = string($00,Fichiers, ++pos) 

while pos <> 0 and pos <> oldpos

   display mid(Fichiers, oldpos, pos - oldpos) 

wend
