Display  Famille 

 

Display permet d'afficher du texte en mode « Caractères ».

 

Attention :

Il n'est pas possible d'utiliser l'instruction Display pour afficher des informations "côté client léger" (il faut passer par l'affichage d'un masque d'écran).

 

 

Display expression [sauts]

Paramètres

Expression

Chaîne de caractères à afficher.

Sauts

Nombre de sauts de ligne à effectuer après l'affichage. Si ce nombre est omis, la valeur prise par défaut est 1, c'est-à-dire que le curseur se positionne sur la première colonne de la ligne suivante.
Si sauts vaut 0, le curseur n'est pas déplacé après l'affichage, et l'affichage suivant commencera donc sur la même ligne.
Si sauts vaut 0 la chaîne à afficher est affichée avec les espaces de fin, sinon les espaces de fin ne sont pas affichés. Donc, pour effacer une portion de ligne il faut que n soit à 0.

display est souvent utilisée avec les crochets de concaténation [] qui permettent également de positionner le curseur.

 

Les fonctions d'affichage sont utilisables au travers des champs suivants de l'enregistrement System :

fonction

nom

Effacement d'écran et curseur en 1,1

clear

Sonnette

bell

Inverse vidéo début

rever

Inverse vidéo fin

eor

Clignotement début

blink

Clignotement fin

eob

Sous brillance début

half

Sous brillance fin

eoh

Transparence début (impression)

sbyp

Transparence fin

eosb

Couleur

color

Positionnement. Ligne 25 début

cpl25

Posit. ligne 25 fin

eop25
 

Les attributs restent valides jusqu'à ce que la fonction de fin soit envoyée.

 

Positionnement de curseur :

Le positionnement de curseur doit toujours se faire à l'intérieur des crochets de concaténation.

Display [ = ligne colonne ]

 

Exemples :

display 'bonjour'

display [ 'La fiche ' code "n'existe pas" ] 0

display [ = 12 40 nom ] ; positionnement curseur

display [ System.clear System.rever *10 "DIVALTO" \ * 20 System.Eor ]
