DDInterface : Champs des liens

La zone champ des liens indique comment garnir les valeurs de l’index de la table destination.

Le remplissage est toujours du type :

Variable_de_l’index_de_la_table_destination = valeur

 

Valeur peut être soit :

- une constante numérique ou héxadecimale (par ex. 3,5 ou $01)

- une constante alpha (par ex. "001")

- une variable de la table d'origine (ex. DOS)

- l'identifiant $ident

 

De plus chacun des deux membres de l’affectation, Variable_de_l’index_de_la_table_destination et valeur, peut être une variable indicée.

 

Champ

Nom du champ de l’index utilisé par le lien.

ChampSQL

Nom du champ au format sql.
Sii le champ est une donnée indicée, en SQL l'indice se retrouve dans le nom du champ, car il n’y a pas de tableaux en SQL.

Exemple :
un index constitué des champs
DOS, REPRRESENTANT(1) et MT(3,2) deviendra en sql
DOS, REPRRESENTANT0001, MT00030002

TypeRemplissage

= 0 : la valeur est une constante alpha

On peut écrire variable_de_l’index = Valeur

Si Valeur est alphanumérique, la zone Valeur contient la valeur sans les quotes.

 

= 1 : la valeur est une constante numérique

On peut écrire variable_de_l’index = Valeur

Si Valeur est numérique, la zone Valeur contient la valeur décimale.

Si le remplissage était de type hexadécimal il est convertit en décimal. Par exemple $41 est retourné sous la forme déciamale, soit 65.

Si la zone OrgHexa est différente de espaces, cela indique que la valeur est hexadécimale.

 

= 2 : la valeur est un champ de la table d'origine

Valeur : contient le nom du champ

ValeurSQL : contient le nom du champ au format Sql 
Indices1,2,3,4 : indices si la valeur est une donnée indicée.

 

Remarque :

Dans la composition des index, il est possible de mettre le mot réservé $ident pour spécifier qu’un champ de l’index contient l’identifiant de la table (C pour client, F pour fournisseur etc ?).
La lecture du dictionnaire essaie toujours de remplacer le mot $ident par la valeur de l’indentifiant de la table de destination.
Cette résolution n’est pas effectuée dans le cas de la lecture d’un lien sortant vers une table qui appartient à un autre dictionnaire.
Pour être complet, le programme doit donc traiter le cas où Valeur = "$ident" ; il faut alors rechercher dans le dictionnaire de destination du lien les caractéristiques de la table.

Valeur

Valeur à affecter dans Champ. Voir TypeRemplissage ci-dessus.

ValeurSQL

Champ à affecter au format SQL.

OrgHexa

Si OrgHexa est différent de espace, cela indique que Valeur contient la représentation décimale d’une constante hexadécimale.

Indice1
Indice2
Indice3
Indice4

Indices du champ de la table d’origine (type remplissage = 2).

 

IndiceIndex1
IndiceIndex2
IndiceIndex3
IndiceIndex4

Indices de la zone Champ (0 précise qu’il n’y a pas d’indices).

Par exemple, un index peut être constitué par les champs :
DOS,REPRRESENTANT(1),MT(3,2)

 

 
 

Exemple

 

1 LienData_Champ                32

1 LienData_ChampSQL             32

1 LienData_TypeRemplissage      2,0

1 LienData_OrgHexa              32

1 LienData_Valeur               256

1 LienData_ValeurSQL            256

1 LienData_IndiceChamp          3,0*4

1 LienData_IndiceChampIndex     3,0*4

 

 LienData_Champ            = HmpSeek(buffer,"Champ")

 LienData_ChampSQL         = HmpSeek(buffer,"ChampSQL")

 LienData_TypeRemplissage  = HmpSeek(buffer,"TypeRemplissage")

 LienData_Valeur           = HmpSeek(buffer,"Valeur")

 LienData_ValeurSQL        = HmpSeek(buffer,"ValeurSQL")

 LienData_OrgHexa          = HmpSeek(buffer,"OrgHexa")

 LienData_IndiceChamp(1)   = HmpSeek(buffer,"Indice1")

 LienData_IndiceChamp(2)   = HmpSeek(buffer,"Indice2")

 LienData_IndiceChamp(3)   = HmpSeek(buffer,"Indice3")

 LienData_IndiceChamp(4)   = HmpSeek(buffer,"Indice4")

 LienData_IndiceChampIndex(1) = HmpSeek(buffer,"IndiceIndex1")

 LienData_IndiceChampIndex(2) = HmpSeek(buffer,"IndiceIndex2")

 LienData_IndiceChampIndex(3) = HmpSeek(buffer,"IndiceIndex3")

 LienData_IndiceChampIndex(4) = HmpSeek(buffer,"IndiceIndex4")

 

 

 display "Nom du champ dans la table destination : " & left(LienData_Champ)

 display "Nom du champ SQL dans la table destination : " & left(LienData_ChampSQL)  

 

 switch LienData_TypeRemplissage

 case 0

    display "remplissage alpha : " & left(LienData_Valeur)

 case 1

    display "remplissage numerique : " & left(LienData_Valeur)

    if LienData_OrgHexa <> " "

       display "remplissage à l'origine en hexa : " & left(LienData_OrgHexa)

    endif

case 2

   display "remplissage de type donnée "

   display "Nom du champ dans la table origine : " & left(LienData_Valeur)

   display "Nom du champ SQL dans la table origine : " & left(LienData_ValeurSQL)
