Pseudo instructions /Value /If /Else /Endif

Ces pseudo-instructions permettent d'effectuer une compilation conditionnelle. Il est parfois utile d'avoir plusieurs variantes d'une même séquence d'instructions et donc de n'en compiler qu'une seule.

Par exemple, il est possible de laisser des instructions pour la phase de mise au point d'un programme, puis de recompiler le programme sans avoir à rechercher toutes les lignes à supprimer.

  

Value : Entrée d'une valeur.

/Value paramètre [ T ou F ]

Si le nom du paramètre n'est pas suivie de T ou F, le compilateur demande d'entrer la valeur de ce paramètre.
Il y a deux valeurs possibles :
 T : pour vrai (true)
 F : pour faux (false)

Il est possible de figer la réponse dans le source pour ne pas avoir à y répondre à chaque compilation. Dans ce cas, la variable doit être suivie de la réponse (T ou F).

Exemple : /Value Debug T

  

/IF /ELSE /ENDIF : Compilation conditionnelle.

/IF paramètre [ and | or paramètre… ]

instructions

[ /ELSE

instructions

]

/ENDIF

 

Les paramètres de l'instruction IF doivent avoir été initialisé par la pseudo instruction Value. L'instruction IF peut être suivie d'une expression booléenne contenant les opérateurs booléens Not And et Or.

 

Exemple :

/Value V1
/Value V2
/If V1
Display "V1 est vrai"
/Else
/If V2
Display "V1 est faux et V2 est vrai"
/Else
Display "V1 et V2 sont faux"
/Endif
/Endif
