ConvertHtmlRtfLastError Famille 

La fonction ConvertHtmlRtfLastError permet de récupérer le code et le libelle de la dernière erreur dans une fonction Convertxxxx

 

int ConvertHtmlRtfLastError ( Exception )

  

Paramètres

 

Exception

Variable qui reçoit le texte décrivant l'erreur.

 

Retour

La fonction retourne le code d'erreur de la dernière fonction appelée.
