FopenData  Famille Thème

 

La fonction FopenData permet d'ouvrir séparément le fichier des données d'un fichier séquentiel-indexé déjà ouvert.

Son utilisation est exeptionnelle. Elle est utilisée par exemple lors de la réorganisation des fichiers.

 

Ptr = FopenData (Tdf1 , Tdf2 , code_réservation)

 
Paramètres

Tdf1

Tdf d'un fichier séquentiel-indexé préalablement ouvert.

Tdf2

Tdf du fichier des données (en sortie).

Code_réservation

Mode de partage du fichier.

 

Retour

0

Pas d'erreur.

Autres

Code d'erreur système.
 
 

Exemple

;Balayage des enregistrements du fichier des données.

record * htdf tdf1

record * htdf tdf2

1 art 50

1 st X

main

tdf1.name = "Fprinters.dhfi" 

hopen(tdf1,"R") 

st = FOpenData(tdf1,tdf2,"P") 

loop hread(tdf2,art) = 0 

   display art 

endloop
