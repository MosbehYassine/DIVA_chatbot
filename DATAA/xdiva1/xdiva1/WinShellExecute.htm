WinShellExecute  Famille Thème

 

Cette fonction permet d'exécuter le programme associé à un fichier. Par exemple, l'exécution du fichier "mondocument.doc", lance le programme Word et charge le fichier.

 

Long WinShellExecute (Opération, fichier, [paramètres], [répertoire], mode_aff)

 

Paramètres

Opération

Opération à effectuer.

"open"

La function ouvre le fichier. Le fichier peut être un exécutable ou un document ou un répertoire.

"print"

La fonction imprime le fichier. Le fichier doit être un document et non un exécutable.

"explore"

La fonction lance l'explorateur de Windows sur le répertoire précisé dans Fichier.

Fichier

Nom de fichier ou nom de programme ou nom de répertoire.

Paramètres

Si le paramètre Fichier est un exécutable, ces paramètres sont passés à l'application. Valeur par défaut = espace

Répertoire

Permet de positionner le répertoire par défaut. Valeur par défaut = espace.

Mode_aff

Mode d'affichage du programme. Valeur par défaut = SHOW_ NORMAL (seul mode possible en client léger Html).
Les valeurs possibles sont :

SW_HIDE

SW_SHOWNORMAL

SW_NORMAL

SW_SHOWMINIMIZED

SW_SHOWMAXIMIZED

SW_MAXIMIZE SW_SHOWNOACTIVATE

SW_SHOW

SW_MINIMIZE

SW_SHOWMINNOACTIVE

SW_SHOWNA

SW_RESTORE

SW_SHOWDEFAULT

SW_MAX

 

Retour 

0

Pas d'erreur.

2

Fichier non trouvé

3

Chemin non trouvé

5

Accès au fichier interdit

8

Pas assez de mémoire

11

Format de l'exécutable erroné.

26

Conflit de partage de la ressource (sharing violation)

27

Association incomplète

28

Erreur de time-out dans la transaction DDE

29

Erreur lors de la transaction DDE.

30

La transaction DDE ne peut se terminer car d'autres transactions sont en cours.

31

Pas d'association avec le fichier spécifié.

32

Dll non trouvée
 

Remarque

La fonction GetSystemFileName permet de trouver le nom Windows d'un fichier ouvert par Harmony.

Exemple

; lancement de l'explorateur dans le répertoire "mes documents"

st = WinShellExecute("explore","e:/mes documents")

; lancement de Word et chargement du fichier agenda.doc 

st = WinShellExecute("open","e:/mes documents/agenda.doc")
