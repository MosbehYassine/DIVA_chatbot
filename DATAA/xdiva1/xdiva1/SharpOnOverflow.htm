SharpOnOverflow

 
Si cette instruction est présente dans un Programme, en cas de débordement de capacité dans un calcul ou une affectation, la donnée réceptrice est remplie avec le caractère #. Le dépassement de capacité se propage lors des calculs, c'est à dire que si une donnée numérique contenant des # est utilisée dans un calcul, la donnée réceptrice sera elle aussi remplie de #.

Cette instruction n'a pas d'incidence si elle est placée dans un module.


Exemple

1 numero 2,0 = 99

main

SharpOnOverflow

numero++

display numero ; --> ##
