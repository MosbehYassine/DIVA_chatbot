Count  Famille 

 

La fonction Count permet de chercher le nombre d'occurrences d'une chaîne de caractères dans une autre.


Ptr = Count(chaîne_à_chercher , chaîne_origine)


Paramètres

Chaîne_à_chercher

Chaîne de caractères à rechercher dans chaîne_origine. La fonction ne tient pas compte des espaces se trouvant à la fin de chaîne_à_chercher.

Chaîne_origine

Chaîne dans laquelle s'effectue la recherche.


Retour

La fonction Count renvoie le nombre d'occurrences trouvées.


Exemple

Display Count ( "O" , "BONJOUR") ; affiche 2.
