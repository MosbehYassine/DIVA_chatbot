ZipArchiveGetLastErrorCode Famille Thème

 

La fonction ZipArchiveGetLastErrorCode() permet de récupérer un code d'erreur détaillé de la dernière fonction en échec du module de gestion des archives.

 

Int ZipArchiveGetLastErrorCode()

 

Retour

Le code d'erreur détaillé de la dernière fonction en échec du module de gestion des archives. Il peut avoir une des valeurs suivantes :

  • 0 Pas d'erreur

  • 1 Erreur de lecture ou d'écriture

  • 2 Fichier non existant ou impossible d'ouvrir le fichier

  • 256 Erreur interne au module de gestion des archives ou usage inattendu.

 

Remarques

Cette fonction doit être appelée immédiatement après celle qui a renvoyé un code d'erreur.

Attention, après l'appel de cette fonction, le code d'erreur détaillé, que renverrait un deuxième appel à cette fonction, serait 0.
