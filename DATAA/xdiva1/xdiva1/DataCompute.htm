DataCompute

La fonction DataCompute permet d’évaluer une expression diva contenue dans une chaîne alphanumérique.

Cette expression peut contenir des variables, des constantes, tous les opérateurs du langage et l’appel de certaines fonctions du langage diva. Toute expression pouvant être évaluée par le debuggeur de Xwin peut être évaluée par DataCompute.

L'expression peut utiliser soit les noms standards (comme en Diva), soit les noms odbc (définis dans le dictionnaire).

Attention, pour que DataCompute puisse s’exécuter aussi bien en mode normal qu’en mode debug, il faut impérativement que les enregistrements soient déclarés avec l’option KeepDataNames.

Long DataCompute (expression , résultat ,[ mode ])

 

Paramètres

Expression

Zone alphanumérique contenant l’expression à évaluer.

 

Résultat

Variable qui contiendra le résultat de l’expression.

 

Mode

0

Mode normal. Les noms des données utilisées sont les mêmes qu'en Diva. (Valeur par défaut)

1

Mode Odbc. Les noms des données (enregistrements et champs) sont les noms odbc.

2

Mode mixte. Seuls les noms des champs sont des noms odbc. Les noms des enregistrements sont les mêmes qu'en Diva.

 

 

Retour

0

Pas d'erreur.

Autre

Erreur lors de l’évaluation. Le code retourné correspond au numéro d’erreur du compilateur Diva.
 

Remarques

Les données et enregistrements utilisés dans Expression doivent impérativement être déclarés dans le module courant.

Si une donnée non déclarée dans le module est utilisée, la fonction retourne la valeur 20.

 

Exemples

 

1 result 10,2

1 nom 10
record KeepDataNames h3fdd eimp

 

st = DataCompute("123 + 10 * 2",result)

display result à 143

 

nom = "toto"

st = DataCompute ("10 + length(nom)",result)

display result à 14

 

eimp.znomimp = "STD"

st = DataCompute('eimp.znomimp && "imp"',nom)

display nom à STDimp
