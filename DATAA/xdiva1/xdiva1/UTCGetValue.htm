UTCGetValue Famille Thème

La fonction UTCGetValue permet de récupérer une valeur des paramètres liés au calcul des dates+heures UTC

Il faut préalablement avoir appelé une des fonctions UTC...

 

int UTCGetValue (valeur)

 

Paramètres

Valeur

Paramètre dont on veut récupérer la valeur.

define defzhdateutc_ActiveTimeBias =1

define defzhdateutc_Bias =2

define defzhdateutc_StandardBias =4

define defzhdateutc_StandardBiasMois =5

define defzhdateutc_StandardBiasJour =6

define defzhdateutc_StandardBiasHeure =7

define defzhdateutc_StandardBiasMinutes =8

define defzhdateutc_StandardBiasjoursemaine =9

define defzhdateutc_DaylightBiasJour =11

define defzhdateutc_DaylightBiasHeure =12

define defzhdateutc_DaylightBiasMinutes =13

define defzhdateutc_DaylightBiasjoursemaine =14

define defzhdateutc_StandardBiasSecondes =15

define defzhdateutc_DaylightBiasSecondes  =16

define defzhdateutc_oldTimeZoneanee             =17

define defzhdateutc_test =18

define defzhdateutc_finalbias =19

 

Retour

La fonction retourne le paramètre demandé (ou 0 si le paramètre est inconnu)
