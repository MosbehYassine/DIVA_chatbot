JsonGetValue Famille Thème

 

JsonGetValue permet de lire une valeur dans l'objet JSON.

 

Int JsonGetValue ( Ticket , Expression , &Retour  )

 

Paramètres

Ticket

Ticket préalablement obtenu par JsonOpen. Avant toute recherche de valeur, la fonction JsonParse doit être appelée.

 

Expression

Expression de la valeur recherchée.

L'expression respecte la syntaxe JavaScript (objet.sousObjet.champ)

Si un objet est une collection (tableau, liste) il faut mettre l'indice entre crochets. Les indices commencent à 1.

La fonction JsonGetLength permet de connaître la taille d'une collection.

 

Retour

Variable contenant le résultat.

 

Retour

0

Pas d'erreur

1

Ticket incorrect

2

Erreur. Voir JsonGetError pour le détail.

3

Erreur de syntaxe dans l'expression.

 

 

Exemple

json = "{ 'menu': {" & \

                "'id': 'file',"  & \

                "'value': 'File',"  & \

                "'popup': {"  & \

                "'menuitem': ["  & \

                   "{'value': 'New', 'onclick': 'CreateNewDoc()'},"  & \

                   "{'value': 'Open', 'onclick': 'OpenDoc()'},"  & \

                    "{'value': 'Close', 'onclick': 'CloseDoc()'}"  & \

                 "]"  & \

                "}"  & \

         "}}";

 

ticket = JsonOpen()

st = JsonParse(ticket,json)

.....

st = JsonGetValue(ticket,"menu.id",valeur);                         --> file

...

st = JsonGetValue(ticket,"menu.value",valeur);                      --> File

...

st = JsonGetValue(ticket,"menu.popup.menuitem[1].onclick",valeur);  --> CreateNewDoc
