Donnée de référence

Il est possible d'affecter les caractéristiques d'une variable contenue dans le dictionnaire (ou dans une structure) à une variable de travail.

Cette méthode est utile pour déclarer des variables de travail dépendantes du dictionnaire (ou d'une structure). Si le dictionnaire (ou la structure) vient à être modifié, il n'y a pas besoin de vérifier tous les programmes, il suffit juste de reconstruire le projet.

 

Déclaration avec une donnée de référence contenue dans un dictionnaire

Syntaxe 1 : niveau nom-donnée [position.] >dictionnaire donnée

Syntaxe 2 : niveau nom-donnée [position.] >>dictionnaire donnée

Le signe > est suivi du nom du dictionnaire puis du nom de la donnée de référence.

Si la syntaxe 2 est utilisée, nom-donnée prend également les mêmes caractéristiques tableau (nombre de dimensions etc) que la donnée de référence.

Exemple

Soit dans le dictionnaire la variable Numero définie en 24,10.
Pour déclarer une variable de travail dont les caractéristiques sont identiques, il suffit d'écrire :
1 Numbis >fdmusi.dhsd Numero

 

 

Déclaration avec une donnée de référence contenue dans une structure

Syntaxe 1 : niveau nom-donnée [position.] >[module.]structure donnée

Syntaxe 2 : niveau nom-donnée [position.] >>[module.]structure donnée

Le signe > est suivi du nom de la structure puis du nom de la donnée de référence. Si la structure est dans un module externe, le nom de la structure doit être précédé du nom du module suivi d'un point.

Si la syntaxe 2 est utilisée, nom-donnée prend également les mêmes caractéristiques tableau (nombre de dimensions etc) que la donnée de référence.

Exemple 1

Structure Element

1 Nom  30

1 Prenom 30

1 Liste L

1 Compteur X

EndStructure

 

1 cpt  >Element Compteur  ; la donnée cpt a les mêmes caractéristiques que le champ Compteur.

 

Exemple 2 : Donnée de référence définie dans une structure externe

 

;---------------- Module1.dhsp ----------------------

Public Structure StructurePublique

1 sp1 10

1 sp2 X

EndStructure

 

;---------------- Programme_principal.dhsp ----------

Module module1.dhop

1 cpt  >module1.StructurePublique sp1
