HSiMod  Famille Thème

 

HSiMod permet de modifier les paramètres d'un fichier séquentiel indexé (nom du fichier des données et composition des clés). Elle s'utilise par exemple pour définir de nouvelles clés sur un fichier de travail.

La fonction HSiMod est en général précédée d'un appel à HSiRead pour lire les paramètres.

 

Ptr = HSiMod (nomcles , cles, status, nomdata, abort) 
 

Paramètres

Nomcles

Nom complet du fichier des clés.

Clés

Nouvelle description des clés. Ce paramètre doit être une instance de l'enregistrement Cles du dictionnaire ddsys.dhsd.

Status

Donnée de type X qui reçoit le code d'erreur système.

NomData

Nouveau nom du fichier des données. Ce paramètre doit obligatoirement être renseigné.

Abort

Booléen (TRUE par défaut) indiquant si la fonction doit arrêter le programme en cas d'erreur, ou rendre la main avec un code d'erreur.

En cas d'arrêt du programme, la fenêtre standard des erreurs est affichée et l'erreur est journalisée dans le fichier ferror.log.

 

Retour

La fonction renvoie la valeur nulle en cas de succès. Sinon, elle renvoie un code d'erreur principal, et le paramètre Status contient le code d'erreur du système.

Pour la liste des erreurs possibles, voir Erreurs des fonctions HcreateFile, HSicreate

 

L'enregistrement Cles contenant la description des clés est un tableau de 256 cases pour les clés.

LettreCle

Lettre clé.

NomCle

Nom de la clé.

PositionCe

Position du code enregistrement.

ValeurCe

Valeur du code enregistrement.

TestCe

Test à effectuer sur le code enregistrement

 

0 =
1 <>
2 <
3 >
4 <=
5 >=
6 &

égal
différent
inférieur
supérieur
inférieur ou égal
supérieur ou égal
et logique
 

Pour chaque clé, on trouve ensuite un tableau de 16 éléments décrivant les données qui composent la clé :

PosCle

Position d'un fragment de clé.

LgCle

Longueur d'un fragment de clé.

 

 

Remarque

Il est conseillé d'utiliser préalablement la fonction HSiRead pour lire les paramètres. Mais attention, toutes les clés non utilisées doivent être positionnées à 0 binaire. Si vous n'utilisez pas toutes les clés déjà présentes dans le fichier il est donc conseillé de réinitialiser la zone définissant les clés (par Init cles = $00) puis de la reconstituer en totalité.
