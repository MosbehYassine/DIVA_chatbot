CreateDirectory  Famille Thème

 

Cette fonction permet de créer des nouveaux répertoires. Un seul appel a CreateDirectory permet de créer plusieurs niveaux de répertoires.

Par exemple, le répertoire c:/Divalto/sys existe. L'appel de CreateDirectory(c:/Divalto/sys/sys1/sys2) va créer les répertoires sys1 et sys2.


Long = CreateDirectory (Chemin)

 
Paramètres

Chemin

Nom complet du répertoire à créer.

 

Retour

0

Pas d'erreur.

$09

Le répertoire existe déjà.

Autres

Code d'erreur système.


Exemple

1 st X

st = CreateDirectory("/Divalto/sys/sys1/sys2")


Voir
