DictionaryExistKey Famille  Thème

DictionaryExistKey permet de savoir si une clé existe ou non dans un dictionnaire


int DictionaryExistKey (ident, clé)


Paramètres

Ident

Identifiant du dictionnaire

Clé

Clé à rechercher dans le au dictionnaire


Retour

0

La clé n'existe pas

1

La clé existe

-1

Le dictionnaire n’existe pas. Ticket invalide
