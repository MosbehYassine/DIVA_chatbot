SendProgramMessage Famille Thème

 

La fonction SendProgramMessage permet d'envoyer un message à tous les utilisateurs qui sont connectés à un même xlan.

Il s'agit du serveur xlan qui sert de serveur de licences ou alors localhost.

Les messages sont récupérés par l'instruction ReceiveProgramMessage qui doit être exécutée de temps en temps.

 

Bool SendProgramMessage ( message, [programme])

Paramètres

Message

Texte du message à envoyer

Programme

Nom du programme que doit exécuter la tâche pour que le message lui soit envoyé.

La valeur par défaut est ia.dhop

Si ce paramètre est vide, le message est envoyé à toutes les tâches.

 

Retour

0

Pas d'erreur.

autre

Code d'erreur système
