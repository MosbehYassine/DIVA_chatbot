Le partage des enregistrements

Il existe trois modes de partage des enregistrements :

  • le mode "réservé" (R ou toute autre lettre que R P ou F);

  • le mode "partagé" (P);

  • le mode "forcé" (F).

Le mode réservé permet de verrouiller un enregistrement. Une fois l'enregistrement lu en mode réservé, il est impossible de le lire en mode réservé ou partagé.

Si l'enregistrement est réservé avec la lettre "R", il est automatiquement libéré lors de la prochaine opération sur le fichier concerné (fonctions Hrewrite, Hdelete, Hread, ...).

Si l'enregistrement est réservé avec une autre lettre que "R", il reste réservé tant qu'il n'est pas explicitement libéré par une instruction Libr ou Liball, ou par la fermeture du fichier. Il est alors possible de réserver plusieurs enregistrements simultanément dans un même fichier.

Ce mode s'utilise en particulier avant de modifier ou de supprimer un ou plusieurs enregistrements.

  
Le mode partagé autorise plusieurs programmes à lire simultanément le même enregistrement. Ce mode s'utilise pour une simple consultation de l'enregistrement. Si un programme veut modifier un enregistrement déjà lu en mode partagé, il doit tout d'abord le relire en mode réservé pour s'assurer qu'aucun autre programme n'est en train de le modifier.

 

 

Le mode forcé (F) permet de lire un enregistrement, même s'il est déjà réservé par un autre programme. Ce mode doit être utilisé avec précaution. Il ne faut en aucun cas réécrire un enregistrement lu en mode forcé.

Ce mode est utilisé lors de simples lectures du fichier (listes ou calcul de statistiques par exemple).

 

 

Exemples :

a) status = Hread(tdf,article,,"P");lecture en mode partagé.

b) status = Hread(tdf,article,,"R");lecture en mode réservé

    ..........                    ;modif. de "article"

  status = Hrewrite(tdf,article)  ;réécriture+libération

  Lit l'enregistrement en mode réservé et le réécrit après modification de "article". Après la réécriture, l'enregistrement est libéré.

c) status = Hread(tdf,article,,"A")
Lit l'enregistrement en mode réservé. Il ne sera pas libéré implicitement lors du prochain accès au fichier.

d) Libr (tdf,"A")
Libère tous les enregistrements qui ont été réservés par le programme avec le code "A", même si les enregistrements appartiennent à plusieurs fichiers.

e) Liball
Libère tous les enregistrements de tous les fichiers réservés par le programme.
