FmoveFile  Famille Thème

Cette fonction permet de renommer ou de déplacer un fichier.

Utilisez de préférence la fonction HMoveFile

 

Ptr = FmoveFile (ancien , nouveau , numéro_fichier_en_erreur )

 

Paramètres

Ancien

Nom du fichier à renommer.

Nouveau

Nouveau nom du fichier. Ce fichier ne doit pas exister.

Si ce nom n'est pas un nom complet, le chemin du nouveau fichier est le même que le nom de l'ancien fichier.

Numéro_fichier_en_erreur

Variable alpha-numérique qui recoit "1" ou "2" pour indiquer quel fichier a provoqué une erreur (1 = ancien, 2 = nouveau).

 
Retour

0

Pas d'erreur.

9

Le fichier Nouveau existe déjà.

Autres

Code d'erreur système.

Numéro_fichier_en_erreur indique le fichier en erreur

 

Remarques 

  • Le fichier ne peut pas être déplacé d'un serveur à un autre.

  • Le fichier peut être déplacé d'un disque à un autre.

Exemples

1 num 1

1 st X

1 f1 32

1 f2 32

 

f1 = "/Divalto/sys/test"

f2 = "/Divalto/sys/test1"

st = FmoveFile(f1,f2,num)

if st <> 0

   if num = '1' 

      ErrorFatal(st,f1) 

   else 

      ErrorFatal(st,f2) 

   endif 

endif
