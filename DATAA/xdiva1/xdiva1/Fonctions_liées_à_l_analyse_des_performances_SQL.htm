Fonctions liées à l'analyse des performances SQL

Voir la documentation de l'analyseur de performances Sql dans le  Manuel de référence d'Harmony  (XperfSql).

 

AnalyzeSqlStart  ( [ avecStats] , [maxElements])

Démarrer l'analyse de performances.

Paramètres

avecStats

Avec ou sans les statistiques générées par le serveur SQL

Valeur par défaut : 0

maxElements

Non utilisé pour l'instant.

 

AnalyzeSqlStop

Arrêt de l'analyse des performances. Le fichier est généré à ce moment
