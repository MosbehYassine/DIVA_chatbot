Ces instructions permettent de lire et de modifier les paramètres d'un état.

Les paramètres d'un état sont contenues dans une chaîne de caractères au format Hmp.

Ils doivent être positionnés avant l'instruction PrintEnd et sont effacés après l'instruction PrintEnd. Il est possible de les positionner avant l'instruction PrintBegin.

 

XharviewReadParameter ( txt )

Lecture des paramètres courants.

 

XharviewWriteParameter ( txt )

Positionnement des paramètres.

 

XharviewAppendParameter ( txt )

Ajout de paramètres aux paramètres existants.

 

Paramètres

Txt

Chaîne de caractères contenant les paramètres.

 

Description des paramètres

 

Paramètres valides pour tous les états

<name>

Nom de l’édition (255 caractères maximum).

Ce nom est utilisé

  • lors de l’envoi d’un mail ; dans le message, au lieu d’avoir le nom « fichier joint », on aura le nom indiqué ici.

  • lors de la sauvegarde du fichier ; ce nom est proposé par defaut.

Attention, ce nom ne doit pas comporter d'extension et il faut éviter de mettre des caractères accentués, des quotes, des espaces et des caractères interdits dans les noms de fichier tel que / \ : . * ?  < > |.

Exemple :  Txt = "<name>facture_00001_ste_dupond_2007-11-06”
 

<comment>

Commentaire libre (255 caractères maximum).

Il est affiché dans la boite de dialogue d’information de XDivaltoViewer.

Exemple :  Txt = "<comment>facture 00001 du 6/11/2007 ste dupond concernant l’achat du photocopieur x123"
 

Paramètres valides lors d'une impression immédiate

<copy>nnn

Nombre de copies à imprimer.

<frompage>nnn

Première page à imprimer.

<topage>nnn

Dernière page à imprimer.

<sort>n

n = 0 : les copies sont assemblées     n = 1 : les copies ne sont pas assemblées.

Exemple d'un état de trois pages avec le paramètre <copy>2

<sort>0  : p1 p2 p3 p1 p2 p3

<sort>1  : p1 p1 p2 p2 p3 p3
