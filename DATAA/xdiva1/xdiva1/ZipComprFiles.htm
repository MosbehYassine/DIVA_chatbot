ZipComprFiles Famille Thème

Cette fonction fait partie du module dhzip

ZipComprFiles permet de compresser un fichier

 

Int ZipComprFiles (file1, file2, entete)

 

Paramètres

File1

Nom windows du fichier à compresser

 

File2

Nom windows du fichier résultat

 

Entete

Boolen indiquant s'il faut rajouter l'entête de reconnaissance des fichiers Zip (TRUE par défaut)

La présence de cet entête permet au fichier d'être reconnu par n'importe quel utilitaire zip.

 

Retour

0 pas d'erreur
1 erreur
