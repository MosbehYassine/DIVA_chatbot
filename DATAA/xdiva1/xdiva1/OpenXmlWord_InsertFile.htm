OpenXmlWord_InsertFile  Famille  Theme

 

La fonction OpenXmlWord_InsertFile utilise le point d'ancrage précédemment posé par la fonction OpenXmlWord_Replace pour y insérer un fichier.
OpenXmlWord_InsertFile crée elle-même un nouveau point d'ancrage à la suite du fichier inséré. On peut ainsi ajouter successivement plusieurs fichiers derrière le paragraphe contenant la chaîne de référence.

 

Int OpenXmlWord_InsertFile (fichier, extension ,justif, breakdoc)

 

Paramètres

Fichier

Nom complet du fichier, au format Windows.

 

Extension

  • " " :  Le type du fichier est recherché à la fin de son nom (valeur par défaut).

  • Autre : Spécifiez l'extension correspondant au type de contenu du fichier si son extension n'est pas représentative de son contenu.
    Exemple : le fichier est un fichier temporaire, d'extension .tmp, et son contenu est une image au format PNG. Dans ce cas, spécifiez ici l'extension png.

    Les seuls types de fichiers reconnus ici sont :

    • jpg, jpeg ou png pour une image.

    • txt pour un simple texte.

    • rtf pour un fichier de type rtf.

    • docx pour un fichier MS Word.

    • htm ou html pour un fichier "simple" au format html.

    • xml pour un fichier au format xml.

Justif

0 ou 1 : paragraphe cadré à gauche (valeur par défaut).
2 : paragraphe centré.
3 : paragraphe cadré à droite.
4 : paragraphe justifié.

 

BreakDoc

1 : indique qu’il faut faire suivre le paragraphe d'une marque fin de document (0 par défaut).

 

Retour

0

Le fichier n'a pas été inséré.

1

Le fichier a été inséré.
