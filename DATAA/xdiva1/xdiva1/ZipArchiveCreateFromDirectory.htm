ZipArchiveCreateFromDirectory Famille Thème

 

Création d'une archive au format zip et ajout d'un répertoire

 

Bool ZipArchiveCreateFromDirectory( ZipArchivePath, DirectoryToAdd[, ZipPath], [ZipPassword] )

 

Paramètres

ZipArchivePath

Chemin vers le fichier zip à créer

DirectoryToAdd

Chemin vers le répertoire dont le contenu sera ajouté à l'archive

ZipPath

Chemin dans l'archive zip où le répertoire doit être ajouté. Ce paramètre est facultatif. S'il n'est pas spécifié, alors sa valeur sera la chaîne vide et le contenu de DirectoryToAdd sera ajouter à la racine de l'archive.

ZipPassword

Mot de passe pour les fichiers chiffrés dans l'archive zip

 

Retour

La fonction renvoie 1 en cas de succès, 0 sinon. Pour avoir plus d'informations sur l'erreur en cas d'échec, utiliser la fonction ZipArchiveGetLastErrorCode()

 

Remarques

Si le fichier n'existe pas, il est crée. S'il existe, son contenu est écrasé.

Le nom peut contenir le chemin complet vers le fichier, le chemin relatif ou juste le nom du fichier.

 

Exemples

; Création de l'archive testZstd.zip et ajout du contenu du répertoire zstd_x64-windows dans l'archive

 retVal = ZipArchiveCreateFromDirectory("C:/zipArchive/testZstd.zip", "C:/zipArchive/zstd_x64-windows")

  if retVal = 0

    errorCode = ZipArchiveGetLastErrorCode()

    errorMessage = ZipArchiveGetLastErrorMessage()

    ;à faire: traiter l'erreur

  endif

 

; Création de l'archive testZstd2.zip et ajout du répertoire zstd_x64-windows et de son contenu dans l'archive

 retVal = ZipArchiveCreateFromDirectory("C:/zipArchive/testZstd2.zip", "C:/zipArchive/zstd_x64-windows", "zstd_x64-windows")
