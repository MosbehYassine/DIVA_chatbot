Généralités sur les fonctions socket

Les fonctions diva Socket permettent d’accéder directement à l’API Winsock de Microsoft.

Elles permettent de se connecter à un serveur via le protocole TCP/IP et de dialoguer avec un service.

La présente documentation décrit brièvement chaque fonction. Pour plus de détails sur le fonctionnement des sockets, voir la documentation en ligne sur le site MSDN.
