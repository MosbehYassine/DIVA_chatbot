Définition du type String

Une variable de type String est une variable alpha-numérique de taille variable.

Les variables de type String sont très pratiques lorsqu’il faut traiter des données dont on ignore la taille. Par exemple, la fonction HmpRead peut renvoyer un seul caractère une chaîne de plusieurs milliers de caractères. Une variable de type String sera toujours assez grande (dans les limites de la mémoire de la machine tout de même) pour contenir le résultat.

Les variables de type String se manipulent exactement comme les variables de type alpha-numérique habituelles. Vous trouverez ci-dessous quelques précisions concernant des fonctions particulières.

 

Déclaration

Une donnée de type String se déclare selon la syntaxe habituelle des déclarations Diva. La longueur est remplacée par la lettre S.

Les données de type String doivent obligatoirement être définies au niveau 1. Elles ne peuvent être redéfinies par des sous-niveaux.

Exemple :

 1 monstring S

 

Utilisation

Le compilateur rend transparente l’utilisation des String. Les variables de type String s’utilisent donc comme des variables de type alpha-numérique.

Lorsqu’une variable de type String est déclarée, le compilateur alloue une structure contenant un pointeur vers la chaîne de caractères et sa longueur. Lorsque la donnée de type String est utilisée le compilateur rajoute un appel à la fonction StringContent qui fait alors pointer vers la chaîne de caractères.

Tant qu’une donnée de type String n’a pas été initialisée, sa longueur est nulle. La fonction StringNew permet d’allouer un chaîne à espaces.

 

Remarques

  • Il n’est pas possible de déclarer une donnée de type String dans le dictionnaire des données, l’allocation de la mémoire étant dynamique.

  • Attention à l'utilisation des fonctions left, mid etc. avec des données de type String.
    If left(monstring,5) = "12345"  est potentiellement dangereux, car si la donnée contient moins de 5 caractères, le programme va être interrompu.
    Il faut écrire : if size(monstring) >= 5 and left(monstring,5) = "12345"
