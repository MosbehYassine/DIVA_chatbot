GetUserParameter

 

La fonction GetUserParameter permet de lire un paramètre utilisateur sauvegardé par SetUserParameter.

Cette fonction est utilisée par Harmony pour stocker l'état des tableaux, les tailles de fenêtres etc.

 

Numer GetUserParameter ( clé, &valeur, type)

 

Paramètres

Clé

Clé de recherche dans la base des paramètres utilisateur

Valeur

Donnée contenant les données lues

Type

Format de la donnée (non documenté). La valeur par défaut est 6 (type libre)

 

Retour

0

Pas d'erreur. Si la clé n'est pas trouvée, Valeur est mis à espaces.

Autre

Erreur système
