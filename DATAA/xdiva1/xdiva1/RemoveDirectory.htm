RemoveDirectory  Famille Thème

RemoveDirectoryEx

 

Cette fonction permet de supprimer un répertoire.

Pour RemoveDirectory, le répertoire doit être vide.

RemoveDirectoryEx balaye récursivement tout les répertoire pour le vider avant de le supprimer.


Long = RemoveDirectory (Chemin)

Long = RemoveDirectoryEx (Chemin)

 
Paramètres

Chemin

Nom complet du répertoire à supprimer.

 

Retour

0

Pas d'erreur.

0x5d

Le répertoire n'est pas vide.

0x211b

Erreur sur la fonction de suppression.Voir Errno.

Autres

Code d'erreur système.


Exemple

1 st X

st = RemoveDirectory("/Divalto/sys/sys1/sys2")
