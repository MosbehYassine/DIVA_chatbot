ModuleInfo  Famille Thème

 

La fonction ModuleInfo retourne une chaîne HMP contenant des informations sur un module chargé.

ModuleInfo fonctionne également pour les modules qui ont été chargés puis déchargés par la fonction de réinitialisation de Ywpf ou de Ymig.

 

Alpha ModuleInfo( [Module] )

 

Paramètre

Module

Nom du module.
Le nom doit comporter une extension correspondant à un objet, dhop, dhof, dhod etc.

Si le paramètre Module n'est pas précisé, la fonction retourne les informations du module courant.

Attention : le module doit être chargé en mémoire. La fonction GetAdressProcedure permet de charger un module (voir exemple ci-dessous).

 

Retour

ModuleInfo retourne une chaîne HMP contenant les paramètres suivants :

Status

0 = pas d'erreur
1 = module non chargé en mémoire.

VersionModule

Version du module positionnée par la pseudo instruction ModuleVersion

Pack

Numéro de Pack Divalto

NumApplic

Numéro d'appliction Divalto

OverWrite

Nom du module de surcharge associé

OverWrittenBy

Nom du module surchargé.

Deleted

1 si le module a été déchargé par la fonction de réinitialisation de Ywpf ou de Ymig.

Info

Informations stockées dans le module par SetModuleInfo.

Si le paramètre OverWrite est présent, ModuleInfo retourne également les informations du module de surcharge

Status_s

0=le module de surcharge existe
1=le module de surcharge n'existe pas

VersionModule_s

Version du module de surcharge positionné par la pseudo instruction ModuleVersion

 

Exemples

Procedure AfficherInfos(s)

1 S      S

1 param  S

1 valeur S

beginp

   Loop hmpRead(s,param,valeur) = 0

      if valeur <> " "

          display param & " " & valeur

      endif

   endloop

endp

 

main

1 s   S

1 adr 16

 

ModuleVersion("6.2a")                         ; positionnement de mon propre numéro de version

s= ModuleInfo()                               ; lecture des caractéristiques de moi-même

AfficherInfos(s)

 

GetAdressFunction("divalto.dhop","bidon",adr) ; provoque le chargement du module divalto.dhop

s= ModuleInfo("divalto.dhop")

AfficherInfos(s)

 

xmeLoad("divaltoe.dhof")                      ; chargement d'un masque et lecture des informations

s= ModuleInfo("divaltoe.dhof")

AfficherInfos(s)
