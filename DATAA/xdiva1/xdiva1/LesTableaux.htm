Les Tableaux

Diva permet la déclaration et le traitement de tableaux de 1 à 4 dimensions.

 
Déclaration :

Syntaxe : taille_élément*nb_élts_dim_1 * nb_élts_dim_2 ...

 

Exemples:

1 Tab 10*20*5
Tableau à 2 dimensions de variables alpha-numériques de taille 10.

 

1 Tab 10,2*10
Tableau d'entiers à une dimension

 

1 Tab X*10
Tableau de type X à une dimension.

 

Remarque :

Toutes les données de niveau supérieur à un tableau sont également indicées. Ceci permet de définir des tableaux de variables structurées.

1 Tab 10*100
2 Var 5
2 Tab1 1*5

La variable Var est un tableau à une dimension et Tab1 est un tableau à 2 dimensions.

 

Utilisation des tableaux

  • en utilisation normale, le nom du tableau doit être suivi des indices écrits entre parenthèses et séparés par des virgules. Ex : Tab(1,i)

  • il est possible d’utiliser la totalité du tableau comme une variable alpha-numérique dont la longueur est celle de tout le tableau. Le nom du tableau doit être suivi de (*).
    Ex : Tab(*) met tout le tableau a espace.
    Remarque : l’utilisation d’un tableau sans parenthèses est équivalent à (*). Cette écriture génère un warning à la compilation.

  • il est également possible de mettre uniquement le couple parenthèse ouvrante, parenthèse fermante. Cette syntaxe est utilisée pour passer un tableau comme argument d'une fonction ou d'une procédure.

    Exemple :
    I = Somtab(Tab())
    Init Tab() = 'Bonjour'     remplit toutes les cases du tableau avec
    la constante Bonjour.

Remarques

La fonction Index permet de connaître le nombre d'éléments d'une dimension d'un tableau. Elle permet de passer un tableau comme paramètre de fonction sans avoir a passer le nombre d'éléments.

La fonction Search permet de rechercher un élément dans un tableau.

La fonction Sort permet de trier un tableau.
