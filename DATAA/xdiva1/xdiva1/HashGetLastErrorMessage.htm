HashGetLastErrorMessage Famille Thème

La fonction HashGetLastErrorMessage() permet de récupérer le dernier message d'erreur généré par la fonction ComputeHash().

Ce message peut contenir :

  • le message d'erreur généré par le dernier appel à ComputeHash() en échec (i.e. qui a renvoyé une chaîne vide comme code de hash)

  • une chaîne vide si aucune erreur n'a été généré par le dernier appel à ComputeHash()

Alpha HashGetLastErrorMessage()

Retour

La fonction renvoie le message d'erreur détaillé.
