Fonctions Assembly .net

Les fonctions Assembly permettent d'appeler du code managé .net depuis le langage Diva.

Par exemple, ces fonctions peuvent être utilisées pour appeler des services Web autres que les services Web Harmony.

 

Les fonctions Assembly sont :

  • AssemblyLoad qui permet de charger une assembly

  • AssemblyGetMethod qui permet d'obtenir un pointeur vers une méthode (ou fonction).

  • AssemblyMethodInvoke qui permet d'exécuter la fonction.

  • AssemblyMethodInvokeCP qui permet d'exécuter la fonction en tenant compte du code page des chaînes.

  • AssemblyGetError qui permet de récupérer un message d'erreur complet.

Il existe les mêmes fonctions préfixées par LC qui sont exécutées sur le poste client.

 

Les fonctions appelées depuis Diva doivent être déclarées "static". Elles doivent obligatoirement avoir la signature suivante :

public static string maFonction(string hmp)

La fonction reçoit tous les paramètres dans une variable de type string et retourne le résultat dans une variable de type string. Pour passer plusieurs valeurs en paramètre on peut utiliser Hmp, Xml etc.

La classe HmpReader  de la dll  DhSystemTools.dll d'Harmony permet de lire les chaïnes Hmp

 

Un exemple d'utilisation des fonctions Assembly pour appeler un service web :

assembly = AssemblyLoad("dllServiceWebNonDiva.dll")

idConvertir = AssemblyGetMethod(Assembly,"ConvertirDevises")

AssemblyMethodInvoke(assembly,idConvertir,"<d1>" & conv.dev1 & "<d2>" & conv.dev2,retour)
