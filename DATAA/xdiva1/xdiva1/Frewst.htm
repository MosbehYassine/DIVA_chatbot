Frewst  Famille Thème

 

La fonction frewst réécrit l'enregistrement dans le fichier sans tenir compte de la structure des enregistrements, c'est à dire que les octets sont écrits tels quels sur le disque.

frewst écrit à partir de la dernière position lue sur la longueur de l'enregistrement passé en paramètre.

ptr = frewst ( tdf , expression )


Paramètres

Tdf

Table de définition du fichier.

Expression

Chaîne de caractères à écrire dans le fichier.

 

Retour

0  

Pas d'erreur. 

$03  

Fichier plein. 

autres

Code d'erreur système.
