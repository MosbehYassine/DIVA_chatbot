TmpFcreate  Famille Thème

 

La fonction TmpFcreate permet de créer un fichier temporaire.

En utilisation 'standard', les fichiers temporaires sont créés automatiquement lors du chargement du module. Dans ce cas, il n'y a pas besoin d'utiliser la fonction TmpFcreate.

La fonction TmpFcreate permet de créer un fichier temporaire si ce dernier a été déclaré par une instruction HTmpFile  avec le paramètre NOOPEN et sans le paramètre OpenOnUse.

Il est plus simple d'utiliser l'option OpenOnUse de HTmpFile qui créé les fichiers lors de leur utilisation.

TmpFcreate permet également de créer un fichier temporaire de type N en utilisant une Tdf quelconque (non déclarée par HTmpFile). Ces fichiers ne seront pas supprimés automatiquement en fin de programme.

Numer = Tmpfcreate (Tdf , [mode] , [ taille_enreg])

 
Paramètres

Tdf

Tdf du fichier temporaire.

Mode

1

Mode automatique (valeur par défaut). Le fichier est créé avec les caractéristiques (fichiers et clés) du dictionnaire de données. La tdf doit obligatoirement avoir été déclarée par l'instruction HTmpFile.

0

Mode non automatique. Dans ce cas, la fonction crée un fichier temporaire de type N avec la taille d'enregistrement précisée par le paramètre taille_enreg.

2

Le fichier temporaire est créé en type U.

Taille_enreg

Taille des enregistrements pour une création en mode non automatique.

 

Remarque

Si la Tdf a été déclarée avec l'option DeleteOnExit, le fichier sera automatiquement supprimé en fin de programme.

Retour

0

Pas d'erreur.

 

Toutes les erreurs provoquent l'arrêt du programme.
