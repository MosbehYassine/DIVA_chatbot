WebRequestGetHeaders Famille Thème

 

Lecture des en-têtes de la réponse.

 

Int WebRequestGetHeaders  ( Ticket , &Données )

 

Paramètres

Ticket

Ticket préalablement obtenu par WebRequestNew.

 

Données

Chaine Json contenant les différents en-têtes de la réponse.

 

Retour

0

Pas d'erreur

1

Ticket incorrect

2

Erreur. Voir le détail avec WebRequestGetError

 

Exemple

 

1 ticketRequete L

1 json L

.....

st = WebRequestGetHeaders(ticketRequete,retour)

....

JsonParse(json,retour)

st = JsonGetValue (json,"Content-Type",retour)
