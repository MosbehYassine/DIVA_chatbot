If - Else - Elsif - Endif  Famille

 

If (expression1)

 Instructions1

[ Elsif (expression2)

 Instructions2 ]

[ Else

 Instructions3]

Endif

 

Instructions1 est exécuté si expression1 est vraie (différente de 0) ; si expression1 est fausse et que expression2 est vraie, Instructions2 est exécuté. Si expression1 et expression2 sont fausses, Instructions3 est exécutée.

Le mot Endif est obligatoire. Dans le cas ou les instructions If sont imbriquées, il faut autant de Endif que de If.

 

Exemple :

If Etat = "M"

   Libelle = "Marié"
Elsif Etat = "C"

   Libelle = "Célibataire"
Else

   Libelle = "?"
Endif

Remarque : La fonction Condition permet de simplifier l'écriture de certains tests. Par exemple : 
 i = Condition(j<2,0,2) 
        est équivalent aux 4 lignes suivantes :
 if j<2
  i=0
 else
  i=2
 endif
