VerifyModuleDate  Famille Thème

 

La fonction VerfiyModuleDate permet de savoir si un module chargé a été modifié sur le disque.

Cette fonction peut être utilisée par un service ou tout programme résident. Le programme peut tester à intervalles régulier si une nouvelle version d'un des modules a été livrée et agir en conséquence.

Comme il n'y a pas de possibilité de déchargement de module, la solution préconisée est alors de faire un ProgramGoto pour recharger la dernière version des modules.

 

Bool VerifyModuleDate  ([ module ])

Paramètre

Module

Nom du module à vérifier.

*ALL (qui est la valeur par défaut) permet de vérifier la date de tous les modules chargés.

 

Retour

TRUE

Il n'y a pas eu de module modifié.

FALSE

Il y a au moins un module qui a été modifié.


Remarque pour le debogage des widget de DivaltoOne

Le programme qui gère les widgets de divaltoOne appelle la fonction VerifyModuleDate sur le module de gestion du widget en cours.

Donc, seul le module de gestion du widget courant est contrôlé.

Pour contrôler plusieurs modules, le module de gestion du widget doit contenir la fonction WidgetVerifyModuleDate qui effectue les contrôles nécessaires.

Exemple :

public function long WidgetVerifyModuleDate()

beginf

   freturn VerifyModuleDate()    ; vérification de tous les modules charges

endf
