Record

L'instruction Record permet de déclarer un enregistrement défini dans un dictionnaire de données.

[public | protected] Record [KeepDataNames] dico mnémo [var]

Public

Spécifie que la variable var est publique. Si plusieurs modules déclarent la même variable publique, elle est allouée une seule fois à l'exécution.

Protected

Spécifie que la variable var est protégée. Une nouvelle instance de var est allouée.

KeepDataNames

Précise que le compilateur doit garder les informations détaillées concernant les champs de cet enregistrement. Cette option permet d’utiliser ces champ dans les instructions DataCompute , DataDescriptor , DataValue . .

La pseudo-instruction /KEEPDATANAMES (oul ‘option de compilation K) permet de positionner cette option pour tous les enregistrements déclarés par la suite.

Voir remarque ci-dessous.

 

Dico

Nom du dictionnaire de données.

Mnémo

Nom de l'enregistrement défini dans le dictionnaire.

Var

Nom de la variable structurée représentant l'enregistrement. Si ce paramètre n'est pas spécifié, le nom de la donnée est le même que le mnémonique.

Record génère une seule donnée. Pour accéder à ses champs, il faut utiliser la notation pointée donnee.champ .

Si l'enregistrement contient une zone packée, le compilateur rajoute les quatre champs suivants :

Champ

Commentaire

Pack

Zone packée

Depack

Zone dépackée

Write

L'enregistrement sans la zone dépackée. C'est ce champ qui est écrit par la fonction Fwrite.

Memory

La totalité de l'enregistrement en mémoire, zone dépackée comprise.

 

Remarques sur KeepDataNames

  • L’option KeepDataNames de l’instruction Record garde tous les noms des champs de l’enregistrement dans le fichier Hop. Ils pourront donc être utilisés dans les instructions DataCompute et DataDescriptor.

  • Si au moment de l’exécution, des champs ont été ajoutés au dictionnaire (sans que le programme ne soit recompilé), XrtDiva.exe lit le dictionnaire pour compléter sa liste de champs. Il faut bien sûr que le dictionnaire soit en ligne.

  • Si l’option KeepDataNames n’est pas positionnée, les instructions DataCompute et DataDescriptor peuvent accéder a n’importe quel champ de n’importe quel enregistrement déclaré dans le module, à condition que le dictionnaire de données soit en ligne.

  • A partir du moment ou le compilateur Diva rencontre une instruction DataCompute ou DataDescriptor, il positionne l’option KeepDataNames pour tous les enregistrements qui vont être déclarés par la suite.
