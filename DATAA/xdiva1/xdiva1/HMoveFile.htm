HMoveFile  Famille Thème

 

La fonction HMoveFile permet de changer le nom d'un fichier ou de le déplacer dans un autre répertoire. Le fichier peut être déplacé sur un autre disque de la même machine. Par contre il ne peut pas être déplacé vers une autre machine.

 

Numer HMoveFile (ancien, nouveau, numficerr, [abort])

 

Paramètres

Ancien

Nom du fichier à déplacer ou renommer.

Nouveau

Nouveau nom de fichier. Pour renommer un fichier sans le déplacer de répertoire, il n'y a pas besoin de spécifier le chemin complet pour le nouveau fichier.

Numficerr

Donnée alpha de 1 caractère. En cas d'erreur, elle contient le numéro ("1" ou "2") du fichier qui a provoqué l'erreur.

Abort

Booléen (TRUE par défaut) indiquant si la fonction doit arrêter le programme en cas d'erreur, ou rendre la main avec un code d'erreur.

En cas d'arrêt du programme, la fenêtre standard des erreurs est affichée et l'erreur est journalisée dans le fichier ferror.log.

 

Retour

0

Pas d'erreur.

Autres

Code d'erreur système.

Si Abort = TRUE, toutes les erreurs provoquent l'arrêt du programme.

 

Exemple

1 numfic 1

; renommer dans le même répertoire

hmovefile("/Divalto/sys/ftest.dhfd","ftestz.dhfd",numfic)

 

; déplacer le fichier

hmovefile("/Divalto/sys/ftest.dhfd","a:/ftest.dhfd",numfic)
