TranslateData Famille Thème

 

La fonction TranslateData permet d’obtenir la traduction d’un champ multilingues.

La traduction des champs multilingues est automatique dans les masques. Par contre, un programme d'export devra faire appel à cette fonction s'il désire avoir la valeur du champ dans une autre langue que la langue de base.

 

Char TranslateData  ( Libelle, [CodeLangue], [EcranImp], [CodeLangueBase] )

 

Paramètres

Libelle

Libellé à traduire.

CodeLangue

Code langue dans lequel le libellé doit être traduit. Par défaut, c'est le code langue de l’utilisateur qui est utilisé.

EcranImp

Ce paramètre n'a de sens que si le paramètre CodeLangue n'est pas précisé.

1 = utilisation du code langue pour les affichages à l'écran (valeur par défaut).

2 = utilisation du code langue pour les impressions.

CodeLangueBase

Langue de base du paramètre Libelle.

La valeur par défaut est le code langue de base défini dans le fichier paramètre (paramètre LanguageBaseData) ou par la fonction SetLanguageData

 

Retour

La fonction retourne le libellé traduit. Si la traduction n'existe pas, la fonction retourne le libellé non traduit.
