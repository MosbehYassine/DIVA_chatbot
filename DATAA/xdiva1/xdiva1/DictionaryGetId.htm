DictionaryGetId Famille  Thème

DictionaryGetId permet de rechercher un dictionnaire nommé. Si le dictionnaire n’existe pas encore, il est alors créé et nommé. La fonction DictionaryExist permet de tester l’existence d’un dictionnaire sans le créer.

Les dictionnaires sont globaux à toute la tâche. Donc, un dictionnaire peut être alloué dans un module et un autre module peut récupérer son identifiant par DictionaryGetId.

 

Long DictionaryGetId (Nom, [ NombreElements] )

Paramètre

Nom

Nom du dictionnaire à chercher ou à créer.
Il n’y a pas de distinction entre minuscules et majuscules (MonDico <=> mondico).

NombreElements

Nombre approximatif d'éléments si le dictionnaire est créé. Voir DictionaryCreate.


Retour

0

Erreur d'allocation du dictionnaire

Autre

Ticket du dictionnaire
