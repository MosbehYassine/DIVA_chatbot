Nombre de paramètres variable

Le langage Diva permet de déclarer des fonctions/procédures avec un nombre de paramètres variable.

Syntaxe : Le nom de la fonction/procédure doit être suivi de (*)

Exemple : procedure htmcases(*)

Lors de l’appel les paramètres sont passés par valeur selon la méthode habituelle.

 

Récupération des paramètres

Pour connaître les paramètres passés à la fonction/procédure, cette dernière doit appeler la fonction ListParamGetId qui retourne un identifiant de liste. Cette liste contient les différents paramètres.

Les instructions classiques des listes (ListFirst, ListNext …) permettent ensuite de lire les paramètres.

Cette liste est détruite automatiquement lorsque la fonction/procédure se termine.

Si la fonction/procédure veut connaître les caractéristiques du paramètre, elle peut appeler la fonction ListDataDescriptor qui lui donne un descripteur de la donnée. Les informations sont ensuite obtenues par les fonctions DataSize , DataType , DataDec et DataValue .

 

Exemple 1

procedure proc_param_multi(*)

1 id     X  ; id de la liste des paramètres

1 descripteur  60       ; descripteur du paramètre courant

1 valeur     60         ; valeur obtenue lors du listnext

1 valeuralpha  60       ; valeur si le type est alpha

1 valeurnumer 24,10     ; valeur si le type est numérique

1 type    X             ; type du paramètre

1 lg      X             ; taille

1 dec     X             ; nombre de décimales

RecordSqlPtr ptSql      ; pointeur de RecordSql

beginp

 id = ListParamGetId    ; récupération de la listedes paramètre

 ListBegin(id)

 loop ListNext(id,valeur)      

  ListDataDescriptor(id,descripteur)  ; descripteur du paramètre

  type = datatype(datavalue(descripteur)) ; caractéristiques

  lg = datasize(datavalue(descripteur))

  dec = datadec (datavalue(descripteur))

  if type = 3       ; alpha = 3

   valeuralpha = datavalue(descripteur) 

   display valeuralpha

 

  elsif type = 101

     PtrRecordSqlFromDescriptor(ptSql,datavalue(descripteur))

     ptSql.ReaderNext(reader)

  else

   valeurnumer = datavalue(descripteur)

   display valeurnumer

  endif

 endloop

endp

 

Main

proc_param_multi(1,2,3,"toto",12.3) 

 

Exemple 2

 

; la procedure htmcases crée les entêtes d’un tableau html

 

procedure htmcases(*) 1 liste L

1 elem 250

beginp

liste = ListParamGetId 

listbegin(liste) 

loop listnext(liste,elem) 

htm(elem)   ; ajout d’une nouvelle case

endloop 

endp

 

Main

htmcases('Client','Stat','CA','Théorique','Visout','Timing','Dernière')
