AssemblyMethodInvokeCP  Famille  Thème

La fonction AssemblyMethodInvokeCP permet d'exécuter une méthode de l'assembly.

Cette fonction est la même que AssemblyMethodInvoke  mais elle permet en plus de passer en paramètres les code pages des chaînes émises et reçues.

 

Long  AssemblyMethodInvokeCP  ( IdAssembly , IdMéthode , entree, &sortie, CPEntree, CPSortie )

 

Paramètres

IdAssembly

Identifiant de l'assembly obtenu par AssemblyLoad.

 

IdMéthode

Identifiant de la méthode obtenu par AssemblyGetMethod.

 

Entrée

Variable alphanumérique contenant les paramètres de la méthode.

 

Sortie

Variable alphanumérique recevant le résultat de la fonction.

 

CPEntrée

Variable alphanumérique contenant le code page de entrée.

 

CPSortie

Variable alphanumérique contenant le code page de sortie.

 

 

 

Retour

0

Pas d'erreur

Autre

Erreur. Appelez AssemblyGetError. pour en connaître le détail.

Erreurs de programmation Diva à l'appel de la méthode :
Identifiant de l'assembly erroné : 0x167d.
Identifiant de la méthode erroné : 0x167e.

Les autres erreurs concernent le code de l'assembly elle-même.
