DVBufferPut   Famille  Thème

La fonction DVBufferPut permet de placer une donnée dans un DVBuffer.

L'écriture se fait toujours en fin et l'objet DVBuffer est automatiquement agrandi en fonction de la taille de la donnée à écrire..

 

Long  DVBufferPut  (id , valeur )

 

Paramètres

Id

Identifiant de DVBuffer obtenu par DVBufferGetId.

 

Valeur

Valeur à placer dans le DVBuffer.

Pour les données de type X L B, la valeur est écrite telle que dans le DVBuffer.

Pour les autres types, la valeur est précédée de sa longueur (sur 4 octets).

 

Retour

0

Pas d'erreur

-1

Identifiant invalide

1

La classe DVBuffer a levé une exception.
