AssemblyGetMethod Famille  Thème

La fonction AssemblyGetMethod permet de récupérer un pointeur vers une méthode (fonction). L'exécution de la fonction se fait ensuite par AssemblyMethodInvoke.

 

Long  AssemblyGetMethod  ( IdAssembly , méthode , [classe] , [espace_de_noms] )

 

Paramètres

IdAssembly

Identifiant de l'assembly obtenu par AssemblyLoad.

 

méthode

Nom de la méthode (fonction).

 

classe

Nom de la classe contenant la fonction. Ce nom est facultatif. S'il n'est pas précisé, la méthode est recherchée dans toutes les classes.

Le fait de préciser la classe et/ou l'espace de noms contenant la méthode permet de lever d'éventuelles ambiguïtés si plusieurs classes contiennent une méthode de même nom.

 

espace_de_noms

Espace de noms contenant la classe.

Le fait de préciser l'espace de noms permet de lever d'éventuelles ambiguïtés.

 

Retour

0

Erreur. Appelez AssemblyGetError. pour en connaître le détail.

Autre

Ticket permettant d'appeler la méthode

 

 

Remarques

  • Les fonctions appelées depuis Diva doivent être déclarées "static". Elles doivent obligatoirement avoir la signature suivante :
          public static string maFonction(string)

    La fonction reçoit tous les paramètres dans une variable de type string et retourne le résultat dans une variable de type string. Pour passer plusieurs valeurs en paramètre on peut utiliser Hmp, Xml etc.

  • La classe HmpReader  de DhSystemTools.dll d'Harmony permet de lire les chaïnes Hmp.
