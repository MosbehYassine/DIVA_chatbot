LCWinDivaltoWriteInt LCWinDivaltoGlobalWriteInt  Famille Thème

L'instruction LCWinDivaltoWriteInt permet d’écrire un entier dans le registre, sous la clé "HKEY_CURRENT_USER\SOFTWARE\Divalto\divalto.ini\"

L'instruction LCWinDivaltoGlobalWriteInt permet d’écrire un entier dans le registre, sous la clé "HKEY_LOCAL_MACHINE\SOFTWARE\Divalto\divalto.ini\"

Ces instructions se trouvent dans le module ysystemex.dhop.
