DhToolsDhvw_FileClose  Thème

Mise à jour et fermeture du fichier .dhvw de base.

 

int DhToolsDhvw_FileClose ()

 

Retour :

0 - si pas d'erreur

1 - si erreur

 

Description :

Cette fonction referme le fichier .dhvw de base chargé au départ par la fonction DhToolsDhvw_FileOpen.
Il contient maintenant l'ensemble des fichiers .dhvw fusionnés.

 

Exemple : Voir la rubrique Exemple de fusion de fichiers dhvw.
