DhToolsDhvw_FileOpen  Thème

Chargement du fichier de base.

 

int DhToolsDhvw_FileOpen (fichier)

 

Paramètre

fichier

Nom complet Windows du fichier .dhvw qui servira à la fois de fichier de base et de fichier résultat de la fusion.

 

Retour :

0  - si pas d'erreur

1  - si erreur

 

Description :

Cette fonction charge le fichier .dhvw qui servira à la fois de fichier de base et de fichier résultat de la fusion.

 

Exemple : Voir la rubrique Exemple de fusion de fichiers dhvw.
