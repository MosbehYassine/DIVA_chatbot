DictionaryExist Famille  Thème

DictionaryExist permet de tester l’existence d’un dictionnaire.

  

Bool DictionaryExist (nom)

  

Paramètre

Nom

Nom du dictionnaire à chercher.

 

Retour

TRUE

Le dictionnaire existe. La fonction DictionaryGetId permet de récupérer l'identifiant du dictionnaire.

FALSE

Le dictionnaire n’existe pas.
