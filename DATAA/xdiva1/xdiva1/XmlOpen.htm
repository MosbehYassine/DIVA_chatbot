XmlOpen Famille  Thème

 

La fonction XmlOpen permet d’ouvrir un flux XML. Un flux est soit un fichier, soit une chaîne de caractères.

 

Numer XmlOpen (FichierOuChaine , [Mode] )

 

Paramètres

FichierOuChaine

Nom du fichier à ouvrir ou variable contenant le flux XML. Le flux peut être de type « fichier » ou de type « mémoire », en fonction de la variable Mode.

 

Mode

Indique le type du flux.

1 = le paramètre Flux est une chaîne de caractère contenant le code XML (valeur par défaut)

2 = le paramètre Flux est un nom de fichier au format Windows

3 = le paramètre Flux est un nom de fichier au format Harmony

 

Retour

0

Erreur d’ouverture du fichier. Voir XmlGetFileError

Autre

Ticket. Ce ticket est ensuite utilisé comme premier paramètre dans les fonctions XmlRead et XmlClose

 

Remarque

Si le paramètre Flux vaut 3 (fichier au format Harmony), le fichier est lu tel que, par la fonction Freadst , sans aucune conversion de caractères. Il faut veiller à ce que le jeu de caractère du fichier ne soit pas le jeu de caractères Harmony. Voir les Fonctions de conversion .

 

Exemple 1 : Ouverture d’un flux fichier

 

1 ticket L

1 chaine S

ticket = XmlOpen("e:/Divalto/diconouvo/monfichier.xml",2) 

if ticket = 0 

status = XmlGetFileError(chaine) 

 display "Erreur=" & tostring(status) & " Fichier=" & chaine

 ProgramExit

endif 

 

Exemple 2 : Ouverture et lecture d’un flux mémoire

 

1 ticket L

1 tag S

1 valeur S

1 chaine S

1 status L

1 stread L

 

1 article 508

2 code 20 

2 libelle 40 

2 prix 10,2 

2 comm 50 

 

main

; Création du flux XML dans une chaine de caractères

;--------------------------------------------------------------------------

chaine = `<?xml version="1.0" standalone="yes"?>`

chaine &= `<BaseArticle>`

chaine &= `<Article code="A1" libelle="libellé article A1" prix="12,34" />`

chaine &= `<Article code="A2" libelle="libellé article A2" prix="45,88" >`

chaine &= `commentaire sous forme de valeur`

chaine &= '</Article>'

chaine &= `</BaseArticle>`

 

; Ouverture du flux. Comme la chaine a été composée en jeu de caractères OEM

; (jeu Harmony) il faut préalablement le convertir en Utf8

;--------------------------------------------------------------------------

ticket = XmlOpen(FromOemToUtf8(chaine))

 

; Positionnement option

;--------------------------------------------------------------------------

XmlSetOption(ticket,"<whitespacehandling>none")

 

; Lecture du flux

;--------------------------------------------------------------------------

loop (stread := XmlRead(ticket,tag,valeur)) not in (XML_ERROR,XML_END)

 

   ; Début d’un nouvel article 

   ; - - - - - - - - - - - - -  

   if tag = "Article" and stread = XML_BEGINTAG 

      Article = " " 

      loop (stread := XmlRead(ticket,tag,valeur)) not in (XML_ERROR,XML_END,XML_ENDTAG) 

         if tag = "code" and stread = XML_ATTRIBUT 

            code = valeur 

         elsif tag = "libelle" and stread = XML_ATTRIBUT 

            libelle = valeur 

         elsif tag = "prix" and stread = XML_ATTRIBUT 

            prix = valeur 

         elsif stread = XML_TEXTVALUE 

            comm = valeur 

         endif 

      endloop 

 

      ; fin de l’article 

      ; - - - - - - - - - 

      if stread = XML_ENDTAG 

         display article 

      endif 

   endif 

endloop

 

if stread = XML_ERROR

   display "Erreur : " & XmlGetError 

endif

XmlClose(ticket)
