LCWinDivaltoWriteString LCWinDivaltoGlobalWriteString  Famille Thème

L'instruction LCWinDivaltoWriteString permet d’écrire une chaîne dans le registre, sous la clé "HKEY_CURRENT_USER\SOFTWARE\Divalto\divalto.ini\"

L'instruction LCWinDivaltoGlobalWriteString permet d’écrire une chaîne dans le registre, sous la clé "HKEY_LOCAL_MACHINE\SOFTWARE\Divalto\divalto.ini\"

Ces instructions se trouvent dans le module ysystemex.dhop.
