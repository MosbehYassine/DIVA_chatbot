WinRegDeleteValue  Famille Thème

La fonction WinRegDeleteValue permet de supprimer une valeur du registre Windows.

Cette fonction se trouve dans le module ysystemex.dhop.

  

Bool WinRegDeleteValue ( clé, nom_valeur)

 

Paramètres

Clé

Clé.

Nom_valeur

Valeur à supprimer. Si nom_valeur est à espace, la valeur par défaut du registre prend le status : valeur non définie.

  

Retour

TRUE

Pas d’erreur.

FALSE

Clé non trouvée.

  

Exemple

module "ysystemex.dhop"

1 buffer 200

main

st=WinRegDeleteValue("HKEY_CURRENT_USER\Software\DivaltoHarmony\macle","mavaleur")
