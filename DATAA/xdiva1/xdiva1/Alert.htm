Alert Famille 

 

Alert est une instruction qui ne fonctionne que pour les Zoom en mode Divalto One.

 

Alert permet d'afficher un (ou plusieurs) messages coté client. Le message n'est pas immédiatement affiché comme pour une instruction MessageBox, mais il est affiché à la fin du traitement serveur.

Si plusieurs appels à Alert on eu lieu pendant le traitement serveur, les différents messages sont concaténés puis affichés.

 

Alert ( message, type)

  

Paramètres

Message

Texte du message. Le caractère $0d est remplacé par <BR>

Type

Type de message. Ce paramètre peut prendre une des valeurs suivantes

define ALERT_SUCCESS = 1

define ALERT_INFO = 0

define ALERT_WARNING = -1

define ALERT_ERROR = -2
