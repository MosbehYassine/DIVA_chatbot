HFile

L'instruction HFile permet de déclarer un fichier défini dans un dictionnaire de données. Les enregistrements doivent être déclarés par l'instruction Record.

[public | protected] HFile dico mnémo vartdf [nom] [noopen] [openonuse] [noshare] [noversioncheck]

Public

Spécifie que la variable Vartdf est publique. Si plusieurs modules déclarent la même variable publique, elle est allouée une seule fois à l'exécution.

Protected

Spécifie que la variable Vartdf est protégée. Une nouvelle instance de Vartdf est allouée.

Dico

Nom du dictionnaire de données.

Mnémo

Nom du fichier défini dans le dictionnaire.

Vartdf

Variable qui identifie la Tdf.

Nom

Nom physique du fichier à ouvrir si ce n'est pas le nom précisé dans le dictionnaire. Ce nom doit être une constante entourée de quotes.

Noopen

Le fichier ne doit pas être ouvert automatiquement lors du chargement du module. Par défaut, le fichier est ouvert avec le nom précisé dans le dictionnaire de données.

Openonuse

Indique que le fichier ne doit pas être ouvert lors du chargement du module mais lors de la première utilisation.

Noshare

Indique que le fichier doit être ouvert en mode réservé. Par défaut, le fichier est ouvert en mode partagé.

Noversioncheck

Indique que le système ne doit pas vérifier la version interne du fichier. Par défaut, le système vérifie que la version courante du fichier correspond bien avec la version spécifiée dans le dictionnaire.
