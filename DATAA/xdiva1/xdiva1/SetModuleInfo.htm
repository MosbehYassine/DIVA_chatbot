SetModuleInfo  Famille Thème

 

La pseudo instruction SetModuleInfo permet de stocker des informations dans un module.

Ces informations peuvent ensuite être lues par la fonction ModuleInfo.

 

SetModuleInfo ( info )

 

Paramètres

Info

Constante alphanumérique.

 

Exemple

Tortoise SVN est un outil permettant de gérer les versions et sous-versions d'un source.

Dans les fichiers, Tortoise remplace la chaîne "$Id:" par des informations de version (numéro de version, date, utilisateur).

Avec SetModuleInfo, il est possible d'afficher la liste de tous les sources utilisés dans un programme, avec le numéro de version de chaque source.

 

 

SetModuleInfo('$Id: gtpp210.dhsp 4092 2009-07-22 09:27:31Z root $')

 

Function Char ChercherMot(Chaine,num)

; Extraction d'un mot dans une chaîne

1 Chaine S

1 num    x

1 Mot    S = ''

1 i      x = 1

Beginf

do while i <= num and (Mot:= SplitWord(Chaine,' ')) <> $00

   i++         

wend

freturn(Mot)

endf                      

 

Procedure AfficherInfosModules

;* Affichage de tous les source utilisés dans un programme

1 param           S

1 valeur          S

1 ModulesNames    S

1 ModuleName      S

1 Info            S

1 SourceName      S

1 Version         10,0

Beginp

   ModulesNames = GetModulesNames                       ; liste de tous les modules

   do while hmpread(ModulesNames,param,ModuleName) = 0  

      display ModuleName

      Info = ModuleInfo(ModuleName)                     ; lecture des infos d'un module

      do while hmpread(Info,param,valeur) = 0

         if param = 'INFO'

            SourceName = ChercherMot(valeur,2)

            Version    = ChercherMot(valeur,3)

            if SourceName <> " "

                Display "  " & SourceName & " " & version

            endif

         endif

      wend

    wend

endp

 

main

AfficherInfosModules

ProgramExit
