ListImplicitesLoad  Famille Thème

 

Cette fonction permet de charger un fichier contenant une liste de chemins implicites.

 

Long = ListImplicitesLoad (fichier, [réseau] ,[ effacement],[ erreur])

 
Paramètres

Fichier

Nom du fichier à charger.

Le fichier est un fichier texte (.txt généralement) et a la structure d'une ligne est la suivante :

- un chemin implicite

- un point-virgule en première position indique une ligne de commentaires.

Réseau

Booléen (TRUE/FALSE) indiquant si la recherche du fichier doit se faire ou non en tenant compte du paramètre SeveurXlogf de Divalto.ini.

Valeur par défaut = TRUE.

Effacement

Booléen (TRUE/FALSE) indiquant si la liste des implicites de la tâche doit être ou non effacée avant la lecture. FALSE permet de fusionner deux listes.

Valeur par défaut = TRUE.

Erreur

Booléen (TRUE/FALSE) qui indique si la fonction peut ou non afficher des messages en cas d'erreur.

Valeur par défaut = FALSE.

 

Retour

0

Pas d'erreur

Autre

Code d'erreur système.
 

Remarque

Après ListImplicitesLoad les nouveaux chemins implicites sont immédiatement pris en compte.

Les fichiers de chemins implicites sont toujours recherchés dans le répertoire /Divalto/Sys.

 
Exemple

; chargement du fichier "mes implicites.txt" avec affichage

; des éventuelles erreurs

1 st X

main

 st = ListImplicitesLoad("mes implicites.txt",,,TRUE)
