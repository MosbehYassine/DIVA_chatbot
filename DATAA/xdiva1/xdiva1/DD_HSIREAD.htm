DD_HSIREAD

La commande DD_HSIREAD permet de lire les index du fichier courant dans la table cles de ddsys.dhsd. Cette structure est utilisée par les instructions HSiCreate , HSiRead , HSiMod .

Il est donc possible de lire la structure des clés par DD_HSIREAD et de créer le fichier ayant cette description de clés.

Il faut avoir préalablement lu un fichier du dictionnaire avec une commande DD_FILE_xxxx .

 

Retour contient la description des clés au format cles de ddsys.dhsd.

 

Voir DDInterface : Index

 

Retour

0

pas d’erreur.

autre

Erreur. Voir DD_GETERROR

 

Exemple

1  ticket L 

1  stindex X

record ddsys.dhsd cles  

 

stindex = DDInterface(DD_HSIREAD,ticket,,cles)
