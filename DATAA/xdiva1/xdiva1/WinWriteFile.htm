WinWriteFile  Famille Thème

 

La fonction WinWriteFile écrit des données dans un fichier. L'écriture se fait à partir de la position courante indiquée par le pointeur du fichier. Après l'écriture, le pointeur est avancé du nombre d'octets écrits et la taille du fichier est mise à jour.

 

Long WinWriteFile (Ticket, Article, TailleEcrits)

 

Paramètres

Ticket

Identifie le fichier. Le fichier doit être ouvert avec l'accès GENERIC_WRITE.

Article

Zone contenant les données à écrire dans le fichier. L'écriture se fait d'après la taille de cette zone.

TailleEcrits

Donnée de type L qui reçoit en retour de la fonction le nombre d'octets réellement écrits.

 

Retour

TRUE

Pas d'erreur.

FALSE

Erreur. Appelez la fonction WinGetLastError pour connaître le détail de l'erreur.

 
Remarques

Si une partie du fichier est verrouillée par un autre processus et que l'écriture chevauche la zone verrouillée, la fonction sort en erreur.

Pour écrire dans un fichier texte, vous devez ajouter le séparateur d'enregistrement $0d0a à la fin des données à écrire.

 

Exemple

Saisie et écriture d'enregistrements dans un fichier.

fic = WinCreateFile("d:\Divalto\sys\stest",

            GENERIC_READ + GENERIC_WRITE, 

            FILE_SHARE_READ + FILE_SHARE_WRITE, 

            0, 

            OPEN_EXISTING, 

            FILE_ATTRIBUTE_NORMAL,0) 

do

   input " " art 

while Harmony.Key <> K_ESCAPE

   st = WinWriteFile(fic, left(art) & $0d0a,nbecr) 

   if st = FALSE 

      MessageBox ("Erreur " & bindec(ldxl(WinGetLastError))," ") 

   endif 

wend
