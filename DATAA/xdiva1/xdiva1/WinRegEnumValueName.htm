WinRegEnumValueName

La fonction WinRegEnumValueName permet de connaître tous les noms de valeurs qui sont sous une clé.

Cette fonction se trouve dans le module ysystemex.dhop.

 

int WinRegEnumValueName  ( clé_départ , index , &nom_valeur )

 

Paramètres

Clé_départ

Clé de départ dans le registre. La fonction balaye toutes les valeurs de cette clé.

 

Index

Doit contenir le résultat du précédent appel ou 0 lors du premier appel.

 

Sous_clé

En retour, nom de la valeur trouvée.

 

Exemple

1 idx 5,0

1 cle 256

 

idx = 0

do

   idx = WinRegEnumValueName("HKEY_CURRENT_USER\Software\Divalto\divalto.ini\system",idx,cle)

while idx

   display  cle

wend
