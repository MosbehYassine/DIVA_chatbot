GetSystemFileName  Famille Thème

 

Cette fonction retourne le nom Windows d'un fichier préalablement ouvert. Elle est utilisée conjointement avec la fonction WinShellExecute.


Alpha = GetSystemFileName (Tdf)

 
Paramètres

Tdf

Tdf d'un fichier préalablement ouvert.

 

Retour

La fonction retourne le nom du fichier Windows.

En cas d'erreur (fichier non ouvert) la fonction retourne espace.


Exemples

; ouverture d'un fichier, récupération de son nom systeme et

; appel de Word pour l'éditer.

record * htdf tdf

1 nom 256

tdf.name = "/Divalto/sys/codes erreurs.doc"

hopen (tdf,"P")

nom = GetSystemFileName(tdf)

WinShellExecute("open",nom)
