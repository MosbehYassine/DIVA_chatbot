DDGetRecord3  Famille Thème

Pour lire les dictionnaires créés par Xwin, utilisez DDInterface (à partir de la version 5.3).

La fonction DDGetRecord3 permet de lire les caractéristiques d'un enregistrement. Elle doit être préalablement appelée à la fonction DDNextData3 qui permet de lire les champs de l'enregistrement.

 

Long DDGetRecord3 (dictionnaire, enregistrement, donnée_réceptrice)

 

Paramètres

Dictionnaire

Nom du dictionnaire de données.

Enregistrement

Nom de l'enregistrement à lire.

Donnée_réceptrice

Donnée qui reçoit les caractéristiques de l'enregistrement. Elle doit être une instance de Record Info du dictionnaire H3fdd.

Retour

0

Pas d'erreur

1

Dictionnaire absent

6

Enregistrement absent

Autre

Erreur. Voir DDGetTextError qui donne un message d'erreur.

Exemple

Voir DDNextData3
