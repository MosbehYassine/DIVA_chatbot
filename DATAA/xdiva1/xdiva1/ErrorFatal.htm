ErrorFatal  Famille Thème

 

Cette intruction permet d'afficher la fenêtre des erreurs d'Harmony avec l'icone Stop. Le programme est ensuite interrompu.

Le contenu de la fenêtre d'erreur est décrit dans : La fenêtre d'erreurs.

 

ErrorFatale (code, [param], [texte] , [titre], [ErreurSysteme] ,[codecompl] , [lieu])

 
Paramètres

Code

Code d'erreur "application". Voir La fenêtre d'erreurs.

Param

Donnée alphanumérique (espace par défaut) qui est incorporée au texte du message (par exemple un nom de fichier).

Ce champ n'a de sens que si un code d'erreur est interprété et que le code interprété possède un paramètre. Pour savoir si un code d'erreur contient un paramètre, utilisez le choix "Code erreur" du programme Xtools.dhop : le texte affiché contient la chaîne XXXXX en lieu et place du paramètre.

Texte

Si ce paramètre est à espace (valeur par défaut), un code d'erreur (Code ou ErreurSysteme) est automatiquement interprété pour donner le texte affiché.

Ce texte est affiché dans la fenêtre des erreurs. S'il contient la chaîne %s, cette chaîne est remplacée par l'interprétation d'un code d'erreur.

Le caractère | permet de forcer le passage à la ligne suivante.

Titre

Texte affiché dans la barre de titre de la fenêtre d'erreur (espace par défaut). Si Titre est à espace, on affiche "Erreur".

ErreurSysteme

Code d'erreur système (0 par défaut).

Codecompl

Code d'erreur complémentaire (0 par défaut).

Si Codecompl vaut –1, la valeur de errno (GetLastError) est affichée.

Cette valeur peut être lue par la fonction GetErrno.

Lieu

Lieu de l'erreur (0 par défaut).

-1 permet d'afficher le lieu interne de la dernière fonction Harmony appelée.

Cette valeur peut être lue par la fonction ErrorCmpl.

Remarques

L'instruction Ferror permet d'appeler plus simplement la fenêtre d'erreur pour les fichiers.

L'instruction ErrorWarning affiche la même fenêtre sans interrompre l'exécution du programme.

 

Exemple 1

tdf.name =  "Fprinters"

st = fopen(tdf,"R") ; ouverture en mode réservé

if st <> 0

   ErrorFatal(st,tdf.name,Codecompl=-1,lieu=-1) 

endif

Si le fichier est en lecture seule, le message affiché est :

Erreur système (open) à l'ouverture du fichier /Divalto/sys/Fprinters

Erreur = 2102 Code Complémentaire=10005

Exemple 2

tdf.name =  "Fprinters"

st = fopen(tdf,"R") ; ouverture en mode réservé

if st <> 0

   ErrorFatal(st,tdf.name, \ 

           "Erreur d'ouverture du fichier des modèles|%s", \ 

Codecompl=-1,lieu=-1) 

endif

Si le fichier est en lecture seule, le message affiché est :

Erreur d'ouverture du fichier des modèles

Erreur système (open) à l'ouverture du fichier /Divalto/sys/Fprinters

Erreur = 2102 Code Complémentaire=10005
