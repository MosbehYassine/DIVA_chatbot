[]  Famille 

 

Les crochets sont un opérateur spécial permettant de concaténer une liste de données. A l'intérieur des crochets de concaténation, il est possible d'effectuer des opérations particulières qui sont :
 - le positionnement de curseur,
 - la génération d'une chaîne d'espaces,
 - la duplication d'une constante.

Alpha [ v1 v2 v3 …. vn ]

 

Paramètres

V1 .. vn

Le type des données se trouvant à l'intérieur des crochets est quelconque.

 

Retour

La concaténation renvoie toujours un résultat de type alphanumérique.

 
 

Positionnement du curseur

[ = ligne colonne ]

Exemple : input [ = 10 2 'Code du compositeur.... : ' ] codecp

 

Génération d'une chaîne d'espaces

[ * nombre_d'espaces ]

Exemple : display [ System.clear System.rever 'Divalto' *10 System.date ]

laisse 10 espaces entre les 2 variables.

 

Duplication d'une constante

[ ! nombre_de_fois constante ]

Exemple : display [ ! 80 '-' ]

affiche un trait de 80 tirets.
