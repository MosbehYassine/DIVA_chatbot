Private   Famille Thème

Le mot clé Private ne peut se trouver que dans un module de surcharge.

Private devant une fonction/procédure signifie que celle-ci

  • n'est pas publique

  • ne surcharge pas une fonction/procédure du module de base.

Autrement dit, toute fonction d'un module de surcharge qui n'est pas déclarée Public ou Private est une fonction de surcharge.

En cas de non respect de ces règles, le compilateur signale une erreur.

 

Attention : le compilateur effectue les vérifications concernant les fonctions privées que si l'option du profil courant "Vérifier que les fonctions non private sont des surcharges"  est à "oui".

 

Remarques concernant les surcharges

  • Dans les traitements de surcharge des dictionnaires, les fonctions doivent être déclarées Public si elles n'existent pas dans le code de base.

  • Dans les traitements de surcharge des masques, les fonctions doivent être déclarées Private si elles n'existent pas dans le code de base.

 

Exemple

Dans le module de traitement du zoom, les fonctions sont facultatives.

Si une fonction n'est pas présente dans le module de base, elle peut être ajoutée dans le module de surcharge avec Private.

module de base

module de surcharge

(rien)

Private Procedure ApresRead
beginp
 ; lecture des données complémentaires
endp

 

Lors d'une mise à jour de version, la fonction a été ajoutée dans le module de base.

On a donc :

module de base

module de surcharge

Public Procedure ApresRead

Private Procedure ApresRead

La recompilation du module de surcharge va signaler une erreur puisque la fonction Private est maintenant devenue une fonction de surcharge.


Il faut donc modifier le source, et certainement appeler la nouvelle fonction de base.

Le traitement corrigé devient :

module de base

module de surcharge

Public Procedure ApresRead

Procedure ApresRead

beginp

  standard.ApresRead
; lecture des données complémentaires
endp
