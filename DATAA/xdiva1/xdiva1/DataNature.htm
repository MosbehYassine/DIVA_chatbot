DataNature

La fonction DataNature permet de connaître le type d'une donnée.

Elle se distingue de DataType du fait :

  • qu'elle renvoie les mêmes valeurs que le dictionnaire de données

  • qu'elle renvoie des valeurs distinctes pour les dates, heures etc.

 

Long DataNature (Donnée)

 

Retour

DataNature retourne le type donnée. Les valeurs possibles sont :

1

Numérique avec décimales variables

2

Numérique

3

Alphanumérique

4

Date

6

Type B

7

Type X

9

Type L

10

Heure

11

Date mensuelle

12

Date + heure

13

Durée

97

Etendu (résultat d'un calcul)

98

Type S (string)

99

Inconnu (type U)

 

Remarque

Cette fonction peut être utile dans les fonctions/procédures pour connaître le format exact d'un paramètre formel.
