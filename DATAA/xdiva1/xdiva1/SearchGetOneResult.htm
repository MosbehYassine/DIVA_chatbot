SearchGetOneResult  Famille  Thème

La fonction SearchGetOneResult permet de lire une ligne du résultat d'une requête..

La description du contenu des DVBuffers n'est pas documentée.

 

Long  SearchGetOneResult ( Id , &IdBuffer, Numéro)

 

Paramètres

Id

Identifiant de la connexion.

 

IdBuffer

En retour, un identifiant de DVBuffer contenant le résultat.

Le contenu de ce DVBuffer n'est pas documenté.

 

Numéro

Indice à lire ou 0 pour lire le suivant.

 

Retour

0

Pas d'erreur

autre

Il n'y a plus de lignes à lire
