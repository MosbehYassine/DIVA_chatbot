Fonctions JSON

Le format JSON s'impose de plus comme un standard pour l'échange de données, notamment pour les services web REST.

Les fonctions JSON de Diva permettent de lire les données dans ce format de manière très simple.

 

L'ordre des opérations est le suivant :

  • Allocation d'un objet Json par JsonOpen

  • Ensuite la chaîne contenant le Json est parsée par JsonParse et l'objet décrit par cette chaîne est construit en mémoire..

  • Puis les fonctions JsonGetValue et JsonGetLength permettent de lire les champs de cet objet.
    La syntaxe est la même qu'en JavaScript.

Exemple :

1 json S

1 ticket L

1 valeur S

 

json = "{ 'article': {" & \

              "'ref': 'ART0001',"  & \

              "'libelle': 'Coffret bois',"  & \

              "'prix': '12,34' " &\

              "}}";

ticket = JsonOpen()

JsonParse(ticket,json)

JsonGetValue(ticket,"article.ref",valeur);          -> ART0001

JsonGetValue(ticket,"article.libelle",valeur);      -> Coffret bois

JsonGetValue(ticket,"article.prix",valeur);         -> 12,34

JsonClose(ticket)
