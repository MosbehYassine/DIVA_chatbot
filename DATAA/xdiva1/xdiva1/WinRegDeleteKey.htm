WinRegDeleteKey  Famille Thème

La fonction WinRegDeleteKey permet de supprimer une clé du le registre Windows.

Toutes les valeurs sous la clé et la clé elle-même sont supprimées.

Cette fonction se trouve dans le module ysystemex.dhop.

  

Bool WinRegDeleteKey ( clé, sous_clé)

 

Paramètres

Clé

Clé.

Sous_clé

Sous-clé à supprimer

  

Retour

TRUE

Pas d’erreur.

FALSE

Clé non trouvée.

  

Exemple

module "ysystemex.dhop"

1 buffer 200

main

i=WinRegDeleteKey("HKEY_CURRENT_USER\Software\DivaltoHarmony","macle")
