Const

L'instruction Const permet de déclarer des constantes.

Const nom_de_constante = expr

Expr peut être une constante simple ou une expression ne contenant que des constantes.

Il est possible de mettre plusieurs déclarations de constantes sur la même ligne.

Une constante définie peut être utilisée dans la définition d'une autre constante.

 

Exemples :

Const TVA = 18,6 CRLF = $0D0A SOC = 'DIVALTO'

Const C1 = 1000+1000*TVA/100

CRLF est une constante hexadécimale car elle est précédée d'un $.

Les constantes prédéfinies sont utilisées comme des constantes ordinaires à l'intérieur des programmes.

Une constante peut avoir le même nom qu'un champ d'un enregistrement, ce qui n'est pas le cas pour les Define.

 

Remarque

Des constantes peuvent être positionnées au niveau des profils de l'atelier Xwin. Elles sont transmises au compilateur Diva à chaque compilation de source.
