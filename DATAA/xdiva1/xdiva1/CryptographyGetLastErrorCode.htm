CryptographyGetLastErrorCode Famille Thème

 

La fonction CryptographyGetLastErrorCode() permet de récupérer un code d'erreur détaillé de la dernière fonction en échec du module de signature numérique.

 

Int CryptographyGetLastErrorCode()

 

Retour

Le code d'erreur détaillé de la dernière fonction en échec du module de signature numérique. Il peut avoir une des valeurs suivantes :

  • 0 pas d'erreur

  • 1 Impossible d'ouvrir un fichier en écriture et/ou en lecture

  • 2 Clé invalide

  • 256 Erreur interne au module de signature numérique ou usage inattendu.

Remarques

Cette fonction doit être appelée immédiatement après celle qui a renvoyé un code d'erreur.

Attention, après l'appel de cette fonction, le code d'erreur détaillé, que renverrait un deuxième appel à cette fonction, serait 0.
