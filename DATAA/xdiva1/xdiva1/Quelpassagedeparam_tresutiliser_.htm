Quel passage de paramètres utiliser ?

Pour une bonne utilisation des fonctions/procédures, il faut veiller à passer les paramètres avec le type de passage approprié. En effet, un mauvais passage de paramètre peut entraîner des effets de bords (variable globale modifiée etc...).


Passage par valeur

Le passage par valeur (par défaut) doit être utilisé si le paramètre ne doit pas être modifié dans le programme appelant. La fonction peut à ce moment là modifier cette variable sans avoir de répercussions au niveau du programme appelant.

Le passage par valeur nécessite de la place en mémoire pour pouvoir recopier les paramètres. Il est donc déconseillé de passer des grands tableaux par valeur.

Si le paramètre peut être une constante, il est obligatoire de le passer par valeur.


Passage par adresse

Le passage par adresse doit être utilisé si le paramètre doit être modifié par la fonction ou la procédure. Ce mode de passage ne consomme pas de mémoire. C'est pourquoi le passage par adresse doit être préféré pour les tableaux.

Il est impossible de passer une constante par adresse.
