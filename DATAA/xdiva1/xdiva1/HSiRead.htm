HSiRead  Famille Thème

 

HSiread permet de lire les paramètres d'un fichier séquentiel indexé non ouvert. Si le fichier est déjà ouvert, utilisez la fonction FsiGetParam.

 

Ptr = HSiRead (nomcles , nomdata , cles, status, abort)

Paramètres

Nomcles

Nom complet du fichier des clés.

NomData

En retour de la fonction, ce paramètre contient le nom du fichier des données.

Clés

En retour de la fonction, ce paramètre contient la description des clés. Ce paramètre doit être une instance de l'enregistrement Cles du dictionnaire ddsys.dhsd.

Status

Donnée de type X qui reçoit le code d'erreur système.

Abort

Booléen (TRUE par défaut) indiquant si la fonction doit arrêter le programme en cas d'erreur, ou rendre la main avec un code d'erreur.

En cas d'arrêt du programme, la fenêtre standard des erreurs est affichée et l'erreur est journalisée dans le fichier ferror.log.

 

L'enregistrement Cles contenant la description des clés est un tableau de 256 cases pour les clés.

LettreCle

Lettre clé.

NomCle

Nom de la clé.

PositionCe

Position du code enregistrement.

ValeurCe

Valeur du code enregistrement.

TestCe

Test à effectuer sur le code enregistrement

 

0 =
1 <>
2 <
3 >
4 <=
5 >=
6 &

égal
différent
inférieur
supérieur
inférieur ou égal
supérieur ou égal
et logique
 

Pour chaque clé, on trouve ensuite un tableau de 16 éléments décrivant les données qui composent la clé :

PosCle

Position d'un fragment de clé.

LgCle

Longueur d'un fragment de clé.

  

Retour

La fonction renvoie la valeur nulle en cas de succès et les paramètres NomData et Clés contiennent les paramètres du fichier. Sinon, elle renvoie un code d'erreur principal, et le paramètre Status contient le code d'erreur du système.

Pour la liste des erreurs possibles, voir Erreurs des fonctions HcreateFile, HSicreate

 

Remarque

La fonction DDHSiRead permet de lire les caractéristiques d’une base à partir du dictionnaire de données.

 

Exemple

 

Lecture des paramètres d'un fichier.
 

record 'ddsys.dhsd' cles

1 statsys x

1 data 256

HSiRead("/Divalto/sys/Fprinters",data,cles,statsys)
