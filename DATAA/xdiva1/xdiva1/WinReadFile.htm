WinReadFile  Famille Thème

 

La fonction WinReadFile lit des données depuis un fichier ; la lecture se fait à partir de la position courante du pointeur associé au fichier. Après chaque lecture le pointeur est mis à jour.

Long WinReadFile(ticket, Article, TailleALire, TailleLue)

 

Paramètres

Ticket

Identifie le fichier à lire. Le fichier doit être ouvert avec l'accès GENERIC_READ.

 

Article

Donnée qui reçoit les données lues.

TailleALire

Spécifie le nombre d'octets à lire dans le fichier.

TailleLue

Donnée numérique qui reçoit le nombre d'octets réellement lus.

 

Retour

TRUE

Ok. Le nombre d'octets lus est dans TailleLue. Si ce nombre est nul, c'est que la fin de fichier est atteinte.

FALSE

Erreur. Appelez la fonction WinGetLastError pour connaître le détail de l'erreur.

 

Remarques

Si un octet est réservé dans la portion de fichier à lire, la fonction sort en erreur.

 

Exemple

Ouverture et lecture d'un fichier.

1 fic L

1 art 50

1 nblus L

fic = WinCreateFile("d:\Divalto\sys\stest", \

         GENERIC_READ, \

         FILE_SHARE_READ, \

         0, \

         OPEN_EXISTING,0,0)

if fic = -1

   MessageBox ("Erreur " & bindec(ldxl(WinGetLastError)), "erreur") 

endif

 

do

   st = WinReadFile(fic, art, size(art), nblus) 

while nblus > 0

   display fstring("F",left(art, nblus)) 0 

wend 

WinCloseHandle(fic)
