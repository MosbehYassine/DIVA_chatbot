Fnumer

La fonction Fnumer formate une chaîne de caractères dans une donnée numérique. Elle vérifie qu’une donnée de type alpha contient une valeur numérique correcte et affecte cette valeur dans une variable numérique. Elle sort en erreur s’il y a débordement de capacité.

 

Bool Fnumer (numer , alpha)

 

Paramètres

Numer

Variable numérique qui reçoit la valeur contenue dans alpha.

Alpha

Variable de type alphanumérique qui contient la valeur à vérifier puis à affecter à Numer.

 

Retour

0

La donnée de type alpha contient des caractères non numériques ou il y a débordement de capacité lors de l’affectation de alpha dans numer.

1

Pas d’erreur
 

Exemple

1 valeurweb 14

1 valnum 10,2

 

input " " valeurweb 

if fnumer(valnum,valeurweb) 

   display "ok" & valnum 

else 

   display "erreur" 

endif
