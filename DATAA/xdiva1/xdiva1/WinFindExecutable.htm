WinFindExecutable  Famille Thème

 

Cette fonction permet de retrouver le chemin d'un programme associé à un fichier (par son extension). Par exemple, quel programme faut-il exécuter pour traiter le fichier montexte.doc.

Voir la fonction WinShellExecute qui permet d'exécuter directement ce programme.

 

Long WinFindExecutable (Fichier, résultat , [répertoire])

 

Paramètres

Fichier

Nom du fichier dont on cherche le programme associé. Attention, ce fichier doit impérativement exister.

Résultat

Donnée alphanumérique qui reçoit le chemin du programme associé.

Répertoire

Chemin d'un répertoire par défaut. Fichier est tout d'abord recherché dans ce répertoire. Ce paramètre est facultatif. Dans ce cas, Fichier doit être un nom complet.

 

Retour 

0

Pas d'erreur. Résultat contient le chemin du programme associé au fichier.

31

Pas d'association trouvée pour ce type de fichier

2

Fichier absent

3

Chemin du fichier non trouvé

11

Le fichier .exe est invalide.

Remarque

Si Fichier n'est pas un nom absolu, il est recherché de la même manière que les exécutables, à savoir, dans le répertoire courant, dans le répertoire Windows, dans les répertoires précisés par la variable d'environnement PATH.

 

Exemples

1 result 260

st = WinFindExecutable("docmapi.doc",result)

if st = 0

   display result ; affiche le chemin de Winword.exe 

endif
