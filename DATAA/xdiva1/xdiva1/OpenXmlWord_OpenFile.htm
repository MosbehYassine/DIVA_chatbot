OpenXmlWord_OpenFile  Famille  Theme

 

La fonction OpenXmlWord_OpenFile ouvre un fichier .docx (document MS Word) déjà existant.

 

int OpenXmlWord_OpenFile (fichier)

 

Paramètre

Fichier

Nom complet du fichier .docx, au format Windows.

 

Retour

0

Pas d'erreur.

Autre

Erreur. Voir la fonction OpenXml_GetMsgError.
