SearchModifyDocument  Famille  Thème

La fonction SearchModifyDocument permet de demander la ré-indexation d'un document dans la base Search.

 

Long  SearchModifyDocument ( Id , Dictionnaire , Document , IdentDocument )

 

Paramètres

Id

Identifiant de la connexion.

 

Dictionnaire

Nom du dictionnaire de documents.

 

Document

Nom du document dans le dictionnaire de documents.

 

IdentDocument

Identifiant du document. Cet identifiant est obtenu par exemple par la fonction ReaderUpdate.

 

Retour

0

La fonction retourne toujours la valeur nulle.

 

  

Voir

SearchCreateDocument, SearchDeleteDocument,, SearchIndex

 

Remarque

  • L'indexation des documents n'est pas faite en temps réel. SearchModifyDocument envoie un ordre au serveur Search qui le met dans la file d'attente des indexations à réaliser.
