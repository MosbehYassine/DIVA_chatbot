Switch2 - Case - Default - Continue - Break- RedoSwitch - Endswitch  Famille

 

La structure Switch2 se différencie de la structure Switch par le fait que les expressions testées sont obligatoirement des constantes.

L'instruction Switch2 est extrêmement rapide à l'exécution, la rapidité du branchement au cas choisi étant indépendant du nombre de choix total.

Voir également SwitchString si l'expression est de type alpha.

 

Switch2 expression

Case constante1 constante2 …. constanteN

 instructions

 [ RedoSwitch ]

 [ Continue ]

 [ Break ]

Case constante1 constante2 …. constanteN

 instructions1

……..

[ Default

 instructions2 ]

Endswitch

 

L'instruction Switch Case2 est une généralisation de l'instruction de sélection simple If. Dans cette structure, l'expression qui suit le mot réservé Switch est appelée sélecteur.

Les expressions de sélection doivent obligatoirement être des constantes numériques ou une constante alpha de un caractère (voir remarque ci-dessous).

A l'exécution, la valeur du sélecteur doit correspondre à l'une des constantes possibles. Les instructions associées sont alors exécutées, après quoi le contrôle est donné à l'instruction suivant la fin de la structure (sauf si une instruction Continue a été rencontrée). Si le sélecteur ne correspond à aucune des constantes, les instructions suivant le mot réservé Default sont exécutées. Si le mot réservé Default est absent, l'exécution du programme se poursuit après le mot réservé Endswitch qui est obligatoire.

Continue provoque un branchement sur l'instruction qui suit le Case suivant (voir exemple).

Break provoque la sortie de la structure Switch. L'exécution du programme se continue après Endswitch.

RedoSwitch provoque un branchement à l'instruction Switch. Expression est à nouveau évaluée.
 

Remarque

Si vous voulez utiliser l'instruction Switch2 pour tester un caractère dans une chaîne vous devez écrire :

switch2 asc(car)

case "a"

...

case "b"

...

Endswitch

En effet, le sélecteur est toujours transformé en numérique suivant les règles habituelles de l'affectation. Par contre, une constante alpha d'un caractère après le case est transformé en la valeur ANSI du caractère.

 

Exemple : Cet exemple illustre l'utilisation de Continue. Le programme effectue un traitement en fonction d'un numéro de département. Pour le département 75, il doit effectuer un traitement particulier pour la ville de Paris mais également effectuer le traitement standard de la région parisienne.

switch2 dep

case 67 68

   Traitement("Alsace") 

case 75

   Traitement("Ville de Paris")  

   Continue 

case 93 94 78

   Traitement("Région parisienne")  

endswitch
