DictionaryModify Famille  Thème

DictionaryModify permet de changer la valeur d'un élément du dictionnaire ou de l'ajouter s'il n'existe pas.

Long DictionaryModify ( ident, clé, élément )

Paramètres

Ident

Identifiant du dictionnaire

Clé

Clé de l'élément à modifier. Si la clé n'existe pas dans le dictionnaire, un nouvel élément est alors ajouté.

Élément

Nouvelles données associées à la clé.

 

Retour

-1

Ticket invalide

0

Pas d'erreur
