SocketSend  Famille   Thème

La fonction SocketSend permet d’envoyer des caractères à l’ordinateur distant.

Int = SocketSend ( socket , données , [ options ] )

 

Paramètres

Socket

Socket obtenu par la fonction SocketNew .

Données

Données à émettre.

Options

Paramètre facultatif. (0 par défaut).

 

Retour

-1

Erreur. Voir SocketLastError

Autre

Nombre d’octets émis.
 

Exemples

Nb = SocketSend (sock, "bonjour")
