WinGetLastError  Famille Thème

 

La fonction WinGetLastError retourne le dernier code d'erreur pour le programme en cours.

La plupart des fonctions de Windows retournent un booléen indiquant si l'exécution de la fonction s'est terminée normalement. En cas d'erreur, la fonction WinGetLastError permet de détailler l'erreur qui a eu lieu.

Après l'appel des fonctions LC (client léger) il faut appeler LCWinGetLastError pour récupérer le code d'erreur coté client.

 

Long WinGetLastError

 

Retour

La fonction retourne le dernier code d'erreur du processus.

 

Remarques

Les codes retournés par WinGetLastError ne sont pas forcément les mêmes pour tous les systèmes d'exploitation.

Vous devez appeler la fonction WinGetLastError immédiatement après la fonction qui a signalé une erreur.

La liste des erreurs se trouve dans le fichier Winerror.h.

La fonction WinGetTextError permet d'obtenir un texte correspondant au numéro d'erreur.
