FileBox  Famille Thème

 

Cette fonction permet d'appeler la boîte de dialogue d'ouverture de fichiers d'Harmony.

 

Long = FileBox (StructureFileBox, FichierAOuvrir, [ FonctionFiltre ])

 
Paramètres

StructureFileBox

Instance de l'enregistrement Efilebox du dictionnaire ddsys.dhsd. Cette structure contient tous les paramètres d'appels de la boîte de dialogue.

FichierAOuvrir

Variable alpha recevant en retour le nom du fichier sélectionné.

FonctionFiltre

Adresse d'une fonction (obtenue par GetAdressFunction) qui permet de filtrer les fichiers à afficher. Avant d'ajouter un fichier à la liste, cette fonction est appelée et elle doit retourner TRUE pour que l'élément soit ajouté. La fonction doit impérativement retourner une valeur de type L. Cette fonction a un paramètre qui est une instance de eldir (voir DirRead)

Si cette fonction a besoin d'ouvrir le fichier, elle doit appeler la fonction FileBoxGetPath qui donne le chemin du fichier.

Exemple :

function long filtre(elt) ; filtre les fichiers modifiés

record ddsys.dhsd eltdir elt ; entre 2001 et 2002

beginf

; si la fonction doit ouvrir le fichier

; il faut ecrire tdf.name = FileBoxGetPath & '/' & elt.Nom

   if (elt.datemod > "2001" and elt.datemod < "2002") 

      freturn true 

   else | freturn FALSE 

   endif 

 

endf

 

Retour

FALSE

Pas de fichier sélectionné

TRUE

Un fichier a été sélectionné. Son nom est dans FichierAOuvrir.
 

Structure EFileBox

Fbtitre

Titre de la boîte de dialogue.

FbFiltre

Donnée contenant des paires de filtres séparés par le caractère "|". Le premier membre de chaque paire décrit un filtre (par exemple, "Fichiers texte"), et le second membre spécifie le filtre à appliquer pour sélectionner ces fichiers (par exemple, "*.txt").
Plusieurs filtres peuvent être précisés pour une seule description en séparant les filtres par des points virgule. (par exemple, "*.dhsp;*.dhsf;*.dhsi").
Exemple : filtre = "Sources|*.dhsp;*.dhsf;*.dhsi|masques|*.dhsf;*.dhsi|diva|*.dhsp|*.*|*.*"

Fbifiltre

Numéro d'ordre du filtre sélectionné à l'ouverture de la boîte de dialogue.

Fbficdep

Fichier à proposer à l'utilisateur.

Fbrepdep

Répertoire de départ. La boîte de dialogue s'ouvre en affichant les fichiers de ce répertoire.

Fbextdef

Extension par défaut. Si l'utilisateur ne précise pas d'extension, cette extension est automatiquement ajoutée.

Fbiimpli

Indice dans la liste des chemins implicites de la tâche. Si Fbrepdep (répertoire de départ) n'est pas positionné, la boîte de dialogue s'ouvre en affichant les fichiers du répertoire implicite demandé.

FbFlags

Drapeaux (combinaison des valeurs suivantes par addition)

HAR_NOCHANGEDIR

L'utilisateur n'a pas le droit de changer de répertoire. Le bouton permettant de remonter dans le répertoire parent est caché.

HAR_CHANGEIMPLIONLY

L'utilisateur peut changer de répertoire en utilisant uniquement les chemins implicites. Le bouton permettant de remonter dans le répertoire parent est caché.

HAR_FILEMUSTEXIST

Le fichier retourné par la fonction doit obligatoirement exister.

HAR_FILEMUSTNOTEXIST

Le fichier ne doit pas exister. Cette valeur doit être utilisée conjointement avec HAR_FOR_SAVE.

HAR_NOBUTTONIMPLI

Le bouton permettant de modifier les chemins implicites est caché.

HAR_BUTTONSEEK

Le bouton appelant la recherche de fichiers par xtools est affiché.

HAR_USERFILTER

Le champ Filtre et le bouton Actualiser sont affichés/

HAR_ALLOWMULTISELECT

L'utilisateur peut sélectionner plusieurs fichiers.
En retour, la variable FichiersAOuvrir contient la liste des fichiers séparés par le caractère $00 et terminée par un double $00. Voir exemple ci-dessous.

 
Fbop

Opération.

HAR_FOR_OPEN

Fonctionnement standard de la boîte de dialogue.

HAR_FOR_SAVE

Le bouton "Ouvrir" devient "Enregistrer".

De plus, si l'utilisateur sélectionne un fichier existant, une confirmation de remplacement est demandée.

 

Fbtri

Sens de tri de la liste des fichiers.

SORT_BY_NAME

Tri par nom

SORT_BY_SIZE 

Tri par taille

SORT_BY_DATE

Tri par date de modification

SORT_BY_TYPE

Tri par type (d'après l'extension)

 

Fblike

Filtre sur les noms de fichiers. Ce filtre peut contenir les caractères jocker * et $.

Exemple : g*3.* = tous les fichiers dont le nom commence par g, se termine par 3 et avec une extension quelconque.

 

 

Exemple

1 aouvrir 256

record 'ddsys.dhsd' efilebox ef

main

ef.fbtitre = "Ouverture de fichier"

ef.fbfiltre = "Sources|*.dhsp;*.dhsf;*.dhsi|masques|*.dhsf;*.dhsi|diva|*.dhsp|*.*|*.*"

ef.fbifiltre = 1 ; filtre sources par défaut

ef.fbop = HAR_FOR_OPEN ; pour lecture

ef.fbflags = HAR_FILEMUSTEXIST; le fichier doit exister

ef.fbtri = SORT_BY_NAME ; tri par le nom

ef.fbficdep = "sp.dhsp" ; fichier proposé

ef.fbextdef = ".dhsp" ; extension par défaut

ef.fbiimpli = 2 ; départ sur le 2ème chemin implic.

if filebox(ef,aouvrir)

display aouvrir 

endif

 

;-------------------------------------------------------------------------------------

;Exemple avec multi-sélection

1 aouvrir S

1 pos     L

1 oldpos  L

record 'ddsys.dhsd' efilebox ef

main

ef.fbtitre = "Ouverture de fichier"

ef.fbfiltre = "Sources|*.dhsp;*.dhsf;*.dhsi|masques|*.dhsf;*.dhsi|diva|*.dhsp|*.*|*.*"

ef.fbifiltre = 1                                      ; filtre sources par défaut

ef.fbop = HAR_FOR_OPEN                                ; pour lecture

ef.fbflags = HAR_FILEMUSTEXIST + HAR_ALLOWMULTISELECT ; le fichier doit exister + multi sélection

ef.fbtri = SORT_BY_NAME                               ; tri par le nom

ef.fbextdef = ".dhsp"                                 ; extension par défaut

ef.fbiimpli = 2                                       ; départ sur le 2ème chemin implic.

if filebox(ef,aouvrir) = TRUE

   pos = 0

   do                                                 ; balayage des résultats

      oldpos = pos + 1

      pos = string($00,aouvrir, ++pos)

   while pos <> 0 and pos <> oldpos

      display mid(aouvrir, oldpos, pos - oldpos)

   wend

endif
