WinDivaltoGlobalDelete - WinDivaltoDelete Famille Thème

L'instruction WinDivaltoDelete permet de supprimer une valeur du registre sous la clé "HKEY_CURRENT_USER\SOFTWARE\Divalto\divalto.ini\"

L'instruction WinDivaltoGlobalDelete permet de supprimer une valeur du registre, sous la clé "HKEY_LOCAL_MACHINE\SOFTWARE\Divalto\divalto.ini\"

 

Ces instructions se trouvent dans le module ysystemex.dhop.

 

WinDivaltoDelete (section, entrée)

WinDivaltoGlobalDelete (section, entrée)

 

Paramètres

Section

Sous chemin dans le registre.

Entrée

Nom de la valeur à supprimer.

  

Voir

LCWinDivaltoDelete, WinRegDeleteKey
