HSelectPrinter

La fonction HSelectPrinter permet de charger un modèle d'imprimante.


Numer HSelectPrinter (modèle, mode, [ temporaire ])


Paramètres


Modèle

Modèle d'imprimante à charger.

Mode

MODELE_CONSEILLE

Le modèle est conseillé, c'est à dire que le menu pourra sélectionner un autre modèle le temps de l'exécution d'un programme.

MODELE_IMPERATIF

Le modèle est impératif, c'est à dire que le menu ne peut pas le modifier.


Temporaire

TRUE

Le modèle d'origine sera restauré à la fin du programme (retour au menu)

FALSE

Le modèle d'origine ne sera pas restauré à la fin du programme (valeur par défaut).

 

Retour

E_MODELE_TRANSPARENCE

Le mode transparence est interdit sous Windows. Voir la définition du modèle. 

E_MODELE_VIDEOVIDE

Le fichier (fihxxxx) est vide.

E_MODELE_ERRVIDEO

Le fichier (fihxxxx) est erroné.

E_MODELE_OPENVOIE

Erreur d'ouverture de la voie série ou parallèle.

E_MODELE_ERRVIDEO1

Erreur lors du chargement du fichier vidéo

E_MODELE_MODPRINTER

Erreur lors du chargement du modèle.

E_MODELE_ERRFIMP 

Erreur sur le fichier Fprinters

E_MODELE_MODELEABSENT

Modèle absent

 


Remarque

En cas d'erreur, la fonction affiche une fenêtre d'alerte. Voir SelectPrinter qui n'affiche pas de message.

 

Exemple

st = HSelectPrinter("test",MODELE_CONSEILLE)
