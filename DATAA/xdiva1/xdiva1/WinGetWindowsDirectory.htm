WinGetWindowsDirectory  Famille Thème

 

La fonction WinGetWindowsDirectory retourne le chemin du répertoire de Windows. Le répertoire de Windows contient entre autres les applications système, les fichiers d'initialisation et les fichiers d'aides.

Alpha WinGetWindowsDirectory

 

Retour

La fonction renvoie le chemin du répertoire Windows.
