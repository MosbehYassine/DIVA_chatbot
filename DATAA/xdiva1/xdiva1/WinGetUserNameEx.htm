WinGetUserNameEx  Famille Thème

 

La fonction WinGetUserNameEx donne le nom de l'utilisateur courant. Elle permet de spécifier le format du nom retourné.

 

Alpha WinGetUserNameEx ( Format)

 

Paramètres

Format

Valeur indiquant le format du nom. Les valeurs possibles sont :

0 : NameUnknown

1 : NameFullyQualifiedDN

2 : NameSamCompatible

3 : NameDisplay

6 : NameUniqueId

7 : NameCanonical

8 : NameUserPrincipal

9 : NameCanonicalEx

10 : NameServicePrincipal

12 : NameDnsDomain

 

Retour

La fonction renvoie le nom de l'utilisateur courant au format demandé.
