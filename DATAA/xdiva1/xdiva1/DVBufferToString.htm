DVBufferToString  Famille  Thème

La fonction DVBufferToString permet de récupérer tout le contenu du DVBuffer. La chaîne récupérée peut ensuite être transmise à un autre programme. Le programme destinataire peut ensuite initialiser un nouveau DVBuffer avec cette chaîne et lire les données qu'il contient.

 

Long  DVBufferToString  (  id , valeur )

 

Paramètres

Id

Identifiant de DVBuffer obtenu par DVBufferGetId.

 

Valeur

Variable (de type S en général) recevant le contenu du DVBuffer.

 

Retour

0

Pas d'erreur

-1

Identifiant invalide
