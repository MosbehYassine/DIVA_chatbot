SetLanguageData Famille Thème

 

La fonction SetLanguageData permet de positionner le code langue de base pour les champs multilingues.

Ce code langue indique dans quelle langue sont les champs écrits dans les fichiers.

Par défaut, le code langue de base provient du fichier paramètres TranslateParams.tx (LanguageBaseData).

 

Alpha SetLanguageData ( CodeLangue )

 

Paramètre

CodeLangue

Nouveau code langue pour les champs multilingues.

 

Remarques

  • Le code langue positionné par SetLanguageData concerne la tâche en cours. Il se transmet lors de l'enchaînement (ProgramGoto) et de l'appel (ProgrammCall) de programmes.

  • Pour désactiver la traduction des champs multilingues; il suffit d'écrire :
    1  FormatDate 1
    SetLanguageData(GetLanguageCode(FormatDate))             

    On dit que la langue de base des champs multilingues est la langue de l’utilisateur courant.

 

Retour

La fonction retourne l'ancienne valeur du code langue.
