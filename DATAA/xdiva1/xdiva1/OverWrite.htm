OverWrite  Famille Thème

 

La déclarative OverWrite indique que le module courant est un module de surcharge et donne le nom du module surchargé. Le compilateur vérifie que la correspondance exacte des prototypes des fonctions surchargées.

OverWrite nom

Paramètres

Nom

Nom (objet compilé) du module surchargé. Si le module a une extension, elle doit obligatoirement être précisée.
