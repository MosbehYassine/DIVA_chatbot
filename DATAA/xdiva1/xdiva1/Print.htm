Print  Famille 

 

Print permet d'imprimer du texte.
Il n'est pas possible d'utiliser l'instruction Print si le programme utilise des masques d'impression harmony.

 

Print expression [sauts]

Paramètres

Expression

Chaîne de caractères à imprimer.

Sauts

Sauts est le nombre d'interlignes à sauter une fois que l'impression de l'expression a été effectuée.
Si sauts est omis, la valeur prise par défaut est 1, c'est-à-dire que l'imprimante passe à la ligne suivante.
Si sauts vaut 0 le PRINT suivant commencera donc sur la même ligne.

Print est souvent utilisé avec les crochets de concaténation [].

Les fonctions d'impression sont utilisables au travers des champs suivants de l'enregistrement System :

fonction

nom

Expansé début

expnd

Expansé fin

eoe

Comprimé début

compr

Comprimé fin

eoc

Normaux début

norm

Normaux fin

eonc

Jeu 1 début

abc1

Jeu 1 fin

eoa1

Jeu 2 début

abc2

Jeu 2 fin

eoa2

Graphique 1 début

gra1

Graphique 1 fin

eog1

Graphique 2 début

gra2

Graphique 2 fin

eog2

Qualité courrier début

qualt

Qualité courrier fin

eoq

Les attributs restent valides jusqu'à ce que la fonction de fin soit envoyée.

 

Exemples

print 'bonjour' *

print [ $0C 'Liste du fichier ' FE *10 'Page ' page ] 2
