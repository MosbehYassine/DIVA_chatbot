Structure

La déclarative Structure permet de définir l'équivalent d'une Table Mémoire du dictionnaire de données. L'instanciation d'une structure se fait par l'instruction RecordDiva.

Les données instanciées par RecordDiva sont similaires à celles instanciées par Record à une seule restriction près : les Structures ne peuvent pas être vues dans les masques.

 

[public] Structure NomStructure [ Taille ]

....

EndStructure

 

La déclaration d'une structure est bornée par les mots-clés : Structure et EndStructure.

Le mot-clé Public indique que la structure peut être utilisée par un autre module.

Le paramètre Taille est facultatif. S'il n'est pas précisé, le compilateur la calcule automatiquement.

 

Déclaration des champs de la structure

Les champs de la structure peuvent être soit :

  • une déclaration par niveau. Comme pour les tables du dictionnaire, les champs ne peuvent être de type S (string).
    Le nom de la donnée est obligatoire, on ne peut avoir un numéro de niveau suivi d'une taille.

  • une déclaration par Record.
    Si le paramètre Var est spécifié, il devient un préfixe qui est ajouté à tous les champs.

  • une déclaration par RecordDiva.
    Si le paramètre Var est spécifié, il devient un préfixe qui est ajouté à tous les champs.

  • Une structure ne peut pas contenir de RecordSql.

Exemple 1

Structure Element

1 Nom  30

1 Prenom 30

EndStructure

 

RecordDiva Element              ; déclaration d'une instance

 

;On peut ensuite écrire

Element.Nom = ...

Element.Prenom = ...

 

Exemple 2 : ajout d'une table de dictionnaire dans une structure

Structure Element

1 Nom  30

1 Prenom 30

Record odfdd.dhsd client

EndStructure

 

RecordDiva Element

 

;on peut ensuite écrire

Element.Nom = ...

Element.Prenom = ...

;champs de la table client

Element.Adrcli = ...

Element.Ce = ...

Element.client = ...

Element.Codecli = ...

Element.Postalcli = ...

Element.Societe = ...

Element.Villecli = ...

 

 

Exemple 3 : ajout d'une table de dictionnaire dans une structure avec un préfixe

Structure Element

1 Nom  30

1 Prenom 30

Record odfdd.dhsd client cc_

EndStructure

 

RecordDiva Element

 

;on peut ensuite écrire

Element.Nom = ...

Element.Prenom = ...

;champs de la table client

Element.cc_Adrcli = ...

Element.cc_Ce = ...

Element.cc_client = ...

Element.cc_Codecli = ...

Element.cc_Postalcli = ...

Element.cc_Societe = ...

Element.cc_Villecli = ...

  

 

Exemple 4 : ajout d'une structure définie dans un module externe

 

;---------------- Module1.dhsp ----------------------

Public Structure StructurePublique

1 sp1 10

1 sp2 X

EndStructure

 

;---------------- Programme_principal.dhsp ----------

Module module1.dhop

Structure Element

1 Nom  30

1 Prenom 30

RecordDiva module1.StructurePublique

EndStructure

 

RecordDiva Element

 

;on peut ensuite écrire

Element.Nom = ...

Element.Prenom = ...

Element.sp1 = ...

Element.sp2 = ...

Element.StructurePublique = ...

 

Exemple 5 : initialisation d'une donnée structurée par une fonction

Structure Element

1 Nom  30

1 Prenom 30

1 Liste L

1 Compteur X

EndStructure

 

Function char InitElement        

;fonction d'initialisation pour la structure Element

RecordDiva Element Elem

beginf

   elem.Liste = ListCreate

   elem.Compteur = 1

   freturn elem

endf

 

RecordDiva Element = InitElement()   ; instanciation et initialisation
