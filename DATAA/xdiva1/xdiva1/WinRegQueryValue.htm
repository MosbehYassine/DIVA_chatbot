WinRegQueryValue  Famille Thème

 

La fonction WinRegQueryValue permet de lire une valeur dans le registre Windows.

Cette fonction se trouve dans le module ysystemex.dhop.

  

Ptr WinRegQueryValue ( clé, sous_clé, buffer)

 

Paramètres

Clé

Clé à chercher.

Sous_clé

Sous-clé dont on veut connaître la valeur. Si sous-clé est à espaces, la valeur de la sous-clé Défaut est retrounée.

Buffer

Zone de réception.

  

Retour

0

Clé ou sous_clé inexistante.

autre

Nombre de caractères écrits dans buffer.

  

Exemple

module "ysystemex.dhop"

1 buffer 200

main

display WinRegQueryValue("HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\App Paths\Winword.exe"," ",buffer)

display buffer

display WinRegQueryValue("HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\App Paths\Winword.exe","path",buffer)

display buffer
