StructureOpenFile  Famille Thème

 

Cette structure est utilisée par les fonctions WinGetOpenFileName et WinGetSaveFileName.

 

1 SopenFile         700

2 Flags             L 

2 Filtre            256 

2 IndexFiltre       X 

2 IndexNom          X 

2 IndexExtension    X 

2 RepertoireInitial 256 

2 Titre             80 

2 ExtensionDefaut   4 

Membres

Flags

Spécifie les options de création de la boîte de dialogue. Flags est une combinaison des valeurs suivantes :

 

OFN_ALLOWMULTISELECT 

Autorise la sélection multiple. Au retour de la fonction, la donnée réceptrice reçoit le nom du répertoire puis la liste de tous les fichiers sélectionnés, chaque fichier étant terminé par le caractère $00. La fin de la liste est marqué par deux caractères nuls $00 $00. Le flag OFN_EXPLORER doit également être positionné.
 
OFN_CREATEPROMPT 

Spécifie que la boîte de dialogue doit demander une confirmation si l'utilisateur veut ouvrir un fichier qui n'existe pas. (Ce flag utilise automatiquement les flags OFN_PATHMUSTEXIST et OFN_FILEMUSTEXIST).

 

OFN_EXTENSIONDIFFERENT 

Spécifie que l'utilisateur peut sélectionner un fichier dont l'extension est différente de celle spécifiée dans ExtensionDefaut.

 

OFN_FILEMUSTEXIST 

Spécifie que l'utilisateur ne peut taper que le nom d'un fichier existant. Si ce flag est spécifié et que l'utilisateur saisit un nom de fichier invalide, une boîte d'alerte est affichée. Si ce flag est spécifié, le flag OFN_PATHMUSTEXIST est également utilisé.

 

OFN_HIDEREADONLY 

Spécifie que la case à cocher "Ouvrir en lecture" n'apparaît pas dans la boîte de dialogue.

  

OFN_NOCHANGEDIR 

Indique que le répertoire courant doit être restauré après l'appel de la boîte de dialogue.

 

OFN_NOLONGNAMES 

Spécifie que les fichiers ayant un nom long ne sont affichés.

 

OFN_NONETWORKBUTTON 

Cache et invalide le bouton "Réseau".

 

OFN_NOREADONLYRETURN 

Spécifie que le fichier sélectionné ne soit pas en lecture seule et qu'il ne soit pas dans un répertoire protégé en écriture.

   

OFN_PATHMUSTEXIST 

Spécifie que l'utilisateur ne peut taper que des chemins et des noms de fichiers valides. Si ce flag est utilisé et que l'utilisateur saisit un nom incorrect, une boîte d'alerte est affichée.

 

OFN_READONLY 

Coche la case à cocher "Ouvrir en lecture". En retour, ce flag indique l'état de la case à cocher.

   

 

Filtre

Donnée contenant des paires de filtres séparés par le caractère "|". Le premier membre de chaque paire décrit un filtre (par exemple, "Fichiers texte"), et le second membre spécifie le filtre à appliquer pour sélectionner ces fichiers (par exemple, "*.TXT"). Plusieurs filtres peuvent être précisés pour une seule description en séparant les filtres par des points virgule. (par exemple, "*.TXT;*.DOC;*.BAK"). Exemple :

filtre = "Sources|*.cpp;*.hpp|includes|*.hpp|sources C|*.cpp|*.*|*.*"

 IndexFiltre

Donnée numérique qui spécifie le filtre à utiliser lors de l'ouverture de la boîte de dialogue. Cette donnée indique une paire dans la donnée Filtre. La première paire correspond à l'indice 1.

IndexNom

En retour, spécifie un offset (à partir de 1) indiquant le début du nom du fichier dans la chaîne contenant le résultat. Par exemple, si le nom du fichier retourné est "c:\dir1\dir2\file.ext", ce champ vaut 13.

IndexExtension

En retour, spécifie un offset (à partir de 1) depuis le début du chemin complet jusqu'à l'extension du fichier. Par exemple, si le nom du fichier retourné est "c:\dir1\dir2\file.ext", ce champ vaut 18.

RepertoireInitial

Indique le répertoire par défaut. C'est le contenu de ce répertoire qui est affiché à l'ouverture de la boîte de dialogue. Si ce champ n'est pas précisé, le système utilise le répertoire courant comme répertoire initial.

Titre

Spécifie le titre affiché dans la barre de titre de la boîte de dialogue. Si ce champ est à espaces, le système utilise les titres par défaut (Ouvrir, Enregistrer).

ExtensionDefaut

Contient l'extension par défaut. Si l'utilisateur n'a pas saisi d'extension, les fonctions WinGetOpenFileName et WinGetSaveFileName ajoutent cette extension au nom du fichier. Seuls les trois premiers caractères de ce champ sont significatifs. Ce champ ne doit pas contenir le point (.).
