SIVerifParam  Famille Thème

 

Cette fonction permet de vérifier le paramétrage des clés d'un fichier séquentiel-indexé.
Le paramétrage doit être préalablement chargé dans un tableau. Cette fonction peut être utilisée avant de modifier les paramètres d'un fichier séquentiel-indexé.

 

Long = SiVerifParam (Clés)

 
Paramètres

Clés

Description des clés.

Instance de l'enregistrement Cles du dictionnaire ddsys.dhsd (voir format).

 

Retour

TRUE

Paramétrage correct

FALSE

Paramétrage incorrect
 

Remarque

Cette fonction est implicitement appelée lors de la création ou de la modification d'un fichier séquentiel-indexé.

 

Exemple

record 'ddsys.dhsd' cles

1 st  X

main

init cles = $00 

cles.LettreCle(1) = 'A' 

cles.poscle(1,1) = 1 

cles.lgcle (1,1) = 10 

st = SiVerifParam(cles)
