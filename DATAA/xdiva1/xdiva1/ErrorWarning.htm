ErrorWarning  Famille Thème

 

Cette intruction permet d'afficher la fenêtre des erreurs d'Harmony avec l'icone Point d'exclamation. Le programme se continue ensuite normalement

Les seules différences avec l'instruction ErrorFatal sont :
- l'affichage de l'icone Point d'exclamation,
- le programme n'est pas interrompu.
