ToHexa  Famille 

 

La fonction ToHexa permet de convertir en hexadécimal n'importe quel type de données. Les données de type L et X sont automatiquement mis dans l'ordre poids forts – poids faibles.

 

Alpha ToHexa (variable , [format])

 

Paramètre

Variable

Donnée à afficher en hexadécimal.
Les données de type X ou L sont tout d'abord retournées au format poids forts – poids faibles.

Les données de type numérique sont tout d'abord traduites en type L.

Les données des autres types sont converties telles quelles.

Format

Donnée numérique pouvant prendre les valeurs de 0 à 3.

- 0 : aucun formatage sur la donnée

- 1 : un préfixe est ajouté devant la valeur hexadécimale (0L, 0x, $)

- 2 : la valeur hexadecimale est formatée avec un espace après chaque groupe de deux caractères.

- 3 : Combinaison de 1 (préfixe) et formatage avec des espaces (2).

 
Retour

La fonction retourne une chaîne de caractères hexadécimale.

Exemples

1 ilong  L = 2

1 inumer 12,2 = 65535

1 ibin   B = 33

1 chaine 2 = "AB"

display tohexa(ilong)   ; --> 00000002

display tohexa(ilong,1) ; --> 0L00000002

display tohexa(ilong,2) ; --> 00 00 00 02

display tohexa(ilong,3) ; --> 0L00 00 00 02

 

display tohexa(inumer+1,1) ; --> 0L00010000

 

display tohexa(ibin)     ; --> 21

 

display tohexa(chaine,0) ; --> 4142

display tohexa(chaine,1) ; --> $4142

display tohexa(chaine,2) ; --> 41 42

display tohexa(chaine,3) ; --> $41 42
