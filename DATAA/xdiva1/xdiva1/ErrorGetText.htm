ErrorGetText  Famille Thème

 

Cette fonction permet de récupérer le texte correspondant à une erreur.

 
char ErrorGetText (code, [param])

 
Paramètres

Code

Code d'erreur à interpréter.

Param

Donnée alphanumérique (espace par défaut) qui est incorporée au texte du message (par exemple un nom de fichier).


Retour

La fonction retourne le texte de l'erreur.


Exemple

display ErrorGetText(0x14,"monfichier")

affiche : Fichier monfichier absent ou inaccessible
