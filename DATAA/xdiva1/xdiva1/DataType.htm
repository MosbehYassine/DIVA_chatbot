DataType

La fonction DataType permet de connaître le type exact d'une donnée.

 

Long DataType (Donnée)

 

Retour

DataType retourne le type donnée. La valeur retournée correspond à la valeur interne de l'exécuteur Diva.

Les valeurs possibles sont :

2

Numérique

3

Alphanumérique ou String

6

Type B

7

Type X

9

Type L

99

Format interne de calcul. Il est conseillé de transférer une telle donnée dans une donnée numérique.

Remarque

Cette fonction peut être utile dans les fonctions/procédures pour connaître le format exact d'un paramètre formel.

 

Exemple

Procedure proc(p1)

1 p1 U

1 type 8,0

beginp

   type = DataType(p1) 

   display type 

endp

 

1 v1 10

1 v2 B

1 v3 X

1 v4 L

1 v5 10,2

main

proc (v1) 

proc (v2) 

proc (v3) 

proc (v4) 

proc (v5) 

proc (v5 + 1) ; format de calcul interne à diva 

Ce programme affiche les valeurs suivantes : 1 2 3 4 5 6
