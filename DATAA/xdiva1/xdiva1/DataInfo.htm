DataInfo  Famille  Thème

La structure DataInfo du dictionnaire H3fdd est utilisée par la fonction DDNextData3 qui permet de lire les caractéristiques d'uns donnée dans le dictionnaire.

Les champs de DataInfo sont :

nom

Commentaire

type

Contient la lettre D

niveau

Niveau

mnemo

Mnémonique

libdata

Libelle donnée

dtcreat

Date de création

dtmodif

Date de modification

cdutil

Code utilisateur

conf1

Confidentialités aff/imp

conf2

Confidentialités mod/sup

tailleelem

Taille d'un élément

nbsdon

Nombre de sous données

datfiller1

Filler

datapack

Contient D si la donnée appartien à la zone packée

datanat

Nature :

 

1

Numérique avec décimales variables

 

2

Numérique

 

3

Alpha-numérique

 

4

Date

 

5

1 Caractère

 

6

Type B

 

7

Type X

 

8

Binaire N octets

 

9

Type L

datadeci

Nombre de décimales

datacvmin

Conversion min->maj

datasaisie

Saisie autorisée

nbdim

Nombre de dimensions

tabdim

Tableau des dimensions

tabenj

Tableau des enjambées

dataoffset

Offset dans l'enregistrement.

tailletot

Taille totale (différente de Tailleelem si la donnée est un tableau)

datavisi

1 = visible
