PtrRecord  Famille Thème

 

La fonction PtrRecord permet d'obtenir l'adresse d'un enregistrement à partir de son nom.

 

Long PtrRecord (nom_enregistrement)

 

Paramètre

Nom_enregistrement

Donnée alphanumérique contenant le nom de l'enregistrement.

 

Retour

0

Erreur, enregistrement non trouvé

Autre

Adresse de l'enregistrement. L'enregistrement doit préalablement avoir été déclaré Public ou Protected par un module.
 

Exemple

1 adr L

; recherche de l'adresse de eimp 

adr = PtrRecord("eimp")  

if adr = 0 

   Abort("Enregistrement non trouvé") 

endif 

; modification de l'enregistrement 

mid(PtrData(adr),1,10) = "1234567890"
