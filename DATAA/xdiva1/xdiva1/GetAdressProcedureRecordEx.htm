GetAdressProcedureRecordEx Famille Thème

 

La fonction GetAdressProcedureRecordEx permet d'obtenir l'adresse d'une procédure liée à une table d'un fichier  en vue de son exécution par l'instruction ProcedureCall.

Rappelons qu'il est possible de définir dans le dictionnaire des fonctions qui seront appelée après chaque opération sur le fichier. L'appel est automatique si les fonctions Ixxx sont utilisées. Si les fonctions Ixxx ne peuvent être utilisées, GetAdressProcedureRecord rend possible l'appel de la fonction à la main.

 

Pour chaque table dans le fichier il est possible d'avoir une fonction qui sera exécutée

  • après lecture (read, pread, seek)

  • avant écriture (write)

  • avant réécriture (rewrite)

  • avant suppression (delete)

La fonction GetAdressProcedureRecordEx se distingue de GetAdressProcedureRecord par le fait que la tdf du fichier n'a pas été forcément déclarée par une instruction HFile.

 

Long GetAdressProcedureRecordEx (tdf, NomEnreg, operation, adresse, statsys)

 

Paramètres

Tdf

Tdf correspondant au ficher ouvert.

 

NomEnreg

Nom d'une instance publique d'enregistrement.

 

Operation

Choix de la procédure à rechercher.

"Read"

après lecture (read , pread, seek)

"Write"

avant écriture (write)

"Rewrite"

avant réécriture (rewrite)

"Delete"

avant suppression (delete)

 

Adresse

Zone alphanumérique de 16 octets qui recevra l'adresse de la fonction. Cette adresse sera utilisée pour l'appel de la fonction.

 

StatSys

Variable de type X recevant un éventuel status d'erreur.

 

Retour

0

Pas d'erreur. Adresse contient l'adresse de la procedure.

-1

Erreur lors de la lecture des caractéristiques du fichier. Voir StatSys.

-2

Le fichier ne contient pas les informations nécessaires. (Nom du dictionnaire de données + mnémonique dans le dictionnaire).

-3

NomEnreg ne correspond pas à un enregistrement public.

1

Procédure absente.

2

Module absent. Le module correspond au dictionnaire compilé (.dhod).

 

Exemple

public record testdd.dhsd arti eart

Record * htdf tdf

1 st      L

1 adr     16

1 statsys X

 

   tdf.name = "farti.dhfi"

   hopen(tdf,"P")

   st = GetAdressProcedureRecordEx(tdf,"eart","write",adr,statsys)

   if st = 0

      ProcedureCall(adr,tdf,eart,"P")

   endif
