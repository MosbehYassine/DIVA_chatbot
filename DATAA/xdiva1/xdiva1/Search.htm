Search

La fonction Search permet d'effectuer une recherche dans un tableau.

Long search ( valeur,
  tableau(),
  [ début ],
  [ fin ],
  [ test ],
  [ valeur_fin ],
  [ test_fin ] )

 

Paramètres

Valeur

Valeur à rechercher dans le tableau.

Tableau

Tableau dans lequel s'effectue la recherche. Le nom de la donnée doit être suivi de ().

Début

Paramètre facultatif indiquant l'indice de départ pour la recherche. Si début est omis ou nul, la recherche débute par la première case du tableau.

Fin

Paramètre facultatif indiquant l'indice de fin pour la recherche. Si fin est omis ou nul la recherche se fera jusqu'à la dernière case du tableau.

Test

Paramètre facultatif indiquant le test à effectuer entre la valeur recherchée et la case du tableau. La valeur par défaut est 1 (égalité).
Les valeurs prises par test sont les suivantes :

1

=

2

<

3

>

4

<=

5

>=

6

<>

7

Like

Valeur_fin

Ce paramètre associé à test_fin permet d'arrêter la recherche dans le tableau. Si le test entre la case courante et valeur_fin est vrai la recherche est terminée.

Test_fin

Test à effectuer entre la valeur de la case courante et valeur_fin. Si test_fin est omis ou nul, il n'y a aucun test d'effectué avec valeur_fin

 

Retour

0

Valeur non trouvée.

Autre

Recherche fructueuse. Indice dans le tableau de l'élément trouvé.
 

Remarques

Le type de la comparaison est fixé par le type de la donnée à rechercher dans le tableau. Si la donnée à rechercher est de type alpha, la comparaison sera alpha; si la donnée à rechercher est numérique, la comparaison sera numérique.

La comparaison alpha étant plus rapide que la comparaison numérique, il est vivement conseillé de faire une recherche de type alpha, même si la valeur recherchée est numérique (voir exemple).

 

Exemple

1 i X

1 tab 5,0*10000

1 v 5,0

 

for i = 1 to 10000

   tab(i) = i 

next

 

input "valeur a chercher = " v

display Search(str(v),tab())

Le tableau est rempli par la boucle for.

Le fait d'utiliser la fonction str passe le type de la variable à rechercher en type alpha. Les temps de recherche sont donc nettement plus courts.

Attention, l'exemple fonctionne du fait que la description de v est la même que celle d'une case du tableau, à savoir 5,0. S'il en était autrement, on ne pourrait pas utiliser la fonction str pour faire une recherche de type alpha.
