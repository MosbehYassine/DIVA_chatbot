Exemple d'utilisation des fonctions WinShell_  Thème

 

Dans l'ERP, ces fonctions sont utilisées dans la gestion des fichiers joints.

Pour rappel, lorsque le programme est utilisé par un client léger, il faut charger les fichiers localement avec LcWinDownload.

On pourrait utiliser WinShellExecute ("OPEN",left(fic),"","",SW_SHOW), mais dans le cadre des pièces jointes, on a besoin de savoir si le fichier est toujours ouvert ou/et s'il a été modifié.

Ceci n'est pas possible avec la version standard de WinShellExecute.

 

Dans le programme d'exemple suivant, on utilise WinShell_Execute pour ouvrir des fichiers.

Avant de quitter notre application, on vérifie que ceux-ci on été libérés et, s'ils ont été modifiés, on veut pouvoir les récupérer.

Pour cela, la fonction WinShell_Read permet, pour chaque fichier, de connaître l'état et, le cas échéant de retarder la fermeture de l'application tant que les fichiers ne sont pas libérés.

De plus, s'ils ont été modifiés, le programme dispose des outils pour le détecter et déclencher une récupération des fichiers mis à jour (non développé dans cet exemple).

 

 

 

module "ymapi.dhop"

;----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

define SHELL_FINI          = 1          ;le fichier est fermé

define SHELL_FINIDDE   = 2          ;la liaison dde est fermée

define SHELL_ERROR    = 3          ;le fichier est en erreur par exemple un pb droit

define SHELL_RUN         = 4          ;le fichier est en cours

define SHELL_ATTENTE  = 5         ;en cours d’utilisation

define TITRE = "test winshell"

 

;----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

1             fic                       260

1             fic2                     260

1             i                         x

1             err                      512

 

;----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

function int EstCeQueJePeutSortirDeLaFenetre

1            flagmodif                                 x

1            flagencours                             x

1            OnAttendEncoreUnPeut           x = 0

1            OnLibereLeFichier                    x = 0

1            diff                                          L

1            i                                             x

beginf

          ;le client veut sortir , on veut vérifier que le fichier est libéré et si il y a eu une modification

          ;il faut alors parcourir la liste des fichiers ouverts car on peut lancer plusieurs fichier par des appels successifs de WinShell_Execute

          ;Harmony maintient cette liste à jour, on n’a donc plus qu'à la consulter

 

          i = WinShell_BeginRead               

          if  i = 0   

               do

                     i = WinShell_Read (fic2,err,flagmodif,flagencours,diff)

               while i <> 0

                     OnLibereLeFichier = 1

                     if i <> SHELL_ERROR                                  

                          ;il y a une erreur on ne peut rien faire sur ce fichier

                          if flagencours or i = SHELL_RUN or i = SHELL_ATTENTE

                              ;il ne faut pas demander à chaque fichier

                              if OnAttendEncoreUnPeut = 0

                                   i = MessageBox("le fichier " & left(fic2) & " est en cours de modification. voulez-vous attendre un peu, le temps que vous puissiez sauvegarder le fichier et sortir de l'application ",TITRE,MB_YESNO)

                              else

                                   i = IDYES

                              endif

                              if i = IDYES

                                   OnAttendEncoreUnPeut = 1

                                   OnLibereLeFichier = 0

                              else

                                   if i = IDYES

                                        MessageBox("attention les modifications du fichier " & left(fic2) & " risquent de ne pas être prise en compte "  , TITRE,MB_OK)

                                        OnLibereLeFichier = 0   ;on ne libère pas le fichier

                                   endif

                              endif

                          else

                               if flagmodif

                                    MessageBox("le fichier " & left(fic2) & " a été modifié,il faut donc le récupérer",TITRE)

                                    ;Traiter ici la récupération des fichiers mis à jour.

                               endif

                          endif

                     endif

                     if OnLibereLeFichier and fic2 <> " "

                          WinShell_FreeFile(left(fic2))

                     endif

                wend

          endif

          if OnAttendEncoreUnPeut

                freturn 0

          endif

          freturn 1

endf

 

;----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

main

          if MapiOpen

                display "erreur"

                programexit

          endif

 

          fic = "c:\divalto\sys\DhsTelnet.txt"

          i = WinShell_Execute ("OPEN",left(fic),"","",SW_SHOW)

          fic = "c:\divalto\sys\DhsServices.txt"

          i = WinShell_Execute("OPEN",left(fic),"","",SW_SHOW)

                

label retour

          messagebox(" cliquez pour dire que vous voulez sortir de l’application ",TITRE,MB_OK)

          if EstCeQueJePeutSortirDeLaFenetre = 0

                goto retour

          endif

label fini

WinShell_FreeAllFile

MapiClose

          Programgoto " "
