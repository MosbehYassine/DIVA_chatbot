LCWinDownloadGetName  Famille Thème

 

La fonction LCWinDownloadGetName permet de connaître le nom exact qu'aura un fichier transféré par la fonction LCWinDownload.

 

long LCWinDownloadGetName ( &Fichier )

 

Paramètre

Fichier

En entrée : nom du fichier (sans le chemin)

En sortie : nom complet du fichier

 

Retour

0

Pas d'erreur

Autre

Code d'erreur système.

 

Remarques

  • LCWinDownload peut être appelée en positionnant NePasModifierNomFichierArrivee à TRUE, dans ce cas, il n'y a pas lieu d'utiliser LCWinDownloadGetName puisque le nom est figé.

  • LCWinDownload retourne le nom exact du fichier coté client.
    LCWinDownloadGetName permet donc de connaître le nom exact AVANT d'effectuer le transfert du fichier.

  • LCWinDownloadGetName peut être utilisée dans les cas suivants :

    • Pour afficher un message avec le nom complet du fichier

    • Pour vérifier les attributs du fichier de destination. L'Erp Divalto positionne le drapeau "lecture seule" de certains fichiers après le transfert. Si on veut à nouveau transférer le même fichier, il faut d'abord changer la valeur de ce drapeau. LCWinDownloadGetName permet de connaître le nom du fichier pour faire la modification de l'attribut avant la copie.
