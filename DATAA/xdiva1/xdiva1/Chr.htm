Chr

La fonction Chr retourne le caractère correspondant à un code ANSI. Elle est l'inverse de la fonction Asc.

 

Alpha = chr ( code_ANSI )

 

Paramètre

Code_ANSI

Valeur numérique correspondant à un code ANSI (entre 0 et 255).

 

Retour

La fonction revoie une donnée alphanumérique sur une position contenant le caractère correspondant au code ANSI.

 

Exemple

Ajouter 1 à tous les caractères d'une chaîne.

1 ch 40

1 i x

 

input 'donnez la chaîne : ' ch

for i=1 to length(ch)

   mid(ch,i,1) = chr (asc(mid(ch,i,1)) + 1) 

next

display ch
