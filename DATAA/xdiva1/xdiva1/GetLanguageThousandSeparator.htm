GetLanguageThousandSeparator Famille Thème

 

La fonction GetLanguageThousandSeparator retourne le séparateur de milliers associé à une langue.

 

Char GetLanguageThousandSeparator ( CodeLangue )

 

Paramètre

CodeLangue

Code de la langue

 

Retour

La fonction renvoie le séparateur de miliiers  (',' ou "." ou espace) correspondant au code de la langue.
