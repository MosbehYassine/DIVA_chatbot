XharviewGetFileXharview  Famille  Thème

L’instruction XharviewGetFileXharview permet de récuperer le nom complet du fichier temporaire contenant l’édition.

Attention : Cette instruction doit être appelée après l’instruction PrintEnd.

 

XharviewGetFileXharview (fichier)

 

Paramètres

Fichier

Variable alphanumérique qui reçoit en retour le nom du fichier temporaire contenant l’état.
