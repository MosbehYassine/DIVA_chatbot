SearchGetError Famille  Thème

La fonction SearchGetError permet de récupérer la description de la dernière erreur des fonctions Search.

 

Long  SearchGetError ( &Message  )

 

Paramètres

Message

Donnée alphanumérique recevant le texte de l'erreur.

 

 

Retour

0

La fonction retourne un code d'erreur et un libellé dans le paramètre Message
