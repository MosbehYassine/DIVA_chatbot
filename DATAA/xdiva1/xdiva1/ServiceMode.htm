ServiceMode Famille Thème

La fonction ServiceMode permet au programme courant de savoir s’il a été lancé comme un service ou comme une tâche ordinaire.

Il permet également de savoir si le programme tourne en tant que Service Web ou en tant que programme Web.

 

int ServiceMode

Retour

0

Le programme est un programme ordinaire (version Win32).

1

Le programme est un service Diva autorisé à interagir avec le bureau (c’est à dire effectuer des affichages et des saisies).

2

Le programme est un service Diva qui n’est pas autorisé à interagir avec le bureau.

3

Le programme est un service Web non autorisé à exécuter WebServiceReturn. Ce programme doit retourner le résultat via le tunnel.

4

Le programme est un service Web autorisé à exécuter WebServiceReturn.

5

Le programme est lancé par le driver Odbc.

6

Le programme est un programme Web.

7

Le programme est un programme ordinaire (version client léger Wpf ou Web).
Utilisez la fonction ServiceModeTransport pour différencier les deux types de client léger.
