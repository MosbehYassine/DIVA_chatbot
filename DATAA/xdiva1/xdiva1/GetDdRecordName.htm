GetDdRecordName

La fonction GetDdRecordName permet de retrouver le mnémonique d'une table à partir d'une instance.

 

Alpha GetDdRecordName (table)

 

Paramètres

Table

Instance d'une table

 

Retour

La fonction retourne le mnémonique de la table.

Si Table n'est pas une instance d'une table, la fonction retourne espace.

 

Exemple

procedure maproc(&tdf,&art)

1 tdf A

1 art A

1 nomrec S

1 nomfile S

beginp

   nomrec = GetDdrecordName(art) ; -> artfiltre

   nomfile = GetDDFileName(tdf)  ; -> ficfiltre

endp

 

hfile testdd.dhsd ficfiltre tdf  

public record testdd.dhsd artfiltre  wart

 

main

   Maproc(tdf,wart)
