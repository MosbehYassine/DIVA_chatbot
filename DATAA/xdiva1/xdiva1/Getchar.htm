Getchar  Famille 

 

La fonction Getchar permet de consulter le clavier. Cette fonction n'est pas bloquante, c'est à dire que le programme continue son exécution même si aucun caractère n'a été tapé.

Attention, Getchar ne fonctionne pas toute seule : il est impératif de l’encadrer des instructions GetBegin et GetEnd.

Plus exactement, en cas de boucle incluant un Getchar, il faut encadrer la boucle de GetBegin et GetEnd (voir l'exemple).

 

GetBegin demande à l'exécutable qui tourne sur le poste "client léger" de démarrer une procédure d'attente d'un événement clavier. A défaut, les caractères tapés sont "perdus".
GetEnd demande au client d'arrêter cette procédure. A défaut, la procédure risque d'intercepter des caractères qui ne lui sont plus destinés.

 

Bin = getchar  ( AvecHarmonyKey )

 

Paramètres

AvecHarmonyKey

TRUE

La fonction positionne Harmony.key. Il est conseillé d'utiliser ce mode.

FALSE

La fonction ne modifie pas Harmony.Key (valeur par défaut).
Ce mode permet d'assurer la compatibilité avec la fonction GetChar de la version 5 d'Harmony.

 

Retour

  • $00 (0 binaire) si aucun caractère n'a été tapé.

  • Sinon :
    Pour les caractères "normaux", il s'agit du code ANSI du caractère. Pour les touches spéciales, il s'agit de leur ancien code PC8 (Cf. Defines F_xxx de Zdiva), pour assurer la compatibilité des programmes conçus en versions 5 ou antérieures d'Harmony.

    Il est conseillé d'ignorer cette valeur et de plutôt tester Harmony.Key pour identifier la touche tapée     (ne pas oublier de positionner le paramètre AvecHarmonyKey à TRUE).
    En effet, toutes les touches et combinaisons de touches génèrent une valeur différente de Harmony.Key, y compris les touches "normales" (lettres, chiffres, etc.) qui génèrent la valeur K_ANSIKEY_OFFSET+nnn, où nnn est le code ANSI de la touche.

 

Remarque importante :

Une boucle sur la fonction Getchar fait monter considérablement l'utilisation du processeur. Dans une telle boucle, il est donc conseillé d'utiliser la fonction Sleep pour rendre la main au système.

Voir également la fonction Getbchar qui est bloquante et ne pénalise pas le système.

 

Exemple :

Attendre qu'un caractère soit tapé pour passer à la suite et traiter le caractère tapé :

 

GetBegin

loop getchar(TRUE) = $00

   Sleep(100) ; attente 100 milli-secondes  

endloop

GetEnd

 

switch Harmony.key

case K_F1

   display "F1"

case K_SF1

   display "Maj+F1"

case K_CTRL_SINSERT

   display "Maj+Ctrl+Insert"

endswitch
