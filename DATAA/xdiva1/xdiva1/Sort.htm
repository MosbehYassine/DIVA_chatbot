Sort

L'instruction Sort permet de trier un tableau à une dimension. La fonction de comparaison de deux éléments est écrite en Diva, ce qui permet de paramétrer un ordre de tri quelconque.

 

Sort (tableau() , [ nb_éléments ] , fonction_compare)

 

Paramètres

Tableau

Nom du tableau à trier. Le nom du tableau doit être suivi de ().

Nb_éléments

Nombre d'éléments à trier. Si ce paramètre est omis ou nul, tous les éléments du tableau sont triés.

Fonction_compare

Donnée de 16 octets contenant l'adresse de la fonction de comparaison. Cette adresse est obtenue par la fonction GetAdressFunction.
La fonction de comparaison doit avoir deux paramètres p1 et p2 de même type que les éléments du tableau. Elle doit retourner une donnée de type L avec les valeurs suivantes :

0 --> p1 > p2

1 --> p1 < p2

2 --> p1 = p2

 

Si fonction_compare est initialisée à $00, le tri est alphanumérique.

Remarque

La fonction de comparaison peut appeler SortCompare (ou SortCompareV) qui compare deux éléments et renvoie 0, 1 ou 2 suivant le résultat de la comparaison.

Sort utilise l'algorithme du "quick-sort" qui présente l'avantage d'être très rapide. Par contre, il présente l'inconvénient de ne pas être stable, c'est à dire que deux éléments dont la clé de tri est égale peuvent se trouver inverser après le tri.

 

Exemple

; Fonction de comparaison de deux éléments

function long compare(&p1,&p2)

1 p1 N

1 p2 N

beginf

   freturn (condition(p1=p2,2,p1<p2)) 

   ; ou freturn SortCompare(p1,p2)

endf

 

1 tab 10,0*10000

1 adr 16

 

main

; obtient l'adresse de la fonction de comparaison 

GetAdressFunction(" ","compare",adr) 

 

; appel du tri 

Sort(tab(),,adr)
