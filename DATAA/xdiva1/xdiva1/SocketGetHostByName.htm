SocketGetHostByName  Famille   Thème

La fonction SocketGetHostByName permet de trouver l’adresse Internet d’un serveur dont on connaît le nom.

alpha = SocketGetHostByName ( nom )

 

Paramètres

Nom

Nom du serveur. Ex : www.Divalto.fr 

 

Retour

Espace

Le nom n’a pu être résolu. Voir SocketLastError.

Autre

Adresse IP de l’ordinateur.

 

Remarque

  • La fonction SocketNew doit avoir été appelée préalablement pour initiliser l’interface socket.

 

Exemple

s = SocketNew()

display SocketGetHostByName("www.Divalto.fr") à 217.128.113.2
