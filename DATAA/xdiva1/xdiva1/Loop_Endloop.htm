Loop - Endloop  Famille

 

La structure Loop est une structure d'itération de type Tant Que

Loop expression

 instructions

Endloop

 

Dans cette structure, le test est effectué avant d'y rentrer la première fois. Donc, si la condition est fausse dès le départ, la boucle n'est jamais exécutée et le contrôle est donné à l'instruction suivant le mot réservé Endloop.

 

Exemple : Sachant que la somme : 1-1/3+1/5-1/7... tend vers PI/4, calculer PI avec 4 décimales.

const eps = 0,00001

vpi = 4

i = 1

s = -1

t = 1/3

 

loop t>eps

   t = 4/(2*i+1) 

   vpi += s*t 

   s = -s 

   i++ 

endloop

Si vous exécutez ce programme, soyez patient car le nombre de boucles à faire est impressionnant (200000).

Il vaut mieux écrire VPI = 3,14159 !!!!
