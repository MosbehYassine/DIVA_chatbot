ModuleVersion  Famille Thème

ModuleVersion est une pseudo instruction qui place un numéro de version (alphanumérique sur 8 positions) dans l'en-tête des objets.

Ce numéro de version est affiché par l'utilitaire xTools et peut être lu par programme avec la fonction ModuleInfo.

 

ModuleVersion Version

 

Paramètre

Version

Version du module (8 caractères maximum).
