LCWinUpload  Famille Thème

La fonction LCWinUpload permet de copier un fichier du client vers le serveur.

 

Long LcWinUpload (FichierDepart , &FichierArrivee , [Compression] , [CleCryptage] , [ToujoursCreer])

 

Paramètres

FichierDepart

Nom complet du fichier de départ

 

FichierArrivee

Nom complet du fichier d'arrivée. En retour de la fonction, FichierArrivee contient le nom effectif du fichier copié.

 

Compression

True pour comprimer le fichier. (FALSE par défaut)

 

CleCryptage

 Clé de cryptage. Si la clé n'est pas spécifiée ou vaut espace il n'y a pas de cryptage.

 

ToujoursCreer

True / False (par défaut)

Cette option permet de toujours créer le fichier de destination. Si un fichier existe déjà avec le même nom, le nom du fichier est suffixé par un indice.

Exemple : Rapport(2).doc

 

Retour

0

Pas d'erreur

Autre

Code d'erreur système.

 

 

Cas particulier du client léger Web

La fonction LCWinUpload est utilisable dans deux cas précis :

  • Après un drag & drop de fichiers dans la fenêtre du navigateur.

  • Après appel à la fonction WinGetOpenFileName.

Les fichiers déposés ou sélectionnés sont placés dans un flux interne au navigateur, ce qui permet ensuite de les récupérer en appelant la fonction LCWinUpload.
Attention : Ce flux n’est valide que 15 minutes.

Un appel "direct" à cette fonction en spécifiant un fichier quelconque du poste client n’est pas possible.
