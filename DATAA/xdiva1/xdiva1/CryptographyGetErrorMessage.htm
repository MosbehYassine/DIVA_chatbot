CryptographyGetErrorMessage Famille Thème

 

La fonction CryptographyGetErrorMessage() permet de récupérer un message d’erreur détaillé à partir d'un code d'erreur détaillé du module de signature numérique.

 

Alpha CryptographyGetErrorMessage( ErrorCode )

 

Paramètres

ErrorCode

Code d'erreur généré par le module de signature numérique et obtenu avec CryptographyGetLastErrorCode().

Retour

La fonction renvoie le message d'erreur détaillé.
