Iread  Famille Thème

Iread permet :

  • de lire l'enregistrement qui suit le dernier enregistrement lu,

  • de lire le premier enregistrement du fichier si aucune lecture n'a été effectuée,

  • de se positionner directement sur un enregistrement en modifiant la clé. L'enregistrement lu est alors celui ayant la clé la plus proche (supérieure ou égale) de la clé demandée (voir exemple).

 

Ptr = Iread ( tdf , table [,nomIndex] [, valeurClé ] [ ,partage ] )

Paramètres

Tdf

Table de définition de fichier.

Table

Donnée réceptrice qui contiendra l'enregistrement lu.

NomIndex

Ce paramètre est facultatif. Il permet de préciser le nom de l'index qui doit être utilisé. S'il n'est pas précisé, la lecture se fait selon l'index courant.

ValeurClé

Ce paramètre est facultatif. Si ValeurClé est spécifié, la lecture se fait à partir de cette valeur de clé. L'enregistrement lu est celui ayant la clé la plus proche (supérieure ou égale) de la clé demandée.

Partage

Mode de partage de l'enregistrement ('P' par défaut).

  

Retour

0  

Pas d'erreur. 

Si une procédure Après Read est définie dans le dictionnaire, elle est appelée.

Les paramètres passés à la procédure Après Read sont :

Tdf

La Tdf du fichier.

Table

L'enregistrement qui a été lu.

Cle

La valeur de la clé associée à l'enregistrement lu.

Partage

Le mode de partage.

Opération

Opération effectuée sur le fichier.
R = lecture du suivant (iread)
P = lecture du précédent (ipread)
S = lecture directe (iseek)

 

H_EOF  

Fin de fichier atteinte. 

H_RESERVED  

Enregistrement réservé. 

Toutes les autres erreurs provoquent l'arrêt du programme

 

Particularités pour les fichiers de type I

Fin de fichier

Si la fonction Iread retourne H_EOF (fin de fichier), un appel à la fonction Ipread délivre le dernier enregistrement du fichier d'après l'index en cours.

Sauvegarde et restauration de la clé

Après la lecture, la clé exacte lue est placée dans le champ KeyValue de la TDF. Il est possible de sauvegarder la clé avec la fonction ISaveKey, d'effectuer d'autres opérations sur le fichier, puis de restaurer la clé avec la fonction IRestoreKey afin de reprendre le traitement sur l'enregistrement suivant (voir exemple 3).

 

Remarques

Après restauration de la clé et du nom d'index la fonction Iread délivre l'enregistrement suivant, tandis que la fonction Iseek délivre le même enregistrement.

Si l'enregistrement contient une zone packée, celle-ci est automatiquement dépackée.

La fonction IFilter permet de filtrer les enregistrements.

Après l'opération de lecture, le traitement  "Après Read" défini dans le dictionnaire est exécuté.

La fonction GetLastRecord permet de récupérer le dernier enregistrement lu.

 

Exemple 1 

Lire dans le fichier des compositeurs le premier compositeur dont le nom commence par une lettre de L à Z.

st = Iread(comp, cpenr, "NOMCOMPO","L")

switch st

case H_EOF

   display "Pas de compositeur trouvé" 

case H_RESERVED

   display "Enregistrement réservé" 

endswitch

 

Exemple 2

Lire le fichier des compositeurs à partir de la lettre L. Dans ce cas, la clé doit être positionnée avant de rentrer dans la boucle.

comp.keyValue = 'L' ; positionnement clé

do

   st = Iread(comp ,cpenr ,"NOMCOMPO",,'F') 

while st = 0

   display [ cpenr.codecp " " cpenr.nom " " cpenr.prenom ] 

wend

 
Exemple 3

Cet exemple illustre l'utilisation de la sauvegarde et de la restauration de la clé dans la tdf.

Soit un fichier de factures FFAC contenant deux types d'enregistrements :
 - les entêtes (clé ENTETEFAC),
 - les lignes détail (clé DETAILFAC).

La donnée Numfac (numéro de facture) est présente dans les deux enregistrements (Entete.Numfac dans l'entête et Detail.Numfac dans la ligne détail) et sert de clé.

Après avoir lu une entête, on sauvegarde la clé; puis on change la clé pour lire les lignes détail correspondant à l'entête lue. Pour passer à la facture suivante, il faut restaurer la clé et lire l'entête suivante.

1 wcle S ; pour sauvegarder la clé

 

st = Iread(ffac, entete,"ENTETEFAC",,"F") ; lecture d'une entête

; test des codes d'erreur 

wcle = IsaveKey(ffac)           ; sauvegarde de la clé 

; lecture de toutes les lignes 

ffac.keyValue = numfac 

do 

   st = Iread(ffac, detail,"DETAILFAC",,"F") 

   ; test des codes d'erreur 

while st = 0 and Detail.Numfac = Entete.Numfac 

   ... ; traitement de la ligne 

wend 

; lecture de l'entête suivante 

IrestoreKey(ffac,wcle)           ; restauration de la clé 

st = Iread(ffac, entete,,,"F")
