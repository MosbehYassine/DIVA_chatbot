FtpRenameFile Famille Thème

 

Renommage d'un fichier sur le serveur.

 

Module "yftp.dhop"

FtpResult FtpRenameFile (server, login, password, remoteFile, newName, [proxyServer], [ProxyMode], [proxyLogin], [proxyPassword])

 

Paramètres

Server

Adresse du serveur sous la forme

ftp://ip[:port]  pour un serveur ftp

sftp://ip[:port]  pour un serveur sftp

 

Login

Identifiant sur le serveur. Si non précisé, c'est "anonymous" qui est utilisé. Dans ce cas, le serveur doit accepter les connexions anonymes.

 

Password

Mot de passe sur le serveur.

 

RemoteFile

Chemin d'accès au fichier sur le serveur.

 

NewName

Nouveau nom du fichier

 

ProxyServer

Adresse du serveur proxy

 

ProxyMode

Mode d'identification sur le proxy.

1

Prendre les paramètres du système. Il n'y a pas d'autre paramètres à préciser, l'authentification est celle du poste de travail.

2

Préciser l'url du serveur, mais authentification SSPI. Inutile de préciser ProxyLogin et ProxyPassword

3

Mode manuel. Il faut préciser tous les paramètres

 

ProxyLogin

Identifiant sur le serveur proxy.

 

ProxyPassword

Mot de passe sur le serveur proxy.

 

Retour

La fonction retourne une structure FtpResult de trois valeurs.

Status

0 = pas d'erreur   2 = Erreur      3 = paramètres incorrects

Retour

Texte renvoyé par la dll

Desc

Texte rendu par le serveur ou description de l'exception en cas d'erreur. Voir aussi FtpGetLastErrorMessage

 

Remarques

  • De nombreux serveurs Ftp / Sftp sont sous Unix ou Linux. Sur ces systèmes d'exploitation, les noms de fichiers sont sensibles à la casse.
    Le paramètre RemoteFile doit donc avoir la casse exacte.

  • En fonction de la configuration du serveur, il se peut que les caractères spéciaux et accentués posent problème.

  • Cette fonction permet aussi de déplacer un fichier d'un répertoire à un autre. Le répertoire destination doit exister et l'utilisateur doit avoir au moins la permission "Rename" au niveau du serveur ftp.

Exemple

module "yftp.dhop"

recordDiva yftp.FtpResult  r

; Renommage du fichier xrtdiva.exe en xrtdiva_renomme.exe

r = FtpRenameFile("ftp://psxbdbh02", login, password, "xrtdiva.exe", "xrtdiva_renomme.exe")

; Déplacement d'un fichier nommé fichier1.xml dans le sous-répertoire subdir.

r =  FtpRenameFile(server, login, password, "fichier1.xml", "subdir/fichier1.xml")

ProgramExit
