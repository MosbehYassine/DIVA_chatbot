HFileCheckVersion  Famille Thème

La fonction HFileCheckVersion permet de contrôler la version d’un fichier ouvert.

Par défaut, le contrôle des versions s’effectue à l’ouverture du fichier lors du chargement du module.

Si le fichier a été ouvert par une fonction Hopen ou Fopen, le contrôle peut être effectué à la main avec HFileCheckVersion. Voir Version des fichiers .

 

Int HFileCheckVersion (tdf , flag_abort, mess)

 
Paramètres

Tdf

Tdf d'un fichier ouvert .

 

Flag_Abort

Booléen indiquant si le programme doit être interrompu en cas d’erreur.

 

Mess

Variable recevant un éventuel message d’erreur.

 

Retour

0

Pas d’erreur.

12

Le fichier n’est pas ouvert.

5734

Le numéro de la base physique ne correspond pas au numéro fourni par le dictionnaire lors de la compilation.

5736

Le dictionnaire ne précise aucun numéro de version mais le drapeau « Toujours contrôler la version » est positionné.
 

Exemple

1 status X

1 rep 1

 

status = fopen(tdf,’P’)

if status = 0

   HFileCheckVersion(tdf,TRUE,rep) 

endif
