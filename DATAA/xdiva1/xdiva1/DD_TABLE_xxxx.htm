DD_TABLE_xxxx  Famille  Thème

Long DDInterface (Commande , &ticket , [paramètres] , retour, [niveau])

 

DD_TABLEBEGIN

DD_TABLEBEGIN_DD

La commande DD_TABLEBEGIN permet de se positionner sur la première table du fichier en cours. Il faut donc avoir préalablement lu un fichier par une commande DD_FILE_xxxx.

La commande DD_TABLEBEGIN_DD permet de se positionner sur la première table du dictionnaire.

 

Retour contient les caractéristiques de la table. Voir DDInterface : Tables .

 

Retour

0

pas d’erreur.

2

Pas de table dans le fichier (dictionnaire).

autre

Erreur. Voir DD_GETERROR

 

Exemple

1  ticket L 

1  reponse 8096  

1  sttable X

sttable = DDInterface(DD_TABLEBEGIN,ticket,,reponse)

 

DD_TABLEFIND

DD_TABLEFIND_DD

La commande DD_TABLEFIND permet de rechercher une table appartenant au fichier en cours. Il faut donc avoir préalablement lu un fichier par une commande DD_FILE_xxxx.

La commande DD_TABLEFIND_DD permet de rechercher une table dans le dictionnaire tout entier. Cela permet par exemple de rechercher une table mémoire.

 

Paramètres doit contenir le nom de la table à chercher.

Retour contient les caractéristiques de la table. Voir DDInterface : Tables .

 

Retour

0

pas d’erreur.

2

Table non trouvée.

autre

Erreur. Voir DD_GETERROR

 

Exemple

1  ticket L 

1  reponse 8096  

1  sttable X

sttable = DDInterface(DD_TABLEFIND,ticket,"article",reponse)

 

DD_TABLENEXT

DD_TABLENEXT_DD

La commande DD_TABLENEXT permet de lire la table suivante appartenant au fichier en cours. Il faut donc avoir préalablement lu une table par DD_TABLEBEGIN ou DD_TABLEFIND. La commande DD_TABLENEXT_DD permet de lire la table suivante dans le dictionnaire tout entier. Cela permet par exemple de balayer les tables mémoire.

 

Retour contient les caractéristiques de la table. Voir DDInterface : Tables .

 

Retour

0

pas d’erreur.

2

Plus de table dans le fichier (dictionnaire).

autre

Erreur. Voir DD_GETERROR

 

Exemple

1  ticket L 

1  reponse 8096  

1  sttable X

sttable = DDInterface(DD_TABLENEXT,ticket,"article",reponse)
