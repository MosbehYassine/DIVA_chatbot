GetAdressProcedureRecord Famille Thème

 

La fonction GetAdressProcedureRecord permet d'obtenir l'adresse d'une procédure liée à une table d'un fichier  en vue de son exécution par l'instruction ProcedureCall.

Rappelons qu'il est possible de définir dans le dictionnaire des fonctions qui seront appelée après chaque opération sur le fichier. L'appel est automatique si les fonctions Ixxx sont utilisées. Si les fonctions Ixxx ne peuvent être utilisées, GetAdressProcedureRecord rend possible l'appel de la fonction à la main.

 

Pour chaque table dans le fichier il est possible d'avoir une fonction qui sera exécutée

  • après lecture (read, pread, seek)

  • avant écriture (write)

  • avant réécriture (rewrite)

  • avant suppression (delete)

 

Long GetAdressProcedureRecord ( tdf , table , opération , adrFonction , [ stopSiErreur] )

 

Paramètres

Tdf

Tdf correspondant au ficher ouvert.

 

Table

Instance de la table.

 

Opération

0

après lecture (read , pread, seek)

1

avant écriture (write)

2

avant réécirture (rewrite)

3

avant suppression (delete)

 

Adresse

Zone alphanumérique de 16 octets qui recevra l'adresse de la fonction. Cette adresse sera utilisée pour l'appel de la fonction.

 

StopSiErreur

Booléen indiquant si le programme doit être arrêté en cas d'erreur (FALSE par défaut)

 

Remarque

GetAdressProcedureRecord  ne peut être appelée que si le fichier est déclaré par HFile. Si le fichier a été ouvert par programme (Hopen) il faut utiliser GetAdressProcedureRecordEx.

 

 

Retour

0

Pas d'erreur

1

Fonction non trouvée dans le module

2

Autre erreur

Si StopSiErreur = TRUE toutes les autres erreurs provoquent un arrêt du programme en cours.

En retour, la zone Adresse contient l'adresse de la fonction.

 

Exemple : appel de la fonction "après écriture"

 

; cet exemple illustre le fait que l'appel a GetAdressProcedureRecord

; peut être fait dans une procedure qui ignore le type de fichier et d'enregistrement

; manipulés. Les informations concernant le fichier et l'enregistrement sont automatiquement

; passées avec les paramètres.

 

hfile testdd.dhsd farti tdfarti

public record testdd.dhsd arti

 

Public Procedure EcrireArticle(&tdf,&art,partage)

record * htdf tdf

1 art A

1 partage 1

beginp

1 adr 16

   if GetAdressProcedureRecord(tdf,art,1,adr,FALSE) = 0

      ProcedureCall(adr,tdf,art,partage)

   endif

   hwrite(tdf,art,partage)

endp

 

main

EcrireArticle(tdfarti,arti,'P')
