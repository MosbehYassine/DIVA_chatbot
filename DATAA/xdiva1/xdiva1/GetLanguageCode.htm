GetLanguageCode Famille Thème

 

La fonction GetLanguageCode  retourne le code langue courant.

 

Alpha  GetLanguageCode  ( TypeDate ,[ EcranImp ] )

 

Paramètre

TypeDate

Donnée alphanumérique qui reçoit le type de date associé au code langue :

Espace : date au format jj/mm/aaaa (LE = little endian).

'A' : date au format mm/jj/aaaa (ME = middle endian).

'B' : date au format aaaa/mm/jj (BE = big endian).

 

EcranImp

1 = Lecture du code langue pour les affichages à l'écran (valeur par défaut).

2 = Lecture du code langue pour les impressions.

 

Retour

La fonction renvoie le code langue courant. (XXXX si aucun code langue sélectionné = langue par défaut).
