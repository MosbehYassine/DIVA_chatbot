GenerateMask

 

Le fonction Diva GenerateMask génère un masque d’écran simple par programme. Elle produit un fichier objet (.dhof) exécutable par le gestionnaire de masques Ywpf. Pour l'appeler, le programme doit déclarer le module yMaskGenerator.dhop.

 

Int GenerateMask (maskToGenerateFile, modelFile, idObjects)

 

Paramètres :

 

maskToGenerateFile

Nom du fichier masque à générer.
Les extensions dhof et dhsf sont valides.
 

modelFile

Nom du fichier source du masque modèle.
Préciser l’extension n’est pas nécessaire.
 

idObjects

Identifiant de la liste des objets à générer.
Cette liste est constituée d'enregistrements de type MaskGenObjDesc du dictionnaire ddsys.dhsd, chaque enregistrement décrivant un objet à ajouter.
 

 

Retour :

La fonction retourne 0 en cas de succès.
Sinon, la fonction renvoie un code erreur explicité dans le fichier zMaskGenerator.dhsp.

 

Remarques :

  • Attention à ne pas éditer le fichier source du masque modèle ou du masque à générer dans Xwin au moment de lancer le programme de génération. En effet, Xwin réserve les masques en cours d'édition, ce qui provoquera l'échec de la génération.

  • Le fichier source du masque généré est créé dans le répertoire du fichier source du masque modèle.

  • Le fichier objet du masque généré est créé dans le répertoire du fichier objet du masque modèle ou, à défaut, dans le répertoire du fichier source du masque modèle.
