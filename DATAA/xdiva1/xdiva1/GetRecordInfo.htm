GetRecordInfo

La fonction GetRecordInfo permet de récupérer les caractéristiques d'un enregistrement.

 

Long = GetRecordInfo ( nom_enregistrement , caractéristiques )

 

Paramètres

Nom_enregistrement

Nom de l'instance de l'enregistrement dont on veut récupérer les caractéristiques. Cet enregistrement doit préalablement avoir été alloué par un module.

Caractéristiques

Zone de 117 octets qui contient en retour les caractéristiques de l'enregistrement.

 

Retour

0

Pas d'erreur.

Autre

Enregistrement non trouvé
 

La zone recevant les caractéristiques est structurée de la manière suivante :

Libellé

Type

Taille totale de l'enregistrement

L

Position du code enregistrement

L

Taille de l'enregistrement sans la zone dépackée

L

Position de la zone packée

L

Taille de la zone packée

L

Valeur du code enregistrement

1

Nom du dictionnaire contenant la définition

32

Mnémonique dans le dictionnaire (le nom de l'instance peut être différent).

32

Mnémonique utilisé dans Odbc

32
 

Exemple

public record fdd eimp eimp

1 st L

1 infoenreg 117

 2 tailletotale L 

 2 positionce L 

 2 taillesansdepack L 

 2 positionpack L 

 2 taillepack L 

 2 valeurce 1 

 2 dico  32

 2 mnemo 32

 2 odbc  32

st = GetRecordInfo("eimp",infoenreg)
