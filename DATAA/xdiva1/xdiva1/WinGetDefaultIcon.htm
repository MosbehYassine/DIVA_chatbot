WinGetDefaultIcon  Famille Thème

 

La fonction WinGetDefaultIcon permet de récupérer le nom de l'icône associée à une extension.

Cette fonction se trouve dans le module ysystemex.dhop.

Le résultat retourné par cette fonction peut être directement copié dans une donnée associée à une bitmap variable.

   

Char WinGetDefaultIcon (ext)

 

Paramètres

Extension

Extension du fichier dont on cherche l'icone. L'extension ne doit pas comporter le point. Ex : "hop".

  

Retour

  

Exemple

m1.icone = wingetdefaulticon("hop")

m1.icone = wingetdefaulticon("doc")
