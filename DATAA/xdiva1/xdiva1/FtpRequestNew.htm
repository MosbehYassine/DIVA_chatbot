FtpRequestNew Famille Thème

 

Création d'une nouvelle requête Ftp ou Sftp.

 

int FtpRequestNew ([ FtpViaSSH ])

 

Paramètres

FtpViaSSH

Indique le choix du protocole.

False = Ftp

True = Sftp (ftp via SSH)

 

Retour

La fonction retourne un ticket qui sera utilisé par toutes les autres fonctions.
