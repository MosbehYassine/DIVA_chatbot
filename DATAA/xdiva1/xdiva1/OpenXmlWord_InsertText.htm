OpenXmlWord_InsertText  Famille  Theme

 

La fonction OpenXmlWord_InsertText ajoute un texte dans le paragraphe en cours (créé précédemment par la fonction OpenXmlWord_CreateParagraph).

 

Int OpenXmlWord_InsertText (texte)

 

Paramètre

Texte

Texte à insérer.

 

Retour

0

Le texte n'a pas été inséré.

1

Le texte a été inséré.
