Zoom.NoIcone

 

Contient le numéro d'une icône à afficher dans la barre de titre de la fenêtre Windows du zoom (par défaut, une icône standard est affichée).

Une valeur différente de zéro indique qu'il faut changer l'icône. Elle est prise dans le noyau d'Harmony si le champ Zoom.Icone est laissé à espace. Sinon, elle est recherchée dans le fichier d'icônes spécifié dans Zoom.Icone.
