Traduction des champs multilingues

 

La saisie de la traduction des champs multilingues est possible depuis le zoom (ou depuis l'utilitaire xtranslateLibZoom.dhop).

 

Confidentialités

Pour avoir le droit de traduire les champs multilingues d'une langue, l'utilisateur doit disposer du code d'accès HTxx (où xx est le code de la langue). Par exemple, pour avoir le droit de traduire les champs en Anglais, l'utilisateur doit disposer du code d'accès HTEN.

De plus, la procédure du zoom ZoomLangueChamps permet d'ajouter un niveau de filtrage des langues autorisées.

La liste des langues existantes provient du fichier paramètres TranslateParams.txt. Pour chaque langue, zoom vérifie que l'utilisateur a le droit d'accès correspondant puis appelle la procédure ZoomLangueChamps.

 

Champs multilingues

Les champs proposés à la traduction sont les champs multilingues placés dans le tableau du mode liste (page 3) du masque.

S'il n'y a aucun champ multilingue dans la page 3 du masque ou si l'utilisateur ne dispose pas des droits de traduction requis, le choix "Traduire" est grisé.


Rappel : La propriété multilingue d'un champ est définie dans le dictionnaire de données. Elle peut également être positionnée au niveau du masque pour des modifications ponctuelles.

Voir : La documentation "Traduction des champs multilingues" du "Manuel de référence d'Harmony".

 

Ajout d'un bouton

Vous pouvez ajouter un bouton à la barre d'outils pour appeler la traduction. Pour que le grisage de ce bouton soit effectif, il doit générer le point d'arrêt 25 et avoir pour identifiant "Traduction".
