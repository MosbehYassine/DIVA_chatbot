Zoom.Status

 

Ce code de retour est positionné par le zoom. Il vaut :

  • E_ZOOM_OK si l'utilisateur est sorti du zoom par le choix "Renvoyer les données".
    Le cas échéant, il faudra, dans la procédure ZoomValidation, garnir la donnée Zoom.ValRetour avec la valeur que le zoom doit renvoyer.

  • E_ZOOM_ABANDON si l'utilisateur est sorti du zoom par le choix "Abandon".

  • Toute autre valeur correspond à une erreur du zoom.
