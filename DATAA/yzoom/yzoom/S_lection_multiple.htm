Sélection multiple

 

Le zoom permet à l'utilisateur de sélectionner plusieurs lignes du tableau et de leur appliquer un traitement. En standard, le zoom permet de supprimer, d'imprimer et d'exporter (par l'impression paramétrable) les lignes sélectionnées. Il permet également au programmeur d'appliquer un traitement personnalisé à ces lignes.

 

Paramétrage du masque du zoom

Si l'on veut autoriser la sélection multiple des lignes du tableau, il faut associer à l'objet tableau du mode liste une donnée de contrôle des lignes. Pour ce faire :

  • Déclarez, dans la liste des enregistrements du masque, l'enregistrement RowInfo du dictionnaire ddsys.dhsd, avec obligatoirement le nom d'instance ZoomSelection.

  • Dans les propriétés du tableau, positionnez le champ "Avec donnée de contrôle" à "Oui" et sélectionnez la donnée RowInfo de l'enregistrement ZoomSelection dans le champ "Donnée de contrôle".

 

Paramétrage des attributs de la sélection

Les attributs de la sélection peuvent être personnalisés dans la séquence ZoomDebut en positionnant la variable ZoomSelection. Par exemple :
 

ZoomSelection = ' '

ZoomSelection.Bitmap = '1'

ZoomSelection.Couleur = 'AFFOK'

 

 

Suppression de la sélection

Le zoom gère automatiquement la suppression des lignes sélectionnées. Lorsque l'opérateur supprime la sélection courante, le zoom affiche une boîte de dialogue avec les choix :

  • Oui

  • Non

  • Tous

  • Aucun

Par défaut, les choix Oui et Non ne sont pas actifs. Pour les activer, il faut que la donnée Zoom.Titrevar soit différente d'espace. Elle contiendra généralement un texte permettant d'identifier chaque ligne à supprimer. Elle est positionnée dans la séquence ZoomApresRead.

 

 

Programmation

  • La fonction ZoomTraiterSelection permet d'indiquer au zoom le nom de la procédure à exécuter afin de traiter chaque ligne sélectionnée :

    Char ZoomTraiterSelection ("Nom_du_module", "Nom_de_la_procedure")

    Ses paramètres sont :

    • Le nom du module où se trouve la fonction à exécuter.
      Si le nom est à espace, le zoom cherche la fonction dans le module de traitement du zoom (Zoom.ModTrait).

    • Le nom de la procédure à exécuter pour chaque ligne sélectionnée.

ZoomTraiterSelection exécute la procédure dont le nom est passé en paramètre pour chaque ligne sélectionnée. Elle renvoie :

    • 'E' si la procédure n'existe pas.

    • Zoom.Ok, positionné par la procédure, après la dernière ligne traitée.

Pour chaque ligne, le zoom appelle la séquence ZoomApresRead avant l'appel à la procédure. Il positionne Zoom.Ok à 'O' avant l'appel et il interrompt le traitement si Zoom.Ok est différent de 'O' au retour de la procédure.

Le zoom consulte le clavier pendant la lecture des lignes sélectionnées : si l'opérateur interrompt la lecture par la touche "Echap", le traitement est interrompu et Zoom.Ok est positionné à 'N'.

 

  • La procédure ZoomViderSelection permet de désélectionner les lignes après le traitement. Par défaut, les lignes restent sélectionnées.

 

Si le traitement modifie des lignes susceptibles d'être affichées à l'écran, la procédure ZoomReactualiserListe ou ZoomReactualiserPage doit être appelée.

 

 

Exemple :

L'exemple consiste à renvoyer les lignes sélectionnées au programme appelant à travers le tunnel, suite à la frappe de la touche F12. Pour illustrer la possibilité d'abandon du traitement de la sélection, le nombre de lignes renvoyées est limité à 100.

 

Module "xzoom7.dhop"

 

Public Procedure ZoomConsultListe

Beginp

   ;renvoyer la sélection

   if Harmony.Key = K_F12 and Zoom.Select = ZOOM_OUI

      NbLignes = 0

      ZoomTraiterSelection (" ","RenvoyerUneLigne")

      If NbLignes <> 0

         Pong ("NbSelection",NbLignes)

      Endif

   Endif

Endp

 

 

Public Procedure RenvoyerUneLigne

1  rep  X

Beginp

   if NbLignes < 100

      Pong ("article" & nospaces(++NbLignes),Article.Reference)

   Else

      rep = Messagebox ("La sélection comprend plus de 100 lignes | " \

            & "Renvoyer ces lignes ou Annuler","Avertissement",MB_OKCANCEL)

      If rep = IDCANCEL

         NbLignes = 0

      Endif

      Zoom.Ok = 'F'    ;pour arrêter le traitement de la sélection

   Endif

Endp
