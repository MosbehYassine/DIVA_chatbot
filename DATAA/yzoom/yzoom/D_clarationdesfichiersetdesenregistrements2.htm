Déclaration des enregistrements du masque d'imprimante

 

Le choix Enregistrements du menu Paramètres de Xwin permet de déclarer les enregistrements utilisés dans le masque.

Il faut obligatoirement déclarer le RecordSql concerné.

 

Remarque :

Si, dans le masque du zoom, vous placez des données appartenant à d'autres enregistrements (par exemple la date définie dans l'enregistrement SYSTEM), il faudra bien entendu aussi déclarer ces derniers.
