ZoomInitPerso       Famille  Thème

 

Objet : Traitement d'initialisation de la saisie des paramètres d'impression.

Procédure : Facultative.

Exécutée : Avant la première saisie des paramètres d'impression.

 

Cette séquence peut être utilisée pour initialiser des paramètres de l'impression.

Il faut déclarer l'enregistrement public Zoom2 qui contient ces paramètres :

  • Zoom2.Titre contient le titre de l'état.

  • Zoom2.SousTitre contient un sous-titre qui apparaît dans le cartouche d'en-tête de page.

  • Zoom2.Pied contient un texte qui apparaît dans le cartouche de pied de page.

  • Zoom2.Police permet d'indiquer la taille de la police. Les valeurs 1, 2, et 3 correspondent respectivement à une taille "Normale", "Moyenne" et "Petite". La valeur par défaut est "Normale".

  • Zoom2.Portrait permet d'indiquer l'orientation de l'état : 1 pour le mode portrait et 2 pour le mode paysage. Le mode par défaut est le mode portrait.

  • Zoom2.Fichier permet d'indiquer si l'on veut envoyer les données vers l'imprimante (1, valeur par défaut), dans un fichier (2) ou vers le presse-papiers (3).

  • Zoom2.P1, Zoom2.P2, Zoom2.P3 et Zoom2.P4 contiennent respectivement les polices du titre, des cartouches d'en-tête et de pied de page, des en-têtes de colonnes et des lignes détails. Si l'on désire modifier les valeurs standard, on garnira ces champs avec le nom d'une police dans la feuille de styles d'Harmony.

  • Zoom2.Fmilliers indique si l'on souhaite séparer les milliers des données numériques (ZOOM_OUI, valeur par défaut) ou non (ZOOM_NON).

 

Exemple :

Public Procedure ZoomInitPerso

Beginp

   Zoom2.Titre = 'Liste des articles par référence '

   Zoom2.Police = 2               ;police moyenne

   Zoom2.SousTitre = 'Dossier 1 '

   Zoom2.Pied = '(C) Divalto'

Endp
