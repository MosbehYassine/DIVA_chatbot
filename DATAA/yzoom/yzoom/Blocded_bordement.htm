Bloc de débordement

 

Numéro de bloc : 3.

Type de bloc : Mobile ou Fixe.

 

Le troisième bloc du masque d'impression est généralement utilisé pour gérer le débordement de page. Il pourra contenir par exemple des totalisations de fin de page. Après l'impression de ce bloc, une nouvelle page sera imprimée. On indiquera donc dans les caractéristiques du bloc :

  • Un saut de page après.

  • Un numéro de bloc à enchaîner (généralement 1).
