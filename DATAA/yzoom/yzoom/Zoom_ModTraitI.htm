Zoom.ModTraitI

 

Contient le nom du fichier objet du module Diva contenant les séquences de traitement spécifiques liées à l'impression.

Ce paramètre est facultatif. Les séquences liées à l'impression sont d'abord recherchées dans le module de traitement du zoom (Zoom.Modtrait). Si elles sont absentes de ce module et que le paramètre ModTraitI est renseigné, elles seront recherchées dans le module ModTraitI.
