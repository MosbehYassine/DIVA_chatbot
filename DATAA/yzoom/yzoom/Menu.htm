Menu du Zoom

 

Par défaut, le zoom gère automatiquement une barre de menu standard donnant accès aux différentes actions. Ce menu est défini dans les ressources du masque Zoom7.dhof.

 

Ce menu peut être personnalisé :

  • Soit par l'ajout de choix supplémentaires en fin de menu ou de sous-menus.
    Pour cela, créez, dans les ressources du masque du zoom, un menu nommé "ZoomAppend".
    A l'exécution, il sera automatiquement fusionné au menu standard (les règles de fusion sont expliquées à la rubrique Menus : Surcharge).

  • Soit par le remplacement du menu complet.
    Pour cela, créez, dans les ressources du masque du zoom, un menu nommé "Zoom".
    A l'exécution, il remplacera le menu standard.
    Vous pouvez récupérer dans votre menu personnel les choix du menu standard que vous souhaitez conserver. Pour cela, copiez ces choix dans le masque Zoom7.dhsf (source livré) et collez-les dans le masque du zoom.

 

Désactivation des choix

Le zoom gère l'activation et la désactivation des choix standard en fonction du contexte.

Dans le cas d'ajout de choix supplémentaires, il convient d'assurer cette gestion pour les choix ajoutés. Pour cela, la donnée Zoom.IdMenu contient l'identifiant du menu. Voir ZoomAvantInput.
