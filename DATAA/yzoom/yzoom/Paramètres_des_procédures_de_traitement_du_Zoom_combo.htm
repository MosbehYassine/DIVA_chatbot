Paramètres des procédures de traitement du Zoom liste

 

Le module de traitements Diva est commun au Zoom liste et au Zoom classique. Si vous avez besoin de connaître le type du zoom exécuté dans un traitement, testez la variable Zoom.FlagComboZoom :

  • TRUE : c'est le Zoom liste qui est exécuté.

  • FALSE : c'est le Zoom classique qui est exécuté.
