Paramètres d'appel d'un Zoom Sql

 

Les différents paramètres du zoom Sql sont stockés dans l'enregistrement Zoom décrit dans le dictionnaire ddsys.dhsd.

Pour appeler un zoom, on précisera :

  • Le nom du RecordSql.

  • Le nom du masque écran.

  • Le nom du module de traitement.

  • Eventuellement un titre.

  • Le niveau de privilège de l'utilisateur.

  • Le fonctionnement du double clic en mode liste.

  • Eventuellement le nom d'un masque d'impression.

  • Eventuellement le nom d'un module de traitement spécifique à l'impression.

  • Le scénario.

  • Eventuellement le nom d'un fichier d'aides et un numéro d'aide.
