RecordSql associé au Zoom

 

La table gérée par un zoom est déclarée dans le masque et dans le module de traitements par un "RecordSql".

Le RecordSql fait l'objet d'un livre spécifique dans cette documentation.

 

Signalons quelques particularités pour le zoom :

  • L’instance du RecordSql doit être déclarée Public dans le module de traitements associé au zoom.

  • Les champs du RecordSql sont directement placés dans le masque du zoom.

  • Un RecordSql peut regrouper les champs de plusieurs tables grâce aux jointures.

  • Le RecordSql associé au zoom ne peut pas comporter de balise <Groupby>.
