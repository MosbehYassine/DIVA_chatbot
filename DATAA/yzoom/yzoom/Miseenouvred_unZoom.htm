Mise en œuvre d'un Zoom

 

Un même zoom peut être lancé :

  • Depuis un menu (du type Divalto).

  • Depuis un programme Diva, y compris depuis le code Diva d'un masque, par la fonction ZoomSql.

De manière générale, le programme appelant doit identifier le zoom, indiquer un niveau de privilège, un scénario du zoom, éventuellement les paramètres d'impression et enfin s'il autorise ou non la récupération du résultat. Il récupère un code de retour, un indicateur de modification du fichier, le résultat du zoom.

 

Les différents paramètres du zoom sont stockés dans l'enregistrement Zoom décrit dans le dictionnaire ddsys.dhsd.

Pour la description exhaustive des paramètres d'appel du zoom, voir Paramètres d'appel.

Pour la description exhaustive des paramètres de retour du zoom, voir Paramètres de retour.

 

La méthode habituelle d'appel à un Zoom en phase de saisie est décrite à la rubrique Appel d'un zoom en saisie de donnée.
