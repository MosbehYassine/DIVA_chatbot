Zoom.TitreVar

 

Cette donnée contient la partie variable du titre du zoom.

Si le titre variable contient des informations liées à la fiche en cours, il convient de mettre à jour la donnée Zoom.TitreVar dans les procédures suivantes :

  • ZoomApresRead.

  • ZoomAvantWrite.

  • ZoomApresCleCreation dans le cas où les données constituant la clé font partie du titre.

  • Eventuellement ZoomAvantRewrite si le titre variable a changé.


Le titre est affiché dans la barre de titre de la fenêtre Windows du zoom.
