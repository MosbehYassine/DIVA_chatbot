Masque

Les champs de la boîte de dialogue du masque sont :
 

Libellé

Zone de commentaires identifiant le masque. Ce libellé s'applique au fichier masque global.

Modifié le

Date de la dernière intervention (pour information).

Par

Code du dernier utilisateur qui est intervenu sur le masque (pour information).

 

 

Feuille de styles

Nom de la feuille de styles à utiliser (fstyleWpf.dhfi par défaut).
Si le fichier spécifié n'existe pas, Xwin propose sa création. A cette occasion, la feuille de styles fstyleWpf.dhfi est recopiée dans la nouvelle feuille de styles.

Code langue du masque

Code de la langue d'origine du masque.
Renseignez cette zone si le masque est conçu dans une langue nécessitant l'application d'un code page non standard (le code page standard de Divalto est le code page "Occidental").

Exemple : PL (polonais).
 

Restriction sur le périmètre de prise en compte du code langue du masque :
Dans l'atelier de développement Xwin, la possibilité de saisir des textes, dans une langue à code page non standard, est limitée aux libellés des objets posés dans le masque et affichés à l'exécution (par exemple, la propriété "Texte" d'un objet Texte ou Groupe). Elle ne concerne pas les libellés "propres" à l'atelier (par exemple, la propriété "Libellé" des boîtes de dialogue des paramètres du masque ou de la page). Pour ces derniers, il est préconisé de les saisir en langue anglaise.
 

Ordre de saisie automatique

Ce paramètre est transmis aux différentes pages, au moment de leur création uniquement. Si cette case est cochée pour une page, l'ordre de saisie automatique (par défaut) est toujours recalculé par Xwin.

 

 

Cadre Aide Page

Fichier  

Nom (sans extension) d'un fichier contenant le texte des aides fenêtrées.
Ce paramètre est transmis aux différentes données, au moment de leur création uniquement.

Le même fichier peut être utilisé par plusieurs masques, ce qui permet de regrouper toutes les aides de l'application. A l'inverse, un masque peut aussi faire appel à plusieurs fichiers d'aide.
 

 

Cadre Traitements

Traitement initial

Nom du traitement à exécuter au chargement du masque (XmeLoad).
Peut être utilisé pour, par exemple, procéder à des initialisations.
Vous pouvez saisir le nom manuellement ou cliquer sur la flèche, auquel cas vous ouvrez un menu contextuel (voir Saisie d'un nom de traitement).

Arrêt clic souris par défaut

Numéro de point d'arrêt "clic souris".
Ce paramètre est transmis aux différentes données, au moment de leur création uniquement.

 

Cadre Surcharge

Surcharge des traitements uniquement

Masque de surcharge uniquement :

  • Case cochée : seule la surcharge des traitements est autorisée.

  • Case non cochée : les dessins et les traitements peuvent être surchargés.

 

Boutons

Commentaires

Permet de saisir des commentaires. 

Touches par défaut

Permet de paramétrer des pièges de touche par défaut.
Ce paramètre est transmis aux différentes données, au moment de leur création uniquement.

Certains pièges de touche peuvent déclencher le même type de traitement, quelque soit la donnée en cours de saisie au moment de la frappe (par exemple, l'appel d'un zoom). Déclarez ces touches "par défaut" plutôt que de le faire ensuite pour chacune des données.
