Le menu Outils

  • Feuille de styles : Permet d'ouvrir une feuille de styles pour y apporter des modifications. Permet également de créer une feuille de styles de surcharge.
     

  • Chemins implicites : Appel de l'utilitaire de gestion des fichiers de chemins implicites.
     

  • Gestionnaire d'extraits de code : Permet d'ajouter ou de retirer des éléments à la liste des dossiers qui vous sera proposée à l'ouverture du sélecteur d'extraits de code source.
     

  • Traduction

    • Extraire les libellés en vue de la traduction : Création d'un dictionnaire contenant tous les libellés à traduire.

    • Choisir un code langue : Sélection d'un code langue. Les libellés des masques sont affichés dans la langue sélectionnée.
       

  • Vérifier la taille des boîtes

    • Pour la page en cours : Vérifie pour la page en cours que les boîtes ont une taille suffisante pour contenir le texte. La langue sélectionnée dans <Choisir un code langue> est utilisée.

    • Pour le masque en cours : Vérification des boîtes pour le masque en cours.

    • Pour un répertoire : Vérification des boîtes pour tous les masques d'un répertoire.

    • Options de vérification : Options pour la vérification (marge d'erreur).
       

  • Moulinette v6 -> v7
    Le programme     Xwin6 inclut une fonction permettant de "mouliner" vos masques d'écran développés en version 6 pour les "traduire" en version 7. Même si la grande majorité des fonctionnalités reste inchangée, des différences existent entre les deux versions. La moulinette les détecte et les stocke dans un "fichier d'erreurs". Dans Xwin7, les choix suivants simplifient la correction des anomalies :

    • Importer un fichier d'erreurs : Lit un fichier d'erreurs produit par la moulinette (exécutée dans Xwin6) et place la liste des différences dans la fenêtre "Compte-rendu". Vous disposez ensuite des mêmes fonctions de positionnement sur les objets concernés qu’après une compilation de masques ayant produit des erreurs.

    • Positionnement sur un fichier dans les erreurs : Permet de vous positionner, dans la liste des différences importées, sur la première différence détectée pour un masque donné.
      Exemple d’utilisation : vous corrigez un certain nombre de masques dans une session de Xwin7 ; avant de refermer Xwin7, vous activez le prochain fichier à traiter ; le lendemain, vous ré-ouvrez Xwin7, vous faites appel à ce choix du menu (qui vous propose par défaut le nom du fichier actif courant) et vous validez. Le curseur est automatiquement replacé sur la 1ère anomalie du premier fichier non encore corrigé (visuellement, il n’est pas toujours évident de se repositionner sur un fichier précis dans une longue liste).
