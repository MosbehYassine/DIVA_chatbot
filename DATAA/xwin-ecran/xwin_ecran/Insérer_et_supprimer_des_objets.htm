Insérer et supprimer des objets

 

Insertion simple d'un objet

Pour insérer un objet dans une page du masque :

  • Sélectionner le choix du menu Objets correspondant au type d'objet souhaité.
    Ou

  • Cliquez sur le bouton correspondant dans la barre d'outils.

Ensuite, "déposez" l'objet à l'endroit souhaité dans la page.

La fenêtre des propriétés est activée. Pour entrer rapidement en modification de la première propriété, tapez la touche Tab.

La gestion de la fenêtre des propriétés est détaillée dans les rubriques du livre Saisie des propriétés des objets.

 

 

Remarque importante :

Xwin crée l'objet avec des paramètres de présentation (police, couleur, etc.) par défaut. Le choix Garder présentation du menu contextuel des objets permet de dire que les paramètres actuels de l'objet concerné deviendront les paramètres par défaut pour ce type d'objet. Ainsi, à la prochaine création d'un objet de même type, ces valeurs lui seront affectées par défaut.

 

 

Insertion multiple d'objets

Voir la rubrique Insertion multiple d'objets depuis le dictionnaire.

 

 

Tous types d'insertion de donnée

Attention : si un traitement "Après saisie" (ou un traitement "Modèle" suivant l'option choisie dans les paramètres du projet) a été affecté à la donnée dans le dictionnaire, ce traitement lui est automatiquement affecté au moment de son insertion dans le masque. Pour tous les détails à ce sujet, consultez la rubrique Description générale des traitements du dictionnaire du livre consacré au dictionnaire de données.

 

 

Suppression d'un ou plusieurs objets

Pour supprimer un ou plusieurs objets, sélectionnez-le(s) puis :

  • Activez le choix Supprimer du menu Edition.

  • Ou cliquez droit sur l'objet et activez le choix Suppression du menu contextuel.

  • Ou tapez la touche Suppr.

Attention : dans le cas d'un objet comportant un point de traitement, cette opération NE supprime QUE l'objet et laisse le code source des traitements inchangé.
