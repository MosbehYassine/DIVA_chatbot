Traduction des masques

 

Harmony intègre des outils permettant d'exécuter les programmes dans un contexte multilingue.

Le processus de traduction est décrit en détail dans le livre consacré à ce sujet.

 

Le principe est le suivant :

  • depuis Xwin, vous créez un dictionnaire contenant tous les libellés à traduire.

  • depuis le programme Xtranslate.dhop, vous créez des dictionnaires en langue étrangère. Ces dictionnaires sont ensuite traduits à la main puis compilés.

La taille des libellés est éminemment variable d'une langue à l'autre. C'est pour cela que Xwin dispose d'outils pour vérifier que les textes traduits ne débordent pas des boîtes. Ces outils permettent :

  • de vérifier que les boîtes sont suffisamment grandes pour contenir le texte traduit,

  • d'agrandir automatiquement les boîtes.
