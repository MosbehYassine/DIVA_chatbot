Liste des onglets

Cette boîte de dialogue permet d'ajouter, de modifier ou de supprimer un onglet du masque en cours. Elle propose la liste des onglets présents dans le masque et les zones :
 

Nom

Nom de l'onglet à créer / modifier / supprimer.

Point d'arrêt

Numéro du point d'arrêt associé à l'onglet (pour information).

Pages

Listes des pages du masque liées à cet onglet (pour information).

  • Pour modifier un onglet, sélectionnez-le dans la liste ou tapez son nom puis cliquez sur le bouton Modifier. Vous pouvez également double-cliquer dans la liste des onglets.
    La boîte de dialogue de paramétrage d'un onglet vous permet alors de modifier les valeurs de l'onglet.

  • Pour créer un onglet, tapez son nom puis cliquez sur le bouton Ajouter.
    La boîte de dialogue de paramétrage d'un onglet vous permet alors de modifier les valeurs de l'onglet.

  • Pour supprimer un onglet, sélectionnez-le dans la liste ou tapez son nom puis cliquez sur le bouton Supprimer.
    Une boîte de dialogue vous demande alors de confirmer la suppression.
