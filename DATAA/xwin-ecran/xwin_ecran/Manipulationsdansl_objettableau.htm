Manipulations dans l'objet tableau

Un tableau présente les zones suivantes :

  • Dans le coin en haut à gauche, un bouton permet de sélectionner toutes les colonnes.

  • La partie gauche du tableau est occupée par la colonne d'état.

  • La ligne du haut contient les en-têtes des colonnes.

  • La partie intérieure du tableau représente les objets qui ont été intégrés au tableau.

 

  • Pour modifier les propriétés :

    • De l'objet tableau lui-même, sélectionnez le tableau par un clic souris dans une colonne vide ou sous les lignes détail, puis allez dans la fenêtre des propriétés.

    • D'un objet et/ou de l'en-tête d'une colonne, cliquez sur cette colonne (indifféremment sur l'en-tête ou sur l'objet) puis allez dans la fenêtre des propriétés. Les propriétés de l'en-tête sont regroupées dans la famille En-tête colonne.

    • De tous les objets ou en-têtes de colonne, cliquez sur la case de sélection de toutes les colonnes puis allez dans la fenêtre des propriétés.

    • De plusieurs colonnes, cliquez sur chaque colonne désirée en gardant la touche Shift enfoncée puis allez dans la fenêtre des propriétés.

  • Pour déplacer une colonne, positionnez le curseur sur l'entête de la colonne, cliquez et glissez vers l'emplacement désiré.

  • Pour élargir une colonne, placez le curseur sur la frontière entre deux colonnes. Cliquez et glissez pour modifier la largeur de la colonne. Vous pouvez aussi élargir ainsi la colonne d'état.

  • Pour agrandir la ligne détail, positionnez le curseur dans la colonne d'état sur la frontière entre deux lignes. Cliquez et glissez pour augmenter la taille de toutes les lignes détail.
     

Remarque : L’utilisateur peut lui-aussi modifier les tailles à sa convenance, à l'exception de celle de la colonne d'état.
