Copier, couper, coller

 

La commande "Couper" ôte les objets sélectionnés et les place dans le presse-papiers.

La commande "Copier" copie les objets sélectionnés dans le presse-papiers.

La commande "Coller" insère le contenu du presse-papiers dans le masque.

 

Ces commandes permettent la copie et le transfert d'un morceau de page vers un autre emplacement du même fichier masque ou vers un autre source de masque. Elles sont disponibles au menu Edition de Xwin :

  • Choix Copier (raccourci clavier : Ctrl+Inser).

  • Choix Couper (raccourci clavier : Suppr).

  • Choix Coller (raccourci clavier : Shift+Inser).

Des boutons Copier , Couper et Coller sont également présents dans la barre d'outils.

 

Attention : dans le cas d'un objet comportant un point de traitement, l'opération Couper NE supprime QUE l'objet et laisse le code source des traitements inchangé.

 

 

Coller dans une page

La commande Coller insère le contenu du presse-papiers dans la page courante. Les objets sont d'abord placés à l'endroit qu'ils occupaient à l'origine et sont tous sélectionnés. Vous pouvez alors les déplacer et les déposer à l'endroit souhaité.

La commande Coller est aussi présente dans le menu contextuel obtenu en cliquant droit dans le fond de la page.

 

 

Coller dans un tableau

Vous pouvez utiliser la commande Coller pour intégrer dans un tableau une sélection d'objets (cette fonctionnalité est particulièrement intéressante pour dupliquer dans un tableau le mode fiche d'un zoom). Ici, vous devez au préalable sélectionner l'objet tableau (dans le cas contraire, les objets ne pourront être collés que dans la page).

Si vous sélectionnez le tableau proprement dit, les objets collés seront placés en dernière colonne. Si vous sélectionnez une colonne du tableau, les objets collés seront placés avant la colonne sélectionnée.

Vous pouvez aussi cliquer droit sur une colonne du tableau et sélectionner le choix "Coller avant" ou "Coller après" du menu contextuel.

Remarque : les groupes de radio-boutons collés sont convertis en multi-choix.

 

 

Coller dans une cellule de grille

Pour coller le contenu du presse-papiers dans une cellule de grille, cliquez droit sur la cellule pour afficher le menu contextuel et exécutez le choix "Coller dans la cellule".

Rappel : Une cellule de grille ne peut contenir qu'UNE autre grille ou UN objet panel page.

 

 

Coller du code source des traitements

Lorsque vous collez un objet faisant appel à un ou plusieurs traitements Diva, Xwin copie aussi le code source de ces traitements.

Remarques :

  • Xwin ne duplique pas le traitement si un code source identique existe déjà.

  • Vous pouvez invalider la copie du code source des traitements : cochez la case Ne pas copier le code source des traitements du cadre Coller d’objets dans un masque dans les options de votre projet.
