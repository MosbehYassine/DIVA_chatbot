Objet  Image variable

Les propriétés d'un objet Image variable sont :
 

Famille Image variable

Indices

S'il s'agit d'un élément de tableau Diva, précisez ses indices.
 

Famille Présentation

Fond

Uniquement si l'image est placée dans un tableau : couleur de fond de la colonne dans la feuille de styles.

Traitement de l'image

Pas de traitement

L'image est affichée sans aucun traitement.

 

Réduire si débordement

L'image est réduite pour qu'elle tienne entièrement dans la boîte. Le traitement respecte les proportions de l'image.

 

Pleine boîte

L'image est agrandie en largeur et en hauteur de façon à remplir la boîte. Ce traitement ne respecte pas les proportions de l'image.

 

Pleine largeur

L'image est agrandie en largeur de façon à remplir la boîte. Ce traitement respecte les proportions de l'image. Il se peut donc qu'elle soit rognée en hauteur.

 

Pleine hauteur

L'image est agrandie en hauteur de façon à remplir la boîte. Ce traitement respecte les proportions de l'image. Il se peut donc qu'elle soit rognée en largeur.

 

Taille maximum

L'image est agrandie au maximum en respectant les proportions de l'image.

 

Mosaïque

Cette fonction n'est plus implémentée dans les masques d'écran à partir de la version 7 d'Harmony.

 

Centrer

L'image est centrée dans la boîte.

Exemple

fichier[;numero] : fichier image (et numéro d'image) à afficher dans Xwin.

Cette propriété est uniquement utilisée par Xwin et n'a aucune incidence à l'exécution.

Noms de l'objet

Voir Présentation.

 

Famille Colonne : Uniquement si l'image est placée dans un tableau - voir Colonne de tableau.

 

Famille Aide

Bulle

Libellé de la bulle.

 

Famille Attachements / coordonnées : voir Attachements / Coordonnées.

 

Famille Commentaire : voir Commentaire.

 

 

Contenu de la donnée associée

Le nom (au format Harmony) du fichier image à afficher n'est connu qu'à l'exécution. Il doit être placé dans la donnée associée à l'objet avant l'affichage du masque. La donnée peut contenir :

  • soit le nom d'un fichier .gif, .jpg, .png, .bmp, .rle, .dib, .tga, .tif, .ico, .dll, .exe (avec l'extension) ;

  • soit un nom de bitmap dans la feuille de styles ;

  • soit un nom de bitmap "interne" précédé du caractère # (voir les images et les boutons de la feuille de styles fstyleWpf.dhfi dont le nom du Fichier image commence par #).

Exemples :

Filemove.jpg 

Fichier filemove.jpg dans Divalto\Sys.

AFF_COMPTA 

Nom de bitmap dans la feuille de styles.

#aff_compta

Nom interne (identique à la précédente).
 

 

Cas particulier des fichiers .ico , .dll et .exe (sauf client léger Html en dehors de certaines icones standard de xrtdiva.exe)

Par défaut, pour les types de fichier ico, .dll et .exe, c'est la première icone contenue par le fichier qui est considérée. Vous pouvez charger une autre icone en plaçant, derrière le nom, son numéro d'ordre (début à 0) précédé d'un ;

Exemples :

"xrtdiva.exe" ou "xrtdiva.exe;0"

Première icone contenue par le fichier xrtdiva.exe.

"xrtdiva.exe;3"

Quatrième icone contenue par le fichier xrtdiva.exe.
 

Par défaut, l'icone sera affichée en 32 x 32. Vous pouvez demander d'afficher la petite icone associée (16 x 16) (sauf client léger Html). Pour cela, le numéro de l'icone doit être suivi de deux paramètres vides, puis du chiffre 1.
Exemple : "xrtdiva.exe;0;;;1" ==> première petite icone.
