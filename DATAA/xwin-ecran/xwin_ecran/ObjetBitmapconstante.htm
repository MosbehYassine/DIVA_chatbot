Objet Image

  Les propriétés d'un objet Image sont :

Famille Image

Nom dans la feuille de style

Nom d'une image dans la feuille de styles.

Suite à la saisie du nom, Xwin affecte à l'image les propriétés correspondantes enregistrées dans la feuille de style :

  • Les propriétés faisant partie du sous-arbre ayant pour racine la ligne "Nom dans la feuille de style" peuvent être personnalisées :

    • Une valeur non personnalisée, affichée en noir, est toujours recherchée dans la feuille de styles ; si vous changez plus tard par exemple le nom du fichier image dans la feuille, la nouvelle image sera automatiquement reprise, sans intervention (ni compilation) au niveau du masque.

    • Une valeur personnalisée, affichée en rouge, n’est plus affectée par un changement au niveau de la feuille. Lorsqu’au moins une valeur est personnalisée, les intitulés de ses ascendants dans l’arbre sont aussi affichés en rouge (dans l'exemple précédent : "Nom dans la feuille de style" puis "Image").

    • Un clic droit sur une propriété personnalisée ouvre un menu popup avec le choix "Reprendre la valeur de la feuille de styles". Ce choix permet de récupérer la valeur enregistrée au niveau de la feuille pour cette propriété.

    • Un clic droit sur le nom dans la feuille de style ouvre un menu popup avec le choix "Reprendre les valeurs de la feuille de styles". Ce choix permet de récupérer toutes les valeurs enregistrées au niveau de la feuille.

  • Les propriétés affichées dans une autre branche de l’arbre sont seulement initialisées avec les valeurs lues dans la feuille (qui sont alors considérées comme de simples valeurs par défaut) : leur valeur, toujours affichée en noir, n’est plus ensuite affectée par un changement au niveau de la feuille.

Fichier
image
(,n°)

Nom du fichier contenant l'image (par exemple : Image1.png).
Un nom personnalisé est affiché en rouge.

Remarque : Des images bitmaps "standard" peuvent être référencées ici à la place d'un nom de fichier. Le nom à indiquer est alors un nom conventionnel commençant par le caractère de reconnaissance # (consultez les images de fstyleWpf.dhfi pour connaître ces noms).
Exemple : #aff_compta.

Vous pouvez faire suivre le nom du fichier d'une virgule puis du numéro de la bitmap à l'intérieur du fichier (fichier de type .exe, .ico ou .dll, non utilisable en client léger Html en dehors de certaines icones standard de xrtdiva.exe).

 

 

Famille Présentation

Traitement de l'image

Traitement à appliquer à l'image.

Cette option est ignorée en client léger Html pour une image "standard" (nom commençant par un #).

 

Pas de traitement

L'image est affichée sans aucun traitement.

 

Réduire si débordement

L'image est réduite pour qu'elle tienne entièrement dans la boîte. Le traitement respecte les proportions de l'image.

 

Pleine boîte

L'image est agrandie en largeur et hauteur de façon à remplir la boîte. Ce traitement ne respecte pas les proportions de l'image.

 

Pleine largeur

L'image est agrandie en largeur de façon à remplir la boîte. Ce traitement respecte les proportions de l'image. Il se peut donc qu'elle soit rognée en hauteur.

 

Pleine hauteur

L'image est agrandie en hauteur de façon à remplir la boîte. Ce traitement respecte les proportions de l'image. Il se peut donc qu'elle soit rognée en largeur.

 

Taille maximum

L'image est agrandie au maximum en respectant les proportions de l'image.

 

Mosaïque

Cette fonction n'est plus implémentée dans les masques d'écran à partir de la version 7 d'Harmony.

 

Centrer

L'image est centrée dans la boîte.
