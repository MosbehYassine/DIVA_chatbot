Modèles de présentation

Cette boîte de dialogue permet d'ajouter, de modifier ou de supprimer un modèle de présentation de la feuille de styles. Elle propose la liste des modèles existants et la zone Nom.

  • Pour modifier un modèle, sélectionnez-le dans la liste ou tapez son nom puis cliquez sur le bouton Modifier. Vous pouvez également double-cliquer dans la liste des modèles. La boîte de dialogue "Modèle de présentation" vous permet alors de modifier les constituants du modèle.

  • Pour créer un modèle, tapez son nom puis cliquez sur le bouton Ajouter.
    La boîte de dialogue "Modèle de présentation" vous permet alors de saisir les constituants du modèle.

  • Pour supprimer un modèle, sélectionnez-le dans la liste ou tapez son nom puis cliquez sur le bouton Supprimer.

Remarque : si le nom dans la liste est précédé d'une étoile, cela signifie que le modèle correspondant se trouve dans la feuille de styles de surcharge.

 

Les paramètres "écran" d'un modèle sont les suivants :

 

Champ en saisie

Nom du style à associer aux champs "En saisie".

Champ en affichage

Nom du style à associer aux champs "En affichage".

Libellé en affichage

Nom du style à associer aux libellés (objets texte).

Champ dans tableau

Nom du style à associer aux champs placés dans un tableau.

En-tête de colonne

Nom du style à associer aux en-têtes de colonne d'un tableau.
