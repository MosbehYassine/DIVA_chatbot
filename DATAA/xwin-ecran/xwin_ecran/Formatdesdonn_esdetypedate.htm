Format des données de type date

code

action

JJ ou DD

Numéro du jour dans le mois. Les 0 non significatifs sont remplacés par des espaces

J0 ou D0

Numéro du jour sur deux positions numériques (07)

MM

Numéro du mois dans l'année. Les 0 non significatifs sont remplacés par des espaces

M0

Numéro du mois sur deux positions numériques (06)

AA ou YY

Année sur 2 positions (2 derniers chiffres)

AAAA ou YYYY

Année sur 4 positions

jjj ou ddd

Nom du jour (d'après le nombre de j)

mmmmmm

Nom du mois (d'après le nombre de m)

#xxxxxxxx#

Les caractères compris entre deux dièses sont reproduits tels quels


Remarques

Si l'année est stockée sur deux chiffres (format aammjj), seul le code AA est utilisable.

Dans les codes jjjjjjj et mmmmmmmmm, chaque caractère représente une lettre du nom du jour ou du mois. Ces codes peuvent être raccourcis : par exemple, jjj ou mmmm. Dans ce cas, les noms de jour et de mois seront éventuellement tronqués.

Pour obtenir le caractère "#" (dièse), il faut le doubler.
