Style

Un style regroupe les quatre attributs de présentation (décrits dans les quatre rubriques précédentes) des objets courants : police de caractère, couleur de fond, bordure et padding.

Ses différents paramètres sont donc un nom de police, un nom de couleur, un nom de bordure et un nom de padding dans la feuille de styles.

A chaque objet concerné placé dans le masque, Xwin permet d'associer un style particulier, identifié par un nom dans la feuille de styles. Lors du choix du style pour cet objet, il suffira de spécifier son nom dans la propriété Style pour lui affecter l'ensemble de ses paramètres. Ainsi, il suffit de spécifier uniquement un nom de style pour que tous les attributs de présentation de l’objet soient positionnés.

 

Exemple

Vous pouvez définir ainsi le style STD :

Police

:

STD

Couleur

:

TRANS

Bordure

:

STD

Padding

:

STD

 

Style par défaut

Un rendu « Standard Divalto » a été défini pour chaque type d’objet (Texte, Champ, Case à cocher, ..., Onglets, Boutons, etc.). Le paramétrage dans la feuille de styles des quatre constituants d'un style (police, couleur de fond, bordure et padding) indique si le style doit ou non produire un rendu standard. Le rendu standard peut être obtenu globalement pour toutes les caractéristiques du style ou spécifiquement pour quelques unes d'entre elles (pour plus de détails à ce sujet, voir la rubrique Styles par défaut).

 

Personnalisation d'un style

Pour un maximum de souplesse, Xwin vous permet de modifier localement, pour un objet précis, chacun des paramètres du style. Vous pouvez donc par exemple changer la police ou la couleur de fond d’un texte sans avoir à apporter de modification à la feuille de styles.
