Boutons

Cette boîte de dialogue permet d'ajouter, de modifier ou de supprimer un bouton de la feuille de styles. Elle propose la liste des boutons existants, la zone Nom et l'ensemble des caractéristiques d'un bouton.

  • Pour modifier un bouton, sélectionnez-le dans la liste ou tapez son nom, modifiez les paramètres voulus puis cliquez sur le bouton Modifier.

  • Pour créer un bouton, tapez son nom, saisissez les paramètres puis cliquez sur le bouton Ajouter.

  • Pour supprimer un bouton, sélectionnez-le dans la liste ou tapez son nom puis cliquez sur le bouton Supprimer.

Remarque : si le nom dans la liste est précédé d'une étoile, cela signifie que le bouton correspondant se trouve dans la feuille de styles de surcharge.

 

Un style "Bouton" peut être utilisé pour les :

  • Boutons classiques (placés directement dans une page de masque).

  • Boutons de barre d'outils (gestion par l'éditeur de ressources).

  • Choix de menu (gestion par l'éditeur de ressources).

 

Les paramètres d'un bouton sont les suivants :

 

1. Paramètres dont la modification est répercutée sur les boutons déjà insérés dans le masque :

 

Nom

Nom donné au bouton dans la feuille de styles.

Fichier
image

Nom du fichier contenant l'image (bouton graphique, bouton de barre d'outils, choix de menu).
Exemple : Bitmap1.png

Remarques :

  • Des images "standard" peuvent être référencées ici à la place d'un nom de fichier. Le nom à indiquer est alors un nom conventionnel commençant par le caractère de reconnaissance # (consultez les images de fstyleWpf.dhfi pour connaître ces noms).
    Exemples : #tbr_abandon, #tbr_ok.

  • Un bouton classique ne peut à la fois afficher une image et un texte. Si ces deux propriétés sont renseignées, l'image primera sur le texte et c'est un bouton graphique qui sera affiché. Par contre, un bouton de barre d'outils ou un choix de menu afficheront l'image suivie du texte.

n°

Numéro de la bitmap à l'intérieur du fichier si le fichier est de type .exe, .ico ou .dll. Sinon, ce numéro doit être nul.
Ce type de fichier n'est pas utilisable en client léger Html (en dehors de certaines icones standard de xrtdiva.exe).

Couleur du fond

Nom d'une couleur de fond dans la feuille de styles (bouton classique uniquement).

Police

Nom d'une police de caractères dans la feuille de styles (bouton texte ou bouton de barre d'outils uniquement - la police d'un choix de menu n'est pas paramétrable).

Padding

Nom d'un padding dans la feuille de styles (bouton classique uniquement).

En client léger Html, les paddings définis ici ne sont pas pris en compte : le contenu du bouton est simplement centré dans la boîte. Si la taille de la boîte est insuffisante, on perd progressivement les paddings avant de tronquer le contenu (en Wpf, les paddings sont conservés et l'image est automatiquement réduite à la taille restante).

Raccourci

Touche de raccourci à associer au bouton graphique. Attention, un raccourci doit être défini de manière unique dans toute fenêtre Windows (menu compris).

Remarque : pour un bouton texte ou un choix de menu, le raccourci est déterminé par le caractère du libellé précédé d'un "_" (par exemple, raccourci "S" pour le libellé "_Suivant").

 

 

Effets spéciaux
 

(bouton graphique classique uniquement).

Image survol + n°

Image à afficher lorsque le curseur de la souris survole le bouton.

Curseur survol

Curseur à afficher lorsque la souris survole le bouton.
Pour afficher un autre curseur, il faut créer un fichier .cur et le placer dans le répertoire /Divalto/Sys.

Son survol

Son à jouer lorsque la souris "entre" sur le bouton.

Il s'agit d'un nom de fichier Windows. Pour ne pas avoir à préciser un chemin complet, placez le fichier dans le répertoire /Divalto/Sys.

Attention en mode Html : certains navigateurs ne reconnaissent pas les fichiers .wav.

Son clic

Son à jouer lors du clic sur le bouton.

Il s'agit d'un nom de fichier Windows. Pour ne pas avoir à préciser un chemin complet, placez le fichier dans le répertoire /Divalto/Sys.

Attention en mode Html : certains navigateurs ne reconnaissent pas les fichiers .wav.

 

 

2. Paramètres dont la modification n'est pas répercutée sur les boutons déjà insérés dans le masque :

 

Texte

Libellé du bouton (bouton texte, bouton de barre d'outils, choix de menu).
Exemples : "Ok", "Abandon".

Remarques :

  • Un bouton classique ne peut à la fois afficher une image et un texte. Si ces deux propriétés sont renseignées, l'image primera sur le texte et c'est un bouton graphique qui sera affiché. Par contre, un bouton de barre d'outils ou un choix de menu afficheront l'image suivie du texte.

  • Si vous faites précéder l'un des caractères du libellé d'un "_", ce caractère servira de touche de raccourci (par exemple, raccourci "P" pour le libellé "_Précédent" ou raccourci "U" pour le libellé "Enregistrer to_ut").

  • Le caractère | permet de découper le texte d'un bouton classique en plusieurs lignes.

Nom pour la sélection

Nom donné au bouton ou au choix de menu. Pour qu'un bouton nommé soit valide, il faut que son nom figure dans la liste des boutons valides de la page en cas de la consultation d'une page par XmeConsult, du tableau en cas de la consultation d'un tableau par XmeListConsult, de la donnée en cours de saisie en cas de saisie par XmeInput ou XmeListInput.

Noms de l'objet

Nom(s) donné(s) au bouton pour sa gestion par les attributs dynamiques.
Séparez les différents noms par une virgule ou un point-virgule.

Type de traitement

Indique l'action à déclencher lorsque le bouton est enfoncé.
Choisissez entre génération de caractères, point d'arrêt ou point de traitement.

Point d'arrêt

Numéro du point d'arrêt (pour le type de traitement "Point d'arrêt').

Chaîne à générer

Caractère à générer (pour le type de traitement "Génération de caractères").
La syntaxe à respecter est décrite à la rubrique Objet Bouton.

Procédure Diva

Nom du traitement Diva (pour le type de traitement "Point de traitement").

Bulle

Texte d'assistance affiché lors du stationnement de la souris sur le bouton.

 

 

3. Paramètres pris en compte à la création d'un bouton de barre d'outils ou d'un choix de menu :

 

Identifiant

Mnémonique permettant d'identifier le bouton (ou le choix) de manière unique dans la barre d'outils (ou le menu).

Nature

Nature du bouton ou du choix.

  • Normal : bouton ou choix simple.

  • Case à cocher : bouton ou choix simulant une case à cocher.
    Remarque : les cases à cocher sont interdites dans un menu principal.

  • Bouton radio : simule un bouton de groupe de radio boutons.
    Remarque : les boutons radio sont interdits dans un menu principal.

Licence consultation

Si cette option est positionnée à la valeur Oui, le bouton est automatiquement grisé lorsque le programme s’exécute dans le mode "Licence Consultation". Le cas échéant (voir la propriété "Type de traitement"), l'option invalide aussi automatiquement la touche affectée au bouton (comme pour tout bouton grisé simulant la frappe d'une touche au clavier).

Rappelons que dans ce mode, toute modification dans une base de données Divalto est interdite. On pourra donc activer cette option pour tous les boutons commandant une fonction de création, modification ou suppression dans la base.
