Fichier source et fichier objet

L'éditeur de masques d'écran Xwin traite des fichiers "source", qui doivent être compilés pour devenir exécutables par le gestionnaire de masques Ywpf. Le résultat d'une compilation est stocké dans un fichier "objet", physiquement distinct du fichier source.

Un fichier peut contenir un ou plusieurs masques, chacun d'eux mono ou multi-écran. Ceci permet de regrouper dans un même fichier source des masques logiquement apparentés.

 

Remarque :

Un source est un fichier "texte", qui peut éventuellement être édité par Xwin en mode "texte".
