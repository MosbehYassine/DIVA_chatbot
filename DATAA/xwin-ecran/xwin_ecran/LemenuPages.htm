Le menu Pages

Le menu Pages permet de déplacer de page en page, d'insérer ou de supprimer une page.

  • Première : Positionnement sur la première page du masque.

  • Dernière : Positionnement sur la dernière page du masque.

  • Suivante : Positionnement sur la page suivante.

  • Précédente : Positionnement sur la page précédente.

  • Numéro : Positionnement sur une page précise en donnant son numéro.

  • Insérer : Insertion d'une page avant la page en cours.

  • Supprimer : Suppression de la page courante.

  • Liste des objets : Ouvre une fenêtre avec la liste de tous les objets de la page.

  • Liste des noms : Ouvre une fenêtre avec la liste de tous les noms des objets (attributs dynamiques).
