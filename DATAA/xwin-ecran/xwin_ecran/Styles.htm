Styles

Cette boîte de dialogue permet d'ajouter, de modifier ou de supprimer un style global de la feuille de styles. Elle propose la liste des styles existants et la zone Nom.

  • Pour modifier un style, sélectionnez-le dans la liste ou tapez son nom puis cliquez sur le bouton Modifier. Vous pouvez également double-cliquer dans la liste des styles. La boîte de dialogue "Style" vous permet alors de modifier les constituants du style.

  • Pour créer un style, tapez son nom puis cliquez sur le bouton Ajouter.
    La boîte de dialogue "Style" vous permet alors de saisir les constituants du style.

  • Pour supprimer un style, sélectionnez-le dans la liste ou tapez son nom puis cliquez sur le bouton Supprimer.

Remarque : si le nom dans la liste est précédé d'une étoile, cela signifie que le style correspondant se trouve dans la feuille de styles de surcharge.

 

Un style est constitué d'un nom de police, de couleur de fond, de bordure et de padding dans la feuille de styles.
