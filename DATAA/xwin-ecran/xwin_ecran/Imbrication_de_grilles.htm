Imbrication de grilles

 

Chaque cellule d'une grille peut inclure une nouvelle grille, sans limite au nombre de niveaux d'imbrication.

 

Pour faciliter leur visualisation dans Xwin, les grilles imbriquées changent cycliquement de couleur. Xwin utilise :

  • Une 1ère couleur pour les grilles de niveau 3N+1,

  • une 2ème couleur pour les grilles de niveau 3N+2,

  • une 3ème couleur pour les grilles de niveau 3N+3 (N = 0, 1, 2, ...).

Par défaut, les trois couleurs utilisées pour l'affichage des grilles dans Xwin sont Noir, Rouge et Bleu mais vous pouvez personnaliser ces couleurs. Pour cela :

  • Sélectionnez le choix Options du menu Outils puis le chapitre Environnement : Police et couleurs.

  • Sélectionnez l'élément "Grille Niveau n" voulu dans la liste des Eléments affichés.

  • Sélectionnez une couleur de bordure : 16 couleurs de base sont accessibles dans la liste des choix du multi-choix correspondant.
    Pour obtenir une autre couleur, cliquez sur le bouton Personnaliser correspondant, qui fait appel à la boîte de dialogue "Couleurs" standard de Windows.
