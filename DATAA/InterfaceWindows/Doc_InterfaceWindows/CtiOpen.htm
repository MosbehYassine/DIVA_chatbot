CtiOpen Famille  Thème

CtiOpen initialise la gestion des appels.

 

Int CtiOpen (voie , caractère , mode_entrant)

 

Paramètres

Voie

Mettre la valeur 1.

Caractère

Caractère qui sera placé dans le tampon du clavier lorsqu’un appel entrant sera détecté.

Ce caractère pourra être lu par une instruction Getbchar . Si l’appel entrant doit pouvoir être détecté pendant la saisie d’un masque Harmony, il faut mettre un point d’arrêt sur la touche correspondante.

Si l’appel a lieu pendant une instruction XmeConsult ou XmeListConsult, Harmony.Key contient le code de retour clavier correspondant.

Une fois le caracètre lu, le programme doit boucler sur la fonction CtiReadEvent pour lire les evénements.

Mode_entrant

Booléen indiquant si les appels entrants doivent être traités.

Attention, un seul programme peut être en mode entrant.

Lorsqu’un programme se met en mode appels entrants, il devient serveur de l’objet Cti et traite les fonctions CtiDial et CtiDrop des autres programmes (avec Mode_entrant = FALSE).

 

Retour

0

Pas d’erreur.

Autre

Erreur

 

Exemple 1

 Ouverture en mode sortant et appel d’un numéro de téléphone

 

 CtiOpen(1," ",FALSE)   ; ouverture

 CtiDial( "0145637215") ; appel d'un numéro de téléphone

 CtiClose               ; fermeture du module cti
