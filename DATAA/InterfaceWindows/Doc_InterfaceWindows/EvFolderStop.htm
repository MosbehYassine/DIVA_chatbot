EvFolderStop  Famille  Thème

La fonction EvFolderStop permet d’arrêter la surveillance d’un répertoire précis ou de tous les répertoires.

 

module "ysystemex.dhop"

Ptr EvFolderStop ( ticket )

 

Paramètres

Ticket

Ticket du répertoire dont on veut arrêter la surveillance. Ce ticket a été rendu préalablement par la fonction EvFolderStart .

Si Ticket = 0 la surveillance de tous les répertoires est arrêtée.

 

Retour

0

Erreur.
