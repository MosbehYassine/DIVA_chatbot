Introduction aux fonctions "Drag and Drop"

Grâce aux fonctions Drop… il est possible de faire glisser des fichiers depuis l’explorateur de fichiers Windows dans une fenêtre Harmony.

Lorsque des fichiers sont déposés dans une fenêtre Harmony, un point d’arrêt est délenché et le programme peut alors lire le nom des fichiers puis effectuer un traitement sur ces derniers.

A l'occasion du point d'arrêt, on peut récupérer les informations suivantes sur le lieu du drag :

Harmony.DropId = Identifiant de l'objet tableau si le drag a eu lieu "sur" un tableau ; 0 sinon.

Dans le cas d'un tableau :

          Harmony.SourisPosX = numéro de colonne

          Harmony.SourisPosY = numéro de ligne
