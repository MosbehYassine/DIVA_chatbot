EvFolderStart  Famille  Thème

 

La fonction EvFolderStart permet d’indiquer le nom d’un répertoire à surveiller.

Elle peut être appelée plusieurs fois afin de surveiller plusieurs répertoires.

Voir également EvFolderStartFilter qui permet de préciser les événements à surveiller.

 

module "ysystemex.dhop"

Ptr EvFolderStart ( dir )

 

Paramètres

Dir

Nom du répertoire à surveiller.

Ce nom doit être au format Windows.

Le répertoire peut être local ou sur une autre machine via le réseau (sauf répertoire réseau d’une machine 95, 98 ou Millenium).

 

 

Retour

0

Erreur, la surveillance du répertoire n'a pas pu être initialisée.

Attention : si le répertoire n'existe pas, la fonction ne retourne pas d'erreur, mais elle refait des tentatives à intervalles réguliers pour voir si le répertoire existe. Cela peut être le cas si vous surveillez un répertoire situé sur le réseau et que l'ordinateur n'est pas encore démarré. Dans ce cas, la surveillance deviendra opérationnelle dès que possible sans que le programme Diva aie quelque chose à faire.
Par contre, si le nom du répertoire est erroné, la fonction ne sort pas d'erreur et la surveillance n'est pas opérationnelle.

Autre

Ticket. La fonction EvFolderGet de lecture d’un événement retourne la valeur de ce ticket pour indiquer le répertoire qui a provoqué l’événement.

 

Exemple 1

Le sous-projet EvFolder du projet exemples.dhpt contient un exemple complet de surveillance de répertoire et de traitement des fichiers.

 

Exemple 2

Surveillance de deux répertoires dans un programme qui fonctionne en tâche de fond. Comme il n’y a pas de masque harmony, le programme utilise getbchar pour attendre un événement.

 

module "ysystemEx.dhop"

main

1 ticket1 X

1 ticket2 X

1 dir     260

1 fini    X

1 car     1

1 i       L

 

i = EvFolderOpen($e0,60*15)                 ;touche F1

ticket1 = EvFolderStart("e:\divalto\temp") 

ticket2 = EvFolderStart("e:\divalto\tmp") 

; si ticket = 0 alors il y a une erreur , le répertoire n'existe pas

; sinon ticket contient le numéro d'événement qui sera transmis

; au programme diva

 

;puis le programme diva doit attendre l'événement

fini = 0

do

while fini = 0

 car = getbchar          ;attente d'un événement

 if car = "F" or car = "f" or car = $e8     ;touche f9

  ;on sort directement il ne faut pas regarder s'il y a des messages

  ;car c'est peut être l'arrêt de la machine et on aura pas le temps

  ;de traiter les messages

  display "Fin du programme "

  fini = 1

 else

  if car = $e0

   do

   i = EvFolderGet    ; on lit l'événement, à faire

                      ; obligatoirement pour vider la

                      ; liste des événements

                      ; si i = 0 alors plus de message

   while i <> 0    

                      ; on traite l'événement

    if i = ticket1

     display "Evenement sur " & "e:\divalto\temp"

    elsif i = ticket2

     display "Evenement sur " & "e:\divalto\tmp"

    endif

   wend

  endif

 endif

wend

 

; Fermeture de la dll

EvFolderClose  

 

 

Exemple 3

Surveillance de deux répertoires dans un programme qui exécute la saisie d’une page de masque.

Les données en saisie du masque doivent piéger la touche paramétrée dans EvFolderOpen .

 

module "ysystemEx.dhop"

main

1 ticket1 X

1 ticket2 X

1 dir     260

1 fini    X

1 car     1

1 i       L

xmeLoad("etest.dhoe")

 

 

i = EvFolderOpen($e0,60*15)

ticket1 = EvFolderStart("e:\divalto\temp") 

ticket2 = EvFolderStart("e:\divalto\tmp") 

 

; saisie du masque

; la touche f1 génère le point d’arrêt 100

xmeinput (harmony.masque,1,0,0)

 

fini = 0

do

while fini = 0

 switch harmony.dataarret

 case Harmony.Key = K_F9

  fini = TRUE

 case 100   

  do

  i = EvFolderGet        ; on lit l'événement

                         ; si i = 0 alors plus de message

  while i <> 0    

   if i = ticket1

    MessageBox("Evenement sur " & "e:\divalto\temp"," ")

   elsif i = ticket2

    MessageBox("Evenement sur " & "e:\divalto\tmp"," ")

   endif

  wend

 endswitch

wend

 

; Fermeture de la dll

EvFolderClose
