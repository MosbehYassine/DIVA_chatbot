DropFilesRead  Famille  Thème

La fonction DropFilesRead permet de lire un nom de fichier qui a été déposé dans la fenêtre du programme en cours. Des appels successifs à DropFilesRead permettent de lire l’ensemble des fichiers déposés.

 

Int DropFilesRead (fichier)

 

Paramètre

Fichier

Variable alphanumérique qui reçoit le nom du fichier.

 

Retour

0

Pas d’erreur. Fichier contient un nom de fichier.

H_EOF

Fin de la liste des fichiers atteinte.

 

Remarque

  • Harmony provoque un point d’arrêt pour indiquer au programme que l’utilisateur a déposé des fichiers dans la fenêtre du programme. Voir DropFilesOpen .

 

Exemple

Voir dans le projet exemples.dhpt , le sous-projet DragFichier.

 

1 fichier  260

DropFilesOpen(5000)   ; active le drop files , celui ci générera

                      ; la point d'arrêt 5000

...

XmeInput(...)

Do

 Switch Harmony.DataArret

 Case 5000

  Loop DropFilesRead(fichier) = 0

   ...

  Endloop

 endif

while (not fini)

 XmeNext(harmony.retour,harmony.CplRetour)

wend

 

DropFilesClose  ; desactive le drop files
