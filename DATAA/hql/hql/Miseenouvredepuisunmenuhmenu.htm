Mise en œuvre depuis un menu

Le moteur hql peut être lancé depuis un menu du type Divalto. Pour cela on indiquera dans le menu le nom du module des chapitres comme nom de programme à enchaîner.

Le module des chapitres doit alors contenir une instruction "main" suivie du positionnement des paramètres et du lancement du moteur Xhql.

 

main

Hql.Modtrait = System.ZnomProg

Hql.Fichier = 'odfic.dhfi'

Hql.Enreg = 'article'

HqlHql

La fonction HqlHql lance le moteur Hql pour le module des chapitres courant.

Des paramètres peuvent être récupérés par la fonction PingReceive.
