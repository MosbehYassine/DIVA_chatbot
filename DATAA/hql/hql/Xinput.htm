Xinput  Famille Thème

 

La procédure Xinput lance la saisie d'une page par l'instruction XmeInput (en mode Goto).

 

Xinput [ page ]

 

Paramètres

Page

Numéro de page à saisir. La valeur par défaut est 1.

 

Remarques 

  • Cette fonction est utilisée dans le chapitre HqlDebutListe pour demander à l'utilisateur de saisir les paramètres de l'édition.

  • Si l'utilisateur abandonne la saisie de la page (Echap ou fermeture de la fenêtre), le programme Hql se termine par une instruction ProgramExit.

  • Il existe un modèle de masque d'écran (xqlm.dhse) que vous pouvez copier.
