Xfdate

La fonction Xfdate permet de faire des calculs sur une date. Elle est très utilisée pour les statistiques et les états de gestion.

date = Xfdate (opérations, date_origine , séparateur)


Paramètres

Opérations

Variable de trois caractères indiquant les opérations à effectuer sur le jour, le mois et l'année.

1er caractère

Opération sur le jour

0 = inchangé

1 = forcé à 1

9 = dernier jour du mois

 

2e caractère

Opération sur le mois

0 = inchangé

1 = janvier

9 = décembre

- = mois précédent

+ = mois suivant

 

3e caractère

Opération sur l'année

0 = inchangé

- = année précédente

+ = année suivante

Date_Origine

Date origine sous la forme AAAAMMJJ

Séparateur

Si un séparateur est précisé, le résultat est sous la forme jjSmmSaaaa

Dans le cas contraire, le résultat est sous la forme aaaammjj.


Exemples

Calcul des dates début et fin pour le mois

datedebut = Xfdate("100",time(1))

datefin = Xfdate("900",time(1))


Calcul depuis le début de l'année :

datedebutannee = Xfdate("110",time(1))


Calcul sur 12 mois glissants :

datedebut = Xfdate ('1--',time(1))

datefin = Xfdate ('9-0',time(1))
