L'enregistrement Hql

L'enregistrement Hql contient les paramètres d'appel de la fonction XHql. Il contient également des informations pour la communication entre le moteur Hql et le module de chapitres.

Fichier

Nom du fichier principal. Il s'agit du nom du fichier physique et non pas du nom dans le dictionnaire de données.

Enreg

Nom de l'enregistrement principal. Il doit être déclaré public dans le module des chapitres.

MsqEcran

Nom du masque écran pour les fonctions Xdisplay et Xinput. Par défaut c'est le nom du module des chapitres avec l'extension .dhoe.

ModTrait

Nom du module des chapitres. Ce paramètre est obligatoire. Le module des chapitres doit obligatoirement contenir la procédure HqlDebutListe (même si elle est vide) et la déclaration publique de l'enregistrement du fichier principal.

MsqImp

Nom du masque d'impression pour la fonction Xprint. Par défaut c'est le nom du module des chapitres avec l'extension .dhoi.

Status

Compte rendu de la fonction Xhql.

Cle

Valeur de la clé de départ du fichier de base si clemin et clemax ne sont pas positionnées. Cle contient également la clé courante dans le chapitre HqlSelection et peut être positionnée dans ce chapitre pour optimiser la lecture du fichier de base.

CleMin

Valeur de la clé minimale. C'est la clé de départ si le sens de lecture est normal.

CleMax

Valeur de la clé maximale. C'est la clé de départ si le sens de lecture est inverse.

Sens

Sens de lecture du fichier. ZOOM_NORMAL ou ZOOM_INVERSE.

Fabandon

Indicateur permettant l'arrêt du traitement en cours par l'opérateur. Par défaut sa valeur est ZOOM_OUI. Pour interdire l'abandon du traitement en cours (par exemple lors d'un traitement par lot en mise à jour du fichier) il convient de positionner Hql.Fabandon à la valeur ZOOM_NON.

Ok

La variable Hql.Ok est testée par le moteur Hql au retour de certains chapitres. Elle permet par d'exemple d'ignorer les enregistrements dans le chapitre HqlSelection.

Version

Contient le numéro de version du moteur Hql.

Date

Contient la date du jour. Elle peut être utilisée dans les masques.

Heure

Contient l'heure au format hh:mm.

NbFiches

Contient le nombre de fiches lues.

NbTotal

Contient le nombre total de fiches lues si l'algorithme comporte un tri du fichier.

Icone

Nom d'un fichier d'icônes permettant de modifier l'icône de la barre de titre de la fenêtre. Voir NoIcone.

NoIcone

Numéro de l'icône du fichier d'icônes. Une valeur différente de zéro indique qu'il faut changer l'icône de la barre de titre de la fenêtre.

Titre

Variable pouvant être utilisée comme titre dans les masques.

Dt1

Variable pouvant être utilisée comme date de départ.

Dt2

Variable pouvant être utilisée comme date de fin.

Z1

Variable pouvant être utilisée pour afficher l'état d'avancement des travaux.

Npage

Numéro de page.

Programme

Nom du programme à enchaîner à la fin du traitement. Ce paramètre n'est pas pris en compte si le moteur Hql est lancé par la fonction xhql (compatibilité xql5).
