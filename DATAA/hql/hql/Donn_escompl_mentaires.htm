Données complémentaires

Xhql lit séquentiellement un fichier de base dont le nom est passé en paramètre à la fonction Xhql. Des informations complémentaires liées peuvent être lues dans certaines procédures du module des chapitres.

  • Dans le chapitre HqlSelection si les critères de sélection portent sur les données complémentaires.

  • Dans le chapitre HqlDetail, assez naturellement, pour les données complémentaires directement liées à l'enregistrement principal.

  • Dans le chapitre HqlLecture si les critères de rupture de début portent sur des données complémentaires.

  • Dans les chapitres Debut ou Fin si les données complémentaires se rapportent aux critères de rupture, par exemple le nom du département pour une rupture sur les deux premiers caractères du code postal.

Exemple

Recherche du nom du fournisseur associé à un article.

public hfile exodd ffour tdffour

public record exodd four

procedure HqlSelection

beginp

 if article.codfour <> "F1"

  Hql.Ok = 'I'

 endif

endp

 

procedure HqlDetail

beginp

 Hseek(tdffour, four, 'A' & article.codfour, 'F')

 Xprint

endp

Remarques

  • Le fichier complémentaire est déclaré à l'aide de l'instruction Diva hfile.

  • De même, l'enregistrement du fichier fournisseur est déclaré par l'instruction Record. Attention à ne pas oublier de le déclarer public afin de pouvoir éditer les données de cet enregistrement.

  • La recherche du fournisseur associé à l'article en cours est faite dans le chapitre HqlDetail, juste avant l'impression du bloc détail.

Attention

Dans les traitements comportant des ruptures de fin, lorsque les données complémentaires ne sont pas recherchées dans les chapitres de rupture de fin, elles correspondent à celles de l'enregistrement précédent. Pour pallier cet inconvénient, la procédure HQLRecord permet de déclarer au moteur HQL les enregistrements complémentaires faisant l'objet d'un traitement dans les chapitres de rupture de fin.
