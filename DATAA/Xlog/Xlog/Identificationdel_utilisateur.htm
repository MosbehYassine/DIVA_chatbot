Identification de l'utilisateur

Décliner son identité n'est possible que si celle-ci est enregistrée dans le fichier des utilisateurs. Si vous ne disposez pas encore d'un code d'identification, consultez l'administrateur du système pour qu'il vous en attribue un.
 
Lorsque vous appelez Xlog.dhop, celui-ci :

  • Enregistre votre code utilisateur. La connaissance de ce code est imposée par la plupart des applications.

  • Modifie vos chemins implicites et vos droits d'accès. Ainsi, lorsque vous travaillez avec une application Harmony, vous retrouvez toujours votre contexte d'exécution personnel.
