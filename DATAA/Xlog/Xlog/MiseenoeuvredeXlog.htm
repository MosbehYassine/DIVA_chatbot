Mise en oeuvre de Xlog

XLOG demande d'introduire votre code et, s'il y a lieu, votre mot de passe :

Code utilisateur

Mot de 20 caractères quelconques qui permet au système Harmony de vous identifier. Les lettres minuscules, y compris les accentuées, sont automatiquement converties en majuscules.

Mot de passe

Suite de caractères quelconques (24 au maximum) permettant de protéger votre code utilisateur.
Attention, les caractères minuscules et majuscules ne sont pas équivalents.
