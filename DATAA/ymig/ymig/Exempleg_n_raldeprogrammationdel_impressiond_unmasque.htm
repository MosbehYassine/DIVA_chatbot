Exemple général de programmation de l'impression d'un masque

Remarque préliminaire :

Nous considérons ici comme acquises certaines notions fondamentales de la programmation sous Harmony : déclaration des chemins implicites, paramétrage et mise en œuvre des projets dans l'éditeur Xwin, création des bases, tables et champs dans le dictionnaire, création d'un masque, dessin et paramétrage des objets dans un masque, etc.

 

Cette rubrique présente un cas classique de programmation d'une impression sous Harmony. Vous y trouverez des explications détaillées sur la manière d'obtenir l'état qui constitue notre exemple type et, plus précisément, sur :

  • Le paramétrage du masque dans Xwin.

  • L'écriture du programme d'impression.

 

1. Création et paramétrage du masque d'impression

  • Création du fichier masques.
    Lancez le programme Xwin.
    Sélectionnez le choix Nouveau du menu Fichier.
    Sélectionnez le choix Masque imprimante et validez.
    Sélectionnez le choix Enregistrer Sous du menu Fichier.
    Donnez un nom au nouveau fichier masques (par exemple, ILISTE.dhsi) et enregistrez-le.

  • Déclaration des enregistrements utilisés dans le masque.
    Sélectionnez le choix Enregistrements du menu Paramètres.
    Ajoutez l'enregistrement SYSTEM du dictionnaire DDSYS.dhsd (pour la donnée System.Zpage contenant le numéro de page) et le ou les enregistrements contenant les variables à imprimer.

  • Paramétrage global du masque.
    Sélectionnez le choix Masque du menu Paramètres.
    Entrez le Libellé : Exercice Harmony (commentaire).
    Cochez un des boutons radio du groupe Hauteur de page (Cf. rubrique Réglage de la hauteur de page) :
    -     Si vous optez pour le bouton d'après le masque, vous devez garnir le champ Nombre de lignes avec le nombre de lignes que vous voulez faire figurer sur chaque page.
    -     Si vous optez pour le bouton d'après le modèle, vous pourrez choisir le nombre de lignes par page en sélectionnant un modèle d'imprimante (la notion standard de modèle d'imprimante est définie dans le manuel de référence d'Harmony ; rappelons également qu'un modèle est chargé dès que vous faites appel à un menu de type Divalto).

  • Paramétrage et dessin du bloc 1 (en-tête).
    Sélectionnez le choix Bloc courant du menu Paramètres (raccourci clavier : F3).
    Entrez le Libellé : En-tête (commentaire).
    Sélectionnez le Type de bloc : Fixe.
    Position début     : 1.
    Position fin     : 7.
    Débordement     : 0.
    Chaînage     : 0.
    Validez la boîte de dialogue Caractéristiques du bloc.
     
    Dessinez le masque " en-tête " suivant (7 lignes) :

DIVALTO  PAGE page (*)

(*) Pour imprimer le numéro de page, placez dans votre masque la donnée standard Zpage de l'enregistrement SYSTEM (dictionnaire DDSYS.dhsd).

  • Paramétrage et dessin du bloc 2 (ligne détail).
    Tapez la touche Page-Down.
    Répondez Oui à la demande de création du bloc 2.
    Sélectionnez le choix Bloc courant du menu Paramètres (raccourci clavier : F3).
    Entrez le Libellé : Ligne détail (commentaire).
    Sélectionnez le Type de bloc : Mobile.
    Nombre de lignes     : 1.
    Position début     : 8.
    Position fin     : -4.
    Débordement     : 3.
    Chaînage     : 0.
    Validez la boîte de dialogue Caractéristiques du bloc.
     
    Dessinez le masque " ligne détail " suivant (1 ligne) :

| Code | Nom | Catégorie |  (*)

(*) Code, Nom et Catégorie sont trois données de l'enregistrement compositeur.

  • Paramétrage et dessin du bloc 3 (bas de cadre).
    Tapez la touche Page-Down.
    Répondez Oui à la demande de création du bloc 3.
    Sélectionnez le choix Bloc courant du menu Paramètres (raccourci clavier : F3).
    Entrez le Libellé : Bas de cadre (commentaire).
    Sélectionnez le Type de bloc : Mobile.
    Nombre de lignes     : 1.
    Position début     : 9.
    Position fin     : -3.
    Débordement     : 0.
    Chaînage     : 4.
    Validez la boîte de dialogue Caractéristiques du bloc.

    Tapez la touche Page-Down.
    Répondez Oui à la demande de création du bloc 4.
    Sélectionnez le choix Bloc courant du menu Paramètres (raccourci clavier : F3).
    Entrez le Libellé : Pied de page (commentaire).

  • Positionnement des blocs dans la page.
    Rappelons que les positions des blocs :
    -     Strictement positives sont relatives au début de la page.
    -     Négatives ou nulles sont relatives à la fin de la page.

  • Affichage d'une " grille ".
    Pour vous aider à calculer le nombre de lignes et de colonnes d'un bloc, affichez une " grille " en sélectionnant le choix (de type case à cocher) Grille du menu Options.
    La couleur de la grille peut être changée en sélectionnant le choix Couleur grille du menu Options.

  • Affichage de blocs " en transparence ".
    Pour vous aider à " cadrer " les différents blocs les uns par rapport aux autres, utilisez la notion d'affichage en transparence. Par exemple, au niveau du bloc 1, affichez le bloc 2 en transparence, ce qui vous permettra de positionner correctement le cadre dessiné dans l'en-tête relativement aux données de la ligne détail. Pour cela :
    Placez-vous sur le bloc 1 du masque.
    Tapez F3 pour afficher les paramètres du bloc 1.
    Entrez les paramètres suivants dans le cadre Transparence :
    Blocs     : 2.
    Positions     : 8.

  • Simulation de l'impression.
    Pour vérifier rapidement le bon " cadrage " relatif des blocs, sélectionnez le choix Simuler un état du menu Blocs.
    Entrez successivement :
    Bloc     : 1 Nombre de fois : 1
    Bloc     : 2 Nombre de fois : 5
    Bloc     : 3 Nombre de fois : 1
    Bloc     : 4 Nombre de fois : 1
    Validez la boîte Paramètres de l'état.
    Après consultation, tapez Return pour revenir au masque.

 

2. Ecriture du programme d'impression

Saisissez les lignes de programme suivantes :

;Exemple de programmation de l'impression d'un masque

 

HFILE         Appli.dhsd Fcomp Fcomp    ;fichier compositeurs 

PUBLIC RECORD Appli.dhsd Comp           ;enregistrement compositeur

 

1 cr X

 

 

;Programme principal

MAIN

 

XmiLoad ("ILISTE.dhoi")                 ;chargement du masque

cr = PrintBegin                         ;réservation de l'imprimante

IF cr <> 0

   ...                                  ;traitement de l'erreur 

ENDIF

 

;Impression de la première en-tête

XmiPrint ("ILISTE.dhoi", 1)

 

;Boucle de lecture du fichier compositeurs

;avec impression du bloc détail

LOOP ((cr := FREAD (Fcomp, Comp, "F")) =0)

   XmiPrint ("ILISTE.fhoi", 2)

ENDLOOP

 

IF cr <> 2

   FERROR Fcomp cr                      ;erreur fatale

ENDIF

 

;Fin du fichier : impression du dernier bas de cadre

;et du dernier pied de page avec Harmony.Ichainage = FALSE

XmiPrint1 ("ILISTE.dhoi", 3, FALSE, Harmony.Ideborde, \

           Harmony.IsautAvant, Harmony.IsautApres) ;(1) 

XmiPrint ("ILISTE.dhoi", 4)                        ;(2)

 

cr = PrintEnd                           ;libération de l'imprimante

IF cr <> 0

   ...                                  ;traitement de l'erreur 

ENDIF

PROGRAMEXIT                             ;fin du programme

(1) On ne sait pas désactiver uniquement le chaînage bloc 4 (pied) --> bloc 1 (en-tête), car le bloc 4 est lui-même automatiquement appelé par le bloc 3 (fermeture du cadre) : on désactive donc les chaînages dès l'appel du bloc 3.
Harmony.Ideborde, Harmony.IsautAvant et Harmony.IsautApres conservent ici leur valeur par défaut (TRUE).

(2) Harmony.Ichainage conserve sa valeur (FALSE) après le XmiPrint1 : on peut donc exécuter la procédure XmiPrint pour imprimer le pied sans chaîner sur l'en-tête.
