XmiPageLength  Famille Thème

Lecture du nombre de lignes par page

 

Int XmiPageLength

 

Valeur rendue par la fonction : Nombre de lignes imprimées par page, qui dépend du paramétrage effectué dans le masque Xwin (Cf. rubrique Réglage de la hauteur de page), à savoir :

  • Valeur courante de la donnée Harmony.Inblignes si, dans les paramètres généraux du masque, vous avez coché la case "d'après le modèle" (cadre Hauteur de page).

  • Valeur indiquée dans le champ Nombre de lignes des paramètres généraux du masque si vous avez coché la case "d'après le masque".

La fonction renvoie 0 si aucun masque d'imprimante n'a encore été chargé.

 

Description de la fonction : La fonction XmiPageLength délivre la taille de la page en nombre de lignes. Elle peut être appelée dès qu'un masque a été chargé (XmiLoad).

 

Exemple :

NbLigParPage = XmiPageLength
