XmiInfoBloc  Famille Thème

Lecture des caractéristiques d'un bloc

 

XmiInfoBloc (Nom du fichier masque, Numéro de bloc)

 

Paramètres :

Nom du fichier masque
(Harmony.Imasque)

Nom du fichier masque (fichier objet, 32 caractères maximum).
Le cas échéant, l'extension .dhoi doit être précisé.

Numéro de bloc
(Harmony.Ibloc)

Numéro de bloc.

 

Description de la fonction :

XmiInfoBloc permet d'obtenir des informations sur le bloc identifié par un Nom de fichier masque et par un Numéro de bloc dans ce fichier. Elle renvoie les caractéristiques saisies par Xwin. Si le masque ou le bloc indiqué n'existe pas, aucune erreur n'est détectée mais tous les paramètres de retour sont positionnés à 0.

Au retour de la fonction, les informations sont disponibles dans les données Opara1 à Opara12 de l'enregistrement Harmony :

Harmony.Opara1

Nombre de lignes du bloc.

Harmony.Opara2

Type du bloc (1=Fixe, 2=Mobile, 3=Fond, 4=Tableau).

Harmony.Opara3

Numéro de ligne début (*).

Harmony.Opara4

Numéro de ligne fin (*).

Harmony.Opara5

Numéro de bloc si débordement.

Harmony.Opara6

Numéro de bloc si chaînage.

Harmony.Opara7

Saut de page début (1=non, 2=oui).

Harmony.Opara8

Saut de page fin (1=non, 2=oui).

Harmony.Opara9

Numéro de point d'arrêt Avant.

Harmony.Opara12

Numéro de point d'arrêt Après.

(*) Harmony.Opara3 et Harmony.Opara4 peuvent prendre des valeurs négatives. Le codage utilisé est le suivant :

[ 1     .. 32767 ] : valeur positive

[ 32768 .. 65535 ] : valeur négative

                     avec 32768 <=> 0

                          65535 <=> -32767

Exemple : 32774 <=> 32768 - 32774 = -6.

 

Exemple :

XmiInfoBloc ("MASQUE.dhoi",4) ;demande d'informations sur le

                              ;bloc 4 du fichier masque "MASQUE"
