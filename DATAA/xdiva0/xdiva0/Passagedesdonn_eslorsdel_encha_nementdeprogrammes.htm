Passage des données lors de l'enchaînement de programmes

En Diva, le seul moyen de transmettre des données d'un programme à un autre est l'utilisation du tunnel. Le programme qui va enchaîner à un autre programme doit donc placer les données dans le tunnel par Ping et le nouveau programme doit les récupérer par PingReceive.

Le menu d'Harmony place la zone Zechange dans le tunnel avec le nom "zechange". Les programmes appelés doivent donc récupérer cette zone.

Exemple :

Main

PingReceive("zechange" , zechange)
