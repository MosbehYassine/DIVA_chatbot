Exemple

Pour illustrer la notion de surcharge multiples, nous partirons d'un exemple, ce qui facilitera la compréhension.

Add-on Italy

Notre premier add-on se nommera Italy. Il contient des éléments pour adapter Divalto à la législation particulière de l'Italie.

Add-on Maroquinerie

Notre second add-on se nommera Maroquinerie. Il contient des éléments pour adapter Divalto aux spécificités de la maroquinerie.

Un partenaire pourra donc utiliser ces add-ons pour les clients finaux suivants :

  1. Le Tanneur : c'est un maroquinier français, donc seul l'add-on Maroquinerie sera utilisé
    Le partenaire pourra également lui-même encore ajouter des données pour traiter les particularités de l'entreprise Le Tanneur.

  2. Tuscany : c'est un maroquinier italien, donc les deux add-ons Italy et Maroquinerie seront utilisés.
    Le partenaire a toujours la possibilité de rajouter une surcharge sur ces deux add-ons pour traiter les particularités de l'entreprise Tuscany.

Remarque : l'ordre des Add-ons est défini dans un fichier paramètres : overwrite.txt.
