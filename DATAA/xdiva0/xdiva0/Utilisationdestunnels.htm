Utilisation des tunnels

Un tunnel est une liste de données dont chaque élément est identifié par un libellé.

Les instructions Ping et Pong permettent d'introduire des données dans un tunnel, les instructions PingReceive et PongReceive permettent d'extraire des données du tunnel.
PingReceive permet de lire les données placées dans le tunnel par l'instruction Ping, PongReceive permet de lire les données placées par Pong.

PingReceiveAndDelete, PongReceiveAndDelete permettent de lire les données d’un tunnel et de les supprimer du tunnel.

Lors de l'introduction d'une donnée dans un tunnel (Ping ou Pong), si un élément du tunnel existe déjà avec le même libellé il est remplacé par les nouvelles données.


Exemple

Programme2

Ping( "client", Client)
Ping("article", Article)
ProgramCall ("Programme2")
