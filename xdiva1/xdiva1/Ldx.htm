Ldx  Famille

 

La fonction Ldx convertit une zone mémoire de deux octets en type X


Ptr = ldx (donnée)


Paramètre

Donnée

Variable de deux octets à transformer en donnée de type X. Si le processeur stocke les données de type X sous la forme Poids Faibles - Poids Forts cas des processeurs Intel), la fonction Ldx assure l'inversion.


Retour

Le résultat est une valeur de type X


Remarques

Les fonctions Ldx et Stx permettent d'utiliser des données de type X de façon indépendante de la manière dont le processeur les stocke. En effet, les processeurs Intel et Alpha de Digital, stockent les données de type X dans l'ordre Poids Faibles - Poids Forts, et tous les autres les stockent dans l'ordre Poids Forts - Poids Faibles.

Si des données de type X sont transmises sur le réseau ou sur une voie série, il est indispensable d'utiliser les fonctions Stx et Ldx pour mettre les données à un format indépendant du processeur, car le type du processeur de l'ordinateur récepteur est inconnu.
