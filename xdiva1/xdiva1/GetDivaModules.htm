GetDivaModules Famille Thème

 

La fonction GetDivaModules permet de récupérer la liste de tous les modules diva (.dhop) chargés.

 

char GetDivaModules ( FiltrerY, FiltrerCourant )

 

Paramètres

FiltrerY

Les modules système (Y*) ne sont pas rendus dans la liste.

FiltrerCourant

Le module courant n'est pas rendu dans la liste.

 

Retour

La fonction retourne une chaîne HMP avec les noms de modules.

Attention : en mode surcharge multiples, la fonction retourne des noms longs (chemin + nom_du_module). Par défaut, seul le nom final est retourné.
