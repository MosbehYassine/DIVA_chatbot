GetAdressProcedure  Famille Thème

 

La fonction GetAdressProcedure permet d'obtenir l'adresse d'une Procédure en vue de son exécution par l'instruction ProcedureCall.

 

Long GetAdressProcedure ( module , procédure , adresse)

 

Paramètres

Module

Nom du module dans lequel se trouve la procédure. Si module est à espaces, la procédure est recherchée dans le module courant. Ne spécifiez pas de chemin, la fonction l’ignore et ouvre le module suivant les implicites.

Procédure

Nom de la procédure à rechercher.

Adresse

Zone alphanumérique de 16 octets qui recevra l'adresse de la procédure. Cette adresse sera utilisée pour l'appel de la procédure.

 

Retour

0

Pas d'erreur

1

Procédure non trouvée dans le module

2

Module absent

Toutes les autres erreurs provoquent un arrêt du programme en cours.

En retour, la zone Adresse contient l'adresse de la procédure.

 

Exemples

1 adr 16

1 st L

; recherche de l'adresse de la procédure 

; AfficheClient dans le module courant

t = GetAdressProcedure(" ","AfficheClient", adr) 

 

; recherche de l'adresse de la procédure

; ImprimerArticle dans le module gtm210

st = GetAdressProcedure("gtm210","ImprimerArticle",adr)
