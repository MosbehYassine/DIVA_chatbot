Fonctions de gestion de fichiers Windows

Diva propose un ensemble de fonctions permettant d'utiliser les API Windows de gestion de fichier. La plupart ont le même nom que dans la bibliothèque Windows mais préfixées par "Win" ; ainsi la fonction d'ouverture de fichier qui s'appelle CreateFile se nomme WinCreateFile en Diva.

Elles permettent :

·          d'ouvrir un fichier quelque soit son emplacement,

·          de lire ou des d'écrire des données,

·          de copier ou renommer un fichier,

·          d'appeler la boîte de dialogue standard de Windows pour la sélection d'un ou plusieurs fichiers,

·          de connaître le nom des répertoires utilisés par Windows (répertoire Windows, Système etc.),

·          de créer ou de supprimer des répertoires,

·          de parcourir les répertoires de Windows.

·          de lire et écrire les fichiers .ini

·          d'accéder à la base de registres

·          de sélectionner une imprimante et d’imprimer un fichier

 

L'usage de ces fonctions est réservé à des applications particulières comme l'interface avec d'autres applications (traitement de texte, tableur) ou pour des applications "système".
