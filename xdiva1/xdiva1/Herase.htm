Herase  Famille Thème

 

Herase efface le contenu du fichier.
S'il s'agit d'un fichier séquentiel indexé, le fichier des données est effacé et le fichier des clés est réinitialisé.
Le fichier doit avoir été préalablement ouvert (en mode réservé de préférence).


Ptr = Herase ( tdf )


Paramètres

Tdf

Table de définition de fichier.

  

Retour

0  

Pas d'erreur.

 

Toutes les erreurs provoquent l'arrêt du programme.
