Fonctions OpenXml

Ce livre décrit l’utilisation du module yOpenXml.dhop, qui permet :

  • La lecture et l'écriture de cellules dans des fichiers Excel au format .xlsx.

  • La gestion du publipostage dans MS Word.

Les fichiers Office d’extension .xlsx, .docx, .pptx, etc. sont des fichiers au format OpenXml (norme ISO, introduite par Microsoft). Ces fichiers sont des archives comprimées contenant des fichiers xml et répondant à la norme.

 

Remarque :

yOpenXml ne remplace pas yOffice. Il modifie directement les données du fichier alors que yOffice pilote l’application pour réaliser les opérations.

 

Le module fait appel à trois librairies :

  • DocumentFormat.OpenXml.dll : dll Microsoft de gestion des formats OpenXml.

  • DhDivaltoOpenXml.dll : dll Divalto gérant les appels à la librairie OpenXml.

  • WindowsBase.dll : dll contenant les fonctions de base utilisées par les dll précitées.

 

Avantages

  • Il n’est pas nécessaire d’installer Office (MS ou Open) sur le serveur pour utiliser la librairie.

  • La lecture et l’écriture des cellules sont nettement plus rapides que ces mêmes opérations pilotées par des fonctions OLE Automation.
    Il en résulte un gain important de performance, notamment pour les imports / exports volumineux.

  • La technologie utilisée repose sur une librairie standard fournie par Microsoft et permettant de gérer les documents Word, Excel, Powerpoint, etc.

  • Les fichiers générés sont lisibles aussi bien dans Excel ou MS Word que dans Open-Office.

 

Limitations

  • La couverture fonctionnelle de yOpenXml est moins étendue que celle de yOffice.

  • Le module s’exécute uniquement côté serveur. Le fichier à traiter doit donc obligatoirement se trouver sur le serveur.
    En mode client léger, si le fichier se trouve sur l'ordinateur client, il doit être téléchargé sur le serveur puis renvoyer vers le client à la fin du traitement.

  • Les formules de la feuille de calcul ne sont pas réévaluées lors de l’écriture d’une cellule (contrairement à yOffice).
    C’est également le cas pour les calculs effectués dans MS Word.

  • Les documents ne sont pas compatibles avec les versions d'Office inférieures à Office 2007.
     

 

Couverture fonctionnelle de yOpenXml

Les fonctions de yOpenXml gèrent les opérations suivantes :

  • Tableur Excel :

    • Ouverture ou création d’un fichier .xlsx.

    • Lecture de la valeur d’une cellule.

    • Gestion des onglets (ou feuilles) : choix de l’onglet (ou feuille), création, duplication, suppression.

    • Modification de la largeur d’une colonne.

    • Ecriture d’une cellule :

      • Plusieurs formats de données sont supportés : texte, date, numérique, etc.

      • Définition d’un style pour le texte de la cellule : police, taille et couleur de caractères, attributs (gras, souligné, ...).

      • Définition d’une couleur de fond pour la cellule.

    • Gestion des plages de cellules nommées.

    • Lecture et écriture de formule.

    • Lecture et écriture de cellule dans un fichier.

    • Sauvegarde du fichier après modification.
       

  • Document Word (publipostage) :

    • Ouverture ou création d’un fichier .docx.

    • Publipostage.

    • Cherche / Remplace d’un texte par un autre.

    • Ajout d’une image, d’un fichier .rtf, d’un autre document .docx.

    • Insertion d’un paragraphe avec ajout de texte.

 

Mise en oeuvre

  • Le programme Diva doit déclarer le module par : module "yOpenXml.dhop".

  • Il doit charger la dll avant son utilisation en appelant la fonction OpenXml_Begin et doit la décharger avant de se terminer en appelant la fonction OpenXml_End.
     

  • Gestion des fichiers Excel .xlsx :

    • Le programme appellera la fonction OpenXml_FileOpen pour charger ou créer un fichier .xlsx puis la fonction OpenXml_FileClose pour mettre le fichier à jour et le refermer. Lorsque le fichier est ouvert, on peut :

    • Se positionner sur une feuille avec la fonction OpenXml_GotoSheet.
      Connaître le nom de la feuille courante par la fonction OpenXml_CurrentSheet.
      Dupliquer la feuille courante par la fonction OpenXml_CopySheet.
      Supprime une feuille par la fonction OpenXml_DeleteSheet.
      Connaître la liste des noms de feuille par la fonction OpenXml_ListSheet.
      Connaître la taille de la feuille Excel avec OpenXml_GetSizeSheet puis OpenXml_GetStartRow / OpenXml_GetEndRow / OpenXml_GetStartColumn /  OpenXml_GetEndColumn.

    • Lire des cellules avec OpenXml_Read et OpenXml_ReadCellByName.
      Connaître le type du contenu de la cellule lue par la fonction OpenXml_GetTypeLastRead.

    • Définir la taille des colonnes avec OpenXml_ColumnWidth.

    • Créer une police avec la fonction OpenXml_CreateFont.

    • Ecrire des cellules avec OpenXml_WriteFormat.

    • Créer une plage de cellules nommées par la fonction OpenXml_AppendNameCell.
      Lire les caractéristiques d'une plage de cellules nommées par la fonction OpenXml_ReadNameCell.
      Lire les caractéristiques d'une plage dans la table des cellules nommées par la fonction OpenXml_ReadNameCellIdx.
      Lire le nombre d’entrées dans la table des noms du document par la fonction OpenXml_ReadCountNameCell.

    • Lire ou écrire une formule de calcul par les fonctions OpenXml_ReadFormula et OpenXml_WriteFormula.

    • Lire une cellule et écrire sa valeur dans un fichier par la fonction OpenXml_ReadToFile ou dans un fichier .rtf temporaire par la fonction OpenXml_ConvertTxtCellToRTF.

    • Récupérer le texte de la dernière erreur produite par la fonction OpenXml_GetMsgError (utilisée lors de l’initialisation du module et lors de l’ouverture d’un fichier).

    • Par défaut, OpenXml charge la liste des cellules du fichier Excel mais un nombre de cellules trop important peut provoquer une saturation de la mémoire de xRtDiva. Pour contourner ce problème, il existe une solution consistant à lire directement le flux Xml du fichier .xlsx : le mode SAX (Simple API for Xml). Dans certains cas, ce mode peut aussi être utilisé pour gagner en performance.

  • Gestion des fichiers Word .docx pour le publipostage :

    • Avant d'appeler toute autre fonction de publipostage, le programme Diva doit faire appel à la fonction Office_SetModePublipostageWithOpenXML pour que OpenXml soit l'interface utilisée pour le publipostage. A la fin du publipostage, il doit appeler la fonction Office_SetDefaultModePublipostage pour restaurer l'interface de publipostage paramétrée par défaut.

    • Le programme appellera la fonction OpenXmlWord_OpenFile pour charger un fichier .docx puis la fonction OpenXmlWord_CloseFile pour mettre le fichier à jour et le refermer. Lorsque le fichier est ouvert, on peut :

    • Chercher et remplacer une chaîne de référence par un texte par la fonction OpenXmlWord_Replace.
      En mode "ancrage", un point d'ancrage est positionné après le paragraphe contenant la chaîne recherchée. On peut alors :

      • Insérer un paragraphe à la position de l’ancrage par la fonction OpenXmlWord_CreateParagraph puis placer un texte dans ce paragraphe par la fonction OpenXmlWord_InsertText.

      • Insérer un fichier à la position de l'ancrage par la fonction OpenXmlWord_InsertFile.

      • Ces deux fonctions créent elle-mêmes un nouvel ancrage après le paragraphe ou le fichier inséré, de manière à permettre des insertions successives.
