MemoryReadClipBoard  Famille Thème

 

La fonction MemoryReadClipBoard alloue une mémoire et y copie le contenu du presse-papiers. La fonction retourne le ticket identifiant cette mémoire et la fonction MemoryRead permet de lire le contenu de cette mémoire.

Cette fonction se trouve dans le fichier source zclipboard.dhsp.

 

Long MemoryReadClipBoard (effacement)

 

Paramètre

Effacement

Booléen (TRUE / FALSE) indiquant si le presse-papiers doit être effacé après la lecture.

 
Retour

0

Presse-papiers vide ou erreur lors de l'allocation ou plus de 10 mémoires ouvertes.

Autre

Ticket qui servira à tous les accès à la mémoire.

 

Exemple

include "zclipboard.dhsp"

record * htdf tdf

1 art 200

1 mem X

main

; Remplissage du presse-papiers avec le contenu d'un fichier 

tdf.name = "stest1" 

hopen(tdf,"P") 

mem = MemoryCreate(0) ; création de la mémoire 

loop hread(tdf,art) = 0 

   MemoryWrite(mem,left(art)) ; écriture dans la mémoire 

endloop 

 

MemoryWriteClipBoard(mem) ; copie dans le presse-papier 

MemoryClose(mem) ; libération mémoire 

; Affichage du contenu du presse-papiers 

mem = MemoryReadClipBoard(FALSE) ; allocation mémoire et copie 

 

loop MemoryRead(mem,art) = 0 ; lecture d'une ligne 

   display left(art) 

endloop 

 

MemoryClose(mem) ; libération mémoire
