DownloadUrlEncode Famille  Thème

 

Lorsqu'un service web doit transférer des volumes très importants (plusieurs dizaines voire centaines de Mo), il est conseillé de passer par des fichiers.

En manipulant des flux mémoires, le risque est de voir la mémoire saturée et donc de sortir en erreur le jour où le flux dépasse la limite de la mémoire disponible.

 

Les fonctions DownloadUrlEncode et DownloadFromUrlEncode permettent d'effectuer le transfert de fichier de façon très simple. Le transfert se fait via le canal http (ou https) et est sécurisé. Le fichier n'est pas mis à la disposition de tout le monde, seul le programme qui a l'Url encodée peut charger le fichier.

 

Les opérations se font dans l'ordre suivant :

 

Le service web

  • écrit les données dans un fichier temporaire

  • appelle la fonction DownloadUrlEncode en passant le nom du fichier temporaire en paramètre

  • retourne au client le résultat de la fonction DownloadUrlEncode  

Le programme client

  • reçoit du service web, l'Url du fichier

  • appelle la fonction DownloadFromEncodedUrl pour télécharger le fichier du serveur dans un fichier local. Le fichier est ensuite automatiquement détruit sur le serveur.

 

Char = DownloadUrlEncode ( fichier , [suppression])

 

Paramètres

Fichier

Nom du fichier à transférer. C'est un chemin complet au format windows.

 

Suppression

Booléen indiquant si le fichier doit être supprimé après le transfert. True par défaut.

 

Retour

La fonction retourne l'url qui va permettre de télécharger le fichier.

 

Remarques

  • Attention : pour se servir de cette Url, le client doit compléter l’url avec l’adresse du serveur : http://serveur/lcweb

  • Le nom du serveur est évidemment le même que celui utilisé pour invoquer le service web. Le nom du serveur est suivi du nom de l'application IIS du serveur client léger web (lcweb par défaut).

 

Exemple

Coté service web :

1 url s

url = DownLoadUrlEncode("c:/divalto/tmp/monfichier.txt",false);

WebServiceReturn(url,0)

 

Coté client :

 

1 retour S

1 st     X

1 url    S

1 ex     S

 

st= WebServiceDivaExecute("http://serveur/WebServiceDiva/WebServiceDiva.asmx", \

                          "<action>LoadFile", \ 

                          "<parametre>xxxx",retour)

url = "http://serveur/lcweb/" & retour

if DownloadFromEncodedUrl(url,"c:/divalto/tmp/fichierlocal.txt",ex) = FALSE

   messageBox(ex," ")

endif
