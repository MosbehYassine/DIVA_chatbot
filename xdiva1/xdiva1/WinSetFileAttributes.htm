WinSetFileAttributes Famille Thème

 

La fonction WinSetFileAttributes permet de positionner les attributs d'un fichier (lecture seule etc.)

 

Long WinSetFileAttributes (Fichier , Attributs)

 

Paramètres

Fichier

Nom du fichier.

 

Attributs

Valeur des attributs.

Les attributs sont une combinaison des valeurs suivantes (définies dans zdiva.dhsp) :

FILE_ATTRIBUTE_READONLY

FILE_ATTRIBUTE_HIDDEN    

FILE_ATTRIBUTE_SYSTEM  

FILE_ATTRIBUTE_DIRECTORY

FILE_ATTRIBUTE_ARCHIVE    

FILE_ATTRIBUTE_NORMAL    

FILE_ATTRIBUTE_TEMPORARY

 

Retour

0

Erreur. Appelez la fonction WinGetLastError pour connaître le détail de l'erreur.

Autre

Pas d'erreur.

 

Exemple

 

; mettre toto.txt en lecture seule

 

1 att  L

att = WinGetFileAttributes("e:\divalto\sys\toto.txt")

if att = -1

   display "Erreur " & WinGetTextError(WinGetLastError)

   ProgramExit

endif

 

att += FILE_ATTRIBUTE_READONLY

if  WinSetFileAttributes("e:\divalto\sys\toto.txt",att) = 0

   display "Erreur " & WinGetTextError(WinGetLastError)

   ProgramExit

endif
