FaccessCodeControl

La fonction FAccessCodeControl permet de vérifier qu'un utilisateur possède un code d'accès.

Voir la fonction HAccessCodeControl qui fournit des explications plus détaillées sur le fonctionnement des codes d'accès.

Ptr = FAccessCodeControl (tdf , code, errsys , [utilisateur] )

 
Paramètres

Tdf

Tdf d'un fichier ouvert ou ".".

Dans le cas où ce paramètre vaut le point, la recherche se fait dans la liste des codes qui a été chargée lors de l'identification de l'utilisateur. Si le fichier xlogf.dhfi est sur un serveur, la recherche se fait dans la liste des codes stockée sur le serveur.

 

Code

Code à rechercher dans la liste

 

Errsys

Donnée de type X contenant un code d'erreur système.si la fonction retourne la valeur 2.

 

Utilisateur

Code utilisateur pour rechercher les droits. Par défaut, le code courant de l'utilisateur est utilisé. Ce paramètre permet de vérifier les confidentialités d'un autre utilisateur que l'utilisateur courant.

Voir FChangeHarmonyUser qui permet de changer de code utilisateur.

 

 

Retour

1

Le code existe.

0

Le code n'existe pas.

2

Erreur système. La donnée errsys contient le code d'erreur.
 

Exemple

hfile h3fdd fimp tdf

1 st X

1 errsys X

main

st = FAccessCodeControl(tdf,"abcd",errsys)

switch st

case 0

   MessageBox("Fonctionnalité interdite"," ") 

   ProgramExit 

case 2

   Ferror tdf,errsys 

endswitch
