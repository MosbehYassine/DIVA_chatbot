GetComboText

La fonction GetComboText permet de trouver le libellé d'un choix à partir de sa valeur.

 

 

String GetComboText (dico , entree , valeur , [ nom ] , [ traduction ] , [ dicoTrad ] , codeLangueBase] )

 

Paramètres

Dico

Nom du dictionnaire des multi-choix.

 

Entrée

Entrée dans le dictionnaire.

 

Valeur

Valeur du choix à chercher dans la liste précisée dans Entrée.

Le type de ce paramètre doit être du même type que la donnée qui sert à stocker cette valeur dans l'application.

 

Nom

Nom associé au choix. Si ce paramètre est précisé, le choix doit être associé à ce nom.

 

Traduction

0

pas de traduction (valeur par défaut)

1

traduction en utilisant la langue sélectionnée pour les affichages

2

traduction en utilisant la langue sélectionnée pour les impressions

 

DicoTrad

Dictionnaire utilisé pour la traduction.

 

CodeLangueBase

Code langue de base. Si la langue demandée pour la traduction est la même que la langue de base, il n'y a pas de traduction à effectuer.

Valeur par défaut : FR

 

Retour

La fonction retourne le libellé correspondant dans le dictionnaire.

En cas d'erreur (fichier absent, entrée non trouvée) la fonction retourne la valeur du choix.
