ListSetName  Famille  Thème

ListSetName permet d’affecter ou de modifier le nom d’une liste.


Bool ListSetName (ticket , nom)


Paramètres

Ticket

Identifiant de la liste.

Nom

Nom à affecter à la liste.


Retour

TRUE

Pas d’erreur

FALSE

La liste n’existe pas. Ticket invalide

 

Exemple

1 l1 L

 

l1 = ListGetId("maliste")

ListSetName(l1,"nouveaunom") ; change le nom

display ListGetName(l1)  ; --> NOUVEAUNOM
