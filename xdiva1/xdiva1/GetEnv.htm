GetEnv  Famille Thème

 

La fonction GetEnv permet de lire la valeur d'une variable d'environnement du processus Windows.

  

Char GetEnv ( nom )

Paramètres

Nom

Nom de la variable d'environnement.

Remarque

La variable d'environnement HARMONY_PARAM est détruite après la lecture. Elle ne peut donc être lue qu'une seule fois.

 

Retour

Espace

La variable n'existe pas ou sa valeur est espace.

Autres

La valeur de la variable
 

Exemples

putenv("toto","valeur") ; création de la variable toto

display getenv("toto") ; affiche valeur

putenv("toto"," ") ; suppression de la variable toto
