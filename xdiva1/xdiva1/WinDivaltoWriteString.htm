WinDivaltoGlobalWriteString - WinDivaltoWriteString Famille Thème

L'instruction WinDivaltoWriteString permet d’écrire une chaîne dans le registre, sous la clé "HKEY_CURRENT_USER\SOFTWARE\Divalto\divalto.ini\"

L'instruction WinDivaltoGlobalWriteString permet d’écrire une chaîne dans le registre, sous la clé "HKEY_LOCAL_MACHINE\SOFTWARE\Divalto\divalto.ini\"

Ces instructions se trouvent dans le module ysystemex.dhop.

 

WinDivaltoWriteString (section, entrée , valeur)

WinDivaltoGlobalWriteString (section, entrée , valeur)

 

Paramètres

Section

Sous chemin dans le registre.

Entrée

Nom de la valeur à écrire.

Valeur

Valeur à écrire.
