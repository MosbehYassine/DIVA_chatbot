Hpclose  Famille Thème

 

Hpclose effectue une fermeture partielle de fichier.
A la différence de Hclose, le fichier reste ouvert. Hpclose demande au système d'exploitation d'écrire sur le disque tous les blocs modifiés qui se trouvent en mémoire cache. Ainsi le fichier est à l'abri d'un arrêt anormal du programme (panne de courant par exemple) jusqu'à une nouvelle modification.

Tous les enregistrements réservés dans le fichier sont automatiquement libérés.


Ptr = Hpclose ( tdf )


Paramètres

Tdf

Table de définition de fichier.

  

Retour

0  

Pas d'erreur.

 

Toutes les erreurs provoquent l'arrêt du programme.
