WebRequestSetProxy Famille Thème

 

Positionnement des paramètres pour le serveur proxy. Si votre connexion passe obligatoirement par un serveur proxy, il faut renseigner ces paramètres.

 

Int WebRequestSetProxy ( Ticket , Url, Mode, Utilisateur, MotDePasse )

 

Paramètres

Ticket

Ticket préalablement obtenu par WebRequestNew.

 

Url

Url du serveur proxy.

 

Mode

1

Prendre les paramètres du système. Il n'y a pas d'autre paramètres à préciser, l'authentification est celle du poste de travail.

2

Préciser l'url du serveur, mais avec authentification SSPI. Inutile de préciser Utilisateur et MotDePasse

3

Mode manuel. Il faut préciser tous les paramètres
 

Utilisateur

Nom de l'utilisateur dans le domaine.

 

MotDePasse

Mot de passe de l'utilisateur.

 

 

Retour

0

Pas d'erreur

1

Ticket incorrect

2

Erreur. Voir le détail avec WebRequestGetError

 

Remarques

WebRequestSetProxy vérifie que l'Url est correctement formée, mais ne vérifie pas que l'adresse existe, ni que l'utilisateur et le mot de passe sont corrects.

 

Exemple

 

1 ticketRequete L

.....

WebRequestSetProxy(ticketRequete,"http://10.10.10.229:8080","DIVALTO","toto","motdepasse")
