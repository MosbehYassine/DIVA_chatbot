WinRegReadBinary  Famille Thème

La fonction WinRegReadBinary permet de lire une chaine binaire dans le registre.

Cette fonction se trouve dans le module ysystemex.dhop.

  

Long WinRegReadBinary (clé, nom_valeur , &buffer, lg_buffer )

 

Paramètres

Clé

Clé dans le registre.

Nom_valeur

Valeur à lire.

Buffer

Zone réceptrice

Lg_buffer

Taille de la zone réceptrice

  

Retour

Buffer reçoit les caractères lus.

La fonction retourne le nombre de caractères lus.

  

Exemple

module "ysystemex.dhop"

1 buf 256

1 nblus L

main

nblus = WinRegReadBinary("HKEY_CURRENT_USER\Software\Divalto\divalto.ini\tests","mavaleurbinaire",buf,size(buf))
