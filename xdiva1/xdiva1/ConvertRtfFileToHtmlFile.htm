ConvertRftFileToHtmlFile Famille 

La fonction ConvertRtfFileToHtmlFile convertit un fichier Rtf en fichier Html

 

Long ConvertRtfFileToHtmlFile (htmlFile, rtfFile, [options] )

  

Paramètres

HtmlFile

Nom du fichier html résultat

  

RtfFile

Nom du fichier rtf

  

Options

Chaine Hmp pour positionner des options.

UTF8WithoutBOM

1 = ne pas mettre de BOM en début de fichier résultat

 

Retour

0 = OK
1 = Erreur (ConvertHtmlRtfLastError permet de récupérer le texte d'erreur)
