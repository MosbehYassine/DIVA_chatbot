Les fonctions évoluées de gestion de fichier

Les fonctions évoluées de gestion de fichier doivent être utilisées de préférence aux fonctions de base.

Les fonctions évoluées sont plus simple d'emploi, et surtout, elles traitent les erreurs "fatales" contrairement aux fonctions de base qui rendent toujours la main. Cela permet de simplifier le traitement des erreurs dans le programme appelant.

En cas d'erreur fatale, le programme affiche une boîte d'alerte avec le code d'erreur et écrit dans le fichier journal ferror.log. Voir Ferror.
