VerifyComboValue Famille Thème

La fonction VerifyComboValue permet de vérifier la valeur d'un multi-choix.

Cette fonction est utile pour les programmes d'import qui doivent vérifier la validité de tous les champs importés.

Attention : cette fonction ne peut pas être utilisée avec des multi-choix de type tableau ou de type liste.

 

Int VerifyComboValue  (DictionnaireMC, Entree, Valeur )

 

Paramètres

DictionnaireMC

Nom du dictionnaire de multi-choix.

 

Entree

Entrée dans le dictionnaire de multi-choix.

 

Valeur

Valeur à vérifier.

 

Retour

0

Pas d'erreur

1

Entrée inexistante dans le dictionnaire

2

Valeur non trouvée

10000 + xxx

Erreur système (10020 = fichier absent par exemple)
