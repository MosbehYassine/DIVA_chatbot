WinFlushFileBuffers  Famille Thème

 

La fonction WinFlushFileBuffers efface les blocs de mémoire dans le cache disque pour le fichier spécifié. Tous les blocs modifiés sont physiquement écrits sur le disque.


Long WinFlushFileBuffers( Ticket )

 

Paramètres

Ticket

Ticket (handle) d'un fichier ouvert. Le fichier doit être ouvert avec l'accès GENERIC_WRITE.

Si ticket est un handle d'une voie de communication, la fonction force l'émission du tampon d'émission.

 

Retour

TRUE

Pas d'erreur.

FALSE

Erreur. Appelez la fonction WinGetLastError pour connaître le détail de l'erreur.
