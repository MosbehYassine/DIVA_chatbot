Init

L'instruction Init permet d'initialiser une variable avec une constante.

init variable = constante

La constante de remplissage peut comporter plusieurs caractères.

Pour initialiser tous les éléments d'un tableau, il suffit d'écrire :

INIT tab() = 10.

Cette utilisation ne fonction que si le tableau n'est pas une sous-donnée d'un autre tableau.


Exemples

init art = '*' ; rempli avec des étoiles

init tab() = 10 ; tous les éléments du tableau =10

init tab = ' ' ; tout le tableau à espace

init art = $00 ; à zéro binaire
