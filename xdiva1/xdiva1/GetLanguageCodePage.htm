GetLanguageCodePage Famille Thème

 

La fonction GetLanguageCodePage  retourne le code page d'une langue.

 

Int GetLanguageCodePage  ( CodeLangue )

 

Paramètre

CodeLangue

Code de la langue

 

Retour

La fonction renvoie le code page correspondant au code de la langue.
