DD_DATA_xxx  Famille  Thème

Long DDInterface (Commande , &ticket , [paramètres] , retour, [niveau])

 

DD_DATABEGIN

DD_DATABEGIN_DD

DD_DATAKEYBEGIN

La commande DD_DATABEGIN permet de se positionner sur le premier champ de la table en cours. Il faut donc avoir préalablement lu une table par une commande DD_TABLExxxx.

La commande DD_DATABEGIN_DD permet de se positionner sur le premier champ du dictionnaire.

La commande DD_DATAKEYBEGIN permet de lire le premier champ de l’index en cours.

 

Retour contient les caractéristiques du champ. Voir DDInterface : Champs

 

Retour

0

pas d’erreur.

2

Pas de champs dans la table (dictionnaire).

autre

Erreur. Voir DD_GETERROR

 

Exemple

1  ticket L 

1  reponse 8096  

1  stchamp X

stchamp = DDInterface(DD_DATABEGIN,ticket,,reponse)

 

DD_DATAFIND

DD_DATAFIND_DD

La commande DD_DATAFIND permet de rechercher un champ appartenant à la table en cours. Il faut donc avoir préalablement lu une table par une commande DD_TABLExxxx.

La commande DD_DATAFIND_DD permet de rechercher un champ dans le dictionnaire tout entier, sans avoir à préciser de table.

 

Paramètres doit contenir le nom du champ à chercher.

Retour contient les caractéristiques du champ. Voir DDInterface : Champs

 

Retour

0

pas d’erreur.

2

Table non trouvée.

autre

Erreur. Voir DD_GETERROR

 

Exemple

1  ticket L 

1  reponse 8096  

1  stchamp X

stchamp = DDInterface(DD_DATAFIND,ticket,"libelle",reponse)

 

DD_DATANEXT

DD_DATANEXT_DD

DD_DATAKEYNEXT

La commande DD_DATANEXT permet de lire le champ suivant appartenant à la table en cours. Il faut donc avoir préalablement lu un champ DD_DATABEGIN ou DD_DATAFIND.

La commande DD_DATANEXT_DD permet de lire le champ suivant dans le dictionnaire tout entier.

La commande DATAKEYNEXT permet de lire le champ suivant de la clé en cours.

 

Retour contient les caractéristiques du champ. Voir DDInterface : Champs

 

Retour

0

pas d’erreur.

2

Plus de champ dans la table (dictionnaire).

autre

Erreur. Voir DD_GETERROR

 

Exemple

1  ticket L 

1  reponse 8096  

1  stchamp X

stchamp = DDInterface(DD_DATANEXT,ticket,,reponse)
