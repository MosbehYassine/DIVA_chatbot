Lmid  Famille 

 

La fonction Lmid permet d'extraire une sous chaîne d'une chaîne de caractère et de transformer le type de cette sous chaîne en type L (donnée numérique sur 32 bits).
Elle peut se trouver à gauche dans une affectation.


Long Lmid (variable , position)


Paramètres

Variable

Le type de la variable est quelconque.

Position

Valeur numérique indiquant la position de début (à partir de 1) de la donnée de type L à extraire.


Retour

La fonction renvoie la sous chaine pointée par Position. Le type de retour est toujours le type L.


Exemple

1 arti 15

Lmid(arti,1) = 0xbebefada 

; positionne la valeur 0xbebefada dans les quatre premiers

; caractères de arti.
