Les tableaux comme paramètres

Pour passer un tableau comme paramètre d'une fonction/procédure, il doit y avoir correspondance exacte entre les dimensions du paramètre formel déclaré dans la fonction/procédure et le tableau passé comme paramètre réel.

Par contre, le nombre d'éléments pour chaque dimension est mis à jour au moment de l'exécution. Donc une fonction/procédure peut utiliser des tableaux sans connaître la taille de ces derniers.
Mais il est impossible par exemple de passer comme paramètre un tableau à deux dimensions à une fonction ou procédure où le paramètre formel est déclaré avec une dimension.

Lors de l'appel, le nom du tableau doit être suivi d'une parenthèse ouvrante et d'une parenthèse fermante.

Exemple

La fonction CumulTableau fait la somme de tous les éléments du tableau. La fonction Index permet de connaître le nombre d'éléments du tableau.

function int CumulTableau(&tab)

1 tab N*1 ; tableau à une dimension

Beginf  

   1 i L

   1 total 24,10 = 0

   for i = 1 to index(tab(),1) 

     total += tab(i) 

   next 

   freturn total  

Endf

 

1 tableau 10,0*100

main

...
display CumulTableau(tableau())
