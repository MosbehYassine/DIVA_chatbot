Fseek2  Famille Thème

 

Fseek2 effectue une lecture en accès direct. fseek2 n'est utilisable qu'avec les fichiers séquentiels-indexés ou avec les fichiers normaux avec enregistrements de taille fixe.

Ptr = fseek2 ( tdf , variable [ , code_réservation ] [ , depack_auto ] )

Paramètres

Tdf

Table de définition de fichier.

Variable

Donnée réceptrice qui contiendra l'enregistrement lu.

Code_réservation

Mode de partage de l'enregistrement ('P' par défaut).

Depack_auto

Décompression automatique des données si l'enregistrement comporte une zone packée.
0  : non  (par défaut)

1  : oui

 

Retour

0  

Pas d'erreur. 

H_RECORD_NOT_FOUND  

Enregistrement non trouvé (type I)
ou positionnement hors fichier (type N). 

H_RESERVED  

Enregistrement réservé. 

autres

Code d'erreur système. 

 

Remarque

La fonction GetLastRecord permet de récupérer le dernier enregistrement lu.

 

FICHIERS SEQUENTIELS-INDEXES (TYPE I)

fseek2 permet de rechercher un enregistrement en indiquant sa clé. Le programme doit préalablement positionner celle-ci dans la TDF (champ Key).

S'il existe un enregistrement ayant la clé indiquée, celui-ci est lu et le système renvoie un status nul (sauf en cas d'erreur de partage).

S'il n'existe aucun enregistrement ayant la clé indiquée, la variable réceptrice est mise à espace et la fonction renvoie le status H_RECORD_NOT_FOUND.

S'il existe des homonymes, c'est le premier (dans l'ordre chronologique des créations) qui est délivré. Par des lectures séquentielles (Fread), il est ensuite possible de lire les homonymes.

 

fseek2 s'utilise en pratique dans les 3 cas suivants :

1) Vérification de l'existence d'une clé avant une création.

Si un fichier a une clé unique (code client par exemple), avant de créer un nouvel enregistrement, il est impératif de vérifier que cette clé n'existe pas dans le fichier.

Exemple : Création d'un client si celui-ci n'existe pas encore dans le fichier client.

; saisie des champs de client 

; on réserve une entité afin d'interdire la création  

; simultanée par plusieurs utilisateurs 

loop fshare (fcli , " creation-client" , 'R')

endloop

 

; recherche en mode partagé. On lit dans une zone de travail 

; pour ne pas casser la saisie 

fcli.key = 'A' & client.codcli

st = fseek2(fcli , wcli , 'P')

switch st

case H_RECORD_NOT_FOUND ; 2 = il n'existe pas -> écriture

                        ; puis libération de l'entité 

   stw = fwrite(fcli , client," ") 

   st = fshare(fcli," creation-client" , "L") 

   

case 0 ; il existe déjà

   st = fshare(fcli , " creation-client" , "L") 

   MessageBox("Le client " & client.codcli & \ 

              "existe déjà"," ")

 

case H_RESERVED ; erreur de partage

   st = fshare(fcli , " creation-client" , "L") 

   MessageBox("Le client " & client.codcli & \

             "est réservé"," ") 

default

   st = fshare(fcli ," creation-client" , "L") 

ProgramExit 

endswitch

 

2) Réservation d'un enregistrement avant modification

Avant de modifier un enregistrement, il faut le réserver pour en interdire l'accès aux autres programmes. Pour ne pas bloquer l'enregistrement trop longtemps, on fera la réservation juste au moment de la réécriture de l'enregistrement. L'ordre des opérations à effectuer est le suivant :

  • lecture de l'enregistrement en mode 'P' ou 'F';

  • saisie des modifications;

  • FSEEK2 en mode réservé dans une zone de manœuvre;

  • réécriture (FREWRITE) de l'enregistrement.

 

Exemple : Modification de l'enregistrement client.

L'enregistrement a été lu au préalable en mode P ou F dans la donnée client.

; saisie des modifications 

; avant fseek2, il n'y a pas besoin de positionner la clé 

; on veut relire le même enregistrement que précédemment 

st = fseek2(fcli , wcli , 'R');

switch st

case 0 ; lecture OK

   stw = frewrite(fcli , client) 

case H_RESERVED ; enreg. réservé

   MessageBox("Enregistrement réservé"," ")

case H_RECORD_NOT_FOUND ; enregistrement supprimé

   MessageBox("Le client " & client.codcli & \ 

              "n'existe plus"," ")

default

...

endswitch

fpclose (fcli)

 

3) Repositionnement sur un enregistrement lu précédemment

Après avoir lu un enregistrement par fseek2 ou fread, il est possible de sauvegarder la clé dans une zone de 256 caractères. Après avoir fait d'autres opérations sur le fichier, on peut restaurer la clé dans la tdf et par la fonction fseek2 relire le même enregistrement.

Exemple :

1 wcle 256

st = fread(fcli , client , "F")

wcle = fcli.key ; sauvegarde de la clé

...... ; autres traitements sur le fichier

fcli.key = wcle ; restauration de la clé

st = fseek2(fcli , client , "F")

; on relit le même enregistrement 

; qui a été lu par fread 

Remarque : Si au lieu d'utiliser la fonction Fseek2 on utilise la fonction Fread, c'est l'enregistrement suivant qui est lu.

 

 

FICHIER NORMAL AVEC TAILLE D'ENREGISTREMENT FIXE

fseek2 permet de lire un enregistrement à partir de son numéro relatif en décimal.

Avant d'utiliser la fonction fseek2, il faut spécifier dans la clé, le numéro d'ordre de l'enregistrement à lire dans le champ Keyn). Il se produit une erreur si cet enregistrement n'existe pas.

Exemple

;________________________________________________________________
; Fonction : F_SEEK2

; Type : int

; Description : Lecture directe d'un enregistrement dans le

; fichier tdf

; en mode "par" et dépacke automatique

; La clé doit être positionnée en entrée

; Paramètres en sortie : 0 = ok 1 = début 2 = réservé 3 = errsys

;________________________________________________________________
;

Function int F_SEEK2 (&tdf , &art , par)

record * htdf tdf ;table de définition

1 art A ;article

1 par A = 'P' ;code partage

beginf

cr = fseek2 (tdf,art,par,1) 

switch cr 

case 0 ;ok 

   freturn (0) 

case H_RECORD_NOT_FOUND ;non trouvé 

   freturn (1) 

case H_RESERVED ;réservé 

   freturn (2) 

default ;erreur système 

   MessageBox("Erreur système numéro " & binhexa (stx (cr)) & \ 

              " en lecture du fichier " & left(tdf.name," ") 

freturn (3) 

endswitch 

endf

 

record * htdf tdf

 ..............

input 'Numéro à lire : ' tdf.keyn

st = f_seek2(tdf , art , 'P')

switch st

case 0

   display 'OK' 

case 1

   display 'Numéro hors des limites du fichier' 

case 2

   display 'Enregistrement réservé ' 

default

.... 

endswitch
