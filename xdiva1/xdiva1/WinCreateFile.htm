WinCreateFile  Famille Thème

 

La fonction WinCreateFile permet de créer, d'ouvrir, d'effacer un fichier, un tube nommé (pipe), un port de communication. Elle renvoie un ticket (Handle) qui peut être utilisé pour accéder à l'objet ouvert.

Nom

Spécifie le nom du fichier, du tube nommé, d'une voie de communication à créer, ouvrir ou effacer..

Accès

Spécifie le type de l'accès au fichier ou aux autres objets. Vous pouvez combiner les valeurs suivantes (par des additions) pour construire la valeur de ce paramètre. GENERIC_READ et GENERIC_WRITE doivent être positionnés pour obtenir un accès en lecture et en écriture.

0

Permet de vérifier l'existence d'un fichier ou d'une voie de communication sans y accéder ultérieurement.

GENERIC_READ

Spécifie un accès en lecture du fichier. Le fichier peut être lu et le pointeur du fichier déplacé.

GENERIC_WRITE

Spécifie un accès en écriture du fichier. Des données peuvent être écrites dans le fichier et le pointeur peut être déplacé.

 

Partage

Spécifie le mode de partage du fichier. Ce paramètre est une combinaison des valeurs suivantes :

0 

Mode réservé. Le fichier n'est pas partagé.

FILE_SHARE_READ

Permet à d'autres programmes d'accéder au fichier en lecture.

FILE_SHARE_WRITE

Permet à d'autres programmes d'accéder au fichier en écriture.

 

Sécurité

Ce paramètre n'est pas utilisé. Il doit être positionné à la valeur nulle.

 

CréationDistribution

Spécifie l'action à effectuer si le fichier existe déjà et l'action à effectuer si le fichier n'existe pas. Pour plus d'informations voir les remarques. Ce paramètre doit être l'une des valeurs suivantes :

CREATE_NEW

Crée un nouveau fichier. La fonction retourne une erreur si le fichier existe déjà.

CREATE_ALWAYS

Crée toujours le fichier. S'il existe déjà il est écrasé.

OPEN_EXISTING

Ouvre un fichier existant. S'il n'existe pas la fonction retourne une erreur.

OPEN_ALWAYS

Ouvre le fichier s'il existe. Si le fichier n'existe pas il est créé.

TRUNCATE_EXISTING

Ouvre le fichier puis le fichier est effacé. L'accès GENERIC_WRITE doit être spécifié sinon la fonction retourne une erreur.

 

Flags

Spécifie les attributs et les flags pour le fichier.

Toute combinaison des valeurs suivantes est possible. Si aucun attribut ne doit être positionné, utilisez FILE_ATTRIBUTE_NORMAL.

FILE_ATTRIBUTE_ARCHIVE

Le fichier est un fichier d'archive. Utilisez ce flag pour marquer un fichier pour les sauvegardes ou les épurations. l.

FILE_ATTRIBUTE_COMPRESSED

Le fichier ou le répertoire est compressé. Pour un fichier, cela signifie que les données sont compressées. Pour un répertoire, cela signifie que tous les fichiers et sous répertoires seront créés avec cet attribut par défaut.

FILE_ATTRIBUTE_NORMAL

Le fichier n'a pas d'attributs particuliers. Ce flag n'a de sens que s'il est utilisé seul.

FILE_ATTRIBUTE_HIDDEN

Le fichier est caché. Il n'apparaîtra pas dans la liste des fichiers du répertoire.

FILE_ATTRIBUTE_READONLY 

Le fichier est en lecture seule. Il est possible de lire le fichier mais l'écriture ou la suppression sont interdites.

FILE_ATTRIBUTE_SYSTEM

Le fichier fait partie du système ou est exclusivement utilisé par le système.

 

FILE_FLAG_WRITE_THROUGH

Non documenté, référez-vous à la documentation Windows

FILE_FLAG_OVERLAPPED

Non documenté, référez-vous à la documentation Windows

FILE_FLAG_NO_BUFFERING

Non documenté, référez-vous à la documentation Windows

FILE_FLAG_RANDOM_ACCESS

Indique que le fichier n'est pas accédé de façon séquentielle. Windows utilise ce flag pour optimiser le cache disque.

FILE_FLAG_SEQUENTIAL_SCAN

Indique que le fichier est accédé séquentiellement du début à la fin. Windows utilise ce flag pour optimiser le cache disque. Si l'application déplace le pointeur du fichier, l'optimisation du cache disque n'est plus faite mais l'opération se fait correctement.

FILE_FLAG_DELETE_ON_CLOSE

Indique que le système doit supprimer le fichier lorsqu'il n'est plus utilisé..

FILE_FLAG_BACKUP_SEMANTICS

Non documenté, référez-vous à la documentation Windows

FILE_FLAG_POSIX_SEMANTICS

Non documenté, référez-vous à la documentation Windows

 

Template

Spécifie un ticket d'un fichier ouvert avec l'accès GENERIC_READ. Les attributs de ce fichier sont pris pour la création du fichier.

 

Retour

-1

Erreur. Appelez la fonction WinGetLastError pour connaître le détail de l'erreur.

Autre

Ticket. Ce ticket est passé en premier paramètre de toutes les fonctions d'accès au fichier ouvert.
Si le fichier existe avant l'appel de la fonction et que CreationDistribution vaut CREATE_ALWAYS ou OPEN_ALWAYS, l'appel à WinGetLastError renvoie la valeur ERROR_ALREADY_EXISTS (bien que le fichier soit ouvert). Si le fichier n'existe pas avant l'appel, WinGetLastError retourne 0

 

Remarques

Lors de la création d'un nouveau fichier la fonction réalise les actions suivantes : 

  • Elle combine les Flags spécifiés avec FILE_ATTRIBUTE_ARCHIVE.

  • Elle met la taille du fichier à 0.

  • Elle copie les attributs du fichier ouvert dont le ticket est précisé par Template si ce paramètre est spécifié (différent de 0).

  • Lors de l'ouverture d'un fichier existant la fonction WinCreateFile réalise les actions suivantes :

  • Elle combine les paramètres spécifiés avec les attributs du fichier existants. WinCreateFile ignore les attributs précisés par Flags.

  • Elle positionne la taille du fichier en fonction de la valeur de CreationDistribution.

  • Elle ignore le paramètre Template.

WinCreateFile peut ouvrir une voie de communication comme un port série (Com1 par exemple). Pour les voies de communication, le paramètre CreationDistribution doit être OPEN_EXISTING, et la paramètre Template doit être nul. Les accès en lecture et/ou écriture peuvent être spécifiés.

 

Exemple

Ouverture du fichier Stest en lecture et en mode partage.

fic = WinCreateFile("d:\Divalto\sys\stest", \

                   GENERIC_READ, \

                   FILE_SHARE_READ, \

                   0, \

                   OPEN_EXISTING,0,0)

if fic = -1

   MessageBox ("Erreur " & bindec(ldxl(WinGetLastError)), "erreur") 

endif
