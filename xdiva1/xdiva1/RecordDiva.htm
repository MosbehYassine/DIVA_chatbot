RecordDiva

L'instruction RecordDiva permet de déclarer une instance de Structure.

 

[public | protected] RecordDiva [module.]structure  [var]

 

Public

Spécifie que la variable var est publique. Si plusieurs modules déclarent la même variable publique, elle est allouée une seule fois à l'exécution.

Protected

Spécifie que la variable var est protégée. Une nouvelle instance de var est allouée.

Module

Facultatif. Si la structure est définie (et est publique) dans un module, il faut préciser le nom du module.

Structure

Nom de la structure.

Var

Nom de la variable structurée représentant l'enregistrement. Si ce paramètre n'est pas spécifié, le nom de la donnée est le même que Structure.

RecordDiva génère une seule donnée. Pour accéder à ses champs, il faut utiliser la notation pointée donnee.champ .

 

Exemple

 

;---------------- Module1.dhsp ----------------------

Public Structure StructurePublique        

;Structure publique pouvant être utilisée par les modules appelants

1 sp1 10

1 sp2 X

EndStructure

 

;---------------- Programme_principal.dhsp ----------

Module module1.dhop

 

Structure Element

;Définition d'une structure locale

1 Nom  30

1 Prenom 30

EndStructure

 

RecordDiva Element                         ; déclare l'instance Element

RecordDiva Element  e1                     ; déclare l'instance e1

RecordDiva module1.StructurePublique sp    ; déclare l'instante sp

 

main

 Element.Nom = e1.Nom

 sp.sp1 = " "
