XmlRead  Famille  Thème

La fonction XmlRead permet de lire l’élément suivant dans le flux XML.

 

Numer XmlRead ( Ticket , &Tag , &Valeur )

Ticket

Ticket rendu par la fonction XmlOpen.

 

Tag

Variable (de type S ou alpha) recevant le nom de la balise (du tag) ou le nom de l’attribut lu.

 

Valeur

Variable (de type S ou alpha) recevant la valeur de la balise ou la valeur de l’attribut lu.

 

Retour

 

XML_ERRORHANDLE

Ticket non valide

XML_ERROR

Erreur dans le flux XML. Voir XmlGetError

XML_END

Fin du flux atteinte

XML_BEGINTAG

Début d’une balise.
Tag contient le nom de la nouvelle balise.

XML_ENDTAG

Fin d’une balise.
Tag contient le nom de la balise.

XML_ATTRIBUT

Attribut.
Tag contient le nom de l’attribut
Valeur contient la valeur de l’attribut.

XML_TEXTVALUE

Texte d’un nœud.
Tag contient le nom de la balise.
Valeur contient la valeur lue.
 

Valeurs généralement non traitées par le programme Diva :

XML_DECLARATION

Déclaration. Valeur contient les paramètres de la déclaration.

XML_WHITESPACE

Espace blanc entre le balisage
Par défaut, les espaces ne sont pas renvoyés. Voir XmlSetOption qui permet de positionner les options.

XML_CDATA

Section CDATA.

XML_PROCESSINGINSTRUCTION

Instruction de traitement.

XML_COMMENT

Commentaire.

XML_SIGNIFICANTWHITESPACE

Espace significatif.

 

Remarque

Aucune conversion minuscules/majuscules n’est effectuée.
