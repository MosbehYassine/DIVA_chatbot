Généralités

HMP (Harmony Markup Parameters) est un petit langage simple permettant de passer un grand nombre de paramètres dans une chaîne de caractères.

Le nom de chaque paramètre est encadré par les caractères < >. Le paramètre est suivi de sa valeur.

Exemple : chaine = "<param1>valeur1<param2>valeur2"

 

HMP est utilisé par exemple :

  • lorsqu’une fonction a un grand nombre de paramètres, dont la plupart sont facultatifs.

  • lorsque le nombre de paramètres d’une fonction risque d’évoluer dans le temps. Dans ce cas, HMP permet de rajouter des paramètres sans avoir à recompiler tous les modules appelants.

  • pour stocker des paramètres dans un fichier paramètre. La recherche des paramètres est alors très simple à réaliser.

 

Les fonctions HMP :

  • HmpRead permet de lire un paramètre ainsi que sa valeur.

  • HmpSeek permet de rechercher un paramètre ainsi que sa valeur.

  • HmpVerify permet de vérifier la syntaxe d’une chaîne HMP.

  • HmpEncode permet d’encoder la valeur d’un paramètre pour éviter toute ambiguïté avec les délimiteurs de paramètres.

 

La syntaxe HMP

La syntaxe HMP est la suivante : <param1>[valeur1]<param2>[valeur2]…

  • Le paramètre peut être délimité par les groupes de caractères suivants
     <>
     {}
     []
     ()

  • Il n’y a pas de distinction minuscules/majuscules pour les paramètres. La fonction de lecture traduit toujours le nom du paramètre en caractères majucules.

  • Les espaces non significatifs autour d’un nom de paramètre sont ignorés.
    < p1 > est équivalent à <p1>

  • La valeur d’un paramètre peut être omise. Dans ce cas, la valeur lue sera à espaces.
