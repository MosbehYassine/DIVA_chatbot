Freturn  Famille Thème

 

L'instruction Freturn indique la fin de l'exécution de la fonction et indique la valeur à retourner au programme appelant.

 

freturn (valeur_à_retourner)

 
Paramètres

Valeur_à_retourner

Le type de cette expression doit correspondre au type (Int, Char, Bin, Ptr ou Long) de la fonction.

L'instruction Freturn est obligatoire pour sortir d'une fonction. Il peut y avoir plusieurs freturn dans une fonction.

Si aucun FRETURN n'est rencontré à l'exécution, le programme est interrompu.

 

Exemple

;________________________________________________________________

; Fonction : F_OPEN

; Type : int

; Description : Ouvre le fichier "fic" en mode "par"

; 

; Paramètres en sortie : 0 = ok 1 = absent 2 = réservé

; 3 = erreur système

;________________________________________________________________

;

Function int F_OPEN (fic , &tdf , par , mes)

1 fic A ; nom du fichier

1 tdf A ;table définition fichier

1 par A ; code partage

1 mes A ; indic message si absent

beginf

   tdf = fic 

   cr = fopen (tdf , par) 

   switch cr 

   case 0 ;ok 

      freturn (0)

 

   case $14 ;absent

      if mes = 'O' 

         MessageBox(" Fichier : " & left(tdf,8) & " absent"," ")

      endif 

      freturn (1)

 

   case H_RESERVED ;réservé

      MessageBox(" Fichier : " & left(tdf,14) & " réservé"," ")

      freturn (2)

 

   default ;erreur système

      MessageBox(" Erreur système numéro " & binhexa (stx (cr)) \ 

               & " à l'ouverture du fichier " & left(tdf,14)," ")

      freturn (3)

   endswitch 

endf
