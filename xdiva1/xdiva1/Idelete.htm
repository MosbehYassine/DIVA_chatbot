Idelete  Famille Thème

 

Idelete supprime le dernier enregistrement lu.
Cette fonction ne peut être appelée qu'après une lecture effectuée généralement en mode réservé.

La suppression d'un enregistrement n'est possible qu'avec les fichiers de type séquentiel-indexé (I) dont le fichier des données est de type N.

 

Ptr = Idelete ( tdf , table)

Paramètres

Tdf

Table de définition de fichier.

Table

Dernier enregistrement lu.

 

Retour

0  

Pas d'erreur.

Si une procédure Avant Delete est définie dans le dictionnaire, elle est appelée.

Les paramètres passés à la procédure Avant Delete sont :

Tdf

La Tdf du fichier.

Table

L'enregistrement qui a été lu.
 

 

Toutes les erreurs provoquent l'arrêt du programme.

  

Remarques

Le système supprime l'enregistrement et ses clés.

Attention : Le système ne récupère pas la place dans le fichier des données. Pour récupérer la place des enregistrements supprimés, il faut utiliser l'utilitaire Xreof.dhop

 

Exemple

Suppression de l'enregistrement client. L'enregistrement a été lu au préalable en mode P ou F dans la donnée client.

; Validation de la suppression 

; relecture en mode réservé 

st = Iseek(fcli , wcli , "CODECLI" , fcli.keyValue , 'R');

switch st

case 0 ; lecture OK

   stdel = Idelete(fcli , client) 

case H_RESERVED ; enreg. réservé

   MessageBox("Enregistrement réservé"," ")

case H_RECORD_NOT_FOUND ; enregistrement supprimé

   MessageBox("Le client " & client.codcli &  

               "n'existe plus"," ") 

endswitch

Hpclose (fcli)
