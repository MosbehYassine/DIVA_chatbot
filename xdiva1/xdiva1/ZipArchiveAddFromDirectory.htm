ZipArchiveAddFromDirectory Famille Thème

 

Ajoute un répertoire dans une archive au format zip

 

Bool ZipArchiveAddFromDirectory( ZipArchivePath, DirectoryToAdd[, ZipPath], [ZipPassword] )

 

Paramètres

ZipArchivePath

Chemin vers le fichier zip à modifier

DirectoryToAdd

Chemin vers le répertoire dont le contenu sera ajouté à l'archive

ZipPath

Chemin dans l'archive zip où le répertoire doit être ajouté. Ce paramètre est facultatif. S'il n'est pas spécifié, alors sa valeur sera la chaîne vide et le contenu de DirectoryToAdd sera ajouter à la racine de l'archive.

ZipPassword

Mot de passe pour les fichiers chiffrés dans l'archive zip

 

Retour

La fonction renvoie 1 en cas de succès, 0 sinon. Pour avoir plus d'informations sur l'erreur en cas d'échec, utiliser la fonction ZipArchiveGetLastErrorCode()

 

Remarques

Si le fichier n'existe pas, il est crée. S'il existe, son contenu est écrasé.

Le nom peut contenir le chemin complet vers le fichier, le chemin relatif ou juste le nom du fichier.
