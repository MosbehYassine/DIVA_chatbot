HkeySkipNext  Famille Thème

 

La fonction HkeySkipNext permet de positionner la clé de manière à ce que la prochaine lecture rende la valeur suivante sur une portion de clé spécifiée.

 

Ptr = HkeySkipNext (tdf , valeurCle)

 

Paramètres

Tdf

Table de définition du fichier.

ValeurCle

Valeur de la clé.

 

Retour

La fonction retourne toujours 0.

Tdf.key est positionnée à ValeurCle  complétée avec le caractère $ff.

 

Exemple 1

Soit un fichier d'adresses avec une clé sur le code postal.

On désire afficher la liste de tous les codes postaux présents dans le fichier. Comme il y a des doublons, le traitement sera nettement optimisé par l'utilisation de la fonction HkeySkipNext.

 

tdf.key = "A"

loop hread(tdf,adresse) = 0

display adresse.cp

hkeyskipnext(tdf,"A" & adresse.cp)   ; sauter tous les homonymes

endloop

 

Si le fichier contient les valeurs suivantes :

 57000
57000
57130
57130
67050
67060
67060

le programme lit uniquement quatre enregistrements et affiche :

 57000
57130
67050
67060

 

Exemple 2

Toujours avec le même fichier et la clé sur le code postal, nous voulons afficher la liste de tous les départements.

tdf.key = "A"

loop hread(tdf,adresse) = 0

display adresse.departement

hkeyskipnext(tdf,"A" & adresse.departement)   ; sauter tous les enregistrements du même département

endloop

 

le programme lit uniquement deux enregistrements et affiche :

57
67
