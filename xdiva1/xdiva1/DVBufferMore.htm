DVBufferMore Famille  Thème

La fonction DVBufferMore permet de savoir s'il y a encore des données à lire.

 

Long  DVBufferMore ( id )

 

Paramètres

Id

Identifiant de DVBuffer obtenu par DVBufferGetId.

 

 

Retour

0

Non, la fin du DVBuffer est atteinte

1

Oui, il y a encore des données à lire.

-1

Identifiant invalide
