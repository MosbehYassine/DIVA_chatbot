DictionaryStats Famille  Thème

DictionaryStats permet de connaître l'état du dictionnaire.

Alpha DictionaryStats (Ident)

Paramètres

Ident

Identifiant du dictionnaire.


Retour

-1

Ident invalide

Autre

Chaîne HMP contenant le résultat


La chaîne HMP contient les éléments suivants :

<TailleTable>

Taille de la table de hash associée au dictionnaire. C'est le nombre d'éléments donné lors de la création de la table.

<CasesVides>

Nombre de cases inoccupées dans la table de hash.

<Collisions>

Nombre total de collisions

<MaxCollisions>

Nombre maximal de collisions pour une entrée de la table. Cela signifie que pour une recherche dans le dictionnaire, le nombre de comparaisons a effectuer sera inférieur ou égal à cette valeur.

<NombreElements>

Nombre d'éléments dans le dictionnaire
