Structure des journaux

Les fichiers journaux se nomment respectivement /Divalto/divaltolog/Ferror.log pour le journal des erreurs et /Divalto/divaltolog/Fevent.log pour le journal des evénements.

Chaque erreur (ou appel de la fonction SystemLogWrite ) provoque l’écriture d’une ligne au format HMP. Les paramètres sont les suivants :

Cat

Catégorie du message

Date

Date

Heure

Heure

NumErr

Numéro de l’erreur

CodeSys

Code système

CodeCompl

Code complémentaire

Lieu

Lieu

User

Code utilisateur Harmony

Tache

Numéro de tâche

Adresse

Adresse dans le programme Diva

Programme

Nom du programme

Module

Nom du module courant

Texte

Texte de l’erreur

UserWin

Utilisateur Window

Ordinateur

Nom de l’ordinateur

Pile

Etat de la pile Diva

Tous les paramètres ne sont forcément renseignés.

Pour obtenir la ligne du source correspondant à l'adresse d'exécution, il faut compiler le module avec l'option L pour obtenir un listing de compilation. Attention, si le programme était compilé en mode Debug il faut également mettre l'option d.
