HARMONY_PARAM  Famille Thème

 

La variable d'environnement HARMONY_PARAM contient une partie de la ligne de commande placée lors du lancement d'Harmony.

Le texte qui est placé dans HARMONY_PARAM doit être précédé de /env.

Elle peut être lue une seule fois par la fonction GetEnv ; une fois lue, elle est automatiquement supprimée.

Elle est également supprimée par les instructions ProgramCall, ProgramGoto et Exec .

Exemple

Soit un raccourci du bureau paramétré de la manière suivante :

Cible : C:\Divalto\Sys\XrtDiva.exe p,pilotage /env mes parametres

Ce raccourci lance le programme p en pilotant la première réponse du programme et en plaçant "mes paramètres" dans la variable d'environnement HARMONY_PARAM.

Le programme Diva peut ensuite récupérer ces valeurs :

1 chaine 20

input "Rep " chaine             ; -> pilotage

display GetEnv("HARMONY_PARAM") ; -> mes parametres
