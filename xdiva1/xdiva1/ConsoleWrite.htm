ConsoleWrite  Famille 

L'instruction ConsoleWrite permet d'afficher un texte dans l'onglet Compte-rendu de Xwin.

Cela nécessite que le programme soit lancé en mode debug depuis Xwin. Si ce n'est pas le cas, ConsoleWrite ne fait aucune action.

 

ConsoleWrite (mess)

 

Paramètres

mess

Message à afficher dans xwin.

 

Remarque

Les messages sont également écrits vers un manager de Logs. Cela permet de traiter les logs dans un contexte d'exploitation, sans utiliser Xwin.

Un logicel comme https://github.com/ishegatron/Sentinel permet de visualiser les logs au dil de l'eau.

Il faut créer un fichier nlog.config (dans divalto/sys)

Exemple :

<?xml version="1.0" encoding="utf-8" ?>

<nlog xmlns="http://www.nlog-project.org/schemas/NLog.xsd" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" autoReload="true">

 

  <targets>

    <target xsi:type="NLogViewer"

            name="diva"

            includeSourceInfo="true"

            address="udp://127.0.0.1:9999"

            />

  </targets>

 

  <rules>

    <logger name="*" minlevel="Trace" writeTo="diva" />

  </rules>

</nlog>

Au lancement de Sentinel :

- faire Next pour prendre les paramètres par défaut

- dans la fenêtre <Provider Registration>, faire Add et prendre tous les paramètres par défaut. (Next puis finish)
