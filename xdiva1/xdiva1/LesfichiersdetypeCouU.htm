Les fichiers de type C ou U

Les fichiers de type C ou U sont destinés à contenir du texte (sources de programmes, textes d'aides,...). Leur structure simple leur permet d'être manipulés par les éditeurs standards des systèmes.

 

Les fichiers de type U

Les enregistrements sont de taille variable, la taille étant limitée à 32 K.

Ces fichiers n'ont pas de structure particulière, les enregistrements étant délimités par un séparateur :

  • sous unix, le séparateur d'enregistrement est le caractère hexa $0A,

  • sous windows, le séparateur d'enregistrement est représenté par la suite des caractères hexa $0D et $0A.

Ces fichiers peuvent être saisis par tout éditeur de textes (vi, edit, xwin, ...).

 

Méthode d'accès :

L'accès aux fichiers de type C ou U est purement séquentiel.

Pour lire un enregistrement précis, il faut avoir préalablement lu tous les enregistrements précédents (fonction fread).
