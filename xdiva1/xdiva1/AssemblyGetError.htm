AssemblyGetError Famille  Thème

La fonction AssemblyGetError permet de récupérer le détail d'une erreur.

Si une des fonctions Assembly retourne une erreur, il faut appeler AssemblyGetError pour connaître le détail.

 

Long  AssemblyGetError  ( &détail )

 

Paramètres

détail

Variable recevant le texte de l'erreur.

 

Retour

La fonction retourne la valeur du code d'erreur et la variable détail contient le texte de l'erreur.
