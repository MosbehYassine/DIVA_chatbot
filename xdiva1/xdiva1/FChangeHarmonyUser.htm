FChangeHarmonyUser

La fonction FChangeHarmonyUser permet de changer le code utilisateur de la tâche courante.

 

Long FChangeHarmonyUser ( action , [ utilisateur ] )

 

Paramètres

Action

1

Changer de code utilisateur. Attention, l'utilisateur courant doit avoir HIP dans ses codes de confidentialités.

2

Revenir à l'état initial.

3

Demande au système si un changement d'utilisateur a eu lieu.

 

Code utilisateur

Nouveau code utilisateur (si Action = 1)

 

Retour

Action = 1

0 : pas d'erreur

0x0070 Privilège insuffisant

Action = 2

La fonction retourne 0

Action = 3

1 : le code utilisateur a été modifié

0 : le code utilisateur n'a pas été modifié.

 

Remarques

  • Le code utilisateur utilisé pour effectuer les connexions xlan ne change pas.

  • Après l'appel de la fonction avec Action=1, la zone harmony.user contient le nouveau code utilisateur.

  • Les contrôles de confidentialités (fonction HAccessCodeControl) sont effectuées avec le nouveau code utilisateur.

  • Le changement de code utilisateur (Action = 1) est protégé. L'utilisateur courant doit avoir HIP dans ses codes de confidentialités. La retour à l'état initial (action = 2) n'est pas protégé.

  • Cette fonction peut être utilisée notamment par les programmes Web qui effectuent une saisie de code utilisateur.
