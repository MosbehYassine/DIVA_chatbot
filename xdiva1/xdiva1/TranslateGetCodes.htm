TranslateGetCodes Famille Thème

 

La fonction TranslateGetCodes retourne la liste des langues disponibles. Elle lit le fichier paramètres TranslateParams.txt et retourne la liste dans une chaîne HMP.

 

Long TranslateGetCodes ( chaîne )

 

Paramètre

Chaîne

Donnée alphanumérique qui reçoit la liste.

 

Retour

La fonction renvoie 1 en cas de succès, 0 sinon.

La chaîne hmp contient les paramètres suivants :

 

<LanguageCode>

Code langue.

<Description>

Commentaire.

<TypeDate>

Espace : date au format jj/mm/aaaa (LE = little endian).

A : date au format mm/jj/aaaa (ME = middle endian).

B : date au format aaaa/mm/jj (BE = big endian).

<CodePage>

Code page de la langue.

<DecimalSeparator>

Séparateur décimal.

Ce paramètre peut prendre une des valeurs suivantes : comma ou point.

<ThousandSeparator>

Séparateur des milliers pour le format \formatmille.

Ce paramètre peut prendre une des valeurs suivantes : comma, point ou space.

<DateSeparator>

Caractère séparant les éléments d'une date ("/" par défaut).

Par exemple, le séparateur "-" correspond à la norme Iso 8601 qui est appliquée au Canada.

<HelpCode>

Code langue pour les fichiers d'aides.

<LanguageCodeData>

Code langue disponible pour la traduction des libellés.

<LangageBaseData>

Code langue de base pour les libellés <=> code langue dans lequel les libellés sont écrits dans les fichiers.

 

Exemple

1 s         S

1 st        X

1 param     S

1 valeur    S

 

st = TranslateGetCodes(s)

if st

   Loop hmpread(s,param,valeur) = 0

      display param & " " & valeur

   endloop

endif
