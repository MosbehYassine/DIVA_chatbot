Ftp_DownloadMultipleFile Famille Thème

 

Téléchargement de plusieurs fichiers depuis un serveur FTP.

 

Module "yftp.dhop"

int Ftp_DownloadMultipleFile (server, login, password, LocalDirectory, [RemoteDirectory], PatternRemoteFile, [OpenHarmony], [proxyServer], [ProxyMode], [proxyLogin], [proxyPassword], [binary], [passive], [IntermediateExtension], [DeleteRemoteFile], ContenuListe, [keepAlive])

 

Paramètres

Server

Adresse du serveur sous la forme

ftp://ip[:port]  pour un serveur ftp

sftp://ip[:port]  pour un serveur sftp

 

Login

Identifiant sur le serveur. Si non précisé, c'est "anonymous" qui est utilisé. Dans ce cas, le serveur doit accepter les connexions anonymes.

  

Password

Mot de passe sur le serveur.

 

LocalDirectory

Chemin local où va être téléchargé le ou les fichier(s).

 

RemoteDirectory

Directory sur le FTP.

 

PatternRemoteFile

Pattern des fichiers à télécharger pour filtre des fichiers à récupérer (*.* pour tout ou *.xml pour ne prendre que les fichiers avec extension XML).

 

OpenHarmony

Indique que le chemin LocalFile est au format Harmony (False par défaut). Cette fonctionnalité n'est implémentée que pour Ftp.

 

ProxyServer

Adresse du serveur proxy

 

ProxyMode

Mode d'identification sur le proxy.

1

Prendre les paramètres du système. Il n'y a pas d'autre paramètres à préciser, l'authentification est celle du poste de travail.

2

Préciser l'url du serveur, mais authentification SSPI. Inutile de préciser ProxyLogin et ProxyPassword

3

Mode manuel. Il faut préciser tous les paramètres

 

ProxyLogin

Identifiant sur le serveur proxy.

 

ProxyPassword

Mot de passe sur le serveur proxy.

 

Binary

Demande au protocole de travailler ou non en mode binaire. False par défaut. Ce mode est toujours recommandé.

 

Passive

TRUE : le processus client est à l'initiative de la connexion (mode par défaut)

FALSE : le processus client est en attente de connexion

 

IntermediateExtension

Permet de télécharger le fichier dans une extension .tmp puis le renommer une fois fini.

Il est possible de modifier la valeur de l'extension par défaut avec Ftp_Set_IntermediateExtension et de récupérer la valeur par défaut de l'extension avec Ftp_Get_IntermediateExtension.

 

DeleteLocalFile

Les fichiers seront supprimés une fois chargés (False par défaut).

 

ContenuListe

Un compte-rendu sous forme de liste sera rendu :

1 : La liste contiendra un compte-rendu pour chaque fichier quel que soit le résultat.

2 : La liste contiendra un compte-rendu pour les fichiers en échec.

3 : La liste contiendra un compte-rendu pour les fichiers en réussite.

 

KeepAlive

La connexion reste ouverte en vue d'une nouvelle opération avec le même serveur (True par défaut)

 

Retour

La fonction retourne un entier.

Status

0 = pas d'erreur   1 = au-moins un fichier en erreur

 

Le détail est disponible dans une liste. L'identifiant de cette liste est récupérable avec Ftp_Get_ListUploadedFile.

Le contenu de cette liste est une structure FtpFileResult de yftp.dhop.

 

 

Remarques

  • De nombreux serveurs Ftp / Sftp sont sous Unix ou Linux. Sur ces systèmes d'exploitation, les noms de fichiers sont sensibles à la casse.
    Le paramètre RemoteFile doit donc avoir la casse exacte.

  • En fonction de la configuration du serveur, il se peut que les caractères spéciaux et accentués posent problème.
