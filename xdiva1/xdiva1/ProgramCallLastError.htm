ProgramCallLastError Famille Thème

 

ProgramCallLastError permet de récupérer le code d'erreur système (windows) après un ProgramCall qui a échoué.

.

Long ProgramCallLastError

 

Retour

La fonction retourne le code d'erreur windows.

Voir la fonction ProgramCallGetError pour avoir le code d'erreur système.
