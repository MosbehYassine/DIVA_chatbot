WinGetTextError Famille Thème

 

La fonction WinGetTextError permet de récupérer un texte correspondant à un numéro d'erreur système. L'erreur est fournie par la fonction WinGetLastError.

 

Char WinGetTextError (erreur)

 

Paramètres

Erreur

Code d'erreur Windows.

 

  

Retour

La fonction retourne le texte correspondant au code d'erreur.
