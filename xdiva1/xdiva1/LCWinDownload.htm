LCWinDownload  Famille Thème

La fonction LCWinDownload permet de copier un fichier du serveur vers le client.

 

Long LcWinDownload (FichierDepart , &FichierArrivee , [CleCryptage] , [NePasModifierNomFichierArrivee])

 

Paramètres

FichierDepart

Nom complet du fichier de départ

 

FichierArrivee (*)

Nom complet du fichier d'arrivée. En retour de la fonction, FichierArrivee contient le nom effectif du fichier copié.

 

CleCryptage

 Clé de cryptage. Si la clé n'est pas spécifiée ou vaut espace il n'y a pas de cryptage.

 

NePasModifierNomFichierArrivee

True / False (par défaut)

True indique que le nom de fichier Arrivee est un nom « complet » sur le poste client et qu'il faut l'utiliser tel que.

False : le fichier est copié dans le répertoire : "Mes Documents/Divalto/Download" du poste client et Arrivee contient le nom complet sur le client.

 

Retour

0

Pas d'erreur

Autre

Code d'erreur système.

 

 

Cas particulier du client léger Web

  • (*) Le client léger Html ne tient pas compte du paramètre FichierArrivee : le fichier de départ est directement téléchargé vers le poste client.
    De plus, le navigateur client n’acceptera pas le transfert si l’extension du fichier lui est inconnue. Cela peut poser problème si l’extension précisée dans le nom du fichier de départ n’est pas celle correspondant effectivement au contenu du fichier. Par exemple, lorsque le fichier de départ est un fichier temporaire d’extension .tmp car cette dernière n’est pas reconnue par le navigateur. La solution consiste ici à produire un fichier de départ directement avec la bonne extension.

  • D’autre part, si le navigateur demande confirmation du téléchargement du fichier, le programme Diva ne doit pas se terminer immédiatement derrière l’instruction car la fenêtre du navigateur se fermera avant que l’utilisateur ait pu répondre à la demande. Le cas échéant, une solution consiste à faire suivre l’instruction d’une MessageBox.
