ConvertHtmlFileToRtfFile Famille 

La fonction ConvertHtmlFileToRtfFile convertit un fichier Html en fichier Rtf

 

Long ConvertHtmlFileToRtfFile (rtfFile, htmlFile, [options] )

  

Paramètres

 

RtfFile

Nom du fichier rtf résultat

 

HtmlFile

Nom du fichier html

  

Options

Chaine Hmp pour positionner des options (non utilisée pour l'instant)

Retour

0 = OK
1 = Erreur (ConvertHtmlRtfLastError permet de récupérer le texte d'erreur)
