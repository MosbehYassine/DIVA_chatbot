LCWinDivaltoDelete LCWinDivaltoGlobalDelete  Famille Thème

L'instruction LCWinDivaltoDelete permet de supprimer une valeur du registre sous la clé "HKEY_CURRENT_USER\SOFTWARE\Divalto\divalto.ini\"

L'instruction LCWinDivaltoGlobalDelete permet de supprimer une valeur du registre, sous la clé "HKEY_LOCAL_MACHINE\SOFTWARE\Divalto\divalto.ini\"

Ces fonctions se trouvent dans le module ysystemex.dhop.
