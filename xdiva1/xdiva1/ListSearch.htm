ListSearch   Famille  Thème

ListSearch permet de rechercher un élément dans la liste en donnant une clé approximative. Elle retourne l'élément dont la clé est supérieure ou égale à la clé recherchée.
La liste doit être en mode de tri automatique. La fonction Diva de comparaison est appelée pour comparer l'élément de la liste avec la valeur recherchée.
ListSearch est très rapide car elle minimise le nombre de comparaisons à effectuer.

Long ListSearch (ticket , valeur , article)

Paramètres

Ticket

Identifiant de la liste.

Valeur

Valeur à rechercher dans la liste.

Article

Donnée réceptrice de l'élément de la liste.

 

Retour

-1

Ticket invalide

0

Recherche infructueuse

Autre

Adresse de l'élément trouvé. Cet élément devient l'élément courant de la liste.
 

Remarque

Si vous voulez utiliser la fonction Diva de comparaison que vous avez passée en paramètre lors de l'appel de ListMode, Valeur doit avoir la même structure que Article. Dans le cas contraire, vous devez utiliser une autre fonction de comparaison en rappelant la fonction ListMode.

Exemple

1 liste L

1 adr 16

1 nom 20

 

function long compare(&p1,&p2)

1 p1 U

1 p2 U

beginf

  freturn SortCompare(p1,p2)

endf

  

main

liste = ListCreate ; création liste

GetAdressFunction(" ","compare",adr)

ListMode(liste,1,adr) ; mode automatique

ListInsert(liste,"DURANT") ; ajout d'éléments

ListInsert(liste,"DUPONT")

ListInsert(liste,"DUPOND")

ListInsert(liste,"ALBERT")

if ListSearch(liste,"DU",nom) ; recherche sur la clé approxi-

    display nom  ; --> DUPOND ; mative.

endif
