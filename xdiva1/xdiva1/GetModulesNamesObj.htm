GetModulesNamesObj  Famille Thème

 

La fonction GetModulesNamesObj retourne une chaîne HMP contenant la liste de tous les modules susceptibles d'être chargés par un programme/module.

Attention, la liste des modules pouvant être chargés est très grande (environ 1000 modules pour un programme).

Contrairement à GetModulesNames qui donne la liste des modules chargés à un instant T, GetModulesNamesObj recherche récursivement tous les modules qui pourraient être appelés.

Si les fichiers objets se trouvent sur un serveur xlan, cette fonction peut être très longue à s'exécuter (plusieurs dizaines de secondes).

 

Char GetModulesNamesObj ( [module] , [récursif] )

 

Paramètres

Module

Nom du module pour débuter la recherche.

Si ce paramètre est omis, la recherche se fait à partir du programme courant.

Récursif

TRUE = la recherche des modules utilisés se fait de manière récursive dans tous les modules trouvés.

FALSE = la recherche ne se fait qu'à un seul niveau avec les éventuelles surcharges. C'est la valeur par défaut.

 

Retour

La fonction retourne une chaîne Hmp avec les paramètres suivants :

Module

Nom du module

Infos

Liste des informations positionnées par la pseudo SetModuleInf. Les lignes sont séparées par le caractère |

VersionModule

Version du module

Pack

Version du service pack

NumApplic

Numéro d'application (pour la prise de licence)

 

 

Exemple

Procedure affiche(chaine)

1 chaine A

1 cle S

1 valeur S

1 cpt 10,0

1 infos L

1 uneInfo S

beginp

 

   GetBegin

   Loop hmpread(chaine,cle,valeur) = 0

      switch (cle)

      case "MODULE"

         display valeur ; nom du module

         if GetChar() <> $00 | Loop GetChar() = $00 | endloop | endif

         cpt++

      case "INFOS"

         infos = SplitList(valeur,"","","|")

         ListBegin(infos)

         Loop ListNext(infos,uneInfo) not in (0,-1)

             display [ "     " uneInfo ]

         endloop

         ListDestroy(infos)

      case "VERSIONMODULE"

          ; valeur contient le numéro de version

      case "PACK"

          ; valeur contient le numéro de pack

      case "NUMAPPLIC"

          ; valeur contient le numéro d'application pour les protections

      endswitch

   endloop

   display cpt

   GetEnd

endp

 

Main

   Affiche(GetModulesNamesObj("ia.dhop"))

   programExit
