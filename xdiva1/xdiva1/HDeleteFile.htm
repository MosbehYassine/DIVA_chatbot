HDeleteFile  Famille Thème

 

La fonction HDeleteFile permet de supprimer un fichier. Si le fichier est de type séquentiel indexé (I), la fonction peut également supprimer le fichier des données.

 

Numer = HDeleteFile (fichier, status, [ suppdata ] , [abort])
 
Paramètres

Fichier

Nom complet du fichier à supprimer.

Status

Donnée de type X qui reçoit en retour le code d'erreur système.

Suppdata

Booléen (TRUE par défaut) indiquant si le fichier des données doit également être supprimé. (cas où Fichier est de type I).

Abort

Booléen (TRUE par défaut) indiquant si la fonction doit arrêter le programme en cas d'erreur ou rendre la main avec un code d'erreur.

En cas d'arrêt du programme, la fenêtre standard des erreurs est affichée et l'erreur est journalisée dans le fichier ferror.log.

 

Retour

La fonction renvoie la valeur nulle en cas de succès. Sinon, elle renvoie un code d'erreur principal, et le paramètre Status contient le code d'erreur du système.

Pour la liste des erreurs possibles, voir Erreurs des fonctions HcreateFile, HSicreate

Si Abort = TRUE, toutes les erreurs provoquent l'arrêt du programme.

 

Remarque

Le fichier ne doit pas être ouvert au moment de l'appel à cette fonction.

 

Exemple

; suppression du fichier "mon fichier"

1 st X

HDeleteFile("/Divalto/sys/mon fichier",st)
