Hdate  Famille Thème

 

La fonction Hdate permet de faire des calculs sur une date.

Par exemple, calculer le dernier jour du mois suivant dans l'année prochaine.

 

Date Hdate ( [date], [op_jour], [ op_mois], [op_année])

 

Paramètres

Date

Date sur 8 positions. Ce paramètre est facultatif ; s'il n'est pas précisé, le calcul se fait sur la date du jour.

Op_jour

Variable alpha-numérique indiquant l'opération à effectuer sur le jour de la date. Ce paramètre peut prendre les valeurs suivantes :
P ou p : indique le premier jour dans le mois

D ou d : indique le dernier jour dans le mois

+n : ajoute n jours à la date

-n : soustrait n jours à la date.

Ce paramètre est facultatif. S'il n'est pas renseigné, aucun traitement n'est fait sur le jour.

Op_mois

Variable alpha-numérique indiquant l'opération à effectuer sur le mois de la date. Ce paramètre peut prendre les valeurs suivantes :
P ou p : indique le premier mois de l'année

D ou d : indique le dernier mois de l'année

+n : ajoute n mois à la date

-n : soustrait n mois à la date.

Ce paramètre est facultatif. S'il n'est pas renseigné, aucun traitement n'est fait sur le mois.

Si la date d'origine correspondait à une fin de mois, le résultat correspond également à une fin de mois.
Ex : hdate("20000229", ,1)  --> 20000331

Op_année

Variable alpha-numérique indiquant l'opération à effectuer sur l'année de la date. Ce paramètre peut prendre les valeurs suivantes :
+n : ajoute n années à la date

-n : soustrait n années à la date.

Ce paramètre est facultatif. S'il n'est pas renseigné, aucun traitement n'est fait sur l'année.

 

Retour

La fonction retourne la date modifiée sur 8 positions.

Exemples

; dernier jour dans le mois

display hdate("20000213","d") --> 20000229

 

; dernier jour du mois précédent

display hdate("20000213","d",-1) --> 20000131

 

; année suivante

display hdate("20000229",,1) --> 20000331

; dernier jour du mois suivant de l'année suivante

;(la date du jour est "20000229")

display hdate(,"d",1,1) --> 20010331
