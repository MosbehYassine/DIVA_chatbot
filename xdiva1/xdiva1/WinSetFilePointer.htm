WinSetFilePointer  Famille Thème

 

La fonction WinSetFilePointer déplace le pointeur d'un fichier ouvert.

 

Long WinSetFilePointer(ticket, Distance, PoidsFortsDistance , Méthode)

 

Paramètres

Ticket

Identifie le fichier dont on veut déplacer le pointeur. Le fichier doit être ouvert avec l'accès GENERIC_READ ou GENERIC_WRITE.

Distance

Spécifie le nombre d'octets pour le déplacement.

PoidsFortsDistance

Donnée de type L contenant les poids forts de la distance. Ce paramètre reçoit en retour les poids forts de la nouvelle position du pointeur de fichier.

Méthode

Précise le point de départ du déplacement dans le fichier. Ce paramètre peut être une des valeurs suivantes

FILE_BEGIN 

Le point de départ est 0 (début du fichier). Si FILE_BEGIN est spécifié, Distance est interprété comme une valeur non signée.

FILE_CURRENT

La valeur courante du pointeur est la position de départ.

FILE_END

La fin du fichier est la position de départ.
 

Retour

-1

Erreur. Appelez la fonction WinGetLastError pour connaître le détail de l'erreur.

Autre

La fonction retourne les poids faibles de la nouvelle position du pointeur et PoidsFortsDistance contient les poids forts de la nouvelle position.

Remarques

WinSetFilePointer ne peut être utilisée avec des tubes nommés ou des voies de communication.

 

Exemple

Ouverture d'un fichier, positionnement en fin de fichier et écriture d'un enregistrement.

1 fic L

1 pf L

1 st L

1 nbecr L 

fic = WinCreateFile("d:\Divalto\sys\stest",

              GENERIC_READ + GENERIC_WRITE, 

              FILE_SHARE_READ + FILE_SHARE_WRITE, 

              0,OPEN_EXISTING,FILE_ATTRIBUTE_NORMAL,0) 

; ... test d'une éventuelle erreur ...

pf = 0

st = WinSetFilePointer(fic,0,pf,FILE_END)

; ... test d'une éventuelle erreur ...

st = WinWriteFile(fic, "nouvel enregistrement" & $0d0a,nbecr)

; ... test d'une éventuelle erreur ...

st = WinCloseHandle(fic)
