XmlSetOption  Famille  Thème

La fonction XmlSetOption permet de positionner des options de lecture du flux.

Pour l’instant, une seule option peut être modifiée, l’option whitespacehandling qui permet d’ignorer ou non les espaces du flux.

 

Numer XmlSetOption ( ticket , valeur)

Ticket

Valeur retournée par la fonction XmlOpen.

 

Valeur

Chaîne HMP contenant les options à positionner.

La seule option qu’il est possible de positionner est WhiteSpaceHandling.

 

Les valeurs possibles pour cette option sont :

None

Les espaces sont ignorés (c’est la valeur par défaut lors de l’ouverture du flux).

Significant

Les espaces significatifs sont retournés.

All

Tous les espaces sont retournés.

 

 

 

Retour

0

Pas d’erreur

-1

Ticket invalide

1

Chaîne Hmp incorrecte

2

Valeur de l’option incorrecte

3

Option inconnue

 

Exemple

 

XmlSetOption(ticket,"<whitespacehandling>all")
