WebRequestSetUrl Famille Thème

 

Positionnement de l'URL du service web dans un objet WebRequest.

 

Int WebRequestSetUrl ( Ticket , Url )

 

Paramètres

Ticket

Ticket préalablement obtenu par WebRequestNew

 

Retour

0

Pas d'erreur

1

Ticket incorrect

2

Erreur. Voir le détail avec WebRequestGetError

 

Remarques

WebRequestSetUrl vérifie que l'Url est correctement formée, mais ne vérifie pas que l'adresse existe..

 

Exemple

 

1 ticketRequete L

ticketRequete = WebRequestNew()

st = WebRequestSetUrl(ticketRequete,"https://jsonplaceholder.typicode.com/posts")
