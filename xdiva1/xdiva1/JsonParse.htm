JsonParse Famille Thème

 

JsonParse convertit une chaîne de caractères JSON en un objet.

Ensuite le contenu de cet objet pourra être lu par la fonction JsonGetValue.

 

Int JsonParse ( Ticket , &ChaineJson  )

 

Paramètres

Ticket

Ticket préalablement obtenu par JsonOpen

 

ChaineJson

Variable contenant la chaîne de caractères au format JSON.

 

 

Retour

0

Pas d'erreur

1

Ticket incorrect

2

Erreur. Voir JsonGetError pour le détail.
