SocketLastError  Famille   Thème

La fonction SocketLastError permet de récupérer un code d’erreur détaillé sur la dernière fonction Socket utilisée. Elle doit être appelée immédiatement après la fonction qui est sortie en erreur.

Int = SocketLastError


Retour

La fonction retourne le code d’erreur de la dernière fonction socket appelée. Voir Constantes socket
