HmpEncode  Thème

La fonction HmpEncode permet d’encoder la valeur d’un paramètre pour qu’il n’y ait pas d’ambiguïté possible dans la chaîne hmp avec les délimiteurs de paramètres.

En effet, il n’est pas possible de mettre le caractère < dans une valeur de paramètre car il sera interprété comme le début d’un autre paramètre.

Par exemple la chaîne <param1>a < b est incorrecte. L’utilisation de HmpEncode permet de résoudre ces problèmes.

Les fonctions HmpRead et HmpSeek fonctionnent sans qu’il soit nécessaire de décoder la chaîne.

 

Alpha HmpEncode (variable)

Variable

Valeur d’un paramètre Hmp à encoder

 

Retour

La fonction retourne la chaîne encodée.

 

Remarque

Il ne faut pas encoder toute un chaîne Hmp mais uniquement la valeur des paramètres (voir exemple ci-dessous).

 

Exemple 

1 hmp S

hmp = "<param1>" & HmpEncode("a < b")

display hmp ; --> <param1>a \< b
