Input  Famille 

 

Input permet d'effectuer une entrée clavier (chaîne de caractères ou valeur numérique) en mode « Caractères ».

 

Attention :

Il n'est pas possible d'utiliser l'instruction Input pour saisir des informations "côté client léger" (il faut passer par la saisie d'un masque d'écran).

 

Input peut toutefois être utilisée par un programme piloté (un programme qui lit ses paramètres d’entrée dans un fichier pilote = batch par l’instruction Input).

 

 
Input expression variable [ sauts ]

 

Paramètres

Expression

Représente la question à poser à l'écran. Elle a la même forme que dans l'instruction Display.

Variable

Variable qui recevra la réponse frappée.
Les données de type numérique sont automatiquement cadrées à droite.

Sauts

Nombre de sauts de ligne à effectuer après l'entrée clavier. Si ce nombre est omis, la valeur prise par défaut est 1, c'est-à-dire que le curseur se positionne sur la première colonne de la ligne suivante.
Si sauts vaut 0, le curseur n'est pas déplacé après la saisie, et l'affichage suivant commencera donc sur la même ligne.

La donnée Harmony.Key permet de connaître la touche qui a provoqué la fin de la saisie (Entrée, touches de fonction, etc.). La liste des codes fournis par la variable Harmony.Key se trouve dans l'include Zdiva.dhsp.

 

Exemple

input [ = 10 1 'Nom ............. : ' ] nom 0
