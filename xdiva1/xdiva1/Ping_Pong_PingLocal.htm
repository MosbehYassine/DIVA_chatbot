Ping - Pong - PingLocal - PingSelf  Famille Thème

 

Les instructions Ping, Pong et PingLocal permettent de placer des données dans un tunnel.

Ping (libellé , expression)

Pong (libellé , expression)

PingLocal (libellé , expression)


PingSelf (libellé , expression)

 

Paramètres

Libellé

Chaîne de caractères identifiant la donnée placée dans le tunnel. La lecture des données placées dans le tunnel se fait par ce libellé.

Expression

Donnée à placer dans le tunnel.

Ping est utilisé avant un enchaînement (ProgramGoto) ou un appel de programme (ProgramCall). Le programme appelé récupère ces données par la fonction PingReceive.

Pong est utilisé avant un retour au programme appelant pour lui renvoyer des données. Le programme appelant récupère ces données par la fonction PongReceive.

PingLocal est utilisé pour sauvegarder une donnée dans le tunnel local.

PingSelf permet d'écrire des données dans le tunnel lu par PingReceive (donc comme si elles avaient été écrites par le programme appelant par Ping)

Exemple : Ping ("client" , ecli)
