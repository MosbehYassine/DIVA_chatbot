Services Web : Généralités

Les fonctions pour les services Web permettent :

  • De développer des services web en Diva

  • D’appeler ces services Web depuis un programme Diva.

Pour l’instant, elles ne permettent pas d’appeler n’importe quel service disponible sur le Web.

Pour appeler d'autres services web que ceux écrits en Diva, vous pouvez utiliser les fonctions Assembly. Les fonctions Assembly permettent d'appeler des fonctions .net et donc d'invoquer n'importe quel service Web.

Voir Fonctions Assembly .net et Exemple d'utilisation des fonctions Assembly

 

Un service Web est une fonction mise à disposition par un serveur et accessible depuis le réseau Internet. Pour le programme Diva, appeler un service Web est donc aussi simple que d’appeler une fonction d’un module.

L’appel se fait par la fonction WebServiceDivaExecute , dont le nombre de paramètres est figé.
