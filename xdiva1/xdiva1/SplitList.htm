SplitList  Famille 

 

La fonction SplitList décompose une chaîne de caractères en une liste de  mots.

 

Long = SplitList (chaîne , [ séparateurs ] , [ séparateursPaire ] , [ séparateursNonRendus ] , [ quotes ] )

 
  

Paramètres

Chaîne

Chaîne de caractères en entrée.

 

Séparateurs

Chaîne de caractères contenant la liste des caractères séparateurs de mots.

Cette chaîne peut être vide.

Exemple : ":.()&=+<>-/*, "

 

SéparateursPaire

Chaîne de caractères contenant la liste des séparateurs de mots qui sont sur deux positions. Les paires doivent être séparées par un espace.

Attention : les paires ne sont prises en compte que si le premier caractère se trouve également dans Séparateurs.

Exemple : ">= <= .. += &= && := ++ --"

 

SéparateursNonRendus

Chaîne de caractères contenant les séparateurs simples qui ne seront pas rendus par la fonction.

Par exemple, si nous voulons extraire une liste de paramètres entre virgules, la virgule elle même ne nous intéresse pas. On mettra donc la virgule dans SéparateursNonRendus

Le séparateur espace n'est jamais rendu.

Les séparateurs non rendus ne doivent pas se trouver dans la liste Séparateurs

 

Quotes

1

un mot entre quotes doit toujours être considéré comme un mot, indépendamment des séparateurs (valeur par défaut)

0

un mot entre quotes n'est pas  toujours être considéré comme étant un mot

2

les quotes sont ignorées, c'est à dire quelles sont traitées comme des caractères ordinaires.

 

Retour

La fonction crée une liste de valeurs et retourne l'identifiant de cette liste.

Cette liste devra être détruite par l'instruction ListDestroy.

 

Exemple 1

1 liste L

1 mot   S

liste = SplitList("a = a + b","=+<>-/* ")

ListBegin(liste)

loop listNext(liste,mot)

   display mot

endloop

ListDestroy(Liste)

 

La fonction affiche les mots suivants :  

a
=
a
+
b
