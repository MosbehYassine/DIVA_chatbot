LCWinDivaltoReadString LCWinDivaltoGlobalReadString  Famille Thème

La fonction LCWinDivaltoReadString permet de lire une chaîne dans le registre, sous la clé "HKEY_CURRENT_USER\SOFTWARE\Divalto\divalto.ini\"

La fonction LCWinDivaltoGlobalReadString permet de lire une chaîne dans le registre, sous la clé "HKEY_LOCAL_MACHINE\SOFTWARE\Divalto\divalto.ini\"

Ces fonctions se trouvent dans le module ysystemex.dhop.
