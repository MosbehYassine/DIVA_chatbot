SearchIndex   Famille  Thème

La fonction SearchIndex permet de commander les indexations dans la base Search.

Les applications utilisent de préférence les fonctions SearchCreateDocument, SearchModifyDocument et SearchDeleteDocument.

 

Long  SearchIndex ( Id , Commande, [ Dictionnaire ] , [ Référence ] , [ IdentDocument ] )

 

Paramètres

Id

Identifiant de la connexion.

 

Commande

Action à effectuer.

define SEARCH_INDEX_ALL        = 0   ; réindexer toute la base

define SEARCH_INDEX_ALL_ERASE  = 1   ; effacer tout et indexer tout

define SEARCH_INDEX_DICTIONARY = 2   ; réindexer tous les documents d'un dictionnaire de documents

define SEARCH_INDEX_REFERENCE  = 3   ; réindexer une référence de document (tous les événements par exemple)

define SEARCH_INDEX_DOCUMENT   = 4   ; indexer un nouveau document

define SEARCH_DELETE_DOCUMENT  = 5   ; supprimer un document

define SEARCH_MODIFY_DOCUMENT  = 6   ; modifier un document

define SEARCH_READ_FILE_PARAMS = 7   ; relecture du fichier paramètres

define SEARCH_DELETE_REFERENCE = 8   ; suppression d'une référence de document

 

Dictionnaire

Nom du dictionnaire de documents

 

Référence

Nom du document dans le dictionnaire de documents

 

IdentDocument

Identifiant du document.

 

 

Retour

0

La fonction retourne toujours 0

 

Remarque

  • Les opérations ne sont pas effectuées en temps réel. Les ordres sont envoyés au serveur Search qui les place dans la file d'attente des indexations à réaliser.
