WinFindFirstFile  Famille Thème

 

La fonction WinFindFirstFile recherche les caractéristiques d'un fichier spécifié.

Cette fonction ne peut pas être utilisée en réseau Xlan. Pour cela voir : DirOpen.

 

Long WinFindFirstFile (Nom, Résultat)

 

Paramètres

Nom

Nom du fichier ou d'un répertoire qui peut contenir les caractères génériques (* et ?).

Résultat

Donnée de 400 octets qui reçoit le résultat de la recherche.

1 Bufdir 400

2 Attributs L 

2 HeureCreation 8 

2 HeureAcces 8 

2 HeureEcriture 8 

2 TaillePoidsForts L 

2 TaillePoidsFaibles L 

2 f1 L 

2 f2 L 

2 Nom 260 

2 NomCourt 14 

 

Attributs

Précise les attributs du fichier trouvé. Ce champ est une combinaison des valeurs suivantes :

FILE_ATTRIBUTE_ARCHIVE 

Le fichier est un fichier d'archive. Les applications utilisent cette valeur pour les sauvegardes ou les épurations.

FILE_ATTRIBUTE_COMPRESSED

Le fichier ou le répertoire est compressé. Pour un fichier, cela signifie que les données sont compressées. Pour un répertoire, cela signifie que les fichiers sont créés par défaut avec l'option.

FILE_ATTRIBUTE_DIRECTORY

Le fichier est un répertoire.

FILE_ATTRIBUTE_HIDDEN 

Le fichier est caché. Il n'est pas affiché lors d'une liste normale du répertoire.

FILE_ATTRIBUTE_NORMAL 

Le fichier n'a pas d'autres attributs.

FILE_ATTRIBUTE_READONLY

Le fichier est en lecture seule. Les applications ne peuvent pas écrire dans ce fichier ou le supprimer.

FILE_ATTRIBUTE_SYSTEM 

Ce fichier fait partie du système d'exploitation ou est utilisé exclusivement par ce dernier.

FILE_ATTRIBUTE_TEMPORARY

Ce fichier est temporaire.

 

HeureCreation

Indique la date et l'heure de la création du fichier. Pour convertir cette heure, utilisez la fonction WinConvertFileTime.

HeureAcces

Indique la date et l'heure du dernier accès au fichier. Pour convertir cette heure, utilisez la fonction WinConvertFileTime.

HeureEcriture

Indique la date et l'heure de la dernière modification du fichier. Pour convertir cette heure, utilisez la fonction WinConvertFileTime.

TaillePoidsForts

Spécifie les poids forts de la taille du fichier. La taille d'un fichier est un nombre sur 64 bits.

TaillePoidsFaibles

Spécifie les poids faibles de la taille du fichier. La taille d'un fichier est un nombre sur 64 bits.

Nom

Cette zone contient le nom du fichier.

NomCourt

Nom court du fichier. Ce nom à la forme classique 8.3 (nom.extension) des noms de fichiers Ms-dos.

 
 

Retour

-1

Erreur. Appelez la fonction WinGetLastError pour connaître le détail de l'erreur.

Autre

Ticket. Ce ticket (handle) est utilisé pour les appels suivants à WinFindNextFile ou WinFindClose.

 

Remarque

La fonction WinFindFirstFile ouvre un ticket (handle) de recherche et retourne les informations du premier fichier trouvé. Après cette première recherche, vous pouvez utiliser la fonction WinFindNextFile pour chercher les autres fichiers qui répondent à votre critère de recherche. Quand votre recherche est terminée, fermez votre ticket par la fonction WinFindClose.

 

Exemple

Ce programme affiche le nom des fichiers d'un répertoire et de tous ses sous-répertoires. La procédure AfficheDirectorie est récursive ; lorsqu'elle rencontre un sous-répertoire, elle se rappelle elle-même pour explorer le sous-répertoire.

1 Bufdir 400 ; zone réceptrice

 2 Attributs L 

 2 HeureCreation 8 

 2 HeureAcces 8 

 2 HeureEcriture 8 

 2 TaillePoidsForts L 

 2 TaillePoidsFaibles L 

 2 f1 L 

 2 f2 L 

 2 Nom 260 

 2 NomCourt 14 

 

;-----------------------------------------------

;Procédure récursive qui affiche le nom et la

;date de dernière modification d'un fichier

;-----------------------------------------------

procedure AfficheDirectorie(nombase)

1 nombase A

1 hdir L

beginp

; lecture du premier fichier 

   hdir = WinFindFirstFile(nombase, Bufdir) 

   if hdir = -1 

      preturn 

   endif 

; si répertoire, appel récursif 

; sinon affichage du nom 

   Repeat 

      display left(nom) & " " & WinConvertFileTime(HeureEcriture) 

      if band(Attributs, FILE_ATTRIBUTE_DIRECTORY) \ 

         and Nom <> "." and Nom <> ".." 

         AfficheDirectorie(left(nombase, length(nombase)-2) \  

                    & "/" & left(nom) & "/*") 

      endif 

   Until WinFindNextFile(hdir, Bufdir) = FALSE 

   ; fermeture du répertoire  

   WinFindClose(hdir) 

endp

 

main

 

1 rep 50

Input "Répertoire à afficher " rep 

AfficheDirectorie(left(rep) & "/*") 

ProgramExit
