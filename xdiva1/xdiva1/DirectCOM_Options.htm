DirectCOM_Options Famille Thème

 

DirectCOM_Options permet de positionner des options supplémentaires afin d'affiner le dialogue avec le port COM.

 

char DirectCOM_Options (option, valeur)

 

Paramètres

 

option

Numérique (3,0)

Code de l'option

valeur

Numérique (6,0)

Valeur de l'option

 

 

Retour

 

En cas de succès la fonction retourne "1". Un message d'erreur est renvoyé en cas d'erreur.

 

 

Liste des options valides

 

Code de l'option

Description

Valeur de l'option

1

Mode de débogage

1 pour activer

2

Taille du buffer de lecture interne à la dll. Ce buffer conserve les informations arrivant sur le port COM jusqu'à lecture par la fonction DirectCOM_Read ou jusqu'à sa saturation.

par défaut le buffer fait 256ko.

Pour changer cette valeur, il faut indiquer le nombre d'unité de mémoire que l'on souhaite affecter au buffer, l'unité de mémoire choisie valant 4ko (4096 octets).

Exemple : pour un buffer de 512ko, il faut indiquer 512/4 = 128 dans la valeur de l'option.

3

Règle de traitement d'un buffer de lecture plein.

1 : valeur par défaut, le buffer fonctionne en mode circulaire (les octets supplémentaires remplacent les premiers octets reçus)

0 : une fois le buffer plein les nouveaux octets sont ignorés.

4

usage interne réservé.

 

5

Timeout de l'API Windows de lecture des voies séries.

Cette API a un Timeout de 500 ms par défaut (propriété SerialPort.ReadTimeout, cf. documentation Microsoft) si la voie série ne répond pas.

Timeout en millisecondes.

6

Timeout de l'API Windows d'écriture sur les voies séries.

Cette API a un Timeout de 500 ms par défaut (propriété SerialPort.WriteTimeout, cf. documentation Microsoft) si la voie série ne répond pas.

Timeout en millisecondes.

 

7

usage interne réservé.

 

8

Taille du buffer propre de l'API Windows de lecture des voies séries..

Cette API dispose d'un buffer propre de 4096 octets (propriété SerialPort.ReadBufferSize, cf. documentation Microsoft).

En temps normal, ce buffer n'est pas sollicité puisque la dll de Harmony récupère les octets à lire sur la voie de manière continue (sur un thread dédié) alimentant son buffer interne de 256k maximum. Cette option ne devrait donc être utile que dans des cas rares et très spécifiques.

taille du buffer en octets.

9

Taille du buffer propre de l'API Windows d'écriture sur les voies séries..

Cette API dispose d'un buffer propre de 2048 octets (propriété SerialPort.WriteBufferSize, cf. documentation Microsoft).

La fonction DirectCOM_Write permet d'écrire plus de 2048 octets en une fois. Cela signifie que cette fonction envoie les données sur la voie en paquets dont la taille maximum vaut cette valeur.

taille du buffer en octets.

10

Time out interne de la dll. Lorsque la fonction DirectCOM_Read est utilisée avec un timeout (voire DirectCOM_SetReadOptions), la dll interroge le buffer de lecture périodiquement jusqu'à la fin du timeout principal (celui réglé par la fonction DirectCOM_SetReadOptions), puis se met en sommeil pour la durée de ce timeout interne. Cette option permet, par exemple, d'augmenter le timeout interne pour alléger la charge du poste client.

valeur en millisecondes du timeout interne. 50 millisecondes par défaut.
