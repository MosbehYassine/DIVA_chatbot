DVBufferGetId   Famille  Thème

La fonction DVBufferGetId permet de créer un nouveau DVBuffer.

Ce DVBuffer peut être créé vide, ou peut être créé à partir d'une chaîne de caractères (c'est le cas lorsque le DVBuffer a été lu sur un socket).

 

Long  DVBufferGetId  ( [ taille ] , [ chaine ] )

 

Paramètres

Taille

Unité d'allocation du DVBuffer. A chaque fois que le DVBuffer doit s'agrandir, sa taille est incrémentée de cette valeur.

Si vous savez à l'avance que vous allez écrire une grande quantité de données, mettez une grande valeur.

La valeur par défaut est de 8 Ko.

 

Chaine

Variable alphanumérique au format DVBuffer. Cela permet d'initialiser un DVBuffer avec des données lues sur le réseau ou depuis un fichier.

 

Retour

La fonction retourne un identifiant de DVBuffer. Cet identifiant est passé en paramètre aux fonctions DVBuffer.
