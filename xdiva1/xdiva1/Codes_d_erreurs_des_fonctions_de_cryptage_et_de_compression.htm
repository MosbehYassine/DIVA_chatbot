Codes d'erreurs des fonctions de cryptage et de compression

 

Codes d’erreur des fonctions de compression et de cryptage.
Ces codes peuvent être retournés par les fonctions FileCompress, FileUnCompress, FileCrypt, FileUncrypt.

0x1901

Erreur d'allocation de mémoire.

0x1902

Erreur d'ouverture du fichier décompressé (voir le code d'erreur système).

0x1903

Erreur de création de la destination (voir le code d'erreur système).

0x1904

Erreur d'ouverture du fichier compressé (voir le code d'erreur système).

0x1905

Erreur lors de l'effacement du fichier destination (voir le code d'erreur système).

0x1906

Le fichier n'est pas un fichier comprimé.

0x1907

Erreur d'écriture (voir le code d'erreur système).

0x1908

Erreur de lecture (voir le code d'erreur système).

0x1909

Erreur lors de la fermeture d'un fichier (voir le code d'erreur système).

0x190A

Erreur lors de l'appel de la fonction stat sur le fichier de départ (voir le code d'erreur système).

0x190B

Le fichier de départ est le même que le fichier d'arrivée.

 

Codes d’erreurs des fonctions de cryptage
Ces codes peuvent être retournés par les fonction FileCrypt, FileUncrypt, Crypt, Uncrypt

0x190C
0x1916

Erreur à l'ouverture ou du chargement du Service de Cryptographie de Windows.

 

0x190D

Erreur à l'ouverture du Service de création de clé du Service de Cryptographie de windows

0x190E
0x190F

Erreur lors de la génération de la clé de cryptage.

 

0x1910
0x1915

Plus de mémoire disponible.

0x1911

Erreur lors de l'encryptage.

0x1912

Erreur lors du décryptage.

0x1913

 

Lors du décryptage, la clé est fausse, elle ne correspond à celle utilisée lors du cryptage.

 

0x1917

Le processus courant n’a pas les droits pour utiliser le Service de Cryptographie de Windows
