L'instruction Gosub permet d'appeler un sous programme.

 return

Etiquette est une chaîne de caractères précédée du mot clé Label.

L'étiquette peut se trouver dans le programme avant ou après son utilisation. Si une étiquette n'est pas définie, le compilateur sort un message d'erreur en fin de compilation.

Les étiquettes sont locales à l'intérieur des fonctions et des procédures. Il n'est donc pas possible d'appeler un sous-programme par Gosub si ce sous programme ne se trouve pas dans la fonction en cours.

Après l'instruction Return le contrôle est donné à l'instruction suivant l'instruction Gosub.

Il est plus intéressant d'utiliser une Fonction ou une Procédure.
