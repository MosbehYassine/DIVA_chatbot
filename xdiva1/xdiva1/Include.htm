Include

La pseudo instruction Include permet d'insérer un fichier source. Elle doit être la seule instruction de la ligne.
Si le fichier a une extension, celle-ci doit obligatoirement être précisée.
 

Include nom_de_fichier
 

Paramètres

Nom_de_fichier

Nom du fichier source à inclure.

Exemple :
 Include "zcpp950.dhsp"
