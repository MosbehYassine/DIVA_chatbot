Fdelete  Famille Thème

 

Fdelete supprime le dernier enregistrement lu.
Cette fonction ne peut être appelée qu'après une lecture (fonctions Fread, Fpread, Fseek2) effectuée généralement en mode réservé.

La suppression d'un enregistrement n'est possible qu'avec les fichiers de type séquentiel-indexé (I) dont le fichier des données est de type N.

 

Ptr = fdelete ( tdf , variable )

Paramètres

Tdf

Table de définition de fichier.

Variable

Dernier enregistrement lu.

 

Retour

0  

Pas d'erreur. 

$1D

Pas de lecture préalable dans le fichier 

autres

Code d'erreur système. 

 

Remarques

Le système supprime l'enregistrement et ses clés.

Attention : Le système ne récupère pas la place dans le fichier des données. Pour récupérer la place des enregistrements supprimés, il faut utiliser l'utilitaire Xreof.

 

Exemples

;________________________________________________________________
; Fonction : F_DELETE

; Type : int

; Description : Supprime l'article art dans le fichier tdf

; Paramètres en sortie : 0 = ok # = erreur

;________________________________________________________________
;

Function int F_DELETE (&tdf , &art)

Record * htdf tdf ;table de définition

1 art A ;article

beginf

cr = fdelete (tdf,art) 

switch cr 

case 0 ;ok 

   freturn (0) 

default ;erreur système 

   MessageBox("Erreur système numéro " & binhexa (stx (cr)) & \ 

              " en suppression dans le fichier " & \

              left(tdf.name)," ") 

endswitch 

freturn(cr) 

endf

 

Suppression de l'enregistrement client. L'enregistrement a été lu au préalable en mode P ou F dans la donnée client.

; Validation de la suppression 

; relecture en mode réservé 

st = fseek2(fcli , wcli , 'R');

switch st

case 0 ; lecture OK

   stdel = f_delete(fcli , client) 

case H_RESERVED ; enreg. réservé

   MessageBox("Enregistrement réservé"," ") 

case H_RECORD_NOT_FOUND ; enregistrement supprimé

   MessageBox("Le client " & client.codcli & \ 

              "n'existe plus"," ") 

endswitch

fpclose (fcli)
