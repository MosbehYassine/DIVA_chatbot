ReceiveProgramMessage Famille Thème

 

La fonction ReceiveProgramMessage permet de lire les messages qui ont été déposés par SendProgramMessage.

Une fois que les messages sont lus, ils sont effacés.

 

int ReceiveProgramMessage ( &liste )

Paramètre

Liste

Donnée numérique qui va recevoir un identifiant de liste. Cette liste contient les différents messages.

Si liste est un descripteur de liste valide c'est cette liste qui va être utilisée.

 

Retour

0

Pas d'erreur

Autre

Erreur système.


Exemple

 

; envoi de deux messages à tout le monde

sendprogrammessage("message1","")

sendprogrammessage("message2","")

 

; lecture des messages

ReceiveProgramMessage(liste)  ; --> 2 éléments dans la liste

ReceiveProgramMessage(liste)  ; --> liste vide
