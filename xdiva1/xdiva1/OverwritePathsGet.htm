OverwritePathsGet  Famille Thème

 

La fonction OverwritePathsGet renvoie une liste contenant le fichier owerwrite.txt actuellement chargé.

 

Int = OverwritePathsGet

 

Retour

La fonction retourne un identifiant de liste. Cette liste devra être ultérieurement détruite par ListDestroy.

Chaque élément de la liste est décomposé comme suit :

; structure des implicites add-on utilisée par OverwritePathsGet

structure uneImpliciteAddOn

1  Type  B          ;voir ADDONIMPLI_TYPE

1  IsAddon B        ;1=je suis un addOn   0=je ne suis pas un add-on mais j'ai écrit une surcharge sur les add-on

1  Nom 256

1  CheminRelatif 256

1  CheminComplet 256

endstructure

define ADDONIMPLI_TYPE_SOURCE = 1

define ADDONIMPLI_TYPE_OBJET  = 2

define ADDONIMPLI_TYPE_PATH_DHOS  = 3
