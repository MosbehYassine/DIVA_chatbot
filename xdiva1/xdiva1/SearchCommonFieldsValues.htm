SearchCommonFieldsValues   Famille  Thème

La fonction SearchCommonFieldsValues permet d'obtenir la liste des valeurs possibles pour un champ.

 

Long  SearchCommonFieldsValues ( Id , Dictionnaire , Document , Variable, &DvBuffer)

 

Paramètres

Id

Identifiant de la connexion.

 

Dictionnaire

Nom du dictionnaire de documents (paramètre inutilisé)

 

Document

Nom du document dans le dictionnaire de documents (paramètre inutilisé)

 

Variable

Nom du champ dans la base Search

 

DVBuffer

Identifiant d'un DvBuffer contenant la réponse du serveur. Le contenu de ce DVBuffer n'est pas documenté.

 

 

Retour

0

Pas d'erreur

1

Erreur dans la base Search.
