XharviewSetOption  Famille  Thème

La fonction XharviewSetOption permet de ‘piloter’ le programme Xharview, c’est à dire de modifier l’enchaînement habituel des opérations.

Ptr XharviewSetOption (option)

 

Paramètre

Option

0 

Mode normal. Xharview est lancé mais c'est l'utilisateur qui choisi d'envoyer ou non l'édition

1 

L’entrée dans Xharview se fait directement par la boîte de dialogue "Envoyer vers..."

2 

L’entrée dans Xharview se fait directement par la boîte de dialogue "Envoyer vers..." mais avec le positionnement des drapeaux "Avec la boîte de dialogue de Exchange"

3 

L’entrée dans Xharview se fait directement dans la boîte de Exchange ou de Fotowin

4 

Le message est envoyé directement sans aucune intervention de l'utilisateur. Si l’instruction XharviewWriteWithPrint est appelée, l'édition s'imprime et le message est envoyé immédiatement

5

Simple positionnement des drapeaux "Avec la boîte de dialogue de Exchange"

Identique au mode 0. Xharview est lancé mais c'est l'utilisateur qui choisi d'envoyer ou non l'édition, mais si l’utilisateur appelle la boîte de dialogue "Envoyer vers...", celle-ci s'ouvre avec  le positionnement des drapeaux "Avec la boîte de dialogue de Exchange"
