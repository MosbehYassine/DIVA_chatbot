ZipArchiveExtractToDirectory Famille Thème

 

Extraction de l'ensemble des fichiers de l'archive zip dans un répertoire

 

Bool ZipArchiveExtractToDirectory( ZipArchivePath, ExtractionDirectory, [ZipPassword] )

 

Paramètres

ZipArchivePath

Chemin vers l'archive zip

ExtractionDirectory

Chemin vers le répertoire où extraire l'archive

ZipPassword

Mot de passe pour les fichiers chiffrés dans l'archive zip

 

Retour

La fonction renvoie 1 en cas de succès, 0 sinon. Pour avoir plus d'informations sur l'erreur en cas d'échec, utiliser la fonction ZipArchiveGetLastErrorCode()

 

Remarques

Si le fichier n'existe pas, il est crée. S'il existe, son contenu est écrasé.

Le nom peut contenir le chemin complet vers le fichier, le chemin relatif ou juste le nom du fichier.

 

Exemple

; Extraction de l'archive test.zip dans le répertoire 'testDirectory'

 retVal = ZipArchiveExtractToDirectory("C:/tmp/test.zip", "C:/tmp/'testDirectory'")
