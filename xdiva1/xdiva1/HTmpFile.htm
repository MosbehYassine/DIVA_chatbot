HTmpFile

HTmpFile permet de déclarer un fichier temporaire. Le format du fichier temporaire (type, description des clés) est pris dans le dictionnaire.

[public | protected] HTmpFile dico mnémo vartdf [NoOpen] [OpenOnUse][DeleteOnExit]

Public

Spécifie que la variable Vartdf est publique. Si plusieurs modules déclarent la même variable publique, elle est allouée une seule fois à l'exécution.

Protected

Spécifie que la variable Vartdf est protégée. Une nouvelle instance de Vartdf est allouée.

Dico

Nom du dictionnaire de données.

Mnémo

Nom du fichier défini dans le dictionnaire.

Vartdf

Variable qui identifie la Tdf

Noopen

Par défaut, le fichier est ouvert automatiquement avec un nom aléatoire lors du chargement du module ou lors de l'entrée dans la fonction/procédure.

Noopen indique que le fichier ne doit pas être créé par le système. Cette option est utilisée dans le cas d'enchaînement de programmes. Le premier programme crée et rempli le fichier qui doit être exploité par un autre programme. Le premier programme doit donc passer le nom du fichier temporaire (via le tunnel) et le second doit ouvrir le fichier "à la main".

Le chemin des fichiers temporaire est défini par la variable d’environnement TEMP. Il peut également être paramétré dans Divalto.ini (avec l'utilitaire xDivaltoMajIni), chapitre [system] entrée pathtemp.

OPENONUSE permet de différer la création, dans ce cas le fichier est créé lors de sa première utilisation.

NOOPEN permet également de différer la création. Dans ce cas, la création se fait par la fonction TmpFcreate.

Openonuse

Indique que le fichier ne doit pas être créé lors du chargement du module mais lors de la première utilisation de la Tdf.

DeleteOnExit

Si DeleteOnExit est précisé, le fichier doit être automatiquement détruit à la fin du programme. Si le fichier est déclaré avec les options NoOpen et DeleteOnExit, le fichier, dont le nom se trouve dans la Tdf à la fin du programme, est détruit. Le fichier peut être fermé puis ouvert à nouveau, la suppression se faisant à la fin du programme ou à la fin de la fonction/procédure.
