WinPathUnExpandEnvStrings  Famille Thème

 

La fonction WinPathUnExpandEnvStrings prend un nom complet de fichier et replace le chemin par une variable d'environnement.

Par exemple :   'C:\Documents and Settings\bhouver.DIVALTO\fichier'    -->  '%USERPROFILE%\fichier'

Cette fonction se trouve dans le module ysystemex.dhop.

 

 

BOOL  WinPathUnExpandEnvStrings (entree , retour)

 

Paramètres

Entree

Chaîne de caractères contenant un nom de fichier complet.

Retour

Chaîne de caractères en sortie après remplacement du chemin par une variable d'environnement.

Si aucune substitution ne peut être faite, Retour contient le nom du fichier passé dans Entree.

Les répertoires traités par la fonction sont :

%USERPROFILE%

%ALLUSERSPROFILE%

%ProgramFiles%

%SystemRoot%

%SystemDrive%

 

Retour

TRUE

La fonction a effectué un remplacement

FALSE

La fonction n'a pas effectué de remplacement

 

Exemples

1 unexpand 200

WinPathUnExpandEnvStrings( 'C:\Documents and Settings\bhouver.DIVALTO\fichier',unexpand)

; unexpand --> '%USERPROFILE%\fichier'
