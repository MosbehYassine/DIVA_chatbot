TranslateComboText Famille Thème

La fonction TranslateComboText permet de récupérer la traduction d'un choix dans un dictionnaire de multi-choix.

 

Alpha TranslateComboText (DictionnaireMC, Entree, Chaine, [ Dictionnaire] , [ EcranImp ] , [ CodeLangueBase] )

 

Paramètres

DictionnaireMC

Nom du dictionnaire de multi-choix.

 

Entree

Entrée dans le dictionnaire de multi-choix.

 

Chaine

Chaîne à traduire. Il s'agit du texte correspondant au choix.

 

Dictionnaire

Dictionnaire de traduction. Il s'agit d'une entrée dans le fichier paramètre des langues.
Valeur par défaut : Divalto.

 

EcranImp

1

Utiliser le code langue d'affichage

2

Utiliser le code langue d'impression

 

 

CodeLangueBase

Code langue du dictionnaire des multi-choix. Si ce code est le même que celui de la langue courante, il n'y a pas de traduction à faire.

Valeur par défaut : FR.
