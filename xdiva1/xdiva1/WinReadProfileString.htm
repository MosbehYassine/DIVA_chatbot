WinReadProfileString  Famille Thème

 

La fonction WinReadProfileString permet de lire une chaîne de caractères dans un fichier .ini.

Attention, le fichier divalto.ini est géré de manière particulière. Voir le chapitre divalto.ini de la documentation Installation et paramétrage d'Harmony.

  

Alpha WinReadProfileString (section, entrée, fichier)

 

Paramètres

Section

Nom de la section du fichier .ini. Dans un fichier .ini, une section est un mot encadré par les crochets [ ]. Ne pas mettre les crochets dans ce paramètre.

Entrée

Entrée (ou mot-clé) dans la section.

Fichier

Nom du fichier .ini.

 

Retour

La fonction renvoie la valeur trouvée ou espaces si l'entrée n'existe pas.

  

Exemple

display WinReadProfileString("System","ServeurXlogf","monfichier.ini")

; recherche de ServeurXlogf=xxxxx dans la section system du fichier

; monfichier.ini
