Define

La pseudo instruction Define permet de substituer dans le texte source un mot par une expression.

Syntaxe 1 : Define nom [ (p1,p2,…pn) ] = [ expression ]

Syntaxe 2 : Define nom [ (p1,p2,…pn) ] : [ expression ]

 

Paramètres

Nom

Chaîne à substituer dans le texte. Le nom doit être suivi de = ou : (voir Remarques)

P1…pn

Paramètres de l'expression. Si un ou plusieurs paramètres sont spécifiés, l'expression correspond à une macro. Lors de la substitution, les paramètres de l'expression sont remplacés par les paramètres d'appel.

Expression

Expression qui remplace nom lors de la compilation. S'il y a des paramètres dans l'expression, il est conseillé de les entourer de parenthèses.

Il ne peut y avoir qu'une seule instruction Define par ligne. La chaîne qui suit le signe égal jusqu'à la fin de la ligne ou au début des commentaires est considéré comme étant la chaîne pour le remplacement.

Les Define qui sont déclarés à l'intérieur des fonctions ou des procédures sont locaux, c'est-à-dire qu'ils ne peuvent être utilisés en dehors de la fonction ou de la procédure. La règle est la même que pour les variables.

Un Define ne peut pas avoir le même nom qu'un champ d'un enregistrement. Si c'est le cas, utilisez la Const.

 

Remarques

Si le define a des paramètres et que le nom est suivi du caractère =, les paramètres sont obligatoires lors de l'utilisation du Define.

Par contre, si le nom du Define est suivi de : les paramètres sont facultatifs. Cela permet d'utiliser Define pour appeler des fonctions tout en gardant la possibilité d'avoir des paramètres facultatifs.

 

Exemples

Définition de constantes :

define SW_HIDE = 0
define SW_SHOWNORMAL = 1
define SW_NORMAL = 1

Définition de macro :

define jour(d) = (nmid((d),7,2,0))

Ce Define permet d'accéder au jour d'une date. L'intérêt du Define par rapport à une fonction est qu'il est possible de l'utiliser à gauche d'une affectation. Par exemple : jour(daten) = 1.


Paramètres facultatifs

Procedure pabc(aa,bb,cc)

1 aa a = "A"

1 bb a = "B"

1 cc a = "C"

Record ddsys.dhsd eimp

beginp

endp

 

main    

 

define mondef0 : pabc("a")

define mondef(aa,bb,cc) : pabc(aa,bb,cc)

 

; toutes ces écritures sont valides

mondef0

mondef()  

mondef("aaa")  

mondef("aaa","bbb")  

mondef(aa="toto",bb="titi",cc="tata") ; les noms des paramètres sont ceux de la fonction

mondef(cc="ccccc",bb="bbbb",aa="aaaa")

mondef("aaaaa",,"ccccc")

mondef(,"bbbb","ccccc")
