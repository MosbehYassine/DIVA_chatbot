JsonGetError Famille Thème

 

La plupart des fonctions JSON retournent la valeur 2 en cas d'erreur. JsonGetError permet de récupérer le détail de l'erreur.

 

Int JsonGetError  ( Ticket , &MessageErreur, &Exception )

 

Paramètres

Ticket

Ticket préalablement obtenu par JsonOpen.

 

MessageErreur

Message d'erreur produit par Harmony.

 

Exception

Texte de l'exception produit par la couche .Net.

 
 

Retour

0

Pas d'erreur

1

Ticket incorrect

 

Exemple

procedure TraiterErreurJson(ticket,st)

1 st L

1 merr S

1 mexcept S

1 ticket L

beginp

   switch st

   case 1

      MessageBox("ticket inconnu"," ")

   case 2

      JsonGetError(ticket,merr,mexcept)

      MessageBox(mexcept,merr)

   case 3

       MessageBox("Erreur de syntaxe dans l'expression","")

   endswitch

endp
