Fmodstat  Famille Thème

 

Fmodstat permet de modifier les caractéristiques d'un fichier non ouvert.


Ptr = Fmodstat (nom, hstat, opération)

 
Paramètres

Nom

Nom complet du fichier.

Hstat

Instance de l'enregistrement HStat du dictionnaire ddsys.dhsd qui contient les nouvelles valeurs.

Opération

Combinaison de valeurs indiquant les caractéristiques à modifier.

Les valeurs possibles sont :

Opération

Champ de Hstat à garnir

Commentaire

STAT_CHANGE_TYPE

Type

Changement du type

STAT_CHANGE_NATURE

Nat

Changement de la nature

STAT_CHANGE_PROTECTION

Protect

Changement de la protection

STAT_CHANGE_LOCK

Locki

Changement du drapeau indiquant une incohérence entre les clés et les données d'un séquentiel-indexé.

STAT_CHANGE_UREAD

Uread

Confidentialité en écriture

STAT_CHANGE_UWRITE

Uwrite

Confidentialité en écriture

STAT_CHANGE_UERASE

Uerase

Confidentialité pour l'effacement

STAT_CHANGE_LGE

Lge

Taille des enregistrements

STAT_CHANGE_VERSION

Version

Version du fichier.

STAT_CHANGE_ATTRIBUTES

ReadOnly

Farchive

Fhidden

Fsystem

Tous les attributs Windows sont modifiés en même temps. Il est donc conseillé de lire les attributs avant de faire une modification.

STAT_CHANGE_DICO

DicoNom

DicoMnemo

Le nom du dictionnaire et le mnémonique du fichier dans le dictionnaire.

STAT_CHANGE_CTRLREL

CtrlRel

Drapeau (1/0) positionnant l'option "Toujours contrôler la version".

 

 

 

Retour

0

Pas d'erreur.

Autres

Code d'erreur système


Remarque

Le fonction SetFileTime permet de modifier les dates et heures de création, d'accès et de modification d'un fichier.
