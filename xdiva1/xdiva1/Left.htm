Left  Famille 

 

La fonction Left permet d'extraire la partie gauche d'une chaîne de caractères. Elle peut se trouver à gauche dans une affectation.

 

Char Left ( variable , [ longueur ] )

 

Paramètres

Variable

Le type de la variable est quelconque.

Longueur

Valeur numérique indiquant le nombre de caractères de la chaîne résultat. Ce paramètre est facultatif. S'il n'est pas précisé, la longueur correspond à la taille de variable sans compter les espaces et les caractères $00 de fin.
Left(var) est donc équivalent à Left(var, length(var)).

 

Retour

La fonction retourne la partie gauche de la chaîne de caractères. Le type de retour est toujours alphanumérique.

 

Exemples

Display left("Bonjour",3)

affiche Bon

 

Left(nom, 3) = "ABC"

; place les caractères ABC dans les trois premiers caractères de la

; donnée nom.

 

1 nom 30
nom = "Dupont"

Display '!' & left(nom) & '!'

; affiche !Dupont!
