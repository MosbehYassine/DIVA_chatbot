DirectCOM_Write Famille Thème

 

Ecrit sur le port COM désigné par le canal passé en premier paramètre le contenu du buffer (deuxième paramètre).

Si le flag "clear" (4è paramètre) est positionné à 1, la fonction d'écriture effacera le contenu du buffer du port avant d'y écrire les données (pour que les données écrites sur le port par la fonction DirectCOM_Write ne soient pas polluées par des données pré-existantes).

 

int DirectCOM_Write (canal, &buffer, lg, clear)

 

 

Paramètres

 

canal

Numérique (3,0)

numéro de canal renvoyé par la fonction DirectCOM_Open.

buffer

Alphanumérique

buffer d'écriture.

lg

Numérique (5,0)

taille du buffer en octet.

clear

Numérique (1,0)

flag indiquant si le buffer du port doit être vidé avant d'écrire les données. Ce flag vaut 0 par défaut.

 

 

Retour

 

La fonction retourne le nombre d'octets écrits en cas de succès, et 0 si une erreur s'est produite.
