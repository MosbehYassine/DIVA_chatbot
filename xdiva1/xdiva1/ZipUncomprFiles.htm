ZipUncomprFiles  Famille Thème

Cette fonction fait partie du module dhzip

ZipUncomprFiles permet de décompresser un fichier

 

Int ZipUncomprFiles (file1, file2, entete)

 

Paramètres

File1

Nom windows du fichier à décompresser

 

File2

Nom windows du fichier résultat. Attention ce fichier doit préalablement exister.

 

Entete

Boolen indiquant si le fichier comporte l'entête de reconnaissance des fichiers Zip (TRUE par défaut)

 

Retour

0 pas d'erreur
Autre erreur
