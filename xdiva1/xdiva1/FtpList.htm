FtpList Famille Thème

 

Récupérer la liste des fichiers d'un répertoire du serveur.

 

Module "yftp.dhop"

FtpResult FtpList (server, login, password, directory, &hmpRetour, [proxyServer], [ProxyMode], [proxyLogin], [proxyPassword])

 

Paramètres

Server

Adresse du serveur sous la forme

ftp://ip[:port]  pour un serveur ftp

sftp://ip[:port]  pour un serveur sftp

 

Login

Identifiant sur le serveur. Si non précisé, c'est "anonymous" qui est utilisé. Dans ce cas, le serveur doit accepter les connexions anonymes.

  

Password

Mot de passe sur le serveur.

 

Directory

Chemin du répertoire fichier sur l'ordinateur local.

 

HmpRetour

Chaîne Hmp contenant la liste des fichiers

 

ProxyServer

Adresse du serveur proxy

 

ProxyMode

Mode d'identification sur le proxy.

1

Prendre les paramètres du système. Il n'y a pas d'autre paramètres à préciser, l'authentification est celle du poste de travail.

2

Préciser l'url du serveur, mais authentification SSPI. Inutile de préciser ProxyLogin et ProxyPassword

3

Mode manuel. Il faut préciser tous les paramètres

 

ProxyLogin

Identifiant sur le serveur proxy.

 

ProxyPassword

Mot de passe sur le serveur proxy.

 

Retour

La fonction retourne une structure FtpResult de trois valeurs.

Status

0 = pas d'erreur   2 = Erreur      3 = paramètres incorrects

hmpRetour

Chaîne Hmp contenant la liste des fichiers

Desc

Texte rendu par le serveur ou description de l'exception en cas d'erreur. Voir aussi FtpGetLastErrorMessage

 

Remarques

  • De nombreux serveurs Ftp / Sftp sont sous Unix ou Linux. Sur ces systèmes d'exploitation, les noms de fichiers sont sensibles à la casse.
    Le paramètre Directory doit donc avoir la casse exacte.

  • En fonction de la configuration du serveur, il se peut que les caractères spéciaux et accentués posent problème.

  • En FTP la fonction ne retourne pas la liste des fichiers dans une chaîne HMP. La fonction retourne la liste des fichiers telle qu'elle est rendue par la commande ftp.

Exemple

structure ElementDir

  1 Nom 256

  1 Taille 14,0

  1 DateModif DH

  1 IsDir 1,0

  1 IsRegular 1,0

endstructure

 

1 ListeDir L = ListCreate()

 

Procedure DecodeDirectory(hmp)

1 hmp A

1 cle S

1 valeur S

1 position X = 0

RecordDiva ElementDir elem

beginp

  Loop HmpReadExt(hmp,cle,valeur,position) = 0

    switch cle

    case "NAME"

      elem.Nom = valeur

    case "LENGTH"

      elem.Taille = valeur

    case "LASTWRITETIME"

      elem.DateModif = valeur

    case "ISDIRECTORY"

      elem.IsDir = valeur

    case "ISREGULAR"

      elem.IsRegular = valeur

    case "/ELEMENT"

      ListAddEnd(ListeDir,elem)

      elem = " "

    endswitch

  endloop

endp

 

main

recordDiva yftp.FtpResult  r

1 hmpRet S

 

r = FtpList("sftp://test.rebex.net","demo","password","pub/example",hmpret)

 

DecodeDirectory(hmpret)
