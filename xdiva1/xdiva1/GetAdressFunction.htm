GetAdressFunction  Famille Thème

 

La fonction GetAdressFunction permet d'obtenir l'adresse d'une fonction en vue de son exécution par l'instruction FunctionCall.

 

Long GetAdressFunction ( module , fonction , adresse)

 

Paramètres

Module

Nom du module dans lequel se trouve la fonction. Si module est à espaces, la fonction est recherchée dans le module courant. Ne spécifiez pas de chemin, la fonction l’ignore et ouvre le module suivant les implicites.

Fonction

Nom de la fonction à rechercher.

Adresse

Zone alphanumérique de 16 octets qui recevra l'adresse de la fonction. Cette adresse sera utilisée pour l'appel de la fonction.

 

Retour

0

Pas d'erreur

1

Fonction non trouvée dans le module

2

Module absent

Toutes les autres erreurs provoquent un arrêt du programme en cours.

En retour, la zone Adresse contient l'adresse de la fonction.

 

Exemples

1 adr 16

1 st L

; recherche de l'adresse de la fonction 

; compare dans le module courant

st = GetAdressFunction(" ","compare", adr) 

 

; recherche de l'adresse de la fonction

; VerifierCompte dans le module gtm210

st = GetAdressFunction("gtm210.dhop","VerifierCompte",adr)
