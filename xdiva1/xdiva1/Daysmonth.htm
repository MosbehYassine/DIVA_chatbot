Daysmonth  Famille Thème

 

La fonction Daysmonth calcule le nombre de jours dans le mois.

 

Ptr Daysmonth (date)

 

Paramètres

Date

Donnée de type date.

 

Retour

La fonction retourne le nombre de jours dans le mois.

Exemple

display daysmonth("19900101") ; affiche 31
