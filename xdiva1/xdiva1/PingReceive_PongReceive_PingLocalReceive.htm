PingReceive - PongReceive - PingLocalReceive  Famille Thème

 

Les fonctions PingReceive, PongReceive, PingLocalReceive permettent de lire une donnée dans un tunnel. La donnée lue n’est pas retirée du tunnel, elle peut donc être relue ultérieurement.

Long PingReceive ( libellé , donnée)

Paramètres

Libellé

Chaîne de caractères identifiant la donnée a lire dans le tunnel.

Donnée

Donnée dans laquelle est affectée la valeur lue dans le tunnel. Si le libellé n'est pas trouvé dans le tunnel, donnée est mise à espaces.


Retour

0 si la donnée a été trouvée dans le tunnel, 1 sinon.
