DDInterface : Fichiers  Famille  Thème

Les commandes de lecture de fichiers renvoient les valeurs suivantes :

Pour le niveau 1 :

Nom

Nom du champ en majuscules.

NomSaisi

Nom avec minuscules et majuscules.

Libelle

Commentaire.

TypeFichier

Type du fichier
1 = Séquentiel-indexé
3 = Normal
4 = Type U

NomFichier

Nom du fichier physique.

VersionFichier

Version du fichier.

LgTable

Taille des enregistrements (0 = taille variable)

SansRepriseDonnee

1 si le fichier n’est pas concerné par les moulinettes de changement de version.

 

Pour le niveau 2 :

DateCreation

Date de création de l’élément.

UtilisateurCreation

Utilisateur qui a créé l’élément.

DateModif

Date de dernière modification de l’élément.

UtilisateurModif

Utilisateur qui a effectué la dernière modification.

NumeroCommentaire

Numéro de commentaire général dans le fichier des commentaires.

 

Exemple

 

1 Dico_Nom                    32

1 Dico_NomSaisi               32

1 Dico_Libelle                80

1 Dico_DateCreation           8

1 Dico_UtilisateurCreation    20

1 Dico_DateModif              8

1 Dico_UtilisateurModif       20

1 Dico_NumeroCommentaire      6,0

1 Dico_NumeroCommentaireLocal 6,0

1 Dico_TypeFichier            3,0 ;type du fichier

1 Dico_LgTable                6,0 ;taille des enregistrements

1 Dico_NomFichier             260 ;nom du fichier reel

1 Dico_VersionFichier         4 ;version du fichier

1 Dico_SansRepriseDonnee      b ;sans reprise des données true / false

 

1 reponse  4096

 

procedure DecodeTypeFichier(type,&texteenclair)

1 type    N

1 texteenclair A

beginp

 switch ( type )

  case 1

   texteenclair = "SI"

  case 3

   texteenclair = "N"

  case 4

   texteenclair = "U"

 endswitch

endp

 

Dico_Nom                  = HmpSeek(reponse,"Nom")

Dico_NomSaisi             = HmpSeek(reponse,"NomSaisi")

Dico_Libelle              = HmpSeek(reponse,"Libelle")

Dico_DateCreation         = HmpSeek(reponse,"DateCreation")

Dico_UtilisateurCreation  = HmpSeek(reponse,"UtilisateurCreation")

Dico_DateModif            = HmpSeek(reponse,"DateModif")

Dico_UtilisateurModif     = HmpSeek(reponse,"UtilisateurModif")

Dico_NumeroCommentaire    = HmpSeek(reponse,"NumeroCommentaire") 

Dico_NumeroCommentaireLocal = HmpSeek(reponse,"NumeroCommentaireLocal")

Dico_TypeFichier            = HmpSeek(reponse,"TypeFichier")

Dico_LgTable                = HmpSeek(reponse,"LgTable")

Dico_NomFichier             = HmpSeek(reponse,"NomFichier")

Dico_VersionFichier         = HmpSeek(reponse,"VersionBase")

Dico_SansRepriseDonnee      = HmpSeek(reponse,"SansRepriseDonnee")
