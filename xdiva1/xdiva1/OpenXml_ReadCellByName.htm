OpenXml_ReadCellByName  Famille  Theme

 

La fonction OpenXml_ReadCellByName lit une cellule nommée par son nom.

 

char OpenXml_ReadCellByName (nom)

 

Paramètre

Nom

Nom de la cellule.

Attention : Si le nom correspond à une plage de cellules, la fonction renvoie uniquement la première cellule.

 

Retour

La fonction retourne le texte contenu dans la cellule ou espace si le nom n’existe pas.

 

Exemple

1 Valeur S

Valeur = OpenXml_ReadCellByName ("mon_nom")     ;lecture de la cellule portant le nom "mon_nom"
