Traitements du dictionnaire associés aux fichiers

 

Définition

Dans le dictionnaire des données, il est possible d'associer des traitements à un couple enregistrement-fichier.

 

Ces traitements pourront être exécutés soit :

  • après une lecture  (Après Read)

  • avant une écriture (avant Write)

  • avant une modification (avant Rewrite)

  • avant une suppression (avant Delete).

Les traitements liés aux fichiers sont exécutés :

  • automatiquement par les fonctions Iread, Iwrite, Irewrite et Idelete

  • par programme en utilisant les fonctions GetAdressProcedureRecord et ProcedureCall. (cas du Zoom par exemple).

Les fonctions Hread etc. et les fonctions Fread etc. n'appellent pas automatiquement les traitements liés aux fichiers.

Attention : L'ERP Divalto n'utilise pas ces fonctionnalités. Seuls les Zoom et les programmes Hql appellent les fonctions liées aux enregistrements.

 

Gestion d'un enregistrement complémentaire

Les traitements associés aux fichiers permettent de gérer automatiquement un enregistrement complémentaire à l'enregistrement principal.

En effet, à chaque opération effectuée dans le fichier principal, un traitement est appelé pour permettre d'effectuer la même opération dans le fichier complémentaire.

Pour gérer un enregistrement complémentaire, il faut bien sûr écrire les quatre fonctions (Après Read, avant Write etc.).

Attention : un enregistrement complémentaire doit obligatoirement se trouver dans un autre fichier que l'enregistrement principal.

 

Gestion des erreurs

Les fonctions Ixxxx appellent les fonctions Hxxxx correspondantes et renvoient le code d'erreur rendu par ces dernières.

Les traitements du dictionnaire sont des procédures qui ne renvoient pas de code d'erreur. Si une erreur y est détectée, il faut la corriger, l'ignorer ou provoquer l'arrêt du programme (par ferror).
