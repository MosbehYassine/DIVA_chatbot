DVBufferGet  Famille  Thème

La fonction DVBufferGet permet de lire une donnée dans un DVBuffer.

La lecture des données est séquentielle.

 

Long  DVBufferGet  (  id , valeur )

 

Paramètres

Id

Identifiant de DVBuffer obtenu par DVBufferGetId.

 

Valeur

Variable recevant la donnée lue.

Attention, le type de la variable réceptrice doit correspondre au type de la donnée écrite dans le DVBuffer. Si une donnée de type X a été écrite dans le DVBuffer, il faut utiliser une donnée de type X pour la lire. En cas d'erreur de type, un décalage se produit et les résultats ne sont pas prévisibles.

 

Retour

0

Pas d'erreur

-1

Identifiant invalide

1

La classe DVBuffer a levé une exception (lecture après la fin du DVBuffer par ex)
