ProgramCallGetError Famille Thème

 

ProgramCallGetError permet de récupérer le détail de l'erreur après un ProgramCall qui a échoué.

.

Long ProgramCallGetError  (message )

Paramètres

Message

Donnée alpha qui reçoit un message détaillant l'erreur.

 

Retour

La fonction retourne le code d'erreur Harmony.

Voir la fonction ProgramCallLastError pour avoir le code d'erreur système.
