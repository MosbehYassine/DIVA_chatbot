ProgramSetComment   Famille Thème

L'instruction ProgramSetComment permet d'associer un commentaire au programme courant. Ce commentaire est affiché par la console d'administration et par le programme Xtask.dhop ; il est également placé dans les journaux en cas d'erreur.

Il permet de préciser des détails concernant le programme. Par exemple, lorsqu'un zoom s'exécute, le programme affiché par la console est xzoom.dhop ; il est intéressant d'associer un commentaire à ce programme pour savoir de quel zoom il s'agit.

 

ProgramSetComment ( texte )

 

Paramètres

Texte

Texte libre qui sera associé au programme courant.

 

Exemple

ProgramSetComment("Zoom sur les clients")
