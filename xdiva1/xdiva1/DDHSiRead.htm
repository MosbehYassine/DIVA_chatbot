DDHSiRead  Famille  Thème

La fonction DDHsiRead permet de lire les caractéristiques d’un fichier dans un dictionnaire.

 

Long DDHsiRead (dictionnaire, fichier, clés, complément, message_erreur, [abort])

 

Paramètres

Dictionnaire

Nom du dictionnaire de données. L’extension hsd est obligatoire.

Fichier

Nom du fichier.

Clés

Zone qui reçoit en retour la description des clés du fichier.

Ce paramètre doit être une instance de l'enregistrement Cles du dictionnaire ddsys.dhsd.

L'enregistrement Cles contenant la description des clés est un tableau de 256 cases pour les clés.

LettreCle

Lettre clé.

PositionCe

Position du code enregistrement.

ValeurCe

Valeur du code enregistrement.

TestCe

Test à effectuer sur le code enregistrement

 

0 =
1 <>
2 <
3 >
4 <=
5 >=
6 &

égal
différent
inférieur
supérieur
inférieur ou égal
supérieur ou égal
et logique
 

Pour chaque clé, on trouve ensuite un tableau de 16 éléments décrivant les données qui composent la clé :

PosCle

Position d'un fragment de clé.

LgCle

Longueur d'un fragment de clé.

  

 

Complément

Zone qui reçoit en retour les autres caractéristiques de la base. Ce paramètre doit être une instance de EparamSI du dictionnaire ddsys.dhsd.

Message_erreur

Zone qui reçoit en retour un éventuel message d’erreur.

Abort

Boolen qui indique si le programme doit être interrompu en cas d’erreur. (FALSE par défaut).

 

Retour

0

Pas d'erreur

2

Fin de champs de l'enregistrement

Autres

Erreur. Voir la zone message_erreur

 

Remarque

La fonction HSiRead permet de lire les paramètres séquentiel-indexé d’un fichier (il s’agit d’une lecture des paramètres depuis la base physique), alors que DDHSiRead lit les paramètres depuis le dictionnaire.

 
Exemple

record ddsys.dhsd cles

record ddsys.dhsd eparamsi compl

main

1 err 200

 DDHSiRead("odfdd.dhsd","odfic",cles,compl,err,true)
