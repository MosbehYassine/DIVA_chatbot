Fpread  Famille Thème

 

fpread permet de lire l'enregistrement précédent le dernier enregistrement lu (fichiers séquentiel-indexé uniquement).
La lecture se fait d'après la clé courante et la "fin de fichier" est provoquée par le début de la clé en cours.

 

Ptr = fpread ( tdf , variable [ , code_réservation ] [ , depack_auto ] )

Paramètres

Tdf

Table de définition de fichier.

Variable

Donnée réceptrice qui contiendra l'enregistrement lu.

Code_réservation

Mode de partage de l'enregistrement ('P' par défaut).

Depack_auto

Décompression automatique des données si l'enregistrement comporte une zone packée.
0  : non  (par défaut)

1  : oui

  

Retour

0  

Pas d'erreur. 

H_EOF  

Début du fichier atteint. 

H_RESERVED  

Enregistrement réservé. 

autres

Code d'erreur système. 

  

Remarques

Il est possible de modifier la clé avant d'utiliser la fonction fpread pour se positionner directement sur un enregistrement. L'enregistrement lu est alors celui dont la clé est inférieure ou égale à la clé placée dans la TDF.

Pour lire un fichier "à l'envers", il faut charger au départ la clé avec une valeur supérieure à la clé la plus grande possible.
Exemples :
 fic.key = 'A' & $FF ou
 fic.key = "Azzzzzz"

 

La fonction GetLastRecord permet de récupérer le dernier enregistrement lu.

 

 

Exemple

;________________________________________________________________
; Fonction : F_PREAD

; Type : int

; Description : Lit en arrière le fichier tdf en mode "par"

; et dépacke automatique

; Paramètres en sortie : 0 = ok 1 = début 2 = réservé 3 = errsys

;________________________________________________________________
;

Function int F_PREAD (&tdf , &art , par)

record * htdf tdf ;table de définition

1 art A ;article

1 par A = 'P' ;code partage

beginf

cr = Fpread (tdf,art,par,1) 

switch cr 

case 0 ;ok 

   freturn (0) 

case H_EOF ;début de fichier 

   freturn (1) 

case H_RESERVED ;réservé 

   freturn (2) 

default ;erreur système 

   MessageBox("Erreur système numéro " & binhexa (stx (cr)) & \ 

               " en lecture du fichier " & left(tdf.name)," ") 

   freturn (3) 

endswitch 

endf
