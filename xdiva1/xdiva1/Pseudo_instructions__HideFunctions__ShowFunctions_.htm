Pseudo instructions /HideFunctions /ShowFunctions

 

La pseudo-instruction Diva /HideFunctions peut être utilisée dans votre code pour que des fonctions ou des commentaires n'apparaissent pas dans la liste des membres ou dans les fenêtres d'informations.

La pseudo-instruction Diva /ShowFunctions rétablit un fonctionnement normal.

 

L'option de compilation "Ignorer les /HIDEFUNCTIONS" du profil permet de compiler les sources en ignorant les /HIDEFUNCTIONS.  Cela permet, en  phase de développement, de voir toutes les fonctions. Lors de la compilation des objets à diffuser, il faut invalider cette option et les fonctions seront cachées.

 

Voir : Cacher des commentaires ou des fonctions de la documentation Xwin.
