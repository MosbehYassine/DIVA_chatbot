DDNextData3  Famille Thème

Pour lire les dictionnaires créés par Xwin, utilisez DDInterface (à partir de la version 5.3).

La fonction DDNextData3 permet de lire un champ de l'enregistrement préalablement lu par DDGetRecord3. Des appels successifs de DDNextData3 permettent de lire les champs suivants.

 

Long DDNextData3 (donnée_réceptrice)

 

Paramètres

Donnée_réceptrice

Donnée qui reçoit les caractéristiques du champ. Elle doit être une instance de DataInfo du dictionnaire H3fdd.

Retour

0

Pas d'erreur

2

Fin de champs de l'enregistrement

Autre

Erreur. Voir DDGetTextError qui donne un message d'erreur

 
Exemple

Affichage des noms des champs d'un enregistrement :

procedure affiche(dico,enregistrement)

1 dico A

1 enregistrement A

record h3fdd recordinfo enreg

record h3fdd datainfo donnee

1 i L

beginp

   ; lecture de l'enregistrement 

   i = ddgetrecord3(dico,enregistrement,enreg) 

   if i 

      display i 

      display ddgettexterror3 

      preturn 

   endif 

   ; boucle de lecture des données  

   loop (i := ddnextdata3(donnee)) = 0 

      display donnee.Mnemo & ":" & donnee.Libdata 

   endloop 

   if i 

      display ddgettexterror3 

   endif 

endp
