ISaveKey Famille Thème

 

La fonction ISaveKey permet de sauvegarder la clé et le nom d'index courants. La fonction IRestoreKey permet de faire l'opération de restauration.

 

char ISaveKey ( tdf )

 

Paramètres

Tdf

Table de définition du fichier

 

Retour

La fonction retourne une chaîne contenant la clé et le nom d'index. Il est conseillé de stocker cette chaîne dans une variable de type S.
