PlaySound  Famille 

Hors client léger Html

 

L'instruction PlaySound demande l'interprétation d'un fichier sons (de type .wav uniquement).

Attention : Pour que cette instruction soit effective, l'ordinateur doit contenir une carte sons ou, à défaut, un pilote (driver) permettant d'interpréter un fichier de type .wav sur le haut-parleur.

 

PlaySound (fichier , mode)

 

Paramètres

Fichier

Nom du fichier .wav.

Mode

SOUND_WAIT 

Le programme attend la fin de l'interprétation pour poursuivre son déroulement.

SOUND_NOWAIT 

Le programme poursuit son déroulement sans attendre la fin de l'interprétation (Windows lance une tâche de fond qui interprète le fichier sons en "parallèle" avec le programme).

SOUND_REPLAY (*) 

Le principe est similaire au mode 1 mais la tâche de fond "boucle" sur l'interprétation. Lorsque le fichier sons est terminé, son interprétation reprend automatiquement au début.

SOUND_STOP (*) 

Permet d'arrêter l'interprétation en cours.

(*) L'existence de ces différentes fonctions dépend des possibilités du pilote (driver) "sons" installé.

 

Exemple

PlaySound ("FICSON.WAV",1)
