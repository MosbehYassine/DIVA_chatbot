DownloadFromEncodedUrl Famille  Thème

 

La fonction DownloadFromEncodedUrl permet de télécharger un fichier dont on a recu l'url de téléchargement créée par DownLoadUrlEncode.

 

Bool DownloadFromEncodedUrl (url, fichier, exception)

 

Paramètres

 

Url

Url complète du fichier (http://serveur/lcweb/fichier.ashx/....)

 

Fichier

Nom (au format windows) du fichier local.

 

Exception

Si la fonction retourne FALSE, cette variable contient le texte de l'exception.
