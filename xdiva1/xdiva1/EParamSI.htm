EParamSI  Famille  Thème

La structure EParamSi du dictionnaire ddsys.dhsd contient les caractéristiques (autres que la description des clés) d’un fichier.

Les champs de EParamSi sont :

Nom

Commentaire

TypeFichier

Type I N ou U.

VersionBase

Version du fichier.

FichierCles

Nom du fichier des clés.

FichierDonnees

Nom du fichier des données (généralement à espaces).

LgEnreg

Taille des enregistrements.
