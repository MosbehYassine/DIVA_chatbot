XlogCheckUser

 

La fonction XlogCheckUser permet de tester la validité d'un code utilisateur et de son mot de passe.

 

int XlogCheckUser (utilisateur, motDePasse, &erreurSysteme, titreErreur)

 

Paramètres

Utilisateur

Code utilisateur à tester.

 

motDePasse

Mot de passe de l'utilisateurr.

 

erreurSysteme

Variable de type X recevant en retour un code d'erreur système.

 

titreErreur

Si ce paramètre est renseigné et différent de espace, la fonction affiche une fenêtre en cas d'erreur.

 

Retour

0   Le code utilisateur et/ou le mot de passe sont erronés.

 

1   Pas d'erreur

 

2   Erreur système. Voir le contenu du paramètre erreurSysteme
