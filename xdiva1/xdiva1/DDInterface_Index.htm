DDInterface : Index  Famille  Thème

Pour le niveau 1 :

Nom

Nom du champ en majuscules.

NomSaisi

Nom avec minuscules et majuscules.

Libelle

Commentaire.

NomTable

Nom de la table accédée par cet index.

LibelleTable

Libellé de la table accédée par cet index.

LettreCle

Lettre clé.

NomDeCle

Nom de clé si la clé est nommée

CleOuNomDeCle

Lettre clé ou nom de la clé.

FlagClePrimaire

TRUE si « clé primaire » est cochée.

Type

Type d’index SQL.

IndexDeReference

1 si l’index est l’index principal.

Longueur

Taille de la clé.

ChampCC

Champ utilisé comme code condition.

ValeurCC

Valeur du code condition.
Attention, cette valeur est transmise en décimal et doit être convertie en binaire.

1 Dico_ValeurCC  1

2 Dico_ValeurCCBin b 

1 valnum 3,0

valnum = HmpSeek(reponse,"ValeurCC")
Dico_ValeurCCBin = valnum 

TestCC

Test à effectuer entre le champ et la valeur. 

PositionCC

Position du code condition dans la table.

PositionCCCle

Position du code condition dans la clé.

NatureCC

Nature du champ code condition. Voir DDInterface : Champs .

ChampCe

Nom du champ servant à identifier l’enregistrement.

ValeurCe

Valeur du code enregistrement. Attention, cette valeur est transmise en décimal et doit être convertie en binaire.

1 Dico_ValeurCe 1

2 Dico_ValeurCeBin b 

1 valnum 3,0

valnum = HmpSeek(reponse,"ValeurCe")
Dico_ValeurCeBin = valnum 

PositionCe

Position du code enregistrement dans la table.

PositionCeCle

Position du code enregistrement dans la clé.

NatureCe

Nature du code enregistrement. Voir DDInterface : Champs .

 

Pour le niveau 2 :

DateCreation

Date de création de l’élément.

UtilisateurCreation

Utilisateur qui a créé l’élément.

DateModif

Date de dernière modification de l’élément.

UtilisateurModif

Utilisateur qui a effectué la dernière modification.

NumeroCommentaire

Numéro de commentaire général dans le fichier des commentaires.

NumeroCommentaireLocal

Numéro de commentaire local.
