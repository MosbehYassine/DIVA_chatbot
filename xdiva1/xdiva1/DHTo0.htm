DHTo0 Famille Thème

 

La fonction DHTo0 ajuste une donnée de type date+heure si l'heure vaut 24h 0m 0s. L'heure est mise à 0 et le jour est incrémenté.

 

DateHeure DHTo0 (dateHeure)

 

Paramètres

DateHeure

Donnée de type date+heure.

 

Retour

Si l'heure vaut 24h 0m 0s la fonction retourne la date du lendemain avec l'heure à 0.

Sinon, elle renvoie le paramètre d'entrée sans modification.

 
  Exemple

1 dateheure dh

dateheure = "20060501240000"

dateheure = DhTo0(dateheure)

display dateheure  ; --> 200605020000
