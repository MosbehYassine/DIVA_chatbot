DDInterface : Champs

Les commandes de lecture de champs renvoient les valeurs suivantes :

Pour le niveau 1 :

Nom

Nom du champ en majuscules.

NomSaisi

Nom avec minuscules et majuscules.

Libelle

Commentaire.

Niveau

1 pour les champs de premier niveau. 2 pour les sous-champs etc.

DonneePack

1 si le champ courant est le champ PACK (zone packée de la table)
2 si le champ courant est le champ DEPACK (zone dépackée de la table)

Position

Position dans la table courante.
Pour les commandes DD_DATAFIND_DD et DD_DATABEGIN_DD la position est par rapport à la table de tous les champs du dictionnaire et ne peut donc être utilisée.
Pour les index, il s’agit de la position du champ dans la clé.

Longueur

Taille du champ

Nature

1 = Numérique avec décimales variables
2 = Numérique
3 = Alphanumérique
4 = Date (aaaammjj)
5 = 1 caractère
6 = Type B
7 = Type X
8 = Binaire
9 = Type L
10 = Heure (hhmmss)
11 = Date mensuelle (aaaamm)
12 = date + heure (aaaammjjhhmmss)  
13 = Durée
14 = Blob (Objet Binaire)

NbDecimales

Nombre de décimales pour les données numériques.

NbDimensions

Nombre de dimensions si la donnée est un tableau.

Dimensionsn

Nombre d’éléments par dimensions (n varie de 1 à 4).

Enjambeesn

Offset à ajouter par dimension (n varie de 1 à 4).

 

 

Pour le niveau 2

DateCreation

Date de création de l’élément.

UtilisateurCreation

Utilisateur qui a créé l’élément.

DateModif

Date de dernière modification de l’élément.

UtilisateurModif

Utilisateur qui a effectué la dernière modification.

NumeroCommentaire

Numéro de commentaire général dans le fichier des commentaires.

NumeroCommentaireLocal

Numéro de commentaire local.

Union

1 si le champ est une union.

LongueurTableau

Taille totale de tous les éléments si le champ courant est un tableau.

FlagOdbc

1 si « Masqué dans ODBC » est coché.

FlagSql

1 si « Masqué dans SQL » est coché.

ValeurInit

Valeur d’initialisation générale.

ValeurInitLocale

Valeur d’initialisation locale.

Edi

Zone « Edi général »

EdiLocal

Zone « Edi local »

 

Pour les champs dans les index :

 

IndiceIndexn

Indices utilisés dans la clé. (n varie de 1 à 4).

PositionTable

Position du champ à l’intérieur de la table
