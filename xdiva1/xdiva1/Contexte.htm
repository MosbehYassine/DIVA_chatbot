Fonctions WinShell_

 

En Diva, la fonction WinShellExecute permet d'exécuter une action sur un fichier.

Mais, une fois l'action lancée, le programme Diva ne conserve aucun lien avec le fichier. Entre autres, il est impossible de :

  • Savoir si le fichier est encore ouvert par le programme qui l’utilise,

  • Savoir si le fichier a été modifié ou pas.

Pour pallier certaines de ces carences, le module ymapi.dhop expose une suite de fonctions « WinShell_».

 

Dans ces fonctions, la principale, WinShell_Execute, se substitue à WinShellExecute et rend le même service de base, mais en plus conserve un lien avec les fichiers lancés.

 

Pour les fichiers exécutés via cette fonction WinShell_Execute, le programme Diva peut, par exemple, ultérieurement consulter leur état avec WinShell_Read.

 

La suite de cette section détaille le fonctionnement de WinShell_Execute et des fonctions connexes.

 

Remarque :

La fonction WinShell_Execute et les fonctions WinShell_ connexes ne sont pas utilisables avec le client web xHtml5 (le navigateur interdit les application web de lancer des programmes)!
