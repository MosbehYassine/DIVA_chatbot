HCreateFile  Famille Thème

 

La fonction HCreateFile permet de créer un fichier de type U ou N.

 

Numer HCreateFile (Fichier, Type, [ Lgenr ] , [ Abort ])

 

Paramètres

Fichier

Nom complet du fichier à créer.

Type

Type du fichier N C ou U.

Lgenr

Longueur des enregistrements ou 0 (valeur par défaut) pour une taille d'enregistrements variable.

Abort

Booléen (TRUE par défaut) indiquant si la fonction doit arrêter le programme en cas d'erreur, ou rendre la main avec un code d'erreur.

En cas d'arrêt du programme, la fenêtre standard des erreurs est affichée et l'erreur est journalisée dans le fichier ferror.log.

 

Retour

0

Pas d'erreur.

$14

Chemin du fichier erroné.

$09

Le fichier existe déjà.

Autres

Code d'erreur système.

Si Abort = TRUE, toutes les erreurs provoquent l'arrêt du programme.

 

Remarque

La création des fichiers séquentiels indexés se fait par la fonction HSiCreate

Exemple

; création du fichier "mon fichier" dans le répertoire sys

; type "N" et enregistrements de taille variable.

; La fonction aborte en cas d'erreur.

HCreateFile("/Divalto/sys/mon fichier","N")
