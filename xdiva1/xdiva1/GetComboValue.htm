GetComboValue

La fonction GetComboValue permet de trouver la valeur d'un choix à partir du texte du choix.

 

int GetComboValue (dico, entree, texte, &resultat)

 

Paramètres

Dico

Nom du dictionnaire des multi-choix.

Entrée

Entrée dans le dictionnaire.

Texte

Texte du choix.

Resultat

Variable qui contient en retour la valeur du choix.
Si une valeur est associée au choix, c'est celle-ci qui est placée dans Resultat. Dans le cas contraire, le numéro d'ordre du choix est placé dans Resultat.

 

Retour

0

Pas d'erreur

1

Erreur. (fichier absent, texte non trouvé etc.)

 

Exemple

i = GetComboValue("gtfdmc.dhfi","choix_anacout","Total ressource",resultat)

; i --> 0

; resultat --> 2  ('Total ressource' est le second choix de la liste)
