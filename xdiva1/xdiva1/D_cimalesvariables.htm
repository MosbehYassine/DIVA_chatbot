Décimales variables

Diva permet de définir des variables numériques sans connaître lors de l'écriture du programme le nombre de décimales de ces variables. Par exemple, dans certains pays la comptabilité se fait sur trois décimales, en gestion les quantités peuvent être sur 0 1 2 ou 3 décimales etc ....

Diva peut gérer jusque 10 types de décimales variables.

 

Déclaration d'une donnée à décimales variables

La syntaxe est la suivante :

niveau [nom de variable] [position .] longueur,DN

Un nombre à décimales variables se définit en mettant ,D suivi du type de décimale variable (0 à 9).


Exemples :

1 Montant 14,D  ; ,D et ,D0 sont équivalents
1 Montant1 14,D0
1 Quantite 14,D1

 

Utilisation d'une donnée

Les données à décimales variables s'utilisent exactement de la même manière que les données à décimales fixes.

Le nombre de décimales de la variable sera pris en fonction de son type dans un tableau défini dans l'enregistrement System.

Avant d'utiliser une donnée à décimales variables, cette table doit être initialisée par le programme. Il est toujours possible de changer en temps réel cette table en cours d'exécution.

 

Localisation de la table

Le champ Zdecn de l'enregistrement System correspond à la déclaration ,D ou ,D0.

Le tableau Zdec de l'enregistrement System correspond à la déclaration ,Dn (n compris entre 1 et 9)..

 

Exemple de programme :

1 n1 10,d0

1 n2 10,d1

1 n3 10,d2

1 n0 10,4

main

System.Zdecn = 0 

System.Zdec(1) = 1 

System.Zdec(2) = 2 

Input 'valeur....: ' N0 

N1 = n0 

N2 = n0 

N3 = n0 

Display n1 

Display n2 

Display n3 

System.Zdecn = 4 

n1 = n0 

Display n1 

Programexit 

A l'exécution pour la valeur entrée 123,45 le programme affiche les valeurs suivantes :
123
123,4
123,45
123,4500

 

Remarque :

Lorsqu'un type de décimales variables est modifié, cette modification n'est prise en compte que lors de la prochaine affectation dans les variables de ce type. Le fait de changer un type de décimales variables ne change en rien le contenu de ces variables.
