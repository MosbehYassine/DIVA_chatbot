SwitchString - Case - Default - Continue - Break- RedoSwitch - Endswitch  Famille

 

La structure SwitchString se différencie de la structure Switch par le fait que les expressions testées sont obligatoirement des constantes.

L'instruction SwitchString est extrêmement rapide à l'exécution, la rapidité du branchement au cas choisi étant très peu dépendante du nombre de choix total.

Endswitch

 

L'instruction SwitchString CaseString est une spécialisation de l'instruction de sélection simple If. Dans cette structure, l'expression qui suit le mot réservé SwitchString est appelée sélecteur.

Les expressions de sélection doivent obligatoirement être des constantes alpha ou string.

A l'exécution, la valeur du sélecteur doit correspondre à l'une des constantes possibles. Les instructions associées sont alors exécutées, après quoi le contrôle est donné à l'instruction suivant la fin de la structure (sauf si une instruction Continue a été rencontrée). Si le sélecteur ne correspond à aucune des constantes, les instructions suivant le mot réservé Default sont exécutées. Si le mot réservé Default est absent, l'exécution du programme se poursuit après le mot réservé Endswitch qui est obligatoire.

Continue provoque un branchement sur l'instruction qui suit le Case suivant.

Break provoque la sortie de la structure Switch. L'exécution du programme se continue après Endswitch.

RedoSwitch provoque un branchement à l'instruction Switch. Expression est à nouveau évaluée.
 

Exemple

switchstring couleur

case "blanc" "noir"

   TraitementNoirEtBlanc() 

case "or"

   TraitementSpecial()  

default

   TraitementCouleur()  

endswitch
