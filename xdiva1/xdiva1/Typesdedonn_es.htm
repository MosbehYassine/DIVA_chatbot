Types de données

Les variables alpha-numériques

Pour déclarer une variable de type alpha-numérique il suffit de préciser sa longueur.

Exemple :
1 Art 508

 

Les variables String

Une variable de type String est une variable de type alpha-numérique de taille variable.

Pour déclarer un variable en type String, il faut remplacer la longueur par la lettre S. La déclaration se fait obligatoirement au niveau 1.

Les données de type String s’utilisent exactement comme les variables de type alpha-numérique.

Exemples :

1 MonString S

1 Chaine  S

Les variables numériques

Pour déclarer une variable numérique, la longueur de la variable doit être suivie d'une virgule et du nombre de décimales de la variable. La longueur de la variable représente la longueur totale, signe et virgule compris.

La taille maximale d'une donnée numérique est de 24 caractères. La partie entière ne peut excéder 14 caractères et la partie décimale ne peut excéder 10 caractères.

Exemples :

1 Nombre 3,0 ; entier sans décimales
1 Montant 10,2 ; entier avec 2 décimales

avec

-99 < Nombre < 999
-999999,99 < Montant < 9999999,99

Les variables de type X

Une variable de type X est une donnée de 2 octets dont la valeur est comprise entre 0 et $FFFF.

Les variables de type X sont considérées par le compilateur comme des variables numériques; il est donc possible de les utiliser dans des calculs.

Les variables de type X ne doivent pas être utilisées pour stocker des adresses.

Pour déclarer une variable en type X, il faut remplacer la longueur par la lettre X.

 

Exemples :

1 i X
1 Indice 10.X

 

Les variables de type L

Une variable de type L est une donnée de 4 octets dont la valeur est comprise entre 0 et $FFFFFFFF.

Il est conseillé d'utiliser des données de type L comme indices de tableau, le calcul des adresses étant beaucoup plus rapide.

Les variables de type L peuvent être utilisées pour stocker des adresses.

Les variables de type L sont considérées par le compilateur comme des variables numériques; il est donc possible de les utiliser dans des calculs.

Pour déclarer une variable en type L, il faut remplacer la longueur par la lettre L.

 

Exemples :

1 i L
1 Adr L

 

Les variables binaires

Une variable binaire est une donnée de 1 octet dont la valeur est comprise entre 0 et 255 ($FF).

Les variables binaires sont considérées par le compilateur comme des variables numériques; il est donc possible de les utiliser dans des calculs.

Pour déclarer une variable de type binaire, il faut remplacer la longueur par la lettre B.

Exemples :
1 B1 B
1 B2 10.B

 

Les variables booléennes

Il n'y a pas à proprement parler de variable booléenne en Diva. Les opérateurs de test renvoient toujours une valeur numérique, 1 pour vrai et 0 pour faux. De manière plus générale, la valeur 0 vaut pour faux et toutes les autres valeurs valent pour vrai.

Il est donc tout à fait possible d'écrire :
Vn = V1 < 10
IF VN ...
où VN et V1 sont des variables numériques.

 

Les variables dates

Les dates doivent être déclarées de type D (8 positions). Les dates sont stockées avec le format suivant : AAAAMMJJ.

Les fonctions utilisant des dates ne fonctionnent que si les dates sont stockées de cette manière. Il existe des fonctions pour formater des dates et faire des calculs (Formatd, Dtnum, Numdt etc...).

Pour accéder aux sous-champs d'une date (an, mois, jour) il faut impérativement utiliser les fonctions HDay etc.

Exemple :

1  date  D

hday(date) = 1

 

Les variables heures

Les variables heures doivent être déclarées de type H H4 ou H6 . Les heures sont stockées avec le format suivant : HHMM(SS).

H6 est équivalent à H.

Pour accéder aux sous-champs d'une heure,  il faut impérativement utiliser les fonctions THour etc.

Exemple :

1  heure   H6

 

Les variables dates+heures

Les variables dates+heures doivent être déclarées de type DH  (14 positions). Les dates+heures sont stockées au format AAAAMMJJHHMMSS.

Pour accéder aux sous-champs d'une date+heure (an, mois, jour) il faut impérativement utiliser les fonctions DHDate etc.

Exemple :

1 DateHeure  DH

 

 

Les variables dates mensuelles

Les variables dates mensuelles doivent être déclarées de type DM ( 6 positions). Les dates mensuelles sont stockées au format AAAAMM.

Pour accéder aux sous-champs d'une date mensuelle  (an, mois) il faut impérativement utiliser les fonctions HYear et HMonth.

Exemple :

1 DateMens  DM

 

 

Les variables durées

Les variables durées doivent être déclarées de type T (numérique sur 8 positions). Elles contiennent un nombre de secondes.
