ZipArchiveCreate Famille Thème

 

Création d'une archive au format zip et ajout d'un fichier.

 

Bool ZipArchiveCreate( ZipArchivePath, PathFilename [, ZipPathFilename], [ZipPassword] )

 

Paramètres

ZipArchivePath

Chemin vers le fichier zip à créer

PathFilename

Chemin vers le fichier à ajouter à l'archive

ZipPathFilename

Chemin dans l'archive zip où le fichier doit être ajouté. Ce paramètre est facultatif. S'il n'est pas spécifié, alors sa valeur sera le nom du fichier donné par 'PathFilename'

ZipPassword

Mot de passe pour les fichiers chiffrés dans l'archive zip

 

Retour

La fonction renvoie 1 en cas de succès, 0 sinon. Pour avoir plus d'informations sur l'erreur en cas d'échec, utiliser la fonction ZipArchiveGetLastErrorCode()

 

Remarques

Si le fichier n'existe pas, il est crée. S'il existe, son contenu est écrasé.

Le nom peut contenir le chemin complet vers le fichier, le chemin relatif ou juste le nom du fichier.

 

Exemples

; Création de l'archive test.zip contenant le fichier myFile.txt

  retVal = ZipArchiveCreate("C:/test.zip", "C:/myFile.txt");

  if retVal = 0

    errorCode = ZipArchiveGetLastErrorCode()

    errorMessage = ZipArchiveGetLastErrorMessage()

    ;à faire: traiter l'erreur

  endif

 

; Création de l'archive test.zip contenant le fichier myFile.txt renommé myFileRenamed.txt

  retVal = ZipArchiveCreate("C:/test.zip", "C:/myFile.txt", "myFileRenamed.txt");
