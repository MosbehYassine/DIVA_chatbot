Crypt

La fonction Crypt permet de crypter une chaîne de caractères avec une clé de cryptage en utilisant le service de cryptographie de Windows.

 

Alpha Crypt (chaine , clé , erreur , [hexa] , [début] , [fin])

 

Paramètres

Chaine

Chaîne à crypter.

Clé

Clé de cryptage.

Erreur

Variable numérique qui contient en retour un éventuel code d’erreur (0=pas d’erreur)

Hexa

Booléen indiquant que le résultat doit être codifié en hexadécimal. Cela permet de générer une chaîne cryptée qui ne contient que des caractères affichables. Cette option est indispensable si votre chaîne cryptée doit être envoyée sur l’internet (pour un service Web par exemple).
Valeur par défaut : TRUE.

Début

Booléen indiquant que la fonction débute un nouveau cryptage. Voir remarques ci-dessous.

Valeur par défaut : TRUE.

Fin

Booléen indiquant que la fonction termine un cryptage. Voir remarques ci-dessous.

Valeur par défaut : TRUE.

 

Retour

En cas de succès, la fonction retourne la chaîne cryptée et erreur est positionné à 0
En cas d’erreur, le paramètre erreur contient un code d’erreur précis.

Attention :  La fonction Crypt ne met pas d’entête de reconnaissance au début de la chaîne cryptée. Cela implique que la fonction Uncrypt ne renvoie jamais d’erreur si la clé de décryptage est fausse.
Si vous voulez vérifier que la clé de décryptage est correcte, ajoutez à la chaîne à crypter une séquence de caractères fixe et vérifiez que vous la retrouvez bien après décryptage.

 

Voir Codes d'erreurs des fonctions de cryptage et de compression .

 

Remarques

  • Les paramètres Début et Fin permettent de crypter un flot de données par étapes. Par exemple, pour crypter un fichier, nous allons lire une partie du fichier, crypter cette partie, écrire le résultat dans le fichier de destination et répéter ces opérations jusqu’à la fin du fichier.
    Début et Fin permettent d’indiquer à quel stade du cryptage se trouve le programme.

    L'algorithme à utiliser est le suivant :

Crypt(chainevide,cle,debut=TRUE,fin=FALSE)

Tantque non fin de fichier

 Crypt(buffer,cle,debut=FALSE,fin=FALSE)

Fintq

Crypt(chainevide,cle,debut=FALSE,fin=TRUE)

Par défaut, Début et Fin sont à TRUE. Ces valeurs sont celles qu’il faut utiliser pour crypter une simple chaine de caractères.

Voir FileCrypt qui crypte un fichier.

 

  • Le résultat d’un cryptage par la fonction Crypt ne peut pas être décrypté par la fonction FileUnCrypt. Il faut utiliser FileCrypt pour crypter un fichier.

 

Exemple 1

Exemple de cryptage d’une chaîne de caractères.

1 depart S

1 arrivee S

1 coder X*

1 cle  S

 

depart = "chaine a crypter"

cle = "macle"

arrivee = crypt(depart,cle,coder)  

display arrivee

 

Exemple 2

Exemple de cryptage d’un fichier dans une chaîne de caractères.

1 depart S  ; chaine a crypter

1 arrivee S ; résultat cryptage

1 coder X   ; code d'erreur

1 cle S     ; cle de cryptage

1 art 20    ; buffer de lecture

1 vide S    ; chaine vide

1 verif S   ; tout l'original pour verif

record * htdf tdfe

main

 ; cryptage d'un fichier dans un string

 tdfe.name = "testcrypt.dhsp"

 hopen (tdfe,"F")

 

 ; marque le début du cryptage

 arrivee = crypt(vide,cle,coder,debut=TRUE,fin=FALSE) 

 

 ; boucle lecture + cryptage

 loop freadst(tdfe,art) = 0

    verif &= left(art,tdfe.sizelast) 

    arrivee &= crypt(left(art,tdfe.sizelast),cle,coder,debut=FALSE,fin=FALSE)

 endloop

 

 ; marque la fin du cryptage

 arrivee &= crypt(vide,cle,coder,debut=FALSE,fin=TRUE)

 

 ; verification

 depart = arrivee

 arrivee = uncrypt(depart,cle,coder)

 if arrivee = verif

    display "ok"

 endif
