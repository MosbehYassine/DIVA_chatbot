ModuleLoad  Famille Thème

 

L'instruction ModuleLoad permet de charger un module Diva en remplacement d'un autre module Diva. Le module qui est remplacé par ModuleLoad ne doit pas avoir été préalablement chargé par l'appel d'une de ses fonctions.

Cette instruction n'est pas utilisée dans la pratique. Voir Appel de fonctions par le nom.

ModuleLoad (module_à_charger , module_remplacé)

Paramètres

Module_à_charger

Nom du module à charger à la place de Module_remplacé.

Module_remplacé

Nom du module qui est remplacé par Module_à_charger. C'est le module qui a été utilisé pour la compilation et qui devrait normalement être utilisé.

 

ModuleLoad peut être utilisée dans le cas suivant : plusieurs programmes utilisent un même masque mais les traitements associés aux données du masque changent d'un programme à l'autre. Pour éviter toute redondance de code, les traitements associés aux données doivent être des appels à des fonctions dans un module. Ce module est remplacé en début de programme par un autre module ayant les mêmes prototypes de fonctions.

Exemple :

Masque

Module Mod1

Module Mod2

Module "Mod1"
……
ControlCo(cl.code)

Procedure ControlCo(co)
Beginp
……..
Endp

Procedure ControlCo(co)
Beginp
……..
Endp

Le masque déclare le module Mod1 (caractéristiques générales - Déclarations). Lors de l'exécution, si le module Mod2 doit être utilisé à la place de Mod1, il faut écrire :
ModuleLoad "Mod2" "Mod1"
