SearchInfo    Famille  Thème

La fonction SearchInfo est une fonction spécifique pour la console de Xsearch.

 

Long  SearchIndex ( Id , Commande,  Paramètres , &IdBuffer )

 

Paramètres

Id

Identifiant de la connexion.

 

Commande

define SEARCH_INFO_ListeChampsCommuns             = 1

define SEARCH_INFO_GetParametresAffichageDocument = 2

define SEARCH_INFO_GetNomServeur                  = 3  ; // traitée coté client

define SEARCH_INFO_ListeDesConnexions             = 4

define SEARCH_INFO_ListeDesEvenementsPeriodiques  = 5

define SEARCH_INFO_ListeDIndexation               = 6

define SEARCH_INFO_ListeDesDocuments              = 7

define SEARCH_INFO_EtatServeur                    = 8

define SEARCH_INFO_ListeAnalyzeurs                = 9

 

Paramètres

Paramètres complémentaires de la commande (non documenté).

 

IdBuffer

En retour, un DVBuffer contenant la réponse du serveur.

Le contenu de ce DVBuffer n'est pas documenté.

 

 

Retour

0

La fonction retourne toujours 0
