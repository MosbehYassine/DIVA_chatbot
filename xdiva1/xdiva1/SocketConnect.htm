SocketConnect  Famille   Thème

 

La fonction SocketConnect effectue une connexion à un serveur.

Int = SocketConnect (socket , adresse_ip , port)

 

Paramètres

Socket

Socket obtenu par la fonction SocketNew .

Adresse_ip

Adresse internet de l’ordinateur distant. Cette adresse peut être exprimée sous la forme xxx.xxx.xxx.xxx ou dans une donnée de type L.

Port

Numéro de port (ou de service) sur l’ordinateur distant.

.

 

Retour

TRUE

Connexion effectuée

FALSE

Erreur. Voir SocketLastError
 

Remarque

  • La fonction SocketGetHostByName permet de trouver l’adresse internet d’un ordinateur à partir de son nom.

 

Exemple

If SocketConnect(sock,"193.0.1.2",2223) = TRUE

….
