Table de définition de fichier (TDF)

Pour utiliser un fichier, le programme doit allouer une zone de 1024 octets appelée Table de Définition de Fichier (TDF) qui servira de zone de communication avec le système. Cette TDF est utilisée par le système pour y stocker des informations propres à la tâche. Elle est également utilisée par le programme pour par exemple indiquer la clé à lire.

 

On distingue essentiellement deux champs à l'intérieur de cette TDF :

  • le nom du fichier sur 256 octets

  • la clé sur 256 octets (fichiers indexés) ou sur 8 octets (fichiers normaux à taille d'enregistrements fixes).

La déclaration d'une Tdf se fait par les instructions HFile et HTmpFile.

 

Exemples :

 

Hfile exodd fcli tdfcli ; déclaration d'une Tdf nommée tdfcli

; le fichier sera automatiquement ouvert  

 

Remarque : une tdf de manoeuvre peut aussi être déclarée de la manière suivante :

Record * htdf wtdf

 

Avant de faire une ouverture de fichier (Hopen), il faut mettre le nom du fichier que l'on veut ouvrir dans le champ Name de la tdf.

Avant de faire une lecture en accès direct ou indexé, il faut (en général) positionner la clé.

 

Exemple 1 : Ouverture d'un fichier séquentiel-indexé et recherche d'un enregistrement :

Record * htdf wtdf ; déclaration d'une tdf de manoeuvre

wtdf.name = "fcomp"

Hopen(wtdf,'P')

....

wtdf.key = "A" & "BACH" ; positionnement de la clé à lire

status = Fseek2(wtdf,article,"P"); recherche de l'enreg. dont la

; clé est BACH 

; on aurait aussi pu écrire

status = Hseek(wtdf,article,"A" & "BACH","P")

 

Exemple 2 : Ouverture d'un fichier de type N à taille d'enregistrement fixe et lecture de l'enregistrement 5230.

Record * htdf fnf

fnf.name = "FNF"

status = fopen(fnf,'P')

....

fnf.keyn = 5230 ; positionnement de la clé à lire

status = fseek2(fnf,article,"P"); lecture de l'enreg no 5230

 

Remarque 1 : Si la clé n'est pas positionnée après l'ouverture du fichier, la fonction fread lit le premier enregistrement du fichier (suivant la clé A pour un fichier séquentiel-indexé).

 

Remarque 2 : L'instruction HFile (déclaration d'un fichier défini dans un dictionnaire) réserve la table de définition du fichier (TDF), positionne le nom du fichier et ouvre ce dernier.
