WinReadProfileSection  Famille Thème

 

La fonction WinReadProfileSection permet de lire la liste des entrées d'une section d'un fichier .ini. Cette fonction ne donne pas les valeurs mais uniquement la liste des mots-clés d'une section.

Attention, le fichier divalto.ini est géré de manière particulière. Voir le chapitre divalto.ini de la documentation Installation et paramétrage d'Harmony.

  

Ptr WinReadProfileSection (section, fichier, buffer)

 

Paramètres

Section

Nom de la section du fichier .ini. Dans un fichier .ini, une section est un mot encadré par les crochets [ ]. Ne pas mettre les crochets dans ce paramètre.

Fichier

Nom du fichier .ini.

Buffer

Zone de réception. Les différentes entrées sont séparées par le caractère $00. La fin de la liste est marquée par $00 $00.

 

Retour

0

Section inexistante.

autre

Nombre de caractères écrits dans buffer.

  

Exemple

; Lecture de toutes les entrées du chapitre system de monfichier.ini

1 buf 2000

1 pos L

1 oldpos L

main

display WinReadProfileSection("system","monfichier.ini",buf)

pos = string($00 , buf , 1)

do

   oldpos = pos + 1 

   pos = string($00,buf, ++pos) 

while pos <> 0 and pos <> oldpos

   display mid(buf, oldpos, pos - oldpos) 

wend
