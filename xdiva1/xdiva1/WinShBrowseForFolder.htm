WinShBrowseForFolder  Famille Thème

 

La fonction WinShBrowseForFolder permet de faire sélectionner un répertoire à l'utilisateur. Elle affiche la boîte de dialogue standard de sélection des répertoires.
Voir la fonction DirectoryBox qui est la boîte de sélection des répertoires d'Harmony.

 

Long WinShBrowseForFolder( numéro ,répertoire, titre, texte, options, resultat)

 

Paramètres

Numéro

Permet d'indiquer la racine pour la navigation.

0

Navigation à partir du poste de travail

Autre

Constante de type CSIDL (voir WinShGetSpecialFolderLocation).

Répertoire

Répertoire où commencer la navigation.

Titre

Titre de la fenêtre de navigation.

Texte

Texte affiché à l'intérieur de la fenêtre.

Options

Il est possible de combiner (par une addition) les valeurs suivantes.

BIF_DONTGOBELOWDOMAIN

Ne pas montrer les machines du voisinage réseau

BIF_STATUSTEXT  

Affichage du répertoire courant dans la fenêtre

BIF_EDITBOX  

En version 7.41 l'utilisateur peut saisir son choix au clavier.

 

Résultat

Variable contenant le répertoire sélectionné.

 

Retour

TRUE

L'utilisateur a sélectionné un répertoire.

FALSE

L'utilisateur a abandonné.
 

 
Exemple

Affichage de la boîte de dialogue à partir du répertoire c:\Divalto.
Les machines du voisinage réseau sont cachées et le répertoire courant est affiché dans la fenêtre.

1 result 256

display WinShBrowseForFolder(0,"c:\Divalto", \ 

                 "Installation des fichiers", \  

                                "Veuillez choisir le repertoire", \ 

BIF_DONTGOBELOWDOMAIN + BIF_STATUSTEXT ,result) 

display result
