FileCompress  Famille Thème

 

Cette fonction permet de comprimer un fichier. Les fichiers comprimés par FileCompress peuvent être expansés par la fonction FileUnCompress.

 

Ptr = FileCompress (fichier_départ , fichier_arrivée, code_système, [comm])

 

Paramètres

Fichier_départ

Nom du fichier à comprimer.

Fichier_arrivée

Nom du fichier comprimé. Si ce fichier n'existe pas, il est automatiquement créé. Le fichier d'arrivée doit obligatoirement être distinct du fichier de départ.

Code_système

Donnée numérique qui reçoit un code d'erreur système.

Comm

Commentaires à associer au fichier. Voir la fonction FileCompressGetComment qui permet de lire ces commentaires.

  
Retour

La fonction retourne un code d'erreur principal et un code d'erreur système.

Voir Codes d'erreurs des fonctions de cryptage et de compression .

 

Remarque

La compression d'un fichier vide ne provoque pas d'erreur. Le résultat est également un fichier vide.

 

Exemple

; compression du répertoire /Divalto/sys dans /Divalto/compresse

procedure comprime

beginp

record 'ddsys.dhsd' OPDIR OP

record 'ddsys.dhsd' ELTDIR EL

1 car 1

1 st X

op.racine = "/Divalto/sys" 

op.prefixe = "*"

op.tri = 1

st = DirOpen(op)

if st

   Display "Erreur " & tohexa(st) & " lors de l'ouverture" 

   preturn 

endif

loop DirRead(op,el) = 0

   if el.flagdir = 0 

      display left(el.nom) & el.taillefd  

      st = FileCompress("/Divalto/sys/" & el.nom, \ 

                        "/Divalto/comprime/" & el.nom, stat) 

      if st 

         Display "Erreur " & str(st) & " Err. Sys = " & tohexa(stat) 

         input " " car 

       endif 

   endif

endloop

DirClose(op)

endp
