WinPrint  Famille Thème

La fonction WinPrint permet d’imprimer un fichier.

 

Ptr WinPrint ( fichier , [imprimante] , [avec_message )

 

Paramètres

Fichier

Nom complet du fichier à imprimer. Ce nom doit être au format Windows. La fonction GetSystemFileName permet de récupérer le nom windows d’un fichier ouvert par Harmony.

De plus, le fichier doit posséder une extension pour laquelle il existe un programme d’impression (.doc, .hwv , .txt etc.).

 

Imprimante

Nom de l’imprimante à utiliser. Si ce dernier n’est pas précisé ou est à espaces, l’impression sera dirigée vers l’imprimante par défaut de la tâche.

 

Avec_message

TRUE/FALSE. Si ce paramètre est à TRUE et qu’il n’y a pas de programme pour traiter l’extension du fichier, un boîte de dialogue s’affiche proposant à l’utilisateur d’abandonner, d’ignorer ou de recommencer.

Si l’utilisateur choisit d’ignorer, la fonction retourne 0.

Si l’utilisateur choisit d’abandonner, la fonction retourne WINPRINT_ABORT.

Si le programme qui utilise WinPrint est une tache de fond ou un service, il faut positionner ce paramètre à FALSE.
Valeur par défaut : TRUE.

 

 

Retour

0

Pas d'erreur 

1

WINPRINT_ABORT. Il y a eu une erreur et l'utilisateur à demandé d'abandonner la suite de l'impression. 

2

WINPRINT_OPENFILE. Impossible d'ouvrir le fichier , il n'existe pas l’utilisateur n'a pas les droits pour l'ouvrir. 

3

WINPRINT_NOREADY. Le programme qui a été lancé pour imprimer ce fichier ne répond plus 

4

WINPRINT_NOPROG. Il n'y a pas de programme pour traiter cette extension 

 

 

Remarque

  • Cette fonction est du même type que la fonction WinShellExecute.

 

Cas particulier du client léger Web


Cette fonction ne traite que les fichiers de type .pdf ou .dhvw (automatiquement convertis en PDF).

 

 

Exemple

1 i x

1 fic 260

1 imp 260

 

main

 imp = WinPrintSelec

 if imp <> " " 

  fic = "c:\Divalto\sys\exemples.txt"  

  display "impression de " & left(fic)

  i = WinPrint(fic,imp)  

  if i = WINPRINT_ABORT

    ;abandon  

  endif      

 endif

 

 ;meme chose mais en prenant l'imprimante par defaut d'harmony

 fic = "c:\Divalto\sys\exemples.txt"  

 display "impression de " & left(fic)

 i = WinPrint(fic)  

 if i = WINPRINT_ABORT

  ;abandon   

 endif
