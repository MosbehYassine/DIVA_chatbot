Stxl  Famille

 

La fonction Stxd convertit une donnée de type L en zone mémoire de 4 octets dans l'ordre Poids Forts - Poids Faibles.

Stxd est la fonction inverse de Ldxl .


Long = Stxl (Donnée)


Paramètres

Donnée

Variable de type L.


Retour

Si le processeur stocke les données de type L dans l'ordre Poids Faibles - Poids Forts, la fonction Stxd assure l'inversion.
