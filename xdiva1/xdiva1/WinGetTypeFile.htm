WinGetTypeFile  Famille Thème

 

La fonction WinGetTypeFile permet de récupérer en clair le type de fichier associé à une extension.

Cette fonction se trouve dans le module ysystemex.dhop.

 

Char WinGetTypeFile (ext)

 

Paramètres

Extension

Extension du fichier dont on cherche l'icone. L'extension ne doit pas comporter le point. Ex : "hop".

  

Retour

Espace

Extension non trouvée, ou pas de type associé

Autre

Le type du fichier

  

Exemple 

module "ysystemex.dhop"

display WinGetTypeFile("doc") --> Document Microsoft Word

display WinGetTypeFile("hop") --> Module Diva
