DirectoryBox  Famille Thème

 

Cette fonction permet d'appeler la boîte de dialogue de sélection des répertoires d'Harmony.

 

Long = DirectoryBox (StructureDirBox, Répertoire)

 
Paramètres

StructureDirBox

Instance de l'enregistrement Edirbox du dictionnaire ddsys.dhsd. Cette structure contient tous les paramètres d'appels de la boîte de dialogue.

Répertoire

Variable alpha recevant en retour le nom du répertoire sélectionné.

 

Retour

FALSE

Pas de répertoire sélectionné

TRUE

Un répertoire a été sélectionné. Son nom est dans Répertoire.
 

Structure EDirBox

Dbtitre

Titre de la boîte de dialogue.

Dbrep

Répertoire à proposer à l'utilisateur.

Dbrepdep

Répertoire de départ. La boîte de dialogue s'ouvre en affichant les sous-répertoires de ce répertoire.

Fbiimpli

Indice dans la liste des chemins implicites de la tâche. Si Dbrepdep (répertoire de départ) n'est pas positionné, la boîte de dialogue s'ouvre en affichant les fichiers du répertoire implicite demandé.

FbFlags

Drapeaux (combinaison des valeurs suivantes par addition)

HAR_NOCHANGEDIR

L'utilisateur n'a pas le droit de changer de répertoire. Le bouton Aller Vers ainsi que le bouton permettant de remonter dans le répertoire parent est caché.

HAR_FILEMUSTEXIST

Le répertoire retourné par la fonction doit obligatoirement exister.

HAR_NOBUTTONIMPLI

Le bouton permettant de modifier les chemins implicites est caché.

HAR_NOCREATEBUTTON

Le bouton permettant de créer un répertoire est caché.

HAR_CHANGEIMPLIONLY

L'utilisateur doit choisir un répertoire dans la liste de ses répertoires implicites. Le bouton Aller Vers est caché.

 
Exemple

record 'ddsys.dhsd' edirbox edb

1 resultat HAR_MAX_PATH

main

edb.dbtitre = "titre"

edb.dbflags = har_nobuttonimpli

edb.dbrepdep = "c:/program files"

edb.dbrep = "microsoft"

if DirectoryBox(edb,resultat)

   display resultat

endif
