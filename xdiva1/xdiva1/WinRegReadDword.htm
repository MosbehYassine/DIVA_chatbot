WinRegReadDword  Famille Thème

La fonction WinRegReadDword permet de lire une valeur entière dans le registre au format REG_DWORD. Quelque soit le type de la valeur dans le registre, cette dernière est convertie en type L.

Cette fonction se trouve dans le module ysystemex.dhop.

  

Long WinRegReadDword (clé, nom_valeur)

 

Paramètres

Clé

Clé dans le registre.

Nom_valeur

Valeur à lire.

  

Retour

La fonction retourne la valeur lue.

Si la clé ou la sous-clé n’existent pas, la fonction retourne zéro.

  

Exemple

module "ysystemex.dhop"

1 i 10,0

main

i=WinRegReadDword("HKEY_CURRENT_USER\Software\DivaltoHarmony\macle","mavaleur")
