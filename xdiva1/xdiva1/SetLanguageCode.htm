SetLanguageCode Famille Thème

 

L'instruction  SetLanguageCode permet de positionner le code langue courant par programme.

 

SetLanguageCode (Code , [ EcranImp ])

 

Paramètre

Code

Code langue.

EcranImp

1 =

Positionnement du code langue pour les affichages. Si les impressions utilisent la même langue que les affichages, le code langue pour les impressions est également positionné.

2 =

Positionnement du code langue pour les impressions.

3 =

Positionnement du code langue pour les affichages et les impressions (valeur par défaut).

 

Remarques

  • Cette instruction est surtout utile pour les programmes Web, afin de permettre à l'internaute de sélectionner une langue.

  • Le code langue positionné par SetLanguageCode concerne la tâche en cours.
    Il se transmet lors de l'enchaînement (ProgramGoto) et de l'appel (ProgrammCall) de programmes.

  • Pour éviter des mélanges de langues dans une même tâche, il est conseillé (voir impératif) d'enchaîner à un autre programme après avoir changé de code langue.

 

Exemple

SetLanguageCode("DE")

ProgramGoto ("Divalto.dhop")
