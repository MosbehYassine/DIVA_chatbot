Xmid  Famille 

 

La fonction Xmid permet d'extraire une sous chaîne d'une chaîne de caractère et de transformer le type de cette sous chaîne en type X (donnée numérique sur 16 bits).
Elle peut se trouver à gauche dans une affectation.


Ptr Xmid (variable , position)


Paramètres

Variable

Le type de la variable est quelconque.

Position

Valeur numérique indiquant la position de début (à partir de 1) de la donnée de type X à extraire.


Retour

La fonction renvoie la sous chaine définie par Position. Le type de retour est toujours le type X.


Exemple

1 arti 15

Xmid(arti,1) = 0xfada 

; positionne la valeur 0xfada dans les deux premiers caractères

; de arti.
