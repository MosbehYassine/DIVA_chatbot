Frewrite  Famille Thème

 

Frewrite réécrit le dernier enregistrement lu dans le fichier.
Cette fonction ne peut être appelée qu'après une lecture (fonctions Fread, Fpread, Fseek2) effectuée généralement en mode réservé.

 

Ptr = frewrite ( tdf , variable [ , pack_auto ] )

Paramètres

Tdf

Table de définition de fichier.

Variable

Donnée à écrire dans le fichier.

Pack_auto

Compression automatique des données si l'enregistrement comporte une zone packée.
0  : non  (par défaut)

1  : oui

 

Retour

0  

Pas d'erreur. 

$03  

Fichier plein (plus de place pour mettre à jour les clés). 

$1D

Pas de lecture préalable dans le fichier 

autres

Code d'erreur système. 

 

Remarques

La réécriture d'un enregistrement n'est possible que pour les fichiers normaux et séquentiels-indexés dont le fichier des données est de type normal (N).

Dans tous les cas, le système prend comme taille d'enregistrement la taille du dernier enregistrement lu, en effectuant une éventuelle troncature ou complémentation à droite par des espaces sur la donnée fournie en paramètre.

Pour les fichiers séquentiels-indexés, le système supprime les clés qui n'existent plus et crée les nouvelles clés.

 

Exemples

;________________________________________________________________
; Fonction : F_REWRITE

; Type : int

; Description : Réécrit l'article art dans le fichier tdf

; et packe automatique

; Paramètres en sortie : 0 = ok # = erreur

;________________________________________________________________
;

Function int F_REWRITE (&tdf , &art)

Record * htdf tdf ;table de définition

1 art A ;article

beginf

cr = frewrite (tdf,art,1) 

switch cr 

case 0 ;ok 

   freturn (0) 

case $03 ; fichier plein 

   MessageBox("Fichier " & left(tdf.name) & " plein"," ") 

default ;erreur système 

   MessageBox("Erreur système numéro " & binhexa (stx (cr)) & \ 

              " en réécriture du fichier " & left(tdf.name)," ") 

endswitch 

freturn(cr) 

endf

 

Modification de l'enregistrement client. L'enregistrement a été lu au préalable en mode P ou F dans la donnée client.

... ; saisie des modifications

; avant fseek2, il n'y a pas besoin de positionner la clé 

; on veut relire le même enregistrement que  

; précédemment 

st = fseek2(fcli , wcli , 'R');

switch st

case 0 ; lecture OK

   stw = frewrite(fcli , client) 

case H_RESERVED ; enreg. réservé

   MessageBox("Enregistrement réservé"," ") 

case H_RECORD_NOT_FOUND ; enregistrement supprimé

   MessageBox("Le client " & client.codcli & \ 

              "n'existe plus"," ") 

endswitch

fpclose(fcli)
