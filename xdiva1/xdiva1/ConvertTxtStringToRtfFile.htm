ConvertTxtStringToRtfFile Famille 

La fonction ConvertTxtStringToRtfFile convertit une chaîne de caractères au format texte dans un fichier Rtf.

 

Long ConvertTxtStringToRtfFile ( rtfFile, txtString, [options] )

  

Paramètres

 

rtfFile

Fichier Rtf résultat


txtString

Chaîne à convertir


Options

Chaine Hmp pour positionner des options (non utilisée pour l'instant)

 

Retour

0 = OK
1 = Erreur (ConvertHtmlRtfLastError permet de récupérer le texte d'erreur)
