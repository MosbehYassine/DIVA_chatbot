Public

Public peut précéder la déclaration

  • d'un fichier par HFile ou HTmpFile

  • d'un enregistrement par Record

  • d'une structure par RecordDiva

  • d'une fonction par Function

  • d'une procédure par Procedure.

A l'exécution, les données publiques sont communes à tous les modules et masques qui ont déclaré ces données avec Public.

Les enregistrements utilisés dans les masques sont toujours publics.

Les fonctions publiques peuvent être appelées depuis un autre module que celui ou elle est définie.
