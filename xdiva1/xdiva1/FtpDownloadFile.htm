FtpDownloadFile Famille Thème

FtpDownloadFileEx

 

Téléchargement d'un fichier depuis un serveur.

 

Module "yftp.dhop"

FtpResult FtpDownloadFile (server, login, password, localFile, remoteFile, [OpenHarmony], [proxyServer], [ProxyMode], [proxyLogin], [proxyPassword])

FtpResult FtpDownloadFileEx (server, login, password, localFile, remoteFile, [OpenHarmony], [proxyServer], [ProxyMode], [proxyLogin], [proxyPassword], [binary], [passive], [keepAlive]

 

Paramètres

Server

Adresse du serveur sous la forme

ftp://ip[:port]  pour un serveur ftp

sftp://ip[:port]  pour un serveur sftp

 

Login

Identifiant sur le serveur. Si non précisé, c'est "anonymous" qui est utilisé. Dans ce cas, le serveur doit accepter les connexions anonymes.

 

Password

Mot de passe sur le serveur.

 

LocalFile

Chemin d'accès au fichier sur l'ordinateur local. Le paramètre OpenHarmony permet de préciser s'il s'agit d'un chemin Harmony ou d'un chemin Windows.

 

RemoteFile

Chemin d'accès au fichier sur le serveur.

 

OpenHarmony

Indique que le chemin LocalFile est au format Harmony (False par défaut). Cette fonctionnalité n'est implémentée que pour Ftp.

 

ProxyServer

Adresse du serveur proxy

 

ProxyMode

Mode d'identification sur le proxy.

1

Prendre les paramètres du système. Il n'y a pas d'autre paramètres à préciser, l'authentification est celle du poste de travail.

2

Préciser l'url du serveur, mais avec authentification SSPI. Inutile de préciser ProxyLogin et ProxyPassword

3

Mode manuel. Il faut préciser tous les paramètres

 

ProxyLogin

Identifiant sur le serveur proxy.

 

ProxyPassword

Mot de passe sur le serveur proxy.

 

Binary

Demande au protocole de travailler ou non en mode binaire. FALSE par défaut. Ce mode est toujours recommandé.

 

Passive

TRUE : le processus client est a l'initiative de la connexion (mode par défaut)

FALSE : le processus client est en attente de connexion

 

KeepAlive

La connexion reste ouverte en vue d'une nouvelle opération avec le même serveur. (TRUE par défaut)

 

Retour

La fonction retourne une structure FtpResult de trois valeurs.

Status

0 = pas d'erreur   2 = Erreur      3 = paramètres incorrects

Retour

Texte renvoyé par la dll

Desc

Texte rendu par le serveur ou description de l'exception en cas d'erreur. Voir aussi FtpGetLastErrorMessage

 

Remarques

  • De nombreux serveurs Ftp / Sftp sont sous Unix ou Linux. Sur ces systèmes d'exploitation, les noms de fichiers sont sensibles à la casse.
    Le paramètre RemoteFile doit donc avoir la casse exacte.

  • En fonction de la configuration du serveur, il se peut que les caractères spéciaux et accentués posent problème.

Exemple

module "yftp.dhop"

recordDiva yftp.FtpResult  r

r = FtpDownloadFile("ftp://psxbdbh02","","","c:/divalto/temp/xrtdiva.exe","xrtdiva.exe")

ProgramExit
