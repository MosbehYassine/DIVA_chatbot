Affectation d'une valeur initiale

 

Le langage Diva permet de donner une valeur initiale à une donnée de niveau 1.

 

Syntaxe

1   var   type = valeur_initiale

 

Valeur_initiale peut être :

  • une constante

  • une expression complexe utilisant des fonctions et/ou des opérateurs.

La valeur initiale est affectée à la donnée :

  • lors du chargement du module, si la donnée est globale

  • lors de l'appel de la fonction/procédure si la donnée est locale

Remarque

Par ce biais, il est possible d'appeler une fonction d'un module au chargement de celui-ci. Il suffit de placer une donnée globale dans ce module qui appelle une fonction d'initialisation.

 

Exemple 1

1    compteur L = 10

1    nom      S = "bruno"

1    lgnom    X = length(nom)

1    liste    L = ListCreate

 

Exemple 2 : Appel d'une fonction d'initialisation dans un module

 

; la fonction MaFonctionInit est appelée au chargement du module

function int MaFonctionInit

beginf

   ..............

   freturn 0

endf

 

1 var_init X = MaFonctionInit
