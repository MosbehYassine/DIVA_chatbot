Fpclose  Famille Thème

 

Fpclose effectue une fermeture partielle de fichier.
A la différence de fclose, le fichier reste ouvert. Fpclose demande au système d'exploitation d'écrire sur le disque tous les blocs modifiés qui se trouvent en mémoire cache. Ainsi le fichier est à l'abri d'un arrêt anormal du programme (panne de courant par exemple) jusqu'à une nouvelle modification.

Tous les enregistrements réservés dans le fichier sont automatiquement libérés.

 

Ptr = fpclose ( tdf )

 

Paramètres

Tdf

Table de définition de fichier.

  

Retour

0  

Pas d'erreur. 

autres

Code d'erreur système. 

 

Exemple

;________________________________________________________________

; Fonction : F_PCLOSE

; Type : int

; Description : Ferme le fichier tdf partiellement

;

; Paramètre en sortie : 0 = ok # = erreur

;________________________________________________________________

;

Function int F_PCLOSE (&tdf)

Record * htdf tdf ;table de définition

beginf

   cr = fpclose (tdf) 

   if cr <> 0  

      MessageBox("Erreur système numéro " & binhexa (stx (cr)) & \ 

           " à la fermeture partielle du fichier " & \ 

           left(tdf.name)," ") 

   endif 

   freturn (cr) 

endf
