Hopen  Famille Thème

 

La fonction Hopen permet d'ouvrir un fichier "à la main". Par défaut les fichiers déclarés par l'instruction HFile sont automatiquement ouverts.

 

Ptr Hopen ( tdf , code_réservation )

 

Paramètres

Tdf

Table de définition de fichier. Le nom du fichier à ouvrir doit être placé au préalable dans la tdf.

Code_réservation

Mode de partage du fichier.

  

Retour

0  

Pas d'erreur.

 

Toutes les erreurs provoquent l'arrêt du programme.

 

Remarques :

Un fichier ouvert doit être fermé avant toute réouverture.

Sous Unix, les noms de fichiers doivent être en caractères minuscules. Harmony ne peut accéder à un fichier unix dont le nom comprend un caractère majuscule. Le nom du fichier à ouvrir placé dans la tdf est automatiquement converti en caractères minuscules.

Si le fichier est de type I (séquentiel-indexé), la clé de la tdf est initialisée à "A". Une lecture (Hread) délivrera donc le premier enregistrement du fichier pour la clé A.

Le champ BaseType de la tdf permet de savoir si le fichier ouvert se trouve dans une base SQL.

 

Exemple :

Record * htdf comp

comp.name = "fcomp.dhfi"

Hopen(comp,"P")
