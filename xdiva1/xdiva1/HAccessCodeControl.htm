HAccessCodeControl  Famille Thème

La fonction HAccessCodeControl permet de vérifier qu'un utilisateur possède un code d'accès.

La base des utilisateurs (xlogf.dhfi) contient pour chaque utilisateur une table de codes d'accès aux objets confidentiels. Un code d'accès est une chaîne alphanumérique de 4 caractères.

La fonction HAccessControl recherche si le code passé en paramètre se trouve dans la liste de l'utilisateur.

La fonction HAccessControl est liée à une Tdf d'un fichier ouvert.

  • Si le fichier est local, la recherche se fait dans la table des codes d'accès qui a été chargée lors de l'identification de l'utilisateur.

  • Si le fichier est sur un serveur Xlan, la recherche se fait d'après la liste des codes d'accès stockés dans la base des utilisateurs (xlogf.dhfi) du serveur.

 

 

Bool HAccessCodeControl (tdf , code , [ utilisateur ])

 
Paramètres

Tdf

Tdf d'un fichier ouvert ou ".".

Dans le cas où ce paramètre vaut le point, la recherche se fait dans la liste des codes qui a été chargée lors de l'identification de l'utilisateur. Si le fichier xlogf.dhfi est sur un serveur, la recherche se fait dans la liste des codes stockée sur le serveur.

 

Code

Code à rechercher dans la liste

 

Utilisateur

Code utilisateur pour rechercher les droits. Par défaut, le code courant de l'utilisateur est utilisé. Ce paramètre permet de vérifier les codes d'accès d'un autre utilisateur que l'utilisateur courant.

Voir FChangeHarmonyUser qui permet de changer de code utilisateur.

 

Retour

TRUE

Le code existe.

FALSE

Le code n'existe pas.

 

Toutes les erreurs provoquent l'arrêt du programme.
 

Exemple

hfile h3fdd fimp tdf

1 st X

1 errsys X

main

if HAccessCodeControl(tdf,"abcd") = FALSE

   MessageBox("Fonctionnalité interdite"," ") 

   ProgramExit 

endif
