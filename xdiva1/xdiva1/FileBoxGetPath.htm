FileBoxGetPath

 

La fonction FileBoxGetPath est utilisée dans la fonction de filtrage liée à la sélection des fichiers (FileBox).

 

char FileBoxGetPath

 

Retour

La fonction retourne le chemin du fichier courant.

 

Exemple

 

; fonction de filtrage pour n'afficher que les dictionnaires de code langue Français

 

function long FiltreEtranger(elt)

record ddsys.dhsd eltdir elt

beginf

record * htdf tdf

record traduction.dhsd e0

record traduction.dhsd e0 e0bis

1 st  X = 0x14

   if elt.flagDir | freturn FALSE | endif

   tdf.name = FileBoxGetPath & '/' & elt.Nom

   if fopen(tdf,'F') = 0

      tdf.key = "A" & CLE_RECONNAISSANCE

      st = fseek(Tdf,e0bis,"F") <> 0

      fclose(tdf)

      if st = 0 and  e0bis.Empreinte <> VALEUR_EMPREINTE

         st = 1;

      endif

      if st = 0 and e0bis.CodeLangue = CODELANGUE_FRANCAIS

         st = 1

      endif

   endif

   freturn st = 0

endf

 

function int SelectionDico

beginf

1 aouvrir 256

1 FonctionFiltre 16

   GetAdressFunction("","FiltreEtranger",FonctionFiltre)

   efb.fbtitre = "Sélection du dictionnaire à traduire"

   efb.fbfiltre = "Dictionnaires|*.dhfi"

   efb.fbifiltre = 1

   efb.fbop    = HAR_FOR_OPEN

   efb.fbflags = HAR_FILEMUSTEXIST

   efb.fbtri   = SORT_BY_NAME

   efb.fbficdep = FileNameLastSegment(m0.FichierEntree)

   efb.fbextdef = ".dhfi"

   efb.Fbrepdep = FileNameBase(m0.FichierEntree)

   if filebox(efb,aouvrir,fonctionFiltre)

      m0.FichierEntree = aouvrir

      freturn TRUE

   else

     freturn FALSE

   endif

endf
