Binhexa  Famille 

 

La fonction Binhexa effectue une conversion de binaire vers hexadécimal.

Voir ToHexa qui est plus pratique à utiliser.

 

Alpha Binhexa (var_binaire)

 

Paramètre

Var_binaire

Donnée contenant une valeur en binaire. Pour afficher le contenu en hexadécimal d'une donnée de type X ou L il faut préalablement utiliser les fonctions Ldx ou Ldxl 

 

Retour

La fonction retourne une chaîne de caractères hexadécimale. Sa taille est le double de la taille de var_binaire.

Exemple

Affichage d'un code d'erreur rendu par une fonction de gestion de fichier.

1 st X

 

st = Fopen(tdf)

If st <> 0 

   Display "Erreur " & Binhexa(Ldx(st)) & \ 

           " à l'ouverture du fichier" 

Endif
