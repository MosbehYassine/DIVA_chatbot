DataDec

La fonction DataDec permet de connaître le nombre de décimales d'une donnée.

 

Long DataDec (Donnée)

 

Retour

DataDec retourne le nombre de décimales de donnée.

 

Remarque

Cette fonction peut être utile dans les fonctions/procédures pour connaître le format exact d'un paramètre formel.

 

Exemple

Procedure proc(p1)

1 p1 N

1 nbdec 2,0

beginp

   nbdec = DataDec(p1) 

   display nbdec 

endp

1 v1 3,0

1 v2 8,2

1 v3 X

1 v4 L

main

proc (v1) 

proc (v2) 

proc (v3) 

proc (v4) 

Ce programme affiche les valeurs suivantes : 0 2 0 0
