WinDivaltoGlobalReadString - WinDivaltoReadString Famille Thème

La fonction WinDivaltoReadString permet de lire une chaîne dans le registre, sous la clé "HKEY_CURRENT_USER\SOFTWARE\Divalto\divalto.ini\"

La fonction WinDivaltoGlobalReadString permet de lire une chaîne dans le registre, sous la clé "HKEY_LOCAL_MACHINE\SOFTWARE\Divalto\divalto.ini\"

 

Ces fonctions se trouvent dans le module ysystemex.dhop.

 

Alpha WinDivaltoReadString (section, entrée)

Alpha WinDivaltoGlobalReadString (section, entrée)

 

Paramètres

Section

Sous chemin dans le registre.

Entrée

Nom de la valeur à lire.

 

Retour

La fonction retourne la valeur lue dans le registre. Si la valeur n'existe pas, la fonction retourne espaces.
