WinDeleteProfile  Famille Thème

 

La fonction WinDeleteProfile permet de supprimer une entrée dans un fichier .ini.

Attention, le fichier divalto.ini est géré de manière particulière. Voir le chapitre divalto.ini de la documentation Installation et paramétrage d'Harmony.

  

Ptr WinDeleteProfile (section, entrée, fichier)

 

Paramètres

Section

Nom de la section du fichier .ini. Dans un fichier .ini, une section est un mot encadré par les crochets [ ]. Ne pas mettre les crochets dans ce paramètre.

Entrée

Entrée (ou mot-clé) dans la section.

Fichier

Nom du fichier .ini.

 

Retour

TRUE

Pas d'erreur.

FALSE

Erreur. Appelez la fonction WinGetLastError pour connaître le détail de l'erreur.

  

Exemple

display WindeletePROFILE("Section","Monentree","monfichier.ini")

; suppression de l'entrée Monentree dans le chapitre Section du

; fichier monfichier.ini
