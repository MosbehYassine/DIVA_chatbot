GetModulesNames  Famille Thème

 

La fonction GetModulesNames retourne une chaîne HMP contenant la liste de tous les modules chargés par le programme.

Les modules qui ont été déchargés par la fonction de réinitialisation de Ymig sont également présents dans cette liste.

 

Char GetModulesNames

 

Retour

La fonction retourne une chaîne Hmp avec le paramètre <module>xxxxx  pour chaque module chargé.
