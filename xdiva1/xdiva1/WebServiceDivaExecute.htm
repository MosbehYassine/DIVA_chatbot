WebServiceDivaExecute Famille  Thème

WebServiceDivaExecute permet d’appeler un service web Diva ; il s'agit d'un programme Diva exécuté sur le serveur Web.

La description complète des services Web Diva fait l’objet d’un livre spécifique. Pour l'écriture d'un service Web Diva voir le guide d'utilisation au chapitre Services Web. 

 

Long WebServiceDivaExecute (url , action_hmp , parametres_hmp, resultat)

 

Paramètres

Url

URL du service Web Diva à exécuter.

Action_hmp

Action à effectuer.
L’action est une chaîne <hmp> qui contient obligatoirement le paramètre <action>

L’action fait référence au fichier paramètre des actions des services, qui contient notamment pour chaque action le nom du programme diva à exécuter.
L’action ne doit pas être cryptée.

Parametres_hmp

Paramètres à passer au service Diva sous le forme de chaîne HMP. La fonction Crypt permet de crypter les paramètres. Ils devront être décryptés par la fonction UnCrypt .
Si vous ne cryptez pas vos paramètres utilisez la fonction HmpEncode pour encoder les valeurs.

Resultat_hmp

Résultat retourné par le service web. Si le résultat est crypté par le service Web il faut le décrypter par la fonction UnCrypt .

 

Retour

0

Pas d’erreur

1

Exception Soap. Resultat_Hmp contient le texte de l’erreur.

2

Exception Web. Resultat_Hmp contient le texte de l’erreur.

3

Autre Exception. Resultat_Hmp contient le texte de l’erreur

0x23xx

Code d’erreur renvoyé par le programme Diva xwebservices.dhop.
Resultat_Hmp contient le texte de l’erreur

Autre

Code d’erreur renvoyé par le programme Diva lancé par xwebservices.dhop.
Resultat_Hmp contient le texte de l’erreur

 

Exemple

1 retour S

1 st L

1 cryptee S

 

cryptee = Crypt("<param1>p1<param2>p2","monmotdepasse",st)

st= WebServiceDivaExecute("http://localhost/WebServiceDiva/WebServiceDiva.asmx", \

                          "<action>sanscalcaire", \ 

                          ,cryptee,retour)

 

if st <> 0  ; en cas d'erreur (service inconnu par ex) retour contient le message

   MessageBox(retour ," ") 

else

   display retour 

endif
