Exécution d’un programme Diva dans un navigateur depuis une URL

 

L’exécution d’un programme Diva dans un navigateur en invoquant une URL est une fonctionnalité offrant des perspectives de développement très vaste. Par exemple, l’envoi d’un mail avec une URL permettant au destinataire, par un simple clic, d’accéder à l’ensemble des fonctionnalités de l’ERP (valider une commande ou une demande de congés, consulter un événement, etc.).

Pour sécuriser l’accès à l’ERP, l’Url commence par une phase d’authentification de l’utilisateur. Certaines informations, comme le profil ou l’identifiant, peuvent être pré-garnies.

 

Deux modes d’exécution du programme sont disponibles :

  1. Le mode "call".
    Le programme s’exécute dans une fenêtre pop-up. La page de login reste affichée avec une image générique.
    Ce mode est à privilégier car la barre de boutons du navigateur n’est pas affichée dans la fenêtre pop-up.

  2. Le mode "goto".
    Le programme s’exécute directement dans la page d’accueil.
    Ce mode n'est pas recommandé car la barre de boutons du navigateur reste affichée dans la page d'accueil et ne doit pas être utilisée.

L’Url peut comporter des paramètres transmis au programme appelé.

 

Contraintes

  • Les programmes qui peuvent être lancés depuis une Url doivent obligatoirement figurer au menu de l'erp (éventuellement en mode masqué) car c'est le menu qui met en place le contexte d’exécution.

  • L’erp doit être au minimum en version X.1.

 

Mise en oeuvre

Pour lancer un choix du menu, il faut connaître son identifiant unique. Cet identifiant est composé de 3 éléments :

  • Son identifiant d’application.
    La table MAPPLIC permet de connaître les identifiants des différentes applications.

  • Son regroupement.
    Le regroupement est visible dans le tableau des choix du menu, accessible via la touche F4 de l’IA.

  • Son numéro d'ordre.
    Le numéro d'ordre est visible dans le tableau des choix du menu, accessible via la touche F4 de l’IA.

Exemple : Pour lancer le zoom Articles, il faut les informations suivantes : Application DAV, Regroupement FIC, Ordre 10.

 

Construction de l’URL

L’Url doit contenir toutes les informations nécessaires au lancement du programme.

  • Paramètres obligatoires :

    • urlDivaMode : mode d’appel (1 : mode "call" - 2 : mode "goto").

    • urlDivaParamc : conteneur des paramètres.

    • urlDivaProgram : programme à lancer (obligatoirement "ia.dhop").

    • urlDivaParams : information sur le choix du menu à lancer, au format :
                             "[LaunchProgram]{_Application}DAV{_Regroupement}FIC{_Ordre}10"
                             (les valeurs en italique sont des valeurs d'exemple).
       

  • Paramètres facultatifs :

    • urlDivaUser : nom d’utilisateur Windows.

    • urlDivaPwd : mot de passe Windows en clair.

    • urlDivaHarmonyUser : nom d’utilisateur Harmony.

    • urlDivaHarmonyPwd : mot de passe Harmony en clair.

    • urlDivaUserProfile : profil utilisateur.

 

Exemple d’Url générée en javascript (nécessite jquery)

L’exemple ci-dessous est le minimum pour lancer un programme. Attention, une partie des paramètres doit être convertie en base 64.


$(document).ready(function () {

    var url = 'http://localhost:8090/lcweb/default.aspx';

    url += "?urlDivaMode=1&";

    url += "urlDivaParamc=";

 

    var pp = "";

    pp += "urlDivaProgram=ia.dhop&";        

    pp += "urlDivaParams=[LaunchProgram]{_Application}DAV{_Regroupement}FIC{_Ordre}10";

    // codage en base 64

    if (window.btoa)

        url += encodeURIComponent(window.btoa(pp));

    else

        url += encodeURIComponent($.base64.encode(pp));

 

    // écriture de l’url sur la page

    document.write("<a href=\"" + url + "\">" + url + "</a>");

});


 

Paramètres complémentaires

Pour envoyer d’autres informations au programme appelé, il est possible de compléter l’attribut "urlDivaParams".

Attention, les séparateurs HMP à utiliser sont obligatoirement "[" et "]".


Dans le programme Diva, on récupère ces informations dans la variable d’environnement "WEBPARAM". Il faut lire la balise "URLDIVAPARAMS".


Exemple :

pp += "urlDivaParams=[LaunchProgram]{_Application}DAV{_Regroupement}FIC{_Ordre}10[numero_commande]12345";


Programme Diva :

1 numero_commande S

1 urldivaparams S

1 env S

Env = GetEnv ("WEBPARAM")

Urldivaparams = HmpSeek (env, "URLDIVAPARAMS")

Numero_commande = HmpSeek (Urldivaparams, "numero_commande")
