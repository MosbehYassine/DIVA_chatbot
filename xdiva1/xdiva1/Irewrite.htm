Irewrite  Famille Thème

Irewrite réécrit le dernier enregistrement lu dans le fichier.
Cette fonction ne peut être appelée qu'après une lecture effectuée généralement en mode réservé.

 

Ptr = Irewrite ( tdf , table)

Paramètres

Tdf

Table de définition de fichier.

Table

Donnée à écrire dans le fichier.

 

Retour

0  

Pas d'erreur.

Si une procédure Avant Rewrite est définie dans le dictionnaire, elle est appelée.

Les paramètres passés à la procédure Avant Rewrite sont :

Tdf

La Tdf du fichier.

Table

L'enregistrement qui a été lu.
 

 

  

Toutes les erreurs provoquent l'arrêt du programme.

 

Remarques

La réécriture d'un enregistrement n'est possible que pour les fichiers normaux et séquentiels-indexés dont le fichier des données est de type normal (N).

Dans tous les cas, le système prend comme taille d'enregistrement la taille du dernier enregistrement lu, en effectuant une éventuelle troncature ou complémentation à droite par des espaces sur la donnée fournie en paramètre.

Lors de la réécriture d'un enregistrement comportant une zone packée, les données dépackées sont compressés dans la zone packée et l'écriture se fait automatiquement sur le champ Write de l'enregistrement. La zone dépackée n'est donc pas écrite dans le fichier (Voir Record).

 

Exemple

Modification de l'enregistrement client. L'enregistrement a été lu au préalable en mode P ou F dans la donnée client.

... ; saisie des modifications

st = Iseek(fcli , wcli , "CODECLIENT" , fcli.keyValue, 'R')

switch st

case 0 ; lecture OK

   stw = Irewrite(fcli , client) 

case H_RESERVED ; enreg. réservé

    MessageBox("Enregistrement réservé"," ")

case H_RECORD_NOT_FOUND ; enregistrement supprimé

    MessageBox("Le client " & client.codcli & \ 

                "n'existe plus"," ")

endswitch

Hpclose(fcli) ; force l'écriture physique
