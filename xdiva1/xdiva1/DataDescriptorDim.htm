DataDescriptorDim

 

DataDescriptorDim permet de savoir si un descripteur obtenu par DataDescriptor correspond à une donnée indicée (tableau).

Elle fourni le nombre de dimensions du tableau.

 

Long DataDescriptorDim (descripteur)

 

Descripteur

Descripteur  obtenu par la fonction DataDescriptor.

Attention, lors de l'appel de DataDescriptor, la donnée doit être suivie de () pour être considérée comme un tableau. Voir l'exemple ci-dessous.

 

Retour

La fonction retourne le nombre de dimensions.

 

Exemple

 

1 desc    S

1 i       3,0

1 nbdim   3,0

1 nom     10

1 tableau 2*3*4

 

; nom n'est pas un tableau, DataDescriptor renvoie une erreur

st = DataDescriptor("nom()",desc)                    

 

; ne pas oublier () après le nom de la variable

st = DataDescriptor("tableau()",desc)

if st = 0

   nbdim = DataDescriptorDim(desc)

   for i = 1 to nbdim

      display i & '->' & tostring(DataDescriptorIndex(desc,i))

   next

endif

; affiche  1->3  2->4

 

; accès à une case

DataDescriptor("tableau(1,2)",desc)

DataValue(desc) = "12"

display tableau(1,2)      ; affiche 12
