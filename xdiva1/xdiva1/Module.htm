Module  Famille Thème

 

Module nom

La déclarative Module permet de déclarer un module externe. Toutes les fonctions/procédures publiques du module peuvent alors être utilisées.

A l'exécution, le module sera chargé lors du premier appel d'une de ses fonctions/procédures.

Paramètres

Nom

Nom (objet compilé) du module externe.

 

Exemple

Module "Gfcli.dhop" 

 

Cas particulier des surcharges multiples

Dans le cadre des surcharges multiples, il est possible de préciser le nom de l'add-on. Dans ce cas, la déclaration doit être suivie de AS alias.

Exemple :

module addon1.modulegttmfic.dhop   as addon1_modulegttmfic

module addon2.modulegttmfic.dhop   as addon2_modulegttmfic

; ensuite l'alias remplace le nom du module

addon2_modulegttmfic.gttmfic_Proc1   : appel de Proc1 du module modulegttmfic.dhop de l'add-on 2
