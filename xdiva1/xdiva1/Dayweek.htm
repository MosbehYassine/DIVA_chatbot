Dayweek  Famille Thème

 

La fonction Dayweek calcule à partir d'une date le numéro du jour dans la semaine.


Ptr Dayweek (date)


Paramètres

Date

Donnée de type date.


Retour

La fonction retourne le numéro du jour dans la semaine

1 : Lundi

2 : Mardi

3 : Mercredi

4 : Jeudi

5 : Vendredi

6 : Samedi

7 : Dimanche

Exemple

display dayweek("19980728") ; affiche 2
