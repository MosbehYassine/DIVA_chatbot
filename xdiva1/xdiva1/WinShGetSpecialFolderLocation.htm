WinShGetSpecialFolderLocation  Famille Thème

 

La fonction WinShGetSpecialFolderLocation permet d'obtenir l'emplacement d'un dossier "spécial" de Windows.

Alpha WinShGetSpecialFolderLocation (Numéro)

 

Paramètres

Numéro

Valeur indiquant le chemin demandé. Ce paramètre peut être l'une des valeurs suivantes :

CSIDL_BITBUCKET 

Spécifie le chemin de la corbeille. L'emplacement de ce répertoire n'est pas dans le registre ; il a les attributs caché et système pour éviter que l'utilisateur le déplace ou le détruise.

CSIDL_CONTROLS 

Dossier du panneau de contrôle.

CSIDL_DESKTOP 

Dossier du bureau de Windows.

CSIDL_DESKTOPDIRECTORY 

Répertoire utilisé pour le stockage physique des objets du bureau. Ne doit pas être confondu avec le dossier du bureau.

CSIDL_DRIVES

Dossier Poste de travail. Contient tous les éléments de l'ordinateur (disques, imprimantes, panneau de contrôle).

CSIDL_FONTS 

Dossier virtuel contenant les fontes de caractères.

CSIDL_NETHOOD 

Répertoire contenant les objets qui apparaissent dans le Voisinage Réseau.

CSIDL_NETWORK

Dossier virtuel du voisinage réseau représentant le sommet de la hiérarchie du réseau.

CSIDL_PERSONAL

Répertoire servant de stockage aux documents personnels (Mes documents).

CSIDL_PRINTERS

Dossier contenant les imprimantes installées.

CSIDL_PROGRAMS

Répertoire contenant les groupes de programmes du menu Démarrer.

CSIDL_RECENT 

Répertoire contenant les documents récemment modifiés.

CSIDL_SENDTO 

Répertoire contenant les destinations pour la fonction Envoyer Vers.

CSIDL_STARTMENU 

Répertoire contenant le menu démarrer.

CSIDL_STARTUP 

Répertoire contenant les fichiers du groupe de démarrage.

Retour

Espaces

Erreur.

Autre

Chemin demandé.

 

Remarque

Le fonction ne renvoie pas toujours une valeur pour chacune des constantes CSIDL. Cela dépend du système d'exploitation ainsi que de la version.

 

Exemple

Affichage du chemin du répertoire servant au stockage aux documents personnels (Mes documents).


 display WinShGetSpecialFolderLocation(CSIDL_PERSONAL)
