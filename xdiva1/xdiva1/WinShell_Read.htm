WinShell_Read Famille Thème

 

Cette fonction permet de lire l'état d'un fichier passé en premier paramètre et précédemment lancé par WinShell_Execute.

 

long WinShell_Read (&FichierOrigine, &err, &flagmodif, &flagencours, &diff)

 

Paramètres

 

FichierOrigine

Alphanumérique

Nom du fichier à scruter.

err

Alphanumérique

Message d'erreur.

flagmodif

X

Flag de retour, indique si le fichier a été modifié.

flagencours

X

Flag de retour, indique si le fichier est en cours d'utilisation.

diff

L

variable de sortie, différence entre la date de dernière modification à la fermeture et la date de dernière modification à l'ouverture.

 

 

Retour

La fonction WinShell_Read retourne le statut du fichier

 

0

Fin de la liste.

1

Le fichier est fermé

2

La liaison DDE est fermée.

3

Le fichier est en erreur.

4

Le fichier est en cours d'utilisation.

5

Le fichier est en cours d'utilisation.

 

Outre le statut, les variables en sortie permettent de récupérer des informations complémentaires (comme décrit dans la liste des paramètres).

Le paramètre diff récupère la différence entre la date de dernière modification à la fermeture et la date de dernière modification à l'ouverture. Celle-ci peut servir dans certains cas particulier : Excel, par exemple, change la date de dernière modification lorsqu'il ouvre un fichier. A la fermeture, si aucune modification n'a été faite, il rétabli la date de dernière modification précédente, mais pas de manière exacte. WinShell_Read utilise alors cette différence pour déterminer si le fichier a été modifié (si cette différence est inférieure, en valeur absolue, a une valeur seuil interne, on peut raisonnablement accepter que le fichier n'a pas été modifié).

 

Dans les cas usuels, seuls la valeur de retour et les flags flagmodif et flagencours sont à considérer.
