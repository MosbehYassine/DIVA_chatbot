OpenXml_Read  Famille  Theme

 

La fonction OpenXml_Read lit le contenu d'une cellule de la feuille courante.

 

char OpenXml_Read (lig, col)

 

Paramètres

Lig

Numéro de ligne

Col

Numéro de colonne

 

Retour

La fonction retourne le texte contenu dans la cellule.

Les données de type date sont toujours au format AAAAMMJJ, quel que soit le format d'affichage des dates.

Les données de type datetime sont toujours au format AAAAMMJJHHMMSS, quel que soit le format d'affichage des datetimes

La donnée Diva réceptrice peut être de type S.
