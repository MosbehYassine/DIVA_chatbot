StringContent  Famille Thème  

La fonction StringContent permet d’accéder à la chaîne de caractères d’une donnée de type String. Elle est rarement utilisée, car le compilateur la génère automatiquement lors de l’utilisation d’une donnée de type String.

Alpha StringContent (variable)

Variable

Donnée de type String.

 

Retour

La fonction retourne la chaîne de caractères de la donnée de type String.
