HStat

La stucture Hstat du dictionnaire ddsys.dhsd est utilisée par les fonctions Fstatfile, Statfile, Fmodstat.

Elle contient les champs suivants :

Donnée

Type

Commentaire

Taillef

B8

Taille du fichier en binaire (64 bits). C'est la taille que le fichier a sur le disque. La fonction Bindec permet convertir ce nombre en décimal.

Rtaillef

B8

Taille réelle du fichier Harmony. La taille de l'entête spécifique d'Harmony est soustraite de la taille. La fonction Bindec permet convertir ce nombre en décimal.

Nom

256

Nom du fichier

TypeF

1

Type U N I (ne permet pas de distinguer les séquentiels-indexés étendus des séquentiels-indexés non étendus.

VraiType

1

I pour les séquentiels indexés non étendus
J pour les séquentiels indexés étendus

Partage

B

1 si le fichier est au format réseau, c'est à dire que le fichier est utilisable en réseau poste à poste.

Nat

1

Nature (non utilisé)

Protect

1

Protection (R W)

Locki

1

Séquentiel indexé en erreur $01 (à réorganiser)

Uread

2

Confidentialités en lecture

Uwrite

2

Confidentialités en écriture

Uerase

2

Confidentialités pour l'effacement

Lge

X

Taille des enregistrements (0=taille variable)

Datem

Date (8)

Date de dernière modification au format AAAAMMJJ

Timem

Heure(6)

Heure de dernière modification au format HHMMSS

Dtcreate

B8

Date + heure de création au format système. Pour convertir, utilisez WinConvertFileTime

Dtacces

B8

Date + heure du dernier accès au format système. Pour convertir, utilisez WinConvertFileTime

Dtwrite

B8

Date + heure de la dernière modification au format système. Pour convertir, utilisez WinConvertFileTime

RdtCreate

B8

Date + heure de création. Les octets sont stockés des poids forts vers les poids faibles. Cela permet de comparer directement deux dates+heures.

Rdtaccess

B8

Date + heure du dernier accès. Les octets sont stockés des poids forts vers les poids faibles. Cela permet de comparer directement deux dates+heures.

Rdtwrite

B8

Date + heure de la dernière modification. Les octets sont stockés des poids forts vers les poids faibles. Cela permet de comparer directement deux dates+heures.

Coderr

X

Code d'erreur complémentaire. Valeur de errno.

Version

4

Version du fichier (voir Version des fichiers )

Ctrlrel

B

1 si l'option "Toujours contrôler la version" est cochée (voir Version des fichiers )

Compresse

B

1 si le fichier est compressé par FileCompress, 0 sinon.

ReadOnly

B

1 si le fichier est en lecture seule.

Farchive

B

1 si le fichier a la propriété Archive

Fhidden

B

1 si le fichier est caché

Fsystem

B

1 si le fichier est marqué comme fichier système.

DicoNom

32

Nom du dictionnaire contenant la description du fichier (fichiers I)

DicoMnemo

32

Mnémonique du fichier dans le dictionnaire (fichiers I)
