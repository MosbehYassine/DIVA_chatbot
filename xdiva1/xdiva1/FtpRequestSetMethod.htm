FtpRequestSetMethod Famille Thème

 

Positionnement de la méthode Ftp et des paramètres complémentaires.

 

int FtpRequestSetMethod  ( Ticket , Methode , Fichier,  [ FichierHarmony ] , [ TimeOut ] )

 

Paramètres

Ticket

Identifiant de la requête obtenu par FtpRequestNew

 

Méthode

Nom de la méthode.

En Ftp toutes les méthodes suivantes peuvent être appelées :

DownloadFile = "RETR";

ListDirectory = "NLST";

UploadFile = "STOR";

DeleteFile = "DELE";

AppendFile = "APPE";

GetFileSize = "SIZE";

UploadFileWithUniqueName = "STOU"

MakeDirectory = "MKD";

RemoveDirectory = "RMD";

ListDirectoryDetails = "LIST";

GetDateTimestamp = "MDTM";

PrintWorkingDirectory = "PWD";

Rename = "RENAME";

En Sftp, seules les méthodes suivantes peuvent être appelées :

UploadFile = "STOR";

DownloadFile = "RETR";

Rename = "RENAME";

MakeDirectory = "MKD";

RemoveDirectory = "RMD";

DeleteFile = "DELE";

 

Fichier

Nom du fichier local pour les commandes de transfert.

Nouveau nom du fichier ou du répertoire en cas de renommage.

 

Retour

0

Pas d'erreur

1

Ticket incorrect

2

Exception. Voir FtpRequestGetError
