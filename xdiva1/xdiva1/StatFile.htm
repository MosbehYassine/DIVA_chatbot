StatFile  Famille Thème

 

StatFile permet de lire les caractéristiques d'un fichier non ouvert.

Voir également FstatFile qui lit les caractéristiques d'un fichier ouvert.
 

Ptr = StatFile (Nom , Hstat)

 
Paramètres

Nom

Nom de fichier. 

Hstat

Instance de l'enregistrement HStat du dictionnaire ddsys.dhsd qui reçoit les caractéristiques du fichier.

Retour

0

Pas d'erreur.

Autre

Code d'erreur système.



Exemple

record 'ddsys.dhsd' hstat

1 st  X

main

st = StatFile("/Divalto/sys/ftestj.dhfi",hstat)

display bindec(hstat.taillef) ; taille sur le disque

display bindec(hstat.rtaillef) ; taille des données

display hstat.vraitype ; type I ou J

display hstat.timem ; heure de modification

display hstat.datem ; date de modification

display Winconvertfiletime(hstat.dtwrite) ; date+heure de
