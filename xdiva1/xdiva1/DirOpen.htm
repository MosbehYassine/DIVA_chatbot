DirOpen  Famille Thème

 

La fonction DirOpen ouvre un répertoire. Les noms des fichiers peuvent ensuite être lus par la fonction DirRead. Ensuite le répertoire doit être fermé par un appel à DirClose.

Long DirOpen (opdir)

Paramètres

Opdir

Instance de l'enregistrement Opdir du dictionnaire ddsys.dhsd.
Les champs suivants doivent être renseignés :

Racine

Chemin du répertoire à ouvrir.

Prefixe

Préfixe des fichiers à lire (par ex : * s*)

Tri

Sens de tri des fichiers
1 = par nom
2 = inutilisé
3 = par date
4 = par taille

Attributs

Ce champ permet de filtrer les noms fichiers en fonction d'un ou plusieurs attributs.

Il est une combinaison des valeurs suivantes :

FILE_ATTRIBUTE_READONLY

FILE_ATTRIBUTE_HIDDEN    

FILE_ATTRIBUTE_SYSTEM  

FILE_ATTRIBUTE_ARCHIVE    

FILE_ATTRIBUTE_NORMAL    

FILE_ATTRIBUTE_TEMPORARY

MontrerCaches

Les fichiers qui ont l'attribut caché (FILE_ATTRIBUTE_HIDDEN) sont rendus par la fonction (par défaut ils ne sont pas rendus)

TestAttributs

Indique le test à effectuer pour filtrer selon les attributs.
1 = Le fichier doit avoir tous les attributs spécifiés dans le champ Attributs.
0 = Le fichier ne doit avoir aucun des attributs spécifiés dans le champ Attributs.
 

Cet enregistrement est garni en retour. Il doit être gardé et sera passé en paramètre dans les autres fonctions de lecture des fichiers.

Retour

0

Pas d'erreur.

$50

Répertoire absent.

$5e

Trop de répertoires ouverts simultanément par le programme.

Autres

Erreurs système.
 

Exemple 1

; lecture du répertoire /Divalto/sys en filtrant les fichiers qui ont l'attribut Archive.

record 'ddsys.dhsd' OPDIR OP

record 'ddsys.dhsd' ELTDIR EL

1 car 1

1 st X

main

op.racine = "/Divalto/sys" 

op.prefixe = "*"

op.tri = 4

op.Attributs =  FILE_ATTRIBUTE_ARCHIVE

op.TestAttributs = "1"

st = DirOpen(op)

if st

   Display "Erreur " & binhexa(ldx(st)) & " lors de l'ouverture" 

   ProgramExit

endif

loop DirRead(op,el) = 0

   display left(el.nom) & el.taillefd & el.heurecre 

   if getchar()

      loop not getchar ()

      endloop

   endif 

endloop

DirClose(op)

programexit

 

Exemple 2

; Parcours récursif de tous les sous-répertoires

 

procedure Parcours(rep)

1 rep A

1 st  X

record 'ddsys.dhsd' OPDIR OP1

record 'ddsys.dhsd' ELTDIR EL

beginp

op1.racine = rep  

op1.prefixe = "*"

op1.tri = 1 

st = DirOpen(op1) 

if st

   Display "Erreur " & binhexa(ldx(st)) & " lors de l'ouverture" 

   Preturn 

endif 

display rep 

loop DirRead(op1,el) = 0

   if (el.flagdir)

      if getchar()  

         loop not getchar ()

         endloop 

      endif 

      Parcours(left(rep) & '/' & left(el.nom)) 

    endif

endloop 

Dirclose(op1) 

endp

main

Parcours("c:")
