FileUncrypt  Famille Thème

FileUncrypt permet de décrypter un fichier crypté par FileCrypt .


Ptr = FileUncrypt (fichier_départ , fichier_arrivée, clé , code_système, [flag])


Paramètres

Fichier_départ

Nom du fichier comprimé à décrypter.

Fichier_arrivée

Nom du fichier decrypté. Si ce fichier n'existe pas, il est automatiquement créé. Le fichier d'arrivée doit obligatoirement être distinct du fichier de départ.

Clé

Clé de cryptage. Cette clé doit être bien évidemment la même que celle qui a servi au cryptage.

Code_système

Donnée numérique qui reçoit un code d'erreur système.

Flag

Booléen (TRUE par défaut) indiquant l'opération à effectuer si le fichier de départ n'est pas un fichier crypté.
TRUE : le fichier de départ est recopié tel que.

FALSE : le fichier de départ n'est pas recopié et la fonction retourne une erreur.

 
Retour

La fonction retourne un code d'erreur principal et un code d'erreur système.

Voir Codes d'erreurs des fonctions de cryptage et de compression .

 
Remarque

Si le fichier d'origine est vide, le fichier destination est toujours créé.

 

Exemple

 1 st X

 FileUnCrypt("e:/Divalto/tmp/crypte.dhsp","e:/Divalto/tmp/decrypte.dhsp","macledecryptage",st)
