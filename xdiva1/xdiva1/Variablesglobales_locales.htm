Variables globales/locales

variable globale

Toutes les variables définies dans un module hors d'une fonction ou d'une procédure sont globales, c'est-à-dire qu'il est possible de les utiliser à l'intérieur des fonctions et des procédures.

 

variable locale

Toutes les variables définies à l'intérieur d'une fonction ou d'une procédure sont locales à la fonction ou à la procédure, c'est-à-dire qu'elles ne sont pas utilisables hors de la fonction ou de la procédure où elles sont déclarées.

Les variables locales ne sont allouées qu'au moment de l'appel de la fonction ou de la procédure. Lors du retour au programme appelant, l'espace mémoire où elles avaient été implantées est libéré.

Les variables locales peuvent avoir le même nom qu'une variable globale. Dans ce cas, c'est toujours la variable locale qui est prise par le compilateur, la variable globale devenant inaccessible dans la fonction/procédure.

 

Exemples

Toujours sur la même procédure qui affiche le carré d'une valeur.

1 valeur 24,10

Procedure Carre(i)

1 i 24,10

Beginp

   valeur = i * i 

   Display [ 'le carré est : ' valeur ] 

endp

 

et le programme principal :

 

input 'Donnez la valeur : ' valeur

carre (valeur)

display [ 'La valeur est : ' valeur ]

A l'exécution pour valeur = 10 ce programme va afficher :
Le carré est : 100
La valeur est : 100

En effet, la procédure carré utilise la variable globale valeur et provoque ainsi un effet de bord désagréable.

Il suffit de rajouter une déclaration dans la procédure pour que notre programme soit à nouveau correct :

1 valeur 24,10

Procedure Carre(i)

1 i 24,10

1 valeur 24,10

Beginp

   valeur = i * i 

   Display [ 'le carré est : ' valeur ] 

endp

 

et le programme principal :

input 'Donnez la valeur : ' valeur

carre (valeur)

display [ 'La valeur est : ' valeur ]

A l'exécution pour valeur = 10 ce programme va afficher :
Le carré est : 100
La valeur est : 10
