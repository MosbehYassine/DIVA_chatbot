OpenXml_FileOpen  Famille  Theme

 

La fonction OpenXml_FileOpen charge un fichier .xlsx.

 

Int OpenXml_FileOpen (fic, [creation], p1)

 

Paramètres

Fic

Nom complet du fichier .xlsx, au format Windows.

 

Creation

0 : Ne pas créer le fichier s'il n'existe pas (valeur par défaut).

1 : Créer le fichier s'il n'existe pas.

 

P1

0 : Ouverture en lecture / écriture.
1 : Ouverture en lecture seule (le fichier reste partageable avec d’autres programmes Diva qui consulteraient ce même fichier).

 

Retour

0

Pas d'erreur.

1

Erreur. Voir la fonction OpenXml_GetMsgError.
