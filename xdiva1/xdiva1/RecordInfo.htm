Record Info  Famille  Thème

La structure RecordInfo du dictionnaire H3fdd est utilisée par la fonction DDGetRecord3 qui permet de lire les caractéristiques d'un enregistrement dans le dictionnaire.

Les champs de RecordInfo sont :

nom

Commentaire

type

Contient la lettre R

niveau

Niveau

mnemo

Mnémonique

librecord

Commentaires

dtcreat

Date de création

dtmodif

Date de modification

cdutil

Code utilisateur

conf1

Confidentialités aff/imp

conf2

Confidentialités mod/sup

taillerec

Taille sans zone packée

nbchamps

Nombre de champs

enrfiller1

Filler

valce

Valeur du code enregistrement

posce

Position du code enregistrement

taillemem

Taille en mémoire

pospack

Position de la zone packée

lgpack

Taille de la zone packée
