DataSize

La fonction DataSize permet de connaître la taille d'une donnée.

 

Long DataSize (Donnée)

 

Retour

DataSize retourne la taille d'une donnée. La taille est indépendante du contenu, il s'agit de la taille spécifiée à la déclaration de la donnée.

Pour une donnée de type String, la fonction renvoie la taille allouée pour la chaîne de caractères, indépendamment de son contenu.

 

Remarques

Cette fonction peut être utile dans les fonctions/procédures pour connaître le format exact d'un paramètre formel.

Pour connaître la taille d'un élément de tableau, le nom du tableau doit être suivi de (). Si ce n'est pas le cas, la fonction retourne la taille totale du tableau.

 

Exemple

Procedure proc(p1) ; donnée simple

1 p1 U

1 taille 8,0

beginp

   taille = DataSize(p1)

   display taille 

endp

 

Procedure proc1(&p1) ; tableau

1 p1 U*1

1 taille   8,0

beginp

   taille = DataSize(p1())  ; taille d'un élément 

   display taille 

endp

 

1 v1 3,0

1 v2 8,2

1 v3 X

1 v4 L

1 tab 5,0*1000

main

proc (v1) 

proc (v2) 

proc (v3) 

proc (v4) 

proc (tab) 

proc1(tab()) 

Ce programme affiche les valeurs suivantes : 3 8 2 4 5000 5
