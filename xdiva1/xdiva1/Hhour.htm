Hhour Famille Thème

La fonction Hhour permet de faire des opérations sur une donnée de type Date+Heure.

Une donnée de type Date+Heure est une donnée alphanumérique de 14 caractères de long.

Elle est décomposée comme suit :

Champ

5.2,0

7.2,0

9.2,0

Minutes 

11.2,0

13.2,0

 

DateHeure Hhour (DateHeure , NbHeures , NbMinutes , NbSecondes , RemplacerEspaces)

 

Paramètres

DateHeure

Date + heure d'origine

NbHeures

Nombre d'heures à ajouter à la DateHeure d'origine. Cette valeur peut être négative.

NbMinutes

Nombre de minutes à ajouter à la DateHeure d'origine. Cette valeur peut être négative.

NbSecondes

Nombre de secondes à ajouter à la DateHeure d'origine. Cette valeur peut être négative.

RemplacerEspaces

"0" si les espaces doivent être remplacés par des 0.

 

Retour

La fonction retourne la nouvelle date + heure.

Exemples

 

1 result dh

1 result1 dh

1 depart dh= "20020228133045" ; le 28/02/2002 a 13h30m45s

main

result = Hhour(depart,1) ; ajouter 1 heure

display result ;--> 20020228143045

 

result = Hhour(depart,25) ; ajouter 25 heures

display result ;--> 20020301143045

 

result = Hhour(depart,1,50,10) ; ajouter 1h50mn10s

display result ;--> 20020228152055

 

result = hHour(depart,0,0,3600) ; ajouter 3600s

display result ;--> 20020228143045

 

result = Hhour(depart,-24,-50,-10) ; soustraire 24h50mn10s

display result ;--> 20020227124035
