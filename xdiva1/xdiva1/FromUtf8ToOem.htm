FromUtf8ToOem  Famille 

La fonction FromUtf8ToOem convertit une chaîne contenant des caractères codés au format Utf8 en une chaîne de caractères codés au format Harmony.

La réciproque de cette fonction est FromOemToUtf8.

  

Alpha FromUtf8ToOem (chaîne , &reste )

 

Paramètres

Chaine

Chaîne de caractères à convertir.

Reste

Donnée de type L qui reçoit le nombre de caractères non traités en fin de chaîne.

Un caractère peut être codé sur plusieurs octets en Utf8. Si la chaîne à traduire est partielle (ce qui arrive lorsque on a lu une partie d’un fichier), il se peut que la coupure intervienne au milieu d’une séquence d’octets représentant un caractère. Dans ce cas, la fonction FromUtf8ToOem indique le nombre de caractères à la fin de la chaîne d’origine qui n’ont pas été traités. Ces caractères devront être traduits une fois que les octets suivants auront été lus. Voir Exemple 2.


 

Retour

La fonction renvoie la chaîne de caractères codée au format Harmony.

Reste contient le nombre d’octets qui n’ont pas été traduits.

 

Remarques

  • La chaîne rendue par la fonction est généralement plus courte que la chaîne d’origine.

  • Il est conseillé d’utiliser des variables de type S

 

Exemple 1

1 resultat S

1 chaine S

1 reste S

1 utf8 S

 

chaine = FromOemToUtf8("chaine à convertir") 

resultat = FromUtf8ToOem(chaine,reste) 

; la taille de la chaîne traduite est size(resultat) 

; dans ce cas, le reste est forcément nul puisque la variable chaine contient toute la 

; chaîne Utf8. 

 

Exemple 2 : Copie d’un fichier Utf8 vers un fichier Harmony

 

; cet exemple illustre une traduction partielle avec la gestion des caractères non traités

; lors d’une première traduction.

; L’utilisation des variables de type S rend l’algorithme très simple

 

function ptr CopierUTF8VersHarmony(fic1,fic2)

1 fic1 A

1 fic2 A

 

record * htdf tdforg

record * htdf tdfdes

1 enrecr S

1 enrconv S

1 enrlec 1024

1 reste S = ""

1 lgreste L=0

1 stread x

1 stwrite x

1 stopen x

beginf

 

   ; Ouverture du fichier origine

   ;-----------------------------

   tdforg.name = fic1

   stopen = fopen(tdforg,"P")

   if stopen <> 0

      freturn(1) 

   endif

 

   ; Ouverture / création du fichier destination

   ;--------------------------------------------

   tdfdes.name = fic2

   stopen = fopen(tdfdes,"R")

   if stopen = $14

      stopen = fcreatefile (tdfdes.name,"U",0) 

      stopen = fopen(tdfdes,"R") 

   endif

 

   if stopen <> 0

      freturn(2) 

   endif

   ferase(tdfdes)

 

   ; boucle de lecture de l’origine

   ;-------------------------------------------

   loop (stread := freadst(tdforg,enrlec)) = 0 

      enrconv = reste & left(enrlec,tdforg.sizelast)  ; ajout du reste 

      enrecr = FromUTF8ToOem(enrconv,lgreste)   ; conversion 

      reste = condition(lgreste,right(enrconv,lgreste),'') ; garder le reste 

; Attention, right(xx,0)

; renvoie toute la chaine

      stwrite = fwritst(tdfdes,enrecr) 

   endloop  

 

   fclose(tdfdes)

   fclose(tdforg)

   freturn(0)

endf

 

main

CopierUtf8VersHarmony("e:/Divalto/tmp/ficutf8.Txt","e:/Divalto/tmp/ficharmony.txt")
