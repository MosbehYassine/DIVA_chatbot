HCopyFile  Famille Thème

La fonction HCopyFile permet de copier un fichier. 

Numer HCopyFile (FichierDepart, FichierArrivee, [SansEffacement] , [Partage], [AfficherErreur], NumeroFichierErreur)

 

 

Paramètres

FichierDepart

Nom du fichier à copier.

FichierArrivee

Nom du fichier destination.

SansEffacement

Booléen indiquant le traitement à faire si le fichier Dest existe.

  • TRUE : le fichier n'est pas effacé et la fonction retourne la valeur 9.

  • FALSE : le fichier est effacé (valeur par défaut)

Partage

Mode d'ouverture ("R", "P" ou "F") du fichier Dep. La valeur par défaut est "R"

Le fichier Dest est toujours ouvert en mode réservé ("R").

AfficherErreur

Booléen indiquant si la fonction doit afficher un message en cas d'erreur. (FALSE par défaut).

NumeroFichierErreur

Variable numérique de 1 caractère. En cas d'erreur pendant la copie, elle contient une valeur permettant d'identifier le fichier en erreur.

  • 1 = fichier de départ.

  • 2 = fichier de destination.

 

Retour

0

Pas d'erreur.

9

Le fichier de destination existe et l'option Noerase est positionnée.

20

Fichier de départ absent

47

Fichier réservé (voir NumeroFichierErreur pour savoir de quel fichier il s'agit)

99

Les fichiers de départ et destination sont les mêmes.

Autres

Code d'erreur système (voir NumeroFichierErreur pour savoir de quel fichier a provoqué l'erreur).

 

Exemple

1 numfic 1,0

1 st X

main

st = Hcopyfile("/Divalto/sys/test1.dhsp" , \

               "/Divalto/tmp/test1.dhsp", \ 

               FALSE,   \ 

               "F", \ 

               true, \ 

               numfic)
