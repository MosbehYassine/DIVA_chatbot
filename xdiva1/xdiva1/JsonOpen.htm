JsonOpen Famille Thème

 

Allocation d'un objet JSON.

 

Int JsonOpen  ( [TailleMaxCache] )

 

Paramètres

TailleMaxCache

Taille maximale en Ko du cache pour cet objet.

Pour accélérer les temps de recherche, l'objet Json utilise un cache dans lequel il garde les requêtes déjà effectuées.

Si on balaye tout un objet Json par des JsonGetValue, à la fin, le cache est plus volumineux que le source Json.

Le paramètre TailleMaxCache permet de limiter la taille du cache, ce dernier est alors vidé lorsque la taille maximale est atteinte.

Par défaut, le cache n'est jamais vidé.

 
 

Retour

La fonction retourne un ticket qui identifie l'objet JSON. Ce ticket est ensuite utilisé dans toutes les autres fonctions pour identifier l'objet JSON..

 

Remarques

L'objet JSON doit être libéré par JsonClose.

 

Exemple

 

1 ticket L

ticket = JsonOpen()
