FtpRequestSetProxy Famille Thème

 

Positionnement des paramètres du proxy.

 

int FtpRequestSetProxy  ( Ticket , Url, Mode, Utilisateur, MotDePasse )

 

Paramètres

Ticket

Identifiant de la requête obtenu par FtpRequestNew

 

Url

Url du serveur proxy.

 

Mode

1

Prendre les paramètres du système. Il n'y a pas d'autre paramètres à préciser, l'authentification est celle du poste de travail.

2

Préciser l'url du serveur, mais authentification SSPI. Inutile de préciser Utilisateur et MotDePasse

3

Mode manuel. Il faut préciser tous les paramètres

 

Utilisateur

Nom de l'utilisateur dans le domaine.

 

MotDePasse

Mot de passe de l'utilisateur.

 

 

Retour

0

Pas d'erreur

1

Ticket incorrect

2

Exception. Voir FtpRequestGetError
