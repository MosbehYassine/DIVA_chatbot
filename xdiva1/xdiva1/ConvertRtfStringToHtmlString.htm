ConvertRtfStringToHtmlString  Famille 

La fonction ConvertRtfStringToHtmlString convertit une chaîne de caractères Rtf en chaîne de caractères Html

 

Alpha ConvertRtfStringToHtmlString ( rtfString, [options] )

  

Paramètres

 

RtfString

Chaîne au format Rtf  

Options

Chaine Hmp pour positionner des options (non utilisée pour l'instant)

 

Retour

La fonction retourne la chaîne au format Html
En cas d'erreur la fonction retourne une chaîne vide. (ConvertHtmlRtfLastError permet de récupérer le texte d'erreur)
