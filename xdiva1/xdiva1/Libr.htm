Libr  Famille Thème

 

L'instruction Libr permet de libérer des enregistrements qui ont été réservés avec un autre code de réservation que R.
La libération des enregistrements qui ont été réservés avec un autre code de réservation que R n'est pas implicite en cours de programme. Il faut donc explicitement les libérer par Libr.

 

Libr tdf code_réservation

 

Paramètres

Tdf

Table de définition de fichier.

Code_réservation

Précise les enregistrements à libérer. Tous les enregistrements préalablement réservés avec ce code_réservation sont libérés.
Attention, le code 'A' est différent du code 'a'.

 
Remarques

Libr peut libérer des enregistrements appartenant à plusieurs fichiers qu'ils soient locaux ou situés sur un serveur.

 

Exemple

st = fread(client,ecli,'a') ; lit et réserve un enreg. client

st = fread(arti, eart , 'a'); lit et réserve un enreg. article

Libr arti 'a' ; libère les deux enregistrements
