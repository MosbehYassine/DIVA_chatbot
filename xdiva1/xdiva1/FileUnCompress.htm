FileUnCompress  Famille Thème

 

Cette fonction permet d'expanser un fichier comprimé par FileCompress.

 

Ptr = FileUnCompress (fichier_départ , fichier_arrivée, code_système, [flag])

 

Paramètres

Fichier_départ

Nom du fichier comprimé à expanser.

Fichier_arrivée

Nom du fichier expansé. Si ce fichier n'existe pas, il est automatiquement créé. Le fichier d'arrivée doit obligatoirement être distinct du fichier de départ.

Code_système

Donnée numérique qui reçoit un code d'erreur système.

Flag

Booléen (TRUE par défaut) indiquant l'opération à effectuer si le fichier de départ n'est pas un fichier comprimé.
TRUE : le fichier de départ est recopié tel que.

FALSE : le fichier de départ n'est pas recopié et la fonction retourne une erreur.

 
Retour

La fonction retourne un code d'erreur principal et un code d'erreur système.

Voir Codes d'erreurs des fonctions de cryptage et de compression .

 
Remarque

Si le fichier d'origine est vide, le fichier destination est toujours créé.

Comme l'expansion d'un fichier non comprimé provoque la copie simple du fichier, FileUnCompress peut être utilisée pour copier un fichier.

 

Exemple

; Décompression du répertoire /Divalto/comprime dans /Divalto/sys

 

procedure decomprime

beginp

record 'ddsys.dhsd' OPDIR OP

record 'ddsys.dhsd' ELTDIR EL

1 car 1

1 st X

op.racine = "/Divalto/comprime" 

op.prefixe = "*"

op.tri = 1

st = DirOpen(op)

if st

   Display "Erreur " & tohexa(st) & " lors de l'ouverture" 

   ProgramExit

endif

loop DirRead(op,el) = 0

   if el.flagdir = 0

      display left(el.nom) & el.taillefd 

      st = FileUnCompress("/Divalto/comprime/" & el.nom, \ 

                          "/Divalto/decomprime/" & el.nom, stat) 

      if st 

         Display "Erreur " & str(st) & " Stat.sys = " & tohexa(stat) 

         input " " car 

      endif 

   endif 

endloop

DirClose(op)

endp
