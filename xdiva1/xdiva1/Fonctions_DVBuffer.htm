Fonctions DVBuffer

Le DVBuffer est un objet fréquemment  utilisé dans Harmony pour transférer des données entre processus. Il permet de sérialiser et désérialiser rapidement des données.

Il est utilisé entre autres pour le dialogue entre le client léger et le serveur, pour le dialogue avec le serveur Power Search.

 

Le DVBuffer est une zone tampon dans laquelle l'écrivain place les données. Ces données doivent être lues par le lecteur dans le même ordre qu'elles ont été écrites. La taille du DVBuffer s'étend automatiquement en fonction des besoins.

 

La création d'un DVBuffer se fait par la fonction DVBufferGetId qui renvoie un identifiant utilisé ensuite par les autres fonctions.

L'écriture dans le DVBuffer se fait par la fonction DVBufferPut. Les données écrites varient en fonction du type de la donnée. L'écriture d'une chaîne de caractères dans un DVBuffer place la longueur (sur 4 octets) suivie des caractères de la chaîne.

 

La lecture dans le DVBuffer se fait par la fonction DVBufferGet. La variable réceptrice doit être de même type que la variable qui a été écrite dans le DVBuffer.
