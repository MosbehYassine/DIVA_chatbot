Fonctions Xml

Les fonctions Xml permettent de lire un flux XML. Ce flux peut être un fichier ou une chaîne de caractères.

Ces fonctions sont principalement utilisées dans les services Web. En effet, le dialogue entre le client et le service se fait généralement en utilisant XML.

Les fonctions XML utilisent la classe XmlTextReader du framework .Net qui fournit un accès en avant uniquement et en lecture seule dans un flux de données XML.

Le framework .Net doit être installé AVANT Harmony pour que ces fonctions soit opérationnelles. Si le framework n’est pas installé, installez-le puis réinstallez Harmony. Si le framework a été installé après Harmony, réinstallez Harmony.

 

Les trois principales fonctions sont :

  • XmlOpen pour ouvrir un flux.

  • XmlRead pour lire l’élément suivant du flux Xml.

  • XmlClose pour fermer le flux.

 

Il n’y a pas de fonctions spécifiques pour l’écriture d’un flux XML. Il est vivement conseillé d’utiliser la fonction XmlTranslate qui convertit les caractères spéciaux (< > etc.).

 

Description succinte de XML

Le langage Xml (Extensible Markup Language) permet de décrire des données structurées. Il ressemble à Html par sa structure de balises.

Un document XML est constitué :

  • D’une déclaration

  • D’un ensemble de balises pour définir les éléments de données. Chaque élément encapsule un sous-ensemble des données qui peut être très simple ou au contraire très complexe.

Dans l’exemple ci-dessous, nous avons la balise <BaseArticle> qui marque le début d’une liste d’articles. Cette balise doit avoir sa balise de fermeture plus loin </BaseArticle>.

Pour chaque article nous trouvons une balise <Article>. Les différents champs de l’article se trouvent placés à l’intérieur de la balise sous forme d’attributs. Si l’article n’a pas de commentaires, la balise se termine immédiatement (voir A1). Si l’article a des commentaires, il sont placés entre la balise de début et la balise de fin de l’article (voir A2).
