ConvertUTCDateToLocalDate Famille Thème

La fonction ConvertUTCDateToLocalDate convertit une donnée date+heure UTC en une donnée date locale au format date+heure.

 

DateHeure ConvertUTCDateToLocalDate (dth, ModeServeur, TimeZoneName)

 

Paramètres

Dth

Date+heure origine au format AAAAMMJJhhmmss.

 

ModeServeur

TRUE : Les paramètres de conversion sont pris sur l'ordinateur serveur (celui qui exécute xrtdiva)

FALSE : Les paramètres de conversion sont pris sur le poste client

 

TimeZoneName

Par défaut, les paramètres sont pris pour la time zone du poste client ou du serveur.

Ce paramètre permet de préciser la time zone à utiliser.

Ex : "Central Standard Time" (US & Canada)

        "Romance Standard Time"  (Paris)

 

Retour

La fonction retourne une date+heure locale au format AAAAMMJJhhmmss

 

Exemple

 

dh = ConvertUTCDateToLocalDate("20230508101010") ; --> '20230508121010'

dh = ConvertUTCDateToLocalDate("20230508101010",,"Central Standard Time") ; --> '20230508051010'

dh = ConvertUTCDateToLocalDate("20230508101010",,"Romance Standard Time") ; --> '20230508121010'
