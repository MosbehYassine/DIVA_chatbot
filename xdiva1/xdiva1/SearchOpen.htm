SearchOpen Famille  Thème

La fonction SearchOpen permet d'établir une connexion avec un serveur Search.

SearchOpen retourne un identifiant de connexion qui est passé en paramètre à toutes les autres fonctions.

 

Long  SearchOpen ( [ NomDuServeur ] )

 

Paramètres

NomDuServeur

Permet de préciser le nom du serveur Search auquel on veut se connecter. Si ce paramètre est omis, la connexion se fait au serveur Search défini dans l'environnement courant.

 

 

Retour

0

Erreur de connexion. La fonction SearchGetError permet de récupérer le message d'erreur.

Autre

Identifiant de la connexion.

 

 

Exemple 

1 IdConnexionSearch L

1 st  L

1 Libelle S

1 pos0d L

main

if SearchOn

IdConnexionSearch = SearchOpen("")

if IdConnexionSearch = 0

st = SearchGetError(libelle)

pos0d = string($0d,libelle)

if pos0d <> 0

pos0d = string($0d,libelle,pos0d+1)

if pos0d <> 0

   libelle = left(libelle,pos0d-1)

endif

endif

ErrorWarning(st, "", libelle)

endif

endif
