GetLanguageData Famille Thème

 

La fonction GetLanguageData permet de lire le code langue de base pour les champs multilingues.

Ce code langue indique dans quelle langue sont les champs écrits dans les fichiers.

Par défaut, le code langue de base provient du fichier paramètres TranslateParams.tx (LanguageBaseData).

 

Alpha GetLanguageData

 

Retour

La fonction retourne la valeur du code langue.
