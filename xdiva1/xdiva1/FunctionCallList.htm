FunctionCallList Famille Thème

 

La fonction FunctionCallList permet d'appeler une fonction dont l'adresse a été obtenue par la fonction GetAdressFunction en passant les arguments de la fonction dans une liste

  

? FunctionCallList (adresse, parametres )

  

Paramètres

Adresse

Zone de 16 octets contenant l'adresse de la fonction obtenue par l'appel de la fonction GetAdressFunction.

  

Parametres

Liste contenant les paramètres à passer à la fonction. Il est impératif de passer tous les paramètres de la fonction et de respecter la concordance des types. Toute incompatibilité entre la définition de la fonction et les paramètres passés par FunctionCallList provoque un arrêt du programme en cours.

Un paramètre est défini par la structure diva suivante :

Type

Type de la donnée. Voir DataType pour connaitre les valeurs

Name

Nom du paramètre

IsPtrRecordSql

Booléen indiquant s'il s'agit d'un RecordSql

La valeur doit être attachée à la première propriété de l'élément.

  

Retour

Le type de retour dépend de la fonction appelée, il n'est donc pas connu au moment de la compilation. Par défaut, le compilateur attribue un type alphanumérique au résultat de FunctionCallList. Si la fonction appelée retourne un entier, il faut le stocker dans une donnée numérique avant de l'utiliser.

  
 Exemple 

define TYPE_ALPHA = 3

Structure Parameter

   1 Type B

   1 Name 64

   1 IsPtrRecordSql B

EndStructure

 

1 adrfonc 16

1 parametres L

1 st  L

1 adr L

RecordDiva Parameter Param

 

function int VerifieCode(code, lettre)

1 code 10

1 lettre 1

beginf

   if left(code,1) = lettre

      freturn 0

   else

      freturn 1

   endif

endf

 

main

   parametres = ListCreate

   

   ; création du premier paramètre

   Param.IsPtrRecordSql = false

   Param.Name = "code"

   Param.Type = TYPE_ALPHA

   adr = ListAddEnd(parametres,param)

   ListSetProp(parametres,1,"zC123",adr)

 

   ; second paramètre

   Param.IsPtrRecordSql = false

   Param.Name = "lettre"

   Param.Type = TYPE_ALPHA

   adr = ListAddEnd(parametres,param)

   ListSetProp(parametres,1,"C",adr)

 

   ; appel de la fonction

   GetAdressFunction(" ","VerifieCode", adrfonc)

   st = FunctionCallList(adrfonc, parametres)

   display st
