DataDescriptor

La fonction DataDescriptor permet d’obtenir le descripteur d’une variable ou d’une expression. L’espression est une chaîne de caractères en langage Diva.
Le descripteur retourné par la fonction peut ensuite être utilisé pour accéder à la variable.

L'expression peut utiliser soit les noms standards (comme en Diva), soit les noms odbc (définis dans le dictionnaire).

Attention, pour que DataDescriptor puisse s’exécuter aussi bien en mode normal qu’en mode debug, il faut impérativement que les enregistrements soient déclarés avec l’option KeepDataNames.

Long DataDescriptor (expression , descripteur , [ mode ] )

 

Paramètres

Expression

Chaîne alphanumérique contenant une expression en langage Diva.

Descripteur

Zone de 120 caractères qui contient en retour le descripteur correspondant à Expression.

Il est conseillé d'utiliser une donnée de type S.

 

Mode

0

Mode normal. Les noms des données utilisées sont les mêmes qu'en Diva. (Valeur par défaut)

1

Mode Odbc. Les noms des données (enregistrements et champs) sont les noms odbc.

2

Mode mixte. Seuls les noms des champs sont des noms odbc. Les noms des enregistrements sont les mêmes qu'en Diva.

 

 

Retour

0

Pas d'erreur.

Autre

Erreur lors de l’évaluation. Le code retourné correspond au numéro d’erreur du compilateur Diva.

 

Remarques

Les données et enregistrements utilisés dans Expression doivent impérativement être déclarés dans le module courant.

Si une donnée non déclarée dans le module est utilisée dans l’expression, la fonction retourne la valeur 20.

Une fois le descripteur récupéré, il peut être utilisé par la fonction DataValue pour récupérer ou modifier le contenu de la donnée.

 

Exemples

1 st L

1 adr S

record KeepDataNames h3fdd eimp

1 tabl 10,2*10

1 ind  L

 

st = DataDescriptor("eimp.znomimp",adr)

if st = 0

   DataValue(adr) = "imp" 

else

   display "Erreur DataDescriptor"

endif

 

tabl(3) = 123

ind = 3

st = DataDescriptor("tabl(ind)",adr)

DataValue(adr)++

display tabl(3) à 124
