WinRegWriteDword  Famille Thème

La fonction WinRegWriteDword permet d’écrire une valeur numérique dans le registre avec le format REG_DWORD.

Cette fonction se trouve dans le module ysystemex.dhop.

  

BOOL WinRegWriteDword (clé, nom_valeur, valeur)

 

Paramètres

Clé

Clé sous laquelle se fait l’écriture.

Nom_valeur

Nom de la valeur à écrire.

Valeur

Valeur à écrire.

  

Retour

FALSE

Erreur

TRUE

Opération effectuée.

  

Exemple

module "ysystemex.dhop"

1 st X

main

st=WinRegWriteDword("HKEY_CURRENT_USER\Software\DivaltoHarmony\macle","Mavaleur",123)
