Les fonctions de base de gestion de fichiers

Toutes les fonctions de base de gestion de fichier renvoient comme résultat une donnée de type X contenant le compte-rendu de l'opération fourni par le système.

Ces fonctions rendent toujours la main, quelque soit l'erreur. Il est donc impératif de tester tous les cas d'erreurs après l'appel d'une fonction de base.

Il est conseillé d'utiliser de préférence les fonctions évoluées de gestion de fichier (préfixées par H) qui arrêtent le programme en cas d'erreur "fatale". Ces fonctions permettent de minimiser les tests à l'intérieur du programme principal tout en gardant la même fiabilité.
