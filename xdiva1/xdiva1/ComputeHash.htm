ComputeHash Famille Thème

Calcule le hash pour les données en entrée avec la fonction de hash spécifiée.

Alpha ComputeHash(buffer, hashMethod)

Paramètres

buffer

Une chaîne contenant le buffer dont le hash doit être calculé

hashMethod

Une constante pour spécifier la fonction de hash qui doit être utilisée choisit dans la liste ci-dessous :

  • HASH_MD5

  • HASH_SHA2_256, nommé SHA-256

  • HASH_SHA2_384, nommé SHA-384

  • HASH_SHA2_512, nommé SHA-512

  • HASH_SHA3_256

La fonction de hash utilisée par défaut est HASH_SHA2_256.

Retour

La fonction renvoie une chaîne contenant le hash calculé encodée en base 16, ou une chaîne vide si une erreur s'est produite. Pour avoir plus d'informations sur l'erreur en cas d'échec, utiliser la fonction HashGetLastErrorMessage()
