WebRequestNew Famille Thème

 

Allocation d'un nouvel objet WebRequest

 

Int WebRequestNew ()

 

Retour

La fonction retourne un ticket qui identifie l'objet WebRequest. Ce ticket est ensuite utilisé dans toutes les autres fonctions pour identifier l'objet WebRequest.

 

Remarques

Chaque appel à un service web doit commencer par WebRequestNew. Le système optimise les connexions / déconnexions aux serveurs.
