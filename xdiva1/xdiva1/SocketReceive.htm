SocketReceive  Famille   Thème

La fonction SocketReceive permet de lire les caractères sur le socket.

Par défaut, cette opération est bloquante, c’est à dire qu’elle ne rend la main que lorsque le nombre de caractère demandé est atteint. L’option SO_RCVTIMEO permet de programmer une attente avec délai.

 

int = SocketReceive ( socket, récep , [ options ])

 

Paramètres

Socket

Socket obtenu par la fonction SocketNew .

Récep

Donnée qui recoit les caractères lus.

Options

Paramètre facultatif (0 par défaut).

.

 

Retour

-1

Erreur. Voir SocketLastError

Autres

Nombre de caractères lus.
 

Exemples

1 data 200

Nb = SocketReceive(sock,data)
