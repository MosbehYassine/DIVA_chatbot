GetInfoHost

La fonction GetInfoHost permet de récupérer les paramètres d'un serveur. La liste des serveurs est modifiée par le choix <Serveurs> du menu Harmony.

 

Long GetInfoHost (serveur, résultat )

 

Paramètres

Serveur

Nom d'un serveur dont on veut récupérer les caractéristiques.

Résultat

Instance de l'enregistrement Serveur du dictionnaire ddsys.dhsd. Les champs de cette structure sont :

Champ

Commentaire

Islg

Taille de la structure Serveur. Ce champ est garni automatiquement.

Issysteme

Système d'exploitation du serveur
2 = Unix
4 = Windows

Isexterne

0 = Local
1 = Réseau poste à poste
2 = Xlan

3 = Xlan SQL

Isadresse

Chemin ou adresse IP

Isport

Numéro de port TCP/IP

Isinterface

Type d'interface

5 = TCP/IP

Les autres valeurs ne sont plus utilisées.
 

Retour

0

Serveur non trouvé

Autre

Taille de la zone retournée par la fonction.
