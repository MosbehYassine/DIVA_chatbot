Fread  Famille Thème

 

fread permet de lire l'enregistrement qui suit le dernier enregistrement lu, ou de lire le premier enregistrement du fichier si aucune lecture n'a été effectuée.

 

Ptr = fread ( tdf , variable [ , code_réservation ] [ , depack_auto ] )

Paramètres

Tdf

Table de définition de fichier.

Variable

Donnée réceptrice qui contiendra l'enregistrement lu.

Code_réservation

Mode de partage de l'enregistrement ('P' par défaut).

Depack_auto

Décompression automatique des données si l'enregistrement comporte une zone packée.
0  : non  (par défaut)

1  : oui

  

Retour

0  

Pas d'erreur. 

H_EOF  

Fin de fichier atteinte. 

H_RESERVED  

Enregistrement réservé. 

autres

Code d'erreur système. 

 

Remarque

La fonction GetLastRecord permet de récupérer le dernier enregistrement lu.

 

Particularités pour les fichiers de type I

La lecture se fait d'après la clé courante (clé "A" par défaut) et la fin de fichier est provoquée par la fin de la clé en cours.

 

Positionnement de la clé

Il est possible de modifier la clé avant d'utiliser la fonction fread pour se positionner directement sur un enregistrement. L'enregistrement lu est alors celui ayant la clé la plus proche (supérieure ou égale) de la clé indiquée dans la TDF (voir exemple).

Sauvegarde et restauration de la clé

Après la lecture, la clé exacte lue est placée dans la TDF par le système. Il est alors possible de sauvegarder cette clé dans une zone de 256 octets, d'effectuer d'autres opérations sur le fichier, puis de restaurer la clé afin de reprendre le traitement sur l'enregistrement suivant (voir exemple 2).

 

Fin de fichier

Lorsque la fin de fichier est atteinte, une lecture par la fonction Fpread ne donne pas le dernier enregistrement du fichier. La clé doit être repositionnée.

 

Remarque : Après restauration de la clé la fonction fread délivre l'enregistrement suivant, tandis que la fonction Fseek2 délivre le même enregistrement.

 

Exemple 1

;________________________________________________________________
; Fonction : F_READ

; Type : int

; Description : Lit séquentiellement le fichier tdf en mode "par"

; et dépacke automatique

; Paramètres en sortie : 0 = ok 1 = fin 2 = réservé 3 = errsys

;________________________________________________________________
;

Function int F_READ (&tdf , &art , par)

record * htdf tdf ;table de définition

1 art A ;article

1 par A = 'P' ;code partage

beginf

cr = fread (tdf,art,par,1) 

switch cr 

case 0 ; ok 

   freturn (0) 

case H_EOF ; fin de fichier 

   freturn (1) 

case H_RESERVED ; réservé 

   freturn (2) 

default ;erreur système 

   MessageBox("Erreur système numéro " & binhexa (stx (cr)) & \ 

                 " en lecture du fichier " & left(tdf.name)," ") 

   freturn (3) 

endswitch 

endf

…….

; Lire le fichier des compositeurs à partir de la lettre L.

comp.key = 'A' & 'L' ; positionnement clé

do

   st = f_read(comp , cpenr , 'F') 

while st = 0

   display [ cpenr.codecp " " cpenr.nom " " cpenr.prenom ] 

wend

 

Exemple 2

Cet exemple illustre l'utilisation de la sauvegarde et de la restauration de la clé dans la tdf.

Soit un fichier de factures FFAC contenant deux types d'enregistrements :
 - les entêtes (clé A),
 - les lignes détail (clé B).

La donnée Numfac (numéro de facture) est présente dans les deux enregistrements (Entete.Numfac dans l'entête et Detail.Numfac dans la ligne détail) et sert de clé.

Après avoir lu une entête, on sauvegarde la clé; puis on change la clé pour lire les lignes détail correspondant à l'entête lue. Pour passer à la facture suivante, il faut restaurer la clé et lire l'entête suivante.

1 wcle 256 ; pour sauvegarder la clé

 

st = fread(ffac, entete, "F") ; lecture d'une entête

; test des codes d'erreur 

wcle = ffac.key ; sauvegarde de la clé 

; lecture de toutes les lignes 

ffac.key = "B" & numfac 

do 

   st = fread(ffac, detail, "F") 

   ; test des codes d'erreur 

while st = 0 and Detail.Numfac = Entete.Numfac 

   ... ; traitement de la ligne 

wend 

; lecture de l'entête suivante 

ffac.key = wcle ; restauration de la clé 

st = fread(ffac, entete, "F")
