OpenXmlWord_Replace  Famille  Theme

 

La fonction OpenXmlWord_Replace cherche et remplace une chaîne de référence dans le document MS Word en cours.

 

Int OpenXmlWord_Replace (cherche, remplace, ancrage)

 

Paramètres

Cherche

Chaîne de caractères à rechercher.

Remplace

Chaîne de caractères de remplacement.

Ancrage

False : OpenXml recherche toutes les occurrences de la chaîne Cherche et les remplace par la chaîne Remplace (valeur par défaut). La main n'est pas rendue au programme avant la fin des remplacements.

True : OpenXml recherche la 1ère occurrence de la chaîne Cherche, la remplace par la chaîne Remplace et pose un point d'ancrage après le paragraphe contenant la chaîne recherchée. La main est rendue au programme pour que celui-ci puisse utiliser ce point d'ancrage pour y insérer un ou plusieurs paragraphes avec du texte ou un ou plusieurs fichiers. Le programme peut ensuite rappeler cette fonction pour procéder à un autre remplacement.

 

Retour :

n

Nombre de modifications faites dans le fichier par la fonction.
Si le paramètre Ancrage = true, n = 1, ce qui signifie qu'il y a eu une modification et qu'un point d’ancrage a été créé.

0

Aucune modification.
Si le paramètre Ancrage = true, 0 signifie que le traitement est terminé.
