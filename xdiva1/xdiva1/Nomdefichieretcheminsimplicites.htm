Nom de fichier et chemins implicites

Un fichier ou un programme Harmony est identifié par un nom de la forme :

 //serveur/chemin/dossier/nom

où :

  • serveur représente un nom de serveur,

  • chemin représente un chemin (suite de dossiers),

  • dossier représente un nom de répertoire,

  • nom est le nom du fichier proprement dit.

Pour les fichiers locaux, l'écriture classique c:/…. est possible.

 

Exemples :

//serveur/divalto/sys/farti

(fichier sur un serveur)

/divalto/sys/fcli

(fichier local)

c:/divalto/sys/fcli

(fichier local)

 

Remarques :

  • La correspondance entre ce nom de fichier et les unités et répertoires d'Unix et de windows est expliquée dans le " Manuel de référence d'Harmony" au chapitre installation.

  • Pour ouvrir un fichier, la Tdf doit être déclarée par une des instructions suivantes : HFile, HTmpfile, Record * htdf.

  • Sous unix, les noms des fichiers sont toujours en caractères minuscules. Harmony ne peut pas accéder à un fichier Unix dont le nom comporte un caractère majuscule.

 

Pour ne pas avoir à préciser le nom complet du fichier (ce qui figerait son emplacement physique), chaque tâche dispose d'une liste de chemins "implicites".

Lors de l'accès à un fichier partiellement identifié, le système recherche le fichier avec le premier chemin implicite. Si la recherche échoue, il fait une tentative avec le deuxième chemin implicite, puis avec le troisième et ainsi de suite.

La liste des chemins implicites peut être modifiée de plusieurs manières :

  • en modifiant le fichier .txt correspondant,

  • par l'utilitaire xpath,

  • lors de l'utilisation de la boîte de dialogue de saisie des fichiers,

  • par programme en utilisant les fonctions ListImplicitesGet et ListImplicitesSet

 

Exemple :

Recherche du fichier FICH.TXT avec les chemins implicites suivants :

  - c:/Divalto/sys

  - //serveur/c3/fic

  - //serveur/c3/prg

Le fichier FICH.TXT sera successivement recherché sous les noms complets suivants : 

  - c:/Divalto/sys/fich.txt

   - //serveur/c3/fic/fich.txt

   - //serveur/c3/prg/fich.txt
