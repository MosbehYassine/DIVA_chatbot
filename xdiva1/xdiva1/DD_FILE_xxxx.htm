DD_FILE_xxxx  Famille  Thème

Long DDInterface (Commande , &ticket , [paramètres] , retour, [niveau])

 

DD_FILEBEGIN

La commande DD_FILEBEGIN permet de se positionner sur le premier fichier du dictionnaire.

Retour contient les caractéristiques du fichier. Voir DDInterface : Fichiers .

 

Retour

0

pas d’erreur.

2

Pas de fichier dans le dictionnaire.

autre

Erreur. Voir DD_GETERROR

 

Exemple

1  ticket L 

1  reponse 8096  

1  stfichier X

stfichier = DDInterface(DD_FILEBEGIN,ticket,,reponse)

 

DD_FILENEXT

La commande DD_FILENEXT permet de se positionner sur le fichier suivant du dictionnaire.

 

Retour contient les caractéristiques du fichier. Voir DDInterface : Fichiers .

 

Retour

0

pas d’erreur.

2

Plus de fichier dans le dictionnaire.

autre

Erreur. Voir DD_GETERROR

 

Exemple

1  ticket L 

1  reponse 8096  

1  stfichier X

1  fini   X = FALSE

stfichier = DDInterface(DD_FILENEXT,ticket,,reponse)

if stfichier = 2

 fini = TRUE

  endif

 

DD_FILEFIND

La commande DD_FILEFIND permet de rechercher un fichier du dictionnaire.

 

Paramètre doit contenir le nom du fichier à chercher.

Retour contient les caractéristiques du fichier. Voir DDInterface : Fichiers .

 

Retour

0

pas d’erreur.

2

Fichier non trouvé.

autre

Erreur. Voir DD_GETERROR

 

Exemple

1  ticket L 

1  reponse 8096  

1  stfichier X

stfichier = DDInterface(DD_FILEFIND,ticket,"odfic",reponse)
