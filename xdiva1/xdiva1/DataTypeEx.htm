DataTypeEx

La fonction DataTypeEx permet de connaître le type exact d'une donnée. Contrairement à DataType elle renvoie une valeur différente pour une variable alphanumérique et un String.

 

Long DataTypeEx (Donnée)

 

Retour

DataTypeEx retourne le type donnée. Les valeurs possibles sont :

2

Numérique

3

Alphanumérique ou String

6

Type B

7

Type X

9

Type L

10

Type S (string)

99

Format interne de calcul. Il est conseillé de transférer une telle donnée dans une donnée numérique.

Remarque

Cette fonction peut être utile dans les fonctions/procédures pour connaître le format exact d'un paramètre formel.
