WinReadProfileInt  Famille Thème

 

La fonction WinReadProfileInt permet de lire une valeur numérique dans un fichier .ini.

Attention, le fichier divalto.ini est géré de manière particulière. Voir le chapitre divalto.ini de la documentation Installation et paramétrage d'Harmony.

  

Numer WinReadProfileInt (section, entrée, fichier)

 

Paramètres

Section

Nom de la section du fichier .ini. Dans un fichier .ini, une section est un mot encadré par les crochets [ ]. Ne pas mettre les crochets dans ce paramètre.

Entrée

Entrée (ou mot-clé) dans la section.

Fichier

Nom du fichier .ini.

 

Retour

La fonction renvoie la valeur trouvée ou 0 si l'entrée n'existe pas.

  

Exemple

display WinReadProfileInt("System","NumeroService","monfichier.ini")

; recherche de NumeroService=xxxxx dans la section system du
; fichier monfichier.ini
