Exemple d'utilisation des fonctions Assembly

 

Le service web "http://www.webserviceX.NET/ConversionRate" permet d'obtenir le taux de change entre deux devises.

Les étapes pour appeler ce service web depuis Diva sont :

  • Création d'un projet C# de type "Bibliothèque de classes".

    1. Ajout d'une référence de service en utilisant l'URL "http://www.webservicex.net/currencyconvertor.asmx".

    2. Ecriture des fonctions d'interface entre Diva et les fonctions du service web.

    3. Test de ces fonctions en écrivant un petit programme en C#

  • Appel des fonctions depuis Diva.

Ecriture d'une fonction d'interface entre Diva et le service web

 

/// <summary>

/// Obtenir le taux de change

/// </summary>

/// <param name="hmp">d1=devise1  d2=devise2</param>

/// <returns>chaine hmp avec le taux ou texte de l'exception</returns>

public static string ConvertirDevises(string hmp)

{

try

{

Currency p1, p2;

string devise1, devise2;

CurrencyConvertor conv = new CurrencyConvertor();

HmpReader reader = new HmpReader(hmp);

reader.Seek("d1", out devise1);

reader.Seek("d2", out devise2);

 

// conversion des valeurs alpha en valeur de l'énumération

p1 = (Currency)Enum.Parse(typeof(Currency), devise1, true);

p2 = (Currency)Enum.Parse(typeof(Currency), devise2, true);

 

// appel du service Web. ConversionRate a été générée par .net

double retour = conv.ConversionRate(p1, p2);

return "<taux>" + retour.ToString();

}

catch (System.Exception e)

{

return e.ToString();

}

}

 

La fonction ConvertirDevises doit obligatoirement avoir cette signature. Tous les paramètres d'entrée sont passés dans une variable de type string et toutes les valeurs retournées sont également passées dans une variable de type string.

Nous avons choisi de placer les deux paramètres dans une chaine Hmp. Les appels à reader.Seek permettent de récupérer les deux paramètres d'entrée.

Petite complication : le service attend des données de type Currency. Ce type est une énumération contenant la liste des codes de devises (USD EUR etc.). Les appels à Enum.Parse permettent de convertir les paramètres alphanumériques dans ce type. En cas d'échec, une exception est levée.

Ensuite l'appel à ConversionRate permet d'obtenir le taux de conversion en invoquant le service web.

Puis le résultat est placé dans une chaine Hmp.

 

Ecriture du programme diva pour appeler le service Web

 

1 assembly L ; identifiant de l'assembly

1 idConvertir L ; id méthode pour obtenir le taux

1 messageErreur S

1 retour S

1 param  S

1 valeur S

main

; chargement de l'assembly

assembly = AssemblyLoad("dllServiceWebNonDiva.dll")

if assembly = 0

AssemblyGetError(messageErreur)

messageBox(messageErreur," ")

ProgramExit

endif

 

; chercher la fonction ConvertirDevises

idConvertir = AssemblyGetMethod(Assembly,"ConvertirDevises")

if idConvertir = 0

AssemblyGetError(messageErreur)

messageBox(messageErreur," ")

ProgramExit

endif

 

AssemblyMethodInvoke(assembly,idConvertir,"<d1>" & "EUR" & "<d2>" & "USD", retour)

 

; si on a recu une chaine HMP on en extrait la valeur

; sinon c'est une erreur

if HmpVerify(retour)

hmpRead(retour,param,valeur)

MessageBox("valeur"," ")

else

messageBox(retour,"Erreur")

endif

ProgramExit
