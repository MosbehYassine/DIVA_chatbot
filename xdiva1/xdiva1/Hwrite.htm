Hwrite  Famille Thème

 

Hwrite écrit un nouvel enregistrement dans un fichier.

 

Ptr = Hwrite ( tdf , variable [ , code_réservation ] )

Paramètres

Tdf

Table de définition de fichier.

Variable

Donnée à écrire dans le fichier.

Code_réservation

Mode de partage de l'enregistrement ('P' par défaut).
Il est possible de réserver le nouvel enregistrement écrit. L'enregistrement écrit ne sera donc pas accessible aux autres tâches tant qu'il ne sera pas libéré.

 

Retour

0  

Pas d'erreur.

 

Toutes les erreurs provoquent l'arrêt du programme.

 

Remarques

L'écriture dans un fichier de type N, C ou U est toujours séquentielle, c'est à dire que les données sont toujours écrites en fin de fichier.

Lors de l'écriture d'un enregistrement comportant une zone packée, les données dépackées sont compressés dans la zone packée et l'écriture se fait automatiquement sur le champ Write de l'enregistrement. La zone dépackée n'est donc pas écrite dans le fichier (Voir Record).

 
Fichiers normaux (N) avec taille d'enregistrement variable

L'enregistrement aura pour longueur la taille de la variable donnée en paramètre.

 

Fichiers normaux (N) avec taille d'enregistrement fixe

Le système écrit un enregistrement ayant la longueur indiquée à la création du fichier, en effectuant une éventuelle troncature ou une complémentation à droite avec des espaces.

 

Fichiers séquentiels-indexés (I)

L'enregistrement est écrit à la fin du fichier des données et le système crée toutes les clés inconditionnelles et ne crée que les clés conditionnelles pour lesquelles la condition est remplie.

Si le fichier des données est de type N avec taille d'enregistrement fixe, le système écrit un enregistrement ayant la longueur indiquée à la création du fichier, en effectuant une éventuelle troncature ou une complémentation à droite avec des espaces.

Si le fichier des données est de type N avec taille d'enregistrement variable, l'enregistrement aura pour longueur la taille de la variable donnée en paramètre.

 

Exemple

 Soit le fichier séquentiel-indexé de factures FFAC contenant deux types d'enregistrements :
 - un type entête,
 - un type ligne détail.

Le fichier des données est de type N à taille d'enregistrement variable.

Les instructions suivantes créent une entête et une ligne détail :

1 entete 80

1 detail 120

st = Hwrite(ffac , entete ) ; crée un enreg. de longueur 80 

st = Hwrite(ffac , detail ) ; crée un enreg. de longueur 120
