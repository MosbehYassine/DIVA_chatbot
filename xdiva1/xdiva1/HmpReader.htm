HmpReader Famille  Thème

 

Pour passer plusieurs paramètres à la méthode appelée par AssemblyInvoke il y a de nombreuses possibilités telles que :

- séparer les valeurs par des virgules,

- utiliser XML

- utiliser HMP

- etc.

 

HMP est couramment utilisé dans les applications Harmony. Il est très simple à mettre en oeuvre.

Voir Harmony Markup Parametres HMP

 

Coté .net, Harmony met à disposition la classe HmpReader permettant de lire une chaîne HMP. Cette classe se trouve dans l'assembly /divalto/sys/DhSystemTools.dll

 

Les méthodes de cette classe sont :

 

public HmpReader(string c)

Constructeur de la classe en lui passant la chaîne HMP.

 

public bool Seek(string param, out string valeur)

Recherche d'un élément dans la chaïne. (HmpSeek)

 

public int Read(out string param, out string resultat)

Lecture du couple paramètre-valeur suivant. (HmpRead)

 

public bool Verify()

Vérification d'une chaîne HMP (HmpVerify)

 

public static string HmpEncode(string chaine)

Fonction statique permettant d'encoder les caractères spéciaux. (HmpEncode).
