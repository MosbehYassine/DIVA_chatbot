Masque

 
Les paramètres généraux du masque sont :
 

Libellé

Commentaire identifiant le masque.
Ce libellé s'applique au masque global (c'est à dire à l'ensemble des blocs).
 

Modifié le

par

Date de la dernière intervention.

Code du dernier utilisateur qui est intervenu sur le masque.
 

Feuille de styles

Nom de la feuille de styles à utiliser (fStyleImp.dhfi par défaut).
 

Code langue du masque

Code de la langue d'origine du masque.
Renseignez cette zone si le masque est conçu dans une langue nécessitant l'application d'un code page non standard (le code page standard de Divalto est le code page "Occidental").

Exemple : PL (polonais).
 

Restriction sur le périmètre de prise en compte du code langue du masque :
Dans l'atelier de développement Xwin, la possibilité de saisir des textes, dans une langue à code page non standard, est limitée aux libellés des objets posés dans le masque et imprimés à l'exécution (par exemple, la propriété "Texte" d'un objet Texte ou Case à cocher). Elle ne concerne pas les libellés "propres" à l'atelier (par exemple, la propriété "Libellé" des boîtes de dialogue des paramètres du masque ou du bloc). Pour ces derniers, il est préconisé de les saisir en langue anglaise.
 

Taille d'une ligne /
colonne  

Taille d'une ligne / colonne en orteils.
Ces tailles déterminent la "grille" du masque.
 

Nombre de lignes /
colonnes

Nombre de lignes / colonnes d'une page.

Le nombre de lignes est significatif si l'option "D'après le masque" du groupe radio "Taille de la page" est sélectionnée ou si le programme Diva ne précise pas cette valeur (Inblignes = 0, cf. chapitre "Réglage de la hauteur de page" du livre consacré à ymig).
Attention : De plus, il est important de renseigner correctement le nombre de lignes par page avant de faire évoluer un masque conçu au départ sans objet Tableau vers une version de ce masque incluant l'objet Tableau.

Le nombre de colonnes est utilisé par Ymig pour adapter le masque à la taille du papier.
 

Orientation

Les valeurs possibles sont Portrait, Paysage et Défaut.
Défaut demande que l'orientation soit celle spécifiée dans le gestionnaire d'imprimantes de windows.
 

Hauteur de la page

  • D'après le modèle : le nombre de lignes par page est spécifié par le programme Diva.
    Ce nombre est généralement fourni par le modèle d'imprimante choisi (Cf. livre consacré au menu Hmenu). Dans ce cas, le nombre de lignes spécifié plus haut n'est pas significatif. Il faut alors veiller à ce que les positions de fin de certains blocs soient exprimées en valeurs négatives (cf. Position des blocs).

  • D'après le masque : le nombre de lignes par page est spécifié par les paramètres du masque.
    Dans ce cas, le nombre de lignes par page est indépendant du modèle d'imprimante choisi. Il est conseillé de sélectionner ce choix si le masque contient un bloc de fond. En effet, un état contenant un bloc de fond doit toujours avoir le même nombre de lignes.

Taille Fixe

 

Indique que le masque d'impression est en mode impression fixe ou non.
Le bouton Recalculer Taille Fixe permet de recalculer les paramètres en fonction du driver d'impression.
 

Pages X/N

Impression du nombre total de pages.

Voir Impression du nombre total de pages dans la documentation Ymig.
 

 

Cadre Traitements

Traitement initial

Ce traitement est exécuté une seule fois, au chargement du masque.
Peut être utilisé en particulier pour effectuer des initialisations.

Vous pouvez saisir le nom manuellement ou cliquer sur la flèche, auquel cas vous ouvrez un menu contextuel (voir Saisie d'un nom de traitement).
 

 

Cadre Surcharge

Surcharge des traitements uniquement

Masque de surcharge uniquement :

  • Case cochée : seule la surcharge des traitements est autorisée.

  • Case non cochée : les dessins et les traitements peuvent être surchargés.

 

Cadre Assistant de personnalisation : Voir la rubrique Propriétés du masque spécifiques à l'assistant.
 
 

Le bouton Adresses donne accès à la boîte de dialogue permettant de paramétrer les différentes adresses de destination de l'état : voir Adresses de destination d'une édition Xwin.
