Destinations de l'état

Cette boîte de dialogue est accessible depuis la boîte de dialogue des paramètres du masque (bouton Adresses).

Elle permet de paramétrer deux adresses différentes (une adresse fax et une adresse E-Mail par exemple) avec ou sans impression.

Attention : la gestion des adresses nécessite l'installation préalable du produit Exchange de Microsoft. De plus, cette possibilité n'existe pas pour les masques caractères.

 

Impression et envoi de l'édition

Par défaut, une édition est toujours envoyée à l'imprimante, il n'y a donc rien à paramétrer dans la boîte de dialogue "Destination de l'état", sauf si vous indiquez une ou deux adresses de destination. Dans ce cas, pour que l'édition soit systématiquement envoyée à l'imprimante en plus des adresses indiquées, il faut le préciser dans la page de l'onglet "Impression".

 

Paramètres constants ou variables

Il y a deux méthodes pour donner la valeur de chaque paramètre :

  • donner directement sa valeur dans le masque Xwin (pour le sujet de l'édition par exemple). Ce mode est appelé "mode constante".

  • indiquer une variable qui contiendra la valeur lors de l'exécution (le numéro de fax du client par exemple). Ce mode est appelé "mode variable".
    Ce deuxième mode permet par exemple d'envoyer automatiquement une commande par fax à un fournisseur, le numéro de fax étant contenu dans la fiche fournisseur.
    Dans ce cas, les variables devront être renseignées avant la demande d'impression du premier bloc de l'état, soit par le programme Diva, soit dans le point de traitement avant gestion.

 

Paramètres

Les pages des deux premiers onglets sont identiques, elles concernent chacune une des deux adresses possibles. La page de l'onglet impression indique si l'état doit être imprimé ou non.

La colonne Variable indique pour chaque paramètre s'il s'agit d'une constante ou d'une variable. Si vous cochez cette case, Xwin vous demande de choisir la donnée par la méthode habituelle. Pour changer ultérieurement de variable, il faut cliquer sur la flèche qui se trouve à droite de la ligne.

Les paramètres à saisir sont :

Type 

Il s'agit du type de l'adresse du destinataire. Il permet de faire le lien avec le driver de transport de messagerie qui doit être utilisé pour envoyer l'édition. Pour plus de détails sur les différents types d'adresses, voir le programme DivaltoViewer.
En mode constante, il peut prendre une des valeurs suivantes :
Rien : cette adresse ne doit pas être prise en compte.
Impression : l'état doit être imprimé. Ce choix présente surtout un intérêt en mode variable, qui permet de choisir au moment de l'exécution si l'état doit être imprimé ou non.
Fax : l'adresse est un numéro de fax.
Mail : l'adresse est de type mail.
E-Mail : l'adresse est une adresse Internet.
Autre : l'adresse est d'un autre type.
Fax2,
Mail2,
E-Mail2 et
Autre2 représentent les mêmes types que Fax, Mail etc. mais en utilisant un deuxième type de driver de transport de messagerie.
Adresse Directe : Dans ce mode, le champ Adresse contient l'adresse complète du destinataire.

En mode variable, la donnée contenant le type doit être de type L, X ou B. A l'exécution elle doit contenir une des valeurs suivantes :  
0 ou 1 correspondent à Rien,
2 à Impression,
3 à Fax,
4 à Mail,
5 à E-Mail,
6 à Autre,
7 à Fax2,
8 à Mail2,
9 à E-Mail2,
10 àAutre2,
11 àAdresse Directe.

Remarque : A l'exécution, il ne peut y avoir plus d'une impression, quelque soit l'état des paramètres.

Adresse 

Indique l'adresse du destinataire. Le format de l'adresse varie en fonction du type précédemment défini.

En mode constante, les éditions iront toujours au même destinataire, ce qui est d'un intérêt limité.

En mode variable, la variable doit être de type alpha-numérique d'une longueur maximum de 256 caractères. Si le type de l'adresse est autre que Rien ou Impression, ce champ est obligatoire.

Ce champ est limité à 2048 caractères et peut contenir jusqu'à 32 adresses (de 63 caractères), séparées par un ";".
Exemples :
xxx@divalto.fr;yyy@hotmail.fr;...
<mailto:xxx@divalto.fr;yyy@hotmail.fr>;...

Sans autre précision, l'édition est adressée à un destinataire classique ("A..."). Mais vous pouvez aussi nommer des destinataires en copie et/ou en copie invisible. Pour cela, spécifiez devant l'adresse :
Cc:   (pour Copie à)
Bcc: (pour Copie invisible à)

Exemples :
xxx@divalto.fr;cc:yyy@divalto.fr;cc:zzz@divalto.fr;bcc:test@hotmail.fr;...
<mailto:xxx@divalto.fr;cc:yyy@divalto.fr;cc:zzz@divalto.fr;bcc:test@hotmail.fr>;...

Sujet 

Indique le sujet de l'édition. Ce texte est affiché dans Exchange pour présenter la liste des messages.

En mode constante, le sujet est figé.

En mode variable, la variable doit être de type alpha-numérique d'une longueur maximum de 256 caractères. Si le type est autre que Rien ou Impression, ce champ est obligatoire.

Message 

Il s'agit d'un petit texte de présentation facultatif qui est intégré à l'édition. Lors de la visualisation d'un message dans Exchange, on voit le sujet, le texte contenu dans la zone Message et une icone représentant l'édition Harmony.
En mode constante, le message est figé.

En mode variable, la variable doit être de type alpha-numérique d'une longueur maximum de 2048 caractères.

Si cette zone message est garnie pour une adresse de type Fax, la première page du fax contiendra seulement le contenu de la zone Message et l'édition de l'état Harmony commencera alors sur la deuxième page.

Profil

Il s'agit du profil utilisateur à utiliser dans Exchange. Si cette zone n'est pas renseignée, c'est le profil par défaut de Exchange ou celui paramétré au niveau de DivaltoViewer qui sera utilisé (cas le plus courant).

En mode constante, le profil est figé.

En mode variable, la variable doit être de type alpha-numérique d'une longueur maximum de 256 caractères.

Mot de passe 

Il s'agit du mot de passe associé au profil si ce dernier n'est pas le profil par défaut. Si cette zone n'est pas renseignée et si le profil est figé, l'envoi de l'édition utilisera le mot de passe paramétré dans DivaltoViewer.

En mode constante, le mot de passe est figé.

En mode variable, la variable doit être de type alpha-numérique d'une longueur maximum de 256 caractères.
