Images

Cette boîte de dialogue permet d'ajouter, de modifier ou de supprimer une image de la feuille de styles. Elle propose la liste des images existantes, la zone Nom et l'ensemble des caractéristiques d'une image.

  • Pour modifier une image, sélectionnez-la dans la liste ou tapez son nom, modifiez les paramètres voulus puis cliquez sur le bouton Modifier.

  • Pour créer une image, tapez son nom, saisissez les paramètres puis cliquez sur le bouton Ajouter.

  • Pour supprimer une image, sélectionnez-la dans la liste ou tapez son nom puis cliquez sur le bouton Supprimer.

Remarque : si le nom dans la liste est précédé d'une étoile, cela signifie que l'image correspondante se trouve dans la feuille de styles de surcharge.

 

 

Les paramètres d'une image (imprimante) sont les suivants :

 

1. Paramètres dont la modification est répercutée sur les images déjà insérées dans le masque :

 

Nom

Nom donné à l'image dans la feuille de styles.

Fichier
image

Nom du fichier contenant l'image.
Exemple : Bitmap1.bmp

Remarque : des images bitmaps "standard" peuvent être référencées ici à la place d'un nom de fichier. Le nom à indiquer est alors un nom conventionnel commençant par le caractère de reconnaissance # (consultez les images de fstyleImp.dhfi pour connaître ces noms).

Numéro

Numéro de la bitmap à l'intérieur du fichier si le fichier est de type .exe, .ico ou .dll. Sinon, ce numéro doit être nul.

Petite icone

Si le fichier est un .ico, cette case permet de choisir la petite icone (16x16) plutôt que la grande. Si la petite icone n'existe pas, la grande icone est réduite.

 

 

2. Paramètres dont la modification n'est pas répercutée sur les images déjà insérées dans le masque :

 

Couleur du fond

Avant l'affichage, la surface de la boîte est effacée avec cette couleur de fond.
Remarque : on ne verra cette couleur que :
- si la boîte est plus grande que l'image.
- si l'image est du type .ico et qu'elle est transparente.

Traitement de l'image

Pas de traitement

L'image est affichée sans aucun traitement.

 

Réduire si débordement

L'image est réduite pour qu'elle tienne entièrement dans la boîte. Le traitement respecte les proportions de l'image.

 

Pleine boîte

L'image est agrandie en largeur et hauteur de façon à remplir la boîte. Ce traitement ne respecte pas les proportions de l'image.

 

Pleine largeur

L'image est agrandie en largeur de façon à remplir la boîte. Ce traitement respecte les proportions de l'image. Il se peut donc qu'elle soit rognée en hauteur.

 

Pleine hauteur

L'image est agrandie en hauteur de façon à remplir la boîte. Ce traitement respecte les proportions de l'image. Il se peut donc qu'elle soit rognée en largeur.

 

Taille maximum

L'image est agrandie au maximum en respectant les proportions de l'image.

 

Mosaïque

L'image est répétée autant de fois que nécessaire pour remplir la boîte.

 

Centrer

L'image est centrée dans la boîte.

Adapter la bitmap à la couleur de fond

Si cette case est cochée, la couleur du pixel en haut à gauche de l'image est remplacée par la couleur du fond sur lequel la bitmap est affichée.

Imprimer selon la résolution de l’image

Indique que l’image doit être imprimée avec la taille contenue dans le fichier image, ce qui permet d’imprimer des images au format exact où elles ont été créées.

Noms de l'objet

Nom(s) donné(s) à l'image pour sa gestion par les attributs dynamiques.
Séparez les différents noms par une virgule ou un point-virgule.
