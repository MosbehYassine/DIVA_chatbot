Style

Un style regroupe les trois attributs de présentation (décrits dans les trois rubriques précédentes) des objets courants : police de caractère, couleur de fond et encadrement. Ses différents paramètres sont donc un nom de police, un nom de couleur et un nom d'encadrement dans la feuille de styles.

A chaque objet concerné placé dans le masque, Xwin permet d'associer un style particulier, identifié par un nom dans la feuille de styles. Lors du choix du style pour cet objet, il suffira de spécifier son nom dans la propriété Style pour lui affecter l'ensemble de ses paramètres. Ainsi, il suffit de spécifier uniquement un nom de style pour que tous les attributs de présentation de l’objet soient positionnés.

 

Exemple :

Vous pouvez définir ainsi le style STD :

Police

:

STD

Couleur

:

TRANS

Encadrement

:

SANS

 

Personnalisation d'un style

Pour un maximum de souplesse, Xwin vous permet de modifier localement, pour un objet précis, chacun des paramètres du style. Vous pouvez donc par exemple changer la police d’un texte sans avoir à apporter de modification à la feuille de styles.
