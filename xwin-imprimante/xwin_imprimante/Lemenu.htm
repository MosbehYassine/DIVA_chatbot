Menu et barre d'outils de l'éditeur de masques d'imprimante

 

Le menu de l'éditeur de masques d'imprimante est très comparable à celui des masques d'écran. Signalons simplement que :

  • Le menu Fichier comporte le choix spécifique :

    • Imprimer une maquette... qui ouvre une boîte de dialogue permettant de sélectionner un fichier maquette à imprimer.
       

  • Le menu Edition comporte le choix supplémentaire :

    • Transformer la sélection en tableau, qui permet de convertir un objet Cadre et son en-tête en objet Tableau.
       

  • Le menu Pages est remplacé par le menu Blocs  :

    • Premier : Positionnement sur le premier bloc du masque.

    • Dernier : Positionnement sur le dernier bloc du masque.

    • Suivant : Positionnement sur le bloc suivant.

    • Précédent : Positionnement sur le bloc précédent.

    • Numéro : Positionnement sur un bloc précis en donnant son numéro.

    • Insérer : Insertion d'un bloc avant le bloc en cours.

    • Supprimer : Suppression du bloc courant.

    • Créer le bloc auxiliaire / Afficher le bloc auxiliaire / Afficher le bloc principal : Création d'un bloc auxiliaire du bloc courant / Editer le bloc auxiliaire du bloc principal courant / Editer le bloc principal du bloc auxiliaire courant.

    • Simuler un état : Visualisation de plusieurs blocs à l'écran de Xwin permettant d'avoir une vue globale de l'état.

    • Liste des objets : Ouvre une fenêtre avec la liste de tous les objets du bloc.

    • Liste des noms : Ouvre une fenêtre avec la liste de tous les noms des objets (attributs dynamiques).
       

  • Le menu Paramètres comporte le choix supplémentaire :

    • Mode Wysiwyg qui permet d'activer ou de désactiver le mode WYSIWYG et de modifier la taille de l'affichage (zoom) à l'écran.
       

  • Le menu Fenêtre comporte le choix supplémentaire :

    • Tableaux (raccourci clavier Alt+4), qui permet d'afficher la fenêtre "Tableaux" (arbre des tableaux du bloc - masque imprimante graphique uniquement) dans la barre d'onglets verticaux.

 

La barre d'outils de l'éditeur de masques d'imprimante est très comparable à celle des masques d'écran. Signalons simplement les boutons :

  •      Créer ou afficher le bloc auxiliaire / Retour au bloc principal.

  •      Afficher / Masquer la grille (option générale des éditeurs de masque).
