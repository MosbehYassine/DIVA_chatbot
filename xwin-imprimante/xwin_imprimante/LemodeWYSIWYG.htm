Le mode WYSIWYG

Le terme WYSIWYG est une contraction de "What you see is what you get". Un état imprimé est dit en mode wisiwyg si le résultat imprimé est l'image exacte de ce qui est vu à l'écran.

 

Choix du driver d'imprimante

Pour réaliser la correspondance entre l'écran et l'imprimante, Xwin a impérativement besoin d'un driver d'imprimante. Si aucune imprimante n'est installée, installez un driver standard d'imprimante laser.

Si plusieurs drivers d'imprimantes sont installés, Xwin utilise le driver défini dans Divalto.ini au chapitre [GraphPrinter]. Si ce chapitre est absent, Xwin utilise le driver de l'imprimante par défaut de Windows.

 

Choix des polices

Seules les polices True Type permettent de réaliser l'affichage et l'impression en mode WYSIWYG. Il est donc conseillé de ne pas utiliser de polices qui ne soient pas True Type (Ms Sans Serif par exemple).

 

Mise en œuvre

Le choix Mode WYSIWYG du menu Paramètres permet d'activer ou désactiver le mode WYSIWYG et de modifier la taille de l'affichage (zoom) à l'écran.
