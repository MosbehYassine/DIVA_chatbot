Objet Image variable

Les paramètres spécifiques de l'objet Image variable sont :
 

Famille Présentation

Fond

Nom d'une couleur de fond dans la feuille de styles.
La couleur TRANS (transparente) est prise par défaut (la couleur utilisée sera alors soit celle du fond de la page, soit celle du cadre plein sur lequel l'image est placée).

Traitement de l'image

Pas de traitement

L'image est imprimée sans aucun traitement.

 

Réduire si débordement

L'image est réduite pour qu'elle tienne entièrement dans la boîte. Le traitement respecte les proportions de l'image.

 

Pleine boîte

L'image est agrandie en largeur et hauteur de façon à remplir la boîte. Ce traitement ne respecte pas les proportions de l'image.

 

Pleine largeur

L'image est agrandie en largeur de façon à remplir la boîte. Ce traitement respecte les proportions de l'image. Il se peut donc qu'elle soit rognée en hauteur.

 

Pleine hauteur

L'image est agrandie en hauteur de façon à remplir la boîte. Ce traitement respecte les proportions de l'image. Il se peut donc qu'elle soit rognée en largeur.

 

Taille maximum

L'image est agrandie au maximum en respectant les proportions de l'image.

 

Mosaïque

L'image est répétée autant de fois que nécessaire pour remplir la boîte.

 

Centrer

L'image est centrée dans la boîte.

Adapter à la couleur de fond

Si cette case est cochée, la couleur du pixel en haut à gauche de l'image est remplacée par la couleur de fond sur laquelle l'image est affichée.

Exemple : sans : avec :

 

Exemple

 

fichier[;numero] : fichier image (et numéro d'image) à afficher dans Xwin.

Cette propriété est uniquement utilisée par Xwin et n'a aucune incidence à l'exécution.

Imprimer selon la résolution de l’image

Indique que l’image doit être imprimée avec la taille contenue dans le fichier image.
Cela permet d’imprimer des images au format exact ou elles ont été créées.

 

Contenu de la donnée associée à l'objet bitmap variable

La variable peut contenir :

  • soit le nom d'un fichier .bmp, .gif, .jpg, .png, .rle, .dib, .tga, .tif, .ico, .dll, .exe,

  • soit un nom d'image dans la feuille de style du masque,

  • soit un nom de bitmap interne précédé du caractère # (ce sont les bitmaps de la feuille de style dont le nom de fichier commence par #),

Exemples :

filemove.bmp 

Fichier filemove.bmp dans Divalto\sys.

AFF_COMPTA 

Nom de bitmap dans la feuille de styles.

#aff_compta 

Nom interne (identique à la précédente).

 

A) Cas particulier pour les .ico , .dll et .exe

Par défaut, pour les types de fichier ico, .dll et .exe, c'est la premiere icone contenue dans le fichier qui est prise, mais vous pouvez charger une autre icone en plaçant son numéro précédé d'un ;

Exemples :

"xrtdiva.exe" ou "xrtdiva.exe;0"

Première icone contenue dans le fichier xrtdiva.exe.

"xrtdiva.exe;1"

Deuxième icone contenue dans le fichier xrtdiva.exe.

"xrtdiva.exe;3"

Quatrième icone contenue dans le fichier xrtdiva.exe.

 

Par défaut , l'icone sera affichée en 32 x 32 , mais vous pouvez aussi demander d'afficher la petite icone associée (16 x 16). Pour cela, le numéro de l'icone doit être suivi de deux paramètres vides, puis du chiffre 1.
Exemple : bitmap = "xrtdiva.exe;0;;;1" --> première icone en petit.

 

B ) Cas particulier pour les fichier .tif

Les fichiers .tif peuvent contenir plusieurs images, par défaut c'est la première qui est affichée.

On peut charger une autre image comme pour les fichiers icones. Pour cela, le nom du fichier doit être suivi du numéro précédé d'un ;.

Exemples :

"toto.tif" ou "toto.tif;0"

Première image.

"toto.tif;1"

Deuxième image.

"toto.tifi;3"

Quatrième image.
