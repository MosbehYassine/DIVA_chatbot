Objet Code-Barre

Les paramètres spécifiques de l'objet Code-Barre sont :
 

Type

Type du code-barre.
Le type "à l'exécution" permet de paramétrer le code-barre au moment de l'exécution du programme.

Dans ce cas, les 6 premiers caractères de la donnée sont utilisés pour le paramétrage du code-barre, la valeur du code-barre devant donc commencer à partir du 7ème caractère.

Ces 6 premiers caractères doivent être initialisés à espaces.:

l Les deux premiers caractères doivent contenir le type de code-barre entre 1 et 19

1 - EAN 13

2 - EAN 8

3 - UPC A

4 - UPC E

5 - 2OF5 Entrelacé

6 - CODE 39

7 - CODE 39 Plus

8 - CODE 93

9 - CODE 93 Plus

10 - CODE 128 type A

11 - CODE 128 type B

12 - CODE 128 type C

13 - CODE EAN 128 type A

14 - CODE EAN 128 type B

15 - CODE EAN 128 type C

16 - CODABAR

17 - MSI

18 - ITF 14

19 - CODE 11

l Le troisième caractère peut prendre une des valeurs suivantes :

espace Les valeurs par défaut du calcul de la clé et de son affichage seront utilisées.

"1" Pas de calcul de la clé 

"2" Calcul de la clé sans affichage 

"3" Calcul et affichage de la clé. 

Largeur élément

Il s'agit de la largeur de la plus petite barre en centièmes de millimètres.

Calcul de la clé

La clé du code est calculée et les barres correspondantes sont imprimées.

Impression de la clé

Les caractères de la clé sont imprimés en clair. Il faut également cocher la case Impression du texte.

Impression du texte

Le texte (le contenu de la donnée) est imprimé en clair sous les barres.

Impression du type

Le type est imprimé en clair au dessus des barres.

Impression verticale

L'objet est tourné de 90 degrés.

Encadrement

Encadrement de l'objet.

Chiffres supplémentaires vers le bas

Si le code contient des chiffres supplémentaires, il sont par défaut affichés au dessus des barres. Cette case permet de les afficher en dessous. Vous pouvez tester ce cas en choisissant le type Ean13 et en tapant la valeur 123456789012-12 dans la zone exemple.

Code barre de type 20 et 21

Dans les codes barres GENCOD, Il existe un cas ou l’on doit utiliser le code 128c ou ean 128c mais en mettant aussi le code fonction 1 (FNC1) dans le corps du code barre.

Pour cela il faut paramétrer l’objet code-barre en type "A l'exécution" dans le masque xwin et programmer en diva de la manière suivante :

1 car  1 ;pour contenir le code FNC1

2 carb b 

1 p1  14 ;exemple de valeurs p1 p2 etc

1 p2  6

 

carb = 174                 ;code interne de FNC1, l'objet code barre prend ce code

                           ;comme étant FNC1

p1 = "93067280054950"      ;exemple de GENCOD : ean 13 + quantité , attention

                           ;multiple de 2 avec des 0 au lieu de espace

p2 = "018750"              ;DLUO + nb de DLUO , attention multiple de 2 avec ces 0 au

                           ;lieu de espace

; la valeur du code barre est

Form.codebarre "201 " & car & p1 & car & p2   ;CODE128C ou

Form.codebarre "211 " & car & p1 & car & p2   ;EAN128C

 

En mode "A l'exécution" les 6 premiers caractères sont :

  • Typecbarre 2,0

  • calculcle  1,0 1 ou esp=aucun 2=calcul clé 3=calcul clé et affichage clé

  • futur  3

  • valeur   reste du champ

 

Les types de code-barre 20 et 21 sont respectivement les mêmes que les types 12 et 15.

  • Type 20 : même type que le type 12, CODE128C, mais sans test que la longueur totale soit un multiple de 2, seule la longueur de chaque élément devant être multiple de 2.

  • Type 21 : même type que le type 15, EAN128C, mais sans test que la longueur totale soit un multiple de 2, seule la longueur de chaque élément devant être doit être multiple de 2.

En effet, il peut y avoir

Form.codebarre = "201 " & car & p1 & car & p2 & car & p3 etc.

ce qui donne un nombre total de caractères impair ce qui provoque une erreur avec les types 12 et 15.

Les codes 20 et 21 ne font pas de test, seule la longueur des éléments p1 , p2 , p3 etc doit être multiple de 2.

 

Remarque

Pour les autres types de codes barre, vous pouvez utiliser la dll YBARCODE  qui prend en charge plus de 140 codes, en particulier des codes 2D.

(Voir l’exemple « Code barres Ybarcode » )
