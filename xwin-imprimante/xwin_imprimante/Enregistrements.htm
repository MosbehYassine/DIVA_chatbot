Enregistrements

Cette boîte de dialogue permet d'indiquer dans quels dictionnaires de données et dans quels enregistrements les données utilisées dans le masque sont recherchées.

La saisie de cette boîte doit être exécutée avant (ou au moment de) l'insertion d'un objet lié à une variable.

  • Pour ajouter un enregistrement à la liste, garnissez les zones Dictionnaire, Enregistrement et Instance puis cliquez sur le bouton Ajouter.

  • Pour supprimer un enregistrement de la liste, sélectionnez-le en cliquant avec la souris puis cliquez sur le bouton Supprimer. La suppression n'est possible que si aucun champ de l'enregistrement n'est utilisé dans le masque.

  • Pour renommer une instance d'enregistrement, sélectionnez-la dans la liste puis cliquez sur le bouton Renommer. Saisissez les nouvelles valeurs.
    Attention     :

    • Tous les objets du masque qui référencent l'instance concernée sont modifiés pour pointer la nouvelle instance.

    • En revanche, aucune modification n'est apportée aux traitements du masque.

 

Les champs à saisir pour l'ajout d'un enregistrement sont :
 

Dictionnaire

Nom du dictionnaire des données. Le bouton situé à droite de la zone permet de rechercher un dictionnaire.

Enregistrement

Nom de l'enregistrement dans le dictionnaire. Le bouton situé à la droite de la zone permet de sélectionner un ou plusieurs enregistrements dans la liste des enregistrements du dictionnaire.

Instance

Le nom de l'instance est facultatif. S'il n'est pas précisé, son nom est le même que celui de l'enregistrement.

Le lien entre l'enregistrement déclaré dans le masque et l'enregistrement du programme Diva se fait d'après ce nom.
 

Exemple :

L'enregistrement Client est déclaré comme suit dans le programme Diva :
 Public Record Demo.dhsd Client Ecli

Pour déclarer ce même enregistrement dans le masque, il faut garnir les zones de la manière suivante :

 

Dictionnaire

:

Demo.dhsd

 

Enregistrement

:

Client

 

Instance

:

Ecli
