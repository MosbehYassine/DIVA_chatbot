Encadrement

Xwin permet d'associer un encadrement à certains objets du masque (libellés, champs, etc.). Le cadre peut être du type :

  • Simple : un cadre simple entoure l'objet.

  • Relief relâché : l'objet est affiché dans une surface ayant l'aspect d'un bouton relâché.

  • Relief enfoncé : l'objet est affiché dans une surface ayant l'aspect d'un bouton enfoncé.

  • Cadre relâché : l'objet est entouré d'un cadre donnant l'impression de relief.

  • Cadre enfoncé : l'objet est entouré d'un cadre qui semble s'enfoncer dans le fond.

A chaque objet concerné placé dans le masque, Xwin permet d'associer un encadrement, identifié par un nom dans la feuille de styles. Lors du choix de l'encadrement pour cet objet, il suffira de spécifier son nom dans la propriété Encadrement pour lui affecter le type de cadre correspondant.

 

Personnalisation d'un encadrement

Pour un maximum de souplesse, Xwin vous permet de modifier localement l'encadrement d'un objet précis et ce, sans avoir à apporter de modification à la feuille de styles.
