Ressources - Stockage

Une ressource (menu ou barre d’outils) est stockée dans un fichier masques d'écran. Vous pouvez :

  • Stocker autant de ressources que vous le désirez dans un même fichier masques.

  • Stocker une ressource dans un fichier masques différent du fichier contenant le ou les masques avec lesquels cette ressource sera affichée à l'exécution (autrement dit, l’utilisation d’une ressource à l’exécution n’est pas limitée aux masques du fichier où elle est stockée). Par exemple, il est parfaitement possible de dessiner une ressource dans un fichier A et, à l’exécution, d’afficher cette ressource sur une page de masque du fichier B. L’association d’une ressource à une page est faite dans le programme Diva, par des fonctions spécifiques.

  • Stocker la surcharge d’une ressource dans un fichier masques différent du fichier contenant la ressource surchargée (une ressource peut d’ailleurs être surchargée plusieurs fois).

 

Remarque : Si vous effectuez une sauvegarde en édition de masque, de ressources, de menu ou de barre d’outils, vous sauvegardez le fichier masques d’écran concerné en globalité (masque lui-même mais aussi toutes ses ressources, menus et barres d’outils).
