Couper une ressource

Des opérations de copier / couper / coller peuvent être effectuées sur les ressources d’un fichier masques. Vous pouvez couper (c’est à dire supprimer avec copie dans le presse-papiers) uniquement une ressource isolée. Pour ce faire :

  • Sélectionnez la ressource dans l’arbre des ressources puis validez le choix Couper du menu Edition (raccourci clavier Maj+Suppr)
    ou
    Cliquez     sur le bouton de la barre d'outils
    ou
    Cliquez droit     sur la ligne de l’arbre des ressources affichant le nom de la ressource à couper (pour la sélectionner) puis validez le choix Couper du menu contextuel.

 

Remarque : La ressource coupée depuis un fichier masques peut être collée dans le même fichier ou dans un fichier masques différent.
