Coller une ressource

Des opérations de copier / couper / coller peuvent être effectuées sur les ressources d’un fichier masques. Vous pouvez coller soit une ressource isolée (précédemment copiée ou coupée), soit l’ensemble des menus ou des barres d’outils (précédemment copié), soit la totalité des ressources (précédemment copiée). Pour ce faire :

  • Validez le choix Coller du menu Edition (raccourci clavier Maj+Inser)
    ou
    Cliquez     sur le bouton de la barre d'outils
    ou
    Cliquez droit     dans la fenêtre des ressources puis validez le choix Coller du menu contextuel.

 

Remarque : Les ressources copiées ou coupées depuis un fichier masques peuvent être collées dans le même fichier ou dans un fichier masques différent.
