Modifier les propriétés d'un bouton de barre d'outils

Pour modifier les paramètres d’un bouton existant :

  1. Sélectionnez le bouton.

  2. Si la fenêtre des propriétés n’est pas affichée, validez le choix Propriétés du menu Edition (raccourci clavier Entrée)
    ou
    Cliquez     sur le bouton de la barre d'outils
    ou
    Cliquez droit     sur le bouton puis validez le choix Propriétés du menu contextuel
    ou
    Cliquez sur l’onglet Propriétés (à droite de l’écran de Xwin).

  3. Saisissez les nouveaux paramètres du bouton dans la fenêtre des propriétés.
