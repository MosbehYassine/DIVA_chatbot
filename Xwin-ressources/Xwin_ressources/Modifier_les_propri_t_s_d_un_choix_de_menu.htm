Modifier les propriétés d'un choix de menu

Pour modifier les paramètres d’un choix existant :

  1. Si ce choix est un choix du menu principal, passez au point suivant.
    Si ce choix est un choix d’un sous-menu de niveau 1, affichez d’abord ce sous-menu en sélectionnant le choix principal correspondant.
    S’il s’agit d’un choix d’un sous-menu de niveau supérieur, poursuivez le même processus jusqu’à afficher ce dernier sous-menu.

  2. Sélectionnez le choix.

  3. Si la fenêtre des propriétés n’est pas affichée, validez le choix Propriétés du menu Edition (raccourci clavier Entrée)
    ou
    Cliquez     sur le bouton de la barre d'outils
    ou
    Cliquez droit     sur le choix puis validez le choix Propriétés du menu contextuel
    ou
    Cliquez sur l’onglet Propriétés (à droite de l’écran de Xwin).

  4. Saisissez les nouveaux paramètres du choix dans la fenêtre des propriétés.
