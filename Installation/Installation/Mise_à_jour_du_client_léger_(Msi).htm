Mise à jour du client léger (Msi)

 

Lorsque la version du serveur change, il faut installer sur les postes clients la version correspondante du client léger.

Vous pouvez configurer le serveur d'applications pour qu'un client léger qui se connecte au serveur avec une ancienne version non compatible se voit automatiquement proposer d’installer la nouvelle version :

  • Appelez l'utilitaire xDivaltoMajini.

  • Au menu "Lecture", sélectionnez le choix "Dans la base de registre globale à l'ordinateur (HKEY_LOCAL_MACHINE)".

  • Si le chapitre ClientLeger n'existe pas, cliquez droit sur la ligne affichant "divalto.ini", sélectionnez le choix "Ajouter un chapitre" et créez le chapitre "ClientLeger".
    Sinon, cliquez droit sur la ligne affichant "ClientLeger" et sélectionnez le choix "Ajouter une valeur".

  • Créer la valeur "UrlTelechargement" et affectez-lui le chemin d'accès au fichier DivaltoSetup.msi correspondant à la nouvelle version du client léger. Par exemple : \\Serveur\LCWebService\DivaltoSetup.msi (où LCWebService est le nom d'un partage pointant sur /Divalto/Internet/LCWebService).
