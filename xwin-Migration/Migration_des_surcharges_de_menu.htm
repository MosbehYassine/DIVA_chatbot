Migration des surcharges de menu

 

L’utilitaire xMigrationMenu.dhop reporte l’ensemble des surcharges d'un menu d’une version d’origine vers une version cible (en général la dernière).


Lancez, depuis le menu Harmony, le choix Migration : Migration des surcharges d'un menu.

 

Sont traités les enregistrements M1, M2, M4 et M7. L'utilitaire identifie champ par champ les modifications apportées par la surcharge puis convertit les enregistrements dans le format de la version cible en leur appliquant les modifications détectées. Elle prend aussi en compte les confidentialités appliquées à des choix de menu.

Les opérations suivantes sont effectuées :

  • Migration des choix de menu.

  • Migration de la table des zooms.

  • Migration des favoris (v6 ou version IA).

  • Migration des états d’impression.

Les nouveaux choix de surcharge ou de zoom sont re-numérotés s’ils entrent en conflit avec de nouveaux choix standard. Un mouchard est produit avec les listes des conflits détectés.

 

Attention : En cas de re-numérotation de zoom ou de choix de menu, il convient de vérifier l’impact sur les appels programmés de ces zooms ou de ces choix.

 

Rappel : Les zooms spécifiques doivent être numérotés à partir de 60 000 pour éviter les conflits avec de nouveaux zooms standard.
