Paramétrage du libellé des dictionnaires spécifiques

 

La colonne Libellé du tableau des efforts affiche un libellé complémentaire pour aider à identifier l'élément. Dans le cas des dictionnaires de données, ce libellé provient d'une table de libellés.

 

Vous pouvez affecter un libellé à vos dictionnaires spécifiques, en ajoutant ces libellés au fichier paramètres MigrationEffort.txt (voir la rubrique Barèmes de calcul des efforts).

Les lignes ajoutées doivent respecter le format suivant :
<DictionnaryLabel><Name>nom.dhsd<Label>libellé

  • <Name> : nom du source du dictionnaire (avec l'extension .dhsd).

  • <Label> : libellé correspondant.

Par exemple :

<DictionnaryLabel><Name>nom1.dhsd<Label>libellé un

<DictionnaryLabel><Name>nom2.dhsd<Label>libellé deux

 

Rappelons qu'un exemple de fichier paramètres est livré sous le nom MigrationEffortSample.txt.
