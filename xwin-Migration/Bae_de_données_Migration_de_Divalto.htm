Base de données Migration de Divalto

 

Au passage d'une version de l'ERP à la suivante, les modifications apportées par Divalto sont inventoriées et enregistrées dans la "Base de données Migration de Divalto". Cette base est consultée par le programme d'estimation de l'effort à produire pour la migration du projet de surcharge.

 

Les objet et les opérations sur ces objets stockés dans la base sont les suivants :

  • Sous-projets supprimés.

  • Sources supprimés (dictionnaires de données, masques d'écran et d'imprimante, modules de programme Diva, dictionnaires de RecordSql).

  • Masques modifiés.

  • Zooms dont le nom du masque a changé (généralement, cela signifie que ce zoom a été "SQLisé").
    Remarque : Ce cas n'est détecté que si le numéro du zoom est resté inchangé dans le fichier a5f entre les deux versions.

  • Dictionnaires de données modifiés :

    • Fichiers supprimés.

    • Tables supprimées.
      Remarque : Les champs de cette table ne sont pas enregistrés dans la base.

    • Tables déplacées dans un autre fichier.

    • Champs modifiés ou supprimés.

    • Index modifiés ou supprimés.

  • Fonctions ou procédures Diva supprimées ou dont le prototype a changé (hors paramètres facultatifs ajoutés).

 

Pour chaque objet enregistré, la base de données contient un "niveau de difficulté" estimé par Divalto pour la migration de cet objet. Ce niveau de difficulté est pris en compte pour estimer l'effort (voir la rubrique Barèmes de calcul des efforts). Les valeurs de la difficulté sont les suivantes :

  • Automatique.
    Cette valeur est par exemple la difficulté par défaut pour un masque modifié par Divalto. En effet, on considère que la surcharge du masque est migrée en utilisant la fonction "Mettre à niveau le projet de surcharge" de Xwin (qui reporte automatiquement les personnalisations du masque effectuées en surcharge vers la nouvelle version du masque standard).

  • Simple.

  • Moyenne.

  • Complexe.

  • A réécrire.
    Cette valeur signifie que l'objet doit être entièrement reconsidéré.

  • Inconnue.
    Cette valeur est par exemple la difficulté par défaut pour toutes les suppressions effectuées par Divalto.

Remarque importante :

Lors d'une migration entre deux versions non consécutives, il est possible qu'un même objet soit répertorié plusieurs fois dans la base. Dans ce cas, c'est la difficulté maximale qui est prise en compte pour l'estimation (la difficulté allant de Automatique à Inconnue dans l'ordre ci-dessus). Les difficultés A réécrire et Inconnue sont de niveaux équivalents et ne sont pas évaluées (un ? est affiché dans la colonne Effort estimé du tableau des efforts).

 

En outre, la base de données contient également des informations complémentaires, non utilisées directement par le programme d'estimation, mais susceptibles d'aider à la valorisation des efforts. Ces informations peuvent être consultées depuis l'écran affichant le tableau des efforts.
