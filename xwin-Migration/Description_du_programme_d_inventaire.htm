Description du tableau d'inventaire

 

L'inventaire est affiché par un programme Diva, dans un tableau arborescent classique.

 

Le tableau d'inventaire présente les colonnes suivantes :
 

Entité

Libellé de la famille ou de l'objet courant.

Exemples de famille : Sous-projets, Sources surcharge, Fonctions, Records.
Exemples d'objet : Sous-projet Xxxx, Dictionnaire Dddd.dhsd, Fichier Fffff, Table Ttttt.

Remarque : L'objet Arbre de Xwin limite la taille de ce libellé à 64 caractères. Il est donc tronqué s'il dépasse cette taille limite. Toutefois, dans ce cas, la bulle associée affiche le libellé complet.
 

Id unique / Compteur

 

Cette zone dépend du type d'objet présenté sur la ligne :

  • Identifiant unique Xwin pour un objet dessiné dans un masque.

  • Compteur.
    Exemples de compteur : Nombre de différences trouvées entre un masque ou un dictionnaire de surcharge et sa base, nombre d'utilisations en surcharge d'un Record de base.

Action

Indique si, dans la surcharge, l'entité courante été ajoutée, modifiée, supprimée, déplacée, surchargée, etc.
 

Libellé

Libellé complémentaire pour, le cas échéant et dans la mesure du possible, aider à identifier l'objet.
Par exemple :

  • Pour un masque, il s'agit du libellé spécifié dans les propriétés générales du masque dans Xwin (lorsqu'il est renseigné).

  • Pour un module, le libellé rappelle le nom du groupe ou du sous-projet où il se situe dans l'arbre du projet de Xwin.

  • Pour un dictionnaire, le libellé est recherché dans une table de libellés. Pour affecter un libellé à vos dictionnaires spécifiques, consultez la rubrique Paramétrage du libellé des dictionnaires spécifiques.

 

 

La première partie de l'inventaire répertorie la totalité des personnalisations apportées au projet Xwin de base. Elle ne liste aucun objet du projet de base.
La structure correspondante de l'arbre de l'inventaire est identique à celle de l'arbre du projet de surcharge (en particulier, on y retrouve l'ordre et le titre des branches employés dans Xwin), à ceci près que les branches vides du projet ne sont pas reportées.

La deuxième partie de l'inventaire donne des informations supplémentaires sur les zooms et certains objets récupérés dans les fichiers .dhbr de navigation (browse).

 

L'arbre d'inventaire présente ainsi les branches suivantes :
 

Groupes de sources surcharge

Liste des groupes de sources ajoutés en surcharge.
Sous chaque groupe, apparaissent les fichiers qu'il contient.
Les personnalisations apportées aux dictionnaires et aux masques surchargés sont listées en détails.
 

Divers surcharge

Simple liste des fichiers placés dans ce dossier.
 

Sous-projets
(surchargés)

Liste des sous-projets surchargés.
Sous chaque sous-projet, apparaissent les sous-branches :

  • Groupes de sources surcharge.
    Simple liste de ces groupes.

  • Sources surcharge.
    Liste des fichiers du sous-projet (normalement, des sources surchargeant les sources de base correspondant).
    Les personnalisations apportées aux dictionnaires et aux masques surchargés sont listées en détails.

  • Divers surcharge.
    Simple liste des fichiers placés dans ce dossier.

Sous-projets surcharge

(spécifiques)

Liste des sous-projets spécifiques.
Sous chaque sous-projet, apparaissent les sous-branches :

  • Groupes de sources.
    Simple liste de ces groupes.

  • Sources.
    Simple liste des fichiers du sous-projet (normalement, des sources spécifiques).

  • Divers.
    Simple liste des fichiers placés dans ce dossier.

Zooms

Liste des zooms (numéro de zoom et nom du fichier masque écran) surchargés (masque et / ou module de traitements).
Obtenue à partir de la table des zooms du fichier a5f(u).dhfi.
 

Zooms spécifiques

Liste des zooms spécifiques (numéro de zoom et nom du fichier masque écran).
Obtenue à partir de la table des zooms du fichier a5f(u).dhfi.
 

Fonctions

Liste des modules qui font appel à des fonctions de base et, sous chaque module, la liste des fonctions qu'il appelle.
 

Hfiles

Liste des instructions diva "Hfile" référençant un fichier de base et utilisées en surcharge ou en spécifique.
 

Records

Liste générale (tous dictionnaires confondus) des tables de base utilisées en surcharge ou en spécifique.
 

RecordsSQL

Liste générale (tous dictionnaires confondus) des tables SQL de base utilisées en surcharge ou en spécifique.
 

Champs diva /
Champs masque

Liste des dictionnaires concernés avec, pour chacun d'eux, la liste des champs de base utilisés en surcharge ou en spécifique :

  • Champs diva : champs utilisés dans un source Diva (y compris les traitements de masques ou de dictionnaires).

  • Champs masque : champs dessinés dans un masque.

Récapitulatif général

Cette branche présente un bilan du nombre global de modifications apportées en surcharge, par type d'objets (nombre de sous-projets surchargés ou spécifiques, nombre total de différences pour les masques ou les dictionnaires surchargés, ...).
 

 

 

La barre d'outils présente les boutons spécifiques suivants :

  • Imprimer.
    Appelle l'impression paramétrable du zoom.
     

  • Tout réduire.
    Seuls les éléments de premier niveau restent affichés dans l'arbre.

  • Tout développer.
    Tous les éléments sont affichés dans l'arbre, quelque soit leur niveau.

  • Développer jusqu'au niveau....
    Permet de spécifier le niveau maximal d'expansion des éléments de l'arbre. Les éléments de niveau supérieur ne sont plus affichés.
     

  • Calculer l'effort.
    Lance le calcul de l'estimation de l'effort à produire pour migrer le projet de surcharge et affiche le tableau de efforts résultant.
    Ce tableau vous permettra ensuite de valoriser les efforts que vous estimerez nécessaires à la migration du projet.
    Remarque : Vous pouvez relancer le calcul une nouvelle fois sans perdre     les valeurs d'effort déjà renseignées.

  • Tableau des efforts.
    Affiche directement le tableau des efforts, à partir du moment où le calcul de l'estimation a déjà été effectué (dans cette session du programme ou dans une session précédente).
    Ce bouton permet donc de consulter le tableau des efforts sans relancer le calcul de l'estimation (opération qui peut être relativement longue pour un gros projet de surcharge).
    Voir la rubrique Revenir ultérieurement au tableau des efforts.
