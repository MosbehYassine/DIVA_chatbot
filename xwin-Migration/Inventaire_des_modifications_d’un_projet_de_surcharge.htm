Inventaire des modifications d’un projet de surcharge

 

Le sous-menu Aide à la migration du menu Projet ou du menu surgissant obtenu en cliquant avec le bouton droit sur le nom du projet dans l'arbre des projets propose les commandes :

  • Inventorier les modifications du projet de surcharge.
    Cette commande :

    • Procède à l'inventaire des personnalisations effectuées sur le projet courant
      (surcharges et développements spécifiques concernant les dictionnaires, les masques, les modules Diva, ...).

    • Écrit la liste des modifications inventoriées dans un fichier log.
      Ce fichier est au format Xml. Il porte le nom du projet de surcharge et il est stocké dans le sous-dossier Xxxx/Migration/Log, où Xxxx est le dossier contenant le projet de surcharge.

    • Appelle l'utilitaire Diva xMigrationInventory.dhop qui affiche cette liste, sous forme arborescente, dans le "Tableau d'inventaire".
      Cet utilitaire permet aussi de lancer le calcul de l'estimation de l'effort à produire pour migrer le projet de surcharge.
       

  • Consulter l'inventaire du projet de surcharge.
    Cette commande affiche directement le tableau d'inventaire, à partir du fichier log précédemment constitué.
    Il permet de consulter le tableau sans refaire l'inventaire, opération qui peut être relativement longue pour un gros projet de surcharge.

Ces choix doivent être appelés après avoir chargé le projet de surcharge à inventorier dans Xwin.

 

 

Principe

Le premier choix fait un état des lieux des surcharges effectuées sur un projet de base. Il dresse l’inventaire détaillé des personnalisations qui lui ont été apportées. Le développeur peut ainsi avoir à la fois une vue d’ensemble et une vue détaillée de l’ampleur d’une surcharge.

L’inventaire présente les informations sous forme arborescente. L’ouverture des branches permet d’accéder aux détails les plus fins.

 

L’inventaire concerne plus précisément :

  • Les masques d’écran, d’impression et les modules Diva standard surchargés.

  • Les masques d’écran, d’impression et les modules Diva spécifiques développés.

  • Les surcharges des dictionnaires de données (*).

  • Les dictionnaires de données spécifiques (**).

  • Les zooms standard surchargés et les zooms spécifiques.
    La liste des zooms est obtenue à partir de la table des zooms du fichier a5f(u).dhfi (***).
    En cas de surcharge, l’inventaire indique si le traitement, le masque ou les deux ont été personnalisés.

(*)  ATTENTION : Nécessite que les dictionnaires de surcharge soient inclus dans le répertoire Sources surcharge d'un sous-projet surchargé (ou dans un Groupe de sources de surcharge du projet).
 

(**) ATTENTION : Nécessite que les dictionnaires spécifiques soient inclus dans le répertoire Sources d'un sous-projet de surcharge (ou dans un Groupe de sources de surcharge du projet).
 

(***) ATTENTION : Nécessite que les fichiers a5f(u) soient en ligne lors de la constitution de l'inventaire.

 

 

L’inventaire se base sur les fichiers .dhbr de navigation (browse) pour fournir les informations suivantes (*) :

  • Les fonctions et procédures standard appelées en surcharge.

  • Les Hfile, Record et RecordSQL utilisés en surcharge.

  • Les champs utilisés en surcharge (dans le dessin d'un masque ou en Diva).

(*) ATTENTION : Nécessite que les fichiers de navigation soient créés et en ligne lors de la constitution de l'inventaire.

 

 

Remarque :

  • L'inventaire ne répertorie pas les surcharges du menu de l'application. En effet, un utilitaire procédant au report de l’ensemble des surcharges d'un menu d’une version d’origine vers une version cible est fourni par ailleurs (voir la rubrique Migration des surcharges de menu).
     

  • Dans un dictionnaire, ne sont répertoriés que les objets "de surcharge".
    Par exemple, dans la liste des tables, les tables de base incluses dans un fichier de surcharge ne sont pas listées (sauf si la table est elle-même surchargée) ; dans la liste des champs, les champs de base inclus dans une table de surcharge ne sont pas listés.
    Par contre (exception à cette règle), tous les champs d'un index de surcharge sont listés.
