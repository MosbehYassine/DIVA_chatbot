Lancement du calcul d'estimation de l'effort

 

A partir du tableau affichant l'inventaire, cliquez sur le bouton Calculer l'effort pour lancer le calcul d'estimation de l'effort et constituer le "Tableau des efforts".

  1. Renseignez les informations suivantes :

    • Version de départ.
      Sélectionnez la version dans laquelle a été développé le projet de surcharge inventorié.

    • Version d'arrivée.
      Sélectionnez la version vers laquelle doit être migré le projet de surcharge inventorié.

    • SQLisation des zooms.
      Cochez cette case si vous comptez SQLiser vos zooms spécifiques. Un barème spécifique est appliqué dans ce cas.

  1. Si ce n'est pas la première fois que ce calcul est demandé, un message vous avertit qu'"Un calcul de l'effort a déjà été réalisé pour cette combinaison de versions".
    Vous pouvez alors choisir ou non de conserver les valeurs d'effort déjà renseignées la fois précédente.

Lorsque le calcul est achevé, le programme affiche une nouvelle page, présentant le tableau des efforts.

 

 

Remarques :

  • Après le passage sur l'écran présentant le tableau des efforts, vous pouvez revenir à tout moment au tableau d'inventaire en cliquant sur le bouton Inventaire.

  • Dans l'écran de l'inventaire, le bouton Tableau des efforts demande le ré-affichage d'un tableau des efforts déjà constitué (dans cette session du programme ou dans une session précédente -voir la rubrique Revenir ultérieurement au tableau des efforts-), ce qui permet de revenir au tableau des efforts sans refaire le calcul (opération qui peut être relativement longue pour un gros projet de surcharge).
