Divalto SAAS

Divalto propose une offre SAAS permettant d’héberger l’ERP dans le cloud. Dans cette architecture :

  1. Les serveurs d’applications sont mutualisés pour l’ensemble des utilisateurs de l’offre.
    Les utilisateurs se connectent aux serveurs à l’aide d’un client léger Wpf  ou Html5.
  2. Chaque site hébergé dispose de sa propre base de données et de répertoires dédiés pour les données propres au site.
  3. Les serveurs de données disposent de services XLAN s’exécutant sur un compte de service propre à chaque site client.
  4. Les services Web s’impersonnent avec un compte de services par site et environnement.
  5. La propagation des paramètres s’effectue par site ou par groupe d’utilisateurs d’un site.
  6. Les services Search s’exécutent par environnement d’un site.
  7. Les fichiers de log sont stockés par site.
  8. Etc.
