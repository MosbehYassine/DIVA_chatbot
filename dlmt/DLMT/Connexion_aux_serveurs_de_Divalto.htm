Connexion aux serveurs de Divalto

DLMT se connecte aux serveurs de Divalto sur l'Url :

https://divawebsce.divaltocloud.com/WebServiceDiva/WebServiceDiva.asmx

 

Dans le cas d’un site Divalto Cloud, la connexion se fait sur les Url suivantes :

https://dlum.divaltocloud.com:443/DlmtCloudService/DlmtCloudService.svc

https://websvc.divaltocloud.com/$SITE$/$ENV$/WebServiceDiva.asmx
où :
$SITE$ représente le numéro de site du client et
$ENV$ représente le nom de l’environnement.
(Cette 2ème Url est utilisée lors de la synchronisation des utilisateurs avec l’ERP.)

L'accès à la plate-forme Beta du Cloud Divalto se fait sur les Url :

https://dlum-rc.divaltocloud.com:443/DlmtCloudService / DlmtCloudService.svc
https://websvc-rc.divaltocloud.com/$SITE$/$ENV$/WebServiceDiva.asmx
