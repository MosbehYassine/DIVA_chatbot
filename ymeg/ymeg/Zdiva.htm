Zdiva

Dans vos programmes, vous serez amené à utiliser des variables " système " (exemples : Harmony.Key, Harmony.Arret, Harmony.Retour) ainsi que des mnémoniques redéfinissant certaines valeurs numériques (exemples : K_ESCAPE, XMENEXT_RESSAISIE, TRUE, FALSE). Ces variables et ces mnémoniques sont déclarés dans le fichier source standard ZDIVA.dhsp.

ZDIVA est automatiquement intégré en tête de vos programmes par le compilateur Diva.

Il contient plus précisément :

  • La déclaration de l'enregistrement SYSTEM
    (défini dans le dictionnaire de données DDSYS.dhsd).
    Cet enregistrement décrit les tables début de tâche ("PATAC") et début de programme ("zone Z"), qui incluent certaines variables "système" concernant la tâche : code utilisateur, nom du programme en cours, etc.

  • La déclaration de l'enregistrement HARMONY
    (défini dans le dictionnaire de données DDSYS.dhsd).
    Cet enregistrement décrit les variables propres à Harmony, comme par exemple Harmony.Arret (numéro du point d'arrêt courant) ou Harmony.Retour (paramètre de la fonction XmeNext).

  • Une liste d'instructions DEFINE associant un mnémonique :
    -     Aux codes de retour des entrées clavier (donnée Harmony.Key) (format : K_xxxx).
    -     Aux codes de reprise dans la saisie d'un masque (donnée Harmony.Retour, paramètre principal de la fonction XmeNext) (format : XMENEXT_xxxx).
    -     Aux modes GOTO et GOSUB, aux paramètres des fonctions menu et barre d’outils, des instructions Diva MessageBox et WindowShow, etc.
