IsRichTextHfileEmpty

Pour vérifier si un fichier " texte riche " est vide

Le nombre d'octets écrits dans un fichier " texte riche " n'est jamais nul car le fichier contient toujours des informations de gestion internes. Pour savoir si l'utilisateur a ou non saisi du texte, le programme doit appeler la fonction Diva IsRichTextHfileEmpty, qui vérifie si le fichier indiqué en paramètre contient une information "utile" saisie par l'utilisateur.

 

Fonction Diva :

Status = IsRichTextHfileEmpty (Nom du fichier texte riche)

 

Compte-rendu renvoyé par la fonction (type X) :

1 = Fichier vide.
2 = Fichier non vide.

 

Exemple :
 

...

IF IsRichTextHfileEmpty (Rtf.Name) = 1

   ...                                        ;fichier vide

ELSE

   ...                                        ;fichier non vide 

ENDIF

...

 

Attention :

Cette fonction ouvre le fichier texte riche en mode partagé. Il est donc interdit de l'appeler si le fichier est déjà ouvert par votre programme en mode réservé.
