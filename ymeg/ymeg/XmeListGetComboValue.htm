XmeListGetComboValue  Famille Thème

Lecture des choix d'un multi-choix (ou d'une case à cocher) placé dans une cellule de tableau

 
Bin XmeListGetComboValue (Masque, Page, Tableau, Colonne, Indice)

 
Paramètres :

Masque

Nom du fichier masque.

Page

Numéro de page.

Tableau

Nom du tableau.

Colonne

Numéro de colonne.

Indice

Indice du choix dans la table des choix (début à 1).

 
Valeur rendue par la fonction :

  • TRUE si un choix existe. Dans ce cas, l’enregistrement Harmony est également garni avec les données suivantes :

  • DataVal

    Libellé du choix.

    DataValComp

    Valeur du choix, convertie au format de stockage de la donnée multi-choix (format fonction de sa longueur LG et de sa nature : B, X, L, numérique, numérique,D ou alpha).
    Vous pouvez ainsi, quelque soit sa nature, utiliser la fonction Diva Left (Harmony.DataValComp, LG) pour comparer / transférer directement la valeur rendue à / dans la donnée multi-choix (voir l’exemple 2).

    Cas des cases à cocher     : la fonction délivre d'abord la valeur associée à l'état non coché puis celle associée à l'état coché.

    CodePageMultiChoix

    Code page.
    Remarques :

    • Le code page est commun à l'ensemble des choix du multi-choix. Tous les choix doivent donc être dans la même langue.

    • La fonction n'analyse que les choix dont le numéro d'ordre est inférieur ou égal à l'indice du choix demandé. Il se peut donc qu'elle délivre la valeur 0 pour les premiers choix puis une valeur non nulle (par exemple, si le multi-choix est déclaré "non obligatoire" dans Xwin car dans ce cas, le 1er choix délivré vaut "Espace" et n'a pas de code page). Par contre, une fois rendu un code page non nul, le code page rendu pour tous les choix suivants sera identique à ce premier code page rendu non nul.

     

    • FALSE dans l’un des trois cas suivants :
      -       La table des choix est terminée (paramètre Indice supérieur au nombre de choix).
      -       La donnée identifiée par son numéro de Colonne dans le tableau n'est pas un multi-choix.
      -       Le libellé du choix contient des caractères non affichables : dans le cas d'un multi-choix de type "Tableau", le libellé est recherché dans un enregistrement ; s’il est invalide, Ywpf ne le délivre pas, considérant que l'enregistrement n'a pas encore été garni.

     

    Description de la fonction :

    • La fonction XmeListGetComboValue lit le Indice ème choix de la donnée multi-choix placée dans la colonne numérotée Colonne, du tableau identifié par le nom du fichier Masque plus le numéro de Page où il a été dessiné et par le nom de Tableau qui lui a été attribué dans Xwin.

    • Le paramètre Colonne est le numéro d'ordre de la colonne dans le tableau, l'ordre à considérer étant celui défini dans Xwin. Les numéros sont calculés à la compilation du masque : ils n'évoluent pas en exploitation, même si l'utilisateur intervertit des colonnes.   

     

    Exemple 1 : Boucle de lecture des choix d'un multi-choix (colonne 3 du tableau nommé TABLEAU et situé en page 2 du masque ETABLE).
     

    Indice = 1

    LOOP XmeListGetComboValue ("ETABLE",2,"TABLEAU",3,Indice)

       DISPLAY (Harmony.DataVal)

       Indice ++

    ENDLOOP

     

    Exemple 2 : Pour un choix de valeur "12", Harmony.DataValComp contiendra :

Nature B       : $0C

Nature X       : $0C $00

Nature L       : $0C $00 $00 $00

Nature Num 5,0 : " 12"

Nature Alpha 5 : "12 "
