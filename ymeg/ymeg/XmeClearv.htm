XmeClearv  Famille Thème

Effacement des variables d'une page

 

XmeClearv (Nom du fichier masque, Numéro de page, Mode)

 

Paramètres :

Nom du fichier masque
(Harmony.Masque)

Nom du fichier masque.

Numéro de page
(Harmony.Page)

Numéro de la page à afficher.

Mode
(Harmony.Mode)

XME_MODE_GOTO = 0 : mode GOTO
XME_MODE_GOSUB = 2 : mode GOSUB.

 

Description de la fonction :

La fonction XmeClearv est similaire à la fonction XmeDispv mais elle affiche les variables comme si celles-ci contenaient des espaces. Elle permet ainsi d'" initialiser " un masque à l'écran, sans effacer le contenu réel des données affichées.

 

Exemple :

XmeClearv ("Masque",1,XME_MODE_GOSUB)    ;page 1 en mode GOSUB
