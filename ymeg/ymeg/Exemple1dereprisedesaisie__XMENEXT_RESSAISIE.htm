Exemple 1 de reprise de saisie : XMENEXT_RESSAISIE

Le code de retour Harmony.Retour = 3 (XMENEXT_RESSAISIE) permet de revenir à l'input de la donnée courante. Il s'utilise en particulier pour refuser l'entrée d'une valeur incorrecte :

  • Au niveau du masque Xwin, placez sur la donnée un point d'arrêt (respectivement de traitement) "Après". Celui-ci rendra le contrôle au programme appelant (respectivement exécutera une séquence de traitement), après l'input de la donnée par l'utilisateur.

  • A cette occasion, contrôlez la valeur introduite par l'utilisateur. Si le résultat du test est négatif, ordonnez que la donnée soit ressaisie en positionnant Harmony.Retour à la valeur XMENEXT_RESSAISIE.

;Séquence de traitement Après la saisie d'un prix unitaire

 

IF Arti.Puart <= 0

   MessageBox ("Prix incorrect","Message",MB_OK)

   Harmony.Retour = XMENEXT_RESSAISIE         ;ressaisie prix 

ENDIF

 

;Séquence de traitement Après la saisie d'un fournisseur

 

Ffour.Key = "A" & Arti.Codfour                ;clé à chercher

IF HSEEK (Ffour, Four, "F") <> 0              ;recherche code

   MessageBox ("Fournisseur inconnu", "Message", MB_OK)

   Harmony.Retour = XMENEXT_RESSAISIE         ;ressaisie code

ENDIF
