Exemple 3 de reprise de saisie : XMENEXT_SIMULATION_TOUCHE

Illustrons le code de retour Harmony.Retour = 11 (XMENEXT_SIMULATION_TOUCHE) par l’exemple suivant :

  • En cours de saisie d'une donnée, l'utilisateur frappe la touche F1, qui provoque l'affichage d'une fenêtre résumant la signification des touches du clavier pour votre application (appelée fenêtre "piano" dans la suite). Pour cela, vous "piégez" F1 au niveau de la donnée dans Xwin, de façon à ce que votre programme récupère la main lorsque F1 est tapée.

  • Le programme affiche la fenêtre "piano". Supposons maintenant que l'utilisateur frappe une des touches proposée (disons, pour fixer les idées, la touche F8 d'appel d'un zoom). Dans son esprit, l'appel du zoom doit intervenir immédiatement : tout doit se passer comme s'il avait tapé F8 au niveau de la donnée en cours de saisie dans le masque de départ (la touche F8 étant elle-aussi piégée pour cette donnée).

  • Mais en réalité, le masque courant est pour l'instant la fenêtre "piano" : F8 n'a pas été tapée au niveau du masque de départ mais au niveau de la fenêtre "piano".
    La fonction de retour XMENEXT_SIMULATION_TOUCHE va consister à "propager" le code de la touche F8 pour simuler sa frappe dans le masque de départ     : au retour de l'affichage du "piano", Ywpf a placé le code de la touche tapée dans Harmony.Key ; pour simuler la même frappe dans le masque de départ, revenez à sa saisie avec Harmony.Retour = XMENEXT_SIMULATION_TOUCHE et la valeur de Harmony.Key dans Harmony.CplRetour.

 

La reprise dans l'algorithme de saisie de Ywpf se fait au niveau du test des pièges de touche :

                Input de la donnée

                        | 

+----------->           | 

|             Test des pièges de touche

|                       |   | 

|                       |   | F8 

|                       |   +--------> Appel du zoom 

|                       | 

|                       |   F1 

|                       +-------> Appel de la fenêtre "piano"

|                                       | 

|                                       | 

|                                  Frappe de F8

|                                       | 

| Harmony.Retour = 11                   | 

+---------------------------------------+ 

  Harmony.CplRetour = Harmony.Key 

 

 

Exemple :

...

fini = 0                                       ;lance la saisie du masque

XmeInput ("MASQUE",1,0,XME_MODE_GOTO)          ;principal (page 1)

DO

   SWITCH Harmony.Arret 

      ...

 

      CASE 100                                 ;piège de la touche F8 

         ZoomSql (...)                         ;appel du zoom

 

      CASE 200                                 ;piège de la touche F1 

         XmeConsult ("MASQUE",2,XME_MODE_GOSUB);fenêtre "piano" (page 2)

         XmeRet                                ;referme la fenêtre "piano"

                                               ;simulation touche tapée

                                               ;au niveau du "piano" :

         Harmony.Retour = XMENEXT_SIMULATION_TOUCHE 

         Harmony.CplRetour = Harmony.Key

 

      ... 

   ENDSWITCH 

WHILE fini = 0                                 ;suite saisie masque principal

   XmeNext (Harmony.Retour, Harmony.CplRetour) 

WEND

...
