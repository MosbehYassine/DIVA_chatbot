XmeListConsultDefProc

Traitement par défaut en consultation de tableau / arbre
(pour compatibilité avec les versions 5 et antérieures d'Harmony)

 
Int XmeListConsultDefProc (Identifiant, Ligne, Ascenseur, Réponse, [Privilège, Sélection, Perso, MessagesInhibes])

 

 
Description de la fonction :

Cette fonction diffère de XmeListConsultDefault sur trois points :

  • Elle comporte le paramètre supplémentaire Réponse.
    Ce paramètre (type B) doit être garni avec la valeur rendue par la fonction XmeListConsult.

  • La fonction considère le paramètre Réponse et l'ancien code de retour des entrées clavier System.Statin (alors que XmeListConsultDefault considère uniquement le nouveau code de retour clavier Harmony.Key).

  • Elle traite encore les touches F3 (création) et Shift+F3 (suppression).
