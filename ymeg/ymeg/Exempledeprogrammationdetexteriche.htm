Exemple de programmation de texte riche

Remarque préliminaire :

Nous considérons ici comme acquises certaines notions fondamentales de la programmation sous Harmony : déclaration des chemins implicites, paramétrage et mise en œuvre des projets dans l'éditeur Xwin, création des bases, tables et champs dans le dictionnaire, création et paramétrage des masques d'écran, etc.

 

Dans cet exemple :

  • On considérera le masque de saisie d'une fiche "article" (Cf. exemple général de programmation d'une saisie de masque). Chaque article sera numéroté (donnée Arti.Numero de l'enregistrement "article" Arti).

  • Dans le masque, on placera une donnée de type texte riche (Man.WnomRtf, A256), déclarée dans un enregistrement de manoeuvre Man.
    Dans Xwin, on précisera que Man.WnomRtf contient un nom de fichier : pour la donnée, sélectionnez le choix La donnée contient un nom de fichier de la propriété Mode.
    A ce niveau, vous devrez aussi indiquer :
    -     Le format : choix Rich-Text ou Texte de la propriété Format.
    -     La largeur maximale des lignes de texte saisies : propriété Largeur de la famille Présentation.

  • L'édition du texte riche utilisera donc un fichier de manoeuvre :
    -     Nous utiliserons pour cela une fonctionnalité très pratique du langage Diva permettant de déclarer et de créer un fichier temporaire (instructions hTmpFile et TmpFCreate).
    -     Le nom de ce fichier de manoeuvre devra être placé dans la donnée texte riche du masque Xwin (Man.WnomRtf).

  • Les textes seront stockés de manière permanente dans un fichier séquentiel indexé spécifique (Frich.dhfi) :
    -     Avant l'affichage ou la saisie du masque, le texte devra être transféré du fichier Frich dans le fichier de manoeuvre.
    -     Après validation de la saisie du masque, le texte devra être transféré du fichier de manoeuvre dans le fichier Frich.
    A cette occasion :
    -     Si le nouveau texte occupe moins de place que l'ancien, on remplacera les premiers enregistrements (par HREWRITE) et on supprimera les anciens enregistrements restants (par HDELETE).
    -     Si le nouveau texte occupe plus de place que l'ancien, on remplacera les anciens enregistrements (par HREWRITE) et on ajoutera les nouveaux enregistrements restants (par HWRITE). S'il s'agit d'un nouveau texte, on écrira tous les enregistrements par HWRITE.

  • Le fichier de travail ne doit pas avoir de structure particulière d'enregistrement (format DOS). Pour y accéder, nous utiliserons donc les fonctions Diva de lecture et d'écriture " octets " FREADST et FWRITST.

  • Par contre, le fichier de travail doit contenir EXACTEMENT le texte riche : cela signifie que la longueur écrite dans ce fichier doit être PRECISEMENT la longueur du texte.
    Les enregistrements de Frich étant de longueur fixe (508) pour permettre les réécritures, il nous faudra conserver la longueur du texte effectivement présent dans l'enregistrement.

  • L'enregistrement Rich du fichier Frich sera donc composé des données suivantes :
    -     NUMERO (8,0) : numéro d'article qui servira de clé d'accès.
    -     LG (3,0) : longueur effective du texte dans l'enregistrement.
    -     TEXTE (497) : texte proprement dit.
    Exemple : Un texte de 1096 (497+497+102) caractères sera rangé dans 3 enregistrements successifs de Frich :
    nnnnnnnn497tttttttttttttttttttttttttt...
    nnnnnnnn497tttttttttttttttttttttttttt...
    nnnnnnnn102tttttttttttttttttttttttttt...

 

;Exemple de programmation d'un texte riche

 

HFILE Appli.dhsd Farti Farti                    ;fichier articles

HFILE Appli.dhsd Frich Frich                    ;        textes

HTMPFILE Appli.dhsd Rtf Rtf NoOpen DeleteOnExit ;        travail

 

PUBLIC RECORD Appli.dhsd Arti                   ;enregistrement article

       RECORD Appli.dhsd Rich                   ;               texte 

PUBLIC RECORD Appli.dhsd Man                    ;               manœuvre

 

...

 

1A cr1 X                                        ;compte-rendu

1 cr2 X                                         ;sur fichier travail

1 cr3 X                                         ;sur Frich

1 rep 1

 

 

;Fonction : F_READST

;Type : INT

;Description : Lecture octets du fichier tdf

;En sortie : 0 = ok 1 = fin 2 = erreur système

 

FUNCTION INT F_READST (&tdf, &art)

record * htdf tdf                               ;table de définition

1 art A                                         ;enregistrement

 

BEGINF

   cr1 = FREADST (tdf, art) 

   SWITCH cr1 

      CASE 0                                    ;ok 

         FRETURN (0) 

      CASE 2                                    ;fin de fichier 

         FRETURN (1) 

      DEFAULT                                   ;erreur système 

         ErrorWarning (cr1,LEFT (tdf.name)," "," ",0,-1,-1) 

         FRETURN (2) 

   ENDSWITCH 

ENDF

 

 

;Fonction : F_WRITST

;Type : INT

;Description : Ecriture octets du fichier tdf

;En sortie : 0 = ok # = erreur

 

FUNCTION INT F_WRITST (&tdf, &art)

record * htdf tdf                               ;table de définition

1 art A                                         ;enregistrement

 

BEGINF

   cr1 = FWRITST (tdf, art) 

   SWITCH cr1 

      CASE 0                                    ;ok 

         FRETURN (0) 

      DEFAULT                                   ;erreur système 

         ErrorWarning (cr1,LEFT (tdf.name)," "," ",0,-1,-1) 

   ENDSWITCH 

   FRETURN (cr1) 

ENDF

 

 

;Procédure : ABORT

;Description : Sortie du programme

 

PROCEDURE ABORT

BEGINP

   PROGRAMEXIT                                  ;fin du programme 

ENDP

 

...

 

;Schéma de programme principal

 

MAIN

 

...

 

TMPFCREATE (Rtf,2,0) ;type U, lgenr = 0

HCLOSE (Rtf)                                    ;fermeture car ouvert par TMPFCREATE

 

...

 

 

;Chargement du fichier de travail AVANT SAISIE du masque

 

HOPEN (Rtf, 'R')                                ;ouverture

HERASE (Rtf)                                    ;effacement

 

Frich.Key = 'A' & Arti.Numero                   ;clé du texte considéré

DO                                              ;boucle de lecture / écriture

   cr3 = HREAD (Frich, Rich,, 'F')              ;jusqu'à changement de 

                                                ;texte ou fin de fichier 

WHILE cr3 = 0 AND Rich.Numero = Arti.Numero

                                                ;écriture octets sur la lg lue

   IF F_WRITST (Rtf, LEFT (Rich.Texte, Rich.Lg)) <> 0

      ABORT

   ENDIF 

WEND

 

HCLOSE (Rtf)                                    ;fermeture

 

 

Man.WnomRtf = Rtf.Name                          ;chargement nom du fichier

...                                             ;saisie du masque

 

 

;Mise à jour du fichier des textes APRES SAISIE du masque

 

HOPEN (Rtf, 'R')                                ;réouverture fichier travail

 

Frich.Key = 'A' & Arti.Numero                   ;clé du texte considéré

cr3 = HREAD (Frich, Rich,, 'F')                 ;1ère lecture ancien texte

 
cr2 = F_READST (Rtf, Rich.Texte)                ;1ère lecture nouveau texte

IF cr2 > 1 | ABORT | ENDIF

 

LOOP cr2 = 0 OR (cr3 = 0 AND Rich.Numero = Arti.Numero)

   IF cr3 = 0 AND Rich.Numero = Arti.Numero     ;ancien non terminé 

      IF cr2 <> 0                               ;DELETE si nouveau < ancien

         HDELETE (Frich, Rich)

      ELSE                                      ;REWRITE si nouveau >= ancien

         Rich.Lg = Rtf.SizeLast                 ;longueur lue 

         HREWRITE (Frich, Rich)

      ENDIF 

 

      cr3 = HREAD (Frich, Rich,, 'F')           ;suite ancien texte 

 

   ELSE                                         ;ancien texte terminé : WRITE

      Rich.Lg = Rtf.SizeLast                    ;longueur lue 

      Rich.Numero = Arti.Numero                 ;positionne la clé 

      HWRITE (Frich, Rich)

      Rich.Numero = " "                         ;pour test fin ancien texte

   ENDIF 

 

   IF cr2 = 0                                   ;suite nouveau texte

      cr2 = F_READST (Rtf, Rich.Texte)

      IF cr2 > 1 | ABORT | ENDIF 

   ENDIF

ENDLOOP

 

HCLOSE (Rtf)                                    ;fermeture fichier travail
