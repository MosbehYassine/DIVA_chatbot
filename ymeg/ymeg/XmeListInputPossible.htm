XmeListInputPossible  Famille Thème

Test d'existence d'une donnée en saisie dans la ligne de tableau courante

 
Bin XmeListInputPossible (Identifiant)

 
Paramètre :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

 
Valeur rendue par la fonction :

  • TRUE si la ligne de tableau comporte au moins une donnée en saisie (l’appel à XmeListInput est possible).

  • FALSE dans le cas contraire.

 
Description de la fonction :

  • La fonction XmeListInputPossible permet de savoir si la saisie d'une ligne du tableau (dont l'identifiant est fourni en paramètre) est possible. Elle NE peut être exécutée QUE si la page de masque contenant le tableau est la page courante.

  • Une ligne peut être saisie si au moins une colonne du tableau est à la fois visible et définie "En saisie" dans Xwin.

  • Pour déterminer la visibilité d'une colonne :

    • Ywpf tient compte des attributs dynamiques de visibilité "ligne" (Cf. fonction XmeListSetAttribut) ET "colonne" (Cf. fonction XmeSetAttribut).
      Attention : pour que la visibilité "ligne" soit vue correctement, il faut que XmeListInputPossible soit appelée alors qu’une ligne courante existe et que cette ligne courante soit présente à l’écran. Ces conditions sont réalisées si vous appelez XmeListInputPossible dans la fonction de saisie personnalisée DefProcSaisie.

    • Ywpf considère également qu'une colonne cachée par l'utilisateur ne peut pas être saisie.
      Il est donc important d’interdire à l’utilisateur de cacher les colonnes stratégiques en sélectionnant dans Xwin, pour ces colonnes, l’option "Toujours" de la propriété Affichage.

 

Exemple :
 

IF XmeListInputPossible (Ident)

   SaisieLigneTableau 

ENDIF
