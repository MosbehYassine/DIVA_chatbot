XmeListSetCreatingOption  Famille Thème

Positionnement de l'option "Création dans un tableau par un clic souris dans la colonne d'état"

 
XmeListSetCreatingOption (Identifiant, Création)

 
Paramètres :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

Création

TRUE si vous autorisez l'utilisateur à cliquer souris dans la colonne d'état " création ", en regard de la première ligne vide du tableau, pour créer un nouvel élément.
FALSE dans le cas contraire (valeur par défaut).

 
Description de la fonction :

La procédure XmeListSetCreatingOption permet de modifier une option concernant la création d'un nouvel élément dans le tableau, dont l'identifiant est fourni en paramètre :

  • Création = TRUE.
    Ywpf affiche un plus dans la colonne d'état en regard de la première ligne vide du tableau ; si l'utilisateur clique souris à cet endroit, le message spécifique " tableau " LIST_CLICK_CREATE_CONTROL est envoyé au programme pour vous permettre de créer un nouvel élément.

  • Création = FALSE (valeur par défaut).
    Cette option est invalidée.

 

Remarques :

  • Si vous validez cette option, comptez une ligne supplémentaire, pour la " ligne de création ", (en plus des lignes déjà occupées) dans le calcul de la valeur de fin de l'ascenseur vertical du tableau (Cf. rubrique XmeListScrollBarInit).

  • La procédure standard XmeListConsultDefault gère cette option lors d'une consultation par XmeListConsult.

  • Cette fonction est ignorée en mode "Licence consultation".

 

Exemple 1 :
 

...

Ident = XmeListGetId ("EOBJTAB",1,"TABLEAU",Ligne)

XmeListSetCreatingOption (Ident, TRUE)          ;option validée

 

Exemple 2 :
 

;Traitement du message LIST_CLICK_CREATE_CONTROL

...

PUBLIC RECORD Appli.dhsd Ligne

PUBLIC RECORD DDSYS.dhsd ScrollBar32 Ascens

1 Fini B

XmeLoad ("EOBJTAB")

Ident = XmeListGetId ("EOBJTAB",1,"TABLEAU",Ligne)

XmeListSetCreatingOption (Ident, TRUE)          ;option validée

XmeDispv ("EOBJTAB",1,XME_MODE_GOTO)            ;affiche page tableau

Fini = FALSE

DO

   XmeListConsult (Ident)                       ;consultation

         Fini = TRUE

 

      CASE Harmony.DataArret = xxx              ;point d'arrêt tableau

         SWITCH2 Harmony.TabClic                ;test type de clic

            CASE LIST_CLICK_CREATE_CONTROL      ;clic "création" 

               ...                              ;traitement de la création

 

            CASE ...                            ;autre clic traité 

               ... 

 

            DEFAULT                             ;autres clics 

                                                ;traitement par défaut 

               XmeListConsultDefault (Ident, Ligne, Ascens) 

         ENDSWITCH 

 

      CASE ...                                  ;autre événement traité 

         ... 

 

      DEFAULT                                   ;autres événements 

                                                ;traitement par défaut 

         XmeListConsultDefault (Ident, Ligne, Ascens) 

   ENDSWITCH

WHILE Fini = FALSE

WEND
