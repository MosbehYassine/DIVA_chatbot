XmeConsult  Famille Thème

Consultation d'un masque

 

Char XmeConsult (Nom du fichier masque, Numéro de page, Mode)

 

Paramètres :

Nom du fichier masque
(Harmony.Masque)

Nom du fichier masque.

Numéro de page
(Harmony.Page)

Numéro de la page à consulter (page initiale s'il s'agit d'un masque multi-écran).

Mode
(Harmony.Mode)

XME_MODE_GOTO = 0 : mode GOTO
XME_MODE_GOSUB = 2 : mode GOSUB.

Traitement de Page-Up et Page-Down

Paramètre obsolète ignoré à partir de la version 7 d'Harmony.

 

 

Valeur rendue par la fonction (type B) :

Il est conseillé d'ignorer cette valeur et de plutôt tester Harmony.Key pour identifier la touche tapée. En effet, toutes les touches et combinaisons de touches génèrent une valeur différente de Harmony.Key, y compris les touches "normales" (lettres, chiffres, etc.) qui génèrent la valeur K_ANSIKEY_OFFSET+nnn, où nnn est le code ANSI de la touche. Sinon :

  • Si un événement souris s'est produit, la valeur rendue est Espace.

  • Si un événement clavier s'est produit, la valeur rendue correspond au code de la touche tapée.
    Pour les caractères "normaux", il s'agit du code ANSI du caractère. Pour les touches spéciales, il s'agit de leur ancien code PC8 (Cf. Defines F_xxx de Zdiva), pour assurer la compatibilité des programmes conçus en versions 5 ou antérieures d'Harmony.

 

Description de la fonction :

  • XmeConsult est la fonction à appeler pour proposer une consultation et attendre un événement sur un masque.
    (Remarque : pour proposer une consultation et attendre un événement sur un objet tableau, utilisez la fonction XmeListConsult.)

  • Elle affiche une page Xwin puis se met en attente d'une frappe au clavier ou d'un événement souris significatif.
    Aucune modification des données n'est possible pour l'utilisateur.
    Attention     : cette fonction n'affiche pas les données des objets tableau de la page (appelez auparavant la fonction XmeListDisplay).

  • Le contrôle est rendu au programme appelant dès qu'un événement clavier ou souris est produit par l'utilisateur :
    -     Si une touche du clavier a été tapée, la variable Harmony.Key est positionnée à la manière habituelle, de même que les indicateurs ShiftKey et ControlKey.
    -     Si un événement souris s'est produit, Harmony.Key est mis à 0.

  • La page ou la fenêtre est identifiée par un Nom de fichier masque et par un Numéro de page dans ce fichier. S'il s'agit d'un masque multi-écran, indiquez le numéro de la page à afficher au départ.

  • Vous devez aussi préciser le Mode d'exécution :
    -     XME_MODE_GOTO  : mode GOTO.
    -     XME_MODE_GOSUB  : mode GOSUB.

  • Si la consultation concerne des pages panels, prenez également connaissance des rubriques Affichage, consultation et saisie de la page mère (pages panels) et Affichage, consultation et saisie isolée d'une page panel.

  • Si la page consultée comporte un chaînage (c'est à dire en cas de masque multi-écran), Ywpf effectue automatiquement les changements de page en cas de frappe des touches Ctrl+Tab ou Maj+Ctrl+Tab. Dans le cas contraire, ces touches rendent la main au programme. Ce fonctionnement n’est pas paramétrable.

  • Un délai peut être associé à la fonction XmeConsult, de manière à ce que celle-ci rende la main à intervalles réguliers et ce, même si l'utilisateur ne produit aucun événement clavier ou souris. Pour tous les détails de mise en œuvre, consultez la rubrique consacrée à la fonction XmeSetTimer.

 

Exemple :

;consultation de la page 2 du fichier masque "MASQUE" en mode GOTO

XmeConsult ("MASQUE",2,XME_MODE_GOTO)

SWITCH Harmony.Key                     ;traitement de la touche tapée :

   CASE K_CTRL_SINSERT                 ;Maj+Ctrl+Inser 

      ... 

 

   CASE K_CTRL_INSERT                  ;Ctrl+Inser 

      ... 

 

   CASE K_SINSERT                      ;Maj+Inser 

      ... 

 

   CASE ...                            ;etc. 

ENDSWITCH

...

 

Remarques :

  • Le masque doit être préalablement chargé par la fonction XmeLoad.

  • Une consultation en mode GOSUB nécessite un appel ultérieur à la fonction XmeRet.

  • En consultation par XmeConsult, Ywpf :

    • Valide tous les boutons et choix de menu non nommés.

    • Valide les boutons et choix de menu nommés, à condition qu'ils soient présents dans la liste des boutons valides de la page consultée (pour modifier cette liste, cliquez sur le bouton Boutons dans la boîte de dialogue des caractéristiques de la page).
      Remarque : En cas de consultation isolée d'une page panel, les boutons nommés valides sont ceux spécifiés pour la page panel consultée (et non ceux de sa page mère).

  • Si l'utilisateur clique sur un bouton ou un choix de menu générant un point d'arrêt, la main est rendue au programme ; celui-ci peut récupérer le numéro du point d'arrêt dans Harmony.DataArret (attention, pas dans Harmony.Arret) ; après le traitement du point d'arrêt, vous pouvez bien entendu rappeler la fonction XmeConsult mais un éventuel code de retour placé dans Harmony.Retour sera ignoré (ce code n'a de sens qu'à l'appel de l'instruction XmeNext).

  • Si l'utilisateur clique sur un bouton ou un choix de menu associé à un point de traitement, la séquence de traitement est exécutée ; au retour de la séquence, Ywpf revient toujours à la consultation ; les données de la page (hors tableaux) sont automatiquement réaffichées mais un éventuel code de retour placé dans Harmony.Retour sera ignoré (ce code n'a de sens qu'au retour d'un traitement exécuté en saisie du masque).

  • En consultation par XmeConsult, tous les événements souris significatifs rendent la main : clic sur une donnée en saisie quelconque (Cf. Souris : Positionnements en consultation de masque),  "clic tableau" quelconque, onglets.

  • Attention, tout numéro de point d'arrêt généré n'est pas transmis dans Harmony.Arret mais dans Harmony.DataArret.

 

Appel d’un menu surgissant en consultation de masque

Pour afficher un menu surgissant (popup-menu) à l’occasion d’une consultation de masque, chargez la donnée Harmony.PopupMenu avec l’identifiant du menu à afficher, avant d’appeler XmeConsult (exemple à la rubrique Menus : Chargement et affichage d'un menu).

 

Appel de l’aide associée à la page consultée

Avec Xwin, vous pouvez associer une aide à toute page de masque. Cette aide servira d’abord d’aide par défaut pour toutes les données présentes dans cette page. Il peut aussi être intéressant d’afficher cette aide si l’utilisateur tape Shift+F1 (touche standard d’appel de l’aide) alors que la page est en consultation par XmeConsult. Pour ce faire, en réponse à la touche Shift+F1, appelez successivement les fonctions XmeInfoPage pour récupérer le nom du fichier d’aides et le numéro de l’aide associée à la page puis le fonction XmeHelp.

 

Positionnement de la page ou de la fenêtre à l'écran :

Dans l'éditeur de masques d'écran de Xwin, vous avez indiqué où vous vouliez afficher le masque à l'écran (champs Offset Ligne et Offset Colonne des paramètres généraux de la page ; accès par le choix Page Courante du menu Paramètres - raccourci clavier F3).
A ce niveau, il s'agissait d'une position "de base" pouvant être modifiée par programme. Si vous souhaitez déplacer la page ou la fenêtre à l'écran par rapport à cette position de base, consultez la rubrique Déplacement d'un masque à l'écran.

 

Attention :

Vous ne devez pas utiliser la fonction XmeConsult en MODE GOSUB pour consulter une page de masque incluant un objet tableau, pour la raison suivante :

  • Ni la fonction XmeConsult ni la fonction XmeDispv n'affichent les données d'un tableau (il faut utiliser la fonction tableau spécifique XmeListDisplay).

  • XmeConsult fait une entrée clavier : il faut donc demander l'affichage de la page (par XmeDispv) puis des données du tableau (par XmeListDisplay) AVANT d'appeler XmeConsult.

  • Le mode GOSUB demande à Ywpf de réafficher la page consultée "par dessus" la page précédemment affichée (même s'il s'agit en réalité de la même page). Un nouveau tableau VIDE sera donc lui aussi réaffiché !

Pour consulter une page de masque incluant un tableau, utilisez la fonction XmeConsult en MODE GOTO (ou la fonction spécifique tableau XmeListConsult).
