XmeListConsultDefault  Famille Thème

Traitement par défaut en consultation de tableau / arbre

 
Int XmeListConsultDefault (Identifiant, Ligne, Ascenseur, [Privilège, Sélection, Perso, MessagesInhibes])

 
Paramètres :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

Ligne

Adresse de l'enregistrement "ligne du tableau" ; au retour de la fonction, cet enregistrement est garni avec les données de la ligne courante.

Ascenseur

Adresse de l'enregistrement "ascenseur" (on utilisera l'enregistrement standard ScrollBar32 du dictionnaire système DDSYS.dhsd) ; au retour de la fonction, l'enregistrement est actualisé pour refléter l'état courant de l'ascenseur vertical du tableau.
Voir paragraphe "Attention" ci-après.

Privilège

Niveau de privilège (paramètre facultatif, ZOOM_PRIVILEGE_SUPPRESSION par défaut) :
- ZOOM_PRIVILEGE_CONSULTATION (1) : la fonction ne doit pas traiter les événements concernant la modification, la création et la suppression de ligne.
- ZOOM_PRIVILEGE_MODIFICATION (2) : la fonction doit traiter les événements concernant la modification de ligne mais pas ceux concernant la création et la suppression.
- ZOOM_PRIVILEGE_CREATION (3) : la fonction doit traiter les événements concernant la modification et la création de ligne mais pas ceux concernant la suppression.
- ZOOM_PRIVILEGE_SUPPRESSION (4) : la fonction doit traiter tous les événements concernant la modification, la création et la suppression de ligne.
Voir texte ci-après.

Sélection

Positionnez cette option à :
- TRUE si vous voulez que XmeListConsultDefault traite les événements concernant la sélection multiple.
- FALSE sinon.
Voir texte et paragraphe "Attention" ci-après.
Paramètre facultatif, FALSE par défaut.

Perso

Positionnez cette option à :
- TRUE si vous souhaitez personnaliser XmeListConsultDefault.
- FALSE sinon.
Pour plus de détails, voir la rubrique Fonctions de personnalisation de XmeListConsultDefault.
Paramètre facultatif, FALSE par défaut.

MessagesInhibes

Positionnez ce paramètre à FALSE si vous autorisez XmeListConsultDefault à afficher tous ses messages de confirmation.
Sinon, ce paramètre peut être une combinaison quelconque (sous forme de somme ou de OU logique) des valeurs suivantes, chacune représentant un message que vous désirez inhiber :
- DEFPROC_MESS_SUPPRESSION inhibe le message demandant confirmation d'une suppression de ligne.
- DEFPROC_MESS_SUPPRESSION_SELECTION inhibe le message demandant confirmation d'une suppression de la sélection.
- DEFPROC_MESS_COLLER_AVANT_APRES inhibe le message demandant si le "Coller" doit se faire avant ou après la ligne courante (ce message est affiché uniquement lorsque l'élément courant se trouve en fin de liste ; en cas d'inhibition du message, le "Coller" aura lieu APRES la ligne courante).
Paramètre facultatif, FALSE par défaut.

 
Valeur rendue par la fonction :

  • TRUE si la liste a été modifiée durant l'exécution de XmeListConsultDefault.

  • FALSE dans le cas contraire.

 
Description de la fonction :

  • XmeListConsultDefault est une fonction standard qui propose un traitement par défaut pour la plupart des événements, susceptibles de se produire lors d'une consultation de tableau / arbre par XmeListConsult : si vous choisissez d'appliquer le traitement standard suite à un événement donné, appelez XmeListConsultDefault au retour de XmeListConsult pour cet événement.

    Vous pouvez choisir d'appeler ou non XmeListConsultDefault pour chaque événement à traiter : par exemple, vous pouvez décider de reprogrammer les opérations de création, modification et suppression de lignes car le traitement standard ne convient pas, tout en conservant le traitement standard pour les déplacements et les sélections dans le tableau / arbre.
     
    En pratique, programmez une structure de contrôle SWITCH / CASE / DEFAULT / ENDSWITCH derrière l'appel à XmeListConsult ; programmez les CASE correspondant aux événements que vous voulez traiter vous-même ; à la suite des CASE, programmez l'appel à XmeListConsultDefault sous DEFAULT (Cf. exemples).

  • XmeListConsultDefault n'est utilisable que si la totalité des lignes du tableau est résidente en mémoire et si l'enregistrement Ligne inclut les données affichées sur une ligne (Cf. rubrique Gestion de la liste associée à un tableau).

  • XmeListConsultDefault traite les événements suivants :
     
    Touches de déplacement     :
    -     Flèche en haut : ligne précédente.
    -     Flèche en bas : ligne suivante.
    -     Home : première ligne.
    -     End : dernière ligne.
    -     Page-Up : page précédente.
    -     Page-Down : page suivante.
     
    Déplacements à la souris     :
    -     Clic souris sur une cellule du tableau : positionnement sur la ligne correspondante.
    -     Toutes actions sur l'ascenseur vertical du tableau : positionnement correspondant.
     
    Création     – Modification – Suppression de ligne
    (si vous avez autorisé l'opération en donnant une valeur suffisante au paramètre Privilège) :
    -     Inser : création d'une ligne derrière la ligne courante.
    -     F4 : modification de la ligne courante.
    -     Suppr : suppression de la ligne courante.
    -     Clic dans la colonne d'état "création" (en regard de la première ligne vide affichant un plus) : création d'un nouvel élément en fin de tableau (attention : cette méthode de création est optionnelle ; pour la valider, appelez la procédure XmeListSetCreatingOption avec le paramètre Création à TRUE, voir l'exemple 2).
    -     Clic dans la colonne d'état en regard d'une ligne de données non vide : modification de cette ligne.
     
    Sélection multiple     – Copier – Couper – Coller
    (si vous avez autorisé la sélection multiple en donnant la valeur TRUE au paramètre Sélection) :
    -     Clic gauche dans l'en-tête de la colonne d'état ou touche Ctrl+A : sélection de toutes les lignes du tableau.
    -     Espace : inversion de la sélection pour la ligne courante.
    -     Ctrl+Touche de déplacement : déplacement sans effacement de la sélection précédente.
    -     Maj+Touche de déplacement : sélection d'un groupe de lignes contiguës.
    -     Maj+Ctrl+Touche de déplacement : sélection d'un groupe de lignes contiguës sans effacement de la sélection précédente.
    -     Ctrl+Clic souris sur une ligne du tableau : inversion de la sélection pour cette ligne sans effacement de la sélection précédente.
    -     Maj+Clic souris sur une ligne du tableau : sélection d'un groupe de lignes contiguës.
    -     Maj+Ctrl+Clic souris sur une ligne du tableau : sélection d'un groupe de lignes contiguës sans effacement de la sélection précédente.
    -     Ctrl+Inser : copie des lignes sélectionnées dans le presse-papiers.
    -     Maj+Inser : insertion des lignes précédemment copiées dans le presse-papiers, devant la ligne courante (remarque : si la ligne courante est la dernière ligne du tableau, la fonction demande à l'utilisateur si l'insertion doit se faire devant ou derrière la dernière ligne).
    -     Suppr : suppression des lignes sélectionnées sans recopie dans le presse-papiers.
    -     Maj+Suppr : suppression des lignes sélectionnées avec recopie dans le presse-papiers.
     
    Changement de la hauteur de la fenêtre     :
    Réaffichage du tableau réduit ou agrandi.
     
    Expansion / Réduction d'un élément d'arbre :
    -     + ou clic souris sur le signe + : expansion de l'élément courant.
    -     - ou clic souris sur le signe - : réduction de l'élément courant.
     
    Gestion du curseur de création d'un arbre
    (si vous avez demandé la présence du curseur de création à l'écran en appelant la procédure XmeListTreeCursorInit avec le paramètre Curseur positionné à TRUE) :
    -     Tab : incrémentation du niveau (et du curseur) de création.
    -     Back-Tab :décrémentation du niveau (et du curseur) de création.
    -     Déplacement à la souris du curseur de création : modification du niveau de création pour refléter la nouvelle position du curseur.
    Remarques :
    – Lorsque l'utilisateur modifie la position du curseur de création, XmeListConsultDefault vérifie automatiquement la cohérence du niveau de création sélectionné, en fonction de l'état de l'arbre et du niveau de l'élément courant ; en cas d'incohérence, le repositionnement du curseur est refusé.
    – Lorsque l'utilisateur se déplace dans l'arbre, XmeListConsultDefault modifie automatiquement la position du curseur de création pour qu'elle corresponde au niveau du nouvel élément courant.

 

Attention :

  • XmeListConsultDefault teste les variables Harmony.Key, ShiftKey et ControlKey, positionnées par XmeListConsult. Entre le XmeListConsult et le XmeListConsultDefault, il ne faut donc pas " casser " ces données.

  • Gestion de l'ascenseur vertical du tableau.
    XmeListConsultDefault gère l'ascenseur vertical du tableau. Dans votre programme, vous devez (voir exemples) :
    -     Déclarer une variable qui contiendra les informations de gestion de l'ascenseur (on utilisera pour cela l'enregistrement standard ScrollBar32 du dictionnaire système DDSYS.dhsd).
    -     Avant d'exécuter le premier XmeListConsult et, le cas échéant, après le remplissage initial du tableau et après avoir exécuté la procédure XmeListSetCreatingOption, appeler la procédure XmeListScrollBarInit pour initialiser l'ascenseur.

  • Gestion de la sélection multiple.
    Si vous souhaitez que XmeListConsultDefault gère la sélection multiple des lignes du tableau, vous devez, dans votre programme (voir exemple 2) :
    -     Positionner le paramètre Sélection à la valeur TRUE.
    -     Déclarer une variable qui contiendra les informations de gestion du marquage des lignes (on utilisera pour cela l'enregistrement standard RowInfo du dictionnaire système DDSYS.dhsd).
    -     Initialiser cette variable pour préciser la couleur et/ou l'image bitmap qui devront être affectées aux lignes sélectionnées.
    -     Indiquer cette variable dans le masque Xwin en tant que donnée de contrôle : déclarez l'enregistrement RowInfo dans la liste des enregistrements du masque, activez la propriété du tableau Avec donnée de contrôle des lignes et cliquez dans la colonne de droite de la propriété Donnée de contrôle puis sur le bouton d’ouverture de la fenêtre de sélection de la donnée. Sélectionnez la donnée RowInfo de l'enregistrement RowInfo.

  • Mode "Licence consultation".
    Lorsque le programme s'exécute en mode "Licence consultation", les fonctions de création, modification, suppression, couper et coller sont automatiquement invalidées. De plus, le cas échéant :

    • Le "+", normalement présent dans la colonne d'état en regard de la première ligne vide du tableau, n'est plus affiché.

    • Le curseur de création d'un arbre, normalement présent dans l'en-tête de la colonne du tableau affichant l'arborescence, n'est plus affiché.

 

Remarques :

  • XmeListConsultDefault peut éventuellement être appelée après un XmeConsult.

  • Le source de la procédure XmeListConsultDefault est livré à titre d'exemple dans le fichier ZYDEFPRO.dhsp.

 

Exemple 1 :
 

;Schéma de programmation de la fonction XmeListConsultDefault

;(sans option particulière)

...

PUBLIC RECORD Appli.dhsd Ligne

PUBLIC RECORD DDSYS.dhsd ScrollBar32 Ascens

 

1 Ident L

1 Fini B

...

 

MAIN 

...

Ligne = " "

XmeLoad ("EOBJTAB")

XmeInfoPage ("EOBJTAB",1)

XmeSetWindowSize ("EOBJTAB",1,Harmony.Opara3,Harmony.Opara4)

 

Ident = XmeListGetId ("EOBJTAB",1,"TABLEAU",Ligne)

...

XmeDispv ("EOBJTAB",1,XME_MODE_GOTO)                    ;affiche page tableau

XmeListScrollBarInit (Ident, Ascens)                    ;initialisation ascenseur

 

Fini = FALSE

DO

   XmeListConsult (Ident)                               ;consultation 

   SWITCH Harmony.Key 

      CASE K_ESCAPE                                     ;fin 

         Fini = TRUE

 

      CASE ...                                          ;événement traité 

         ...                                            ;traitement personnel 

 

      CASE ...                                          ;événement traité 

         ...                                            ;traitement personnel 

 

      CASE ...                                          ;événement traité 

         ...                                            ;traitement personnel 

 

      DEFAULT                                           ;autres événements 

                                                        ;traitement par défaut 

         XmeListConsultDefault (Ident, Ligne, Ascens) 

   ENDSWITCH

WHILE Fini = FALSE

WEND

 

...

 

Exemple 2 :
 

;Schéma de programmation de la fonction XmeListConsultDefault

;(avec sélection multiple et affichage d'un plus dans la colonne

; d'état de la première ligne vide)

...

PUBLIC RECORD Appli.dhsd Ligne

PUBLIC RECORD DDSYS.dhsd RowInfo

PUBLIC RECORD DDSYS.dhsd ScrollBar32 Ascens

 

1 Ident L

1 Fini B

...

 

MAIN 

...

Ligne = " "

RowInfo = " "                                          ;infos pour la sélection

RowInfo.bitmap = " "                                   ;pas de bitmap en col. état

RowInfo.couleur = "BLEUCIEL"                           ;couleur ligne sélectionnée

RowInfo.CoulSelec = FALSE

RowInfo.Selection = FALSE                              ;état initial

...

XmeLoad ("EOBJTAB")

XmeInfoPage ("EOBJTAB",1)

XmeSetWindowSize ("EOBJTAB",1,Harmony.Opara3,Harmony.Opara4)

 

Ident = XmeListGetId ("EOBJTAB",1,"TABLEAU",Ligne)

XmeListSetCreatingOption (Ident, TRUE)                 ;plus en colonne d'état

...

XmeDispv ("EOBJTAB",1,XME_MODE_GOTO)                   ;affiche page tableau

XmeListScrollBarInit (Ident, Ascens)                   ;initialisation ascenseur

 

Fini = FALSE

DO

   XmeListConsult (Ident)                              ;consultation 

   SWITCH Harmony.Key 

      CASE K_ESCAPE                                    ;fin 

         Fini = TRUE

 

      CASE ...                                         ;événement traité 

         ...                                           ;traitement personnel 

 

      CASE ...                                         ;événement traité 

         ...                                           ;traitement personnel 

 

      DEFAULT                                          ;autres événements 

                                                       ;traitement par défaut 

         XmeListConsultDefault (Ident, Ligne, Ascens,,TRUE) 

   ENDSWITCH

WHILE Fini = FALSE

WEND
