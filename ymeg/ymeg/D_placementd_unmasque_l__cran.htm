Déplacement d'un masque à l'écran

Fonctions concernées :

XmeClearv

XmeConsult

XmeDisp

XmeDispv

XmeInput

 

Paramètres d'entrée auxiliaires :

Harmony.Ocolonne

Déplacement colonne (0 par défaut).

Harmony.Oligne

Déplacement ligne (0 par défaut).

 

Harmony.Ocolonne et Harmony.Oligne permettent de modifier par programme l'emplacement d'un masque (page ou fenêtre) à l'écran. Les valeurs que vous donnez à ces paramètres s'ajoutent aux coordonnées " de base ", indiquées dans l'éditeur de masques d'écran de Xwin (champs Offset Ligne et Offset Colonne des paramètres généraux de la page ; accès par le choix Page Courante du menu Paramètres - raccourci clavier F3). Par exemple :

  • Harmony.Ocolonne / Harmony.Oligne = 0 / 0.
    Conserve la position de base indiquée dans l'éditeur Xwin.

  • Harmony.Ocolonne / Harmony.Oligne = 0 / 7.
    Déplace le masque de 7 lignes vers le bas, par rapport à la position définie dans Xwin.

  • Harmony.Ocolonne / Harmony.Oligne = 5 / 3.
    Déplace le masque de 3 lignes vers le bas et de 5 colonnes vers la droite, par rapport à la position définie dans Xwin.

 

Exemple :

L'affichage des lignes " détails " d'une facture constitue un exemple représentatif de masque déplacé à l'écran par programme :

Ligne 1                        <-+ En-tête facture :

      2 Numéro de facture :      | 

      3 Code client :            | Page 1 ; 

      4 Mode de règlement :      | 7 lignes ; 

      5                          | Offset ligne = 0

      6 Article Prix Qté Total   | 

      7 ---------------------- <-+ 

      8 ....... .... ... ..... <-- Une ligne détail : 

      9 ....... .... ... .....     Page 2 ; 

      10 ....... .... ... .....    1 ligne ; 

      11 ....... .... ... .....    Offset ligne = 6 (*)

      12 ....... .... ... ..... 

      13 ....... .... ... ..... 

      14 ....... .... ... ..... 

      15 ....... .... ... ..... 

      16 ....... .... ... ..... 

      17 ....... .... ... ..... 

      18 ---------------------- <-+ Pied de facture : 

      19                          | Page 3 ; 

      20 Total général :          | 4 lignes ; 

      21                        <-+ Offset ligne = 17

(*) Cette valeur, définie dans l'éditeur de masques Xwin, est la position " de base " de la ligne détails. Avant d'afficher la page 2, nous lui ajouterons l'indice de la ligne courante dans le tableau des lignes détails (en faisant débuter les indices à 1). Ainsi, par exemple, l'offset définitif de la première ligne détails vaudra bien 7 (valeur de base de l'offset ligne 6 + indice début 1 = 7).

 

XmeDispv ("MASQUE",1,XME_MODE_GOTO)          ;affiche l'en-tête

 

FOR i = 1 TO 10 ;10 lignes détails

   ...                                       ;chargement des données

   ...                                       ;à afficher pour la 

   ...                                       ;ligne courante 

   Harmony.Oligne = i                        ;offset ligne à ajouter 

                                             ;à l'offset de base 

   XmeDispv ("MASQUE",2,XME_MODE_GOSUB)      ;affiche une ligne 

   XmeRet                                    ;retour à la page 1 

NEXT

 

XmeDispv ("MASQUE",3,XME_MODE_GOTO)          ;affiche le pied
