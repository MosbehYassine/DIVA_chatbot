XmeListDisplay  Famille Thème

Affichage des données d'un tableau

 
XmeListDisplay (Identifiant)

 
Paramètre :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

 
Description de la fonction :

  • La procédure XmeListDisplay affiche les lignes du tableau dont l'identifiant est fourni en paramètre. Elle n'affiche pas le cadre du tableau.

  • XmeListDisplay NE peut être appelée QUE si la page de masque contenant le tableau est la page courante (ou une de ses pages panels). Les fonctions d'affichage de la page (XmeDisp, XmeDispv, etc.) affichent le cadre du tableau mais pas ses données.

 
Remarque importante :

L'affichage des lignes du tableau est optimisé de telle manière que seuls les champs modifiés sont actualisés à l'écran. En conséquence, il n'existe pas de fonction permettant d'afficher une ligne ou une donnée isolée du tableau.

 

Exemple :

...

XmeLoad ("EOBJTAB")

XmeInfoPage ("EOBJTAB",1)

XmeSetWindowSize ("EOBJTAB",1,Harmony.Opara3,Harmony.Opara4)

 

Ident = XmeListGetId ("EOBJTAB",1,"TABLEAU",Ligne)

...

XmeDispv ("EOBJTAB",1,XME_MODE_GOTO)       ;page courante=page tableau

                                           ;& affiche cadre du tableau 

XmeListDisplay (Ident)                     ;affiche les lignes

...
