Exemple général de programmation d'une saisie de masque

Cette rubrique montre un exemple classique de programmation sous Harmony. Vous y trouverez des explications détaillées sur :

  • La création des fichiers, tables et champs dans le dictionnaire.

  • La création et le paramétrage des masques d'écran.

  • Les séquences de traitement.

  • Le programme principal.

 

Dans notre exemple, nous allons programmer la création et la modification de la fiche article suivante :

+-------------------------------------------+

| Fonction     : ........                   |

| Code article : ..........                 |

| Libellé      : ..........                 |

|                                           |

| Prix unitaire     : ..........            |

| Quantité en stock : ..........            |

|                                           |

| Code fournisseur   : ..........           |

| Nom du fournisseur : ..........           |

+-------------------------------------------+

Et nous demanderons confirmation de la validation ou de l'abandon de la saisie de cette fiche dans la fenêtre suivante (ceci pour monter un exemple d'appel de fenêtre en mode "Gosub" : il serait bien entendu plus simple d'utiliser la fonction MessageBox pour demander cette confirmation) :

+---------------------+

|Validation /Abandon  |

+---------------------+

|                     |

|   +-----+ +-----+   |

|   | Oui | | Non |   |

|   +-----+ +-----+   |

|                     |

+---------------------+

 

1. Déclarations dans le dictionnaire des données

  • Création du dictionnaire des données.
    Lancez le programme Xwin.
    Sélectionnez le choix Nouveau du menu Fichier.
    Sélectionnez l’option Dictionnaire.
    Enregistrez le nouveau dictionnaire dans un dossier Exo sous le nom Appli.dhsd.

  • Création des fichiers dans le dictionnaire.
    Déclarez les deux bases suivantes :
    -     Farti (Libellé : Fichier articles ; Taille des enregistrements : 0 ; Nom : Farti.dhfi).
    -     Ffour (Libellé : Fichier fournisseurs ; Taille des enregistrements : 0 ; Nom : Ffour.dhfi).

  • Création de l'enregistrement Article.
    Dans la base Farti, déclarez la table suivante :
    -     Arti (Libellé : Fiche article ; Taille : 300 ; En mémoire : 300).

  • Création des données de l'enregistrement Article.
    Dans la table Arti, déclarez les champs suivants :
    -     Codart (Libellé : Code article ; Nature : 10).
    -     Libart (Libellé : Libellé ; Nature : 30).
    -     Puart (Libellé : Prix unitaire ; Nature : 8,2).
    -     Stoart (Libellé : Quantité en stock ; Nature : 5,0).
    -     Codfour (Libellé : Code fournisseur ; Nature : 10).

  • Création de l'enregistrement Fournisseur.
    Dans la base Ffour, déclarez la table suivante :
    -     Four (Libellé : Fiche fournisseur ; Taille : 300 ; En mémoire : 300).

  • Création des données de l'enregistrement Fournisseur.
    Dans la table Four, déclarez les champs suivants :
    -     Codfour (cette donnée ayant déjà été créée, ses paramètres ne doivent pas être ressaisis).
    -     Nomfour (Libellé : Nom ; Nature : 30).

  • Création des clés des fichiers.
    Définissez une clé sur le code article pour le fichier Articles et une clé sur le code fournisseur pour le fichier Fournisseurs.

  • Création d'un enregistrement de manœuvre.
    Déclarez la table mémoire suivante :
    -     Man (Libellé : Manoeuvre ; Taille : 1000 ; En mémoire : 1000).

  • Création des données de l'enregistrement Man.
    Dans la table mémoire Man, déclarez les champs suivants :
    -     Wfonc (Libellé : Fonction en cours ; Nature : 1,0).

 

2. Création des fichiers séquentiels-indexés articles et fournisseurs sur disque

  • Attention : Les opérations précédentes ne créent pas physiquement les fichiers séquentiels indexés Farti.dhfi et Ffour.dhfi. Pour ce faire, cliquez droit sur la ligne affichant chaque fichier et sélectionnez le choix du menu surgissant Créer/Modifier fichier Séquentiel Indexé.

 

3. Création et paramétrage des masques d'écran

  • Création du fichier masques.
    Sélectionnez le choix Nouveau du menu Fichier.
    Sélectionnez le choix Masque écran et validez.
    Sélectionnez le choix Enregistrer Sous du menu Fichier.
    Enregistrez le nouveau fichier masques dans le dossier Exo sous le nom Eappli.dhsf.

  • Création du dictionnaire des multi-choix.
    Sélectionnez le choix Multi-choix du menu Paramètres.
    Entrez Applimc.dhfi dans la zone Dictionnaire et validez par Return.
    Répondez par Oui à la demande de création du fichier.

  • Déclaration des enregistrements utilisés dans le masque.
    Sélectionnez le choix Enregistrements du menu Paramètres.
    Entrez APPLI.dhsd dans le champ Dictionnaire.
    Laissez la zone Fichier à espace (cette zone est présente à titre purement indicatif).
    Entrez ARTI dans le champ Enregistrement.
    Cliquez sur le bouton Ajouter.
    Entrez maintenant FOUR dans le champ Enregistrement.
    Cliquez sur le bouton Ajouter.
    Entrez enfin MAN dans le champ Enregistrement.
    Cliquez sur le bouton Ajouter.
    Vous devez obtenir la liste suivante :
    Appli.d    hsd Arti Arti
    Appli.d    hsd Four Four
    Appli.d    hsd Man  Man
    Quittez la boîte de dialogue Fichiers / Enregistrements par le bouton Ok.

  • Paramétrage de la page 1 : Fiche article.
    Sélectionnez le choix Page courante du menu Paramètres (raccourci clavier : F3).
    Entrez le Libellé : Fiche article (commentaire).
    Le multi-choix Effacement doit indiquer : Effacement complet.
    Nombre de lignes     : 23.
    Nombre de colonnes     : 80.
    Validez la boîte de dialogue Caractéristiques de la page.

  • Paramétrage de la page 2 : Fenêtre de validation.
    Tapez la touche Page-Down.
    Répondez Oui à la demande de création de la page 2.
    Sélectionnez le choix Page courante du menu Paramètres (raccourci clavier : F3).
    Entrez le Libellé : Validation (commentaire).
    Entrez le Titre : Validation (titre de la fenêtre).
    Cochez     la case Fenêtre.
    Nombre de lignes     : 5.
    Nombre de colonnes     : 20.
    Offset ligne     : 10.
    Offset colonne     : 40.
    Validez la boîte de dialogue Caractéristiques de la page.

  • Paramétrage de la page 3 : Fenêtre d'abandon.
    Tapez la touche Page-Down.
    Répondez Oui à la demande de création de la page 3.
    Sélectionnez le choix Page courante du menu Paramètres (raccourci clavier : F3).
    Entrez le Libellé : Abandon (commentaire).
    Entrez le Titre : Abandon (titre de la fenêtre).
    Cochez     la case Fenêtre.
    Nombre de lignes     : 5.
    Nombre de colonnes     : 20.
    Offset ligne     : 10.
    Offset colonne     : 40.
    Validez la boîte de dialogue Caractéristiques de la page.
    Tapez deux fois Page-Up pour revenir en page 1.

 

4. Dessin de la page 1 : Fiche article

  • Création du libellé Code article.
    Sélectionnez le choix Texte du menu Objets ou cliquez sur le bouton équivalent.
    Déplacez le cadre dessiné par Xwin à la souris et cliquez à l'endroit de la page où vous voulez placer le libellé.
    Dans la fenêtre des propriétés du texte, entrez le Texte : Code article.

  • Création des autres libellés.
    Procédez de la même manière pour les libellés :
    -     Libellé.
    -     Prix unitaire.
    -     Quantité en stock.
    -     Code fournisseur.
    -     Nom du fournisseur.
    -     Fonction.

  • Création de la donnée Code article.
    Sélectionnez le choix Champ du menu Objets ou cliquez sur le bouton équivalent.
    Double-cliquez sur la ligne de la liste affichant l'enregistrement Arti pour afficher les données de cet enregistrement.
    Sélectionnez la donnée Codart et validez par Ok.
    Déplacez le cadre dessiné par Xwin à la souris et cliquez à l'endroit de la page où vous voulez placer la donnée.

  • Création des autres données.
    Procédez de la même manière pour les données :
    -     Libellé (donnée Libart de l'enregistrement Arti).
    -     Prix unitaire (donnée Puart de Arti).
    -     Quantité en stock (donnée Stoart de Arti).
    -     Code fournisseur (donnée Codfour de Arti).
    -     Nom du fournisseur (donnée Nomfour de Four).
    La donnée Fonction (Wfonc) n'est pas un champ mais un multi-choix et nous l'étudierons après le paramétrage des champs définis précédemment.

  • Création "avancée" des libellés et des champs.
    Une autre possibilité plus rapide de créer les objets précédents consiste à sélectionner le choix Donnée du dictionnaire du menu Objets (ou à cliquer sur le bouton équivalent). Vous pouvez ensuite sélectionner l'ensemble des données à inclure dans le masque. En cochant la case Insertion avec les libellés, vous insérez simultanément les libellés correspondants.

  • Paramétrage de la donnée Codart (code article).
    Double-cliquez sur la donnée Code article dans le dessin du masque. Dans la fenêtre des propriétés du champ, affectez au code article les paramètres suivants :

    -     Point d'arrêt Après saisie numéro 10
    (entrez la valeur 10 dans la propriété Arrêt Après de la famille Traitements), destiné à vérifier l'existence du code introduit :
    * Si le code n'existe pas encore, le programme passera en création et poursuivra la saisie.
    * Si le code existe déjà, le programme passera en modification et poursuivra la saisie.
     
    -     Traitement Avant saisie,
    qui permettra d'interdire à l'utilisateur de revenir sur le code article après que celui-ci ait été saisi : on teste pour cela la valeur du code et si ce dernier n'est plus à espace, on demande à Ywpf de sauter sa saisie (Cf. Exemple 4 de reprise de saisie : XMENEXT_SAUT_DONNEE).
    Remarque     : Permettre à l'utilisateur de ressaisir la clé, en cours de création ou de modification, complique la programmation et n'est pas souhaitable. La simplicité voulue de l'exemple justifie l'emploi de la méthode indiquée précédemment. Une autre solution consiste à saisir les données composant la clé dans une fenêtre à part et à définir ces données "en affichage" (interdisant par là même leur saisie) dans le masque principal.
    Cliquez dans la colonne de droite de la propriété Traitement avant (famille Traitements) puis sur le bouton d’ouverture de la fenêtre d’édition du source. Répondez Oui à la demande de création puis à la demande de génération automatique.
    Saisissez les lignes de programme suivantes dans le corps de la procédure générée :

;Traitement avant saisie du code article

IF Arti.Codart <> " "                    ;1ère saisie ?

   Harmony.Retour = XMENEXT_SAUT_DONNEE  ;non : ressaisie interdite

ENDIF

 

En tête du source, saisissez aussi les deux lignes suivantes :

 

HFILE Appli.dhsd Ffour Ffour  ;fic. Fournisseurs

1     Rep       1             ;réponse opérateur

 

Revenez à la fenêtre Mdi du masque (cliquez sur l’onglet « fichier » qui le représente).

  • Paramétrage de la donnée Libart (libellé).
    Double-cliquez sur la donnée Libellé dans le dessin du masque et affectez au libellé article la propriété suivante (famille Saisie) : Obligatoire : Oui. 
     

  • Paramétrage de la donnée Puart (prix unitaire).
    -     Traitement Après saisie,
    permettant de contrôler la valeur introduite. Nous interdirons ici l'entrée d'une valeur négative ou nulle.
    Dans les propriétés de la donnée Puart, cliquez dans la colonne de droite de la ligne Traitement après (famille Traitements) puis sur le bouton d’ouverture de la fenêtre d’édition du source. Répondez Oui à la demande de création puis à la demande de génération automatique et saisissez les lignes de programme suivantes dans le corps de la procédure générée :

;Contrôle du prix unitaire

IF Arti.Puart <= 0

   MessageBox ("Prix incorrect","Message",MB_OK)

   Harmony.Retour = XMENEXT_RESSAISIE

ENDIF

  • Paramétrage de la donnée Stoart (quantité en stock).
    -     Traitement Après saisie,
    pour contrôler que la valeur introduite est au moins égale à 5.
    Dans les propriétés de la donnée Stoart, cliquez dans la colonne de droite de la ligne Traitement après (famille Traitements) puis sur le bouton d’ouverture de la fenêtre d’édition du source. Répondez Oui à la demande de création puis à la demande de génération automatique et saisissez les lignes de programme suivantes dans le corps de la procédure générée :

;Contrôle de la quantité en stock

IF Arti.Stoart < 5                                  ;au moins 5 éléments ?

   MessageBox ("Quantité insuffisante","Message",MB_OK)

   Harmony.Retour = XMENEXT_RESSAISIE

ENDIF

  • Paramétrage de la donnée Codfour (code fournisseur).
    -     Table associée : Oui (propriété de la famille Saisie),
    permettant d'afficher un bouton d'appel de zoom lorsque cette donnée a le focus en saisie.

    -     Traitement Après saisie,
    permettant de rechercher le code introduit dans le fichier fournisseurs :
    * Si le code n'existe pas, sa saisie est refusée et la question est reposée.
    * Si le code existe, sa saisie est acceptée.
    Dans les propriétés de la donnée Codfour, cliquez dans la colonne de droite de la ligne Traitement après (famille Traitements) puis sur le bouton d’ouverture de la fenêtre d’édition du source. Répondez Oui à la demande de création puis à la demande de génération automatique et saisissez les lignes de programme suivantes dans le corps de la procédure générée :

;Lecture du nom du fournisseur

Ffour.Key = "A" & Arti.Codfour                    ;clé cherchée

IF HSEEK (Ffour,Four,"F") <> 0                    ;recherche

   MessageBox ("Fournisseur inconnu","Message",MB_OK)

   Four.Nomfour = " "                             ;raz nom affiché

   Harmony.Retour = XMENEXT_RESSAISIE

ENDIF

 

- Piège de la touche F8 (point d'arrêt numéro 101),
pour nous permettre d'appeler le zoom du fichier fournisseurs lorsque l'utilisateur tapera F8, F9 (Cf. rubrique "Appel d'un Zoom ou Consultation de la Liste des fiches d'une table") ou Ctrl+F (Cf. rubrique "Appel personnalisé d'un Zoom par la touche Ctrl+F") en saisie du code.
Cliquez sur la ligne de la propriété Piège touches de la famille Traitements.
Entrez la valeur 101 dans la zone placée au dessus du libellé F8.
Validez la boîte de dialogue des Touches par Ok.
Remarque : Au dessus des libellés des touches de fonction (F1, …, F16), vous trouvez quatre zones en saisie. La zone inférieure (située juste au dessus du libellé) correspond au numéro de point d'arrêt associé au piège de la touche elle-même, les zones supérieures correspondent aux pièges des combinaisons de touches Maj+Fnn, Ctrl+Fnn et Maj+Ctrl+Fnn.

  • Paramétrage de la donnée Nomfour (nom du fournisseur).
    -     Donnée en affichage.
    Cette donnée n'est pas stockée dans le fichier Articles mais dans le fichier Fournisseurs. En saisie de la fiche Article, elle est automatiquement renseignée par la séquence de traitement, exécutée après la saisie du code fournisseur. Elle-même n'est donc pas saisie : pour la donnée NomFour, sélectionnez le choix Affichage de la propriété Saisie de la famille Saisie.
    Remarque : Après la saisie d'un code article déjà existant, c'est le programme principal qui lira l'enregistrement Fournisseur, correspondant à l'article demandé, pour renseigner le nom du fournisseur.

  • Création de la donnée Wfonc (fonction).
    La valeur affichée renseigne l'utilisateur sur la fonction en cours : création ou modification. Nous en ferons un multi-choix de nature numérique prenant la valeur 1 en création et 2 en modification.
    Wfonc ne fait évidemment pas partie d'un enregistrement stocké sur disque. C'est pourquoi nous l'avons déclarée dans un enregistrement de manoeuvre (Man).
    Sélectionnez le choix Multi-choix du menu Objets ou cliquez sur le bouton équivalent.
    Double-cliquez sur la ligne de la liste affichant l'enregistrement Man pour afficher les données de cet enregistrement.
    Sélectionnez la donnée Wfonc et validez par Ok.

  • Paramétrage de la donnée Wfonc (fonction).
    -     Donnée en affichage.
    Wfonc sera renseignée par le programme lors du point d'arrêt après la saisie du code article. N'étant pas une donnée saisie, il faut la déclarer "en affichage" : pour la donnée Wfonc, sélectionnez le choix Affichage de la propriété Saisie de la famille Saisie.
     
    -     Déclaration des choix.
    Cliquez     dans la colonne de droite de la propriété Dictionnaire, Choix puis sur le bouton d’ouverture de la boîte de dialogue Dictionnaire des Multi-choix.
    Saisissez Applimc.dhfi dans la zone Dictionnaire.
    Entrez Fonction dans la zone Choix.
    Cliquez     sur le bouton Ajouter. La boîte de dialogue Choix est affichée.
    Sélectionnez le Type de choix : Normal.
    Entrez Création dans la zone Texte.
    Cliquez     sur le bouton Ajouter Après.
    Entrez Modification dans la zone Texte.
    Cliquez     sur le bouton Ajouter Après.
    Validez la boîte Choix par Ok.
    Validez la boîte Dictionnaire des Multi-choix par Ok.

 

5. Dessin de la page 2 : Confirmation de validation

  • Tapez Page-Down pour aller sur la page 2.

  • Création des boutons.
    Sélectionnez le choix Bouton du menu Objets ou cliquez sur le bouton équivalent.
    Placez le premier bouton et affectez-lui les propriétés suivantes :
    -     Texte du bouton : Oui.
    -     En saisie : Oui (obligatoire ici car la fenêtre n'a pas de donnée en saisie).
    -     Type de traitement : Point d'arrêt.
    -     Traitement / Arrêt / Chaîne : 301.
    Créez le 2ème bouton de manière similaire avec les paramètres :
    -     Texte du bouton : Non.
    -     En saisie : Oui.
    -     Type de traitement : Point d'arrêt.
    -     Traitement / Arrêt / Chaîne : 302.

 

6. Dessin de la page 3 : Confirmation d'abandon

  • "Copier" de la page 2.
    Le contenu de la page 3 est identique à celui de la page 2 (les deux fenêtres ne diffèrent que par leur titre).
    Nous allons dupliquer le contenu de la page 2 à l'aide de la fonction "Copier – Coller".
    Sélectionnez le choix Sélection du menu Edition.
    Sélectionnez le contenu complet de la page 2 à la souris.
    Sélectionnez le choix Copier du menu Edition.

  • "Coller" dans la page 3.
    Tapez Page-Down pour aller sur la page 3.
    Sélectionnez le choix Coller du menu Edition.
    Cliquez immédiatement pour poser les objets dupliqués.

 

7. Création et écriture du programme Diva principal

  • Création du fichier source.
    Sélectionnez le choix Nouveau du menu Fichier.
    Sélectionnez le choix Texte et validez.
    Sélectionnez le choix Enregistrer Sous du menu Fichier.
    Enregistrez le nouveau fichier source dans votre dossier Exo sous le nom Appli.dhsp.

  • Saisissez les lignes de programme suivantes :

;Exemple de programmation de la saisie d'un masque

 

HFILE Appli.dhsd Farti Farti                    ;fichier articles 

HFILE Appli.dhsd Ffour Ffour                    ;        fournisseurs 

PUBLIC RECORD Appli.dhsd Arti                   ;enregistrement article

PUBLIC RECORD Appli.dhsd Four                   ;               fournisseur

PUBLIC RECORD Appli.dhsd Man                    ;               manoeuvre

       RECORD Appli.dhsd Arti Warti             ;article de travail 

       RECORD DDSYS.dhsd Zoom                   ;enregistrement zoom  

 

DEFINE CREAT = 1                                ;valeurs de Wfonc

DEFINE MODIF = 2

 

1 fini X                                        ;drapeau fin de saisie

 

 

;Procédure : SAISIE

;Description : Saisie de la fiche article

 

PROCEDURE Saisie

BEGINP

   Arti = " "                                   ;raz article 

   fini = 0 

   XmeInput ("EAPPLI",1,0,XME_MODE_GOTO)        ;lancement saisie 

   DO                                           ;tests des causes de 

      SWITCH Harmony.Arret                      ;l'interruption 

         CASE Harmony.Key = K_ESCAPE            ;abandon :

                                                ;fenêtre de confirmation

            XmeInput ("EAPPLI",3,0,XME_MODE_GOSUB)

            IF Harmony.Arret = 301              ;seul "Oui" abandonne

               fini = 1                         ;--> saisie abandonnée 

            ENDIF                               ;retour à la saisie sinon

            XmeRet                              ;referme la fenêtre

 

         CASE 10                                ;arrêt après saisie code :

            IF Arti.Codart <> " "               ;espace interdit

               Farti.Key = "A" & Arti.Codart    ;recherche article

               IF HSEEK (Farti, Warti ,'F') = 0

                  Man.Wfonc = MODIF             ;clé ok : modification

                  Arti = Warti                  ;maj article réel

                                                ;recherche fournisseur

                  Ffour.Key = "A" & Arti.Codfour

                  IF HSEEK (Ffour, Four, "F") <> 0

                     Four.Nomfour = "Inconnu"   ;nom affiché

                  ENDIF

               ELSE

                  Man.Wfonc = CREAT             ;clé non ok : création

               ENDIF

            ELSE

               Harmony.Retour = XMENEXT_RESSAISIE ;ressaisie si espace

            ENDIF

 

         CASE 101                               ;piège touche F8 : 

            if Harmony.KeyZoomCombo

               ZoomCombo (...)                  ;appel de la "Fenêtre liste"

            elsif Harmony.KeyZoomSearch

               ...                              ;appel personnalisé du zoom

            else

               ZoomSql (...)                    ;appel du Zoom

            endif

            IF Zoom.Status = E_ZOOM_OK          ;zoom validé ?

                                                ;=> donnée suivante

               Harmony.Retour = XMENEXT_TEST_ABANDON

            ENDIF                               ;sinon retour au code

                                                ;(Retour = 0)

 

                                                ;après les points d'arrêt 

 

         CASE Harmony.Key in (K_UP, K_BTAB)     ;flèche en haut ou Back-Tab 

                                                ;sur la 1ère donnée du masque : 

                                                ;on ne fait rien => 

                                                ;retour à la saisie 

                                                ;(Retour=0) 

 

                                                ;validation ou sortie 

                                                ;par Tab ou Flèche bas 

                                                ;sur la dernière donnée : 

         CASE Harmony.Key in (K_RETURN, K_TAB, K_DOWN)

                                                ;fenêtre confirmation

            XmeInput ("EAPPLI",2,0,XME_MODE_GOSUB) 

            IF Harmony.Arret = 301              ;seul "Oui" valide

               fini = 2                         ;--> saisie validée 

            ENDIF                               ;retour à la saisie sinon 

            XmeRet                              ;referme la fenêtre

 

      ENDSWITCH 

   WHILE fini = 0                               ;suite de la saisie 

      XMENEXT (Harmony.Retour, Harmony.CplRetour) 

   WEND 

ENDP

 

 

;Schéma de programme principal

 

MAIN

Arti = " "                                      ;initialisations
