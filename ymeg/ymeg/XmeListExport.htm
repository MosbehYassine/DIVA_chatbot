XmeListExport  Famille Thème

Export et filtrage des données d'un tableau

 

XmeListExport (Identifiant, Ligne, Pexport, [Module], [Id_filtre])

 
Paramètres :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

Ligne

Enregistrement "ligne du tableau".

Pexport

Paramètre de gestion de l’export (Cf. variable Zoom.SceExport).

Module

Nom du module contenant la fonction de sélection DefprocExportSelection.
Voir le paragraphe "Sélection des lignes du tableau dans le cadre de l'export".
Ce paramètre est facultatif (Harmony.DefpModule par défaut).

Id_filtre

Identificateur de la liste où stocker les éléments filtrés.
Voir le paragraphe "Filtrage des lignes du tableau".
Attention : ce paramètre est obligatoire si un filtrage est effectué.

 
 
Description de la procédure :

  • Cette procédure permet en particulier :

    • D’exporter les données d’un tableau (de manière similaire à l’impression paramétré du zoom).

    • De filtrer les lignes d’un tableau (de manière similaire à la fonction de filtrage du zoom).

  • Plus précisément, elle exécute l'action correspondant au point d'arrêt généré par le choix du menu, affiché par la procédure XmeListExportPopupMenu et sélectionné par l'utilisateur (XmeListExportPopupMenu affiche un menu surgissant contextuel, proposant les fonctions d'export et/ou de filtrage que vous souhaitez fournir à l'utilisateur pour l'objet tableau Identifiant ; chaque choix génère un point d'arrêt spécifique traité par XmeListExport).
    Reportez-vous à la rubrique consacrée à XmeListExportPopupMenu pour connaître la liste complète des fonctions offertes.

  • XmeListExport est définie dans le module yListExport.dhop. Votre programme doit donc déclarer ce module
    (Module "yListExport.dhop") avant d'y faire appel.

 

Sélection des lignes du tableau dans le cadre de l'export :

Si l'action demandée est un export, XmeListExport appelle, pour chaque ligne du tableau, la fonction de nom pré-défini DefprocExportSelection du module Module. Si vous désirez effectuer une sélection, programmez la fonction DefprocExportSelection. Cette fonction a la syntaxe suivante :

Function int DefprocExportSelection (Identifiant, &Ligne, Selection)

Paramètres en entrée :

Identifiant    Identificateur du tableau.

Ligne           Enregistrement "ligne du tableau" garni par XmeListExport avec la ligne courante.

Selection     Valeur de la variable RowInfo.Selection associée à la ligne courante.

 

Retour de la fonction :

0 : La ligne doit être sélectionnée.
1 : La ligne doit être ignorée.

DefprocExportSelection est facultative. Si vous l'implémentez et si vous la placez dans un module autre que celui désigné par la variable Harmony.DefpModule, précisez ce module dans le paramètre Module.

 

 

Filtrage des lignes du tableau :

Si l'action demandée est un filtrage, XmeListExport stocke les lignes éliminées par le filtre dans une liste complémentaire. Vous devez créer cette liste et indiquer son identificateur dans le paramètre Id_filtre.
