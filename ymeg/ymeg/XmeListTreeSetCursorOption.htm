XmeListTreeSetCursorOption  Famille Thème

Positionnement de l'option "Affichage du curseur de création d'un arbre"

 
XmeListTreeSetCursorOption (Identifiant, Curseur)

 
Paramètres :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

Curseur

TRUE si vous voulez faire apparaître le curseur de création dans l'en-tête de la colonne du tableau affichant l'arborescence.
 
Remarque : Ywpf N'affiche ce curseur QU'à l'occasion d'un XmeListConsult.
 
FALSE dans le cas contraire.

 
Description de la fonction :

La procédure XmeListTreeSetCursorOption permet de valider (Curseur = TRUE) ou d'invalider (Curseur = FALSE) l'affichage du curseur de création dans l'arbre dont l'identifiant est fourni en paramètre.

 

Remarques :

  • La procédure XmeListTreeSetCursorOption NE peut être appelée QUE si la page de masque contenant le tableau est la page courante (ou l'une de ses pages panels).

  • XmeListConsultDefault assure une gestion standard du curseur de création, dès lors que vous avez fait appel à XmeListTreeSetCursorOption (ou à XmeListTreeCursorInit) avec le paramètre Curseur à TRUE.

  • Par défaut, Ywpf N'affiche PAS de curseur de création.
    Le curseur n'est pas affiché non plus en mode "Licence consultation".

 

Exemple :
 

XmeListTreeSetCursorOption (Ident, TRUE) ;curseur création validé
