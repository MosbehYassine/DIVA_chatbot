Exemple de programmation de positionnement souris en consultation de masque

Reprenons l'exemple donné à la rubrique Exemple de programmation du point d'arrêt "Demande de saisie" et adaptons la programmation au cas de la consultation :
 

;Schéma de programmation de positionnement souris,

;en consultation de masque par XmeConsult

 

...

 

PUBLIC RECORD Appli.dhsd Efact                  ;enregistrement en-tête

PUBLIC RECORD Appli.dhsd Pfact                  ;               pied

 

1 Etat X

 

 

;Fonction : SaisieEntete

;Type : Int

;Description : Saisie de l'en-tête

;En entrée : seq = point de séquence de la donnée où faire

;                  débuter la saisie

 

FUNCTION INT SaisieEntete (seq)

1 seq X

1 fini X

 

BEGINF

   fini = 0 

   XmeInput ("EDEMAND",1,seq,XME_MODE_GOTO)     ;-> directement sur 

   DO                                           ;la donnée cliquée 

      SWITCH Harmony.Arret

         ... 

      ENDSWITCH 

   WHILE NOT fini 

      XMENEXT (Harmony.Retour, Harmony.CplRetour)

   WEND

 

   FRETURN (fini) 

ENDF

 

 

;Fonction : SaisiePied

;Type : Int

;Description : Saisie du pied

;En entrée : seq = point de séquence de la donnée où faire

;                  débuter la saisie

 

FUNCTION INT SaisiePied (seq)

1 seq X

1 fini X

 

BEGINF

   fini = 0 

   XmeInput ("EDEMAND",2,seq,XME_MODE_GOTO)      ;-> directement sur 

   DO                                            ;la donnée cliquée 

      SWITCH Harmony.Arret

         ... 

      ENDSWITCH 

   WHILE NOT fini 

      XMENEXT (Harmony.Retour, Harmony.CplRetour)

   WEND

 

   FRETURN (fini) 

ENDF

 

 

;Fonction : CONSULTATION

;Type : Int

;En sortie : 2 = abandon

;            1 = demande de saisie

 

FUNCTION INT Consultation

1 fini X

BEGINF

   fini = 0 

   XmeConsult ("EDEMAND",1,XME_MODE_GOTO)

 

   REPEAT 

      SWITCH Harmony.Key 

         CASE K_ESCAPE

            fini = 2                             ;abandon 

         CASE Harmony.SourisPage <> 0 AND \      ;donnée en saisie

              Harmony.SourisSeq <> 0 

            fini = 1 

 

         ...                                     ;etc.

      ENDSWITCH 

   UNTIL fini <> 0 

 

   FRETURN (fini)

ENDF 

 

 

;Programme principal

 

MAIN

Efact = " "

Pfact = " "

XMELOAD ("EDEMAND")                              ;chargement masque

XmeInfoPage ("EDEMAND",1)                        ;récupération de la taille de la page 1

XmeSetWindowSize ("EDEMAND",1,Harmony.Opara3,Harmony.Opara4) ;--> taille initiale de la fenêtre

...

XMEDISPV ("EDEMAND",1,XME_MODE_GOTO)

XMEDISPV ("EDEMAND",2,XME_MODE_GOTO)

...

 

Etat = Consultation                              ;consultation du masque

IF Etat = 1                                      ;demande de saisie :

   IF Harmony.SourisPage = 1                     ;donnée de la page en-tête 

      SaisieEntete (Harmony.SourisSeq) 

   ELSIF Harmony.SourisPage = 2                  ;donnée de la page pied 

      SaisiePied (Harmony.SourisSeq) 

   ENDIF 

ENDIF
