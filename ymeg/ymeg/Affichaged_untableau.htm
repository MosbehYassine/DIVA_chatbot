Affichage d'un tableau

  • Le "cadre" d'un objet tableau est affiché par les fonctions classiques d'affichage de page de Ywpf (XmeDisp, etc.).

  • Par contre, aucune fonction de base de Ywpf n'affiche les données d'un tableau. Il faut utiliser pour cela des fonctions spécifiques "tableau" : XmeListDisplay, XmeListConsult ou XmeListInput.

  • Il n'existe pas de fonction permettant d'afficher une ligne ou une donnée isolée d'un tableau : les fonctions citées précédemment affichent toujours toutes les lignes (présentes à l'écran). En revanche, l'affichage est optimisé de telle manière que seuls les champs modifiés sont actualisés à l'écran.

  • Si le tableau contient plus d'éléments que l'écran ne peut en afficher, vous devez préciser l'élément à placer en première ligne à l'écran grâce à la fonction XmeListSetOffset. La fonction XmeListGetOffset permet de connaître le rang du premier élément affiché.

  • Pour connaître le nombre de lignes d'un tableau qu'il est possible d'afficher à l'écran, utilisez la fonction XmeListScreenCount.

  • Pour modifier dynamiquement les attributs d’affichage :
    - D’une colonne complète de tableau, utilisez la méthode de marquage des colonnes ou la fonction XmeSetAttribut.
    - D’une ligne complète de tableau, utilisez la méthode de marquage des lignes ou la fonction XmeListSetAttribut.
    - D’une cellule isolée de tableau, utilisez la fonction XmeListSetAttribut.

 

Attention :

Un objet tableau ne peut pas être inclus dans un masque multi-écran (pages chaînées), pour la raison suivante : seule une fonction telle que XmeListDisplay permet d'afficher les données d'un tableau ; dans un masque multi-écran, le passage d'une page à une autre est transparent pour le programme ; celui-ci n'étant pas averti du changement de page, il ne peut appeler XmeListDisplay pour remplir le tableau et ce dernier sera affiché vide. Vous pouvez toutefois contourner ce problème en remplaçant le masque multi-écran par des pages non chaînées, avec programmation explicite des changements de page.
