DefProcColler  Famille Thème

Fonction " Coller " d'une ligne de tableau / arbre personnalisée
(appelée par XmeListConsultDefault)

 
Int DefProcColler (Identifiant)

 
Paramètre :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

 
Votre fonction doit rendre :

  • TRUE si vous autorisez l'insertion de la ligne courante du presse-papiers dans le tableau.

  • FALSE si vous refusez cette insertion.

 
Conditions d'exécution de la fonction :

Pour que XmeListConsultDefault fasse appel à DefProcColler, vous devez :

  • Mettre le paramètre Perso de XmeListConsultDefault à la valeur TRUE.

  • Dans votre programme et avant tout appel à XmeListConsultDefault, placer le nom du module (qui peut être le programme courant) contenant la définition de DefProcColler, dans la zone DefpModule de l'enregistrement Harmony.

 
Description de la fonction :

  • La fonction DefProcColler est appelée par XmeListConsultDefault après une demande de " Coller " par l'utilisateur et avant l'insertion en liste d'une ligne du presse-papiers. Lorsque celui-ci contient plusieurs lignes (suite à un " Copier " ou à un " Couper " d'une sélection), la fonction est appelée avant l'insertion de CHAQUE ligne.
    Rappelons que l'insertion est faite Avant la ligne courante (sauf en fin de liste, où l'utilisateur peut choisir entre une insertion Avant et une insertion Après la ligne courante).

  • DefProcColler peut être utilisée par exemple pour refuser l'insertion sous certaines conditions.
    Remarque : Avant d'appeler DefProcColler, XmeListConsultDefault garnit l'enregistrement concerné avec le contenu de la ligne en provenance du presse-papiers.

  • Lorsque l'utilisateur effectue un " Copier " ou un " Couper ", un en-tête de reconnaissance personnalisé peut être automatiquement placé par XmeListConsultDefault dans le presse-papiers. Vous pouvez alors consulter cet en-tête lorsque l'utilisateur effectue le " Coller " correspondant.
    Ceci peut par exemple vous permettre de vérifier que l'utilisateur ne colle pas dans une facture des lignes copiées ou coupées dans une autre.
     
    Pour mettre en oeuvre cette fonctionnalité    , garnissez la zone DefpClipId de l'enregistrement Harmony avant d'appeler XmeListConsultDefault (précisément, avant que soit effectué un copier ou un couper) ; placez-y (sur 100 caractères maximum) une " clé " identifiant le futur contenu du presse-papiers de manière unique.
     
    A l'occasion d'un copier ou d'un couper, XmeListConsultDefault copie Harmony.DefpClipId dans le presse-papiers. Lorsqu'un coller est ensuite effectué, XmeListConsultDefault recharge Harmony.DefpClipId avec l'en-tête lu dans le presse-papiers, avant d'appeler DefProcColler. Vous pouvez alors consulter sa valeur et, par exemple, la comparer avec la " clé " attendue.
     
    Attention     : A cette occasion, XmeListConsultDefault CASSE la donnée Harmony.DefpClipId. Le cas échéant, DefProcColler devra donc la recharger avec la " clé " de départ !
     
    Remarque     : L'en-tête de reconnaissance personnalisé N'est utile QUE pour les copier – couper - coller dans un MEME tableau. En effet, XmeListConsultDefault interdit implicitement de copier des lignes d'un tableau dans un autre (il gère dans tous les cas un premier en-tête, formé du nom du tableau dans Xwin et de la longueur de l'enregistrement concerné).
     
    Attention     : Harmony.DefpClipId NE DOIT PAS être chargée dans la fonction DefProcDelete ; en effet, d'une part l'écriture dans le presse-papiers a lieu AVANT son appel, d'autre part DefProcDelete N'est PAS exécutée lors d'un " Copier ". De même, Harmony.DefpClipId ne doit pas être chargée dans la fonction DefProcCopier, non exécutée lors d'un " Couper ".

  • L'insertion des lignes en liste proprement dite continue à être prise en charge par XmeListConsultDefault.

  • En cas de " Copier " ou de " Couper " d'un élément d'arbre, les sous-niveaux de l'élément sont automatiquement copiés dans le presse-papiers. Lors du " Coller " correspondant, DefProcColler est appelée pour CHAQUE ligne à insérer (donc pour l'élément " père " puis pour chaque " descendant ").
    Toutefois, au retour, l'autorisation d'insertion N'est vérifiée QUE pour l'élément père : ses descendants sont toujours insérés (autrement dit, si vous donnez l'autorisation d'insérer un père, vous ne pouvez pas refuser l'insertion de ses descendants).
    Dans le cas d'une sélection, l'autorisation d'insertion est vérifiée pour CHACUN des éléments père (mais pas pour leurs descendants respectifs). Rappelons que les éléments père sont tous de même niveau.

 

Attention : DefProcColler DOIT laisser l'élément courant de la liste inchangé. De plus, c'est l'enregistrement concerné lui-même (garni en entrée avec la ligne à coller) qui sera inséré en liste ; si vous changez son contenu, c'est l'enregistrement modifié qui sera inséré.
 

Exemple :
 

;Programme PROG (schéma)

...

 

FUNCTION INT DefProcColler (Ident)

1 Ident L

1 retour X

beginf

   IF Harmony.DefpClipId <> Clé           ;contrôle de l'identifiant

      retour = FALSE                      ;coller refusé 

      Harmony.DefpClipId = Clé            ;restaure DefpClipId

   ELSE 

      retour = TRUE                       ;coller accepté

   ENDIF

   FRETURN (retour) 

endf

 

...

...

 

Main

...

Harmony.DefpModule = 'PROG.dhop'          ;le programme lui-même

...

Harmony.DefpClipId = Clé                  ;identifie le contenu

                                          ;du presse-papiers 

Fini = FALSE

DO                                        ;boucle de consultation

   XmeListConsult (Ident) 

   SWITCH Harmony.Key                     ;événement produit ? 

      CASE K_ESCAPE                       ;touche Echap : 

         Fini = TRUE                      ;stop 

 

      DEFAULT                             ;autres événements 

                                          ;traitement par défaut 

                                          ;avec personnalisation 

   XmeListConsultDefault (Ident, Ligne, ScrollBar32, \

                          Privilège, Sélection, TRUE)

   ENDSWITCH

WHILE Fini = FALSE

WEND
