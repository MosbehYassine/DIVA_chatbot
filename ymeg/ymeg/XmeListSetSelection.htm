XmeListSetSelection  Famille Thème

Marquage ou sélection des éléments d'un tableau

 
XmeListSetSelection (Identifiant, Sélection, Indice Début, Indice Fin)

 
Paramètres :

Identifiant

Identificateur du tableau rendu par la fonction XmeListGetId.

Sélection

Indicateur demandant le marquage (TRUE) ou le démarquage (FALSE) des lignes indiquées.

Indice Début

Rang dans la liste de la première ligne à (dé)marquer.

Indice Fin

Rang dans la liste de la dernière ligne à (dé)marquer.

 
Description de la fonction :

La procédure XmeListSetSelection modifie le champ Sélection de la donnée de contrôle, associée aux éléments du tableau paramétré dont le rang est compris entre Indice Début et Indice Fin (pour tous renseignements sur la donnée de contrôle, on se reportera aux rubriques Marquage des lignes d'un tableau et Sélection multiple des lignes d'un tableau).
 
Au prochain affichage du tableau :

  • Si le paramètre Sélection vaut TRUE, les lignes correspondant aux éléments paramétrés seront marquées (pour ces éléments, l'indicateur Donnée de contrôle.Selection sera mis à TRUE). Dans ce cas :
    -     Si la donnée de contrôle associée à un élément précise une couleur (Donnée de contrôle.Couleur = "Nom d'une couleur dans la feuille de styles" ou Donnée de contrôle.CoulSelec = TRUE), la ligne correspondante prendra la couleur indiquée.
    -     Et/ou si la donnée de contrôle précise une image bitmap (Donnée de contrôle.Bitmap = "Nom dans la feuille de styles ou numéro prédéfini d'une image bitmap"), la colonne d'état en regard de la ligne affichera la bitmap indiquée.

  • Si le paramètre Sélection vaut FALSE, les lignes seront démarquées (Donnée de contrôle.Selection mis à FALSE) :
    -     Elles reprendront leur couleur de base.
    -     Les images bitmap éventuellement présentes dans la colonne d'état seront effacées.

 

XmeListSetSelection est une facilité d'écriture qui équivaut à programmer les instructions suivantes :
 

;XmeListSetSelection (Ident, Selec, Ideb, Ifin) <=>

 

XmeListGetPosition (Ident, Position)

XmeListIndex (Ident, Ligne, Ideb)

LOOP Ideb++ <= Ifin

   RowInfo.Selection = Selec

   XmeListModify (Ident, Ligne)

   XmeListNext (Ident, Ligne)

ENDLOOP

XmeListSetPosition (Ident, Position)

XmeListCurrent (Ident, Ligne)

 

Remarques :

  • Couleur et/ou image bitmap peuvent être différentes pour chaque ligne du tableau.

  • La procédure XmeListSetSelection elle-même n'effectue aucun affichage.

  • La procédure standard XmeListConsultDefault gère la sélection multiple des lignes lors d'une consultation par XmeListConsult.

 

Exemple :
 

;Marquage uniforme (toutes les lignes marquées

;sont affichées avec les mêmes attributs)

...

PUBLIC RECORD DDSYS.dhsd RowInfo

...

 

MAIN 

                                      ;on initialise les infos

                                      ;sur les attributs des lignes 

RowInfo = " "                         ;une fois pour toutes :

RowInfo.Bitmap = "1"                  ;coche en colonne d'état

RowInfo.CoulSelec = FALSE

RowInfo.Couleur = "BLEUCIEL"          ;couleur bleu ciel

 

RowInfo.Selection = FALSE             ;état initial

...

XmeListSetSelection (Ident,TRUE,3,5)  ;marque les éléments 3, 4, 5

...

XmeListSetSelection (Ident,FALSE,4,4) ;démarque l'élément 4

...
