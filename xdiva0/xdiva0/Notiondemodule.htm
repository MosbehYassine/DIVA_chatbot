Notion de module

La compilation d'un source Diva génère un module. Un module peut être soit un exécutable soit une bibliothèque de fonctions.

Seules les fonctions déclarées Public sont visibles à l'extérieur du module. Un module A peut donc appeler des fonctions/procédures définies Public dans un module B.

Un module qui veut utiliser une fonction/procédure d'un module externe doit déclarer le module externe par la déclarative Module

Si le module a une extension, elle doit être précisée.

Exemple : Module "mfcli.dhop"
