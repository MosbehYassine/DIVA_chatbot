Noms des fonctions/procédures

Il peut y avoir ambiguïté sur le nom d'une fonction/procédure si un programme utilise deux modules contenant une fonction/procédure de même nom.

 

Exemple :

Module PROG

Module MODA

Module MODB

public procedure affiche(tx)

1 tx a

beginp

……………

endp

 

module "moda"

module "modb"

 

main

affiche("bonjour")

ProgramExit

public procedure affiche(tx)

1 tx a

beginp

……………

endp

public procedure affiche(tx)

1 tx a

beginp

……………

endp

 

 

Lors de la compilation de Prog, le compilateur détecte l'ambiguïté et affiche le message suivant : "La fonction/procédure AFFICHE est dans les modules suivants : Courant MODA MODB".

Pour lever l'ambiguïté il faut préfixer le nom de la fonction/procédure par le nom du module (sans extension) dans laquelle elle se trouve. Pour appeler la fonction/procédure qui se trouve dans le même source, il faut utiliser le mot Local.

Remarque

Avec l'écriture module.fonction il ne faut pas spécifier d'extension pour le module même s'il a été déclaré avec une extension.

Exemple :

Local.affiche("bonjour")  ; appel de la fonction définie dans Prog

Moda.affiche("bonjour")  ; appel de la fonction définie dans Moda

Modb.affiche("bonjour")  ; appel de la fonction défini dans Modb
