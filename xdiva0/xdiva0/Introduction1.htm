Introduction

Les programmes Harmony sont développés avec un seul langage : Diva. Le même langage sert à écrire les programmes et les traitements associés aux données placées dans les masques de saisie.

Le code généré par le compilateur Diva est entièrement 32 bits, c'est à dire qu'il n'y a pas de limite quant à la taille des programmes et la taille des données utilisées par un programme.

La compilation des sources Diva se fait directement depuis l'éditeur Xwin. De plus

  • un debugger puissant permet d'exécuter les programmes pas-à-pas, de visualiser le contenu des données etc.

  • un outil de navigation permet de retrouver tous les endroits où un objet (champ, table, choix) est utilisé.
