Diva et les masques graphiques

Lien avec les enregistrements du programme

Dans la boite de dialogue des enregistrements de Xwin, la saisie du préfixe est remplacée par la saisie du nom de la variable. Le lien entre le programme et le masque est fait d'après ce nom.

Exemple :

Si dans le programme se trouve la déclaration suivante :

 Public Record xxfdd Client EnregClient

il faut ajouter la ligne suivante aux enregistrements du masque :
Dictionnaire       :  xxfdd
Enregistrement  :  client
Variable            :  enregclient.

L'enregistrement doit être déclaré Public dans le programme pour que le masque et les données travaillent sur les mêmes données.

 

Déclarations et traitements initiaux

Il est possible de déclarer des variables locales au masque qui sont visibles dans tous les traitements du masque. De même, il est possible de déclarer des modules externes qui sont utilisés dans les traitements liés aux données.

Des traitements initiaux peuvent être programmés dans la boite de dialogue "Paramètres masque --> Traitement initial". Ces instructions sont exécutées une seule fois au chargement du masque.

 

Instructions

Les traitements (avant/après la saisie, avant/après l'impression d'un bloc etc.) sont saisis directement dans la fenêtre des traitements du masque.
