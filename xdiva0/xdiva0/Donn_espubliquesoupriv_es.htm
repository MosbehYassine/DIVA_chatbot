Données publiques ou privées

Les données déclarées dans un module peuvent être soit locales au module (aucun autre module ne peut y accéder, c'est le cas par défaut) soit être publiques (d'autres modules peuvent y accéder).

Seules les données en provenance du dictionnaire (instructions Hfile et Record) peuvent être publiques. Leur déclaration doit être précédée du mot clé Public.

 

Exemple :

Module A

Module B

Module C

Record appfdd Client
Public Record addfdd Article

Public Record appfdd Client
Public Record addfdd Article

Public Record appfdd Client
Public Record addfdd Article

 

Les modules B et C partagent l'enregistrement Client et les trois modules partagent l'enregistrement Article. Par contre, l'enregistrement Client du module A n'est pas partagé par les autres modules, il est local au module A.

Pour qu'un module Diva puisse accéder à un enregistrement utilisé dans un masque Xwin, cet enregistrement doit obligatoirement être déclaré Public dans le module.

 

Remarque

Il est possible d'exécuter une fonction de module au moment ou il est chargé. Voir Affectation d'une valeur initiale
