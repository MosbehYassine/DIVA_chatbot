Fonctions/procédures publiques ou privées

Par défaut, les fonctions/procédures sont privées, c'est à dire qu'elles ne peuvent être appelées depuis un autre module.

Pour qu'une fonction/procédure puisse être appelée depuis un autre module, elle doit être déclarée publique.

Exemple :

Module A

Module B

Public Int Function RechercherClient(code)
1 code A
Beginf
……….
Endf

Module "A"
………………
st = RechercherClient(CodeCli)

La fonction RechercherClient est définie publique dans le module A. Le module B peut donc utiliser cette fonction.
