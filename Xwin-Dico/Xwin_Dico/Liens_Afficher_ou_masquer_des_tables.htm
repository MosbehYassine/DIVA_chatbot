Liens : Afficher ou masquer des tables

Cette boîte de dialogue vous permet de sélectionner les tables que vous désirez voir dans le schéma courant. Xwin vous propose la liste de toutes les tables incluses dans la gestion des liens. Vous pouvez masquer, afficher ou supprimer des tables.

Dans la liste des tables, sélectionnez les tables que vous désirez afficher ou masquer et cliquez sur le bouton correspondant à l’action désirée.
