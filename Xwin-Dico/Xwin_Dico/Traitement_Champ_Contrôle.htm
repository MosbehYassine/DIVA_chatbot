Traitement Champ Contrôle

 

Le traitement local (facultatif) "Contrôle", associé à un champ d'une table, est destiné à être appelé explicitement par un programme ou un module Diva, généralement pour contrôler la valeur du champ.
 

Il s'agit d'une fonction de type Int ayant le paramètre suivant :

  • table
    Instance de la table contenant le champ à contrôler (passée par adresse).

 

Exemple du squelette de la fonction généré par Xwin :
 

;*

Public Function Int Champ_MaTable_MonChamp_Ctrl (&MaTable)

;

Record "MonDico.dhsd" MaTable

Beginf

   

   Freturn (0)

Endf

 

Exemple d'appel de cette fonction :

 

Module "MonDico.dhod"

 

Public Record "MonDico.dhsd" MaTable MonInstance

1   Resultat   X

 

Resultat = MonDico.Champ_MaTable_MonChamp_Ctrl (MonInstance)
