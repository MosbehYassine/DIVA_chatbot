Séquence des opérations

Rappel 

Avant de vous plonger dans la création des liens, vérifiez que tous les index de vos fichiers sont correctement définis.

L’accès aux liens du dictionnaire se fait par le choix Liens du menu Affichage où par le bouton .

Lorsque vous ouvrez pour la première fois les liens d’un dictionnaire, l’arbre est vide. La première opération à effectuer est de sélectionner les tables du dictionnaire sur lesquelles les liens vont être posés.

 

Ajouter des tables

Préalablement, dans le menu Options, vérifiez que le choix Créer des liens à l’ajout d’une table est coché.

Puis, pour ajouter les tables, sélectionnez le choix Ajouter une table du menu contextuel du dictionnaire ou de la liste des liens.

La boîte de dialogue de sélection des tables vous permet de sélectionner tout d’abord un fichier puis de sélectionner une ou plusieurs tables de ce fichier.

Les liens sont automatiquement créés, vous pouvez les voir en expansant les éléments de l’arbre.

Remarquez que tous les liens sont marqués de rouge ce qui signifie qu’ils ne sont pas valides.

Pour l’instant, le schéma est vide.

 

Créer des schémas

Dans le menu Schéma, sélectionnez le choix Créer automatiquement un schéma par table. Dans l’arbre vous pouvez maintenant voir la liste des schémas créés et les afficher dans la partie droite.

 

Examiner et valider les liens

Il vous reste maintenant à valider les liens. Dans le schéma ou dans l’arbre, cliquez sur un lien ; la boîte de dialogue des propriétés du lien s’affiche. Vérifiez que le lien est correct puis décochez la case Lien invalide.

 

Remarque

C’est vous qui décidez quels sont les tables et les liens qui doivent être affichés dans un schéma.Si vous ajoutez une table à la liste des tables de l’arbre, cette nouvelle table ne s’affichera pas automatiquement. Utilisez les choix Afficher ou Masquer des tables et Afficher ou Masquer des liens pour choisir les éléments qui doivent apparaître dans le schéma.
