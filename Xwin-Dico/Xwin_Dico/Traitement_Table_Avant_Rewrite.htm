Traitement Table Avant Rewrite

 

Le traitement local (facultatif) "Avant Rewrite", associé à une table d'un fichier, est automatiquement appelé par l'instruction Diva iRewrite avant la réécriture de l'enregistrement.

 

Il s'agit d'une procédure ayant les paramètres suivants :

  • tdf
    Table de définition de fichier utilisée pour effectuer la réécriture de l'enregistrement (passée par adresse).

  • table
    Instance de l'enregistrement réécrit (passée par adresse).

 

Exemple du squelette de la procédure généré par Xwin :
 

;*

Public Procedure Table_MonFichier_MaTable_Rewrite (&tdf,&table)

;

Record *  htdf tdf                  ;table de définition de fichier

Record MonDico.dhsd MaTable table

Beginp

   

Endp
