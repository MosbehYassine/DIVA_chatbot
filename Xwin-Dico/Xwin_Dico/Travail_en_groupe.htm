Partage du dictionnaire

Un dictionnaire peut être utilisé simultanément par plusieurs utilisateurs.

Il peut donc être consulté depuis plusieurs postes, utilisé par les compilateurs etc.

 

N lecteurs – 1 écrivain

Si plusieurs utilisateurs peuvent lire un dictionnaire, un seul utilisateur peut faire une modification à un instant donné. Les autres utilisateurs devront attendre que la modification soit terminée et le dictionnaire sauvegardé.

L’interdiction de modification est signifiée par un message :
Le fichier xxxx est en cours de modification par un autre utilisateur.

 

Chargement de la dernière version

Lorsqu’un utilisateur commence une modification dans un dictionnaire, Xwin contrôle qu’il a bien la dernière version du dictionnaire sous les yeux. Si le dictionnaire a été modifié depuis un autre poste, le message suivant s’affiche :
Vous ne travaillez pas avec la dernière version du fichier xxxxx
Désirez-vous charger cette dernière version ?
