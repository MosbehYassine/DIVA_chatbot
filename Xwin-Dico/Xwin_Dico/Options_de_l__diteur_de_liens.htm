Options de l’éditeur de liens

 

Le menu option comporte les choix suivants :

Créer les liens à l’ajout d’une table

Lorsque ce choix est coché, et que vous ajoutez une table à la liste des tables de l’arbre, Xwin crée automatiquement les liens concernant cette table.

 

Créer les schémas avec les liens sortants
Créer les schémas avec les liens entrants
Créer les schémas avec les liens sortants et entrants

Ce groupe permet de sélectionner le mode de création des schémas. Une fois le schéma créé vous pouvez toujours cacher/afficher certains liens. Cette option es valable lors de la génération automatique d’un schéma.

 

Invalider tous les liens
Valider tous les liens

Rend tous les liens du dictionnaire invalides/valides.
Par défaut, lorsqu’un lien est créé automatiquement par Xwin, il est marqué comme invalide. Il doit être ensuite validé pour être effectivement pris en compte.

Il est déconseillé d’utiliser le choix Valider tous les liens. Il est conseillé de vérifier et de valider chaque lien.

 

Réajuster les numéros de liens nouvellement créés

Réajuster tous numéros de liens

Ces choix permettent de renuméroter les liens lorsqu'il y a plusieurs liens entre deux tables et que certains d'entre eux ont été supprimés.

Attention : une fois que le dictionnaire a été sauvegardé, il ne faut plus utiliser Réajuster tous numéros de liens.
