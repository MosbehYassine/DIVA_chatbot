Voir les index et les liens

Le dictionnaire peut être vu de trois manières : 

  • par fichiers, tables et champs

  • par fichiers, tables et index.

  • par les liens entre les tables.

 

Pour passer en mode « Champs »

sélectionnez le choix Champs du menu Affichage

ou cliquez sur le bouton

 

Pour passer en mode « Index »

sélectionnez le choix Index du menu Affichage

ou cliquez sur le bouton

 

Pour passer en mode « Liens »

Sélectionnez le choix Liens du menu Affichage

cliquez sur le bouton

Pour revenir en mode Champs ou Index vous devez préalablement sortir de l’éditeur de liens.
