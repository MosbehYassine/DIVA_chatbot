Traitement Champ Après saisie

 

Le traitement local (facultatif) "Après Saisie", associé à un champ d'une table, est normalement destiné à être appelé par le traitement "Après saisie" de ce champ inséré dans un masque d'écran.
 

Il s'agit d'une fonction de type Int ayant le paramètre suivant :

  • table
    Instance de la table contenant le champ saisi (passée par adresse).

 

Lorsque vous insérez le champ dans un masque d'écran, Xwin génère (*) automatiquement un traitement "Après saisie" pour ce champ et y place une ligne de code faisant appel au traitement "Après saisie" du dictionnaire, aux conditions suivantes :

  1. Que ce traitement ait été effectivement créé dans le dictionnaire au moment de l'insertion.
    La génération n'a lieu que dans ce cas et une création ultérieure du traitement dans le dictionnaire n'a aucun effet sur les champs déjà insérés dans un masque.

  2. Que vous ayez sélectionné l'option "Générer l'appel au traitement du dictionnaire" au niveau des paramètres de votre projet.

(*) Ce traitement est généré même si le champ est finalement défini dans le masque comme étant "En affichage" et non "En saisie" (mais bien entendu, il ne sera jamais appelé).

 

 

Exemple du squelette de la fonction généré par Xwin dans le dictionnaire :
 

;*

Public Function Int Champ_MaTable_MonChamp_Ap (&MaTable)

;

Record "MonDico.dhsd" MaTable

Beginf

   

   Freturn (0)

Endf

 

Exemple d'appel de cette fonction dans un masque :

 

Module "MonDico.dhod"

 

Public Procedure Champ_MonChamp_1_Ap

Beginp

   MonDico.Champ_MaTable_MonChamp_Ap (MaTable)

Endp
