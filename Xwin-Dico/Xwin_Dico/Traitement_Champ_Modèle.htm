Traitement Champ Modèle

 

Le traitement local (facultatif) "Modèle", associé à un champ d'une table, est normalement destiné à être recopié dans le traitement "Après saisie" de ce champ inséré dans un masque d'écran.
 

Il s'agit d'une procédure sans paramètre.

 

Lorsque vous insérez le champ dans un masque d'écran, Xwin génère (*) automatiquement un traitement "Après saisie" pour ce champ et y recopie le corps de la procédure "Modèle" du dictionnaire (**), aux conditions suivantes :

  1. Que le modèle ait été effectivement créé dans le dictionnaire au moment de l'insertion.
    La génération n'a lieu que dans ce cas et une création ultérieure du modèle dans le dictionnaire n'a aucun effet sur les champs déjà insérés dans un masque.

  2. Que vous ayez sélectionné l'option "Copier le traitement du dictionnaire dans le masque" au niveau des paramètres de votre projet.

(*) Le traitement est généré même si le champ est finalement défini dans le masque comme étant "En affichage" et non "En saisie" (mais bien entendu, il ne sera jamais appelé).

(**) Attention : le code copié est celui contenu par la dernière version sauvegardée du dictionnaire (et non le code "courant" si celui-ci n'a pas encore été sauvegardé).

 

Exemple du squelette de la procédure généré par Xwin dans le dictionnaire :
 

;*

Public Procedure Champ_MaTable_MonChamp_Modele

;

Beginp

   

Endp
