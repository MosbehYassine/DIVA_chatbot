Définition d'un nom de traitement

 

Les fonctions de gestion des noms de traitement sont décrites dans le livre Saisie d'un nom de traitement de la documentation de l'éditeur de masque d'écran.

 

Il existe toutefois une différence fondamentale entre le dictionnaire et les masques, à savoir que les noms de traitement sont figés dans le dictionnaire (*) et ne sont pas modifiables. Il en résulte deux différences pratiques : la saisie manuelle du nom et sa sélection dans la liste des noms existants ne sont pas possibles. Pour définir un traitement sur un objet, sélectionnez cet objet, placez-vous sur la ligne de la fenêtre des propriétés concernée puis :

  • Cliquez dans la zone de saisie pour faire apparaître le bouton zoom puis cliquez sur ce bouton.

    OU

  • Cliquez droit dans la zone de saisie puis sélectionnez le choix Générer le traitement du menu contextuel.

 

(*) Cette différence se justifie par le fait que chaque objet est unique dans le dictionnaire alors que dans un masque, vous pouvez par exemple insérer la même donnée dans plusieurs pages et affecter à cette donnée des traitements différents selon la page (dans un zoom "Articles" par exemple, on peut imaginer que le traitement après saisie du code fournisseur procède à la recherche du nom du fournisseur en mode fiche mais pas en mode liste).

 

 

Surcharge des noms de traitement du dictionnaire

Notez les règles suivantes concernant la surcharge des noms de traitement :

  • Traitement associé aux tables
    Si le traitement n'est pas défini dans la base, vous pouvez l'ajouter dans la surcharge.
    Par contre, si le traitement est déjà défini dans la base, vous ne pouvez pas l'annuler : au besoin, créez un source de surcharge vide.

  • Traitement Après saisie des champs
    Si ce traitement n'est pas défini dans la base, vous ne pouvez pas l'ajouter dans la surcharge.
    En effet, ce traitement n'est exécuté que si les masques y font explicitement appel. Or, si le traitement est absent du dictionnaire de base, cela signifie que les masques "de base" n'y font pas appel. Le surcharger resterait donc sans effet.
    Si le traitement est déjà défini dans la base, vous ne pouvez pas l'annuler : au besoin, créez un source de surcharge vide.

  • Traitement Contrôle des champs
    Si le traitement n'est pas défini dans la base, vous pouvez l'ajouter dans la surcharge.
    Par contre, si le traitement est déjà défini dans la base, vous ne pouvez pas l'annuler : au besoin, créez un source de surcharge vide.

  • Traitement Modèle des champs
    Toutes les opérations sont ici autorisées.

  • Traitement des champs virtuels
    Ce traitement étant obligatoire, il ne peut pas être annulé (mais il peut être surchargé).
