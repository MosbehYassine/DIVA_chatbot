Traitement Champ virtuel

 

Le traitement local (obligatoire) "A chaque accès", associé à un champ virtuel d'une table, est automatiquement exécuté à chaque accès (affichage, impression, mention dans une expression Diva, etc.) au champ.

Il sert à calculer la valeur du champ virtuel.
 

Il s'agit d'une fonction dont le type dépend de la nature du champ et ayant le paramètre suivant :

  • table
    Instance de la table contenant le champ virtuel à calculer (passée par adresse).

 

Exemple d'un squelette de fonction généré par Xwin (donnée virtuelle de nature numérique ==> type Int) :
 

;*

Public Function Int Champ_MaTable_MonChampNumerique_Val (&MaTable)

;

Record "MonDico.dhsd" MaTable

Beginf

   

   Freturn (0)

Endf
