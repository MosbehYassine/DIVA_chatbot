Description générale des traitements du dictionnaire

 

Dans le dictionnaire, des traitements locaux peuvent être associés aux tables d'un fichier et aux champs d'une table.

  • Les traitements (facultatifs) associés à une table d'un fichier sont automatiquement appelés lorsque les instructions Diva correspondantes sont exécutées :

    • Le traitement "Après Read" est appelé par les instructions iRead, iPread et iSeek après lecture de l'enregistrement.

    • Le traitement "Avant Write" est appelé par l'instruction iWrite avant écriture de l'enregistrement.

    • Le traitement "Avant Rewrite" est appelé par l'instruction iRewrite avant réécriture de l'enregistrement.

    • Le traitement "Avant Delete" est appelé par l'instruction iDelete avant suppression de l'enregistrement.
       

  • Le traitement (obligatoire) associé à un champ virtuel d'une table (traitement "A chaque accès") est automatiquement exécuté à chaque accès (affichage, impression, mention dans une expression Diva, etc.) au champ.

     

  • Les traitements (facultatifs) associés à un champ d'une table sont normalement destinés à contrôler la valeur du champ, en général à la suite de sa saisie dans un masque d'écran. Contrairement aux traitements précédents, leur exécution n'est pas automatique et ils doivent être appelés d'une manière ou d'une autre. Plus précisément :
     

    • Traitement "Après Saisie"
      Lorsque vous insérez le champ dans un masque d'écran, Xwin génère (*) automatiquement un traitement "Après saisie" pour ce champ et y place une ligne de code       faisant appel au traitement "Après saisie" du dictionnaire, aux conditions suivantes :

      1. Que ce traitement ait été effectivement créé dans le dictionnaire au moment de l'insertion.
        La génération n'a lieu que dans ce cas et une création ultérieure du traitement dans le dictionnaire n'a aucun effet sur les champs déjà insérés dans un masque.

      2. Que vous ayez sélectionné l'option "Générer l'appel au traitement du dictionnaire" au niveau des paramètres de votre projet.

    • Traitement "Modèle"
      Lorsque vous insérez le champ dans un masque d'écran, Xwin génère (*) automatiquement un traitement "Après saisie" pour ce champ et y       recopie le corps du traitement "Modèle" du dictionnaire, aux conditions suivantes :

      1. Que ce modèle ait été effectivement créé dans le dictionnaire au moment de l'insertion.
        La copie n'a lieu que dans ce cas et une création ultérieure du modèle dans le dictionnaire n'a aucun effet sur les champs déjà insérés dans un masque.

      2. Que vous ayez sélectionné l'option "Copier le traitement du dictionnaire dans le masque" au niveau des paramètres de votre projet.

(*) Ce traitement est généré même si le champ est finalement défini dans le masque comme étant "En affichage" et non "En saisie" (mais bien entendu, il ne sera jamais appelé).

    • Traitement "Contrôle"
      Cette fonction ne fait l'objet d'aucune génération automatique. Elle doit être appelée explicitement.

      Exemple d'appel du traitement Champ_MaTable_MonChamp_Ctrl :

      Module "MonDico.dhod"
      Public Record "MonDico.dhsd" MaTable MonInstance
      1   Resultat   X
      Resultat = MonDico.Champ_MaTable_MonChamp_Ctrl (MonInstance)
