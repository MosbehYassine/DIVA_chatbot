Affichage du contenu d'un fichier

Depuis Xwin, il est possible de visualiser le contenu d’un fichier.

Mise en œuvre

Le choix  Affichage contenu fichier est accessible depuis le menu contextuel d’une table. Attention, la table doit avoir un fichier comme ascendant et non pas être sélectionnée depuis la liste de toutes les tables du dictionnaire.

Xwin appelle Xtools.dhop (choix « Afficher/Modifier d’après le dictionnaire »)  pour afficher le fichier. Le fichier paramètre créé à cette occasion est détruit au retour. Si vous désirez le garder, vous pouvez le sauvegardez dans Xtools.dhop avec le bouton ‘Enregistrement des paramètres dans un fichier’.
