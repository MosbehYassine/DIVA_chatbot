Créer un fichier source

La commande "Nouveau" permet la création d'un nouveau texte source. Elle crée une nouvelle fenêtre MDI dans Xwin et est accessible par deux moyens :

  • Sélectionnez le choix Nouveau du menu Fichier (raccourci clavier : Ctrl+N).

  • Ou cliquez sur le bouton de la barre d'outils.

 

La boîte de dialogue "Nouveau" apparaît. Sélectionnez le choix :

  • Texte pour créer un nouveau source Diva (extension .dhsp).

  • Dictionnaire de RecordSql pour créer un nouveau dictionnaire de RecordSql (extension .dhsq).

  • Dictionnaire de Jointures Sql pour créer un nouveau dictionnaire de Jointures Sql (extension .dhsj).

Validez par OK.

 

 

Remarques :

  • La création d'un dictionnaire de RecordSql ou d'un dictionnaire de Jointures Sql génère automatiquement une balise d'en-tête : Voir la rubrique Assistance au codage dans un dictionnaire Sql.
     

  • Pour enregistrer le nouveau source sur disque, consultez la rubrique Sauvegarder un fichier source.

  • Les nouveaux fichiers sont libellés FichierN jusqu'à leur première sauvegarde. N est ici un nombre incrémenté séquentiellement.
     

  • Les lignes d'un source sont limitées à 251 caractères.
