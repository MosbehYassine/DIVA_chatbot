Pour ajouter une donnée dans la fenêtre des variables

Méthode 1 :

  1. Placez le curseur sur la variable ou sélectionnez-la dans votre source.

  2. Sélectionnez le choix Consulter / Modifier une variable du menu Déboguer (raccourci clavier : Maj+Ctrl+F8) ou cliquez sur le bouton de la barre d'outils du débogueur.
    La boîte de dialogue " Consulter / Modifier une variable " apparaît.

  3. Cliquez sur le bouton Ajouter aux variables.
    La fenêtre des variables est affichée si l'onglet correspondant n'était pas déjà sélectionné.

 

Méthode 2 :

  1. Dans la fenêtre de débogage rapide, cliquez droit sur la ligne affichant la donnée à ajouter.

  2. Validez le choix Ajouter à la liste des variables du menu contextuel.

 

Méthode 3 :

  1. Placez le curseur sur la variable ou sélectionnez-la dans votre source.

  2. Cliquez droit pour ouvrir le menu contextuel et validez le choix Ajouter ...... à la liste des variables.
