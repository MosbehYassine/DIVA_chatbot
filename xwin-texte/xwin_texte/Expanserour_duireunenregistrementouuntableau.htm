Expanser ou réduire un enregistrement ou un tableau

 

Lorsque la donnée affichée (dans les fenêtres Variables, Locales et Contexte ou dans la boîte de dialogue "Consulter / Modifier une variable") est un enregistrement, vous pouvez visualiser les données qui le composent. De même, vous pouvez visualiser les éléments d'un tableau :

  • Au départ, le signe plus (+) apparaît en première colonne d'une ligne affichant le nom d'un enregistrement ou d'un tableau. Si vous double-cliquez sur cette ligne, la structure est "expansée" (les données de l'enregistrement ou les éléments du tableau sont affichés).

  • Ensuite, c'est le signe moins (-) qui apparaît en première colonne. Si vous double-cliquez sur la ligne une nouvelle fois, la structure est "réduite" (les sous-données disparaissent de la liste).

 

Dans la fenêtre de débogage rapide :

  • Le signe plus (+) apparaît initialement à gauche de la ligne affichant le nom de la structure. Si vous cliquez sur le +, la structure est "expansée" (les données de l'enregistrement ou les éléments du tableau sont affichés dans une deuxième fenêtre ; utilisez au besoin l'ascenseur ou la roulette pour faire défiler les sous-données).
    Le cas échéant, plusieurs expansions en cascade sont possibles.

  • A partir de là, c'est le signe moins (-) qui apparaît à gauche de la ligne. Si vous cliquez sur le -, la structure est "réduite" (la fenêtre affichant les sous-données est refermée).
