Pour configurer les options d'assistance au codage

  1. Pour modifier les options de saisie assistée :
    Sélectionnez le choix Options du menu Outils pour appeler la boîte de dialogue "Options".
    Dans la liste des chapitres,     cliquez     sur Editeur de texte : Saisie assistée.
     

  2. Pour modifier les options de couverture du code :
    Sélectionnez le choix Options du menu Outils pour appeler la boîte de dialogue "Options".
    Dans la liste des chapitres,     cliquez     sur Débogage : Couverture du code.
     

  3. Pour modifier les couleurs (soulignage des erreurs de compilation en ligne et couverture du code) :
    Sélectionnez le choix Options du menu Outils pour appeler la boîte de dialogue "Options".
    Dans la liste des chapitres, cliquez sur Environnement : Police et couleurs.
    Sélectionnez l'élément concerné dans la liste Eléments affichés.
    Sélectionnez la couleur voulue pour les caractères et pour le fond.

    16 couleurs de base     sont accessibles dans la liste des choix des multi-choix correspondants.
    Pour obtenir une autre couleur, cliquez sur le bouton Personnaliser correspondant, qui fait appel à la boîte de dialogue "Couleurs" standard de Windows.
