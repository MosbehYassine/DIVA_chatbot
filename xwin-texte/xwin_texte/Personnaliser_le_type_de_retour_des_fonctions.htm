Personnaliser le type de retour des fonctions

 

En langage Diva, les types de retour des fonctions sont en pratique limités à quelques types généraux (char, int, etc.).

Du point de vue de l'assistance au codage, il peut être intéressant de personnaliser ce type de retour afin de le rendre plus "parlant". A cet effet, la syntaxe normale du type de retour a été étendue de la manière suivante : concaténez au mnémonique "Diva" du type le caractère "_" suivi du libellé de votre choix. C'est alors ce libellé qui sera affiché à la place du type par les fonctions d'aide à la saisie.

 

Exemples :

public function ptr_BOOL f1       ;affichera BOOL à la place de ptr

public function char_Client f2    ;affichera Client à la place de char
