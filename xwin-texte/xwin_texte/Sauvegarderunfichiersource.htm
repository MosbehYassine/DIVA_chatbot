Sauvegarder un fichier source

Lorsqu'une modification est opérée sur un texte source, le nom du fichier est suivi d'une étoile (*) dans le titre de la fenêtre MDI associée ainsi qu'au menu Fenêtre. Cette étoile est effacée lorsqu'une sauvegarde est effectuée.

 

Une sauvegarde " simple " est d'abord possible. Après avoir activé la fenêtre concernée :

  • Sélectionnez le choix Enregistrer du menu Fichier (raccourci clavier : Ctrl+S).

  • Ou cliquez sur le bouton de la barre d'outils.

Vous pouvez aussi cliquer avec le bouton droit de la souris sur l’onglet affichant le nom du fichier à sauvegarder et sélectionner le choix Enregistrer du menu contextuel.

 

Si le fichier n'a pas encore été nommé, la boîte de dialogue " Sauvegarde du fichier source texte " est affichée (celle-ci est identique à la boîte utilisée pour ouvrir un fichier) :

  • Sélectionnez le dossier de stockage.

  • Entrez le nom du fichier.

  • Validez par OK.

Si le fichier est déjà nommé, la commande est exécutée sans poser aucune question.

 

Une sauvegarde groupée de tous les sources (textes ET masques) peut aussi être faite :

  • Sélectionnez le choix Tout enregistrer du menu Fichier.

  • Ou cliquez sur le bouton de la barre d'outils.

Remarque :

Si vous lancez la compilation d'un source, Xwin effectue automatiquement une sauvegarde groupée de TOUS les sources chargés et modifiés.

 

Enfin, vous avez la possibilité de sauvegarder votre texte dans un autre fichier que celui ouvert au départ (sous un autre nom). Après avoir activé la fenêtre concernée :

  • Sélectionnez le choix Enregistrer sous du menu Fichier (raccourci clavier : Maj+Ctrl+S).

  • La boîte de dialogue " Sauvegarde du fichier source texte " est affichée (voir plus haut).

Cette procédure est utile pour maintenir plusieurs versions d'un même source ou pour conserver à la fois l'original inchangé et la dernière version modifiée.

 

Nota : La sauvegarde d’un source de traitements sauve également le masque/dictionnaire concerné (et réciproquement).
