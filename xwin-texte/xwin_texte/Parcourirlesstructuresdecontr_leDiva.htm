Parcourir les structures de contrôle Diva

Dans tout programme, il arrive fréquemment de manipuler des structures de grande taille (exemples : Beginf – Endf, Switch – EndSwitch) et des structures imbriquées (exemples : Loop – Endloop, If – Else – Endif, parenthèses).

L'éditeur de textes de Xwin offre un moyen simple de parcourir les divers éléments des structures de contrôle. Par exemple :

  • A partir de l'instruction Switch, balayer les Case et Default correspondants.

  • Retrouver l'instruction Endloop (respectivement Loop) correspondant à une instruction Loop (respectivement Endloop).

  • Retrouver la parenthèse fermante (respectivement ouvrante) correspondant à une parenthèse ouvrante (respectivement fermante).

 

Voyons la méthode à employer sur trois exemples :
 

Exemple 1 : Retrouver la fin d'une boucle Loop – Endloop.

  • Placez le curseur sur le mot clé Loop et sélectionnez le choix Structure Fin du menu Rechercher (raccourci clavier : F7).

  • Ou cliquez avec le bouton droit de la souris sur le mot clé pour ouvrir le menu surgissant et sélectionnez le même choix.

Le curseur est amené sur le mot clé Endloop.

 

Exemple 2 : Retrouver la parenthèse ouvrante correspondant à une parenthèse fermante.

  • Placez le curseur immédiatement derrière la ) et sélectionnez le choix Structure Début du menu Rechercher (raccourci clavier : Maj+F7).

  • Ou cliquez avec le bouton droit de la souris immédiatement derrière la ) pour ouvrir le menu surgissant et sélectionnez le même choix. Le curseur est positionné sur la parenthèse ouvrante correspondante.

 

Exemple 3 : Parcourir une structure à éléments multiples (ici If – Elsif – ... – Else – Endif).

  • A partir du premier élément (If) :

    • La commande Structure Fin amène le curseur sur le dernier élément (Endif).

    • La commande Elément de structure suivant (raccourci clavier : Ctrl+F7) amène le curseur sur le 1er élément intermédiaire (premier Elsif ou, à défaut, Else).

  • A partir d'un élément intermédiaire (Elsif ou Else) :

    • La commande Structure Début ramène le curseur sur le premier élément (If).

    • La commande Elément de structure suivant descend le curseur sur l'élément intermédiaire suivant (Elsif suivant ou, à défaut, Else).

    • La commande Elément de structure précédent (raccourci clavier : Maj+Ctrl+F7) remonte le curseur sur l'élément intermédiaire précédent (Elsif précédent).

    • La commande Structure Fin amène le curseur sur le dernier élément (Endif).

  • A partir du dernier élément (Endif) :

    • La commande Structure Début ramène le curseur sur le premier élément (If).

    • La commande Elément de structure précédent remonte le curseur sur le dernier élément intermédiaire (Else ou, à défaut, dernier Elsif).

 

Remarques :

  • Outre leur fonctionnement décrit ci-dessus, les fonctions de recherche d'éléments de structure "tournent en boucle". Ainsi, les touches F7 et Maj+F7 balaient en boucle les éléments de structure début et fin, et les touches Ctrl+F7 et Maj+Ctrl+F7 balaient en boucle tous les éléments de la structure.

  • Un message est affiché si l'éditeur ne trouve pas l'élément de structure demandé.

  • Si le curseur n'est pas positionné sur une structure reconnue, les choix de menu sont grisés.

  • Les structures traitées sont les suivantes :
    Beginf – Endf
    Beginp – Endp
    Do – While – Wend
    For – Next
    If – Else / Elsif – Endif
    Loop – Endloop
    Proto – EndProto
    Repeat – Until
    Structure – EndStructure
    Switch – Endswitch
    [-]
    (-).
