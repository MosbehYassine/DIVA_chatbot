Lancer ou poursuivre l'exécution du programme

Pour exécuter votre programme jusqu'à ce qu'un point d'arrêt soit atteint :

  • Sélectionnez le choix Exécuter du menu Déboguer (raccourci clavier : F5).

  • Ou cliquez sur le bouton de la barre d'outils.

 

Pour exécuter votre programme jusqu'à la ligne pointée par le curseur :

  • Sélectionnez le choix Exécuter jusqu'au curseur du menu Déboguer (raccourci clavier : Alt+F8).

  • Ou cliquez droit sur la ligne de code où vous désirez interrompre votre programme et sélectionnez le choix Exécuter jusqu'au curseur du menu surgissant contextuel.

  • Ou cliquez sur le bouton de la barre d'outils du débogueur.

 

Les commandes permettant d'exécuter votre programme en " pas à pas " sont décrites dans les rubriques qui suivent.
