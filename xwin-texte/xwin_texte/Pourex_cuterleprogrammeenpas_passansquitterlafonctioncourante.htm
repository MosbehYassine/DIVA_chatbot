Pour exécuter le programme en pas à pas sans quitter la fonction courante

  1. Si votre programme n'est pas encore lancé, posez un point d'arrêt sur la ligne de code où vous voulez démarrer votre analyse puis lancez l'exécution du programme.

  2. Après l'interruption du programme :
    Sélectionnez le choix Pas à pas sans entrée dans les fonctions du menu Déboguer (raccourci clavier : F8).
    Ou
    Cliquez     sur le bouton de la barre d'outils du débogueur.
     
    Le débogueur exécute l'instruction courante et s'arrête sur l'instruction suivante. Si l'instruction exécutée est un appel de fonction (ou de procédure), le débogueur n'" entre " pas dans le corps de la fonction : il l'exécute normalement et s'arrête sur la ligne suivant l'appel.

  3. Répétez l'opération 2 pour continuer d'exécuter le programme, instruction par instruction.

 

Remarque : Si votre programme ne tourne pas encore, la commande " Pas à pas sans entrée dans les fonctions " lance son exécution. Le programme est alors interrompu sur sa première instruction.
