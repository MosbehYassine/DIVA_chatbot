Pour ouvrir un fichier source

Méthode 1 (si un projet est ouvert) :

  • Dans l'arbre de la fenêtre Projet (en général au niveau du sous-projet en cours dans un des dossiers suivants : Sources, Groupes de sources ou Includes) :
    Sélectionnez le fichier puis tapez Entrée
    Ou
    Double-cliquez     sur le fichier
    Ou
    Cliquez     avec le bouton droit de la souris sur le fichier et sélectionnez le choix Ouvrir.

 

Méthode 2 :

  1. Sélectionnez le choix Ouvrir du menu Fichier (raccourci clavier : Ctrl+O).
    Ou
    Cliquez     sur le bouton de la barre d'outils.
    La boîte de dialogue " Ouverture du fichier source " apparaît.

  2. S'il n'est pas déjà sélectionné, cliquez sur le dossier contenant le fichier ; la liste des fichiers de ce dossier est affichée.

  3. Si le fichier voulu n'apparaît pas dans la liste, vérifiez les options sélectées (Types et Filtre).

  4. Sélectionnez le fichier dans la liste et validez par OK.
    Ou double-cliquez sur le nom du fichier dans la liste.
    Ou saisissez son nom et validez par OK.

 

Méthode 3 :

Si le source concerné fait partie des dix sources (textes et masques confondus) les plus récemment ouverts, sélectionnez le choix Fichiers récents du menu Fichier et cliquez sur le nom du source.

 

Méthode 4 :

Cliquez droit sur un mot (ou, dans certains cas, sur une ligne) contenant le nom d'un fichier source ou objet "Xwin" (.dhsp, .dhsd, .dhsf, .dhsi, .dhsq, ...) et sélectionnez le choix du menu contextuel "Ouvrir fichier".

Remarque : Si le fichier est un dictionnaire de données (.dhsd), un second choix "Ouvrir fichier" propose d'ouvrir le fichier .dhsj (dictionnaire de jointures).
