Pour modifier les options d'aide à la saisie

L'éditeur de texte de Xwin intègre un certain nombre d'outils d'aide à la saisie des codes sources. Vous pouvez choisir quels outils doivent être mis en oeuvre ou au contraire invalidés. Pour ce faire :

  1. Sélectionnez le choix Options du menu Outils.
    La boîte de dialogue "Options" apparaît.

  2. Dans la liste des chapitres, cliquez sur Editeur de texte : Saisie assistée.
    Le volet présentant les options d'aide à la saisie est affiché.

  3. Faites votre choix parmi les options proposées.

  4. Validez par OK.
