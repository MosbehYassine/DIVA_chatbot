Rechercher une chaîne ou un mot dans plusieurs fichiers

La commande "Recherche multi-fichiers" s'utilise pour faire une recherche de mot ou de chaîne dans un ou plusieurs fichiers, préalablement chargé(s) ou non dans l'éditeur. Les options de recherche sont les suivantes :

  • Rechercher les occurrences d'une chaîne de caractères quelconques (attention, les espaces sont significatifs)
    Ou
    Rechercher les occurrences d'un mot.
    Un mot est une zone de texte dans une ligne précédée et suivie d'un symbole autre qu'une lettre, un chiffre ou le caractère "Underscore" (la zone de texte peut aussi débuter et/ou terminer la ligne).

  • Demander que la recherche tienne compte ou non de la casse des caractères, c'est à dire différencie ou non les caractères minuscules et majuscules lors des comparaisons.

  • Etendre la recherche aux sous-dossiers des dossiers choisis.

  • Traiter les masques et les dictionnaires comme des fichiers "texte".
    Attention     : dans le cas contraire, la recherche portera uniquement sur le code source des traitements des masques / dictionnaires.

Pour être pris en compte, la chaîne ou le mot doivent être entièrement contenus par une même ligne de source. Lorsqu'une occurrence est trouvée, elle est placée dans une liste affichée dans la fenêtre Recherche.

 

Pour effectuer une recherche multi-fichiers :

  • Sélectionnez le choix Recherche multi-fichiers du menu Rechercher (raccourci clavier Maj+Ctrl+F) ou cliquez sur le bouton de la barre d'outils pour appeler la boîte de dialogue correspondante.

  • Saisissez les différents champs puis lancez la recherche en cliquant sur le bouton Rechercher.

 

Les boîtes multi-choix Préfixes, Types et Dossiers permettent de préciser les fichiers concernés par la recherche :

  • Préfixes.
    Ce paramètre permet de sélectionner un préfixe ou une liste de préfixes, afin de limiter la recherche aux seuls fichiers dont le nom débute par l'un des préfixes choisis.
    Ouvrez le multi-choix (raccourci clavier : Alt+flèche en bas) pour sélectionner une des listes prédéfinies ou saisissez une liste personnelle. Les différents préfixes d'une liste doivent être séparés entre eux par un point virgule. Attention, les espaces sont significatifs.
    Un " vrai " préfixe doit se terminer par le caractère * ; si l'étoile est omise, il ne s'agit plus d'un préfixe mais du nom complet du fichier.
    Exemples     :
    *     : La recherche s'effectuera dans tous les fichiers.
    SGTP*     : La recherche concernera uniquement les fichiers dont le nom commence par SGTP.
    SPROG;STEST     : La recherche s'effectuera exclusivement dans les fichiers SPROG et STEST.
    S*;W*     : La recherche concernera tous les fichiers dont le nom commence soit par la lettre " s " soit par la lettre " w ".

  • Types.
    Ce paramètre permet de sélectionner un type ou une liste de types de fichiers.
    Ouvrez le multi-choix (raccourci clavier : Alt+flèche en bas) pour sélectionner une des listes prédéfinies ou saisissez une liste personnelle. Les différents types d'une liste doivent être séparés entre eux par un point virgule. Attention, les espaces sont significatifs.
    Exemples     :
    .dhsp     : La recherche concernera uniquement les fichiers d'extension .dhsp (sources de programme).
    .dhsf     : La recherche concernera uniquement les fichiers d'extension .dhsf (sources de masque d'écran).
    .dhsi     : La recherche concernera uniquement les fichiers d'extension .dhsi (sources de masque d'imprimante).
    .dhsw     : La recherche concernera uniquement les fichiers d'extension .dhsw (sources de masque web).
    .dhsp;.dhsf;.dhsi;.dhsw     : La recherche concernera les fichiers d'extension .dhsp, .dhsf ou .dhsi ou .dhsw.
    *     : La recherche concernera tous les types de fichiers.

  • Dossiers.
    Ce paramètre permet de sélectionner un dossier ou une liste de dossiers de recherche.
    Ouvrez le multi-choix (raccourci clavier : Alt+flèche en bas) pour sélectionner un des chemins implicites de la tâche ou saisissez une liste personnelle. Les différents dossiers d'une liste doivent être séparés entre eux par un point virgule. Attention, les espaces sont significatifs.
    Exemples     :
    /UL1/PRG     : La recherche concernera uniquement les fichiers situés dans le dossier PRG (chemin UL1).
    /UL1/PRG;/UL2/SRC;/UL3/FIC     : La recherche concernera les fichiers des dossiers PRG (chemin UL1), SRC (chemin UL2) ou FIC (chemin UL3).

 

Remarques :

  • La boîte de saisie de la chaîne à chercher est aussi un multi-choix contenant les quinze dernières chaînes recherchées. Si vous désirez opérer une nouvelle recherche d'une chaîne déjà cherchée auparavant, plutôt que la saisir une deuxième fois, ouvrez le multi-choix (raccourci clavier : Alt+Flèche en bas) et sélectionnez-la dans la liste.

  • Si vous placez le curseur " sur " un mot ou si vous sélectionnez une chaîne avant de lancer la commande, la boîte de dialogue " Recherche multi-fichiers " proposera la recherche de ce mot ou de cette chaîne par défaut.

  • La recherche se fait toujours dans le ou les fichier(s) complet(s).

  • Lorsque la fenêtre « Recherche » est en mode « Masquage automatique », le lancement d’une recherche ouvre la fenêtre pour vous permettre de consulter les éventuelles occurrences trouvées et lui transfert le focus pour qu’elle ne se referme pas immédiatement. Pour redonner rapidement le focus à la fenêtre d’édition Mdi, tapez la touche Echap.

 

Xwin affiche la liste des occurrences trouvées dans la fenêtre Recherche. Lorsque l'onglet correspondant est sélectionné, vous pouvez alors  :

  • Valider le choix Erreur/Occurrence Suivante (raccourci clavier : F4) ou le choix Erreur/Occurrence Précédente (raccourci clavier : Maj+F4) du menu Rechercher pour parcourir la liste à votre gré.
    Xwin charge au besoin le source en mémoire et place automatiquement le curseur sur la ligne concernée. Une marque spécifique est affichée en marge de la ligne contenant l'occurrence courante.

  • Vous positionner directement sur une occurrence précise en sélectionnant la ligne voulue dans la liste puis en tapant Entrée, ou en double cliquant simplement sur cette ligne.

 

 

Raccourcis clavier (lorsque l'onglet Recherche est sélectionné) :

F4

Positionnement sur l'occurrence suivante du résultat d'une recherche multi-fichiers.

Maj+F4

Positionnement sur l'occurrence précédente.
