Imprimer un fichier source

Vous pouvez imprimer soit la totalité d'un texte, soit la sélection courante. Pour ce faire, activez la fenêtre affichant le texte concerné, puis :

  • Sélectionnez le texte à imprimer si vous vous intéressez à une partie du texte seulement.

  • Validez le choix Imprimer du menu Fichier (raccourci clavier : Ctrl+P).
    La boîte de dialogue " Imprimer " apparaît.

  • Choisissez l'option de portée Sélection (si vous voulez limiter l'impression au texte actuellement sélectionné) ou l'option de portée Tout (si vous voulez imprimer la totalité du texte).

  • Au besoin, modifiez les options de mise en page puis validez par OK.

 

Les options de mise en page sont les suivantes :

  • Nombre de lignes par page : Hauteur maximale en lignes de la page imprimée.

  • Nombre de colonnes par page : Largeur maximale en colonnes de la page imprimée.

  • Envoi d'un 0C en fin de page : Option commandant l'envoi automatique du code de saut de page à la fin de chaque page (il est conseillé de cocher la case avec une imprimante laser).

  • Caractères comprimés : Option demandant l'impression du texte en caractères comprimés.
