Corriger les erreurs de compilation

Lorsqu'un compilateur détecte des erreurs syntaxiques, Xwin les affiche dans la fenêtre compte rendu. A partir de là :

  • Sélectionnez le choix Erreur Suivante du menu Rechercher (raccourci clavier : F4).
    Xwin active le source contenant la première erreur et se positionne au niveau de l'erreur. Dans un source texte, il place automatiquement le curseur sur la ligne concernée et une marque est affichée en marge pour vous permettre de facilement repérer la ligne erronée courante.
    Vous pouvez saisir immédiatement les corrections nécessaires.

  • Sélectionnez ensuite le choix Erreur Suivante (raccourci clavier : F4) ou le choix Erreur Précédente (raccourci clavier : Maj+F4) du menu Rechercher, pour passer à l'erreur suivante ou revenir sur l'erreur précédente.

  • Répétez l'opération jusqu'à ce que vous ayez corrigé toutes les erreurs.

Si vous désirez vous positionner directement sur une erreur précise :

  • Sélectionnez la ligne affichant l'erreur dans la liste des erreurs de la fenêtre Compte rendu puis tapez Entrée.

  • Ou double-cliquez simplement sur cette ligne.
