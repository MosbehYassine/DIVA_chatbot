Pour afficher les erreurs de compilation

Pour afficher l'erreur suivante :

  • Sélectionnez le choix Erreur Suivante du menu Rechercher (raccourci clavier : F4).
    S'il s'agit du premier accès aux erreurs après la compilation, Xwin affiche la première erreur détectée par le compilateur.

 

Pour afficher l'erreur précédente :

  • Sélectionnez le choix Erreur Précédente du menu Rechercher (raccourci clavier : Maj+F4).
    S'il s'agit du premier accès aux erreurs après la compilation, Xwin affiche directement la dernière erreur détectée par le compilateur.

 

Pour vous positionner directement sur une erreur précise :

  1. Si besoin est, affichez la fenêtre compte rendu.

  2. Sélectionnez la ligne affichant l'erreur dans la liste des erreurs de la fenêtre Compte rendu puis tapez Entrée.
    Ou
    Double-cliquez     simplement sur cette ligne.

 

Dans tous les cas, Xwin active le source contenant l'erreur et place le curseur sur la ligne concernée. Une marque est affichée en marge pour vous permettre de repérer la ligne erronée courante.

Vous pouvez saisir immédiatement les corrections nécessaires.
