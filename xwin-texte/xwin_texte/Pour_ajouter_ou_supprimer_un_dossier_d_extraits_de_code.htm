Pour ajouter ou supprimer un dossier d'extraits de code

  1. Sélectionnez le choix Gestionnaire d’extraits de code du menu Outils.
    La boîte de dialogue "Gestionnaire des extraits de code" est ouverte.
     

  2. Pour ajouter un dossier, cliquez sur le bouton Ajouter puis sélectionnez le dossier voulu.
    Remarque : Xwin ne fait pas de recherche dans les sous-dossiers ; le cas échéant, ajoutez les sous-dossiers à la liste.
     

  3. Pour retirer un dossier, cliquez sur le bouton Supprimer après avoir sélectionné le dossier à retirer dans l'arbre.
     

  4. Validez par OK.

 
 

Si vous expansez un dossier dans l'arbre affiché dans le cadre de gauche, vous affichez la liste de tous les fichiers d'extraits de code contenus par ce dossier.

Si vous sélectionnez un de ces fichiers, vous affichez dans le cadre de droite toutes les informations sur ce fichier (identifiant, auteur, descriptif et code source). Vous pouvez alors cliquer sur le bouton Editer pour charger le fichier sélectionné dans Xwin.
