Pour sauvegarder un fichier source

  1. Activez la fenêtre concernée.

  2. Sélectionnez le choix Enregistrer du menu Fichier (raccourci clavier : Ctrl+S).
    Ou
    Cliquez     sur le bouton de la barre d'outils.

  3. Si le fichier n'a pas encore été nommé, la boîte de dialogue " Sauvegarde du fichier source texte " apparaît. Dans ce cas :

  4. S'il n'est pas déjà sélectionné, cliquez sur le dossier de stockage.

  5. Entrez le nom du fichier.

  6. Validez par OK.

 

Autre méthode :

  1. Cliquez avec le bouton droit de la souris sur l’onglet affichant le nom du fichier à sauvegarder.

  2. Sélectionnez le choix Enregistrer du menu contextuel.

 

Nota : La sauvegarde d’un source de traitements sauve également le masque/dictionnaire concerné (et réciproquement).
