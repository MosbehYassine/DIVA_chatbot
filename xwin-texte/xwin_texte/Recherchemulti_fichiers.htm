Recherche multi-fichiers

Utilisez cette boîte de dialogue (raccourci clavier Maj+Ctrl+F) pour rechercher les occurrences d'une chaîne de caractères ou d'un mot dans plusieurs fichiers, déjà chargés ou non dans l'éditeur. Pour être sélectionnée, une chaîne doit être entièrement contenue par une même ligne de source.

 

Chaîne à rechercher

Saisissez ici la chaîne de caractères à trouver ou ouvrez le multi-choix pour sélectionner une chaîne dans la liste des précédentes recherches. Les espaces saisis sont significatifs.

Préfixes

Ce paramètre permet de sélectionner un préfixe ou une liste de préfixes, afin de limiter la recherche aux seuls fichiers dont le nom débute par l'un des préfixes choisis.
Ouvrez le multi-choix (raccourci clavier : Alt+flèche en bas) pour sélectionner une des listes prédéfinies ou saisissez une liste personnelle. Les différents préfixes d'une liste doivent être séparés entre eux par un point virgule. Attention, les espaces sont significatifs.
Un " vrai " préfixe doit se terminer par le caractère * ; si l'étoile est omise, il ne s'agit plus d'un préfixe mais du nom complet du fichier.
Exemples :
* : tous les fichiers.
SGTP* : fichiers dont le nom commence par SGTP.
SPROG;STEST : fichiers SPROG et STEST.
S*;W* : fichiers dont le nom commence par s ou w.

Types

Ce paramètre permet de sélectionner un type ou une liste de types de fichiers.
Ouvrez le multi-choix (raccourci clavier : Alt+flèche en bas) pour sélectionner une des listes prédéfinies ou saisissez une liste personnelle. Les différents types d'une liste doivent être séparés entre eux par un point virgule. Attention, les espaces sont significatifs.
Exemples :
.dhsp : fichiers d'extension .dhsp (programmes).
.dhsf : fichiers d'extension .dhsf (masques écran).
.dhsi : fichiers d'extension .dhsi (masques imprimante).
.dhsw : fichiers d'extension .dhsw (masques web).
.dhsp;.dhsf;.dhsi;.dhsw : fichiers d'extension .dhsp, .dhsf, .dhsi ou .dhsw.
* : tous les types de fichiers.

Dossiers

Ce paramètre permet de sélectionner un dossier ou une liste de dossiers de recherche.
Ouvrez le multi-choix (raccourci clavier : Alt+flèche en bas) pour sélectionner un des chemins implicites de la tâche ou saisissez une liste personnelle. Les différents dossiers d'une liste doivent être séparés entre eux par un point virgule. Attention, les espaces sont significatifs.
Exemples :
/UL1/PRG : fichiers du dossier PRG (chemin UL1).
/UL1/PRG;/UL2/SRC;/UL3/FIC : fichiers des dossiers PRG (chemin UL1), SRC (chemin UL2) ou FIC (chemin UL3).

Mot complet

Considérons une portion de texte correspondant exactement à la chaîne indiquée (attention, les espaces sont significatifs). Si vous cochez cette case, la portion de texte doit être précédée et suivie d'un symbole autre qu'une lettre, un chiffre ou le caractère "Underscore" pour être sélectionnée (remarque : la portion de texte peut aussi débuter et/ou terminer une ligne).
Si vous ne cochez pas cette case, toute portion de texte correspondant à la chaîne indiquée sera sélectionnée et ce, quelques soient les caractères la précédant ou la suivant.

Respecter la casse

Considérons une portion de texte correspondant exactement à la chaîne ou au mot indiqué (attention, les espaces sont significatifs). Si vous cochez cette case, les caractères de la portion de texte doivent être de même casse que les caractères correspondants de la chaîne pour que le résultat de la recherche soit positif.
Si vous ne cochez pas cette case, la recherche ne différencie pas minuscules et majuscules lors des comparaisons.

Chercher dans les sous-dossiers

Cochez cette case si vous souhaitez que la recherche s'étende récursivement aux sous-dossiers des dossiers choisis.

Traiter
les masques et les dictionnaires comme des textes

Si vous cochez cette case, tout masque / dictionnaire sera considéré comme un fichier "texte". Dans le cas contraire, la recherche portera uniquement sur le code source des traitements du masque / dictionnaire.
