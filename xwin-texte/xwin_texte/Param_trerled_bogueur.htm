Paramétrer le débogueur

 

Les points suivants font l'objet d'options pouvant être modifiées dans la fenêtre des options de Xwin :

  • Le débogueur de Xwin peut afficher, à la manière d'une bulle, la valeur courante de la donnée survolée par le curseur de la souris (fenêtre de débogage rapide).

  • Les valeurs peuvent être affichées soit en décimal, soit en hexadécimal (dans la fenêtre de débogage rapide, dans la fenêtre "Consulter ou modifier une variable", dans les fenêtres "Contexte", "Variables", etc.).

  • La fonction de couverture du code demande à Xwin de surveiller les chemins de code parcourus à l'occasion d'une ou plusieurs exécutions en mode débogueur. Lorsqu'elle est activée, les instructions exécutées font l'objet d'une coloration spécifique.

 

Pour accéder aux options du débogueur :

  • Sélectionnez le choix Options du menu Outils pour appeler la boîte de dialogue "Options".

  • Dans la liste des chapitres, cliquez sur Débogage : Général ou Débogage : Couverture du code pour afficher les volets présentant les options du débogueur.

 

Remarque : Le paramétrage du type d'affichage s'obtient également depuis le menu contextuel des fenêtres de débogage rapide.
