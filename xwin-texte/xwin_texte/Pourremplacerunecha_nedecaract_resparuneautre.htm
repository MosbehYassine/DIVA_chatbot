Pour remplacer une chaîne de caractères par une autre

Pour remplacer une chaîne de caractères dans le source courant :

  1. Positionnez le curseur à l'endroit où vous voulez démarrer la recherche.
    Si le curseur est situé "sur" un mot (ou un caractère non blanc) ou si une chaîne de caractères est sélectionnée, l'éditeur proposera cette entité comme chaîne de recherche par défaut.

  2. Sélectionnez le choix Remplacer du menu Rechercher (raccourci clavier Ctrl+H).
    La fenêtre de recherche et remplacement apparaît dans le coin NE de la fenêtre Mdi active.

  3. Entrez le texte à trouver dans la boîte Terme recherché (ou sélectionnez-le dans la liste des précédentes recherches, après ouverture du multi-choix). Les espaces saisis sont significatifs.

  4. Entrez le texte de remplacement dans la boîte Terme de remplacement (ou sélectionnez-le dans la liste des précédents remplacements, après ouverture du multi-choix). Les espaces saisis sont ici aussi significatifs. Le texte de remplacement peut être vide.

  5. Sélectionnez les options de recherche désirées.

  6. Cliquez sur le bouton :

    • (Remplacer, chercher l'occurrence suivante) pour lancer une recherche (si la chaîne recherchée n'est pas déjà sélectionnée dans le source) ou remplacer la chaîne recherchée (si elle est déjà sélectionnée dans le source). Dans les deux cas, l'éditeur recherche l'occurrence suivante et la sélectionne si elle existe.
      Utilisez le bouton pour ignorer la chaîne couramment sélectionnée et passer à l'occurrence suivante.

      Remarque       :
      L'éditeur analyse le fichier de manière circulaire. La recherche reprend automatiquement au début du fichier si la fin du fichier est atteinte. Un temps d'arrêt a lieu lorsqu'une boucle complète a été effectuée (message en barre d'état "Aucune autre occurrence").
       

    • (Remplacer tout) pour procéder au remplacement de toutes les occurrences de la chaîne trouvées dans le texte (sans demande de confirmation occurrence par occurrence). Le nombre d'occurrences remplacées est affiché en barre d'état.
