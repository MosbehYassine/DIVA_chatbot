Imprimer

Utilisez cette boîte de dialogue (raccourci clavier Ctrl+P) pour imprimer le fichier source ou le texte sélectionné courant.

 

Portée

Choisissez l'option :
Tout pour imprimer la totalité du fichier source en cours.
Sélection pour limiter l'impression au texte actuellement sélectionné.

Nombre de lignes
par page

Indiquez ici la hauteur maximale en lignes de la page imprimée.

Nombre de colonnes
par page

Indiquez ici la largeur maximale en colonnes de la page imprimée.

Envoi d'un 0C
en fin de page

Cochez cette case pour commander l'envoi automatique du code de saut de page à la fin de chaque page (conseillé avec une imprimante laser).

Caractères comprimés

Cochez cette case pour imprimer le texte en caractères comprimés.
