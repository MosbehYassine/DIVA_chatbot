Cacher des commentaires ou des fonctions

La pseudo-instruction Diva /HideFunctions peut être utilisée dans votre code pour que des fonctions ou des commentaires n'apparaissent pas dans la liste des membres ou dans les fenêtres d'informations.

 

La pseudo-instruction Diva /ShowFunctions rétablit un fonctionnement normal.

 

Attention : /HideFunctions appliquée à une fonction ne la cache que si le source qui la contient a été recompilé et n'appartient pas au sous-projet courant.

 

Exemple 1 : la fonction module_f2 et la procédure module_p2 sont cachées.

 

   ...

 

   public function int module_f1 (p1)

   ;

   ; Commentaires de module_f1

   ;

   1 p1 N

   beginf

      ...

   endf
 

/HIDEFUNCTIONS

   public function int module_f2 (p2)

   ;

   ; Commentaires de module_f2

   ;

   1 p2 N

   beginf

      ...

   endf

public procedure module_p2

   beginp

      ...

   endp
/SHOWFUNCTIONS

 

  public procedure module_p1

   beginp

      ...

   endp

 

 

Exemple 2 : les commentaires de la procédure module_p3 sont cachés.

 

...

 

public procedure module_p3 (p3)

/HIDEFUNCTIONS

;

; Commentaires de module_p3

;

/SHOWFUNCTIONS

1 p3 N

beginp

   ...

endp
