Pour modifier la couleur des soulignages

  1. Sélectionnez le choix Options du menu Outils.
    La boîte de dialogue "Options" apparaît.

  2. Dans la liste des chapitres, cliquez sur Environnement : Police et couleurs.
    Le volet présentant les options liées aux couleurs est affiché.

  3. Sélectionnez l'élément concerné dans la liste Eléments affichés.
    Deux couleurs sont utilisées pour le soulignage des erreurs et avertissements détectés par les compilations "en ligne". Les éléments correspondants sont : Compilation : Erreur et Avertissement.

  4. Sélectionnez la couleur voulue :
    16 couleurs de base     sont accessibles dans la liste des choix du multi-choix Caractères / Bordures.
    Pour obtenir une autre couleur, cliquez sur le bouton Personnaliser correspondant, qui fait appel à la boîte de dialogue "Couleurs" standard de Windows.

Pour restaurer les couleurs (et la police) de base, cliquez sur le bouton Police et couleurs par défaut.
