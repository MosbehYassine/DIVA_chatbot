Pour réactiver le dernier fichier actif

Lorsque plusieurs fichiers sont chargés dans l'éditeur, il arrive fréquemment qu'en travaillant sur le fichier A, on veuille ponctuellement consulter le fichier B puis revenir au fichier A (en mode plein écran). Pour réaliser cette opération :

  1. Vous êtes sur le fichier A. Tapez à plusieurs reprises Ctrl+Tab, SANS lâcher la touche Ctrl, jusqu'à atteindre le fichier B.

  2. Relâchez la touche Ctrl.

  3. Effectuez ce que vous avez à faire sur le fichier B.

  4. Tapez à nouveau Ctrl+Tab. Vous revenez au fichier A.
