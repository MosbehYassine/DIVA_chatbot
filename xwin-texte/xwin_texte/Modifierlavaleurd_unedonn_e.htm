Modifier la valeur d'une donnée

Quand l'exécution est interrompue, suite à un point d'arrêt ou en mode pas à pas, vous pouvez modifier le contenu des variables de votre programme, par exemple pour tester différentes stratégies ou pour "corriger" les effets d'un bogue en temps réel.

Pour modifier la valeur d'une donnée :

 

Fenêtre de débogage rapide :

  • Placez le curseur souris sur la variable à modifier pour ouvrir la fenêtre de débogage rapide (à la manière d'une bulle).

  • Cliquez dans la zone affichant son nom ou sa valeur (ou cliquez droit sur la ligne concernée et sélectionnez le choix Modifier la valeur du menu contextuel).

  • Saisissez la nouvelle valeur.
    Attention     : une chaîne alphanumérique doit être encadrée de ' ou ".

  • Tapez Tab ou Entrée pour valider la saisie (ou cliquez hors zone de saisie dans la fenêtre).
    Tapez Echap pour abandonner.

 

Boîte de dialogue Consulter / Modifier une variable :

  • Placez le curseur sur la donnée ou sélectionnez-la dans votre source.

  • Appelez le choix Consulter / Modifier une variable du menu Déboguer (raccourci clavier : Maj+Ctrl+F8) ou cliquez sur le bouton de la barre d'outils du débogueur, pour afficher la boîte de dialogue "Consulter / Modifier une variable".

  • Entrez la nouvelle valeur dans la boîte Nouvelle valeur.
    Attention     : une chaîne alphanumérique doit être encadrée de ' ou ".

  • Cliquez sur le bouton Assigner.
