Pour arrêter l'exécution du programme sur une instruction

Pour interrompre le programme avant l'exécution d'une instruction :

 

Méthode 1 (arrêt sur ligne simple – souris) :

  1. Cliquez dans la partie Gauche de la marge (curseur souris en forme de flèche pointant au NO), à hauteur de la ligne de source choisie.

    Ou

    Cliquez     dans la marge avec le bouton droit de la souris puis sélectionnez le choix Poser/Annuler un point d'arrêt du menu contextuel.

 

Méthode 2 (arrêt sur ligne simple – barre d'outils) :

  1. Placez le curseur sur la ligne de source contenant l'instruction.

  2. Cliquez sur le bouton de la barre d'outils.
    Un cercle coloré apparaît dans la marge de la ligne pour signaler la présence d'un point d'arrêt sur cette ligne. Cette même opération effectuée une nouvelle fois annule le point d'arrêt posé (le cercle coloré disparaît).

 

Méthode 3 (arrêt sur ligne simple – menu principal) :

  1. Placez le curseur sur la ligne de source contenant l'instruction.

  2. Sélectionnez le choix Poser / Annuler un point d'arrêt du menu Déboguer (raccourci clavier : Ctrl+B).
    Un cercle coloré apparaît dans la marge de la ligne pour signaler la présence d'un point d'arrêt sur cette ligne. Cette même opération effectuée une nouvelle fois annule le point d'arrêt posé (le cercle coloré disparaît).

 

Méthode 4 (arrêt sur ligne simple – menu contextuel) :

  • Cliquez droit sur la ligne de source contenant l'instruction pour ouvrir le menu contextuel et sélectionnez le choix Poser / Annuler un point d'arrêt.
    Un cercle coloré apparaît dans la marge de la ligne pour signaler la présence d'un point d'arrêt sur cette ligne. Cette même opération effectuée une nouvelle fois annule le point d'arrêt posé (le cercle coloré disparaît).

 

Méthode 5 (tous arrêts sur ligne) :

  1. Placez le curseur sur la ligne de source contenant l'instruction.

  2. Sélectionnez le choix Points d'arrêt du menu Déboguer (raccourci clavier : Maj+Ctrl+B).
    La boîte de dialogue " Points d'arrêt " apparaît ; remarquez que le numéro de ligne est automatiquement renseigné avec la ligne courante dans la boîte Ligne.

  3. Sélectionnez l'option Arrêt sur ligne (ou, s'il y a lieu, l'option Arrêt sur ligne si expression vraie ou Arrêt sur ligne si expression change) dans la boîte Type.

  4. Le cas échéant, spécifiez l'expression dans la boîte Expression.

  5. Cliquez sur le bouton Ajouter.
    La liste des points d'arrêt montre maintenant le nouveau point d'arrêt.

  6. Cliquez sur le bouton OK.
