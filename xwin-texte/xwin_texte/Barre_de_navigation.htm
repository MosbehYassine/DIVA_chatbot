Barre de navigation

 

La barre de navigation s'affiche au dessus de la fenêtre d'édition et comporte deux listes déroulantes.

 

Source Diva

Cette barre permet de consulter le nom de la fonction en cours d'édition et d'accéder directement à une fonction particulière de votre code.

  • La liste de droite contient toutes les procédures et fonctions du source courant.
    Remarque : si ce dernier est un source exécutable, la liste inclut la "fonction" Main.

    Le cas échéant, la liste affiche le nom de la fonction en cours d'édition (elle affiche un élément vide si le curseur clavier n'est ni à l'intérieur d'une fonction, ni à l'intérieur du Main).
     

  • Le contenu de la liste de gauche dépend du type de source :

    • Cas d’un source principal
      La liste contient les fonctions définies dans tous les fichiers Include du programme.

    • Cas d’un Include
      La liste contient les fonctions définies dans le source principal plus celles définies dans tous les autres fichiers Include du programme (restriction : si plusieurs sources principaux du sous-projet référencent l'Include, le contenu de la liste de gauche correspondra au dernier programme compilé en ligne ; cette restriction peut concerner les traitements de base et de surcharge d'un masque ou d'un dictionnaire).

Utiliser la barre de navigation
 

Source Diva

  • Consulter le nom de la fonction en cours d'édition
    La liste de droite affiche en permanence le nom de la fonction en cours d'édition. Elle affiche un élément vide si le curseur clavier n'est ni à l'intérieur d'une fonction, ni à l'intérieur du Main. Ceci s'avère très pratique, en particulier lorsque le code d'une fonction est particulièrement long, pour savoir dans quelle fonction vous vous trouvez, sans être obligé de remonter dans le texte jusqu'à sa déclaration.
     

  • Accéder directement à une fonction particulière
    Si vous sélectionnez un élément d’une des listes, vous vous rendez immédiatement sur la fonction choisie.

Désactiver la barre de navigation

Décochez la case "Afficher la barre de navigation" dans les options de l'éditeur de texte (volet Saisie assistée). Pour plus d'informations, consultez la rubrique Modification des options et désactivation des fonctions d'assistance au codage.
