Paramétrer les exécutions

Pour démarrer une exécution, Xwin doit connaître le nom du programme objet que vous désirez lancer.

En effet, d'une part l'éditeur de textes vous permet de charger plusieurs sources de programme exécutables, d'autre part il n'est pas interdit de déboguer un programme lancé indirectement : vous pouvez ainsi demander l’exécution initiale du programme Y (qui appelle ou chaîne au programme X) alors que c'est le programme X que vous voulez déboguer. Deux exemples :

  • Le programme Y appelle le programme X à déboguer en lui passant des paramètres et vous voulez vérifier ce passage de paramètres.

  • Le programme X à déboguer doit être lancé depuis le menu Y de l’application (cas, par exemple, des applications Divalto).

Si vous travaillez dans le cadre d'un projet Xwin, le paramétrage des exécutions s'effectue au niveau des propriétés des projets et des sous-projets.

 

 

La suite de cette rubrique concerne uniquement les applications exécutées HORS cadre d'un projet de Xwin.

 

Hors projet, le nom du programme objet à lancer peut être spécifié dans les paramètres d’exécution.

Pour ouvrir la boîte de dialogue des paramètres et accéder aux options d'exécution des programmes Diva :

  • Sélectionnez le choix Options du menu Outils.

  • Dans la liste des chapitres, cliquez sur Compilation, exécution hors projet pour afficher le volet présentant les options d'exécution :

    • Si le champ "Nom du programme à exécuter" est garni, Xwin lancera l'objet spécifié ici.

    • Si ce champ est laissé vide, Xwin lancera l'objet correspondant au source situé dans la fenêtre couramment active.
