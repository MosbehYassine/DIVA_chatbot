Consulter / Modifier une variable

Utilisez cette boîte de dialogue (raccourci clavier Maj+Ctrl+F8) pour :

  • Consulter ou modifier la valeur d'une variable.

  • Ajouter une variable dans la fenêtre Variables.

 

La boîte liste Valeur courante affiche la valeur actuelle de la donnée saisie dans la boîte Expression, après validation du bouton Recalculer (ou après la frappe de Entrée).

S'il s'agit d'un enregistrement ou d'un tableau, le signe plus (+) ou moins (-) est affiché en première colonne : Double-cliquez sur une ligne comportant le signe plus pour "expanser" la structure (afficher les données de l'enregistrement ou les éléments du tableau) ; double-cliquez sur une ligne comportant le signe moins pour la "réduire".

 

Expression

Nom de la variable à afficher ou à modifier.

Nouvelle valeur

Valeur à affecter à la variable, après validation du bouton Assigner.

Valeur courante

Valeur actuelle de la variable.

 

Recalculer

Demande le calcul de la variable saisie dans la boîte Expression et affiche le résultat dans la boîte Valeur courante.

Assigner

Dans votre programme, affecte la valeur saisie dans la boîte Nouvelle valeur à la variable en cours.

Ajouter aux variables

Place la variable en cours dans la fenêtre Variables. Affiche cette fenêtre si l'onglet correspondant n'est pas déjà sélectionné.
