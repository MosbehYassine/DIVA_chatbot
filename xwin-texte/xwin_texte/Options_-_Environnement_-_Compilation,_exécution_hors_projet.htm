Options - Environnement - Compilation, exécution hors projet

 

Cette rubrique ne concerne pas les applications exécutées dans le cadre des projets de Xwin.

 

 

Options de compilation (hors projet)
 
Compilation en mode : Choisissez l'option :

  • Débogueur pour bénéficier des fonctions du débogueur en phase de mise au point de vos programmes.

  • Normal pour générer les codes objet utilisés en exploitation.

 
Source à compiler : Deux options sont possibles :

  • Paramètre à espace : Xwin compilera le programme source situé dans la fenêtre active au moment où vous lancerez la compilation. Cette solution est intéressante lorsque vous êtes amené à développer plusieurs programmes en même temps.

  • Paramètre renseigné : Xwin compilera toujours le programme dont le nom de source est indiqué ici, et ce, quelque soit la fenêtre active au moment où vous lancerez la compilation. Cette solution est très pratique lorsque vous développez un programme unique faisant référence à des fichiers "Include" : vous pouvez travailler dans une fenêtre contenant un fichier Include et lancer la compilation du programme principal sans quitter cette fenêtre.

Remarque : Ce paramètre ne concerne pas les compilations de masque : pour compiler un masque, il faut toujours que la fenêtre correspondante soit active au moment de lancer la compilation.
 
Options de compilation : Si vous désirez générer un listing de compilation et/ou un journal des comptes rendus d'erreur, indiquez ici une ou plusieurs des commandes suivantes, séparées entre elles par des espaces :

  • Lfic (lettre L suivie d'un nom de fichier) : Demande la génération d'un listing de compilation dans le fichier "fic".

  • Zfic (lettre Z suivie d'un nom de fichier) : Demande aussi la génération d'un listing de compilation dans le fichier "fic" mais le listing contiendra en supplément le code généré par le compilateur.

  • Cfic (lettre C suivie d'un nom de fichier) : Demande au compilateur d'écrire un compte rendu global de la compilation (nombre d'erreurs et d'avertissements) dans le fichier journal "fic".

 
Dossier des fichiers objet : Deux options sont possibles :

  • Paramètre renseigné : Xwin stockera toujours les fichiers objet dans le dossier indiqué ici. Les fichiers objet qui n'existent pas encore dans ce dossier seront automatiquement créés.
    Si le nom du source ne comporte pas d'extension, le nom de l'objet est déduit du nom du source en lui ôtant son premier caractère (exemple : SPROG => PROG) ; sinon, l'extension .dhsp est remplacée par .dhop (exemple : PROG.dhsp => PROG.dhop).

  • Paramètre à espace : Xwin ne créera aucun fichier objet de manière automatique. Il ouvrira une boîte de dialogue vous demandant de choisir le dossier de stockage.

 

 

Options d'exécution (hors projet)
 
Nom du programme à exécuter : Indiquez ici le nom du programme objet que Xwin devra lancer lorsque vous commanderez une exécution. Si ce champ est laissé vide, Xwin lancera l'objet correspondant au programme source en cours d'édition.
 

Remarque : Il est possible de nommer ici le programme Y (qui appelle ou chaîne au programme X) alors que c'est le programme X que vous voulez déboguer ; par exemple :

  • Le programme Y appelle le programme X à déboguer en lui passant des paramètres et vous voulez vérifier ce passage de paramètres.

  • Le programme X à déboguer doit être lancé depuis le menu Y de l’application (cas, par exemple, des applications Divalto).
