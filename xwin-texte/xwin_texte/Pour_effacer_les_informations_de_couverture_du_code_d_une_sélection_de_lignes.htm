Pour effacer les informations de couverture du code d'une sélection de lignes

  • Sélectionnez le groupe de lignes voulu dans le code source.

  • Sélectionnez le choix Marquer la sélection comme non couverte du sous-menu Couverture du code du menu Déboguer ou du menu contextuel de l'éditeur de textes.

    Hors phase de débogage     (voir remarque ci-dessous) et si le choix du menu est grisé (*), commencez par rétablir le mode "Colorier les lignes couvertes" (voir la rubrique Pour activer ou désactiver la colorisation des lignes couvertes).

    (*)     : Ceci peut arriver si vous avez validé l'option de Xwin "Activer / Désactiver automatiquement la colorisation des lignes couvertes en Début / Fin de session de débogage", car hors débogage, le mode "Colorier les lignes couvertes" est normalement désactivé.
     

Remarque :

Cette opération est considérée comme une modification du source avec toutes les implications que cela comporte (montée de l'* de modification dans la barre de titre de la fenêtre, application possible des commandes Annuler et Recommencer, enregistrement définitif à la sauvegarde du source, etc.). En particulier, comme la trace est automatiquement interrompue lorsqu'un source du sous-projet est modifié, cette commande est interdite en cours de débogage (afin de ne pas interrompre la trace ipso facto).
