Ouvrir un fichier source

Pour charger un fichier source existant (avec création d'une nouvelle fenêtre MDI dans Xwin), vous disposez des méthodes suivantes :

  • Dans l’arbre de la fenêtre Projet, sélection du fichier dans une des listes de sources d’un sous-projet (chaque sous-projet propose jusqu’à trois listes de sources : Sources, Groupes de sources et Includes).

  • Commande "Ouvrir" du menu principal.

  • Sélection du fichier dans la liste des sources ouverts récemment.

  • Commande "Ouvrir" du menu contextuel de l'éditeur de textes.

 

 

1. Sélection dans la fenêtre Projet.

Cf. Projet : Pour charger un fichier dans l'éditeur.

 

 

2. Commande Ouvrir du menu principal.

Cette commande est accessible par deux moyens :

  • Sélectionnez le choix Ouvrir du menu Fichier (raccourci clavier : Ctrl+O).

  • Ou cliquez sur le bouton de la barre d'outils.

La boîte de dialogue " Ouverture du fichier source " apparaît :

  • Sélectionnez le dossier contenant le fichier.

  • Sélectionnez le fichier dans la liste ou saisissez son nom.

  • Validez par OK (ou double-cliquez sur le nom du fichier).

Cette boîte de dialogue propose trois autres paramètres :

  • Types : Détermine les fichiers à afficher dans la liste :
    – Masques écran : fichiers d'extension .dhsf.
    – Masques imprimante : fichiers d'extension .dhsi.
    – Masques Web : fichiers d'extension .dhsw.
    – Diva : fichiers d'extension .dhsp.
    – Sources : fichiers d'extension .dhsd, .dhsq, .dhsj, .dhsf, .dhsi, .dhsw ou .dhsp.
    – Dictionnaires : fichiers d'extension .dhsd, .dhsq, .dhsj.
    – Projets : fichiers d'extension .dhpt.
    – Objets : fichiers d'extension .dhof, .dhoi, .dhow ou .dhop.
    – *.* : tous les fichiers.

  • Mode (Auto/Texte) : Ce multi-choix concerne uniquement l'ouverture des fichiers source des dictionnaires et des masques. Il n'a aucun effet ici.

  • Filtre : Permet de restreindre la liste des fichiers proposés aux seuls fichiers respectant ce filtre (en plus du type précédemment sélectionné). Après saisie d’un nouveau filtre, cliquez sur le bouton Actualiser. Exemples :
    menu* pour n’afficher que les fichiers dont le nom commence par "menu"
    *gtt* pour n’afficher que les fichiers dont le nom contient la chaîne "gtt"

 

3. Sélection dans la liste des sources ouverts récemment.

Si le source à charger fait partie des dix sources (textes et masques confondus) les plus récemment ouverts, sélectionnez le choix Fichiers récents du menu Fichier et cliquez sur le nom du source.

 

 

4. Commande "Ouvrir" du menu contextuel de l'éditeur de textes.

Ce choix est actif uniquement lorsque la souris est placée sur un mot (ou, dans certains cas, sur une ligne) contenant le nom d'un fichier source ou objet "Xwin" (.dhsp, .dhsd, .dhsf, .dhsi, .dhsq, ...).

Remarque : Si le fichier est un dictionnaire de données (.dhsd), un second choix "Ouvrir fichier" propose d'ouvrir le fichier .dhsj (dictionnaire de jointures).

 

Remarque : Vous ne pouvez pas ouvrir deux fois le même fichier dans deux fenêtres différentes.
