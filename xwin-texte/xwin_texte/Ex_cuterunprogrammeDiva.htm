Exécuter un programme Diva

Après la compilation sans erreur du programme, vous pouvez lancer son exécution. Deux modes d'exécution sont possibles :

  • Exécution sous contrôle du débogueur.
    Attention     :

    • Il n'est pas possible de déboguer simultanément plusieurs instances de votre programme.

    • Pour bénéficier des fonctions du débogueur, vous devez avoir compilé votre programme en mode "débogueur".

    • Pour bénéficier de la fonction de couverture du code, vous devez avoir compilé votre programme avec l'option correspondante (en être dans le cadre d'un projet de Xwin).
       

  • Exécution sans mise en route du débogueur.
    Remarques     :
    -     Ce mode d'exécution est permis, même si le programme a été compilé en mode "débogueur".
    -     Le lancement simultané de plusieurs instances du programme est ici possible.

 

Pour lancer l'exécution du programme sous contrôle du débogueur :

  • Sélectionnez le choix Exécuter du menu Déboguer (raccourci clavier : F5) ou cliquez sur le bouton de la barre d'outils.

  • Les choix du menu Déboguer :
    -     Pas à pas sans entrée dans les fonctions (F8),
    -     Pas à pas avec entrée dans les fonctions (Maj+F8),
    -     Exécuter jusqu'au curseur (Alt+F8)
    démarrent également l'exécution du programme en mode mise au point. Elles permettent une interruption immédiate, sans pose préalable de point d'arrêt.

 

Pour lancer l'exécution du programme sans mise en route du débogueur :

  • Sélectionnez le choix Exécuter sans déboguer du menu Projet (raccourci clavier : Ctrl+F5).

 

Pour déboguer un programme non lancé depuis Xwin en mode débogueur :

Il est possible de déboguer un programme dont l'exécution n'a pas été lancée depuis Xwin en mode débogueur :

  • Sélectionnez le choix Attacher une tâche du menu Déboguer.
    OU
    Sélectionnez le choix Attacher une tâche et interrompre l'exécution pour également interrompre l'exécution du programme.

  • Sélectionnez la tâche concernée dans la liste des tâches en cours.

Le programme doit toutefois avoir été compilé en mode débogueur.
