Pour paramétrer les exécutions de programme Diva

 

Applications exécutées dans le cadre des projets de Xwin.

 

Si vous travaillez dans le cadre d'un projet Xwin, le paramétrage des exécutions s'effectue au niveau des propriétés des projets et des sous-projets.

 

 

Applications exécutées hors projet Xwin.

  1. Sélectionnez le choix Options du menu Outils.
    La boîte de dialogue "Options" apparaît.

  2. Dans la liste des chapitres, cliquez sur Compilation, exécution hors projet.
    Le volet présentant les options d'exécution est affiché.

  3. Si vous garnissez le champ Nom du programme à exécuter, Xwin lancera l'objet spécifié ici lorsque vous commanderez une exécution. Si au contraire ce champ est laissé vide, Xwin lancera l'objet correspondant au programme source en cours d'édition.

  4. Validez par OK.
