Pour modifier la valeur d'une donnée

Pour modifier la valeur d'une donnée :

 

Méthode 1 (fenêtre de débogage rapide) :

  1. Placez le curseur souris sur la variable et attendez quelques instants sans bouger la souris (comme pour l'affichage d'une bulle), afin d'ouvrir la fenêtre de débogage rapide.

  2. Cliquez dans la zone affichant son nom ou sa valeur
    OU
    cliquez droit sur la ligne concernée et sélectionnez le choix Modifier la valeur du menu contextuel.

  3. Entrez la nouvelle valeur.
    Attention     : une chaîne alphanumérique doit être encadrée de ' ou ".

  4. Tapez Tab ou Entrée pour valider la saisie (ou cliquez hors zone de saisie dans la fenêtre).
    Tapez Echap pour abandonner.

 

Méthode 2 (boîte de dialogue Consulter / Modifier une variable) :

  1. Placez le curseur sur la variable ou sélectionnez-la dans votre source.

  2. Validez le choix Consulter / Modifier une variable du menu Déboguer (raccourci clavier : Maj+Ctrl+F8) ou cliquez sur le bouton de la barre d'outils du débogueur.
    La boîte de dialogue " Consulter / Modifier une variable " apparaît.

  3. Entrez la nouvelle valeur dans la boîte Nouvelle valeur.

  4. Cliquez sur le bouton Assigner.
