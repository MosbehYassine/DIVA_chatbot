Le menu contextuel des onglets

 

Onglets « Fichiers »

  • Enregistrer : Sauve le fichier actif.

  • Fermer : Ferme le fichier actif (et la fenêtre MDI correspondante).

  • Fermer tout sauf cet élément : Ferme tous les documents sauf le fichier actif.

  • Fermer tous les éléments à droite : Ferme tous les documents placés à droite du fichier actif.

  • Fermer tous les éléments à gauche : Ferme tous les documents placés à gauche du fichier actif.

  • Fermer tous les documents : Ferme tous les documents.

  • Copier le chemin complet : Copie le nom complet du fichier actif dans le presse-papier.

  • Copier le chemin : Copie le chemin du fichier actif dans le presse-papier.

  • Copier le nom : Copie le nom du fichier actif dans le presse-papier.

  • Ouvrir le dossier contenant : Ouvre le dossier contenant le fichier actif dans l'explorateur et sélectionne ce fichier.

 

Barre de titre des fenêtres correspondant aux autres onglets

  • Désancrer (onglet compte rendu) : Désancre la fenêtre "onglet".

  • Masquer automatiquement : Active / désactive le mode « Masquage automatique ».

  • Copier le contenu dans le presse-papiers (onglet compte rendu) : Copie le contenu de la fenêtre "onglet" dans le presse-papiers.

  • Effacer (onglet Messages) : Efface le contenu de la fenêtre.
