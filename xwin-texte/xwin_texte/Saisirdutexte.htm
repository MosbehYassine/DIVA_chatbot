Saisir du texte

Il existe deux modes de saisie du texte :

  • Le mode Insertion.
    Dans ce mode :

    • Les caractères tapés sont insérés dans la ligne de texte, juste derrière le curseur. Les caractères suivants de la ligne sont décalés d'une position vers la droite.

    • INS est affiché dans la partie droite de la barre d'état.

    • Le curseur clavier est une barre verticale placée à l'endroit où le caractère sera inséré.
       

  • Le mode Remplacement.
    Dans de mode :

    • Les caractères tapés annulent et remplacent, au fur et à mesure, les caractères déjà existants dans la ligne et pointés par le curseur. En fin de ligne, les nouveaux caractères sont ajoutés comme en mode insertion.

    • REM est affiché dans la partie droite de la barre d'état.

    • Le curseur clavier est un rectangle noir "recouvrant" le caractère qui sera remplacé.

 

Le passage d'un mode à l'autre s'obtient en tapant la touche Inser.
