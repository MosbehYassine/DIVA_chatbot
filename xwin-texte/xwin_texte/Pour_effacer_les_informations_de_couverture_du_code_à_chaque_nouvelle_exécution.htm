Pour effacer les informations de couverture du code à chaque nouvelle exécution

 

  1. Sélectionnez le choix Options du menu Outils.
    La boîte de dialogue "Options" apparaît.

  2. Dans la liste des chapitres, cliquez sur Débogage : Couverture du code.
    Le volet présentant les options correspondantes du débogueur est affiché.

  3. Cochez ou décochez la case Effacer les informations de couverture à chaque nouvelle exécution.
    Si la case n'est pas cochée, les informations de couverture sont conservées entre deux exécutions d'un programme. Ceci permet de couvrir les différentes portions de code des sources concernés, en passant par plusieurs exécutions successives.
    Sinon, toutes les informations attachées à     tous les sources du sous-projet courant seront effacées à chaque nouvelle exécution du programme. 

  4. Validez par OK.
