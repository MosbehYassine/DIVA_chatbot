Utiliser la fenêtre Listes

L'écran de Xwin contient une barre d'onglets Comptes rendus, située sous la zone d'affichage des fenêtres MDI. En phase de mise au point, le volet Listes affiche les listes Diva créées par le programme.

 

Afficher la fenêtre Listes

Pour faire apparaître la fenêtre " Listes " à l'écran, en phase de mise au point :

  • Cliquez sur l'onglet Listes. Si cet onglet n’apparaît pas, la fenêtre est ancrée et donc déjà affichée.
     

  • Ou sélectionnez le choix Listes du menu Déboguer : Fenêtres du débogueur.

  • Ou cliquez sur le bouton de la barre d'outils du débogueur.

Nota : Vous disposez de nombreuses possibilités pour afficher cette fenêtre à votre convenance : ancrage permanent, déplacement à l’écran, ajustement de sa taille, etc. Pour plus de détails, consultez la rubrique barre d'onglets Comptes rendus.

 

Contenu de la fenêtre Listes

La fenêtre affiche une ligne par liste Diva créée par le programme en cours. Pour chaque liste, vous trouvez les renseignements suivants :

<ticket> : <élément courant> / <nombre d'éléments> = <valeur>
 

<ticket>

Valeur du ticket associé à la liste.

<élément courant>

Position de l'élément courant (à partir de 1).

<nombre d'éléments>

Nombre d'éléments de la liste.

<valeur>

Valeur de l'élément courant.

 

 

Consulter une liste Diva

Double-cliquez sur la ligne représentant la liste à examiner. Une boîte de dialogue est affichée pour vous permettre de visualiser ses éléments.

 

La partie supérieure de la boîte donne les renseignements suivants :
 

Numéro

Valeur du ticket associé à la liste.

Courant / nombre d'éléments

Position de l'élément actuellement sélectionné (à partir de 1) / nombre d'éléments total de la liste.

Position / courant

Position / adresse de l'élément courant au moment de l'arrêt du programme.

Instance de

Lorsque le débogueur connaît la structure de l'élément placé en liste, il affiche ici le nom du dictionnaire et le nom de l'enregistrement ; dans ce cas, l'élément est automatiquement expansé (ses données composantes sont affichées).
Sinon, voir la paragraphe " Si l'élément n'est pas automatiquement expansé " ci-dessous.
 

La 1ère fenêtre affiche le contenu de l'élément sélectionné.

La 2ème fenêtre affiche, le cas échéant, les propriétés attachées à l'élément sélectionné (en décimal ou en hexadécimal si vous cochez la case "Afficher les propriétés en hexadécimal").

Entre ces deux fenêtres, une barre de redimensionnement horizontale permet de modifier leurs dimensions respectives.
 

 

Pour vous déplacer dans la liste

Utilisez l'ascenseur ou les différents boutons :

Premier élément.

Elément précédent.

Elément courant au moment de l'arrêt du programme.

Elément suivant.

Dernier élément.

Elément précisé par son numéro d'ordre.

 

Si l'élément n'est pas automatiquement expansé

Si les champs qui composent l'élément ne sont pas affichés, cela signifie que le débogueur ne sait pas déterminer "tout seul" la structure de l'élément. C'est par exemple toujours le cas avec une liste associée à un objet tableau Xwin (car des données de gestion interne sont ajoutées par Ywpf à l'enregistrement stocké en liste).

Pour expanser l'élément, cliquez sur le bouton Changer le type puis entrez le nom du dictionnaire et le nom de l'enregistrement concerné.

Exemple : Votre programme utilise un objet tableau pour la saisie des lignes détail d'une facture (enregistrement Ligne du dictionnaire Applidd) ; si vous consultez la liste associée, les champs de Ligne n'apparaîtront pas automatiquement ; pour les obtenir, cliquez sur le bouton "Changer le type" et remplissez les champs de la boîte ouverte avec les valeurs Applidd et Ligne.
