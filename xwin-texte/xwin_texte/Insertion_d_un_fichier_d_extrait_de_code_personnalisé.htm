Insertion d'un fichier d'extrait de code personnalisé

L'outil d'insertion d'extraits de code de Xwin permet d'insérer automatiquement dans votre programme des bouts de code enregistrés dans des fichiers d'extrait personnels.

 

Déclarer les dossiers de stockage des fichiers d'extrait de code

  • Utilisez le Gestionnaire d'extraits de code pour ajouter des dossiers à la liste des dossiers dans lesquels le sélecteur d'extraits de code de Xwin recherchera les fichiers d'extrait.

  • Des exemples d'extrait sont livrés dans le dossier /Divalto/Exemples/Extraits.

 

Afficher le sélecteur d'extraits de code

  • Placez le curseur sur la ligne derrière laquelle vous voulez insérer l'extrait de code.
    Remarque : La position du curseur dans la ligne (colonne) est sans importance. Xwin ne tient pas non plus compte d'une éventuelle sélection actuelle de texte.
     

  • Tapez Alt+Ctrl+E ou sélectionnez le choix Insérer un extrait de code... du menu contextuel de l'éditeur de textes.
    Ce choix fait appel au sélecteur de dossiers, composé du champ en saisie "Insérez l'extrait" et d'une boîte à liste présentant la liste des dossiers spécifiés avec le gestionnaire d'extraits de code.

    Remarques :
    Si la liste ne comporte qu'un unique dossier, Xwin saute la phase de sélection du dossier et ouvre immédiatement le sélecteur de fichiers d'extrait de code.
    Xwin enregistre le dernier dossier que vous avez sélectionné et le propose par défaut lors d'une prochaine sélection.

    Vous pouvez maintenant taper le nom d'un dossier ou sélectionner un dossier dans la liste.
     

  • Après validation d'un dossier, Xwin affiche le sélecteur de fichiers d'extrait, composé du champ en saisie "Insérez l'extrait" et d'une boîte à liste présentant la liste des fichiers d'extrait contenus par le dossier validé précédemment.

    Vous pouvez maintenant taper le nom d'un extrait ou sélectionner un extrait dans la liste.

 

Naviguer dans la Liste des dossiers ou des extraits

  • Vous pouvez naviguer dans la liste en la faisant défiler (ascenseur ou molette) ou en utilisant les touches de direction (Flèche en Bas, Flèche en Haut, Page Up, Page Down, Ctrl+Page Up, Ctrl+Page Down).

  • La sélection dans la liste « suit » les caractères tapés dans le champ "Insérez l'extrait". Si vous connaissez les premières lettres de son nom, tapez-les pour atteindre directement le dossier ou l'extrait désiré dans la liste.

Une fenêtre d'information rapide affiche le descriptif et le code source du fichier d'extrait couramment sélectionné dans la liste.



Valider un dossier ou Insérer un extrait dans le code source

Effectuez l'une des opérations suivantes :

  • Sélectionnez le nom (clic simple, touche de direction, ...) puis tapez Tab ou Entrée.

  • Double-cliquez sur le nom.

  • Sans nom sélectionné, tapez Tab ou Ctrl+Entrée pour valider l'élément de la liste qui a le focus.

L'extrait de code validé est inséré dans le document derrière la ligne pointée par le curseur clavier (cette ligne restant inchangée).



Refermer le sélecteur d'extraits

A tout moment, tapez Echap ou cliquez dans l'éditeur.
