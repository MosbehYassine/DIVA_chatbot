Fenêtre Arbre des traitements

La fenêtre Arbre des traitements est liée à l’onglet Traitements de la barre d'onglets verticaux.

Remarque : cet onglet n’est présent que lorsqu’une fenêtre MDI de type source de traitements d’un masque ou d’un dictionnaire est active.

 

La fenêtre présente les noms des procédures de traitement déclarées à l’intérieur du masque ou du dictionnaire propriétaire. Sont affichés successivement :

  • Un arbre respectant la structure naturelle du source propriétaire.
    Exemple d’un masque d’écran : celui-ci comporte un traitement propre, des pages, des menus, des barres d’outils. Une page comporte des traitements propres, des tableaux, des données. Un tableau comporte un traitement propre et des données. Un menu ou une barre d’outils comporte des choix ou des boutons générant éventuellement un traitement. Etc.

    Remarque     : ne sont présents dans cet arbre que les objets contenant au moins un traitement.
     

  • La liste de toutes les procédures, classées par ordre alphabétique.

 

Cet arbre et cette liste permettent entre autres :

  • De visualiser rapidement l’ensemble des traitements déclarés à l’intérieur du masque ou du dictionnaire.

  • De se positionner rapidement sur une procédure/fonction dans le source des traitements : il suffit de double-cliquer sur son nom dans l’arbre ou dans la liste.

  • Un menu contextuel, obtenu en cliquant droit sur une ligne, permet de plus :

    • De se positionner sur l’objet concerné dans le source propriétaire :

      • Aller à la définition de l’objet
        Ce choix active la fenêtre Mdi propriétaire et se positionne sur l’objet concerné (exemple : ouverture de la boîte de dialogue des paramètres généraux du masque ou d’une page ou sélection d’une donnée ou d’un item de ressource).

      • Aller à la définition du traitement
        Ce choix active la fenêtre Mdi propriétaire, se positionne sur l’objet concerné et, si les paramètres de cet objet sont saisis dans la fenêtre des propriétés, se place dans cette fenêtre sur le traitement concerné (exemple : sélection d’une donnée ou d’un item de ressource et placement sur le traitement dans la fenêtre des propriétés).

    • De se positionner sur une procédure/fonction dans le source des traitements :

      • Editer le traitement
        Ce choix positionne le curseur sur la procédure/fonction portant le nom sélectionné.

      • Editer le traitement de la surcharge
        Ce choix positionne le curseur sur la procédure/fonction de surcharge portant le nom sélectionné, dans le cas d'un masque de surcharge ou d'un dictionnaire surchargé.

      • Editer le traitement de la base
        Ce choix positionne le curseur sur la procédure/fonction de base portant le nom sélectionné, dans le cas d'un masque de surcharge ou d'un dictionnaire surchargé.

    • De générer le squelette de la procédure/fonction dans le source des traitements :

      • Générer le traitement
        Ce choix génère un squelette pour la procédure/fonction portant le nom sélectionné et positionne le curseur à l'intérieur du code généré.

      • Générer le traitement dans la surcharge
        Ce choix génère un squelette pour la procédure/fonction portant le nom sélectionné et positionne le curseur à l'intérieur du code généré, dans le cas d'un masque de surcharge ou d'un dictionnaire surchargé. Le code généré inclut l'appel à la procédure/fonction de base.

Pour effectuer une recherche dans l'arbre, procédez à la manière habituelle après avoir activé la fenêtre.
