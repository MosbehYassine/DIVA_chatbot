Pour insérer un extrait de code personnalisé

 

Pour afficher le sélecteur d'extraits

  1. Faites appel au Gestionnaire d'extraits de code pour déclarer les dossiers dans lesquels vous avez stockés vos fichiers d'extrait de code personnels.
     

  2. Placez le curseur sur la ligne derrière laquelle vous voulez insérer l'extrait de code.
    La position du curseur dans la ligne (colonne) est sans importance. Xwin ne tient pas non plus compte d'une éventuelle sélection actuelle de texte.
     

  3. Tapez Alt+Ctrl+E.

    OU

    Sélectionnez le choix Insérer un extrait de code... du menu contextuel de l'éditeur de textes.

    Si vous n'avez déclaré qu'un unique dossier dans le gestionnaire d'extraits de code, passez directement au point 4.

    Le sélecteur de dossiers, composé du champ en saisie "Insérez l'extrait" et d'une boîte à liste présentant la liste des dossiers spécifiés avec le gestionnaire d'extraits de code, est affiché. Vous pouvez maintenant taper le nom d'un dossier ou sélectionner un dossier dans la liste.
     

  4. Validez le dossier désiré.
     

  5. Le sélecteur de fichiers d'extrait, composé du champ en saisie "Insérez l'extrait" et d'une boîte à liste présentant la liste des fichiers d'extrait contenus par le dossier validé précédemment, est affiché. Vous pouvez maintenant taper le nom d'un extrait ou sélectionner un extrait dans la liste.

 

Pour naviguer dans la Liste des dossiers ou des extraits

  • Faites défiler la liste avec l'ascenseur ou la molette.

    OU

    Utilisez les touches de direction (Flèche en Bas, Flèche en Haut, Page Up, Page Down, Ctrl+Page Up, Ctrl+Page Down).
     

  • La sélection dans la liste « suit » les caractères tapés dans le champ "Insérez l'extrait".
    Si vous connaissez les premières lettres de son nom, tapez-les pour atteindre directement le dossier ou l'extrait désiré dans la liste.
     

  • Une fenêtre d'information rapide affiche le descriptif et le code source du fichier d'extrait couramment sélectionné dans la liste.

 

Pour valider un dossier ou insérer un extrait dans le code source

  • Sélectionnez le nom (clic simple, touche de direction, ...) puis tapez Tab ou Entrée.

    OU

    Double-cliquez     sur le nom.

    OU

    Sans nom sélectionné, tapez Tab ou Ctrl+Entrée pour valider l'élément de la liste qui a le focus.

    L'extrait de code validé est inséré dans le document derrière la ligne pointée par le curseur clavier (cette ligne restant inchangée).

 

Pour refermer le sélecteur d'extraits

  • A tout moment, tapez Echap ou cliquez dans l'éditeur.
