Parcourir les composants d'un RecordSql ou d'une Jointure Sql

 

Le nombre de lignes de source d'un RecordSql dans un dictionnaire de RecordSql ou d'une Jointure dans un dictionnaire de Jointures Sql peut rapidement devenir important. L'éditeur de Xwin offre un moyen simple d'en parcourir les divers composants. Par exemple :

  • A partir de la balise <RecordSql>, balayer toutes ses Sections (<Select>, <From>, <Where>, etc.).
    A partir de la balise <Where>, balayer tous ses Case.

  • A partir d'un de ses composants (Section ou Case), retrouver la déclaration du RecordSql correspondant.

  • Retrouver le délimiteur fermant '>' (respectivement ouvrant '<') correspondant au délimiteur ouvrant (respectivement fermant) d'une déclaration de Section.

 

Exemple 1 : Balayer les Sections d'un RecordSql (ou les Case d'un Where).

  • Placez le curseur sur le mot clé RecordSql (ou Where) et sélectionnez le choix Elément de structure suivant du menu Rechercher (raccourci clavier : Ctrl+F7).

  • Ou cliquez avec le bouton droit de la souris sur le mot clé pour ouvrir le menu surgissant et sélectionnez le même choix.

Le curseur est amené sur la 1ère Section du RecordSql (par exemple <Select>) puis, si vous renouvelez l'opération, sur ses Sections suivantes (par exemple <From>, puis <Where>, etc.). Si le curseur se trouve sur le mot clé Where, il est amené sur le 1er Case du Where puis, si vous renouvelez l'opération, sur ses Case suivants.

La commande Elément de structure précédent (raccourci clavier : Maj+Ctrl+F7) remonte le curseur sur la Section ou le Case précédent.

 

Exemple 2 : Retrouver le RecordSql "père" d'un de ses composants.

  • Placez le curseur sur le mot clé (nom de Section ou Case) et sélectionnez le choix Structure Début du menu Rechercher (raccourci clavier : Maj+F7).

  • Ou cliquez avec le bouton droit de la souris sur le mot clé pour ouvrir le menu surgissant et sélectionnez le même choix.

Le curseur est ramené sur la déclaration du RecordSql.

Remarque : La commande Structure Fin amène le curseur sur la dernière Section du RecordSql.

 

Exemple 3 : Retrouver le chevron fermant correspondant au chevron ouvrant.

  • Placez le curseur sur le '<' et sélectionnez le choix Structure Fin du menu Rechercher (raccourci clavier : F7).

  • Ou cliquez avec le bouton droit de la souris sur le '<' pour ouvrir le menu surgissant et sélectionnez le même choix.

Le curseur est positionné immédiatement derrière le chevron fermant correspondant.

 

 

Remarque :

Si le curseur n'est pas positionné sur un composant reconnu, les choix de menu sont grisés.
