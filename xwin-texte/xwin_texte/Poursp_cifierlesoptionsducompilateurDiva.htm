Pour spécifier les options du compilateur Diva (hors projet)

Ne concerne pas les applications compilées dans le cadre des projets de Xwin.

  1. Sélectionnez le choix Options du menu Outils.
    La boîte de dialogue "Options" apparaît.

  2. Dans la liste des chapitres, cliquez sur Compilation, exécution hors projet.
    Le volet présentant les options des compilations Diva est affiché.

  3. Renseignez le champ Options de compilation.

  4. Validez par OK.
