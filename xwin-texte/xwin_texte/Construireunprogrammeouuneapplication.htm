Construire un programme ou une application

Avant d'exécuter votre application, vous devez compiler les programmes, les masques et les dictionnaires qui la composent. Les compilations s'effectuent en "tâche de fond". Durant une génération, vous conservez donc la main pour éditer d'autres sources, naviguer dans votre application, etc. Seule l'exécution du programme est interdite.

Exception hors projet : une compilation de masque est faite par l'éditeur lui-même. Dans ce cas, vous perdez la main durant la compilation et vous devez en attendre la fin pour la récupérer.

 

Nous vous conseillons de créer un projet autour de votre application. Un des nombreux avantages des projets est que Xwin détermine automatiquement la liste des sources, qui doivent être recompilés suite aux modifications apportées depuis la dernière construction, et enchaîne automatiquement les compilations.

 

Xwin propose deux modes de compilation :

  • Le mode "débogueur".
    Ce mode vous permet de bénéficier des fonctions du débogueur pour effectuer la mise au point de votre programme.
    L'option complémentaire "Couverture du code" demande au compilateur de code source de Xwin de générer les informations nécessaires à la fonction de couverture du code.

  • Le mode "normal".
    Ce mode vous permet de générer le code objet qui sera ensuite utilisé en exploitation.

 

Si des erreurs sont détectées lors des compilations de sources, Xwin vous permet de les repérer très rapidement :

  • L’onglet Compte rendu affiche la liste de toutes les erreurs.

  • Si vous tapez une première fois la touche F4, Xwin charge au besoin le source concerné dans une nouvelle fenêtre, affiche cette dernière et place automatiquement le curseur sur la ligne en erreur. Vous pouvez alors corriger immédiatement votre source.

  • Les touches F4 et Maj+F4 (ou les commandes du menu équivalentes) permettent ensuite de passer à l'erreur suivante ou de revenir sur l'erreur précédente. Une marque dessinée en marge permet de repérer la ligne erronée courante.

  • L'accès direct à une erreur précise est également possible. Il suffit de double-cliquer sur la ligne voulue dans la fenêtre Compte rendu.

Si les compilations se terminent sans erreur, vous pouvez lancer l'exécution du programme.

 

Remarque : Pour vous aider à développer plus rapidement vos programmes, Xwin compile "en ligne" tous les codes source (programmes et traitements de masque ou de dictionnaire) chargés de votre sous-projet courant. En ligne (ou à la volée) signifie sans demande explicite de génération et chaque fois que vous modifiez un source. Les erreurs détectées sont immédiatement signalées par le soulignage de la zone de code concernée et si vous faites stationner la souris sur une zone soulignée, une bulle explicitant l'erreur est affichée. Attention, une vraie génération est toutefois nécessaire pour pouvoir exécuter un programme modifié.
