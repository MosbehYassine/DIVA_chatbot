Pour copier un morceau de programme ailleurs dans le source

  1. Sélectionnez la zone de texte à copier.

  2. Validez le choix Copier du menu Edition (raccourci clavier : Ctrl+Inser ou Ctrl+C).
    Ou
    Cliquez     sur le bouton

  3. Placez le curseur à l'endroit du texte où vous voulez faire la copie.

  4. Validez le choix Coller du menu Edition (raccourci clavier : Maj+Inser ou Ctrl+V).
    Ou
    Cliquez     sur le bouton

 

Rubrique de référence :

Copier, couper, coller, insérer et supprimer du texte
