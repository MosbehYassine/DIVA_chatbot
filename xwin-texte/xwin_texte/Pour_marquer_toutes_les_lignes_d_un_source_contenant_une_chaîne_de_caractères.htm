Pour marquer toutes les lignes d'un source contenant une chaîne de caractères

  • Affichez la fenêtre de recherche.

  • Dans cette fenêtre, saisissez la chaîne à rechercher et sélectionnez les éventuelles options de recherche.

  • Dans cette fenêtre, cliquez sur le bouton de la barre d'outils.
