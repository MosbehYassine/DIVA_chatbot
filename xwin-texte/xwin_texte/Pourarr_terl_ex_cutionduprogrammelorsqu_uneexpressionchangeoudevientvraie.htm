Pour arrêter l'exécution du programme lorsqu'une expression change ou devient vraie

  1. Sélectionnez le choix Points d'arrêt du menu Déboguer (raccourci clavier : Maj+Ctrl+B).

  2. Sélectionnez l'option Arrêt si expression vraie ou Arrêt si expression change dans la boîte Type.

  3. Spécifiez l'expression dans la boîte Expression.

  4. Cliquez sur le bouton Ajouter.
    La liste des points d'arrêt montre maintenant le nouveau point d'arrêt.

  5. Cliquez sur le bouton OK.
